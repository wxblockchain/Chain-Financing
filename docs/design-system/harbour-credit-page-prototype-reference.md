# Harbour Credit 现有页面继承参考

## 1. 目的与强制边界

本文件用于后续页面生成与调整。`prototypes/` 下已落库的两份原型是**已经生成的现有页面**；后续页面必须以它们为母版做增量调整，而不是把它们当作可自由改写的灵感样张。

每个新页面都属于 `existing-system adaptation`，必须遵守：

1. 先选对端别和现有 shell；
2. 再选最接近的现有页面 archetype；
3. 复用已有 token、组件、状态表面与断点；
4. 只替换本页内容区和本页必要的局部组合；
5. 不重建全局导航、字体、配色、密度、响应式策略或另一端的布局模式。

本文件与组件规范配合使用：组件规范回答“控件如何画”，本文件回答“新页面从哪一种已存在页面结构开始组合”。

## 2. 唯一现有页面基线

母版是仓库里正在运行的两份原型，不是任何外部附件：

| 端别 | 已生成页面 | 用途 |
| --- | --- | --- |
| 管理端 | `prototypes/协议管理/v1.0-协议管理-原型.html` | 管理端 app shell、密度、列表 / 详情 / 编辑布局母版 |
| 管理端 + 资产端 | `prototypes/账户与登录/v1.0-账户与登录-原型.html` | focus shell（登录、重置密码）与资产端 app shell 母版 |

两份原型共用 `prototypes/_shared/`：token、组件、侧栏、路由、Toast、弹层都在那里，
新页面不需要也不允许复制其中任何一段。

原型中的领域名称、机构、数值、日期、地址、身份信息、权限与流程规则不构成通用页面内容；
它们只能被相同层级的真实页面需求替换。

## 3. 使用顺序

新增或改造页面前，设计说明必须先写以下四项：

```text
继承端别：管理端 admin / 资产端 asset
继承 shell：app（侧栏+顶栏+内容区） / focus（居中卡片）
继承母版：<本文件第 4 节的名称>
继承 archetype：<本文件第 5 节的名称>
本页增量：<仅内容区、组件组合和状态差异>
```

若无法映射到任一 shell 或 archetype，先补充页面设计说明和评审件；不得直接生成一套新的页面语言。

## 4. 固定 shell 母版

### 4.1 管理端：sidebar + topbar + compact canvas

| 元素 | 必须继承的规则 |
| --- | --- |
| 应用框架 | 白色 238px 左侧栏 + 右侧主内容区；侧栏全高、右边线清晰，内容区 `min-width: 0` |
| 侧栏 | 品牌区、低强调分组标签、紧凑导航项与底部上下文区；导航项约 8px 纵向内边距、9px 圆角 |
| 顶栏 | 吸顶或稳定顶栏；breadcrumb 在左、轻量工具区在右；约 13px 纵向与 26px 横向内边距 |
| 画布 | `max-width: 1500px`，内容横向内边距 24–26px；标题区后接统计/筛选/内容卡，不压成一张巨型卡 |
| 密度 | 数据表头约 10–10.5px、行约 48px、操作位保持可达；结构化短值使用等宽字体 |
| 响应式 | 1280 / 1440 / 1920px 优先保证无溢出；约 1180px 时先收束双栏和统计宫格，不能挤压表格关键操作 |

管理端新页面不得使用公开层 hero、展示型大标题或宽松入口卡替代高密度画布。

### 4.2 面客公开层：header + wide content + narrative rhythm

> **仓库内暂无对应原型。** 本节保留为将来接入公开层时的设计意图，
> 在对应原型落库之前，不得作为新页面的继承母版使用。

### 4.3 面客认证后：header + subnav + main/right rail

> **仓库内暂无对应原型。** 同上，暂不作为继承母版。
> 资产端目前走的是 4.1 的 app shell，只是通过 `[data-end="asset"]` 放宽了密度。

### 4.4 focus 版式：居中卡片，无侧栏

用于登录、设置/重置密码这类未登录或强制中断的页面。实现见 `_shared/base.css` 的 `.focus*`。

| 元素 | 必须继承的规则 |
| --- | --- |
| 整页框架 | `.focus` 占满视口高度，纵向排布顶栏与主体；页底色为 `--bg` |
| 顶栏 | `.focus-top` 承载品牌与轻量工具区（语言、页面目录、PRD），带下边线；不放业务导航 |
| 主体 | `.focus-body` 水平居中、顶部对齐；卡片列 `.focus-col` 有最大宽度约束，不铺满宽屏 |
| 卡片 | 单张卡片承载一个任务；标题、说明、表单、主操作依次纵向排列，主操作只有一个 |
| 页脚 | `.focus-foot` 承载低强调补充链接 |
| 禁止 | 在 focus 版式里出现侧栏、面包屑、数据表格或多列仪表盘 |

focus 与 app 由 `registry.js` 里页面的 `layout` 字段决定，模块不自行切换整页框架。

## 5. 页面 archetype 母版

| 页面意图 | 首选母版 | 固定区块顺序 | 允许的本页增量 |
| --- | --- | --- | --- |
| 未登录 / 强制中断（登录、重置密码） | focus 版式母版 | `.focus-top` → 居中卡片 → `.focus-foot` | 卡片内的表单字段与提示 |
| 内部列表、治理、台账、配置 | 管理端列表母版 | 页面头 → 统计卡（可选） → 内容卡头/筛选 → 表格 → 状态表面 | 字段列、筛选控件、卡片数量、局部摘要 |
| 内部详情、对照、参数编辑 | 管理端双栏母版 | 页面头 → 主内容卡 / 辅助卡 → 行级详情或抽屉 | 内容字段、详情区块、局部操作位 |
| 内部记录、监控、时间序列 | 管理端记录母版 | 页面头 → 摘要卡 → 记录/时间线 + 辅助面板 | 信息层级、局部图形容器、列表项 |
| 公开入口或介绍页（暂无原型） | 面客公开叙事母版 | header → 叙事区 → 入口卡/信息区 → 补充 section → footer | 文案、插图、入口卡数量和内容 |
| 公开列表或详情页（暂无原型） | 面客公开内容母版 | header → 页面头或详情头 → 列表/详情卡 → 补充信息 → footer | 筛选项、列表条目、详情内容 |
| 认证后工作台或管理页 | 资产端 app shell 母版 | header → subnav → 页面头 → 摘要/列表卡 → 状态表面 | 摘要项、表格列、局部 actions |
| 认证后分步或资料页 | 资产端 app shell + 步骤指示器 | header → subnav → 页面头 → 主列内容 + right rail → 状态表面 | 主列区块、步骤标题、资料项 |

页面只能选一个主母版。需要多个内容形态时，先在同一母版的内容区叠加同类卡片，不能混合两个端别的全局骨架。

## 6. 共享视觉 DNA 与保留项

所有页面继续引用 [token 总览](README.md#token-总览)（值以 `_shared/tokens.css` 为准）和两份组件规范：

- [管理端组件规范](harbour-credit-admin-components.md)
- [面客端组件规范](harbour-credit-portal-components.md)

必须保留：

- 冷白背景、白色表面、蓝色主操作、青绿辅助状态、细灰边界和轻阴影；
- 无衬线正文 + 等宽结构化短值；
- `--sp-*` 基准间距与 `--radius` / `--radius-sm` / `--radius-xs` / `--radius-pill` 四档圆角；
- 页面内只有一个视觉主操作；
- 中英文与长文本的容器扩展规则，以及可见 `focus-visible`；
- 仅使用 `transform` 和 `opacity` 的低干扰动效，并尊重 `prefers-reduced-motion`。

不得新建平行 token、修改基础色板、采用浏览器默认控件风格，或为了单个页面改变全局视觉密度。

## 7. 状态表面与内容替换

状态是现有页面的一部分，后续页面按原有容器层级保留，而非另建一套反馈界面。

| 状态 | 继承方式 |
| --- | --- |
| 默认 | 继承母版的页面头、卡片、表格或主列/right rail 顺序 |
| 加载 | 在原卡片或原行结构内使用 skeleton/行内 spinner，保持高度与节奏 |
| 空 | 在原内容卡或表格体中居中显示轻量图标、短说明、可选单个修复入口 |
| 错误 | 在原容器内使用浅色提示区或 Toast；不让全页结构跳变 |
| 受限/禁用 | 保留可读信息层级，降低行动强调并留出解释区域；不能只使用灰色 |

后续任务可替换的只有真实页面所需的标题、字段、文案、内容卡和本页状态文本；不得带入既有原型中的演示数据、身份、金额、地址或业务流程。

## 8. 生成前检查表

- [ ] 已声明继承端别、shell、archetype 与本页增量。
- [ ] 没有跨端复用全局骨架；管理端与面客端保持各自密度。
- [ ] 沿用既有 token、字体、卡片、按钮、表格与状态表面。
- [ ] 新增区块在母版内容区内组合，而非重做导航、顶栏或页脚。
- [ ] 仅用真实本页需求替换内容；未复制演示数据或功能规则。
- [ ] 已验证管理端 1280/1440/1920px，或面客端的 980/920/700px 收束。
- [ ] default、loading、empty、error、restricted 的容器位置已明确。

## 9. 限制

此仓库当前沉淀的是设计文档，不含前端页面源码。该事实不降低本文件的继承约束：本文件以两份指定最新 HTML 的已生成页面为唯一可量取母版。后续若项目补充真实前端实现，应先核对其是否与该母版一致；仅在获得明确批准后才更新本文件的基线。
