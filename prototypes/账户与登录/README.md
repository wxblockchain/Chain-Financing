### B · 资产端登录页

1. **PRD 面板去掉「验收标准」一节**，只保留四类：字段与校验、关键业务规则、状态与异常分支、中英双语文案。
2. **语言切换器改下拉**（C-04 / D-24）：地球图标 + `EN` / `中文`，点开是选项列表；双端通用，未登录页与控制台一致。
3. **Toast 移到顶部居中**（C-12 / D-25）：全站唯一轻提示载体，成功与信息 3 秒、失败 5 秒、最多 3 条、可手动关闭、同内容去重。
4. **删除登录页副标题**「第一次来？…」。建号确认表达保留在 P-A10 顶部。
5. **密码显示/隐藏改眼睛图标**（D-26），带 `aria-label`，全站密码框统一。
6. **密码 Tab 下三条静态入口**：「忘记密码？」「没有密码？设置密码」「改用邮箱验证码登录 →」。前两条都去 P-A03，**复用同一套流程**（D-08）；P-A03 的标题是中性文案「设置或重置密码」，差异只在验证码校验通过后才体现（防枚举，9.3 关键约束），页面上写明了这条约束。
7. **钱包登录改「链接外部钱包」**：先有钱包地址输入框（手填，带格式与校验和提示口径），再连钱包签名；**12 条状态提示全部走顶部 Toast**（未检测到钱包 / 链接成功 / 拒绝链接 / 请求签名 / 拒绝签名 / 签名过期 / 验签失败 / 地址不一致 / 切换账户 / 网络不支持 / 切换成功 / SDK 失败），钱包面板内不再有内嵌文案。面板里挂了这 12 条的触发按钮，逐条可看。
8. **锁定态改全通道锁死 + 阶梯**：锁定时页面**只展示剩余等待时间**，没有 Tab、没有表单、没有任何解锁入口或"可改用其他方式"的表达。两档都能看到——第 1 档 10 分钟且提示带「若再次触发，锁定时间会更长」，第 2 档 30 分钟不带这句。
9. **「无法访问邮箱」入口已随账户恢复一并删除**。
10. **界面上不再出现「资产端」字样**：品牌区副标题去掉，只保留产品名与图标（管理端保留「管理端」副标题）；原型抽屉的页面目录分组改为「未登录 / 已登录 / 管理端」。PRD 面板里引用 PRD 原文的章节名（如「7.2 资产端登录」）属于 PRD 内容，按界定保留。

1. **删除建号确认独立页**，建号后直接进 P-A10，确认区块在顶部并展示本次建号所用凭据。

## 3. 怎么看

双击 HTML，建议窗口 ≥ 1280px，默认落在资产端登录页。

- **换页**：已登录页面用左侧菜单与右上角账号下拉；未登录页从顶栏 `Pages / 页面` 抽屉进入（目录按「未登录 / 已登录 / 管理端」分组）。
- **看状态**：页面顶部的状态切换器（标着 `Prototype · state`）。
- **看规格**：页头的 `PRD` 按钮。
- **换语言**：右上角语言下拉，英文是默认。

## 4. 前端实现时要特别注意的（原型只体现界面）

1. **锁定是阶梯且全通道锁死**：首次 10 分钟（N-01）、再次 30 分钟（N-02）、第 3 次起维持 30 分钟；距上次**触发**满 24 小时（N-03）归零。锁定期间登录三方式与设置/重置密码全部不可用，**没有任何提前解除通道**。
2. **锁定判定必须在凭据校验之后**（D-17）：锁定期间用户仍会收到验证码邮件，输入正确验证码后才被告知锁定。不得为省一次发信把判定提前到发码阶段——那会重新打开邮箱枚举通道。
3. **钱包手填地址只是账户选择器**，身份证明始终是签名；**服务端必须校验签名恢复地址与手填地址一致**，不一致直接拒绝（D-05）。前端比对只是快速反馈，不构成防线。
4. **设置密码与忘记密码复用同一套流程**（D-08）：同页面、同接口、同验证码用途；发码阶段标题必须中性，差异只在验证码通过后体现。
5. **钱包地址绑定后不可修改**（D-06）：服务端必须拒绝任何修改请求，不能只靠前端隐藏入口。
6. **首次绑定凭据不触发会话失效**（D-15 例外），只有变更已有凭据才触发；由服务端据字段是否由空变非空判定。

## 7. 假设与边界

1. **总览页与用户中心只做壳子**：前者本期不做内容，后者内容归 WS-303，本原型只提供落地目标、面包屑层级与凭据卡点位置。
2. **面包屑的二级层级**用用户中心下的「个人认证」做演示，实际层级由左侧菜单归属推导（5.3）。
3. **锁定倒计时是静态展示**（09:12 / 28:47），真实倒计时与到期自动恢复由前端实现。
4. 视觉口径已收敛到 `prototypes/_shared/`：token 与公共组件是唯一来源，`docs/design-system/` 只保留语义说明与约束，两者已对齐。
5. 本轮同样不维护自动化验证套件，改为人工逐页、逐状态过了一遍（12 个页面 × 全部状态 + 弹窗全部状态；1280 / 1440 / 1920 无横向溢出、无控制台报错）。

## 8. 源码组织
