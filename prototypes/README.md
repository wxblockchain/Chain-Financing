# 原型目录

原型文件统一存放于此，并与 `prd/` 中的功能名一一对应。

## 组织方式

- 公共层：`_shared/`（token、公共组件、页面登记表、公共运行时）。**唯一来源，改一处全模块生效**，用法见 `_shared/README.md`。
- 设计约束：`docs/design-system/`（该用哪个组件、什么禁止、可访问性与响应式契约）。`_shared/` 管「长什么样」，它管「该怎么用」，新增模块两边都要看。
- HTML 原型：存入 `[功能名]/` 子目录，可直接打开预览；只写本模块自己的页面、文案、演示数据与状态，公共部分一律引用 `_shared/`。
- Figma 或设计稿：在目录 README 中记录导出文件或外链地址。
- 交互说明：在 `[功能名]/README.md` 中说明关键交互。

## 注意

- `node_modules/`、`dist/` 等构建产物不入库，详见根目录 `.gitignore`。
- 大体积导出包通过 GitHub Release 管理。
