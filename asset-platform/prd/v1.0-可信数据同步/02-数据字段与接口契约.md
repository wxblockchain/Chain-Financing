## 10. 数据与字段

### 10.1 推送报文字段

| 编号 | 字段 | 类型 | 必填 | 本期使用 | 口径与校验 | 业务意义 |
| --- | --- | --- | --- | --- | --- | --- |
| D-DS-01 | 来源系统标识 | 枚举 | 是 | 是 | 本期恒为「资产平台」 | 幂等键第一段；未来多来源时区分 |
| D-DS-02 | 来源资产 ID | 文本 | 是 | 是 | 取资产管理端资产主键，即 WS-305 D-01 应收账款编号（16 位，`AR` + `yyyyMMdd` + 6 位序列）；运营端加唯一约束 `[假设-待确认 Q-DS-01]` | **幂等键 + 两端追溯主键** |
| D-DS-03 | 资产方企业标识 | 企业唯一标识 | 是 | 是 | 取 WS-305 D-02 债权方（卖方）主体 | 资产归属 |
| D-DS-04 | 资产方企业名称 | 文本 | 是 | 是 | 与标识同源，不单独维护 | 清单展示 |
| D-DS-05 | 资产方钱包地址 | 文本 | 否 | **仅存储** | `0x` + 40 位十六进制；**本期不校验业务有效性、缺失不阻断推送、不产生额外状态**；运营端展示按脱敏基线缩略 `[假设-待确认 Q-DS-02]` | 透传字段，供后续 issue 使用 |
| D-DS-06 | 资产类型 | 枚举 | 是 | 是 | 本期取值只有「应收账款」；**枚举须可扩展** `[假设-待确认 Q-DS-09]` | 分类与筛选 |
| D-DS-07 | 币种 | 枚举 | 是 | 是 | ISO 4217，取值范围同 WS-305 6.2（CNY / HKD / USD / KYD / NGN） | 金额语义，缺此项金额无法解释 |
| D-DS-08 | 资产金额 | 金额 | 是 | 是 | 取 WS-305 D-05；> 0；小数 2 位 | 清单展示基数 |
| D-DS-09 | 账期起始日 | 日期 | 是 | 是 | `yyyy-MM-dd`，≤ 到期日 | 账期起点 |
| D-DS-10 | 到期日 | 日期 | 是 | 是 | `yyyy-MM-dd`，≥ 账期起始日 | 应当回款日 |
| D-DS-11 | 合同号 | 文本数组 | 是，至少 1 个 | 是 | 取 WS-305 D-08 全部值，原样透传，**不在运营端重做去重判定** | 贸易合同标识 |
| D-DS-12 | 发票号 | 文本 | 否 | 是 | 取 WS-305 D-09 | 业务检索 |
| D-DS-13 | 贸易类型 | 枚举 | 否 | 是 | 取 WS-305 D-10 | 贸易性质 |
| D-DS-14 | 结算方式 | 枚举 | 否 | 是 | 取 WS-305 D-11 | 结算安排 |
| D-DS-15 | 确权信息快照 | 结构 | 是 | 是 | 含确权方（买方）企业标识与名称、确权时间、确权结论、提交次数（WS-305 D-19）；**快照取推送时刻的值，运营端只存不改** | 可信来源凭证 |
| D-DS-16 | 材料份数 | 整数 | 是 | 是 | 取 WS-305 D-13 的份数；**本期不传附件原件与下载链接** `[假设-待确认 Q-DS-06]` | 佐证材料存在性 |
| D-DS-17 | 推送批次号 | 文本 | 是 | 是 | 每次提交生成，重推生成新批次号 | 批量追溯 |
| D-DS-18 | 推送时间 | 时间 | 是 | 是 | UTC 存储，展示按各端基线 | 审计留痕 |
| D-DS-19 | 推送人 | 账号标识 | 是 | 是 | 资产管理端操作账号 | 审计留痕 |

> **字段清单以简报第五节的建议列表为基线，并按 WS-305 已定稿字段逐条对齐**。资产管理端如给出正式字段定义，以其为准 `[假设-待确认 Q-DS-10]`。

### 10.3 资产管理端新增字段

| 编号 | 字段 | 类型 | 口径 |
| --- | --- | --- | --- |
| D-DS-40 | 同步状态 | 枚举 | 空（未推送） / 已推送 / 推送失败；挂在应收账款记录上，**不改动 WS-305 D-15 的业务状态**，两者互不覆盖 |
| D-DS-41 | 最近推送时间 / 最近推送人 / 最近批次号 | 系统 | 展示与追溯 |
| D-DS-42 | 重推次数 | 整数 | 该资产被再次推送的次数，初始 0；**本期唯一的重推计数** |
| D-DS-43 | 最近失败原因码 / 原因 | 枚举 + 文本 | 取自运营端回执，仅同步状态为 S-DS-2 时有值；转「已推送」后清空并在推送记录中留档 |

> D-DS-40 与 WS-305 D-15 是两个独立字段：D-15 描述资产的业务生命周期（已确权），D-DS-40 描述它的同步生命周期。任何实现都不得把同步状态写回 D-15。

### 10.4 收单失败原因码

> 原因码由运营端产生、随回执返回，**只在资产管理端呈现给人看**（8.1）。

| 编号 | 原因 | 面向用户的文案（中，资产管理端展示） | 可否重推解决 |
| --- | --- | --- | --- |
| E-DS-01 | 来源不可信 | 来源系统身份校验未通过，请联系技术人员 | 否 |
| E-DS-02 | 报文字段缺失或格式错误 | 数据不完整：{字段名}，请补齐后重推 | 是（补齐后） |
| E-DS-03 | 枚举取值非法 | {字段名} 取值不在允许范围内 | 是（修正后） |
| E-DS-04 | 数值或日期不合规 | {字段名} 不符合校验规则 | 是（修正后） |
| E-DS-05 | 运营端服务内部异常 | 对方系统暂时不可用，请稍后重推 | 是 |
| E-DS-06 | 回执未知（超时 / 中断） | 结果未知，可直接重推，重推受幂等保护 | 是 |

## 11. 接口契约要点

本节只定义**语义**，不指定协议实现、传输格式与技术选型。

| 编号 | 接口 | 方向 | 语义 |
| --- | --- | --- | --- |
| I-DS-01 | 资产推送 | 资产平台 → 运营端 | 输入：推送批次号 + 资产数组（D-DS-01～D-DS-19），单批 ≤ 500 条；输出：与输入等长的逐条结果数组，每条含来源资产 ID、结果类型（新入库 / 幂等命中 / 失败）、原因码。**部分成功不整体回滚** |
| ~~I-DS-02~~ | ~~重推请求（运营端 → 资产平台）~~ | — | **已随「运营端不提供重推入口」删除，编号保留为空位不再复用**。本期不存在任何由运营端发起的反向调用 |
| ~~I-DS-03~~ | ~~对账查询~~ | — | **已随对账视图删除，编号保留为空位不再复用** |

**契约级约束**

1. **本期只有一个跨平台接口，且只有一个方向**：资产平台 → 运营端。运营端不主动调用资产平台的任何接口。
2. **幂等语义写在接口层**：同一「来源系统标识 + 来源资产 ID」重复调用 I-DS-01，第二次及以后一律返回「幂等命中」且为成功语义，不得返回错误，不得改动已有数据。
3. **回执必须逐条可归因**：任何一条失败都要能定位到具体资产与具体字段，不允许只返回批次级的成功 / 失败。这是本期失败排查的唯一信息来源——运营端不留失败痕迹，回执写得含糊就等于失败不可查。
4. **金额传输遵循脱敏基线**：传数值 + 币种代码，不传拼好的字符串（WS-308 `01-国际化基线.md` 8.2）。
5. **钱包地址不得进入日志与通知参数**：完整钱包地址仅存储于清单数据，日志与任何展示层取缩略形态。
6. **接口调用失败与业务失败必须可区分**：前者落 E-DS-05 / E-DS-06，后者落 E-DS-02～E-DS-04。

## 12. 非功能需求

| 维度 | 要求 |
| --- | --- |
| 性能 | 单批 500 条的推送提交，从点击确认到返回逐条结果的**目标**耗时 ≤ 30 秒；清单列表首屏与筛选响应目标 ≤ 2 秒。标「目标」的数值在联调阶段校准，不影响功能验收 |
| 一致性 | 幂等唯一约束在数据层强制，不得仅靠应用层判重；并发推送同一资产不得产生两条记录 |
| 安全 | 两端账号完全不互通，跨平台调用走**服务间鉴权**（凭据由技术侧配置下发，不在页面上配置、不由运营自助管理）；越权访问与推送、重推动作须记入安全审计日志 |
| 脱敏 | 运营端一切展示、日志遵循 WS-308 `01-国际化基线.md` 第 8 节；钱包地址缩略前 6 后 4，完整值仅在用户主动复制时进入剪贴板；企业名称、金额按该表口径处理 |
| 可追溯 | 推送、重推、收单各留一条记录，**记录只增不改不删**；收单失败虽不进运营端产品页面，但**必须记入运营端服务日志**用于排障，日志保留期遵循各端既有审计口径 |
| 兼容性 | 两端均为 Web 桌面端，浏览器支持范围沿用 WS-302 / WS-308 既有口径；本期不做移动端适配 |
| 国际化 | 资产管理端文案沿用 WS-302 双语口径；运营端沿用 WS-308 `01-国际化基线.md` 第 1～7 节；**币种代码、来源资产 ID、批次号、钱包地址不翻译** |
| 可用性 | 失败必须在资产管理端可见、可自助解决：任何一条 S-DS-2 都要在页面上给出原因文案与下一步动作，不得只给错误码 |
