## 国家 / 地区清单口径

- 个人认证「国籍」与企业认证「企业注册地」共用同一份值集 `COUNTRY_GROUPS`，按 ISO 3166-1 alpha-2 代码 + 英文名 + 中文名三元组存储；两个字段都不接受自由输入。
- **原型内是代表性子集，共 68 条**（业务常用法域 8 + 亚太 12 + 中东与中亚 6 + 欧洲 22 + 美洲 11 + 非洲 9），弹层底部常驻占位说明。**生产环境取标准清单**：由平台元数据服务下发 ISO 3166-1（alpha-2 代码为准，中英文名称随语言切换），结构与字段名不变，前端不再内置清单；名称口径以 ISO 3166-1 官方短名的中英文译名为准，港澳台按国内既有写法（中国香港特别行政区 / 中国澳门特别行政区 / 中国台湾地区）落地，不使用「国家」以外的独立表述。
- 检索支持中文名、英文名与 ISO 代码三种输入；命中为空时给出「演示子集中没有匹配项 / 生产环境检索全量清单」的说明，而不是空白。
- 交互：点击字段展开弹层并自动聚焦搜索框；Enter 选中当前首个匹配、↓ 进入清单、Esc 或点击空白关闭；选中项在清单中以 `aria-selected` 高亮。加载失败走 P-K01 的「国家清单失败」状态，可重试。
- 模板联动只认注册地：`CN → T1`、`HK → T2`、`US → T3`、`KY → T4`、`NG → T5`，**清单中其余任意国家 / 地区一律落 T6 通用模板**（新加坡、中国澳门、中国台湾地区等原先硬编码到 T6 的项目现在走同一条兜底规则）。切换注册地仍先弹确认框，弹框内显示「原注册地 · 原模板 → 新注册地 · 新模板」并逐项列出将清空的模板专有内容。
- 国籍不参与模板切换，只影响个人信息校验口径（R-P04 国籍与证件不符）与展示。管理端列表 / 详情的国家列同样按代码渲染，中英文切换时随之变化。

## 关键规则如何操作

1. 顶栏点「页面 / Pages」打开 8 页切换抽屉；资产端、管理端页面可直接互切，每页保留自己的状态切换条。
2. P-A17 切换未提交 / 草稿 / 审核中 / 驳回 / 双通过：个人信息卡始终在上、企业信息卡在下；未提交整卡为空态，已有资料时展示核心信息与卡头状态，点击整卡进入填写或详情。
3. P-A17 切到「缺邮箱 / 缺钱包」，点主按钮、提示条或认证整卡，体验 C-09 两步就地补齐；关闭后仍停在原页。
4. P-K01 右侧固定区自上而下是「进度」和「操作」：进度卡在上，下一步 / 提交、保存草稿、上一步在下方的操作卡；页面顶部不再重复展示进度，右侧不展示规则说明。整条右栏 sticky 常驻，滚动到页面任意位置主操作都可见；视口过矮时进度卡先内部滚动，操作卡不被挤出屏幕。
5. P-K01 步骤 1 切换身份证 / 护照，查看影像槽位从两张变为一张；证件号码仍保留输入原样。点「国籍」展开标准国家 / 地区清单，试着搜「尼日」「KY」「Brazil」三种输入。
6. P-K01 步骤 2 的「企业注册地」用同一份清单：选 HK / US / KY / NG 分别切到 T2～T5，选德国、巴西、新加坡、中国台湾地区等清单内其他项统一落 T6 通用模板，选回中国（大陆）回到 T1。确认弹窗显示「原注册地 · 原模板 → 新注册地 · 新模板」并逐项列出将清空的模板专有内容；取消不变，确认后即时换模板并重算企业唯一标识。
7. P-K01 步骤 3 可切到企业重复、限频和已通过后更新，查看拦截与后果告知。
8. P-K03 切到驳回，查看顶部原因汇总、个人 / 企业资料卡头状态、字段旁定位和重新提交入口；切到双通过，查看更新资料入口。
9. P-M31 / P-M33 右侧审核操作区随滚动保持可见；材料查看器位于审核记录上方，可放大、缩小、旋转、全屏和下载，复制 / 查看 / 下载均反馈已留痕。
10. P-M33 分别切到「级联 · 企业审核中 / 企业原已通过 / 企业原已驳回」，查看三种时机的差异提示与禁用的通过按钮；切到「二次查重失败」验证通过被拦截。
11. P-M31 / P-M33 点驳回，至少选择一项结构化原因后才能提交，补充说明上限 500 字且用户可见。

## 本期不做

## 跨模块交接与限制

- 消费 WS-302：账户、邮箱、钱包、时区、语言、登录落地、C-08 / C-09；P-A11 的凭据补全演示保持原样。
- 消费平台元数据：国家 / 地区标准清单（ISO 3166-1 alpha-2 + 中英文名称）需要由服务端接口下发并按语言返回名称；接口不可用时前端落 P-K01「国家清单失败」态并可重试。清单归属方与更新频率需在联调前确认，本原型不把内置子集当作权威数据。
- 产出给 WS-302 / 业务模块：个人状态、企业状态、双通过放行信号。
- 产出给 WS-304：认证站内信事件与 P-K03 跳转目标；本原型不重做消息中心。
- 仓库版依赖 `_shared`，支持真实跨模块链接。Issue 附件版由仓库版机械内联 `_shared` 四件生成，只供离线预览；其跨模块链接因缺少相邻文件而失效，这是已批准限制。
- Q-01 四地材料清单仍待合规闭环：原型按 PRD 建议结构展示演示槽位，不把它描述为权威清单。
- Q-14 材料保留期未确定：原型不出现任何保留期承诺。
