**范围。** M5 只提供机构主数据、固定类型、唯一机构编号、机构状态和唯一账号。新关系仅可选择启用机构；何时分配业务对象、停用后既有对象是否可见/可办、材料和铸造等规则归 M2/M3b/M4b，不在本篇定结果。基础资质是机构级资料，不能要求绑定申请或代币，也不能由上传自动推导业务权限。菜单内具体办理和业务消息归所属模块，M5 只发开通邮件。本文不改写 PRD、原型，不执行测试或建设评测设施。

**与旧版的关系。** 原“监管机构管理 Eval v1.1”归档于 Git 历史，本版统一为“机构管理”。旧版具体发行/在途结果、固定 PDF/10 MB/10 份限制及已移除的 AC 不进入当前评估。附件现按通用文件策略评估，具体参数由研发核实；不能从历史版本取值填补。

## 2. Case 数量与覆盖

建议启动 60 条原子 case：D1 12、D2 18、D3 10、D4 10、D5 10；由 14 条复合 AC 全子条件与字段边界、编号/邮箱竞态拆分，数量不足则扩充。稳态建议 150～250 条，优先补充访问方式、并发和真实回流；上述数量待测试确认，均为计划。风险集建议正常 20、边界 16、异常/对抗 20、OOD 4，共 60；未提供真实失败材料，历史失败暂 0，不能据此推断产品无缺陷。风险配比不代表线上流量。

**覆盖切片。** 三类型 × 启用/停用 × 待首登/正常/锁定，按风险组合；运营甲乙、机构、未登录、面客端拒绝身份；入口/直链/接口/文件；新生成/重复/伪造编号；名称 1/2/100/101 字、联系人 1/2/50/51 字、电话 5/6/30/31 字与非法字符、地址 1/2/300/301 字、说明 0/1000/1001 字、合法/无效邮箱、他账号当前/历史邮箱与大小写变体；账号成功/业务失败/邮件失败/重复提交/并发；基础资质选填为空、通用文件策略边界、资料保存失败与读取失败。OOD 包括未知编号、伪造机构类型、非常用国家地区码、直接访问非当前身份对象。电话合法性以字符和长度规则为准，不擅加国家号码真实性审核。

通用文件策略需研发给出版本、允许格式、数量及适用的大小等参数和判定证据；按实际配置的上限前/等于/超过构造合成样本，不预填旧版限制。没有确认策略时不能把文件边界标通过。此为技术依赖，不新增产品审批或材料准入规则。

## 3. 通过线

单例预期全部满足且禁止行为未发生才通过。模板的子场景分别执行计数；一条 AC 的任一子条件失败，该 AC 不通过。环境故障可凭研发证据和测试确认标无效，修复后重跑；依赖未就绪/未执行标未验证。产品超时、错投、半保存不得排为环境问题。

| 级别 | 定稿定义与归类 |
| --- | --- |
| P0 | 影响业务进程，或危及平台安全：越权、编号或邮箱错属、开通失败/重复/半保存、机构状态影响账号登录、凭据泄露、错误扩权/改历史 |
| P1 | 规则执行偏差导致误解或额外绕行，但有明确恢复路径、不阻断业务且不涉及安全：可恢复的字段/文件边界偏差、空/失败说明不清、非关键字段呈现不符 |
| P2 | 仅呈现/体验细节，不影响用户判断、操作结果或业务状态：非关键措辞、间距、辅助反馈细节 |

同 case 取最高风险。本文分级沿用既定口径，新增问题由产品仲裁实际业务影响；是否作为合入/发布门槛由测试、安全和发布方决定，不回写 PRD。

| 层级 | 建议门槛（全部待相关方确认） | 理由 |
| --- | --- | --- |
| B1～B5 | 每条相关 case 0 失败且无未验证，任一失败阻断 | 身份、账号、资料与安全损失高 |
| D1～D5 的 P0 | 每维度、每个必需切片 100% 通过 | 业务正向可用与安全拒绝同时满足 |
| P1 | 每维度通过率≥95%；剩余逐条缺陷及明确兜底，由测试、安全、发布方决定放行，产品提供业务影响说明 | 可恢复差错的受控评审 |
| P2 | 不单设发布率，记录缺陷与修复计划 | 不影响判断和操作 |
| 整体与联调 | 14 条 AC 子条件和字段/通用文件策略均有映射，必需 case 无未验证；真实账号/邮件/文件依赖验证；P0 相对同集上一版本无回归 | 不以少跑或模拟代替真实接入 |

维度通过率=有效通过原子 case 数÷有效已执行原子 case 数；按类型、机构/账号状态、访问路径、模拟/真实依赖和优先级分别列分子分母，不合并掩盖风险。未验证/无效另列数量、原因；建议无效数超计划执行数 5% 则停止放行结论、修环境重跑。并发/真实邮件/文件保存建议固定数据快照、依赖版本与操作时序重复 3 次，任一次产品失败即失败。规模、无效比例、重复次数均待测试确认。

规则断言逐例判，不靠置信区间放过；人工比例与 L3 比例建议报告样本量、Wilson 95% 区间，置信水平待确认。小样本零失败不能证明低风险；版本比较用同一 case 集、相同环境逐例配对，新规则单列；当前没有执行基线、分数、区间或提升结论。

**兜底。** 业务保存失败不建机构/账号、不发信、保留有效输入；邮件失败不回滚已开通账号、运营线下告知且平台不重发；编辑失败保留最近成功值；读取失败可重试。线上止血可建议暂停受影响开通/编辑或回退版本，不能擅自冻结所有账号或决定既有业务终止；具体方案、责任、时限待安全/研发运维/发布方确认。通用文件策略由研发验证，线下交付规范由运营/安全负责，均不新增平台功能。

## 4. 标注方法

| 角色 | 责任 |
| --- | --- |
| 产品/PRD 负责人 | 仲裁业务预期与影响；保持 M5 与业务模块边界，不代定发布门槛 |
| 测试负责人 | 拆分 AC/字段，维护功能↔AC↔case↔维度/级别/版本映射；确认数量、抽样与统计方案 |
| 研发/安全 | 核实通用文件策略、账号历史邮箱、编号唯一性、访问及邮件事实证据；复核全部 B 类 |
| 运营代表/中英文审校 | 双人独立判断档案提示、邮件内容和线下告知指引 |
| 发布负责人 | 会同测试、安全确认通过线、阻断与签字机制 |

启动由产品与测试共同标注每条 case 的前置、预期、禁止与追溯，合成案例仍待人工复核；B 类全复核。扩展建议产品抽查新增普通样本 20%，B 类全复核；每次 release 建议第二人复判呈现类 10%（不足 10 条至少 1 条），比例待测试确认。分歧先记未决，不取均分；产品仲裁业务含义，安全裁定风险证据，发布方决定放行。

| 二元 rubric | 正例锚点 | 反例锚点与级别 |
| --- | --- | --- |
| R1 身份与状态是否真实且不越界？ | 停用只显示机构状态，账号依自身规则登录 | 停用等于账号冻结，或承诺所有既有对象仍可办（P0） |
| R2 档案与资质是否仅属机构？ | 编号不变，资质选填、不绑定申请/代币 | 换名重建身份、上传自动授予业务权限（P0） |
| R3 业务结果与邮件结果是否分清？ | “账号已开通，邮件发送失败，可线下告知” | 邮件失败导致再次建账号（P0）；可恢复但提示含糊（P1） |
| R4 开通邮件是否目标正确、七项齐全且中英可理解？ | 正确编号/类型/凭据及手动登录首登要求，主题无密码 | 错投、主题密码、错误登录凭据/入口（P0）；非关键语病（P1） |
| R5 空、失败、未提供、保存成功是否可区分？ | 读取失败可重试，未填资质明确为空 | 丢资料/假成功（P0）；可恢复的表述偏差（P1） |

适用 rubric 全为“是”才通过，不适用注明理由。保留脱敏页面/响应、编号/邮箱归属证明、状态前后值、邮件受理和测试收件证据；不在评估材料保留初始密码原文。邮件受理不等于用户收到。启动不用 LLM judge；未来双语初筛须人工校准集与回归集隔离，一致率/关键错误漏检门槛待测试/安全确认，模型只建议，最终人工裁决。

## 5. 跑评频率

下表仅为建议，均待执行方确认，不在本次创建自动化或执行评测。

| 层级/频率 | 触发与范围 | 责任/产物 |
| --- | --- | --- |
| L1 每次相关 commit | 机构主数据/编号/历史邮箱、启停、文件、账号或邮件接入变更；字段、原子性、幂等、权限断言 | 研发/测试；逐例结果、B 类、映射与版本差异；阻断合入策略待确认 |
| L2 每次 release | 启动/稳态集全量，三类型/双状态、真实账号/邮件/通用文件策略、并发、人工提示与邮件复核 | 测试组织，产品/安全/运营审校复核；切片结果、未验证、配对回归、放行决定 |
| 每周回归 | 编号/历史邮箱不重用、启停不改账号、通用授权结果不被 M5 覆盖、基础资质不越界 | 测试与相关模块；接口契约记录，不代定其业务结果 |
| 每月或外部变化 | 邮件/存储/文件策略/鉴权接口、浏览器变化；本模块无被测模型，以兼容/OOD 探索代替模型 frontier eval | 研发/安全/测试；新风险与样本更新 |
| L3 上线后观察 | 正常上线流程决定采用后，独立观察真实业务；不在本次接入或实验 | 运营/测试/安全；真实流量统计与事故调查 |

L3 建议口径：完整建立机构+账号数÷合法开通提交事实数；重复开通事实产生多机构/账号数÷重复提交事实数；邮件受理事实数÷应发开通邮件事实数（收信另有证据）；机构启停误改账号/会话事实数÷启停事实数；保存后编号与档案一致事实数÷成功资料保存数。按类型/状态/依赖版本分层，样本量、观察窗口、告警、响应时限待测试/运营/安全/发布方确认，不用工单关闭代理账号可用，也不以风险集配比解释真实用户分布。

失败来源包括工单、异常告警、线上观察、OOD；建议 3 工作日内脱敏复现、标真实来源编号并回流（时限待确认），未经证实投诉标待核查。B 类补直链/接口或并发变体。集合按 `Eval-M5-RG-vX.Y` 版本化，当前依据 `f20b8d2933a4cc464651e5509db49d1d947bd5e8`；PRD 更新对比功能、AC 与消息，旧 case 归档留因；风险覆盖集和真实统计集分开，分布漂移时重估覆盖。

**仍待执行/依赖方确认：** Case 数量、重复与抽样比例、通过线/阻断/签字、真实环境与账号、通用文件策略具体版本和参数、L1/L2/L3 节奏、告警/止血及线下凭据安全告知规范。当前没有需 PRD 再决定的产品规则；业务模块的材料、分配和停用后办理问题在对应模块处理，不作为本 M5 产品待确认项，也不自动派发其他 agent。
