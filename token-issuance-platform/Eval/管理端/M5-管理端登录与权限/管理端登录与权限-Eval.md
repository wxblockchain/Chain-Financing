## 2. Case 数量与覆盖

**数量是计划，尚无已执行 case。** 建议启动集 104 条原子 case（D1 22、D2 24、D3 22、D4 22、D5 14）；以 49 条 AC 的全部子条件拆分为下限，数量不足时扩容，不能为满足 104 条而漏场景。稳态建议每维度 40～80 条，总计 200～400 条，主要展开角色/状态/入口、时钟边界、并发与回流；数量待测试负责人确认。

启动风险覆盖集计划：正常 32、边界 32、异常与对抗 32、OOD 8，共 104 条；历史失败暂为 0，未提供真实失败材料，不据此断言产品没有失败。安全边界多，采用高比例异常和边界场景。此人为配比不能解释线上流量；L3 统计集独立。

**必需切片（展开时不承诺用全笛卡尔积）：**

- 运营甲/乙与机构 X/Y，未登录/待首登/正常/锁定；机构启用/停用与账号状态交叉；面客端身份作为拒绝样本。
- 页面入口/直接 URL/接口/文件/消息链接；本人/他人/不存在对象；双设备、双标签页、延迟响应。
- 密码 7/8/20/21 字符、仅字母/数字、内外空格、相同当前/最近初始密码；邮箱 254/255 字符、大小写及空格。
- 时钟：2 分钟、10 分钟（验证码与再验证分开）、60 秒、2 小时、4 小时、180 天；在边界前/恰好/后采样，按 01/04 册已明确的满时失效或触发，以及第 180 天内仍可由内部支持追溯且前台无查询入口的口径判定，不再列为产品待确认项；测试时钟与测量精度由研发、测试确定。
- 三套失败计数必须隔离：密码、验证码、人机校验；邮箱/IP 发送额度及失败重试单独核对；成功/失败通知顺序与归属。
- 模拟依赖与真实邮件/消息/多设备联调分开。OOD 包括浏览器时区不可推断、不常见标准时区/夏令时、未知对象、外部原目标；使用合成地址与测试邮箱，不使用真实凭据。

## 3. 通过线

**单例。** 预期全部满足、禁止行为均未出现才通过；一行模板拆分后逐个判定，不以多数子场景通过代表整行通过。无法执行标未验证；环境原因导致无法判定标无效，需研发证据及测试确认，重跑后再计入。产品超时、发码失败误报成功等是有效失败，不能排除。

**优先级。** P0 口径由业务方确认；P1/P2 采用现版 Eval 的定义与具体归类定稿，不回写 PRD。本文代表场景及 rubric 的级别随本版定稿；同一 case 多风险按最高级，业务阻断或涉及权限、凭据、数据泄露即为 P0；新增问题的业务影响歧义由产品仲裁，发布决定由测试、安全及发布方负责。

| 级别 | 定义 | 本模块示例 |
| --- | --- | --- |
| P0 | 影响业务进程，或危及平台安全（已确认口径） | 登录/找回不可用、未完成首次密码设置即进入业务、失效凭据仍可用、会话残留、锁定或验证被绕过、跨机构/跨角色访问、通知错投、凭据泄漏、安全审计缺失、机构停用被误作账号锁定 |
| P1 | 规则执行有偏差，用户会误解或多走一步，但有明确兜底或绕行，不阻断业务、不涉及安全（本 Eval 定稿） | 有默认页可继续但原目标丢失；语言保存失败未回显原值；可重试但读取错误表述不清；已确认图标形式不符但行为可用 |
| P2 | 呈现与体验细节，不影响用户判断、操作结果及业务状态（本 Eval 定稿） | 非关键措辞/视觉间距差异、状态与结果均可获知时的辅助反馈细节；不含已确认的图标约束 |

**以下指标采用方式与门槛全部为建议，待测试、安全及发布负责人确认；研发负责技术可行性与环境，产品只仲裁业务预期、影响与兜底，不代定发布门槛。不能视为已获发布授权。**

| 层级 | 建议通过线 | 理由 |
| --- | --- | --- |
| B1～B7 阻断候选 | 所有关联 case 0 失败且无未验证；任一次失败阻断 | 安全与业务错误不能靠平均抵消 |
| D1～D5 的 P0 | 每维度、每个必需切片 100% 通过 | 口径覆盖业务进程和平台安全 |
| 每维度的 P1 | 通过率 ≥95%；其余逐条建缺陷，产品说明业务影响与兜底，由测试、安全及发布负责人决定是否放行 | 有明确恢复路径的非阻断偏差可评审 |

维度通过率 = 有效通过原子 case 数 ÷ 有效已执行原子 case 数；分别列 P0/P1/P2、角色、账号/机构状态、入口、模拟/真实依赖，不合并掩盖安全切片。未验证、无效、跳过另列数量与原因，未验证的必需项不能视为通过。建议无效占计划执行数超过 5% 时暂停本轮结论、修复环境后重跑，此比例待确认。

有真实时序/依赖的会话、并发和通知 case 建议重复 3 次，任一次产品失败该 case 即失败；固定账号快照、依赖版本、时间基点、请求顺序/延迟，记录环境。登录失败枚举需对有效/无效邮箱做随机交错的配对时延观察，记录样本量与时延分布，不能以一次响应看似相同判通过；测量窗口、重复次数、可区分时延容差待安全负责人确认，不声称绝无侧信道。规则断言逐条判定，无须用置信区间替代；人工比例和未来 L3 比例按有效分子/分母与 Wilson 95% 区间报告（置信水平建议、待确认），小样本零失败不证明低风险。版本比较固定同一 case 集与环境逐例配对，新增 case 单列，未有稳定基线前不报告提升。

**失败兜底。** 按 PRD 核对：保存失败原值保留；验证失效重新开始；验证码真实发送失败说明并允许一次立即重试；账号锁定等到期；变更通知失败不回滚生效凭据。[安全通知求助方式][support]须为需求方统一提供的长期有效、可审计官方渠道，账号无法登录仍可使用，中英文引用同一渠道，不使用个人联系方式或占位内容；渠道变化不改变密码、邮箱或通知触发规则。此业务规则已确定，只有具体渠道值仍为上线前外部依赖待确认；缺失时不能把相关 case 判通过。线上出现 B 类风险时建议先停止相关变更入口/回退受影响版本并保留证据，具体止血方式、责任人与响应时限待安全、研发/运维及发布方确认，本篇不执行处置。

| R3 结果与恢复 | P0 或 P1 | 已生效与未生效、失败与空状态能否区分，并给正确下一步？ | 通知失败但新密码生效，要求重登 | 把改密生效说成失败（P0）；可重试错误未给入口（P1） |
| R4 语义与安全告知 | P0 或 P1 | 双语是否同一事实、时间含时区、设置/重置/修改区分；求助是否为长期有效可审计的统一官方渠道，未登录仍可用且两语言相同？ | 两段验证码相同；密码变更和邮箱安全通知使用需求方提供的同一官方渠道，退出管理端仍可求助 | 两语言用途不同或指向错误邮箱；个人/占位求助渠道、必须登录才可求助或中英渠道不同（均 P0）；不影响事实与恢复路径的非关键翻译差异（P1） |
| R5 偏好与业务值 | P1，影响业务升 P0 | 切语言是否保留输入、意见原文不翻译，时区仅改变展示？ | UTC 换算后到期判断不变 | 改时区延长验证码有效期（P0） |
| R6 已确认操作约束 | P1，泄密升 P0 | 眼睛显隐、复制形式是否合规且不改值/扩大明文范围？ | 眼睛仅切换本人当前输入显示 | 用文字按钮替代（P1）；在别处展示已保存密码（P0） |

每次判定保留脱敏的响应/页面、状态迁移、邮件受理与消息事实编号、时间与账号归属，不把凭据原文写入评估记录；只能确认“受理”的证据不能标记为用户已收到。启动不使用模型 judge；未来若需双语初筛，先建立人工双标校准集并与回归集隔离，约定一致率和关键错误漏检门槛（待确认），初筛结果仍由人工裁决，不得裁决安全/发布。当前没有校准数据，不声称 judge 可靠。

## 5. 跑评频率

以下仅是方案，所有节奏、责任与采用范围待确认，不创建自动化、执行评测或线上实验。

| 层级/节奏 | 触发与范围 | 建议责任与产物 |
| --- | --- | --- |
| L1 每次相关 commit | 登录/会话、账号、验证码/人机校验、再验证、权限中间件、邮件事件有变更；确定性拒绝、时钟与计数、首登/找回状态、改邮箱当前/历史归属、敏感字段扫描 | 研发与测试；逐例结果、AC 映射与 B 类清单；是否阻断合入待确认 |
| L2 每次 release | 全量启动/稳态集；两角色、多状态、启用/停用、真实邮件/M7/多设备；通知双语与安全人工复核 | 测试组织，产品/安全/审校复核；分维度切片结果、未验证清单、配对回归与发布签字 |
| 每周回归 | 会话失效、跨机构数据/文件、验证码额度、运营本人安全消息、机构状态与账号状态隔离；相邻模块变化即加跑 | 测试；跨模块回归记录及回流 case |
| 每月或外部变化时探索 | 本模块无被测模型，替代 frontier eval：邮件服务/人机服务、浏览器/标准时区、身份或权限接口变化 | 研发与测试；兼容/OOD 清单，新增风险说明 |
| L3 上线后业务观察 | 经正常上线流程采用后，按真实流量观察账号恢复、变更与业务可达；不在本次接入或开展实验 | 产品/测试/安全；脱敏统计和调查结论，不能由离线率推断真实业务收益 |

L3 建议口径：合法有效凭据登录完成数÷合法有效凭据登录尝试数（排除已证明的主动取消，失败原因单列）；找回后成功重新登录数÷成功重置数（观察窗口待确认）；改邮箱后账号身份/所属机构保持且操作未改业务关系数÷成功改邮箱数；邮件服务受理数÷应发邮件事实数；本人安全消息可见事实数÷应产生站内消息事实数；对所属模块授权为拒绝的请求被放行数÷所属模块授权为拒绝的有效请求数。真实投递/用户可读须另有证据，不能以服务受理冒充；观察周期、样本下限、告警线和响应时限待确认。来源按角色、机构状态、流程步骤、客户端与依赖版本分层；身份合法性无法确认的请求单列未知，不能任意排除改善比率。

**回流与版本。** 工单、告警、线上指标异常和 OOD 探索发现的问题，建议 3 个工作日内脱敏、复现并落历史失败 case（时限待确认），标明真实来源编号、规则提交、失败条件与复核人；B 类补接口/直链变体。未经证实的投诉保留为待核查，不充当真实失败。集合使用 `Eval-M5-LG-vX.Y`，本版依据完整提交 `f20b8d2933a4cc464651e5509db49d1d947bd5e8`；PRD 任一册更新需对比规则、AC 和消息变更，更新受影响映射与需求变更回归标签，作废 case 归档留因。风险覆盖集与真实流量统计集分开；流量/机构状态/失败原因分布漂移后重估覆盖配比，不按人工风险配比加权解释线上总体。
