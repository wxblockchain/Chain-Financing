# 代币发行平台 · Eval

本目录存放代币发行平台各模块的产品 Eval 设计，回答“如何判断模块交付后的表现合格”。每份 Eval 固定五部分：评估维度、Case 数量与覆盖、通过线、标注方法、跑评频率。

Eval 只是评估方案，不是评测报告：没有实际执行评测，就不写分数或通过结论。规则以 [PRD](../PRD/README.md) 为准，Eval 不改写 PRD，也不替代 PRD 的 04 验收册与测试用例。

## 目录约定

```
Eval/
├─ README.md
├─ 面客端/
├─ 管理端/
└─ 两端共用/
```

- 端与模块目录与 `PRD/` 一致，命名为「模块号-模块名」，例如 `面客端/M1-企业登录与企业账户/`。
- 每个模块目录放一份 Eval，命名为「模块名-Eval.md」。
- 每份 Eval 开头写明所依据的 PRD 提交。PRD 有新提交时，对照该提交判断 Eval 是否需要同步更新，并在下表更新依据提交。
- 跨模块的规则写在各自模块的 Eval 中，用链接互相引用，不另建公共文件。
- 新模块的 Eval 按所属端放入对应目录，并在下表增加一行。
