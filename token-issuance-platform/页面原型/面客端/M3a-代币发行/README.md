# M3a · 代币发行（企业申请）

企业选择资产、监管机构与接收账户，签名提交发行申请，并查看审核进度与铸造结果。依据 [PRD](../../../PRD/面客端/M3a-代币发行-企业申请/01-代币发行-企业申请-PRD.md)（`cly-v6.0.0` 的 `e0fc67d`）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、地址、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“已认证企业”进入，或直接双击本目录 [`代币发行.html`](代币发行.html)。真实侧栏与账号菜单可跨模块跳转，语言、时区与身份随之传递。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 面客端/M3a-代币发行/代币发行.html --output <仓库外路径>.html`，可双击离线打开；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，按分组列出全部画面，并提供「主流程下一屏」。等待类画面不自动推进。

## 主流程

- 申请发行：L1 申请列表 → A1 / A2 选择资产 → I1 → I2 → I4 填写申请信息 → F1 核对 → G1 等待钱包签名 → F4 提交中 → F5 提交成功 → D1 申请详情（IA-DEMO-0042）。
- 接收账户为登录地址：I5 → F2 → G6 → F6 → F7 → D11；为原登录地址顺延的普通账户：I6 → F3 → G7 → F8 → F9 → D12。
- 提交异常后重选：E6 机构已停用 → I10；E7 账户已删除 → I11。
- 可选监管机构为全部启用机构（示例监管机构 C、D、E、G），不含已停用的 F。
- 详情：D1–D6 覆盖待监管审核、监管驳回、待运营审核、运营驳回、发行处理中、铸造成功；D6 的代币编号进入 M4a DEMO-TOKEN-001。

## 待确认项

- 业务签名展示签名地址、签名时间、签名值三项，不展示签名内容哈希（与 PRD e0fc67d 一致）。
- I10 / I11 重选后的核对页沿用 F1 的示例数据。

## 实际核验
