# M3a · 代币发行（企业申请）

企业选择资产、监管机构与接收账户，签名提交发行申请，并查看审核进度、监管协议与铸造结果。依据 [PRD](../../../PRD/面客端/M3a-代币发行-企业申请/01-代币发行-企业申请-PRD.md)（2026-11-05 版）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、地址、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“已认证企业”，或直接双击 [`代币发行.html`](代币发行.html)。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 面客端/M3a-代币发行/代币发行.html --output <仓库外路径>.html`；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，列出全部画面并提供「主流程下一屏」；等待类画面不自动推进。

## 主流程

- 申请发行：L1 → A1 / A2 选择资产 → I1 → I2 → I4 填写申请信息 → F1 核对 → G1 等待钱包签名 → F4 提交中 → F5 提交成功 → D1 申请详情（IA-DEMO-0042）。
- 接收账户为登录地址：I5 → F2 → G6 → F6 → F7 → D11；为原登录地址顺延的普通账户：I6 → F3 → G7 → F8 → F9 → D12。
- 提交异常后重选：E6 机构已停用 → I10；E7 账户已删除 → I11。
- 详情 D1–D6 覆盖待监管审核、监管驳回、待运营审核、运营驳回、发行处理中（铸造中与铸造失败统一展示）、铸造成功。代币数量单位为合约代币符号 cou；申请阶段不展示代币数量。
- 编号即入口：申请编号进入申请详情；资产编号进入可信资产衔接画面（S1–S7，确权 / 回款 / 发行三个状态）；D6 铸造结果的代币编号 DEMO-TOKEN-001 进入 M4a 代币详情。
