# M3a · 代币发行（企业申请）

企业选择资产和监管机构，接收地址自动取当前登录地址并只读展示；核对、签名后提交，再查看审核进度和铸造结果。依据 [PRD](../../../PRD/面客端/M3a-代币发行-企业申请/01-代币发行-企业申请-PRD.md)（`43ac7a6` 的账户口径）；规则、校验与异常分支以 PRD 为准，数据均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“已认证企业”，或直接双击 [`代币发行.html`](代币发行.html)。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 面客端/M3a-代币发行/代币发行.html --output <仓库外路径>.html`；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，列出全部画面并提供「主流程下一屏」；等待类画面不自动推进。

## 主流程

L1 → A1 / A2 选择资产 → I1 / I2 选择监管机构 → F1 核对 → G1 钱包签名 → F4 提交中 → F5 成功 → D1。未选监管机构时不可继续；选定机构后即可进入核对，无账户选择步骤。E6 返回 I10 重选监管机构。D8 展示提交后地址变更：顶栏为新登录地址，历史接收地址与业务签名保留提交时地址。

核对页保留资产信息、监管机构、网络、接收地址、关键后果和签名地址。提交时接收地址与业务签名地址一致；提交后读取申请快照。已提交的其他历史演示记录保留原接收地址；铸造结果、数量和签名上链范围沿用现行原型。

## 本轮覆盖与限制

本轮同步“仅保留当前登录地址”口径；发行申请文件等并行新增 PRD 功能未纳入本轮画面。原型不证明真实签名、数据固化、接口、权限或链上交易能力。
