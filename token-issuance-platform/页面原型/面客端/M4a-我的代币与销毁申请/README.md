# M4a · 我的代币与销毁申请

企业查看已铸造的代币，满足条件时用钱包以登录地址对业务信息签名并申请销毁，查看审核、销毁与解除监管进度。依据 [PRD](../../../PRD/面客端/M4a-我的代币与销毁申请/01-我的代币与销毁申请-PRD.md)（`9fca0c6`）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、地址、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“已认证企业”，或直接双击本目录 [`我的代币与销毁申请.html`](我的代币与销毁申请.html)。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 面客端/M4a-我的代币与销毁申请/我的代币与销毁申请.html --output <仓库外路径>.html`；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，列出全部画面并提供「主流程下一屏」。

## 主流程

- 签名内容为代币、申请销毁数量和持有地址，签名值随销毁交易写入链上；确认环节仍展示全部关键信息。
- 申请销毁：M01 我的代币 → M05 代币详情（DEMO-TOKEN-021）→ M21 确认关键信息 → M24 钱包签名 → M29 提交中 → M30 提交成功 → M39 申请详情（BA-DEMO-0031）→ M41 销毁中 → M43 销毁成功 → M44 待解除监管 → M45 已解除监管。列表「申请销毁」进入 M22。
- 再次申请销毁：M40 驳回（BA-DEMO-0024）→ M52 确认 → M53 签名 → M54 提交成功 → M56 新申请待运营审核。
- 销毁失败后被驳回：M72 申请详情（BA-DEMO-0021，代币在质押地址）⇄ M73 代币详情（DEMO-TOKEN-026，融资中，不能申请销毁）。
- 未认证：M58 / M59 → M71 前往资产可信平台确认。

演示数据与 M4b 一一对应：代币 001、021–026，申请 BA-0018 / 0019 / 0021 / 0024 / 0030 / 0031。已销毁代币的持有地址为空。DEMO-TOKEN-001 的资产与发行申请编号进入 M2 / M3a 对应记录；其他代币的这两项编号没有匹配画面，显示范围提示。
