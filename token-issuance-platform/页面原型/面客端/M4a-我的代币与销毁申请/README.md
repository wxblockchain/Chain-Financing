# M4a · 我的代币与销毁申请

企业查看已铸造的代币，满足条件时签名申请销毁，并查看审核、销毁与解除监管进度。依据 [PRD](../../../PRD/面客端/M4a-我的代币与销毁申请/01-我的代币与销毁申请-PRD.md)（`cly-v6.0.0` 的 `e0fc67d`）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、地址、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“已认证企业”进入，或直接双击本目录 [`我的代币与销毁申请.html`](我的代币与销毁申请.html)。真实侧栏与账号菜单可跨模块跳转，语言、时区与身份随之传递。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 面客端/M4a-我的代币与销毁申请/我的代币与销毁申请.html --output <仓库外路径>.html`，可双击离线打开；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，按分组列出全部画面，并提供「主流程下一屏」。等待类画面不自动推进。

## 主流程

- 申请销毁：M01 我的代币 → M05 代币详情（DEMO-TOKEN-021）→ M21 确认关键信息 → M24 等待钱包签名 → M29 提交中 → M30 提交成功 → M39 申请详情（BA-DEMO-0031）→ M41 销毁中 → M43 销毁成功 → M44 待解除监管 → M45 已解除监管。也可从列表「申请销毁」打开 M22。
- 再次申请销毁：M40 驳回（BA-DEMO-0024）→ M52 确认 → M53 等待签名 → M54 提交成功 → M56 新申请 BA-DEMO-0031 待运营审核。DEMO-TOKEN-021 的申请历史为 BA-0024（驳回）→ BA-0031。
- 列表与对应：代币 001、021–026 与申请 BA-0018 / 0019 / 0021 / 0024 / 0030 / 0031 与 M4b 一一对应；已销毁代币的持有地址显示“—”。
- 未认证：M58 / M59 受限引导 → M71 前往资产可信平台确认，取消回到原页面。
