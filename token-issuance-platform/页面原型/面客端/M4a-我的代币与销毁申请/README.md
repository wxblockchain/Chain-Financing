# M4a · 我的代币与销毁申请

企业查看本企业已铸造代币、发起钱包销毁、查看销毁结果与独立的资产托管信息，并只读查看发行机构文件和补充记录。依据 [PRD](../../../PRD/面客端/M4a-我的代币与销毁申请/01-我的代币与销毁申请-PRD.md)（`d35057b`）；规则、校验与异常分支以 PRD 为准。页面数据、机构、文件和说明均为演示数据。

本轮为既有企业端控制台适配（existing-system adaptation）。已应用 Hallmark 交接补丁（基于 `7ea33e3`），同步 M26“请切换到签名地址”和 M35“申请状态”，在其 89 屏基线上做视觉优化，不新增业务画面、状态或数据。源层复用 [token](../../_shared/tokens.css)、[组件 CSS](../../_shared/components.css) 与[组件规范 §9](../../_shared/design-system/组件规范.md#9-信息密集记录与只读办理进度m4a)，没有页面私有 token 或业务模拟逻辑。

## 打开方式

- 仓库联看：完整同步 `页面原型/`，双击 [index.html](../../index.html) 选择已认证企业，或直接打开本目录 [我的代币与销毁申请.html](我的代币与销毁申请.html)。
- 单模块附件：在 `页面原型/` 执行 `python3 _shared/export.py --source 面客端/M4a-我的代币与销毁申请/我的代币与销毁申请.html --output <仓库外路径>.html`。导出件可双击离线打开，跨模块入口显示范围提示。
- 画面目录默认关闭，桌面位于侧栏底部；可选择全部画面和“主流程下一屏”。钱包、链上结果均是预设画面，不调用真实钱包、不广播交易、不自动模拟成功。

## 主流程与业务不变量

- 销毁：M01 → M05（DEMO-TOKEN-021）→ M21 → M24 钱包签名 → M29 广播 → M30 → M39 / M41 销毁中 → M43 销毁成功、托管中 → M45 销毁成功、已解除托管。列表入口使用 M22。
- 失败重新发起：M40 原失败（BA-DEMO-0024）→ M52 / M53 / M54 → M56 新申请（BA-DEMO-0031）。DEMO-TOKEN-026 使用 M42 → M74 / M75 / M76 → M77 新申请（BA-DEMO-0032）⇄ M78；原失败由 M81 只读展示并引导当前申请。
- 失败且仍在质押地址：M72 ⇄ M73，无重新销毁入口。非平台入口：M79 ⇄ M80，历史失败 M82 引导对应结果。
- 提交锁：签名后未取得交易标识为 M33 确认中 → M89 我的代币 ⇄ M87 代币详情；M88 为其他页面或设备被锁拦截。确认中 / 销毁中长时间无结果，企业仍看原状态，没有线上处理或再次提交入口。
- 补充记录：DEMO-TOKEN-021 的详情有一条记录，“在托管文件中查看”定位、展开并聚焦对应批次；其他代币显示暂无，M90 为读取失败，可重试。M7 通过原 `tokenSupplement021` / `t-ready~supplement` 直达补充记录。
- 文件：按托管 / 法律 / 审计分类，只读查看、下载。M85 为文件读取失败，M86 为预览；文件读取失败时，补充记录仍保留原结果与定位。机构名称、机构类型、上传说明等业务原文不翻译。
- 我的代币列表不展示地址和融资状态，“币种”仅为图标及 COU；单位价值完整展示，不补零、不截断。
- 确认弹窗固定四条须知，地址只称“签名地址”，“确认销毁”直接进入钱包。M26 提示切换到签名地址，当前登录身份不变。
- 销毁申请状态（销毁中 / 销毁失败 / 销毁成功）与托管状态（托管中 / 已解除托管）分别展示，没有“待解除托管”。M35 表头为“申请状态”，代币详情销毁记录仍为“当前状态”。
- 申请详情“销毁交易”只有本申请的一行，替换交易仍合入原行；签名地址及提交时间保留原申请，结果、数量和完成时间依 PRD。没有新增替换交易画面或哈希。
- 资产托管卡标题仍为“资产托管”；解除机构、时间、说明、通知文件及只读权限不变。企业不办理解除、上传、删除或替换文件。

## 实际核验

2026-11-10：Chromium headless 在 1280 / 1440 / 1920 × 900 下，对全部 89 屏分别检查中文 / English，共 534 次。核对画面可达性、脚本错误、整页溢出、相邻表格内容、重复 ID 与全部跳转目标；源页及导出的离线附件分别核验。

与应用补丁后的交接基线比较：业务字段和数值、时间、地址、文件、四条须知、操作去向与禁用条件保持一致；销毁交易及资产托管卡原内容保持一致。实际点击四个确认按钮、弹窗 Tab / Escape 与焦点返回、确认中列表到原代币、补充记录到文件批次及预览返回、读取失败重试、只读交易区域聚焦。M3b / M4b 的现有列表在 1280 px 下检查中英文与固定操作区，未启用 M4a 的新列表变体。截图只供内部核验，不作为附件。

## 未验证范围与继承限制

- 未验证真实钱包、链上、身份权限与文件服务；一次签名直接销毁仍需研发按 M6 验证，AC-M4A-16 / 37 的链上部分待验。提交锁、替换交易识别和监听收口由研发与测试负责，原型不证明这些能力已实现。
- 768 / 375 px 沿用交接限制，本轮不声明完成移动端适配；Safari / Firefox 未验证。
- 演示单位价值均为 1 USD，未覆盖 0.8 USD 或较长完整小数值；未改演示值、计算或精度。跨端代币、机构、到期时点及补充记录仍须对应模块统一；M2 到期示例尚可能为 23:59:59（+04:00），M4a 按来源时区 24:00。
- 演示申请部分提交时间相同，按原固定顺序显示；BA-DEMO-0033 与 BA-DEMO-0031 是不同画面变体，未新增同列展示。文件仅展示原演示文件信息，未提供真实下载。
