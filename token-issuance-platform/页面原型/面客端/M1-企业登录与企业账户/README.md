# M1 · 企业登录与企业账户

企业端钱包登录、游客引导、企业与用户信息，以及唯一当前登录地址的只读展示。本轮对齐 PRD 基线 `705229b`（2026-11-10）的 M1 四册：[功能](../../../PRD/面客端/M1-企业登录与企业账户/01-企业登录与企业账户-PRD.md)、[流程](../../../PRD/面客端/M1-企业登录与企业账户/02-企业登录与企业账户-流程图与状态机.md)、[通知](../../../PRD/面客端/M1-企业登录与企业账户/03-企业登录与企业账户-消息通知.md)、[验收](../../../PRD/面客端/M1-企业登录与企业账户/04-企业登录与企业账户-验收.md)。规则、校验与异常分支以 PRD 为准，数据均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择企业端身份，或直接双击 [`企业登录与企业账户.html`](企业登录与企业账户.html)。侧栏与账号菜单可跨模块跳转，语言、时区与身份随之传递。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 面客端/M1-企业登录与企业账户/企业登录与企业账户.html --output <仓库外路径>.html`，离线双击打开；跨模块入口显示范围提示。
- 侧栏底部（窄屏为右下角）的「画面目录 · 演示数据」默认关闭，列出全部画面并提供「主流程下一屏」。等待类画面不自动推进。

## 主流程

登录：L1 → L3 → L4 → S1 → P1。L4、S1 等等待画面使用目录中的「主流程下一屏」推进，不自动建立登录；S1 仍为未登录，没有账户或消息入口。P1 后从侧栏查看企业账户和用户信息，通过账户菜单退出。

首次登录不成立的结果：S2 调取失败 / 超时 / 认证结论缺失（可重新登录）、S8 来源无法确认（中性说明）、S9 缺少稳定账户标识（错误码，重新登录或返回）、S10 一个地址对应多个账户（请联系资产可信平台，返回或重新登录）、S5 建立企业用户失败（错误码，重试或放弃并返回）、S4 / S7 上游账户锁定或禁用（登录未完成，仍为未登录，显示解除信息）。登录期间调取不到账户时为 S3，只说明登录已结束；登录期间上游账户锁定或禁用时为 S11（登录已结束并显示解除信息，禁用与锁定版式相同，以锁定代表）。

认证引导：游客注册（G1）、未认证企业的用户信息与企业信息（P2 / U6「前往完成认证」）及企业账户受限页（A4 / A6）都先经过 G2 确认，取消 / Esc 返回原处。无企业归属（含上游未提供企业标识）的 P3 / U7 不提供跳转，也不显示消息入口；认证未通过与审核中版式相同，以 P2 / U6 代表。

## 待确认

- 账户入口读取不到本次钱包地址时显示“我的账户”（AC-M1-53）：共享壳层暂无按画面指定“无地址”的方式，本轮未单独出屏。
- “返回发起登录的原处”：本模块唯一的未登录入口是 L1，S5 / S9 / S10 的返回在原型中都落到 L1；真实去向按发起登录的位置决定。

## UI 视觉深化（2026-11-10，承接 `a204919`）

本轮为 existing-system adaptation（console），局部修改 S4 / S7 / S11 / A1 四屏，其余 34 屏继承未改。保留全部画面、原业务文案、数据、身份、路由和操作，不增加状态分支。

- S4 / S7 / S11：解除说明和重新登录按钮归入同一文本区，取消图标跨四行造成的空行。锁定图标沿用共享警告色，页面仍分别表达“首次登录未完成”和“登录期间登录已结束”，不凭颜色区分结果。
- A1：保持一行三列表格，无操作列；标识列 160 px、网络列 184 px，地址列承接余量，缩写与完整地址复制不变。表格最小阅读宽度为本模块专用的 560 px，窄容器仅在表内滚动；溢出时显示双语提示，并通过 `aria-describedby` 关联到可聚焦的滚动区。
- 375 px 下表格容器为 341 px，最大横向滚动距离从原 459 px 收紧至 219 px；三列完整保留，Tab 可到达复制按钮，方向键可滚动。未来追加行或列仍在原列表中进行，新增列时应重新评估最小阅读宽度。
- 实现只涉及模块 HTML、`m1.css` 及滚动提示的英文映射；本次未修改共享 token、壳层、组件规范、PRD 或 Eval。
