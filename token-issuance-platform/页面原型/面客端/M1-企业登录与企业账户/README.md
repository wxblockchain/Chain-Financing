# M1 · 企业登录与企业账户

企业端钱包登录、游客引导、企业信息、用户信息与企业账户（数币账户）。依据 [PRD](../../../PRD/面客端/M1-企业登录与企业账户/01-企业登录与企业账户-PRD.md)（`9fca0c6`）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、地址、编号均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择企业端身份，或直接双击 [`企业登录与企业账户.html`](企业登录与企业账户.html)。侧栏与账号菜单可跨模块跳转，语言、时区与身份随之传递。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 面客端/M1-企业登录与企业账户/企业登录与企业账户.html --output <仓库外路径>.html`，离线双击打开；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，列出全部画面并提供「主流程下一屏」。等待类画面不自动推进。

## 主流程

- 登录：L1 连接钱包 → L3 确认签名（展示连接的地址与网络）→ L4 等待钱包签名返回 → S1 账户信息加载中 → P1 企业信息。登录失败与登录结束在平台内容区呈现（S2–S6）。
- 新增账户：A1 列表 → A5 填写信息 → A7 签名说明 → A8 等待签名 → A10 登记成功。
- 删除账户：A12 删除确认；A13 登录地址不可删除；A14 被引用不可删除，可前往 M3a 申请 IA-DEMO-0031 或 M4a 代币 DEMO-TOKEN-001。A15 登录地址变更后，原登录地址顺延为普通账户（来源仍为“登录地址”）。
- 游客与未认证：G1 游客引导 → G2 前往资产可信平台确认；未认证 / 无企业归属的业务菜单显示锁形标记，用户信息见 U6 / U7。
- 登录后在钱包中切换地址不影响登录，本模块不提示；业务签名时的地址核对在 M3a / M4a。账户入口只有登录地址与退出，没有“切换钱包”入口。

## 未出屏

- 登录环节的钱包异常（无可用钱包、网络不符、取消或拒绝签名、签名中钱包切换地址、签名过期）：登录按用户意见只保留 L1 / L3 / L4，这些反馈以 PRD 为准。
- 登录后返回原目标与原目标失效的说明，以 PRD 为准。
