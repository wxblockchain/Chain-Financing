# M1 · 企业登录与企业账户

企业端钱包登录、游客引导、企业与用户信息，以及唯一当前登录地址的只读展示。依据 [PRD](../../../PRD/面客端/M1-企业登录与企业账户/01-企业登录与企业账户-PRD.md)（`43ac7a6` 的账户口径）；规则、校验与异常分支以 PRD 为准，数据均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择企业端身份，或直接双击 [`企业登录与企业账户.html`](企业登录与企业账户.html)。侧栏与账号菜单可跨模块跳转，语言、时区与身份随之传递。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 面客端/M1-企业登录与企业账户/企业登录与企业账户.html --output <仓库外路径>.html`，离线双击打开；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，列出全部画面并提供「主流程下一屏」。等待类画面不自动推进。

## 主流程

登录：L1 → L3 → L4 → S1 → P1；企业账户：A1 查看当前地址，A15 查看上游地址变更后的唯一新地址，A3 读取失败，A4 未认证受限。旧地址不作为其他账户保留。

本期不提供其他账户的新增、编辑、删除、备注名或默认账户操作；当前地址也不可删除。账户只展示账户标识、Ethereum 网络和数币地址，地址缩写、完整悬停及复制沿用公共组件。历史申请与已铸造代币不随登录地址变化改写。
