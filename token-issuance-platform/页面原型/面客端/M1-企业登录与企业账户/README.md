# M1 · 企业登录与企业账户

企业端钱包登录、游客引导、企业信息、用户信息与企业账户（数币账户）。依据 [PRD](../../../PRD/面客端/M1-企业登录与企业账户/01-企业登录与企业账户-PRD.md)（`cly-v6.0.0` 的 `e0fc67d`）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、地址、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择企业端身份进入，或直接双击本目录 [`企业登录与企业账户.html`](企业登录与企业账户.html)。真实侧栏与账号菜单可跨模块跳转，语言、时区与身份随之传递。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 面客端/M1-企业登录与企业账户/企业登录与企业账户.html --output <仓库外路径>.html`，可双击离线打开；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，按分组列出全部画面，并提供「主流程下一屏」。等待类画面不自动推进。

## 主流程

- 登录：L1 连接钱包 → L3 确认签名 → L4 等待钱包签名返回 → S1 账户信息加载中 → P1 企业信息。
- 新增账户：A1 列表 → A5 填写信息 → A7 签名说明 → A8 等待签名 → A10 登记成功。
- 删除账户：A1 → A12 删除确认；登录地址见 A13（不可删除），被引用账户见 A14（被处理中的发行申请 IA-DEMO-0031 引用，可前往 M3a 查看申请）；A15 登录地址变更后，原地址被代币 DEMO-TOKEN-001 引用。
- 游客与未认证：G1 游客引导 → G2 前往资产可信平台确认；未认证 / 无企业身份的业务菜单显示锁形标记，用户信息见 U6 / U7。

## 实际核验

2026-11-04（WS-585 统一核验）：Chromium headless 遍历源码全部 35 屏 × 中文 / English × 1280 / 1440 / 1920 px，无脚本错误、失效跳转、重复 id 或整页横向溢出；英文界面除原文数据（企业、机构、账号名称，意见与文件名）外无中文残留。由 `export.py` 生成的单模块附件在断网环境遍历全部画面，无外部请求。仓库联看中本模块的跨模块入口均能解析到已登记画面。
