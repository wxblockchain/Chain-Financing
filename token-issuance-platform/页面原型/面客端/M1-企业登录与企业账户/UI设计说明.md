# M1 · UI 设计说明

2026-11-04｜PRD 基线：`41870b4`（含登录后切换钱包、原地址顺延规则）｜原型基线：`6ae7c13`｜existing-system adaptation｜企业端 console，含登录与游客。

本轮按用户“按照建议改为上下结构，并定为通用规范”的确认，将只读字段统一为字段名在上、值在下。规则落在共享 `.facts` 中，企业信息、用户信息与其他模块共用，资产详情不再单独覆盖。保留企业账户表格、偏好设置行、连接摘要及原有页面分组。

## 本轮变化

- 通用字段名 13 px / 辅助色，值 14 px / 正文色，标签和值间距 4 px，字段上下内边距各 16 px。长英文标签和值使用完整列宽换行。
- `.facts-region` 容器达到 762 px 时仍为两列、列间距 32 px，其余一列；`.single` 始终单列，`.wide` 与 `.inset` 沿用既有用途。每个字段不另套卡片。
- 移除通用 120 px、个人资料 104 px、英文 160 px 固定标签列宽，以及资产详情专属上下覆盖；不重设字体、颜色或业务数据。
- 用户信息保留一张分区卡片及分区标题响应式；“本次登录”“个人资料”的字段改上下结构。“偏好设置”仍为左侧说明、右侧下拉，小屏上下排列。
- 共享变化同时作用于现有详情、关联记录和弹窗中的只读信息。资产详情沿用同样的 4 / 16 / 32 px 参数；表格、状态 / 连接摘要与输入表单按各自组件呈现。

实现与适用范围的唯一来源为 `_shared/components.css` 和 [组件规范 v1.27](../../_shared/design-system/组件规范.md) §4.5 / §4.16。没有模块私有样式副本。

## 继承的已确认设计

- 登录只保留 L1 / L3 / L4，签名后进入平台；三屏按 L3 等宽等高。顶栏语言显示“中文 / EN”，弹窗无语言入口。
- 登录成功后钱包换地址不影响本次登录；A15 新地址为当前登录地址，原地址顺延为普通账户，来源仍为“登录地址”。编辑、删除和引用限制沿用 PRD。
- 企业账户表格保留六列、当前登录行、固定操作及窄屏浏览提示；行操作弹窗带入所选账户，地址缩写、完整复制，关闭 / Esc 回到发起处。
- 所有网络仍为图标 + Ethereum。企业、个人、地址、备注等业务值不随语言自动翻译；IANA 时区只改变时间呈现。
- 桌面内容左右各 24 px，不恢复 1200 px 居中限宽；游客、认证引导和离开确认保留平台内页承载及原权限。
- 完整目录保留跨模块导航与语言、时区和身份传递。单模块 HTML 的跨模块入口继续提示打开完整目录；尚未交付模块保留原有反馈。

## 实际核验

- Chromium headless，9 个模块共 234 个含只读信息的画面，在 1280 px 下检查中英文，共 468 个组合；按页面 / 弹窗 / 身份选择代表，在 320、375、768、1440、1920 px 下再检查 340 个组合。字段上下排列、单列变体、模态窗底栏及整页宽度检查通过，无脚本报错。
- M1 的 11 个相关画面全部纳入六种宽度的中英文检查；离线附件断网复核这 11 屏的中英文及 375 / 1440 px，共 44 个组合，无外部脚本或样式依赖。
- 实际检查完整地址复制、语言 / 时区预览、账户六列、A15 原地址编辑及返回、签名窗 Tab / Esc、G1 / G2 返回与登录三屏等大。人工查看企业信息、用户信息及窄屏签名核对窗。
- 其余模块按共享消费者覆盖核验，未重做各模块全部业务流程验收。截图仅用于内部核验。

未验证真实钱包 / 接口、服务端持久化、跨设备同步、Safari / Firefox、实体移动设备及完整无障碍审计。保存、删除和签名仍为原有静态演示，不代表正式业务完成。

## 打开方式

- 完整联看 ZIP：解压后打开 `页面原型/index.html`，或打开本目录 [企业登录与企业账户.html](企业登录与企业账户.html)，保留目录结构以支持跨模块导航。
- 单文件附件：由 `_shared/export.py` 从源页生成，可双击断网预览 M1。右下角画面目录选择“企业信息 / 用户信息”，可查看本次布局；企业账户 A15 保留原有操作示例。
- 正式规则以 [PRD](../../../PRD/面客端/M1-企业登录与企业账户/01-企业登录与企业账户-PRD.md) 为准。
