# M1 · UI 设计说明

2026-11-03｜PRD 基线：`41870b4`（含 `bb7dc9a` 登录后切换钱包、`6279b3d` 原地址顺延）｜原型基线：`b25aebb`｜existing-system adaptation｜企业端 console，含登录与游客。

本轮承接 Hallmark 已更新的 M1 原型，优化账户列表的扫描与操作辨识，以及操作弹窗中的账户核对。保留桌面左右各 24 px 的宽屏布局、L1 / L3 / L4 等大卡片、顶栏「中文 / EN」、弹窗内无语言入口及已接通的跨模块导航。

## 本轮优化

- 四个账户列表使用统一六列宽度。当前登录行以中性浅底、首列主色线及原有「登录地址」文字标记；A15 的原登录地址保持普通行，来源仍为「登录地址」，未设置备注名时继续显示占位文字。
- 编辑与删除的操作高度统一为 36 px，删除使用危险文字色及对应悬停底色。所有删除继续可点击，限制在既有二次反馈内说明。
- 表格最小宽度 960 px；窄容器增加横向浏览说明、可聚焦的滚动区，操作固定在右侧。保留六列、原顺序和完整信息，不缩小字号挤入手机。
- 编辑、删除及两类受限反馈统一使用有字段标签的只读地址区，缩写地址可查看、复制完整值。编辑按网络 → 地址及不可更换说明 → 备注名排列；「查看代币」使用可辨识的次按钮。
- 修正行与弹窗的展示对应：从 A15 原登录地址点击编辑 / 删除时，弹窗显示该行地址；新登录地址的删除说明显示新地址。关闭 / Esc 回到发起页，顶栏保持新登录地址。目录直接进入弹窗仍采用原有示例。

取值在 `_shared/tokens.css`，变体样式在 `_shared/components.css`；M1 的 `account-display.js` 只读取现有行，将其展示值带入既有弹窗。不做账户保存、业务校验、引用判断或真实钱包交互。

## 保留的业务与呈现口径

- 登录成功后，在钱包里切换地址不提示、不结束登录。签名返回前换地址的处理以 PRD 为准，本原型不单独出屏。S3 仍用于上游登录地址变更等原有登录结束反馈。
- A15 新地址为当前登录地址，不可编辑，删除时说明不能删除。原地址保留为普通账户，来源不改，可编辑备注名，删除遵循引用规则；不赋予原地址企业登录资格。
- 登录连接成功直接到 L3；确认签名进入 L4 等钱包签名返回，验签后直接进入平台。原型只演示画面，不接插件钱包。
- 资料由资产可信平台维护；语言和 IANA 时区支持展示预览，地址及其他业务值不随语言变化。网络保持图标 + Ethereum，全模块地址缩写、完整复制，金额和时间原值不变。
- 完整目录可跨模块跳转并传递语言、时区和身份；单模块 HTML 对跨模块入口保留提示。消息模块尚无原型，铃铛继续使用既有提示。

## 核验边界

- Chromium headless，中英文，320 / 375 / 768 / 1280 / 1440 / 1920 px：八个优化画面逐项检查，1280 px 补查全部 33 屏，共 146 个画面组合及一次键盘横向滚动检查；未发现整页横向溢出、操作列越界、对话框标题缺失或脚本错误。
- 单文件附件断网复核中英文、375 / 1440 px 下八个优化画面，共 32 个组合；无外部脚本或样式依赖。
- 实际点击 A1、A15 全部行操作，中英文共 24 次：地址、备注名、完整复制值、顶栏登录地址、Esc / 关闭后的发起页与焦点正确。目录直接打开编辑窗恢复原有示例；当前登录行无编辑，受限删除窗无危险确认。
- 回归中英文及 375 / 1440 / 1920 px 的登录三屏等宽等高与主流程原型跳转，尺寸与基线一致；抽查其余 8 个模块的默认壳层加载、整页宽度和弹窗无语言入口。
- 完整联看 ZIP 解压后断网打开：验证 M1 → M2 可信资产及「查看代币」→ M4a 的 DEMO-TOKEN-001 详情，语言 / 时区继续传递。人工查看中英文账户页、窄屏滚动及所选原登录地址编辑窗。
- 新增删除链接的悬停文字 / 背景实测对比度 4.71:1、点击高度 36 px；键盘焦点为既有 2 px 可见轮廓。此为局部核验，不代表完整无障碍审计。截图仅用于内部核验。

未验证真实钱包 / 接口、服务端持久化、跨设备同步、Safari / Firefox、实体移动设备及完整无障碍审计。保存、删除等仍为原有静态演示反馈，不代表正式业务完成。
