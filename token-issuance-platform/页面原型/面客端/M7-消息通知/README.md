# M7 · 消息通知（企业端）

企业用户从顶栏消息入口查看未读数和最近消息，进入消息列表按已读状态与分类筛选，打开消息阅读并点编号前往原业务，一次标记当前筛选下的全部未读。组件按本平台[组件规范 §12](../../_shared/design-system/组件规范.md#12-消息通知m7)。依据 [PRD](../../../PRD/两端共用/M7-消息通知/01-消息通知-PRD.md)（基线 `231cf13`）；消息标题与正文取自各来源模块现行 03 消息通知册（M1、M3b、M4b）。**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、地址、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“已认证企业”或“未认证企业”，在任一企业端页面点顶栏铃铛打开最近消息预览；或直接双击本目录 [`消息通知.html`](消息通知.html)。语言、时区与身份随跳转传递，浏览器返回可回到原消息。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 面客端/M7-消息通知/消息通知.html --output <仓库外路径>.html`；前往原业务等跨模块入口显示范围提示。
- 侧栏底部（窄屏为右下角）的「画面目录 · 演示数据」默认关闭，按分组列出全部画面并提供「主流程下一屏」。

## 主流程

- 任一企业端页面点铃铛 → P01 最近消息 → 查看全部消息 → L01 消息列表 → D05「代币铸造成功 · DEMO-TOKEN-001」（打开即已读，角标 5 → 4）→ 点代币编号进入 M4a 代币详情 → 浏览器返回 → 面包屑回 L09（该条原地变为已读）→ A01 全部已读确认 → A03 处理中 → A05 成功。
- 其他去向：D07 发行申请已驳回（IA-DEMO-0012）进入 M3a 申请详情“运营驳回 · 可重新发起”；D02 销毁成功、D01 资产已解除托管、D09 / D10 销毁失败进入 M4a 对应销毁申请；D11「认证状态已变更」用“前往用户信息”进入 M1；D12「机构追加了发行材料 · DEMO-TOKEN-021」（业务提醒，L10 筛选可见）点代币编号进入 M4a 该代币详情的补充记录（路由 `tokenSupplement021`）。
- 原业务不可访问：D13「发行申请已进入铸造 · IA-DEMO-0008」编号只展示，提示“相关内容暂不可访问。”
- 未认证企业：U01 消息列表照常可看 → V05「代币铸造成功」→ 点 DEMO-TOKEN-001 前往原业务页面，由该页面给出认证引导（U02，标题随原业务菜单变化；侧栏业务菜单同样进入 U02）；V11 认证状态已变更仍进入 M1 用户信息；V12 机构追加了发行材料同样进入认证引导；V13 原业务不可访问仍只展示编号。没有有效企业归属（含上游未提供企业标识）的用户和游客一样不显示消息入口（由 M1 画面承载，见 M1 P3 / U7）。

本期不做（PRD §1.2）：发送、编辑、撤回消息与模板；邮件、短信与浏览器推送；删除、归档；逐条标为已读 / 未读；通知开关；两端未读合计。未登录打开消息链接后回到原消息由 M1 登录承载，本模块未单独出屏。
