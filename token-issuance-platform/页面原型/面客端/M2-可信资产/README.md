# M2 · 可信资产（企业端）

企业查看本企业已确权的资产，从可发行资产申请代币发行。管理端画面见 [管理端 M2](../../管理端/M2-可信资产/README.md)。依据 [PRD](../../../PRD/两端共用/M2-可信资产/01-可信资产-PRD.md)（2026-11-10，`7b28d70`）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、地址、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“已认证企业”，或直接双击 [`可信资产.html`](可信资产.html)。侧栏与账号菜单可跨模块跳转，语言、时区与身份随之传递。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 面客端/M2-可信资产/可信资产.html --output <仓库外路径>.html`，离线双击打开；跨模块入口显示范围提示。
- 侧栏底部（窄屏为右下角）的「画面目录 · 演示数据」默认关闭，列出全部画面并提供「主流程下一屏」。

## 主流程

- 申请发行：C1 资产列表 → D1 资产详情（RA-DEMO-0128，满足发起条件）→「申请发行」进入后续发行申请的固定资产填写画面。列表是主流程起点的快照；M2 不展开后续处理流程。
- 点击时条件已变化：C1 中 RA-DEMO-0166 列表快照为“未到期 / 可发行”，点击「申请发行」→ D11（上游已改为已逾期）：留在可信资产，一次列出全部不能发起的原因，不进入申请填写，发行状态仍为“可发行”。
- 关联记录：列出这笔资产的全部发行申请（提交时间由新到旧），申请状态按 M3a 企业可见状态展示。D3 IA-DEMO-0031（运营处理中）、D4 IA-DEMO-0015（运营驳回）、D5 IA-DEMO-0019（铸造成功）→ DEMO-TOKEN-001、D9 IA-DEMO-0027（发行处理中）、D10 IA-DEMO-0048（运营处理中）+ IA-DEMO-0012（运营驳回）。已有匹配画面的申请编号进入对应申请详情；代币编号进入这枚代币的详情。IA-DEMO-0015 没有匹配记录画面，保留只读编号。
- 驳回后重新申请：申请被驳回后资产回到“可发行”。D4 RA-DEMO-0097 满足发起条件，提供“申请发行”并提示最近一笔申请已被驳回；D10 RA-DEMO-0160 已用同一资产重新申请（与 M3a 的 IA-DEMO-0012 → IA-DEMO-0048 一致）。
- 到期：到期时点为来源时区（演示均为 Asia/Dubai）到期日当天 24:00，按当前时区换算展示日期、时间和时区。列表“到期日”列为日期 + 时分，表头标时区；详情摘要与“到期日”字段同为换算值，“原始到期日”展示上游到期日与来源时区。例如 RA-DEMO-0128 原始到期日 2027-03-31 Asia/Dubai，在 Asia/Shanghai 下为 2027-04-01 04:00。
- 列表：演示行序即默认排序（进入本平台时间由新到旧，时间本身不在列表展示）；分页条只画第 1 页。C2 尚无资产不显示筛选条；C6 无匹配、C3 读取失败保留筛选条与已填条件。
- 未认证：C4 受限引导 → C5 前往资产可信平台确认，取消回到 C4。
- 名称与语言：C1 债务人名称列分别展示名称、上游提供的英文名称；详情债权人 / 债务人拆成“企业名称”“企业英文名称”两个字段。切换语言只改变界面标签与平台文案，上游名称、国家 / 地区、地址等保持原值与顺序；未提供英文名称不补写。列表每个名称均能悬停或点按核对完整值。
- 金额原值：D1 的累计已回款为 50,000.00 USD、余额为 0.00 USD，上游仍未结清且未逾期，保留“未到期 / 可发行”和“申请发行”；D3 同样展示 82,400.00 USD 已回款、0.00 USD 余额，不改写状态。企业不显示金额关系预警；同笔资产的运营预警见 O8 / O4，机构对照见 R3。均为静态画面，不执行计算或校验。

- M2 详情摘要将交易方、到期信息逐行排列；时区紧随时间，在空间允许时同行显示。关联申请编号列固定 240 px，状态紧邻编号，避免两列明细表的中间空白过大。
