# M2 · 可信资产（企业端）

企业查看本企业已确权的资产，从可发行资产申请代币发行。管理端画面见 [管理端 M2](../../管理端/M2-可信资产/README.md)。依据 [PRD](../../../PRD/两端共用/M2-可信资产/01-可信资产-PRD.md)（2026-11-06，`9c13023`）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、地址、编号、金额均为演示数据。本轮为既有系统视觉深化（existing-system adaptation / console），以英文阅读为主，保留 PRD `9c13023` 的模块边界与全部既有画面。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“已认证企业”，或直接双击 [`可信资产.html`](可信资产.html)。侧栏与账号菜单可跨模块跳转，语言、时区与身份随之传递。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 面客端/M2-可信资产/可信资产.html --output <仓库外路径>.html`，离线双击打开；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，列出全部画面并提供「主流程下一屏」。

## 主流程

- 申请发行：C1 资产列表 → D1 资产详情（RA-DEMO-0128，满足发起条件）→「申请发行」进入后续发行申请的固定资产填写画面。列表是主流程起点的快照；M2 不展开后续处理流程。
- 关联记录：只读展示发行模块返回的当前申请结果。D3 IA-DEMO-0031（处理中）、D4 IA-DEMO-0015（已驳回）、D5 IA-DEMO-0019（已发行）→ DEMO-TOKEN-001、D9 IA-DEMO-0027（处理中）。不标注处理主体或内部阶段，不按身份映射状态。已有匹配画面的申请编号进入对应申请详情；代币编号进入这枚代币的详情。IA-DEMO-0015 没有匹配记录画面，保留只读编号。
- 未认证：C4 受限引导 → C5 前往资产可信平台确认，取消回到 C4。
- 名称与语言：C1 债务人名称列分别展示名称、上游提供的英文名称；详情债权人 / 债务人拆成“企业名称”“企业英文名称”两个字段。切换语言只改变界面标签与平台文案，上游名称、国家 / 地区、地址等保持原值与顺序；未提供英文名称不补写。列表每个名称均能悬停或点按核对完整值。
- 金额原值：D1 的累计已回款为 50,000.00 USD、余额为 0.00 USD，上游仍未结清且未逾期，保留“未到期 / 可发行”和“申请发行”；D3 同样展示 82,400.00 USD 已回款、0.00 USD 余额，不改写状态。企业不显示金额关系预警；同笔资产的运营预警见 O8 / O4，监管对照见 R3。均为静态画面，不执行计算或校验。

## 宽屏列间距修订（2026-11-09）

宽屏余量按字段角色分配到编号、资产价值、到期、回款、发行及企业操作列，名称仅承接部分增量；只读操作列仍保持 80 px。修复企业资产、运营全平台、运营企业详情内资产、机构关联资产四处列表的同类大空白。1920 px 下企业列表债务人列约 768 → 364 px，运营双名称列各约 428 → 258 px。

本轮仅修改上述列表的共享列宽规则及相关规范（existing-system adaptation / console）。企业列表、详情明细与其他画面继承并核查，保留金额紧凑排布；字段、名称原值、状态、分页与跳转未改。

Chromium 中英文 × 375 / 768 / 1280 / 1440 / 1920 / 2560 px，两端全部 37 屏回归；无整页横向溢出或单元格裁切，22 个已有资产编号入口核验通过。窄表继续表内滚动、右侧操作固定；长名称可核对完整值。未测 Safari / Firefox、触屏及真实接口权限。

## UI 深化（2026-11-06）

- 资产列表以编号、数值、时间、状态和操作的阅读空间为基础分配列宽，名称列分配余量；表格实际宽度 ≥1100 px 时为长英文状态留足空间，窄表允许按词换行。首末列与卡片头对齐，资产价值仍右对齐，分页与筛选规则继承。
- 两个名称按上游原值与固定顺序展示，原名 13 px、英文名称 12 px；保留各字段的完整悬停、键盘及点按核对。不会根据界面语言替换名称。
- 资产详情的债权人与债务人按实际详情容器 ≥900 px 并排，其余宽度纵向排列；长名称在各自分区完整换行，国家 / 地区与登记标识成对。资产基本信息、回款汇总沿用自适应三列，其他分区沿用各自布局，导航样式不变。
- 管理端企业列表使用专门的列宽变体；运营现有金额预警改为图标加文字，与业务状态底色标签区分。预警仍为非阻断，企业、监管不显示。
- M2 资产、企业列表在窄屏时仅表内横向滚动，操作列固定在右；滚动区可由键盘聚焦。不新增页面、状态、查询、分页、校验或处理逻辑。

组件来源：`_shared/tokens.css`、`components.css`、`asset-detail.js`，详见组件规范 **v1.65 §4.14**。本轮没有更换品牌、色彩或字体栈；共享资产详情的 M3a 引用继承双方对照组件，其业务页面与流程未改。
