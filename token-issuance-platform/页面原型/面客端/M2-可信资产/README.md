# M2 · 可信资产（企业端）

企业查看本企业已确权的资产，从可发行资产申请代币发行。管理端画面见 [管理端 M2](../../管理端/M2-可信资产/README.md)。依据 [PRD](../../../PRD/两端共用/M2-可信资产/01-可信资产-PRD.md)（`9fca0c6`）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、地址、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“已认证企业”，或直接双击 [`可信资产.html`](可信资产.html)。侧栏与账号菜单可跨模块跳转，语言、时区与身份随之传递。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 面客端/M2-可信资产/可信资产.html --output <仓库外路径>.html`，离线双击打开；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，列出全部画面并提供「主流程下一屏」。

## 主流程

- 申请发行：C1 资产列表 → D1 资产详情（RA-DEMO-0128，满足发起条件）→「申请发行」进入 M3a 已带入该资产的画面。列表是主流程起点的快照。
- 关联记录：点击申请编号进入 M3a 申请详情，点击代币编号进入 M4a 代币详情，不另设“查看”按钮。D3 IA-DEMO-0031（待运营审核）、D4 IA-DEMO-0015（监管驳回）、D5 IA-DEMO-0019（铸造成功）→ DEMO-TOKEN-001、D9 IA-DEMO-0027（铸造阶段对企业显示“发行处理中”）。
- 未认证：C4 受限引导 → C5 前往资产可信平台确认，取消回到 C4。
