# M2 · 可信资产（企业端）

企业查看本企业已确权的资产，从可发行资产申请代币发行。管理端画面见 [管理端 M2](../../管理端/M2-可信资产/README.md)。依据 [PRD](../../../PRD/两端共用/M2-可信资产/01-可信资产-PRD.md)（`cly-v6.0.0` 的 `e0fc67d`）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、地址、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“已认证企业”进入，或直接双击本目录 [`可信资产.html`](可信资产.html)。真实侧栏与账号菜单可跨模块跳转，语言、时区与身份随之传递。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 面客端/M2-可信资产/可信资产.html --output <仓库外路径>.html`，可双击离线打开；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，按分组列出全部画面，并提供「主流程下一屏」。等待类画面不自动推进。

## 主流程

- 申请发行：C1 资产列表 → D1 资产详情（RA-DEMO-0128，满足发起条件）→「申请发行」进入 M3a 已带入该资产的选择资产画面。
- 关联申请：D3（RA-0131 → IA-DEMO-0031 待运营审核）、D4（RA-0097 → IA-DEMO-0015 监管驳回）、D5（RA-0102 → IA-DEMO-0019 铸造成功）、D9（RA-0143 → IA-DEMO-0027 发行处理中）的申请编号进入 M3a 对应详情。
- 未认证：C4 受限引导 → C5 前往资产可信平台确认，取消回到 C4。

## 待确认项

- 资产列表是主流程起点的快照：RA-DEMO-0128 显示“可发行”，M3a 主流程提交后的申请为 IA-DEMO-0042（待监管审核）。
- 已撤销确权详情、已结清且曾逾期的回款进度，以及筛选无结果 / 筛选失败 / 到期范围无效三种状态未出屏，以 PRD 为准。

## 实际核验

2026-11-04（WS-585 统一核验）：Chromium headless 遍历源码全部 14 屏 × 中文 / English × 1280 / 1440 / 1920 px，无脚本错误、失效跳转、重复 id 或整页横向溢出；英文界面除原文数据（企业、机构、账号名称，意见与文件名）外无中文残留。由 `export.py` 生成的单模块附件在断网环境遍历全部画面，无外部请求。仓库联看中本模块的跨模块入口均能解析到已登记画面。
