# M1 · UI 设计说明

2026-10-29｜PRD 基线：`cly-v6.0.0` / `98ad0e0`（含 `0510d45` 规则更新）｜原型基线：`597f78e`｜existing-system adaptation｜企业端 console，含登录与游客。

本轮按用户“根据最新 PRD 更新原型，并优化页面”的授权，落实已确认的流程、字段与删除行为；新增画面均用于呈现这些 PRD 变化。

## 更新内容

- 登录按六步展示：连接钱包 → 连接成功 → 确认签名 → 钱包签名返回 → 验签通过 → 登录成功。连接成功显示地址及网络；确认前披露签名用途。第六步展示登录成功后调取身份中的反馈，不假设钱包连接即已登录。
- 登录说明采用用户指定原文，支持网络在底部同行显示图标与 Ethereum。所有网络名称仍为英文。
- 账户菜单收窄到 208 px，只保留缩写地址、复制和退出。去掉企业名称及其他提示。
- 左侧入口、面包屑、页面标题改为“企业账户”；列表标题为“数币账户”，保留数量。列序为账户备注名、区块链网络、数币地址、来源、创建时间、操作；去掉验证状态与删除限制说明。
- 每行删除均可点击：普通账户进入删除确认；登录地址及引用账户进入说明弹窗，只能关闭。引用示例明确显示代币 DEMO-TOKEN-001；其他引用类型和运行期间发生引用的情况以 PRD 为准。
- 新增表单按只读网络 → 数币地址 → 备注名排列；签名核对和编辑中同样拆分网络与地址。地址输入完整显示，其他展示缩写，复制传递完整值。
- 用户信息合成一张分区卡片，收紧资料行、表格行与页面留白。偏好设置参照借贷平台管理端截图，包含语言和 IANA 时区两个下拉。
- 支持中英文即时切换、输入值保留、当前浏览器语言记忆、时间按所选 IANA 时区显示，时间戳不改变。表单打开时可用弹窗标题栏的地球按钮切换语言。

## 实际核验

- Chromium headless，在 English / 简体中文及 320、375、768、1280、1440、1920 px 下逐屏检查，共 420 个组合；未发现脚本报错、整页横向溢出、主要容器越界或弹窗操作裁切。核对 SVG 图标与网络名称的垂直对齐。
- 离线单文件在 1280 px、两种语言下检查全部 35 屏，共 70 个组合；没有外部脚本、样式或图标依赖。抽查桌面与窄屏截图，截图仅用于内部核验。
- 点击走通六步登录和新增 / 签名 / 成功；等待外部结果时通过原有画面目录继续。检查三类删除结果、Tab 焦点循环、下拉与弹窗按 Esc 关闭后焦点恢复、未认证导航、游客无时区设置、账户菜单与退出。
- 实测填写地址和备注名后用弹窗语言入口切换，输入保留；语言可刷新记忆。切换 UTC / Asia/Shanghai 后示例显示 01:30:12 / 09:30:12，原始 datetime 不变。检查偏好保存中只禁用对应项、失败画面保留可重选控件。
- 检查复制处理器向 Clipboard API 传递完整 42 位地址；自动化捕获调用值，没有读取或改写用户系统剪贴板。
- 英文界面保留正式企业名、人名、原始备注名和注册地址，不自行翻译业务值。未验证真实钱包、真实接口、跨设备同步、全部 IANA 时区、Safari / Firefox、实体移动设备及完整无障碍审计。

## 打开与实现边界

源码在完整目录下打开 [企业登录与企业账户.html](企业登录与企业账户.html)。附件由 `_shared/export.py` 从同一源码生成，双击可离线打开；右下角原有画面目录默认收起。首次无浏览器语言记忆时为 English，可在顶栏切换简体中文。

保持轻量展示原型，企业、地址、邮箱、引用编号均为示例。钱包、接口、认证与账户增删改仍为静态画面和演示反馈；不执行业务校验或模拟后台。偏好保存中 / 失败为可从目录查看的静态画面，正常改选只更新预览，不伪装为服务端保存。

当前浏览器的语言可记忆；企业账户偏好的持久化、跨设备同步和服务端保存失败恢复需正式接口承接。时区预览仅本次打开期间保留，重新打开按浏览器有效时区初始化，推断失败为 UTC。正式规则以 [PRD](../../../PRD/v1.0-企业登录与企业账户-PRD.md#C-PROFILE-02) 为准。

本轮源码、共享 token、展示组件、[组件规范 v1.2](../../_shared/design-system/组件规范.md) 同步入库；未修改 PRD 或其他模块页面。
