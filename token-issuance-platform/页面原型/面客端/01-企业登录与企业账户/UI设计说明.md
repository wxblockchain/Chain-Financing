# M1 · UI 设计说明

2026-10-29｜基线：`cly-v6.0.0` / `08a9e0b`｜类型：existing-system adaptation｜界面：企业端 console，含独立登录与游客页。

## 本次变化

- 所有网络名称统一为前置图标 + **Ethereum**，覆盖说明、表头、表单、签名核对及壳层动态生成的受限说明。复用借贷平台已有 SVG，不依赖外部请求。
- 网络与币种共用 `.asset-label`，图标 18 px、间距 6 px、名称保持可见。M1 没有具体币种字段；ETH、USDT、USDC 图形资产供后续组件复用，不增加本模块币种选择、余额或网络选项。
- 沿用原蓝白体系。侧栏选中项用浅底和左侧标记；标题 24 px，字段标签与表格辅助信息 13 px，状态标签 12 px；地址继续缩写展示，等宽字体提高可辨识度。
- 资料页改为标签在上、值在下，两列内容对齐；弹窗沿用紧凑的横向标签。表格备注名列留出说明宽度，操作表头右对齐。登录增加钱包识别图形，主操作保持单一。
- 补齐 900 / 600 px 断点，窄屏菜单与表格各自在容器内横向滚动，弹窗内容可滚动、底栏可换行；修正锁定提示造成的窄屏页面溢出，以及直接按画面 hash 打开长页面时页头被浏览器片段定位跳过的问题。
- 同步 [组件规范 v1.1](../../_shared/design-system/组件规范.md)、token 与公共组件。当前共享层的实际消费者只有本 M1 原型。

## 画面覆盖

沿用原有 28 屏，没有新增画面或业务状态。以下均受公共视觉调整影响，并已逐屏检查：

| 页面 | 既有画面 | 数量 |
| --- | --- | --- |
| 登录 | L1–L5：默认、等待签名、确认身份、失败、登录结束 | 5 |
| 游客 | G1–G2：引导、离开确认 | 2 |
| 企业信息 | P1–P6：已认证、审核中、空、读取失败、地址不一致、账户入口展开 | 6 |
| 用户信息 | U1–U3：默认、个人信息空、读取失败 | 3 |
| 数币账户 | A1–A12：列表、仅登录地址、读取失败、受限、新增填写与错误、签名说明 / 等待 / 不一致、成功、编辑、删除 | 12 |

用户已确认的用户中心命名、内容区面包屑、地址缩写、账户菜单内容均保留。对照基线，28 屏的身份 / 状态 / 下一步 / 底层页面等元数据、输入框属性及跳转目标均未改变。

## 实际核验

- Chromium headless：源页在 320、375、768、1280、1440、1920 px 宽度逐屏检查，共 168 个组合；未发现整页横向溢出、主要容器越界、弹窗底栏按钮裁切或脚本报错。密集表格的容器内滚动是预期行为。
- 抽查登录、资料页、列表、填写与签名弹窗截图；实测窄屏菜单末项可达、表格可横向滚动且操作列可见。
- 点击走通登录 → 企业信息 → 数币账户 → 新增 → 签名 → 成功；钱包等待画面通过原有画面目录继续。检查编辑 / 删除弹窗关闭、Esc、语言与账户下拉、退出、未认证导航及地址缩写与完整 `title`。
- 检查前置 SVG 与名称对应、图标尺寸、ETH / USDT / USDC 图形及未知币种的中性占位。Linux 标题实际使用 WenQuanYi Micro Hei，无字体下载。
- 正文、次文字、弱文字、主按钮及成功 / 警告 / 错误文字的已用纯色组合对比度为 4.71:1–18.22:1；检查主按钮键盘聚焦与 Enter 操作。这不构成完整无障碍审计。
- 从源文件导出单文件 HTML，在离线模式、1280 px 下检查全部 28 屏；样式、脚本、图标与许可均内联，没有外部资源依赖。

## 使用与边界

源码在完整目录下直接打开 [企业登录与企业账户.html](企业登录与企业账户.html)。离线评审附件由 `_shared/export.py` 生成，双击打开；右下角原有画面目录默认关闭。

这是轻量布局与信息展示原型，企业、地址、邮箱、编号均为演示数据。钱包、数据读取、签名、复制、保存与删除沿用原有演示反馈，没有接入真实服务；语言入口不执行真实翻译。业务规则与异常分支以 [PRD](../../../PRD/v1.0-企业登录与企业账户-PRD.md) 为准。

未覆盖其他业务模块、管理端页面、真实钱包 / 接口联调、完整英文翻译，以及 Safari / Firefox 和实体移动设备测试。
