# M1 · UI 设计说明

2026-10-29｜PRD 基线：`cly-v6.0.0` / `98ad0e0`（含 `0510d45` 规则更新）｜原型基线：`9a3d6cb`，游客展示以用户最新意见为准｜existing-system adaptation｜企业端 console，含登录与游客。

本轮按用户“G1 G2 也在页面内呈现，保持统一”修订游客引导及离开确认。G1 使用平台骨架的常规内容区；G2 在同一内容区显示确认卡片，取消后回到发起处。登录三屏、企业账户、资料与偏好沿用上一轮原型，身份与权限规则保持原有口径。

## 更新内容

- 本轮：G1 从独立居中卡片改为平台内页；G2 从遮罩弹窗改为内容区确认卡片，保留顶栏、返回关系和实际身份。游客不显示业务菜单、消息或时区设置。
- 以下为继承的既有设计：

- 登录只保留 L1、L3、L4：连接成功直接到 L3，确认签名表示唤起插件钱包签名并进入 L4，返回并验签通过后直接进入平台，不停留在“验签通过 / 登录成功”独立页面。
- 删除 L2、L5、L6、L7、L8 及其原页面 ID。身份读取中、无法确认身份、登录结束放在平台内容区（S1–S3）；确认身份前不展示企业资料、业务菜单与消息入口。
- 三屏等宽、等高，实际尺寸随原 L3 内容自适应，无固定高度裁切。1440 px 下保留原 L3 的 480 px 宽度，当前核验环境下英文高度约 631 px、中文约 610 px。其他宽度也以 L3 为准；非当前屏不可见且不可聚焦。
- 登录说明采用用户指定原文，支持网络在底部同行显示图标与 Ethereum。所有网络名称仍为英文。
- 账户菜单收窄到 208 px，只保留缩写地址、复制和退出。去掉企业名称及其他提示。
- 左侧入口、面包屑、页面标题改为“企业账户”；列表标题为“数币账户”，保留数量。列序为账户备注名、区块链网络、数币地址、来源、创建时间、操作；去掉验证状态与删除限制说明。
- 每行删除均可点击：普通账户进入删除确认；登录地址及引用账户进入说明弹窗，只能关闭。引用示例明确显示代币 DEMO-TOKEN-001；其他引用类型和运行期间发生引用的情况以 PRD 为准。
- 新增表单按只读网络 → 数币地址 → 备注名排列；签名核对和编辑中同样拆分网络与地址。地址输入完整显示，其他展示缩写，复制传递完整值。
- 用户信息合成一张分区卡片，收紧资料行、表格行与页面留白。偏好设置参照借贷平台管理端截图，包含语言和 IANA 时区两个下拉。
- 支持中英文即时切换、输入值保留、当前浏览器语言记忆、时间按所选 IANA 时区显示，时间戳不改变。表单打开时可用弹窗标题栏的地球按钮切换语言。

| 页面 | 画面 | 数量 |

## 实际核验
+
+- 本轮使用 Chromium headless，在 English / 简体中文及 320、375、768、1280、1440、1920 px 下检查 G1 / G2，共 24 个组合；离线附件也检查同样 24 个组合。未发现脚本报错、整页横向溢出、主要内容越界或确认按钮裁切。
+- 检查 G1 注册 → G2 确认、取消 / Esc 返回、语言切换、地址与邮箱完整复制值、游客退出；游客始终没有业务导航、消息或时区控件。
+- 合并同分支 M2 新增的共享组件后，抽查 M2 面客端、运营端与监管端的页面渲染、角色导航及账户入口；保留 M2 的组件规范与说明，未改其模块页面。
- 回归未认证企业从业务受限页发起离开确认，取消后回到原受限页，保持企业导航与身份；抽查新增 / 删除模态弹窗与焦点返回，避免页内确认影响普通弹窗。
+- 抽查登录 L1 / L3 / L4 等高与流程跳转。其余页面沿用上一轮核验，本轮没有重做全站视觉审计。截图仅用于内部核验。
+- 未验证真实钱包、真实接口、跨设备同步、Safari / Firefox、实体移动设备及完整无障碍审计。
+
+## 打开与实现边界

源码在完整目录下打开 [企业登录与企业账户.html](企业登录与企业账户.html)。附件由 `_shared/export.py` 从同一源码生成，双击可离线打开；右下角原有画面目录默认收起。首次无浏览器语言记忆时为 English，可在顶栏切换简体中文。

保持轻量展示原型，企业、地址、邮箱、引用编号均为示例。钱包、接口、认证与账户增删改仍为静态画面和演示反馈；不执行业务校验或模拟后台。偏好保存中 / 失败为可从目录查看的静态画面，正常改选只更新预览，不伪装为服务端保存。

当前浏览器的语言可记忆；企业账户偏好的持久化、跨设备同步和服务端保存失败恢复需正式接口承接。时区预览仅本次打开期间保留，重新打开按浏览器有效时区初始化，推断失败为 UTC。正式规则以 [PRD](../../../PRD/v1.0-企业登录与企业账户-PRD.md#C-PROFILE-02) 为准。

本轮源码、页内确认布局、[组件规范 v1.5](../../_shared/design-system/组件规范.md) 同步入库；未修改 PRD 或其他模块页面。
