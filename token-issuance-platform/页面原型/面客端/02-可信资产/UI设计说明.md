## 页面结构

- 详情页顶部是资产摘要：金额、债务人、到期日，右侧四格分别是确权、结清、逾期、发行状态。面客端在摘要底部给出发起条件：满足时写“债权人已确权，满足发起条件”，不满足时逐条列出原因；申请中、已驳回、已发行写说明并给去向按钮。
- 下方依次是基本信息（含债权人、债务人）、贸易订单（含标的物明细）、采购订单、账款信息（销售账款、采购账款）、回款进度（含回款记录与支付凭证编号）、材料。只入库字段（运输方式、起运地、目的地）不展示。
- 沿用 WS-507 最新共享壳层（`1dfe60d`）：内容区随窗口展开，左右各 24 px，不另设 M2 最大宽度。
- 列表将确权、结清、逾期、发行状态各放一列；发行状态仅显示状态。移除行内附注（行业、英文名、上游变更提示、发起限制）；发起限制与上游提示在详情保留。非美元、状态无法获取两条原有列表记录补齐详情入口，以免移除附注后原因无处查看。
- 到期日有值时直接展示日期与时分，表头标注时区；源 HTML 保留文本值，浏览器启动后统一转换时区。金额数字 / 币种分别为表格 13 / 11 px、详情 14 / 12 px、摘要 28 / 14 px。
- 详情增加吸顶分区标签，点击定位，滚动同步高亮；所有分区保持连续可读，页尾不添加占位留白。资产详情包含概览、关联记录（有则显示）及六组信息，企业详情也可定位对应分区。
- 运营端的“上游已撤销确权”“上游已删除”只在运营端出现：列表不追加提示，详情页顶部保留提示条；企业端和监管端没有。
- 运营菜单把“可信资产 / 企业查看”拆成“可信资产”“企业”两项（M5 规定菜单名称和顺序由设计确定）；监管机构只有“可信资产”。

## 需要 PRD 同步的地方

1. PRD 3.4 要求运营看到完整以太坊地址和“验证状态”。原型沿用 M1 中用户已确认的口径：地址缩写，悬停看完整地址、复制得到完整地址；数币账户不再有验证状态。请 PRD 按此口径修订。
2. 申请状态取值（如“待运营审核”“铸造成功”）属于 M3a / M3b，原型暂用示意值，待这两个模块的 PRD 定稿后对齐。
3. 字段名使用 PRD 中各行业通用的名称（如“唯一识别码”“运输单据编号”），没有按汽车贸易改成 VIN、海运提单号；如需按行业显示，请在 PRD 中说明。

## 本期不做

应收账款以外的资产、汽车贸易以外的行业、在本平台录入或修改资产信息、代币的监管 / 融资 / 销毁状态、上游变更后的系统处理、界面语言与时区的选择保存（M1 / M5）、发行申请流程（M3a）、申请详情与代币台账（M3b / M4b）。这些去向在原型中只提示“属于其他模块”。

## 实际核验

- Chromium headless：M2 面客端 13 屏、管理端 16 屏，English / 简体中文 × 1280 / 1440 / 1920 逐屏核验；无脚本报错、整页横向溢出、表格横向滚动或操作列裁切，金额数字字号均大于币种字号。三种宽度的代表性列表与详情另作浏览器视觉检查；英文状态按完整单词换行。
- M2 全部详情分区标签共完成 516 次点击核验：定位目标可见、焦点到达分区、当前标签正确、画面路由保持不变；向上滚回顶部恢复概览高亮。另用键盘 Enter 激活标签，核对页尾分区不会被吸顶栏遮住。
- 点击走通：企业端全部七条列表记录 → 对应详情 → 返回列表；运营资产 → 详情 → 企业详情 → 企业资产 → 资产详情；监管关联资产 → 详情；真实语言菜单切换与键盘定位。发起发行及申请 / 代币的跨模块去向仍沿用原型提示。
- 到期日按 UTC、Asia/Shanghai、America/New_York 分别核对，日期与时分正确，切换语言后保留；原始带时区时间戳未改。
- 共享层回归：M1 全部 33 屏 × 双语 × 三种宽度，无脚本报错、页面溢出或操作列裁切；没有改写 M1 页面与已确认的宽屏样式。
- 两个最终单文件离线打开核验：全部 29 屏可达，列表日期、金额层级、详情导航与源文件一致，无网络请求。
- 未验证：Safari / Firefox、1280 px 以下宽度、完整无障碍审计。企业、地址、金额、编号均为演示数据。
