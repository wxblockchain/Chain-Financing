# M2 · 可信资产 UI 设计说明

2026-10-30｜existing-system adaptation｜console：企业、运营与监管机构。PRD 基线：[可信资产 PRD](../../../PRD/v1.0-可信资产-PRD.md)，本轮对应 `54d56bb`；实现基于已有原型 `7d7e918`，共享层沿用分支最新版本。组件规范：[v1.8](../../_shared/design-system/组件规范.md)。

## 交付与运行

- [企业端源码](可信资产.html)：13 屏；[管理端源码](../../管理端/02-可信资产/可信资产.html)：16 屏。
- 保留原有画面、目录、身份、路由与主流程，不附带 M1 页面。企业、姓名、地址、编号与金额均为演示数据。
- 完整源码目录下双击 HTML；评审附件由 `_shared/export.py` 从源码生成，离线双击打开，无外部字体、脚本与图片请求。生成件不入库。
- 首次默认 English，右上角可切换中文；浏览器已有语言记忆时沿用。时区展示仍由原共享展示层负责，M2 不新增偏好保存入口。

## 本轮视觉调整

- 英文优先：系统字体增加 Arial / Liberation Sans / system-ui 拉丁字母回退；中文按原字体回退。M2 英文字段标签扩到 160 px，中文仍为 120 px，长标签按完整词换行；上游企业名称等业务值保留原文。
- 金额用正文无衬线字体与等宽数字特性，币种弱化并与数字基线对齐：表格 13 / 11 px、字段 14 / 12 px、摘要 28 / 14 px。编号、地址继续使用等宽字体。所有金额、精度、币种与时间戳保持原值。
- 资产摘要以金额为主要阅读入口，右侧由四个框收敛为三项状态和细分隔线。满足发起条件的提示改用浅灰底与确认图标，减少与主要操作争夺注意力；异常提示保留原有警示色及完整原因。
- 列表统一为确权、回款、发行三列。回款状态按最新 PRD 的既有示例结果展示为未到期、已逾期、已结清或暂时无法确认；没有在原型中引入归并计算。列表不追加原因或上游变更附注，完整资产编号不换行。
- 详情分区标签移到资产概览下方，移除概览标签；关联记录（有则显示）和六组信息保持连续展开。标签点击定位、滚动同步高亮、键盘焦点与既有路由保留；吸顶偏移随实际顶栏高度更新。
- 详情面包屑中的可信资产 / 企业可用鼠标或 Enter 返回真实列表。没有独立页面的“业务”分类保留文本。管理端申请编号仍是唯一申请入口。
- 资产列表增加核心筛选布局，沿用借贷平台管理端 36 px 胶囊控件。资产编号、债务人、发行、回款状态为首行，币种及到期起止时间为次行；运营全平台、监管列表增加债权人，企业自己的列表与企业详情不重复显示债权人。时区可见。
- 企业端已成功发行的关联申请结果统一写“已发行”；原有待审核画面继承。企业端“发行处理中”与运营真实铸造状态的映射沿用 PRD，本轮没有新增铸造 / 失败重试画面。

## 原型与业务边界

筛选控件可输入与选择，原生重置可用；查询只给出原型说明，不过滤样本、不伪装查询成功。筛选匹配、时间范围校验、无匹配 / 查询失败、返回列表后按最新数据查询以及时区切换时保留范围，均由 PRD §5.6 与正式实现承接。本轮不新增这些结果画面或模拟逻辑。

申请详情、发行流程与代币后续状态仍属于 M3a / M3b / M4，不在 M2 重建。数币账户沿用已确认的地址缩写、完整值复制与不展示验证状态口径。

## 实际核验

- Chromium headless：M2 全部 29 屏与 M1 原有 33 屏，English / 简体中文 × 320 / 375 / 768 / 1280 / 1440 / 1920 px，共 744 次画面检查；无脚本报错、整页横向溢出或卡片越界，筛选控件均在视口内。1280 px 及以上表格无需横向滚动；窄屏密集表格在自身容器内滚动。
- 详情分区完成 600 次实际点击，覆盖中英文、375 / 1280 / 1440 / 1920 px：目标不被吸顶标签遮挡，焦点落到分区，当前标签正确，画面路由未改变。另用 Enter 激活，核对分区焦点。
- 每个含真实列表祖先的详情面包屑均以 Enter 核对返回，监管返回保持监管列表。资产筛选原生重置及查询原型说明已实测；原有源 HTML 的画面 ID、跳转目标、时间戳、金额与币种逐项比对不变。
- UTC / Asia/Shanghai / America/New_York 核对已知到期时点的日期与时分。材料异常弹窗核对初始焦点、Tab 限制与 Esc 返回。
- 最终两个自包含附件重新离线核验：全部 29 屏 × 双语 × 1280 / 1440 / 1920 px，共 174 次画面检查；无报错或外部请求，三项状态、标签及面包屑与源码一致。
- 浏览器实际使用 Liberation Sans（非网络字体）；主要正文、辅助文字、操作与状态文字的实际配色对比度分别为 7.53、4.68、6.70、5.40 / 5.20 / 4.71，控件描边对白底为 3.69。未做完整读屏或无障碍审计。
- 未验证 Safari / Firefox、真实账户权限与服务端查询。没有接入真实 API、钱包或查询服务，不将静态原型核验视为业务系统验收。
