## 本轮同步（PRD 7fb395b → a957f38）

- **状态分列**：销毁申请状态只有销毁中 / 销毁失败 / 销毁成功，资产托管状态只有托管中 / 已解除托管；“待解除托管”不再作为状态出现。销毁记录列表分两列展示，详情页头为“销毁成功 + 托管中/已解除托管”，进度第 4 段为“托管中”，台账“销毁进度”只取销毁申请状态。
- **非平台入口**：提交时间取链上确认时间；运营销毁记录详情与资产托管机构解除详情新增“非平台入口风险项”（到期、结清、融资），解除详情页头下方显著提示风险，解除照常可办。
- **销毁中满 10 分钟**：`b-pending-2` 页头下方提示联系平台开发，详情不提供线上处理按钮。
- **地址**：提交条件快照改为“当前所在地址”；“铸造到账地址”改为“发行地址”。持有信息只展示当前所在地址（质押期间为质押地址）；运营另看持有数量、融资状态、下游融资结果、链上验证结果，机构只看当前所在地址与代币当前状态。
- **机构可见范围**：解除详情新增销毁交易记录（发送地址、时间、来源、结果）；操作进度主体为“企业名称 · 发送地址”和“链上结果”；名单内机构可从本机构代币台账查看各笔销毁申请（新增 `rl-b-0024`、`rld-b-0018`），不显示原始失败说明，法律服务 / 审计机构不显示解除操作人。
- **列表**：四个列表均分页（只画第 1 页）；解除托管列表取消“待解除 / 已解除”切换，改为查找 + 资产托管状态、交易来源筛选，托管中在前；两个台账新增查找与“销毁进度”筛选。尚无记录不显示筛选条，筛选无匹配与读取失败保留条件。当前资产估值超两位小数时截断展示并可查看完整值。
- **调价**：未销毁且无销毁中申请即可调整（含质押、违约、合约停用），沿用原画面；销毁中不可调。

## 主流程

- 运营：`b-list → b-pending`（销毁中）→ `b-release`（销毁成功 · 托管中）；失败看 `b-failed`、`b-prior-failed`（已有新申请），超过 10 分钟看 `b-pending-2`，非平台入口与风险项看 `b-external`。
- 解除资产托管（资产托管机构 示例机构 C）：`r-list → r-detail → r-edit → r-ready → r-confirm → r-submitting → r-result`。必填、文件上传中或失败、提交失败、结果未确认，以及停用机构、依据缺失、非平台入口风险提示（`r-external`）见画面目录。
- 调整单位价值（DEMO-TOKEN-001）：`l-001 → v-edit → v-ready → v-confirm → v-pending → v-success → l-001-updated`；失败为 `v-failed`，处理中详情为 `l-001-updating`。`l-021`（销毁中）的调整按钮不可用，已销毁代币不显示调整入口；`l-022`（质押中）可调整。
- 机构查看销毁申请：资产托管机构 `rl-021 → rl-b-0024`（销毁失败）；审计机构（示例机构 D，只读）`r-list-audit`（无解除事项）→ `rld-list` → `rld-025 → rld-b-0018`。
