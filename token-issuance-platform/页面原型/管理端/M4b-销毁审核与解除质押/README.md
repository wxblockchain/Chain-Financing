# M4b · 销毁审核、解除监管与代币台账

运营审核并执行销毁、处理销毁失败重试；监管机构对已销毁代币解除监管；两种身份按各自范围查看代币台账。依据 [PRD](../../../PRD/管理端/M4b-销毁审核与解除质押/01-销毁审核与解除质押-PRD.md)（`cly-v6.0.0` 的 `5f8c1e0`）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、地址、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“运营”或“监管机构”进入，或直接双击本目录 [`销毁审核与解除质押.html`](销毁审核与解除质押.html)。真实侧栏与账号菜单可跨模块跳转，语言、时区与身份随之传递。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 管理端/M4b-销毁审核与解除质押/销毁审核与解除质押.html --output <仓库外路径>.html`，可双击离线打开；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，按分组列出全部画面，并提供「主流程下一屏」。等待类画面不自动推进。

## 主流程

- 通过并销毁：b-list → b-pending（BA-DEMO-0031）→ b-approve → b-approve-submitting → b-burning → b-release（销毁成功，待解除监管）。
- 解除监管：r-list → r-detail → r-form → r-form-file → r-submitting → r-done。
- 驳回：b-unknown（BA-DEMO-0024，结清无法确认）→ b-reject → b-reject-ready → b-reject-submitting → b-rejected。
- 失败重试：b-failed（BA-DEMO-0021）→ b-retry → b-retry-submitting → b-retry-burning。
- 驳回销毁失败的申请：b-failed-pledged（代币在质押地址，不能重试）→ b-reject-failed → b-reject-failed-submitting → b-rejected-failed（原通过与失败记录保留）。
- 台账：l-list / rl-list → 代币详情 → 销毁记录编号 → 销毁详情（运营）或解除监管详情（监管，仅销毁成功的申请可点）。DEMO-TOKEN-031 属于 Demo Trading C Pte. Ltd.、示例监管机构 F，只出现在运营台账。

## 已落实的裁定与待确认项

- Q-M4B-02、Q-M4B-04 已按当前处理执行：驳回意见必填，解除备注与凭证选填，均不设上限或格式提示；不展示销毁交易哈希、执行进度，不设超时提醒，结果未确认时保持销毁中。
- 违约代币禁止销毁：持有信息显示质押地址时，待审申请不能通过（`b-pending-pledged`），销毁失败申请不能重试、可驳回（`b-failed-pledged` 起）。平台无下游违约状态，违约与正常融资质押同样按质押地址呈现，不另设违约标识；违约代币保持监管中，不形成解除事项。
- 持有地址条件为“持有地址为铸造到账地址且质押地址为空”，条件核对中以一项展示。
- Q-M4B-06（销毁交易由谁签名提交、合约能否销毁企业持有地址中的代币）待开发验证，确认前不新增链上授权或字段。
