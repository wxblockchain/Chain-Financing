# M4b · 销毁审核、解除监管与代币台账

运营审核并执行销毁、处理销毁失败；原监管机构对已销毁代币解除监管；运营与监管机构按各自范围查看代币台账。依据 [PRD](../../../PRD/管理端/M4b-销毁审核与解除质押/01-销毁审核与解除质押-PRD.md)（`9fca0c6`）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、地址、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“运营”或“监管机构”，或直接双击本目录 [`销毁审核与解除质押.html`](销毁审核与解除质押.html)。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 管理端/M4b-销毁审核与解除质押/销毁审核与解除质押.html --output <仓库外路径>.html`；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，列出全部画面并提供「主流程下一屏」。

## 主流程

- 通过并销毁：01 列表 → 04 待运营审核（BA-DEMO-0031）→ 20 确认 → 21 提交中 → 11 销毁中 → 14 销毁成功、待解除监管。销毁交易由平台签名提交，运营与企业不使用钱包。
- 驳回：09 条件无法确认（BA-DEMO-0024）→ 24 / 25 / 26 填写意见 → 27 → 17 驳回。
- 失败重试：12 销毁失败（BA-DEMO-0021）→ 31 确认 → 33 → 34 重试后销毁中；74 为平台未能签名或提交导致的失败，同样手动重试。
- 驳回销毁失败的申请：13 代币在质押地址（不能重试）→ 28 → 29 → 30 驳回，原通过与失败记录保留；77 持有信息查询失败时不能重试也不能驳回。
- 解除监管：35 → 39 → 45 → 46 → 48 → 49 解除完成；41 为已停用机构仍可解除。
- 台账：50 / 53 → 代币详情 → 销毁记录编号 → 销毁详情（运营）或解除监管详情（监管，仅销毁成功的申请可点）。

演示数据与 M4a 一一对应：代币 001、021–026，申请 BA-0018 / 0019 / 0021 / 0024 / 0030 / 0031。DEMO-TOKEN-027 为 M3b 铸造成功结果（IA-DEMO-0031），由路由 `reviewToken` 进入 75 / 76；DEMO-TOKEN-031 属于 Demo Trading C Pte. Ltd.、示例监管机构 F，只出现在运营台账。违约代币与正常融资质押同样按持有信息中的质押地址展示，不另设违约标识。已销毁代币的持有地址为空。
