## 本次修订

- **单位与识别**：代币数量、申请销毁数量、实际销毁数量的单位改为代币符号 cou；代币价值、资产价值仍用 USD。销毁详情、解除监管详情、代币详情的页头与 M4a 一致：第一行为所属网络，标题为代币图标、数量和符号加状态标签，下一行为编号（详情另带企业名称）和时区。
- **列表统一**：销毁审核列表、解除监管列表都改为每列一类信息，带“查看”操作列；编号即入口，“查看”与点编号进入同一详情，办理动作只在详情中进行。
  - 销毁审核列表：销毁申请编号 / 企业名称 / 代币编号 / 资产编号 / 申请销毁数量 / 提交时间 / 当前阶段。
  - 解除监管列表：在销毁数量、销毁成功时间之后增加“解除时间”列，待解除事项该列为空。
  - 两种代币台账：改为与 M4a 我的代币相同的表格，另加“发行人”列，按发行时间由新到旧排列。列为所属网络 / 代币类型 / 代币编号 / 发行人 / 代币数量 / 代币价值 / 持有地址 / 到期日 / 销毁进度 / 操作。已销毁代币的持有地址为空。“未发起”统一改为“未申请”。
- **编号前往**：代币编号进入所在台账的代币详情。运营点击销毁申请编号进入销毁详情；监管机构只能点击已销毁成功的申请，进入解除监管详情，其他阶段只显示编号。资产编号、发行申请编号有匹配画面时进入 M2 / M3b，否则显示范围提示。确认弹窗中的编号只展示、不跳转；取消原“查看代币 / 查看资产”文字入口和合约名称跳转。
- **销毁详情**：申请概览（`.application-summary` + `.review-timeline`，与 M3a / M3b / M4a 相同）→ 销毁条件核对 → 持有信息 → 申请信息 → 业务签名 → 结果 / 解除记录 → 本代币其他申请 → 审核与执行记录。分区导航和吸顶标题沿用共享层。
  - 条件核对新增“持有地址是否为铸造到账地址”一项。
  - 业务签名包括签名地址、签名时间和签名值，仅运营可见。
  - 运营审核人、驳回意见放在概览时间线下方。
- **代币详情**：分为代币发行信息（12 项）/ 持有信息列表 / 发行关联业务 / 监管信息 / 销毁条件与记录，与 M4a 相同；运营和监管看到的内容一致，只是范围不同，且不展示账户备注名。
- **新增画面**：

  - `l-holding-fail`：持有信息查询失败，替代原 `l-partial`。
  - 重试未通过画面 `b-retry-blocked` 改为“持有地址不是铸造到账地址”。重试确认中说明沿用原业务签名、企业不再签名。

## 主流程

- 通过并销毁：`b-list` → `b-pending`（BA-DEMO-0031）→ `b-approve` → `b-approve-submitting` → `b-burning` → `b-release`（销毁成功，待解除监管）。
- 解除监管：`r-list` → `r-detail` → `r-form` →（选择凭证）`r-form-file` → `r-submitting` → `r-done`。
- 驳回：`b-unknown`（BA-DEMO-0024，结清无法确认，不能通过）→ `b-reject` → `b-reject-error` → `b-reject-ready` → `b-reject-submitting` → `b-rejected`。
- 失败重试：`b-failed`（BA-DEMO-0021）→ `b-retry` → `b-retry-submitting` → `b-retry-burning`。
- 台账：`l-list` / `rl-list` → 代币详情 → 销毁记录中的编号 → 对应销毁详情，或监管机构的解除监管详情。

提交中和销毁中画面不会自动推进，用画面目录中的“主流程下一屏”查看结果。其他同类申请上的通过、驳回和解除按钮保持可用状态，点击后提示演示只展开主流程示例。
