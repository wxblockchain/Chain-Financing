# M3b · 发行审核与铸造

监管机构一审（上传监管协议后通过，或驳回），运营二审（选择合约通过并铸造，或驳回），以及铸造失败后的重试。依据 [PRD](../../../PRD/管理端/M3b-代币发行-审核与铸造/01-代币发行-审核与铸造-PRD.md)（2026-11-05 版）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、地址、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“运营”或“监管机构”，或直接双击 [`发行审核.html`](发行审核.html)。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 管理端/M3b-发行审核/发行审核.html --output <仓库外路径>.html`；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，列出全部画面并提供「主流程下一屏」；等待类画面不自动推进。

## 主流程

演示申请 IA-DEMO-0031（RA-DEMO-0131，82,400.00 USD，示例监管机构 C，合约 Demo Contract K），提交、一审时间、签名与协议文件与 M3a 一致。

- 监管一审通过：r-list → r-wait-reg → 上传协议（2 份）→ 确认 → 提交中 → r-wait-ops。
- 运营二审通过并铸造：o-list → o-wait-ops → 分步弹窗「1 选择合约 · 2 发起铸造 · 铸造进度」→ 平台签名并提交 → 等待链上结果 → 铸造成功。第 2 步只展示写入链上的 5 项（接收地址、代币数量、到期日、资产编号、企业业务签名值），另列交易所用合约。
- 驳回：监管、运营各自填写意见（空白时提示必填）→ 确认 → 提交中 → 驳回结果。
- 铸造重试：o-failed → o-retry「确认重试 · 铸造进度」→ 铸造中 → 铸造成功；原合约仅平台停用时仍可重试，实际链上异常单独提示且不可重试。
- 关联资产展示确权、回款、发行三个状态，与可信资产一致；结清、逾期的经过在资产详情查看。业务签名（签名地址、时间、值）只有运营可见。
