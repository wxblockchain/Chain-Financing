# M3b · 发行审核与铸造

监管机构一审（上传监管协议后通过，或驳回），运营二审（选择合约通过并铸造，或驳回），以及铸造失败后的重试。依据 [PRD](../../../PRD/管理端/M3b-代币发行-审核与铸造/01-代币发行-审核与铸造-PRD.md)（`cly-v6.0.0` 的 `e0fc67d`）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、地址、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“运营”或“监管机构”进入，或直接双击本目录 [`发行审核.html`](发行审核.html)。真实侧栏与账号菜单可跨模块跳转，语言、时区与身份随之传递。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 管理端/M3b-发行审核/发行审核.html --output <仓库外路径>.html`，可双击离线打开；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，按分组列出全部画面，并提供「主流程下一屏」。等待类画面不自动推进。

## 主流程

- 监管一审通过：r-list → r-wait-reg → 上传协议（2 份）→ 确认 → 提交中 → r-wait-ops。
- 运营二审通过并铸造：o-list → o-wait-ops → 分步弹窗「1 选择合约 · 2 发起铸造 · 铸造进度」→ 签名并提交 → 等待链上结果 → 铸造成功；成功后点代币编号进入 M4b 代币台账。
- 驳回：监管、运营各自填写意见 → 确认 → 提交中 → 驳回结果；驳回终态不显示监管协议。
- 铸造重试：o-retry「确认重试 · 铸造进度」→ 提交中 → 铸造中 → 铸造成功。
- 演示申请 IA-DEMO-0031（RA-DEMO-0131，82,400.00 USD）的提交、一审时间与协议文件名与 M3a 一致；合约为 Demo Contract K。
