# M3b · 发行审核与铸造

按用户“直接输出页面原型”合并后续阶段交付。类型：existing-system adaptation / console；基线为 `cly-v6.0.0` 的 M3b PRD 四册（含 `3d581de` 对既有业务与合约停用的修订），沿用组件规范 v1.13，并在 v1.14 登记本次新增的审核组件。

## 打开与维护

- 完整同步 `页面原型/` 后双击 [发行审核.html](发行审核.html)，默认进入运营「发行审核」列表；监管画面在右下角默认关闭的「画面目录 · 演示数据」中切换。
- 使用现有真实侧栏切换 M2、M5、M6；资产详情的 `IA-DEMO-0031` 可返回本模块同一笔申请。语言、IANA 时区和对应身份随仓库联看传递；未交付的代币台账、销毁等入口保留范围提示。
- 源文件只引用 `_shared/` 的 token、组件、图标、展示、壳层、导航及详情分区导航，不包含模块 CSS 或第二套运行时。审核列表、进度、合约单选、意见框和文件预览样式维护在 `components.css`，取值全部来自既有 token。
- 从 `页面原型/` 执行 `python3 _shared/export.py --source 管理端/03-发行审核/发行审核.html --output <仓库外路径>.html`，生成可双击打开的单模块离线附件。附件不含 `navigation.js`，跨模块入口只提示范围；生成件不入库。

## 画面清单与到达方式

共 **74 屏**，全部在画面目录中可到达。列表 → 详情、上传／选择／填写 → 确认 → 提交中由页面按钮逐屏跳转；提交中与铸造中不自动推进，使用目录中的「主流程下一屏」查看后续结果。各画面为同笔演示申请的独立阶段快照，不构成实时状态机。

| 目录分组 | 屏数 | 覆盖内容 |
| --- | ---: | --- |
| 运营 · 申请列表 | 5 | 默认、暂无申请、无匹配、读取失败、铸造失败申请 |
| 监管 · 申请列表 | 5 | 同上；仅本机构数据范围 |
| 运营 · 申请详情 | 12 | 七种申请状态、读取失败、无权或不存在、上游撤销确权、上游暂不可用、原合约平台停用但继续铸造 |
| 监管 · 申请详情 | 10 | 七种状态、读取失败、无权或不存在、机构停用仍可办理在途一审 |
| 监管协议 · 查看与下载 | 8 | 两角色各有 PDF 示例预览、签署页示例预览、查看失败、下载失败 |

| 操作反馈 | 2 | 两角色各一屏：其他审核人已处理后的状态变化反馈 |

上述新增画面状态为 covered；共享壳层、组件和既有 M2/M5/M6 业务画面为 preserved from existing。本次仅为 M2 申请编号补跨模块路由，未重画 M2。保持两位小数 USD、Ethereum、只读发行字段、监管数据范围与意见原文；监管看不到账户备注、运营账号或铸造失败说明。

首次二审只可选可用合约。重试沿二审原合约，不重新按首次筛选条件排除平台停用合约；实际链上执行异常单独出屏。此口径来自最新 PRD `3d581de`，替代 Stage 1 基线中“平台停用须先启用再重试”的旧表述。

本期不做（out of scope）：企业提交、撤回和修改申请；驳回后重开或退回；在线签署协议；一审后替换、删除或补传协议；审核人修改数量、币种、到期日、地址；合约部署与维护；融资质押、销毁、解除质押及任务分派认领。上述功能由 PRD 或相邻模块承接，不在本原型中新增。

## 验证与边界

Chromium headless：全部 74 屏按中文／英文 × 1280／1440／1920 px 遍历，共 444 次画面检查；检查重复 ID、画面跳转目标、横向溢出及控件裁切，未发现异常。人工查看代表性列表、详情、协议上传、铸造确认与失败记录画面。已检查主流程、合约选择、Tab 焦点约束、Esc 返回及焦点恢复、语言切换保留当前输入、地址复制的完整值、详情分区导航、仓库 M2/M5/M6 双向跳转、刷新与浏览器前进后退、机构停用身份及展示偏好保持。离线附件遍历全部画面，无外部样式或脚本依赖、无跨模块文件请求；目录默认关闭。未测 Safari/Firefox、真实接口或全平台端到端业务。

**规则、校验与异常分支以 PRD 为准。** 演示数据明确标识。表单、协议上传与预览、下载、审核、铸造和重试均为画面规格：输入可编辑，但不执行业务校验、不保存输入流转、不发送申请或交易；PDF／图片预览使用标记清晰的示例内容，未连接真实文件服务。提交中屏的按钮保持不可重复提交的表现，结果用静态画面承接。
