# M5 · 管理端登录与权限、监管机构管理

管理端邮箱密码登录、首次改密、找回密码、本人修改密码与登录邮箱、账户设置与访问反馈，以及运营的监管机构管理。两个子模块在一个源 HTML 中维护。依据 [管理端登录与权限 PRD](../../../PRD/管理端/M5-管理端登录与权限/01-管理端登录与权限-PRD.md) 与 [监管机构管理 PRD](../../../PRD/管理端/M5-监管机构管理/01-监管机构管理-PRD.md)（`9fca0c6`，2026-11-05）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、邮箱、编号均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择管理端身份进入，或直接双击本目录 [`管理端账号与监管机构管理.html`](管理端账号与监管机构管理.html)。真实侧栏与账号菜单可跨模块跳转，语言、时区与身份随之传递。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 管理端/M5-管理端登录与权限/管理端账号与监管机构管理.html --output <仓库外路径>.html`，可双击离线打开；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，按分组列出全部画面，并提供「主流程下一屏」。人机校验的滑块点击即视为通过（提示“验证通过”）；等待类画面不自动推进。

## 主流程

- 登录：login-ops / login-reg → 仓库联看中进入该角色的「发行审核」（单模块附件中进入账户设置）。
- 首次改密：login-initial → first-ready → login-changed → 重新登录。
- 找回密码：recover-filled →「获取验证码」→ recover-captcha（人机校验）→ recover-code → recover-ready → login-recovered；运营为 recover-ops-*。发送失败重试、重新获取验证码都回到人机校验。
- 本人改密码：账户设置「修改密码」→ password-ops / password-reg（验证当前密码）→ password-ready / password-reg-ready（设置新密码）→ login-changed。
- 本人改邮箱：账户设置「修改登录邮箱」→ self-email（验证当前密码）→ self-email-filled → self-email-captcha → self-email-code → self-email-confirm → r-settings-new（当前登录保留，提示“登录邮箱已修改”）；运营为 self-email-ops-* → o-settings-new。
- 监管机构管理：rg-list → rg-detail → edit-ready → edit-saved；添加机构 invite-ready → invite-sent → rg-initial；停用 / 启用 disable-confirm → rg-off、enable-confirm → rg-detail。
- 访问受限：access-menu / access-data / access-action 的出口为「返回发行审核」。
- 示例机构：C 启用 / 正常，D 待首登改密，E 账号锁定，F 已停用，G 新添加。
