# M2 · 可信资产与企业（管理端）

运营只读核对全平台资产、企业与企业数币账户，机构只读查看本机构关联资产。企业端画面见 [企业端 M2](../../面客端/M2-可信资产/README.md)。依据 [PRD](../../../PRD/两端共用/M2-可信资产/01-可信资产-PRD.md)（2026-11-10，`48e5924`）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、地址、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“运营”或“机构”，或直接双击 [`可信资产.html`](可信资产.html)。侧栏与账号菜单可跨模块跳转，语言、时区与身份随之传递。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 管理端/M2-可信资产/可信资产.html --output <仓库外路径>.html`，离线双击打开；跨模块入口显示范围提示。
- 侧栏底部（窄屏为右下角）的「画面目录 · 演示数据」默认关闭，列出全部画面并提供「主流程下一屏」。

## 主流程

- 运营：O1 资产列表 → O4 资产详情（发行申请中，申请状态“运营处理中”，已关联机构“示例机构 C”）；点击申请编号 IA-DEMO-0031 查看对应申请。O6 已发行（铸造成功），点击代币编号 DEMO-TOKEN-001 进入全平台代币台账中的代币详情。运营只读查看已关联机构，不在 M2 分配机构或处理申请。
- 运营 · 企业：E1 企业列表 → E4 企业详情（企业信息、企业用户、数币账户、资产）。登录地址本期不允许变更，原 E5（登录地址变更后）已删除。
- 机构：R1 关联资产列表 → R3 资产详情 → 点击申请编号查看本机构已关联申请。没有审核、驳回或申请处理操作。R6 本机构已停用时关联资产仍可查看。
- 多笔申请：运营 O10（RA-DEMO-0160）按提交时间由新到旧列出全部申请：IA-DEMO-0048 待分配机构、IA-DEMO-0012 运营驳回 · 示例机构 C。机构只看本机构关联的申请：R7（RA-DEMO-0174，演示资产）只关联被驳回的 IA-DEMO-0017，资产如实显示“已发行”但不展示代币编号；R8（RA-DEMO-0102）属于铸造成功申请 IA-DEMO-0019 的名单内机构，展示 DEMO-TOKEN-001。
- 申请状态：运营与机构按 M3b 真实申请状态展示（O4 / R3 / R6 运营处理中，O6 铸造成功，O7 / R5 铸造失败）。资产确权后信息不再变化，上游不存在撤销确权或删除资产，确权状态只有“已确权”。
- 到期：到期时点为来源时区（演示均为 Asia/Dubai）到期日当天 24:00，按当前时区换算展示日期、时间和时区；详情“原始到期日”展示上游到期日与来源时区。
- 列表：资产列表与企业列表都分页（只画第 1 页），演示行序即默认排序（资产按进入本平台时间、企业按取得时间，均由新到旧，时间本身不展示）。尚无记录（O2、E6、R2）不显示筛选 / 查找；无匹配（O9、E2）与读取失败（O3、E3）保留条件。
- 运营预警：O1 的 RA-DEMO-0128 / 0131 标记“金额待核对”，点击编号或“查看”分别到 O8 / O4；E4 的企业内资产列表也显示标记并可进入相同详情。详情并列展示原始资产价值、累计已回款、余额、结清状态，并说明核对上游、不影响申请。不实现预警检测，不新增消息通知。
- 身份对照：RA-DEMO-0131 在企业 D3、运营 O4、机构 R3 / R6 均为原始资产价值 82,400.00 USD、已回款 82,400.00 USD、余额 0.00 USD，上游仍未结清；仅运营显示预警。
- 双名称：资产列表债权人 / 债务人、企业列表分别展示上游名称及存在的英文名称；详情拆成两个字段。语言不切换名称值或顺序。

数币账户字段沿用 M1：账户标识“登录地址”、区块链网络 Ethereum、当前数币地址（缩写、完整悬停和复制）。只读展示唯一地址，不展示备注名、来源、创建/更新时间或验证状态。
