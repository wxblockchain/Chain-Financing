# M2 · 可信资产与企业（管理端）

运营查看全平台资产、企业与企业数币账户，监管机构查看本机构关联资产。企业端画面见 [企业端 M2](../../面客端/M2-可信资产/README.md)。依据 [PRD](../../../PRD/两端共用/M2-可信资产/01-可信资产-PRD.md)（2026-11-06，`26620e6`）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、地址、编号、金额均为演示数据。本轮为既有系统修订（existing-system adaptation / console），继承已批准的布局与其他流程。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“运营”或“监管机构”，或直接双击 [`可信资产.html`](可信资产.html)。侧栏与账号菜单可跨模块跳转，语言、时区与身份随之传递。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 管理端/M2-可信资产/可信资产.html --output <仓库外路径>.html`，离线双击打开；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，列出全部画面并提供「主流程下一屏」。

## 主流程

- 运营：O1 资产列表 → O4 资产详情（发行申请中）→ 点击申请编号 IA-DEMO-0031 进入 M3b 运营审核详情；O6 已发行，点击代币编号 DEMO-TOKEN-001 进入 M4b 代币台账详情；O7 关联申请铸造失败，管理端显示真实状态。
- 运营 · 企业：E1 企业列表 → E4 企业详情（企业信息、企业用户、数币账户、资产）；E5 为登录地址变更后的数币账户（只展示新的当前登录地址，旧地址不保留为其他账户）。
- 监管：R1 关联资产列表 → R3 资产详情 → 点击申请编号进入 M3b 监管详情；R5 铸造失败显示真实状态；R6 本机构已停用时关联资产仍可查看。
- 运营预警：O1 的 RA-DEMO-0128 / 0131 标记“金额待核对”，点击编号或“查看”分别到 O8 / O4；E4 / E5 的企业内资产列表也显示标记并可进入相同详情。详情并列展示应收金额、累计已回款、余额、结清状态，并说明核对上游、不影响申请。复用静态画面，不实现预警检测，不新增消息通知。
- 身份对照：RA-DEMO-0131 在企业 D3、运营 O4、监管 R3 / R6 均为应收 82,400.00 USD、已回款 82,400.00 USD、余额 0.00 USD，上游仍未结清；仅运营显示预警。RA-DEMO-0128 的企业 D1 仍可申请发行，运营 O8 只读。
- 双名称：资产列表债权人 / 债务人、企业列表分别展示上游名称及存在的英文名称；详情拆成两个字段。语言不切换名称值或顺序，也不翻译国家 / 地区、地址及其他上游内容。英文名称缺失的企业仍只展示已提供的名称。

数币账户字段沿用 M1：账户标识“登录地址”、区块链网络 Ethereum、当前数币地址（缩写、完整悬停和复制）。只读展示唯一地址，不展示备注名、来源、创建/更新时间或验证状态。
