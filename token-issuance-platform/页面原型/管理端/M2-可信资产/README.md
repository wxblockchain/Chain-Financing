# M2 · 可信资产与企业（管理端）

运营查看全平台资产与企业，监管机构查看本机构关联资产。企业端画面与资产详情组件见 [企业端 M2](../../面客端/M2-可信资产/README.md)。依据 [PRD](../../../PRD/两端共用/M2-可信资产/01-可信资产-PRD.md)（`cly-v6.0.0` 的 `e0fc67d`）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、地址、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“运营”或“监管机构”进入，或直接双击本目录 [`可信资产.html`](可信资产.html)。真实侧栏与账号菜单可跨模块跳转，语言、时区与身份随之传递。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 管理端/M2-可信资产/可信资产.html --output <仓库外路径>.html`，可双击离线打开；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，按分组列出全部画面，并提供「主流程下一屏」。等待类画面不自动推进。

## 主流程

- 运营：O1 资产列表 → O4 资产详情（发行申请中）→ 关联申请 IA-DEMO-0031 进入 M3b 运营审核详情；O5 上游已撤销确权、O6 已发行且上游已删除（代币 DEMO-TOKEN-001 可前往 M4b 代币台账）。
- 运营 · 企业：E1 企业列表 → E4 企业详情（企业信息、数币账户 3 个、资产）。
