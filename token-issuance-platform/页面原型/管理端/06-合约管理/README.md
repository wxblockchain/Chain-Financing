业务基线为 `PRD/v1.0-合约管理-PRD.md` 及同名流程与验收册（2026-10-30 版，含 `3d581de` 最新停用规则）。视觉沿用组件规范 v1.13（`5f07698`）、`_shared/tokens.css`、`components.css`、`frame.js` 及管理端 M2 的真实壳层。规则、校验与异常分支以 PRD 为准。

## 使用与维护

- 双击 [合约管理.html](合约管理.html)，直接进入“系统管理 / 合约管理”，没有新增登录、首页或角色选择页。右下角“画面目录 · 演示数据”默认关闭。
- 演示数据使用 Demo Contract K / L 与示例地址，不对应已部署合约。固定画面展示名称编辑、启停与结果，不根据输入执行校验、持久化修改或模拟并发。常规主操作跳到固定成功画面；提交中、错误和冲突可从目录查看，提交中画面可通过目录的“主流程下一屏”查看结果。
- 中文与 English 即时切换；合约名称、标准、Ethereum 和地址不随语言改变。输入框可输入，复制取得完整地址，弹窗支持焦点约束、Esc 及取消返回。
- 源文件仅引用 `_shared/` 公共资源，无独立主题、模块 CSS 或第二套运行时。维护源文件，使用已有导出器生成离线单文件附件，生成件不入库：

  ```sh
  python3 _shared/export.py --source 管理端/06-合约管理/合约管理.html --output <仓库外路径>/合约管理.html
  ```

- 仓库联看通过共享导航连接已交付模块；附件仅包含 M6，跨模块入口显示范围提示。导航新增 `adminContracts` 文件与运营路由，保留运营更正邮箱后的展示身份。未生成其他模块页面。

主流程：`ct-list` → `ct-edit` → `ct-renamed`；停用合约改名为 `ct-edit-off` → `ct-renamed-off`。列表的停用 / 启用分别进入 `ct-disable` → `ct-disabled`、`ct-enable` → `ct-enabled`。所有目录画面都有真实目标，维护弹窗取消回发起列表。

列表一次展示六项信息与操作，不加筛选。可用在前，同状态按演示配置先后排序；启停结果重排。标准、类型、网络、地址只读。名称为必填，不自定长度上限或唯一性。确认说明二审可选范围与既有业务影响：停用仅限制新选择，已确定合约的业务继续沿原合约办理，失败仍可手动重试，无需先启用。
