# M6 · 合约管理

运营查看合约列表，编辑合约名称，启用或停用合约。依据 [PRD](../../../PRD/管理端/M6-合约管理/01-合约管理-PRD.md)（`cly-v6.0.0` 的 `e0fc67d`）；**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、地址、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“运营”进入，或直接双击本目录 [`合约管理.html`](合约管理.html)。真实侧栏与账号菜单可跨模块跳转，语言、时区与身份随之传递。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 管理端/M6-合约管理/合约管理.html --output <仓库外路径>.html`，可双击离线打开；跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，按分组列出全部画面，并提供「主流程下一屏」。等待类画面不自动推进。

## 主流程

- 编辑名称：C01 合约列表 → C07 当前名称 → C11 保存中 → C04 名称保存成功；停用合约改名为 C14 → C15 → C16。
- 停用 / 启用：C18 停用确认 → C20 提交中 → C06；C17 启用确认 → C19 → C05。
- 演示合约：Demo Contract K（ERC-3525，启用，0x3525…3525，即 M3b 铸造与 M4a / M4b 代币所属合约）、Demo Contract L（停用）；代币符号 cou。
