# M7 · 消息通知（管理端：运营、机构）

运营管理人员与机构从顶栏消息入口查看未读数和最近消息，进入消息列表按已读状态与分类筛选，打开消息阅读并点编号前往原业务，一次标记当前筛选下的全部未读。组件按本平台[组件规范 §12](../../_shared/design-system/组件规范.md#12-消息通知m7)。依据 [PRD](../../../PRD/两端共用/M7-消息通知/01-消息通知-PRD.md)（`ac4b3ac`）；消息标题与正文取自各来源模块现行 03 消息通知册（M3b、M4b、M5 登录与权限）。**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、账号、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“运营”或“机构”，在任一管理端页面点顶栏铃铛打开最近消息预览；或直接双击本目录 [`消息通知.html`](消息通知.html)。语言、时区与身份随跳转传递，浏览器返回可回到原消息。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 管理端/M7-消息通知/消息通知.html --output <仓库外路径>.html`；前往原业务等跨模块入口显示范围提示。
- 侧栏底部（窄屏为右下角）的「画面目录 · 演示数据」默认关闭，按分组列出全部画面并提供「主流程下一屏」。

## 主流程

- 运营：任一管理端页面点铃铛 → P01 最近消息 → 查看全部消息 → L01 消息列表 → D02「销毁成功知会 · BA-DEMO-0040」（非平台入口，打开即已读，角标 4 → 3）→ 点销毁申请编号进入 M4b 非平台入口销毁记录 → 浏览器返回 → 面包屑回 L12（该条原地变为已读）→ A01 全部已读确认 → A05 处理中 → A07 成功。
- 运营告警：D09「销毁失败知会 · BA-DEMO-0021」进入 M4b 销毁失败记录（只读）；D06 / D07 铸造超时、铸造失败（IA-DEMO-0027）在管理端没有对应记录画面，编号只展示。
- 机构（示例机构 C，资产托管机构）：L21 → R01「代币已销毁，待解除托管 · BA-DEMO-0040」→ 点编号进入 M4b 解除托管详情办理；R03（BA-DEMO-0019）在停用机构示例下进入“机构已停用 · 仍可办理”；R04（BA-DEMO-0018）已解除，只看原记录。

## 实际核验

### UI 视觉深化（2026-11-09，组件规范 v1.66）

本轮为既有系统适配（existing-system adaptation），surface 为桌面控制台，继承 `00e23b4` 的画面与业务语义。没有新增画面；列表与预览改为标题→摘要→分类和编号，时间统一靠右顶对齐。未读以浅主色底、圆点、标题字重和文字标签共同区分，已读弱化底色。详情沿内容区左边线限宽 1040 px，正文 16 px / 1.8，相关业务单独分区，保留完整正文、交易来源、时间、编号与原入口。

| 组件 × 原有画面 | 本轮覆盖 |
| --- | --- |
| 列表 L01–L12、L21、已读结果 A07 | 修改且浏览器实测；含筛选、无结果、空、读取失败与加载更多失败 |
| 预览 P01–P04、P21 | 修改且实测；宽度 440 px、长标题最多两行，消息区独立滚动 |
| 详情 D01–D23、R01–R05、S02 | 修改且实测；消息内容、去向、已读保存失败提示保留 |
| 全部已读确认 / 处理中 / 失败、S01 / S03 | 继承原样，实测布局与键盘回归 |
| 其他模块 | 正文页继承未改；共享最近消息样式同步到 9 个其他模块并实测入口 |

Chromium 对双端原有全部 103 屏（管理 57、企业 46）在中文 / English、320 / 375 / 768 / 1280 / 1440 / 1920 px 共检查 1236 次渲染：无脚本错误、未发现整页或所测控件的横向越界；截图抽看列表、详情、预览、确认与已读结果。双端导出的离线件在中英文检查全部画面（206 次），目录 ID 与源码一致，无 HTTP 请求。

实点 8 条跨模块消息入口，落到对应编号的业务画面；检查消息行键盘焦点 / Enter、预览滚动 / Esc 返回铃铛、确认弹窗 Tab 焦点约束 / Esc 返回、禁用操作说明与时区切换。375 px 宽、667 / 1000 px 高时，页面滚动前后预览都位于顶栏实际底边之下，铃铛与浮层底部入口可点击，评审目录不遮挡入口。详情另检查放大字体后的正文、相关字段（720 CSS px）；这不是全站放大验收。新增浅底上的时间使用 `--muted`，正文、元信息与状态文字按实际表面对比度核对。字体使用既有系统回退，无新增字体请求。

未测 Safari / Firefox、真实移动设备与真实消息服务；送达时效、已读持久化、缓存隔离和权限仍以 PRD 与后续实现验收为准。M5 密码通知措辞仍沿用上游暂稿。
