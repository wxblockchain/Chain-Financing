# M7 · 消息通知（管理端：运营、机构）

运营管理人员与机构从顶栏消息入口查看未读数和最近消息，进入消息列表按已读状态与分类筛选，打开消息阅读并点编号前往原业务，一次标记当前筛选下的全部未读。组件按本平台[组件规范 §12](../../_shared/design-system/组件规范.md#12-消息通知m7)。依据 [PRD](../../../PRD/两端共用/M7-消息通知/01-消息通知-PRD.md)（基线 `3c2c2d2`）；消息标题与正文取自各来源模块现行 03 消息通知册（M3b、M4b、M5 登录与权限；M5 机构管理只发邮件，不进消息中心）。**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、账号、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“运营”或“机构”，在任一管理端页面点顶栏铃铛打开最近消息预览；或直接双击本目录 [`消息通知.html`](消息通知.html)。语言、时区与身份随跳转传递，浏览器返回可回到原消息。审计机构（示例机构 D）从 M4b 的审计机构画面点铃铛进入。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 管理端/M7-消息通知/消息通知.html --output <仓库外路径>.html`；前往原业务等跨模块入口显示范围提示。
- 侧栏底部（窄屏为右下角）的「画面目录 · 演示数据」默认关闭，按分组列出全部画面并提供「主流程下一屏」。

## 主流程

- 运营：任一管理端页面点铃铛 → P01 最近消息 → 查看全部消息 → L01 消息列表 → D02「销毁成功知会 · BA-DEMO-0040」（非平台入口，打开即已读，角标 7 → 6）→ 点销毁申请编号进入 M4b 非平台入口销毁记录 → 浏览器返回 → 面包屑回 L12（该条原地变为已读）→ A01 全部已读确认 → A05 处理中 → A07 成功。
- 审核任务：D09「新发行申请待分配机构 · IA-DEMO-0031」，该申请已分配机构，点编号进入 M3b 申请详情查看当前结果（运营处理中），不再提供分配动作。
- 运营告警：D03「代币单位价值调整超时待处理 · DEMO-TOKEN-001」进入 M4b 代币详情“调价处理中”（l-001-updating）；D10「销毁超时待处理 · DEMO-TOKEN-021」（提交锁满 10 分钟仍无交易标识，以代币编号识别）进入 M4b 代币台账详情（l-021-lock）；D12「销毁超时待处理 · BA-DEMO-0030」进入 M4b 销毁中记录（只读，正文提示联系平台开发）；D13「销毁失败知会 · BA-DEMO-0021」进入 M4b 销毁失败记录；D07 / D08 铸造超时（提示联系开发）、铸造失败（IA-DEMO-0027）在管理端没有对应记录画面，编号只展示。
- 业务提醒：D14「机构追加了发行材料 · DEMO-TOKEN-021」（L14 筛选可见）点代币编号进入 M4b 全平台代币台账该代币详情的补充记录（路由 `ledgerTokenSupplement021`），只读。
- 机构（示例机构 C，资产托管机构）：L21 → R01「代币已销毁，待解除托管 · BA-DEMO-0040」→ 点编号进入 M4b 解除托管详情办理；R03（BA-DEMO-0019）在停用机构示例下进入“机构已停用 · 仍可办理”；R04（BA-DEMO-0018）已解除，只看原记录。
- 审计机构（示例机构 D）：M4b 代币详情点铃铛 → 预览 → X03「代币已销毁 · DEMO-TOKEN-025」；相关业务为代币编号，前往 M4b 本机构代币台账详情。
