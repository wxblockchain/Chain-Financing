# M7 · 消息通知（管理端：运营、监管机构）

运营管理人员与监管机构从顶栏消息入口查看未读数和最近消息，进入消息列表按已读状态与分类筛选，打开消息阅读并点编号前往原业务，一次标记当前筛选下的全部未读。版式参考借贷平台运营端消息通知，组件按本平台[组件规范 §12](../../_shared/design-system/组件规范.md#12-消息通知m7)。依据 [PRD](../../../PRD/两端共用/M7-消息通知/01-消息通知-PRD.md)（`9fca0c6`）；消息标题与正文取自各来源模块的 03 消息通知册。**规则、校验与异常分支以 PRD 为准**。画面中的企业、机构、账号、编号、金额均为演示数据。

## 打开方式

- 仓库联看：完整同步 `页面原型/` 后双击 [`index.html`](../../index.html) 选择“运营”或“监管机构”，在任一管理端页面点顶栏铃铛打开最近消息预览；或直接双击本目录 [`消息通知.html`](消息通知.html)。语言、时区与身份随跳转传递，浏览器返回可回到原消息。
- 单模块附件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 管理端/M7-消息通知/消息通知.html --output <仓库外路径>.html`；前往原业务等跨模块入口显示范围提示。
- 右下角「画面目录 · 演示数据」默认关闭，按分组列出全部画面并提供「主流程下一屏」。

## 主流程

- 运营：任一管理端页面点铃铛 → P01 最近消息 → 查看全部消息 → L01 消息列表 → D03「有发行申请待二审 · IA-DEMO-0031」（打开即已读，角标 4 → 3）→ 点申请编号进入 M3b 待运营审核详情 → 浏览器返回 → 面包屑回 L12（该条原地变为已读）→ A01 全部已读确认 → A05 处理中 → A07 成功。
- 原动作已办完：D05「新的销毁申请 · BA-DEMO-0031」点编号进入 M4b 待解除监管详情，只能查看当前结果。
- 监管机构：L21 → R01「代币已销毁，待解除监管 · BA-DEMO-0031」→ 点编号进入 M4b 解除监管详情办理；停用机构（目录切换为停用示例）进入“机构已停用 · 仍可解除”。R04 一审申请 IA-DEMO-0031 已审，进入 M3b 查看当前进度。
