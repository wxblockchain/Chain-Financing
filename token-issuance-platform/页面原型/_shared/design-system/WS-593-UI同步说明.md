# WS-593 · 原型 3b3eb0e 的 UI 同步

2026-11-10｜existing-system adaptation / console｜组件规范 v1.78

基于 `cly-v6.0.0` 的原型 `3b3eb0e`、PRD `48e5924`，沿用浅色控制台、现有字体与组件、英文优先和双语切换。本轮调整视觉呈现，保留 755 个画面、原有业务文字、字段、数值、身份、状态、禁用条件与路由。

## 核验与运行

- Chromium，源码通过本地 `file://` 运行。11 个模块中英文各遍历 755 屏，检查脚本错误、整页横向溢出、字段/表头长标签和画面跳转目标。选中列的屏幕阅读器隐藏名称不计作可见文字裁切。
- 对直接修改的 26 屏及相关只读材料、价值核对画面，补充 375 / 768 / 1280 / 1440 px 与 1280 × 600 短视口核验，共 350 次中英文布局检查，无脚本错误、整页横向溢出或所查字段/表头裁切。小宽度只验证既有布局，不代表新增移动端产品流程。
- 对照基线逐项检查修改页面的正文、画面属性、表单默认值、按钮/链接/时间与跳转属性，均保持原合同。浏览器另测申请表键盘滚动、材料追加入口至只读结果、上传中/失败/已销毁的禁用反馈、弹窗 Tab/Escape 与焦点返回，以及窄台账固定操作列和完整值浮层。
- 评审附件从实际源层通过 `_shared/export.py` 生成；单文件 HTML 双击打开，通过画面目录核对本模块。跨模块入口需完整解压联看包后双击 `页面原型/index.html`，与仓库原打开方式一致。单模块附件不展开其他模块。
- 四份单模块 HTML（M2 企业/管理端、M4a、M4b）中英文离线各遍历共 217 屏，即 434 次画面检查，无外部请求、脚本错误或整页横向溢出。仓库联看实点 M2 已发行资产 → `l-001`、M3b 铸造结果 → `l-027`、M3a 铸造结果 → `t-future`，均到达原型登记的对应代币详情。

未验证 Safari、Firefox、触屏设备、真实上传、真实接口或生产权限。本轮没有变更上游待定项：M3a“已发行”提交失败仍未单独出屏；上传人仍不展示；不另增 0.8 USD 样本。原型已有的调价示例保留原值，未跨模块改算资产价值。
