# M2 可信资产 · UI 设计说明

2026-11-06｜existing-system adaptation / console｜组件规范 v1.52

## 基线与视觉方向

基于 Hallmark 最新 M2 原型 `432cdd1`，业务依据 PRD `9c13023`，沿用已确认的英文优先、蓝色主操作、浅色控制台与上下排列只读字段。两端 37 屏的身份、业务值、状态、入口及演示数据保持原合同；不扩展发行流程。

本次让列宽服务英文内容，让交易双方可并排对照，并区分数据质量提示与业务状态。既有品牌、字体栈、摘要、无边框分区导航、分页、主操作及空 / 异常画面继续使用。

## 组件与布局

| 对象 | 本次设计 |
| --- | --- |
| 四处资产列表 | 编号、数值、时间、状态与操作使用确定的阅读空间，名称分配余量；容器 ≥1100 px 时加宽，长英文状态单行。企业详情内资产使用只读操作列，避免留出多操作空白 |
| 企业列表 | 单独分配名称、登记标识、地址和认证列；表头按词换行，名称和地址保留完整核对方式 |
| 双名称 | 固定名称在前、英文名称在后；13 / 12 px 层级，只改变标签语言，不改变值或顺序；缺失不补写 |
| 交易双方 | 详情容器 ≥900 px 时左右并排，低于此宽度纵向排列；名称在各自分区跨行，国家与登记标识成对。此变体不改变其他只读字段的两列 / 三列规则 |
| 运营金额预警 | 既有标记改为警告图标加文字，避免与业务状态底色标签混淆；仍为非阻断提示，仅运营可见 |
| 窄表与键盘 | 最小表宽 960 px，表内滚动，操作列固定在右；M2 资产和企业表格滚动区提供区域名称和键盘入口 |

权威样式在 `tokens.css`、`components.css`，交易双方结构由 `asset-detail.js` 生成；两端不复制私有样式。精确尺寸与可变规则见 [组件规范 §4.14](组件规范.md#414-资产信息m2-起)。M3a 的共享资产引用继承双方对照组件；未改其他模块的业务源页、规则或流程。

## 实际核验

- Chromium headless，`file://`，中英文；37 屏 × 375 / 768 / 1280 / 1440 / 1920 px 共 370 次布局检查。无脚本错误、整页横向溢出或表格单元格裁切；1280 px 起 M2 资产和企业列表无需横向滚动。
- 浏览器中逐项对比修改前后的上游值、只读字段、金额、时间、状态与链接目标，一致；没有重新计算金额或状态。
- 画面目录逐项点击；22 个已有资产编号入口与同行“查看”目标一致。六个既有跨模块入口到达对应填写页、申请详情或代币详情。
- 实测更多筛选展开与 Esc 焦点返回、Enter 核对完整名称、键盘横向滚表、固定操作列及详情锚点滚动和焦点；900 px 交易双方断点两侧核验通过。
- 共享消费者中英文 × 1280 / 1440 / 1920 px 共 102 次代表画面检查，无脚本错误或整页横向溢出。
- 本次英文名称副文字对白底对比度 7.53:1，运营预警文字 5.43:1；沿用的主色焦点对白底 6.70:1。使用项目系统字体栈，无新增在线字体或图片依赖。
- 单文件评审件与联看 ZIP 从维护源生成；离线核验不请求外部网络，单文件不展开跨模块页面。内部截图不作为附件交付。

## 打开与边界

单文件 HTML 可以离线双击查看本端 M2 的全部画面，右下角目录默认关闭。需要核对申请、代币详情等跨模块入口时，完整解压联看 ZIP，按包内打开说明进入 M2。界面首次默认英文，已保存的浏览器语言偏好仍有效；顶栏可切换中文。

未验证 Safari / Firefox、触屏设备、真实接口、实际权限、查询 / 分页或申请提交能力。小宽度仅为布局回归，不表示新增移动端流程。既有未出屏项与外部记录画面缺口见两端 README；本轮没有补造这些画面。其他模块在联看包中按现状继承。
