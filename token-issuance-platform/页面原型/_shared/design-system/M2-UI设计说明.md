## 业务口径核对

- 回款筛选只有未到期 / 已逾期 / 已结清；发行筛选只有可发行 / 发行申请中 / 已发行，均含“全部”。M2 不再出现无法确认 / 获取状态。
- 驳回后资产回到可发行；企业看 M3a 企业状态，运营 / 机构看 M3b 对应申请状态；没有新增下游处理逻辑。
- D11 从 C1 RA-DEMO-0166 进入，仍显示可发行，但回款为已逾期并解释不能申请，不进入申请填写。
- R7 仅关联被驳回申请时没有代币编号；R8 属于已发行申请名单时有代币入口。机构不显示运营金额预警，不提供申请处理动作。
- 浏览器比对全部 M2 画面的金额、完整值、时间、状态、表单默认值与修改前一致。入口变化为上述两项明确修复，其他路径沿用。

## 实测与限制

Chromium headless、`file://`、reduced motion：41 屏 × 中文 / English × 375 / 768 / 1280 / 1440 / 1920 / 2560 px，共 492 次布局检查；M3a 共享引用另有 90 次。无脚本错误、整页横向溢出或表格单元格裁切；小宽度只作布局回归，不代表新增移动业务流程。

逐项点击 41 个画面目录入口。全部 15 个实际跨模块入口检查到达页面及原编号匹配；0097 / 0171 范围提示和 D11 分支实测通过。完整值浮层中的 12,345.675 USD 可核对、位于视口内并可按 Esc 收起。截图仅用于内部核验，不附加展示外壳。

两份离线单文件从维护源生成，支持双击查看本端 M2；完整联看需解压 ZIP 保留目录结构。原型使用演示数据，没有查询、分页、状态计算或业务提交模拟。

真实剩余缺口见两端 README：0097 / 0171 的填写画面、部分外部申请详情、曾逾期后结清、无效到期范围及机构列表特定空 / 失败画面。范围缺口没有用其他对象页面替代。Safari / Firefox、触屏、真实接口、身份权限与提交能力未验证；本轮不替代产品 Eval 或后端验收。
