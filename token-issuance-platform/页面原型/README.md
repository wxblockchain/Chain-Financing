## 打开与导出

- 完整同步 `页面原型/` 后双击任一模块 HTML，在现有侧栏或账号菜单内切换已交付模块，同一标签页打开，无需启动服务。面客端 M1↔M2；管理端 M2↔M5（运营的可信资产、企业、监管机构管理与本人账户；监管的关联资产与本人账户）。右下角「画面目录 · 演示数据」默认关闭，只列当前模块画面。
- 企业认证受限时仍展示受限画面；运营和监管不会因跨模块跳转切换角色。语言与展示时区随跳转保留。未交付模块继续显示范围提示。
- 生成单文件评审件（不入库）：

  ```
  python3 _shared/export.py --source 面客端/01-企业登录与企业账户/企业登录与企业账户.html --output <仓库外路径>.html
  ```

导出件仍是单模块离线附件，只内联该模块必要资源，不包括 `navigation.js` 或其他模块画面；从 issue 打开时跨模块入口显示范围提示。源码与附件由明确模式区分，不按 `file://` 猜测。新模块接入与体积要求见 [组件规范 §5.1](_shared/design-system/组件规范.md#51-仓库联看与单模块附件)。

配色与控件尺寸以借贷平台运营端为基线；M1 已按最新 PRD 更新：L1 / L3 / L4 三屏登录、企业账户列表、删除结果、语言与时区偏好；支持中英文即时预览及浏览器语言记忆。游客引导与离开确认统一在平台内容区展示。平台内容区随窗口展开，桌面两侧各保留 24 px 边距，减少宽屏留白。组件规范为 v1.12（保留 M2 资产信息组件与管理端骨架）。实际覆盖与核验见 [M1 UI 设计说明](面客端/01-企业登录与企业账户/UI设计说明.md)。

M2 可信资产分面客端、管理端两个文件，见 [M2 UI 设计说明](面客端/02-可信资产/UI设计说明.md)。

M5 按用户“直接输出页面原型，并入库”合并阶段，复用组件规范 v1.11（继承 v1.10，增补账号/附件组件）。从共用登录入口打开；正常登录示例进入账户设置，角色差异与空态、异常在默认关闭的画面目录中查看。范围、画面清单与实际核验见 [M5 README](管理端/01-管理端登录与权限/README.md)。规则、校验与异常分支以 PRD 为准，未实现真实登录、发信或上传。
