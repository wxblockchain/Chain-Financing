# 代币发行平台 · 页面原型

原型只说明页面布局和展示的信息；规则、校验与异常分支以 [PRD](../PRD/README.md) 为准。画面中的企业、机构、地址、邮箱、编号、金额均为演示数据。

## 打开

完整同步 `页面原型/` 后双击 [`index.html`](index.html)，选择端与身份进入（企业端：未登录 / 已认证企业 / 未认证企业；管理端：未登录 / 运营 / 监管机构），无需启动服务。

- 进入后用真实侧栏和账号菜单在已交付模块间切换，同一标签页打开，支持刷新与浏览器返回。
- 右下角「画面目录 · 演示数据」默认关闭；展开后顶部可切换企业端 / 管理端及身份，下方列出当前模块的全部画面和「主流程下一屏」。
- 跨模块时保留当前身份、语言与展示时区；停用机构、改邮箱等展示变体沿用同一角色。
- 顶栏消息入口在每个模块都可展开最近消息预览，单条消息与“查看全部消息”进入 M7 消息通知。

## 目录约定

```
页面原型/
├─ index.html                 仓库联看入口（评审工具）
├─ _shared/                   公共层，见下表
├─ 面客端/<模块号>-<模块名>/   企业端模块：<模块名>.html、route.js、README.md
└─ 管理端/<模块号>-<模块名>/   管理端模块（运营、机构），结构同上
```

- 目录以 PRD 模块号开头（M1、M2、M3a、M3b、M4a…）。同一模块两端都有画面时，两端各一个目录且模块号相同。
- 每个模块只维护自己的 HTML、`route.js` 与 README，不复制壳层、菜单、token 或 CSS，也不写行内样式。
- **新增模块**：建目录 → 写模块 HTML（引用 `../../_shared/`）→ 写 `route.js` 登记菜单 / 操作 key 对应的各身份落地画面 → 在 `_shared/modules.js` 追加一行 → 在上方模块表追加一行。不需要修改其他模块或 `navigation.js`。细则见[组件规范 §5.1](_shared/design-system/组件规范.md#51-仓库联看与单模块附件)。

| 公共层文件 | 作用 |
| --- | --- |
| `tokens.css`、`components.css` | 唯一 token 与公共组件 |
| `frame.js`、`display.js`、`asset-icons.js` | 壳层与画面目录、中英文与时区展示、网络与币种图标 |
| `menu.client.js`、`menu.admin.js` | 企业端菜单、管理端（运营 / 监管）菜单，全仓各一份 |
| `asset-detail.js`、`asset-filters.js` | 可信资产详情与筛选的共享画面，以及详情分区导航 |
| `inbox.js`、`inbox-pages.js` | 顶栏消息入口与最近消息预览、三类身份的演示消息（所有模块加载）；M7 列表与逐条详情的生成（只被 M7 引用） |
| `navigation.js`、`modules.js` | 仅仓库联看：读取模块清单与各模块 `route.js`，跨模块跳转及端与身份切换；导出附件时排除 |
| `export.py` | 生成单模块离线附件 |
| [`design-system/组件规范.md`](_shared/design-system/组件规范.md) | 组件规范与原型轻量化约定 |

配色与控件尺寸以借贷平台运营端为基线，详见组件规范 §1。

## 导出单模块附件

在 `页面原型/` 下执行（生成件不入库）：

```
python3 _shared/export.py --source <端>/<模块目录>/<模块名>.html --output <仓库外路径>.html
```

附件只内联该模块必要资源，不包括 `navigation.js`、`modules.js`、各模块 `route.js` 或其他模块画面，可在 issue 中直接双击离线打开。跨模块入口显示“此入口在单模块附件中不展开”的范围提示，画面目录提示到仓库中打开 `index.html` 切换端与身份。源码与附件由明确模式区分，不按 `file://` 猜测。
