# 代币发行平台 · 页面原型

本目录存放代币发行平台的页面原型。原型底座与本平台自持的设计规范在 `_shared/` 之下（`tokens.css` / `base.css` / `shell.js` / 页面登记表 / `export.py` / `design-system/`），与模块原型同处本目录，不另开第三个子目录。当前尚未落库，仅有本 README 占位。

参考原型请到 **`cly-V1.0.0`** 分支的 `financial-service-platform/prototypes/` 读取，原型底座见同分支 `asset-platform/prototypes/_shared/`，组件与设计规范见 `docs/design-system/`（与资产可信平台一致，可一并参考 `asset-platform/prototypes/`）。逐模块的参考路径见 WS-345。
