## 打开与导出

- 在完整的 `页面原型/` 目录下双击模块 HTML 即可打开；右下角「画面目录 · 演示数据」列出全部画面。
- 生成单文件评审件（不入库）：

  ```
  python3 _shared/export.py --source 面客端/01-企业登录与企业账户/企业登录与企业账户.html --output <仓库外路径>.html
  ```

配色与控件尺寸以借贷平台运营端为基线；M1 已按最新 PRD 更新：L1 / L3 / L4 三屏登录、企业账户列表、删除结果、语言与时区偏好；支持中英文即时预览及浏览器语言记忆。组件规范为 v1.4（补入 M2 资产信息组件与管理端骨架）。实际覆盖与核验见 [M1 UI 设计说明](面客端/01-企业登录与企业账户/UI设计说明.md)。

M2 可信资产分面客端、管理端两个文件，见 [M2 UI 设计说明](面客端/02-可信资产/UI设计说明.md)。
