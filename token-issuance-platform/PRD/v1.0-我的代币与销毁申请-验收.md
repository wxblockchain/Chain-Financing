# 我的代币与销毁申请 · 验收

2026-10-30｜需求评审稿｜供测试使用

本册只列验收标准，测试用例与执行步骤由测试小队编写。以[01 功能与业务规则](./v1.0-我的代币与销毁申请-PRD.md)和本册验收，原型仅用于核对布局。

共 32 条验收，编号 AC-M4A-01～32。每条名称放在前提中，表格只有前提、操作、预期结果三列；一条含多个场景时，所有场景都满足才算通过。标注待验的分支不能据模拟数据判通过，其他分支仍可独立验收。

## 0. 验收前准备

- 账号：企业 A、企业 B 的已认证用户；未认证企业用户、游客、未登录身份；同一企业变更前后的登录地址；两个运营账号及原监管机构、其他监管机构。
- 代币：成功铸造、铸造尚未成功、已销毁；原地址顺延普通账户；账户备注名或合约名称变化；合约停用。已铸造样本包含两位小数数量、完整地址、关联资产及发行申请。
- 资格：未到期但已结清、恰好到期且已结清、已到期未结清、逾期后结清；下游与链上无质押、有质押、相互不一致、任一或两项未知；身份或结清依据获取失败。
- 申请：无记录、待审、驳回、销毁中、销毁失败及运营重试、销毁成功、等待解除监管、解除完成；同一代币有多次驳回及一笔新申请；提交结果未确认、读取失败、越权和不存在对象。
- 消息：同一提交重复送达、已读后重取、驳回后新提交；中英文和不同时区。
- 配套依据：M4b [两端衔接字段清单](./v1.0-销毁审核与解除质押-PRD.md#handoff)；停用合约分支须闭合[停用合约依赖（Q-M4A-02）](./v1.0-我的代币与销毁申请-PRD.md#Q-M4A-02)。
