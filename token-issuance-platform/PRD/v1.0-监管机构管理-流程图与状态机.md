## 邀请添加监管机构（图 1）

```mermaid
flowchart TD
    A[运营管理人员邀请添加监管机构] --> B[填写核心资料、登录邮箱、初始密码]
    B --> C{各项符合规则?<br/>名称不重名，邮箱在管理端唯一}
    C -->|否| C1[指出哪一项、什么原因<br/>已填内容保留]
    C1 --> B
    C -->|是| D{提交成功?}
    D -->|否| D1[不建立机构和账号，不发邮件<br/>说明原因，可修改后重试]
    D -->|是| E[新增监管机构：机构状态为启用，进入企业可选范围<br/>建立账号：待首登改密]
    E --> F[向登录邮箱发送邀请邮件]
    F --> G{邮件服务是否受理}
    G -->|已发出| G1[说明邀请邮件已发出]
    G -->|发送失败| G2[说明未能发出，请线下告知登录邮箱和初始密码<br/>机构和账号不回滚]
    G1 --> H[监管机构用登录邮箱和初始密码登录<br/>先完成首次登录强制改密]
    G2 --> H
    H --> I[账号状态变为正常]
```

## 停用与启用（图 2）

```mermaid
flowchart TD
    A[运营管理人员在机构详情中操作] --> B{当前机构状态}
    B -->|启用| C[确认停用：说明企业不能再选择<br/>该机构仍可登录，在途业务照常办理]
    B -->|停用| D[确认启用：说明重新出现在企业可选范围]
    C -->|取消| Z[机构状态不变]
    D -->|取消| Z
    C -->|确认| E{提交时状态仍为启用且保存成功?}
    D -->|确认| F{提交时状态仍为停用且保存成功?}
    E -->|状态已被他人改变| Y[不重复执行，展示最新状态]
    F -->|状态已被他人改变| Y
    E -->|失败| X[状态保持原样，可重试]
    F -->|失败| X
    E -->|成功| G[机构状态：停用]
    G --> G1[新业务：企业不能再选择<br/>未提交的申请提交时须重新选择]
    G --> G2[在途业务：待监管审核的申请仍由该机构审核<br/>本机构铸造的代币销毁后仍由该机构解除质押<br/>相关消息照常发给该机构]
    G --> G3[账号：状态不变，仍可登录，数据范围不变]
    F -->|成功| H[机构状态：启用<br/>重新进入企业可选范围]
```

## 运营更正邮箱（图 4）

```mermaid
flowchart TD
    A[运营在原机构中更正登录邮箱] --> B[填写新邮箱与新初始密码]
    B --> C{校验通过且邮箱有变化}
    C -->|否| D[不替换账号或发邮件<br/>说明原因或无需修改]
    C -->|是| E[确认原账号作废及全部旧登录结束]
    E -->|取消| D
    E -->|确认| F{当前信息未变化且保存成功}
    F -->|否| G[保持原账号与机构资料<br/>信息已变化时重新确认]
    F -->|是| H[旧邮箱和旧密码作废<br/>旧登录与未用验证码失效<br/>新邮箱为唯一有效账号且待首登改密]
    H --> I[机构与历史业务及消息保留<br/>原有锁定不提前解除]
    I --> J{向新邮箱发开通邮件}
    J -->|已发出| K[机构使用新邮箱和初始密码首登改密]
    J -->|发送失败| L[替换照常生效<br/>运营线下告知新凭据]
    L --> K
```

监管机构本人找回密码与自行改邮箱分别见[找回密码（图 4）](./v1.0-管理端登录与权限-流程图与状态机.md#fig-4)与[本人改邮箱（图 5）](./v1.0-管理端登录与权限-流程图与状态机.md#fig-5)。

<a id="state-1"></a>
## 监管机构状态机

```mermaid
stateDiagram-v2
    state "启用" as ON
    state "停用" as OFF
    [*] --> ON: 运营邀请添加成功
    ON --> OFF: 运营确认停用
    OFF --> ON: 运营确认启用
```

- 初始状态是启用；没有终态，本期不能删除监管机构。
- 只有启用的机构能被企业选择发起新的发行申请；两种状态下账号都可以登录，已有的在途业务都照常办理。
- 编辑核心资料、邮箱修改与本人找回密码都不改变机构状态。
