## 邀请添加监管机构（图 1）

```mermaid
flowchart TD
    A[运营管理人员邀请添加监管机构] --> B[填写机构名称、登录邮箱、初始密码]
    B --> C{各项符合规则?<br/>名称不重名，邮箱在管理端唯一}
    C -->|否| C1[指出哪一项、什么原因<br/>已填内容保留]
    C1 --> B
    C -->|是| D{提交成功?}
    D -->|否| D1[不建立机构和账号，不发邮件<br/>说明原因，可修改后重试]
    D -->|是| E[新增监管机构：机构状态为启用，进入企业可选范围<br/>建立账号：待首登改密]
    E --> F[向登录邮箱发送邀请邮件]
    F --> G{邮件服务是否受理}
    G -->|已发出| G1[说明邀请邮件已发出]
    G -->|发送失败| G2[说明未能发出，请线下告知登录邮箱和初始密码<br/>机构和账号不回滚]
    G1 --> H[监管机构用登录邮箱和初始密码登录<br/>先完成首次登录强制改密]
    G2 --> H
    H --> I[账号状态变为正常]
```

## 停用与启用（图 2）

```mermaid
flowchart TD
    A[运营管理人员在机构详情中操作] --> B{当前机构状态}
    B -->|启用| C[确认停用：说明企业不能再选择<br/>该机构仍可登录，在途业务照常办理]
    B -->|停用| D[确认启用：说明重新出现在企业可选范围]
    C -->|取消| Z[机构状态不变]
    D -->|取消| Z
    C -->|确认| E{提交时状态仍为启用且保存成功?}
    D -->|确认| F{提交时状态仍为停用且保存成功?}
    E -->|状态已被他人改变| Y[不重复执行，展示最新状态]
    F -->|状态已被他人改变| Y
    E -->|失败| X[状态保持原样，可重试]
    F -->|失败| X
    E -->|成功| G[机构状态：停用]
    G --> G1[新业务：企业不能再选择<br/>未提交的申请提交时须重新选择]
    G --> G2[在途业务：待监管审核的申请仍由该机构审核<br/>本机构铸造的代币销毁后仍由该机构解除质押<br/>相关消息照常发给该机构]
    G --> G3[账号：状态不变，仍可登录，数据范围不变]
    F -->|成功| H[机构状态：启用<br/>重新进入企业可选范围]
```

## 重置密码（图 3）

```mermaid
flowchart TD
    A[运营管理人员为监管机构重置密码] --> B[填写新的初始密码]
    B --> C{符合密码规则<br/>且与当前密码不同?}
    C -->|否| C1[说明原因，原密码不变]
    C1 --> B
    C -->|是| D[确认：说明该机构登录全部结束<br/>须用新的初始密码登录并再次改密<br/>平台不发邮件，请线下告知]
    D -->|取消| D1[原密码不变]
    D -->|确认| E{保存成功?}
    E -->|否| E1[原密码不变，可重试]
    E -->|是| F[旧密码失效，新的初始密码生效<br/>账号变为待首登改密<br/>该机构所有设备上的登录立即结束]
    F --> G{账号锁定中?}
    G -->|是| G1[锁定不提前解除<br/>到期后才能用新的初始密码登录]
    G -->|否| H[监管机构用新的初始密码登录<br/>先完成首次登录强制改密]
    G1 --> H
```

<a id="state-1"></a>
## 监管机构状态机

```mermaid
stateDiagram-v2
    state "启用" as ON
    state "停用" as OFF
    [*] --> ON: 运营邀请添加成功
    ON --> OFF: 运营确认停用
    OFF --> ON: 运营确认启用
```

- 初始状态是启用；没有终态，本期不能删除监管机构。
- 只有启用的机构能被企业选择发起新的发行申请；两种状态下账号都可以登录，已有的在途业务都照常办理。
- 编辑机构信息、重置密码都不改变机构状态。
