# 管理端登录与权限 · 验收

2026-10-30｜需求评审稿｜供测试使用

本册只写验收标准，测试用例与执行步骤由测试小队编写。规则见[功能与业务规则](./v1.0-管理端登录与权限-PRD.md)，各节顺序与功能册一致。

怎么读：

- 编号沿用原值，缺号不代表遗漏；运营代重置场景删除，新增本人找回与改邮箱场景。
- 一条验收写了多个场景时，全部场景都满足才算通过。
- 涉及其他业务模块菜单内数据的场景（[菜单权限矩阵、数据范围与无权访问](#AC-LG-32)），在对应模块上线前只核对菜单可见性与直接访问的拒绝结果；各菜单内的数据筛选随对应模块验收。

## 0. 验收前准备

账号：

- 运营账号甲、乙：开发人员已分配，均已完成首次改密；运营账号丙：开发人员刚分配，处于待首登改密。
- 监管机构 X、Y 各一个账号，均已完成首次改密；监管机构 Z 刚被邀请添加，账号处于待首登改密。
- 已停用的监管机构 W 一个账号，W 有一笔待监管审核的发行申请。
- 一个不是管理端账号的邮箱；一个面客端可登录的以太坊钱包地址。

数据：

- 发行申请：企业选择 X 的、选择 Y 的各至少一笔；由 X、Y 各自铸造的代币各至少一个。
- 一条发给监管机构 X 的消息链接；一条发给全体运营的消息链接。
- 密码样本：7 位、8 位、20 位、21 位；只有字母、只有数字；中间含空格；前后带空格；与当前密码相同；与初始密码相同。
- 邮箱写法样本：同一登录邮箱的全大写、大小写混合、前后带空格三种写法。
- 验证码：正确、错误、已使用、作废、过期、用途或目标邮箱不符的样本，及同用途重发；位数、时效、发送限额与错误次数的边界依赖 Q-LG-01。
- 邮箱：可收信新邮箱、已被运营或其他机构占用邮箱、已作废旧邮箱；本人改邮箱与运营更正同时进行的数据。
- 环境：可模拟网络或服务异常、语言或时区保存失败；可调整时间以验证 4 小时有效期、30 分钟无操作和锁定时长；浏览器时区可设置，也可模拟推断失败。
