<a id="fig-1"></a>
## 可信资产的来源与进入本平台（图 1）

```mermaid
flowchart TD
    A[下游企业向本企业下单购买新车] --> B[本企业向厂商采购<br/>车辆海运直发下游指定仓库]
    B --> C[车辆交付<br/>本企业形成对下游企业的应收账款]
    C --> D{下游企业在上游平台确权}
    D -->|未确权| E[不进入本平台<br/>任何角色都看不到]
    D -->|已确权| F[同步进入本平台<br/>确权状态：已确权<br/>发行状态：可发行]
    F --> G{L1 通用必传信息是否完整}
    G -->|完整| H[可查看<br/>满足其他条件时可发起申请]
    G -->|有缺失| I[可查看，缺失项标明上游未提供<br/>不能发起申请]
    F --> J{之后上游撤销确权或删除资产}
    J -->|是| K[只在运营端提示<br/>不自动改变任何状态]
```

<a id="fig-2"></a>
## 发行状态（图 2）

初始状态为“可发行”；“已驳回”和“代币已销毁”是终态。铸造中、铸造失败待重试期间保持“发行申请中”；销毁申请审核中、被驳回、销毁中、销毁失败待重试期间保持“已铸造”。

```mermaid
stateDiagram-v2
    state "可发行" as S1
    state "发行申请中" as S2
    state "已驳回" as S3
    state "已铸造" as S4
    state "代币已销毁" as S5

    [*] --> S1: 已确权应收账款同步进入本平台
    S1 --> S2: 企业提交发行申请成功（M3a）
    S2 --> S3: 监管一审驳回或运营二审驳回（M3b）
    S2 --> S4: 铸造成功（M3b）
    S4 --> S5: 代币销毁成功（M4b）
    S3 --> [*]
    S5 --> [*]
```

## 监管状态与融资状态（图 3）

监管状态在铸造成功后才出现；融资状态只在发行状态为“已铸造”时展示，由下游借贷平台提供。监管状态的口径见[监管状态的口径（Q-AS-09）](./v1.0-可信资产-PRD.md#Q-AS-09)。

```mermaid
stateDiagram-v2
    state "监管中（所选监管机构）" as R1
    state "已解除监管" as R2
    [*] --> R1: 铸造成功（M3b）
    R1 --> R2: 代币销毁后，监管机构在平台上解除监管并留存记录（M4b）
    R2 --> [*]
```

```mermaid
stateDiagram-v2
    state "未融资" as F1
    state "融资中" as F2
    [*] --> F1: 铸造成功
    F1 --> F2: 下游借贷平台提供：代币在融资中
    F2 --> F1: 下游借贷平台提供：融资已结束
    F1 --> [*]: 代币销毁后不再展示
```

## 确权、结清与逾期状态（图 4）

三个状态都由上游平台提供，与发行、监管、融资状态互不推动。到期的时点见[到期的时点（Q-AS-08）](./v1.0-可信资产-PRD.md#Q-AS-08)。

```mermaid
stateDiagram-v2
    state "已确权" as C1
    state "已撤销确权（仅运营端提示）" as C2
    [*] --> C1: 进入本平台
    C1 --> C2: 上游撤销确权
```

```mermaid
stateDiagram-v2
    state "未结清" as P1
    state "已结清" as P2
    [*] --> P1
    [*] --> P2: 进入本平台时已结清
    P1 --> P2: 上游提供已结清
    P2 --> [*]
```

```mermaid
flowchart TD
    A[逾期状态：未逾期] --> B{上游提供已逾期}
    B -->|是| D[逾期状态：已逾期]
    B -->|否| C{到达到期日时<br/>是否仍为未结清且未逾期}
    C -->|是，未取得上游最新状态| D
    C -->|否，已结清| E[保持未逾期]
    D --> F[之后以上游提供的状态为准]
```

<a id="fig-5"></a>
## 从可信资产发起发行申请（图 5）

```mermaid
flowchart TD
    A[已认证的企业用户查看本企业资产] --> B{发行状态为可发行}
    B -->|否| X[不提供发起<br/>说明：申请处理中 / 已驳回 / 已铸造或代币已销毁]
    B -->|是| C{确权状态为已确权}
    C -->|否| Y[不提供发起<br/>说明债权人确权已撤销]
    C -->|是| D{未到期<br/>未结清、未逾期且未到达到期日}
    D -->|否| Z[不提供发起<br/>说明已逾期 / 已结清 / 已到达到期日]
    D -->|是| E{币种为 USD 且 L1 完整<br/>各状态均已取得}
    E -->|否| W[不提供发起<br/>说明仅支持美元计价 / 信息不完整 / 暂时无法确认状态]
    E -->|是| F[展示债权人已确权<br/>企业发起申请，进入代币发行·企业申请并带入资产]
    F --> G{企业是否提交}
    G -->|未提交就离开| H[资产保持可发行]
    G -->|提交| I{提交时按最新信息重新判断}
    I -->|不满足| J[不能提交，说明原因<br/>不产生第二笔申请]
    I -->|满足| K[提交成功<br/>发行状态变为发行申请中]
```

<a id="fig-6"></a>
## 各角色的查看范围（图 6）

```mermaid
flowchart TD
    A[访问可信资产或企业信息] --> B{访问者身份}
    B -->|游客| G[看不到可信资产<br/>按游客引导处理]
    B -->|未认证的企业用户| U[看得到入口，看不到资产数据<br/>按认证引导处理]
    B -->|已认证的企业用户| C{资产的债权人是本企业}
    C -->|是| C1[可查看列表与详情<br/>可从满足条件的资产发起申请]
    C -->|否| N[无权查看或资产不存在<br/>不返回任何信息]
    B -->|监管机构| D{资产被本机构的发行申请使用}
    D -->|是| D1[可查看资产详情与本机构的这笔申请<br/>看不到企业信息、数币账户和上游变更提示]
    D -->|否| N
    B -->|运营管理人员| E[可查看全平台企业、资产、数币账户<br/>和上游变更提示，全部只读]
```
