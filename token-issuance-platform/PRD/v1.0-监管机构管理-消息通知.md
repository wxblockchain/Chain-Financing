本册逐项写明本模块发出的每类消息。本模块只发 1 类邮件，不发站内消息。必发，运营与监管机构都不能关闭。邮件不进入消息中心，不设分类【确认】（BR-24，见[消息通知 · 接入字段](./v1.0-消息通知-PRD.md#intake-fields)）。

| 消息 | 渠道 | 触发功能 |
| --- | --- | --- |
| [监管机构邀请邮件（NT-R03）](#NT-R03) | 邮件 | [邀请添加监管机构（F-RG-02）](./v1.0-监管机构管理-PRD.md#F-RG-02) |

## 监管机构邀请邮件（NT-R03）

依据：邀请时发邮件、首次登录强制改密【确认】（BR-04）；监管邀请走邮件【确认】（BR-24）；邮件包含登录邮箱和初始密码，首次登录强制改密降低风险【确认】；邮件发送失败可以线下自己发送【确认】。

**识别与归属**

| 项目 | 规则 |
| --- | --- |
| 消息名称与事件编号 | 监管机构邀请邮件（NT-R03） |
| 发送来源 | 监管机构管理；其他模块不发同义邮件 |
| 渠道 | 邮件，不发站内消息，不进入消息中心 |
| 收件人 | 运营在邀请时为该监管机构分配的登录邮箱。不抄送运营，也不发给其他监管机构 |

**触发与同一事实**

| 项目 | 规则 |
| --- | --- |
| 触发 | 运营邀请添加监管机构成功，机构与账号已建立时发送一封 |
| 不触发 | 邀请未提交成功；编辑监管机构信息；停用、启用；重置密码 |
| 同一事实的区分依据 | 一家监管机构的一次邀请只发一封；重复提交、刷新都不再发送。本期没有重新发送邀请邮件 |
| 发送失败 | 邮件服务未受理时，邀请照常成功、不回滚；运营看到发送失败的提示，线下将登录邮箱和初始密码告知该机构【确认】。平台不自动重发 |
| 发生时间 | 邀请添加成功的时间 |

**内容与去向**

| 项目 | 规则 |
| --- | --- |
| 必须写明 | 监管机构名称；登录邮箱；初始密码；管理端登录入口；首次登录须修改密码 |
| 不得出现 | 其他监管机构或企业的任何信息；运营账号的邮箱；免密登录或自动登录的链接 |
| 语言 | 同一封邮件内先简体中文、后 English，两段内容相同；动态值按原文填入，不翻译 |
| 打开后去哪 | 邮件中的管理端登录入口（由开发配置的地址）；打开后须输入登录邮箱和初始密码，按[首次登录强制改密（F-LG-03）](./v1.0-管理端登录与权限-PRD.md#F-LG-03)先改密 |

动态值：

| 动态值 | 业务含义 |
| --- | --- |
| 机构名称 | 邀请时填写的机构名称 |
| 登录邮箱 | 邀请时分配的登录邮箱，即本邮件的收件地址 |
| 初始密码 | 邀请时运营设置的初始密码 |
| 登录入口 | 管理端登录入口地址 |

主题与正文（纯文本）：

| 内容 | 简体中文 | English |
| --- | --- | --- |
| 主题 | 代币发行平台管理端账号已开通 | Your Token Issuance Platform admin account is ready |
| 正文 | 您好，{机构名称}：平台已为您开通代币发行平台管理端账号。登录邮箱：{登录邮箱}；初始密码：{初始密码}；登录入口：{登录入口}。首次登录须修改密码，修改后初始密码失效。请妥善保管账号信息，不要转发本邮件。 | Hello {机构名称}, an admin account for the Token Issuance Platform has been created for you. Login email: {登录邮箱}; initial password: {初始密码}; sign-in page: {登录入口}. You must change your password when you first sign in, after which the initial password will no longer work. Please keep your account details safe and do not forward this email. |

- 邮件主题中不出现初始密码。
- 正文措辞可由设计调整，但必须写明的五项不能缺少。
