2026-11-05｜需求评审稿｜供测试使用

规则以[01 功能与业务规则](./01-销毁审核与解除质押-PRD.md)及本册为准；原型用于核对布局。本册只写验收标准，测试用例、执行步骤及技术验证由后续测试小队编写。

## 0. 验收前准备

- 账号：两个运营账号；原监管机构 X、其他机构 Y；X 停用、首次待改密及本人修改登录邮箱前后身份；企业 A、B 的已认证与未认证身份、未登录身份。
- 代币与资产：成功铸造、尚未铸造成功、融资中、销毁申请中、已销毁；两位小数代币数量、代币符号 cou 及其图标、资产价值，铸造到账地址、合约；一个暂无对应图标的代币符号；至少两枚同为 Ethereum、cou 的代币，其中一枚有多笔销毁申请；发行时间不同的多枚代币；原机构或合约改名、合约停用、企业登录地址改变；已到期已结清、未到期已结清、已到期未结清及到期依据缺失。
- 链上持有：未质押（质押地址为空）、质押中、解除质押后回到原持有地址、融资违约后留在质押合约地址、质押地址与下游融资结果不一致、链上查询失败、持有地址不是铸造到账地址、已销毁。
- 业务签名：企业以登录地址及本次申请授权标识签名的申请；授权标识未使用、已使用、已失效或属于其他企业／其他提交；签名后企业登录地址变更；驳回后使用新授权标识重新签名的申请；销毁失败后运营重试的申请；签名记录读取失败。
- 融资依据：下游与链上两项均无、均有、一有一无、任一或两项未知；审核或重试前事实变化；结果与另一笔代币相混、数量不符的数据。
- 申请与解除：待审、驳回、多笔历史驳回及新申请、销毁中、明确失败、执行结果未知、失败重试成功、成功待解除、已解除；关联字段缺失或结果矛盾；重复、并发及读取失败数据。
- 记录与消息：有／无失败说明、备注与凭证；上传失败、取消、重复送达和已读记录；中英文及时区差异、旧消息指向已处理申请。
- 销毁执行环境：可模拟平台签名私钥不可用、销毁交易未能提交，以及开发人员处理后恢复；可读取每次销毁交易写入链上的内容；包含审核阶段直接驳回、已提交交易但执行失败后驳回的申请。
- 风险暂停：平台暂停新的销毁申请、恢复新的销毁申请；暂停前已有待审、销毁中、销毁失败及完成申请。

## 2. 销毁详情与条件核对

对应[销毁详情与条件核对（A-BURN-02）](./01-销毁审核与解除质押-PRD.md#A-BURN-02)。

| 前提 | 操作 | 预期结果 |
| --- | --- | --- |
| <a id="AC-M4B-05"></a>申请与代币对应（AC-M4B-05）：一笔完整申请及其原铸造记录 | 查看详情及关联记录 | 唯一代币、申请编号，企业、资产、原地址、合约、原机构及完整数量正确对应；代币数量两位小数，单位为原合约的代币符号，不显示为 USD；代币价值等于关联资产的资产价值并带 USD；所属网络与代币类型（图标与符号）取原合约，暂无图标时只展示代币符号，其余信息与动作不受影响；铸造到账地址只展示地址本身，不展示账户备注名；能追溯原发行及成功铸造记录，不被新登录地址改写 |
| <a id="AC-M4B-06"></a>到期与结清依据（AC-M4B-06）：未到期已结清、恰好到期已结清、已到期未结清、余额为零但未确认结清 | 查看前置条件并尝试通过 | 仅到期且上游明确已结清满足该组条件；恰好到期算已到期；余额为零或已有回款不能代替结清；未知不能通过 |
| <a id="AC-M4B-07"></a>融资双重判断（AC-M4B-07）：两项均无、均有、不一致、任一未知，含一项有另一项未知 | 查看条件及尝试通过 | 仅均无通过；任一有质押阻断；不一致按有质押并保留两项实际结果，企业得到联系平台提示；未知明确无法确认并阻断；其他已知限制同时说明 |
| <a id="AC-M4B-08"></a>历史条件与当前事实（AC-M4B-08）：审核后结清或融资信息变化 | 查看原审核记录和重新取得的当前条件 | 原审核依据、核对时点不被新值覆盖，当前条件与历史事实可区分；运营不能手工改外部结果 |

| <a id="AC-M4B-39"></a>持有地址与持有信息（AC-M4B-39）：申请待审或销毁失败，代币分别为未质押、质押中、质押地址与下游结果不一致、链上查询失败、持有地址不是铸造到账地址 | 运营查看销毁详情的持有信息，尝试通过或重试 | 持有信息以行展示持有地址、质押地址（无质押为空）、持有数量（单位为代币符号）、融资状态及查询时间，不展示账户备注名；仅链上持有信息显示持有地址为铸造到账地址、质押地址为空，且其他条件满足时可以通过或重试；持有地址不是铸造到账地址时保持原阶段并说明代币不在铸造到账地址，可驳回，无改址或强制销毁入口；查询失败说明暂时无法获取并阻断，不用铸造到账地址补行或显示为未融资；质押地址与下游结果矛盾按有融资质押处理；融资违约后留在质押合约地址的代币不能通过或重试，说明仍在质押地址 |
| <a id="AC-M4B-43"></a>违约代币禁止销毁（AC-M4B-43）：融资违约后代币留在质押合约地址，分别为没有申请、申请待运营审核、申请销毁失败；另有一枚正常融资质押中、销毁失败的代币，以及一笔持有信息查询失败的销毁失败申请 | 运营查看销毁审核列表、销毁详情与全平台代币台账，尝试通过、重试与驳回；原监管机构查看解除监管列表与本机构代币台账 | 没有申请的违约代币不进入销毁审核列表；待审申请不能通过，填写意见可以驳回，驳回后代币为融资质押中；销毁失败申请不能重试，填写意见可以驳回：申请变为驳回，代币为融资质押中，原审核通过、失败与重试记录保留，另记驳回结果，企业收到驳回消息且不能再申请；正常融资质押中的失败申请同样可以驳回；持有信息查询失败时不能驳回，只能按失败重试规则处理；三者都没有强制销毁、改址或违约代币销毁入口，不形成解除事项，监管情况始终为监管中；台账与详情按持有信息展示质押地址与融资状态，不出现违约标识 |
| <a id="AC-M4B-40"></a>销毁申请的业务签名记录（AC-M4B-40）：企业以登录地址及本次申请授权标识签名提交的申请，之后企业登录地址变更；驳回后的新申请；失败后运营重试 | 运营、原监管机构、其他机构分别查看申请详情及签名记录，并直接取得 | 签名记录随原申请保存且不能修改，包含签名地址、签名时间、签名值和本次申请授权标识；登录地址变更不改签名地址；驳回后的新申请使用新的授权标识和自己的签名，旧授权与签名不能复用；重试沿用原授权标识与原签名，不产生新签名；读取失败可重试且不影响其他信息；管理端不展示签名原文，签名记录不另设链上交易哈希；签名地址、签名值和授权标识可核对完整值；运营可见，原监管机构及其他机构看不到，直接取得也被拒绝 |
| <a id="AC-M4B-45"></a>风险期间的新申请暂停与既有申请（AC-M4B-45）：平台暂停新的销毁申请，已有待审、销毁中、销毁失败及完成申请；之后恢复 | 企业尝试提交新申请；运营与监管机构查看并办理既有申请 | 暂停期间不产生新的销毁申请；既有申请仍可查看，阶段不回滚、不自动驳回或改变；运营审核、执行、失败重试及监管机构解除仍按各自当前权限、阶段和前置条件办理，必要依据无法确认时不放行；恢复后企业须按 M4a 重新取得当前资格和新的本次申请授权标识再签名提交，暂停期间失效的授权不能复用 |

## 3. 通过并执行销毁

对应[通过并执行销毁（A-BURN-03）](./01-销毁审核与解除质押-PRD.md#A-BURN-03)、[平台签名提交销毁交易](./01-销毁审核与解除质押-PRD.md#platform-signing)。

| 前提 | 操作 | 预期结果 |
| --- | --- | --- |
| <a id="AC-M4B-10"></a>确认、取消与重新核对（AC-M4B-10）：申请待审且条件曾满足 | 核对确认内容、取消；或条件已变化时提交通过 | 确认能核对申请、代币、资产、完整数量（单位为代币符号）、原地址合约及机构，说明通过即执行及后续解除；取消不产生结果；提交时当前条件不满足或未知则保持待审并说明限制，不自动驳回 |
| <a id="AC-M4B-11"></a>通过即执行（AC-M4B-11）：申请待审且全部当前条件满足 | 运营确认通过 | 记录审核通过、审核方、审核时间及运营审核人，申请进入销毁中并执行原代币完整数量；运营全程无需使用钱包，也看不到签名私钥；企业无需再次签名，不收到签名或链上授权请求；不另建执行待办，不允许另选数量、地址或合约 |
| <a id="AC-M4B-12"></a>并发审核与旧动作（AC-M4B-12）：两位运营打开同一待审申请 | 分别提交通过、驳回或重复点击 | 只承认一次生效审核与实际执行；后处理者看到真实结果，不能覆盖生效审核或重复销毁；过期阶段不保留可执行旧动作 |
| <a id="AC-M4B-13"></a>执行未确认与明确失败（AC-M4B-13）：销毁中，存在未确认结果、明确失败结果，以及平台签名私钥不可用或销毁交易未能提交 | 取得执行结果并查看；私钥问题由开发人员处理后运营手动重试 | 未确认保持销毁中，不以等待认定失败、不开放另次执行；确认失败才进入销毁失败并留记录；签名私钥不可用或交易未能提交时申请进入销毁失败，保留失败记录，全体运营收到销毁失败告警，开发人员处理后运营可手动重试；以上均不显示已销毁或形成解除待办；不展示销毁交易哈希或执行进度，等待再久也不发超时提醒 |
| <a id="AC-M4B-14"></a>成功与待解除承接（AC-M4B-14）：执行结果对应原代币及完整数量 | 取得成功结果并在两端查看 | 记录实际销毁数量（单位为代币符号，与申请数量一致）及成功时间，代币已销毁，原机构待解除；可同时承接成功与待解除，成功事实保留；历史不删除，企业不能再次申请 |
