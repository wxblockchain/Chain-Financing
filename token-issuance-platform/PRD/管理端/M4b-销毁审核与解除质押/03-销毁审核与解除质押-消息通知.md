# 销毁执行、解除资产托管与代币台账 · 消息通知

2026-11-09｜管理端发起业务，企业／名单内机构／运营接收｜需求评审稿

本模块发出七类站内消息，均必发且不可关闭，不发邮件。共同接收、已读、语言、前往与送达规则按 M7 执行；发生后 60 秒内可见。NT-C07 随销毁驳回流程取消而停用，编号不重新分配；NT-C10 用于向企业告知销毁失败，NT-A05 用于向运营知会销毁成功，NT-R04 用于向名单内的法律服务机构、审计机构同步销毁结果。

## 1. 事件总览

| 消息 | 端与收件范围 | 分类 | 功能环节 |
| --- | --- | --- | --- |
| [销毁成功（NT-C06）](#NT-C06) | 面客端，本次申请所属企业 | 业务办理进度 | [直接执行销毁](./01-销毁审核与解除质押-PRD.md#A-BURN-03) |
| [销毁失败（NT-C10）](#NT-C10) | 面客端，本次申请所属企业 | 业务办理进度 | 直接执行确认失败 |
| [资产已解除托管（NT-C08）](#NT-C08) | 面客端，该资产所属企业 | 业务办理进度 | [解除资产托管](./01-销毁审核与解除质押-PRD.md#R-RELEASE-03) |
| [代币已销毁、待解除托管（NT-R02）](#NT-R02) | 管理端，本代币唯一的资产托管机构 | 审核任务 | 销毁成功后形成解除待办 |
| [代币已销毁（NT-R04）](#NT-R04) | 管理端，名单内的每家法律服务机构、审计机构 | 业务办理进度 | 链上确认销毁成功 |

| [销毁成功知会（NT-A05）](#NT-A05) | 管理端，全体运营 | 业务办理进度 | 链上确认销毁成功 |

<a id="NT-C06"></a>
## 2. 销毁成功（NT-C06）

- 触发：该笔申请的代币完整数量确认销毁成功，记录成功事实时发一次。
- 收件人：本次申请所属企业。
- 必须包含：销毁申请编号、资产编号、申请提交时间、完整销毁数量与代币符号、等待资产托管机构解除资产托管的说明。
- 打开后：M4a 该笔销毁申请详情。读取或送达失败不改变成功事实，不允许再销毁。

<a id="NT-C10"></a>
## 3. 销毁失败（NT-C10）

- 触发：该笔申请从销毁中确认进入销毁失败时发一次；执行仍在进行或结果未确认不触发。
- 收件人：本次申请所属企业。
- 必须包含：销毁申请编号、资产编号、申请提交时间、失败时间、本笔申请已结束的说明，以及当前仍满足销毁条件时可重新发起一笔销毁交易的指引。
- 打开后：M4a 原销毁失败申请详情；不恢复原申请。是否可新建申请以代币当前位置、融资与其他资格为准。

<a id="NT-C08"></a>
## 4. 资产已解除托管（NT-C08）

- 触发：本代币的资产托管机构上传解除托管通知文件并解除成功，生效记录已形成。同一代币只发一次。
- 收件人：该笔资产所属企业。
- 必须包含：销毁申请编号、资产编号、资产托管机构名称、解除完成时间和已解除结果。资产托管机构名称取办理机构的当前名称。不包含操作人；消息不附解除说明或通知文件。
- 打开后：M4a 对应成功销毁申请的解除进度与结果，可在该处查看解除说明和解除托管通知文件。

<a id="NT-R02"></a>
## 5. 代币已销毁、待解除托管（NT-R02）

- 触发：确认销毁成功并形成资产托管机构待解除事项，与 NT-C06 源于同一成功事实。
- 收件人：[本代币的资产托管机构](./01-销毁审核与解除质押-PRD.md#custodian)，只发一条；名单内的法律服务机构、审计机构改收 NT-R04。本模块不根据当前启用机构重新分配，机构停用、更名或邮箱变更不改归属。
- 必须包含：销毁申请编号、企业名称、资产编号、完整销毁数量及代币符号、销毁成功时间和办理解除资产托管的说明。
- 打开后：M4b 该笔解除资产托管详情；已解除时只看原记录，阅读消息不等于完成待办。

<a id="NT-R04"></a>
## 5.1 代币已销毁（NT-R04）

- 触发：确认代币完整数量销毁成功时发一次，与 NT-C06、NT-R02 源于同一成功事实；平台入口和非平台入口均触发。
- 收件人：[名单内机构](./01-销毁审核与解除质押-PRD.md#listed-institutions)中的每家法律服务机构、审计机构，各收一条；资产托管机构只收 NT-R02，不重复收本消息；名单中没有这两类机构时不发送。机构停用、更名或邮箱变更不改收件人。
- 必须包含：销毁申请编号、企业名称、资产编号、完整销毁数量及代币符号、销毁成功时间，以及由资产托管机构办理解除资产托管、本消息仅供知悉的说明。
- 打开后：M4b [本机构代币台账](./01-销毁审核与解除质押-PRD.md#R-TOKEN-01)中该代币的只读详情；不提供办理动作。

<a id="NT-A04"></a>
## 6. 销毁失败知会（NT-A04）

- 触发：企业钱包已广播的销毁交易从销毁中确认进入销毁失败；钱包未广播不产生申请，也不触发本消息。
- 收件人：全体运营，各自记录已读；该消息是知会而非待处理任务。
- 必须包含：销毁申请编号、企业名称、资产编号、申请提交时间、失败时间；已取得内部失败说明时可附原文。不包含“待重试”指引。
- 打开后：M4b 原申请的只读销毁记录详情；不提供审核、驳回或重试动作。

<a id="NT-A05"></a>
## 7. 销毁成功知会（NT-A05）

- 触发：平台监听到代币完整数量已在链上销毁成功时发一次；平台入口和非平台入口均触发。
- 收件人：全体运营，各自记录已读；该消息只供知悉与审计，不形成待处理任务。
- 必须包含：销毁申请编号、企业名称、资产编号、完整销毁数量及代币符号、销毁成功时间和交易来源。非平台入口必须明确显示“非平台入口”。
- 打开后：M4b 对应销毁记录详情；不提供审核、撤销、恢复代币或重试动作。

## 9. 内容、权限与重复事实

- 同一事实重复送达不新增、不改发生时间、不重置已读；失败后企业创建的新申请是新事实。
- 消息不包含完整钱包地址、签名、个人联系方式、内部运营账号、解除说明、解除托管通知文件原件或下载地址。内部失败说明只可进入 NT-A04。
- 从消息前往时重新检查当前身份和数据权限；阅读消息不代表获得办理权限。
- 本模块不发销毁已发起、审核通过、销毁驳回、手动重试已受理、台账查看或解除失败通知。非平台入口销毁成功时沿用 NT-C06、NT-R02、NT-R04，并向运营发送成功知会；消息中标明交易来源为“非平台入口”。
