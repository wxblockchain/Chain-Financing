# 机构管理 · 消息通知

2026-11-09｜本模块只发送机构账号开通邮件；编辑、启停、登录邮箱填错的纠正和业务分配均不由本模块发送消息。

<a id="NT-R03"></a>
## 机构账号开通邮件（NT-R03）

| 项目 | 规则 |
| --- | --- |
| 触发 | 添加机构及唯一账号成功后 |
| 收件人 | 添加时填写的机构登录邮箱 |
| 内容 | 机构编号、机构名称、机构类型、登录邮箱、平台生成的初始密码、管理端登录入口、首次登录必须修改密码 |
| 主题 | 不含初始密码 |
| 语言 | 先简体中文、后 English，两段内容相同；具体措辞与排版由设计决定。与管理端登录与权限的[邮件语言规则](../M5-管理端登录与权限/03-管理端登录与权限-消息通知.md#email-language)相同 |
| 不触发 | 添加失败、重复提交承接原结果、编辑、停用、启用；开发人员按[登录邮箱填错的纠正](./01-机构管理-PRD.md#login-email-fix)更正邮箱并重置凭据（不重发，新初始密码线下告知） |

- 每个成功建立的账号只发一次开通邮件。
- 邮件失败不回滚机构和账号；运营看不到初始密码，可线下告知机构用登录邮箱通过忘记密码完成首次密码设置，本期无重发入口。
- 不同时生成站内消息。密码变更、找回和邮箱修改消息由“管理端登录与权限”定义。
