# 机构管理 · 消息通知

2026-11-06｜本模块只发送机构账号开通邮件；编辑、启停和业务分配均不由本模块发送消息。

<a id="NT-R03"></a>
## 机构账号开通邮件（NT-R03）

| 项目 | 规则 |
| --- | --- |
| 触发 | 添加机构及唯一账号成功后 |
| 收件人 | 添加时填写的机构登录邮箱 |
| 内容 | 机构编号、机构名称、机构类型、登录邮箱、初始密码、管理端登录入口、首次登录必须修改密码 |
| 主题 | 不含初始密码 |
| 语言 | 中英文内容均可理解，具体排版由设计决定 |
| 不触发 | 添加失败、重复提交承接原结果、编辑、停用、启用 |

- 每个成功建立的账号只发一次开通邮件。
- 邮件失败不回滚机构和账号；运营可线下告知，本期无重发入口。
- 不同时生成站内消息。密码变更、找回和邮箱修改消息由“管理端登录与权限”定义。
