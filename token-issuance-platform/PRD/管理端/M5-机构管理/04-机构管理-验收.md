# 机构管理 · 验收

2026-11-09｜对应功能册：[01](./01-机构管理-PRD.md)｜流程册：[02](./02-机构管理-流程图与状态机.md)｜消息册：[03](./03-机构管理-消息通知.md)

怎么读：

- 编号沿用原值，缺号不代表遗漏。
- 一条验收写了多个场景时，全部场景都满足才算通过。

## 0. 验收前准备

- 准备运营、机构账号、未登录用户；准备三种固定机构类型、启用/停用机构及不同账号状态。
- 准备重名、当前账号已用邮箱、其他账号历史上使用过的邮箱、无效联系资料、邮件发送失败和两个运营并发操作样本。
- 资质附件样本：PDF、JPG、JPEG、PNG 各一份；恰好 10 × 1024 × 1024 字节与超过 1 字节的文件；第 11 份文件；Office 文档、压缩包、空文件；扩展名与实际内容不一致及仅修改扩展名的文件；可模拟上传失败。
- 准备一家添加时登录邮箱填错的机构 V：填错的邮箱已收到开通邮件，并已在其他设备登录；由开发人员把登录邮箱更正为正确邮箱并设置新初始密码；内部支持人员可核对平台安全记录。

## 1. 机构档案与账号

对应功能：[机构档案与账号](./01-机构管理-PRD.md#fields)、[机构级基础资质附件的文件规则](./01-机构管理-PRD.md#qualification-files)、[添加机构并开通账号（F-RG-02）](./01-机构管理-PRD.md#F-RG-02)、[登录邮箱填错的纠正](./01-机构管理-PRD.md#login-email-fix)、[编辑机构资料（F-RG-04）](./01-机构管理-PRD.md#F-RG-04)

| 编号 | 场景与操作 | 预期结果 |
| --- | --- | --- |
| <a id="AC-RG-01"></a>AC-RG-01 | 机构账号或未登录用户访问机构管理 | 无入口；直接访问和修改被拒，不返回机构资料；运营可使用 |
| <a id="AC-RG-02"></a>AC-RG-02 | 查看列表并按机构编号、名称、邮箱查找，组合筛选 | 展示唯一机构编号、名称、类型、登录邮箱、机构状态、账号状态、添加和最近登录时间；查找与筛选结果正确 |
| <a id="AC-RG-03"></a>AC-RG-03 | 无机构、筛选无结果、读取失败 | 三种结果可区分；失败可重试，不误报空列表 |
| <a id="AC-RG-04"></a>AC-RG-04 | 分别选择资产托管、审计、法律服务并提交完整资料；检查是否存在其他、自定义或类型配置入口 | 每次生成全平台唯一且不可修改的机构编号，原子化建立机构和唯一账号；机构启用，账号待首登改密；类型正确保存；没有其他、自定义或类型配置入口 |
| <a id="AC-RG-05"></a>AC-RG-05 | 空/重名名称、无类型、无效联系人或邮箱、当前重复登录邮箱、其他账号历史上使用过的登录邮箱、不合规密码 | 均不建立机构或账号，不发邮件；指出原因并保留有效输入；历史邮箱不能分配给新账号 |
| <a id="AC-RG-06"></a>AC-RG-06 | 邮件服务不可用时添加 | 机构和账号照常建立；明确邮件失败，可线下告知，无重发入口 |
| <a id="AC-RG-07"></a>AC-RG-07 | 重复点击、刷新或网络重发 | 只产生一家机构、一个账号和一封开通邮件 |
| <a id="AC-RG-17"></a>AC-RG-17 | 机构 V 由开发人员更正登录邮箱并重置凭据后，分别用填错的邮箱登录和找回密码，用正确邮箱配旧初始密码、新初始密码登录；运营查看 V 的详情；另尝试把填错的邮箱分配给新添加的机构 | 运营在产品内没有修改登录邮箱的入口；填错的邮箱不能登录，找回得到与未注册邮箱相同的中性反馈，也不能分配给新机构；旧初始密码不能登录，新初始密码登录后进入首次登录强制改密；V 原有的登录全部结束，回到登录入口时说明账号登录信息已重置、需使用线下告知的登录信息重新登录，账号为待首登改密；详情显示正确的登录邮箱，机构编号、档案和机构状态不变；没有重发开通邮件，也没有站内消息或邮件；安全记录中有一条记录，含修改前后的登录邮箱 |
| <a id="AC-RG-08"></a>AC-RG-08 | 查看机构详情 | 展示机构编号、完整档案、机构级基础资质、机构和账号状态及时间，不展示初始密码，无改机构编号、登录邮箱、代重置或删除入口 |
| <a id="AC-RG-09"></a>AC-RG-09 | 编辑名称、三类固定值中的类型、联系资料和机构级基础资质 | 新档案值保存；机构编号、登录邮箱和账号状态不变；基础资质不绑定具体发行申请、代币或其他业务对象；不结束登录、不发通知；不由 M5 改写历史业务 |
| <a id="AC-RG-18"></a>AC-RG-18 | 机构数量超过一页；运营翻页，查找或筛选后在第二页进入机构详情再返回 | 按添加时间从新到旧排列，展示总数和当前页；条件变化后从第一页开始；返回时回到原所在页并保留条件 |
| <a id="AC-RG-19"></a>AC-RG-19 | 添加机构和编辑机构资料时分别上传资质附件：PDF、JPG、JPEG、PNG 各一份；恰好 10 × 1024 × 1024 字节的文件；累计到第 10 份后再添加第 11 份；超过上限、Office 文档、压缩包、空文件、扩展名与实际内容不一致、仅修改扩展名的文件；模拟上传失败后重试；编辑时移除一份再添加 | 四种格式和恰好上限的文件均可添加，恰好 10 份可以保存；第 11 份不能添加；超过上限、格式不符、空文件、扩展名与内容不一致或仅改扩展名的文件均不添加并说明原因；上传失败的文件不计入份数，可重试；不合规或失败的文件不影响已添加的其他文件和已填写内容；编辑时移除后可再添加，保存后合计不超过 10 份；添加与编辑的规则相同 |
| <a id="AC-RG-20"></a>AC-RG-20 | 运营添加审计机构 X 后，分别在中文和英文界面查看机构列表、详情，并让 X 作为名单内机构追加材料触发企业与运营消息 | 机构类型始终按选定名称“审计机构”原样展示，不随界面语言变化；中英文消息正文中的机构类型同样为“审计机构” |

## 2. 停用与启用

对应功能：[停用与启用（F-RG-05）](./01-机构管理-PRD.md#F-RG-05)

| 编号 | 场景与操作 | 预期结果 |
| --- | --- | --- |
| <a id="AC-RG-10"></a>AC-RG-10 | 运营停用启用机构 | 确认前展示机构名称、类型和影响说明，影响说明写明不再进入新的机构分配、已有的分配、材料待办和解除托管，以及铸造成功后至代币销毁前的材料追加继续有效；确认后变停用，不出现在新业务的机构可选范围中；账号状态和历史不变，不发通知 |
| <a id="AC-RG-11"></a>AC-RG-11 | 停用机构存在既有业务 | M5 只提供停用状态，不在本模块断言既有待办、材料、代币的查看或办理结果；按所属业务模块验收 |
| <a id="AC-RG-14"></a>AC-RG-14 | 运营重新启用 | 恢复进入新业务选择范围；账号和历史不变，不发通知 |
| <a id="AC-RG-15"></a>AC-RG-15 | 两位运营并发编辑或启停；模拟保存失败 | 后提交按最新状态校验，不静默覆盖；失败保持最近一次成功结果，可重试 |
