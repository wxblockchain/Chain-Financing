# 机构管理 · 验收

2026-11-06｜对应功能册：[01](./01-机构管理-PRD.md)｜流程册：[02](./02-机构管理-流程图与状态机.md)｜消息册：[03](./03-机构管理-消息通知.md)

## 0. 验收前准备

- 准备运营、机构账号、未登录用户；准备三种固定机构类型、启用/停用机构及不同账号状态。
- 准备重名、当前账号已用邮箱、其他账号历史上使用过的邮箱、无效联系资料、邮件发送失败和两个运营并发操作样本。

## 1. 机构档案与账号

| 编号 | 场景与操作 | 预期结果 |
| --- | --- | --- |
| AC-RG-01 | 机构账号或未登录用户访问机构管理 | 无入口；直接访问和修改被拒，不返回机构资料；运营可使用 |
| AC-RG-02 | 查看列表并按机构编号、名称、邮箱查找，组合筛选 | 展示唯一机构编号、名称、类型、登录邮箱、机构状态、账号状态、添加和最近登录时间；查找与筛选结果正确 |
| AC-RG-03 | 无机构、筛选无结果、读取失败 | 三种结果可区分；失败可重试，不误报空列表 |
| AC-RG-04 | 分别选择资产托管、审计、法律服务并提交完整资料；检查是否存在其他、自定义或类型配置入口 | 每次生成全平台唯一且不可修改的机构编号，原子化建立机构和唯一账号；机构启用，账号待首登改密；类型正确保存；没有其他、自定义或类型配置入口 |
| AC-RG-05 | 空/重名名称、无类型、无效联系人或邮箱、当前重复登录邮箱、其他账号历史上使用过的登录邮箱、不合规密码 | 均不建立机构或账号，不发邮件；指出原因并保留有效输入；历史邮箱不能分配给新账号 |
| AC-RG-06 | 邮件服务不可用时添加 | 机构和账号照常建立；明确邮件失败，可线下告知，无重发入口 |
| AC-RG-07 | 重复点击、刷新或网络重发 | 只产生一家机构、一个账号和一封开通邮件 |
| AC-RG-08 | 查看机构详情 | 展示机构编号、完整档案、机构级基础资质、机构和账号状态及时间，不展示初始密码，无改机构编号、登录邮箱、代重置或删除入口 |
| AC-RG-09 | 编辑名称、三类固定值中的类型、联系资料和机构级基础资质 | 新档案值保存；机构编号、登录邮箱和账号状态不变；基础资质不绑定具体发行申请、代币或其他业务对象；不结束登录、不发通知；不由 M5 改写历史业务 |

## 2. 停用与启用

| 编号 | 场景与操作 | 预期结果 |
| --- | --- | --- |
| AC-RG-10 | 运营停用启用机构 | 确认后变停用，不再进入新业务机构选择范围；账号状态和历史不变，不发通知 |
| AC-RG-11 | 停用机构存在既有业务 | M5 只提供停用状态，不在本模块断言既有待办、材料、代币的查看或办理结果；按所属业务模块验收 |
| AC-RG-14 | 运营重新启用 | 恢复进入新业务选择范围；账号和历史不变，不发通知 |
| AC-RG-15 | 两位运营并发编辑或启停；模拟保存失败 | 后提交按最新状态校验，不静默覆盖；失败保持最近一次成功结果，可重试 |

## 3. 账号开通邮件

| 编号 | 场景与操作 | 预期结果 |
| --- | --- | --- |
| AC-M7-32 | 添加成功、添加失败、重复提交、后续编辑和启停 | 每个成功账号只向登录邮箱发送一次开通邮件；含机构编号、名称、类型、邮箱、初始密码、入口和首登改密要求；主题无密码；其余场景不发送 |

本册不验收机构分配、待办、材料、铸造或代币范围；这些分别在 M3b、M4b、M2 验收。
