# 代币发行 · 审核与铸造 · 消息通知

2026-11-06｜面客端：企业用户；管理端：运营管理人员｜需求评审稿

本册只定义本模块产生的五类站内消息。收件、阅读、未读数、语言、送达、去重和前往异常等共同规则由 [M7 消息通知](../../两端共用/M7-消息通知/01-消息通知-PRD.md#MSG-06)统一承接，本册不重复。编号沿用既有编号，缺号不代表遗漏。

机构分配、名单调整、机构停用、首次材料待办和材料上传均不发送消息；机构通过本模块待办查看当前事项。

## 1. 消息登记

| 消息 | 发送来源 | 端与分类 | 触发环节 | 收件范围 | 打开后去哪 |
|---|---|---|---|---|---|
| [发行申请进入铸造（NT-C03）](#NT-C03) | M3b 选择合约并发起铸造 | 面客端；业务办理进度 | 申请首次成功进入铸造中 | 申请所属企业 | M3a 申请详情 |
| [发行申请已驳回（NT-C04）](#NT-C04) | M3b 运营驳回 | 面客端；业务办理进度 | 运营驳回成功 | 申请所属企业 | M3a 申请详情 |
| [铸造成功（NT-C05）](#NT-C05) | M3b 铸造结果 | 面客端；业务办理进度 | 链上铸造成功 | 申请所属企业 | M4a 代币详情 |
| [铸造失败待重试（NT-A03）](#NT-A03) | M3b 铸造结果 | 管理端；运营告警 | 每次铸造取得明确失败结果 | 全体运营 | M3b 申请详情 |
| [铸造超时待处理（NT-A05）](#NT-A05) | M3b 铸造结果 | 管理端；运营告警 | 单次铸造开始满 10 分钟仍无明确结果 | 全体运营 | M3b 申请详情 |

企业消息归属于申请所属企业，不归属于提交时登录地址。管理端消息发给事件发生时具备运营身份的全体有效账号；机构不接收本册消息。

<a id="NT-C03"></a>

## 2. 发行申请进入铸造（NT-C03）

| 项目 | 规则 |
|---|---|
| 触发 | 运营确认发起铸造，申请首次从“运营处理中”成功进入“铸造中” |
| 不触发 | 保存或调整机构名单、机构停用、机构上传材料、首次待办完成、铸造失败后的手动重试、提交未成功 |
| 同一事实 | 申请所属企业 + 申请编号 + 首次进入铸造中；一笔申请最多一条 |
| 发生时间 | 申请首次进入铸造中的时间 |
| 必须写明 | 申请编号；已进入铸造；等待链上结果 |
| 查看与办理条件 | 企业仍可查看本企业申请；企业无需办理，M3a 显示“发行处理中” |

| 语言 | 标题 | 正文 |
|---|---|---|
| 中文 | 发行申请已进入铸造 | 您的发行申请 {申请编号} 已进入铸造，请等待链上结果。 |
| English | Issuance application entered minting | Issuance application {application number} has entered minting. Please wait for the on-chain result. |

<a id="NT-C04"></a>

## 3. 发行申请已驳回（NT-C04）

| 项目 | 规则 |
|---|---|
| 触发 | 运营驳回成功，申请进入“运营驳回” |
| 不触发 | 驳回未成功、申请已进入铸造、机构上传材料或材料待办关闭 |
| 同一事实 | 申请所属企业 + 申请编号 + 运营驳回；一笔申请最多一条 |
| 发生时间 | 运营驳回生效时间 |
| 必须写明 | 申请编号；申请已驳回；驳回意见原文 |
| 查看与办理条件 | 企业仍可查看本企业申请与驳回结果；申请已终止，无后续操作 |

| 语言 | 标题 | 正文 |
|---|---|---|
| 中文 | 发行申请已驳回 | 您的发行申请 {申请编号} 已被驳回。驳回意见：{驳回意见}。 |
| English | Issuance application rejected | Issuance application {application number} has been rejected. Reason: {rejection reason}. |

驳回意见按运营输入的原文展示，不自动翻译；英文界面需明确这是原文内容。

<a id="NT-C05"></a>

## 4. 铸造成功（NT-C05）

| 项目 | 规则 |
|---|---|
| 触发 | 链上明确返回本次铸造成功，申请进入“铸造成功” |
| 不触发 | 仍在等待、铸造失败、结果回调重复到达或消息发送失败后的业务重放 |
| 同一事实 | 申请所属企业 + 申请编号 + 成功代币编号；一枚成功代币最多一条 |
| 发生时间 | 铸造成功确认时间 |
| 必须写明 | 申请编号；代币编号；完整代币数量；代币符号 |
| 查看与办理条件 | 企业仍可访问本企业代币；若代币暂不可读取，消息保留并由 M7 展示前往异常结果 |

| 语言 | 标题 | 正文 |
|---|---|---|
| 中文 | 代币铸造成功 | 发行申请 {申请编号} 已铸造成功，代币编号为 {代币编号}，数量为 {代币数量} {代币符号}。 |
| English | Token minting succeeded | Issuance application {application number} was minted successfully. Token ID: {token ID}; quantity: {token quantity} {token symbol}. |

<a id="NT-A03"></a>

## 5. 铸造失败待重试（NT-A03）

| 项目 | 规则 |
|---|---|
| 触发 | 平台签名、交易提交或链上执行取得明确失败结果；每次铸造尝试分别判断 |
| 不触发 | 仍在等待、只发生超时、手动重试已提交但尚无结果、同一次失败重复回调 |
| 同一事实 | 全体运营 + 申请编号 + 本次铸造尝试；每次尝试最多一条 |
| 发生时间 | 本次铸造明确失败的时间 |
| 必须写明 | 申请编号；本次铸造失败；交易哈希仅在已产生时写明 |
| 查看与办理条件 | 当前运营仍可查看该申请；申请为“铸造失败”时可按原参数重试，其他状态只查看最新结果 |

| 语言 | 标题 | 正文 |
|---|---|---|
| 中文 | 铸造失败，等待重试 | 发行申请 {申请编号} 本次铸造失败，请进入申请详情查看并处理。{交易哈希信息} |
| English | Minting failed and requires retry | Minting failed for issuance application {application number}. Open the application details to review and retry. {transaction hash information} |

失败说明可能包含内部信息，不写入消息正文；仅在有交易哈希时加入交易哈希信息。

<a id="NT-A05"></a>

## 6. 铸造超时待处理（NT-A05）

| 项目 | 规则 |
|---|---|
| 触发 | 单次铸造从进入“铸造中”起满 10 分钟仍无明确成功或失败结果 |
| 不触发 | 10 分钟内已成功或失败、同一次铸造已发过超时消息、页面停留时间达到 10 分钟但业务开始时间未达到 |
| 同一事实 | 全体运营 + 申请编号 + 本次铸造尝试 + 超时节点；每次尝试最多一条 |
| 发生时间 | 本次铸造开始满 10 分钟的时点 |
| 必须写明 | 申请编号；等待已超过 10 分钟；当前仍在处理中；交易哈希仅在已产生时写明 |
| 查看与办理条件 | 当前运营可查看铸造进度；超时不开放重试或驳回，只等待明确结果 |

| 语言 | 标题 | 正文 |
|---|---|---|
| 中文 | 铸造超时，等待结果 | 发行申请 {申请编号} 的铸造已等待超过 10 分钟，当前仍在处理中。请进入详情查看。{交易哈希信息} |
| English | Minting is taking longer than expected | Minting for issuance application {application number} has been pending for over 10 minutes and is still processing. Open the details to review it. {transaction hash information} |

超时不代表失败。后续取得明确结果时，按实际结果发送铸造成功或铸造失败消息。
