<a id="NT-LG-01"></a>
## 找回密码验证码（NT-LG-01）

- 触发：本人在忘记密码流程获取或重发验证码，目标为当前有效监管机构登录邮箱且满足最终确认的发送限制。
- 不触发：邮箱格式不合格、未绑定机构账号、运营账号、原账号邮箱已作废、发送限制未满足或请求失败。
- 收件人：只发当前登录邮箱，不发联系邮箱、不抄送运营，不给其他机构发。
- 必须包含：本次找回验证码、用途为设置新密码、验证码有效期、非本人操作时忽略的提示；不包含现有密码、新密码、初始密码或其他账号信息。
- 同一事实：同一次发送请求只产生一封，重复提交不重复发；本人再次成功获取是新的发码事实，使前一码失效。
- 异常：真实发送失败说明暂时无法发送、可重试；密码、邮箱与已有登录不变。未绑定账号、运营与旧邮箱使用中性反馈，不通过提示或响应差异泄露账号与角色。
- 去向：回到本人发起的找回流程输入验证码；仅收到邮件不获得登录资格。

<a id="NT-LG-02"></a>
## 修改邮箱验证码（NT-LG-02）

- 触发：正常且已登录的监管机构本人校验当前密码后，对本次新邮箱获取或重发验证码，且满足最终确认的发送限制。
- 不触发：登录失效、当前密码错误、账号锁定、新邮箱格式不合格或已被占用、新旧邮箱相同、发送限制未满足或请求失败。
- 收件人：只发本次新邮箱，不要求旧邮箱收码，不向联系邮箱、运营或其他机构发送副本。
- 必须包含：本次修改登录邮箱验证码、用途、验证码有效期、非本人操作时忽略的提示；不包含当前密码与其他账号信息。
- 同一事实：同一发送请求只发一封；成功重发为新发码事实，使同用途旧码作废；目标邮箱变化后原目标码不能用于新目标。
- 异常：发送失败不能使新邮箱生效，原邮箱、密码与登录保持原值；可按最终确认的发送限制重试。
- 去向：回到本人已发起的账户设置流程输入验证码；收到邮件不等于邮箱已修改。

## 共同内容与有效性

- 每封邮件先简体中文、后 English，两个语言段表达同一用途与有效期，使用同一验证码；具体措辞由设计确定。
- 验证码不出现在主题或预览文本中，不提供免密登录链接，也不通过邮件发送设置后的密码。
- 规则见[验证码的共同规则](./v1.0-管理端登录与权限-PRD.md#verification-rules)；位数、有效期与发送限制依赖[验证码参数待确认](./v1.0-管理端登录与权限-PRD.md#Q-LG-01)，相关数值边界待验，不判通过。
- 密码与邮箱修改成功后不另发成功通知；首次改密、本人改密、锁定与解除、登录成功与失败、语言与时区变更均不新增消息。
