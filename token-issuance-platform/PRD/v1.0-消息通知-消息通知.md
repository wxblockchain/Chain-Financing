本文件不属于消息通知模块的规则。按用户裁定，每类消息由发送它的业务模块在自己的消息通知册中维护【确认】。此前集中登记在这里的消息（目前剩 14 类），待各来源模块迁入自己的消息通知册后逐条删除，全部迁出后删除本文件；迁入前，本文件仍是这些消息的唯一规则来源。

**以下情况不发送任何消息。** 下列节点不在简报事件清单中：

- 企业：铸造失败、销毁失败（企业在自己的申请中看到处理状态）；销毁审核通过（以“销毁成功”告知）；提交发行申请、提交销毁申请本身。
- 监管机构：运营二审结果、铸造结果、销毁申请的提交与驳回。
- 运营：企业提交发行申请（尚待监管审核）、监管驳回、铸造成功、销毁成功、解除质押。
- 任何角色：登录与退出、企业数币账户的新增 / 编辑 / 删除、合约查看。

**按业务流程的发送顺序。**

- 发行：企业提交申请 → 新的待审申请（NT-R01）→ 监管通过：监管审核通过（NT-C01）+ 待二审的申请（NT-A01）；或监管驳回：监管审核驳回（NT-C02）→ 运营通过：运营审核通过（NT-C03）；或运营驳回：运营审核驳回（NT-C04）→ 铸造成功：铸造成功（NT-C05）；或铸造失败：铸造失败待重试（NT-A03），运营重试后再按结果发送。
- 销毁：企业发起销毁 → 新的销毁申请（NT-A02）→ 运营驳回：销毁申请驳回（NT-C07）；或审核通过并执行销毁 → 销毁成功：销毁成功（NT-C06）+ 代币已销毁、待解除质押（NT-R02）；或销毁失败：销毁失败待重试（NT-A04），运营重试后再按结果发送 → 监管解除质押：资产已解除质押（NT-C08）。

状态名称引用简报第 5 节。原业务的识别信息由各来源模块定义【确认】；下文写的上游资产编号与销毁申请提交时间是暂用识别，迁入时由来源模块确认或替换。

## 2. 发给企业的消息（C-MSG）

<a id="NT-C01"></a>
### 2.1 监管审核通过（NT-C01）

| 项目 | 规则 |
| --- | --- |
| 触发 | 监管机构一审通过并已上传监管协议，发行申请由“待监管审核”变为“待运营审核”时发送一次 |
| 不触发 | 一审未提交成功、协议上传未完成、监管驳回 |
| 收件人 | 提交该笔发行申请的企业。不发给其他企业 |
| 必须写明 | 上游资产编号；监管机构名称；结果为监管审核通过；下一步为等待平台运营审核；监管协议已可在该申请中查看 / 下载【确认】（BR-18） |
| 打开后去哪 | 该笔发行申请（代币发行·企业申请，M3a） |
| 同一事实 / 新事实 | 一笔申请只有一次监管审核结果，只发一次 |

<a id="NT-C02"></a>
### 2.2 监管审核驳回（NT-C02）

| 项目 | 规则 |
| --- | --- |
| 触发 | 监管机构一审驳回，发行申请变为“监管驳回”时发送一次 |
| 不触发 | 驳回未提交成功（例如未填写驳回意见） |
| 收件人 | 提交该笔发行申请的企业 |
| 必须写明 | 上游资产编号；监管机构名称；结果为监管驳回；驳回意见；申请已终止，这笔资产不能再次发起发行申请【确认】（BR-12） |
| 打开后去哪 | 该笔发行申请（代币发行·企业申请，M3a） |
| 同一事实 / 新事实 | 只发一次；驳回后申请终止，不会再有新的审核结果 |

## 4. 发给运营管理人员的消息（A-MSG）

以下消息的收件人均为全体运营：每位运营管理人员都能看到同一条消息，各自记录已读，见[谁能看到哪些消息（MSG-01）](./v1.0-消息通知-PRD.md#MSG-01)。

<a id="NT-A01"></a>
### 4.1 待二审的申请（NT-A01）

| 项目 | 规则 |
| --- | --- |
| 触发 | 监管机构一审通过并已上传监管协议，发行申请变为“待运营审核”时发送一次，与[监管审核通过（NT-C01）](#NT-C01)同时发生 |
| 不触发 | 监管驳回；企业刚提交、尚待监管审核 |
| 收件人 | 全体运营 |
| 必须写明 | 企业名称；上游资产编号；监管机构名称；监管通过时间；需要进行二审 |
| 打开后去哪 | 该笔发行申请的二审（代币发行·审核与铸造，M3b） |
| 同一事实 / 新事实 | 一笔申请只发一次；某位运营已完成二审后，其他运营打开时按[前往原业务（MSG-05）](./v1.0-消息通知-PRD.md#MSG-05)看到当前结果 |

<a id="NT-A02"></a>
### 4.2 新的销毁申请（NT-A02）

| 项目 | 规则 |
| --- | --- |
| 触发 | 企业发起销毁申请成功，销毁申请进入“待运营审核”时发送 |
| 不触发 | 发起时前置条件不满足（未到期、未结清、仍有融资质押）而未能提交；提交失败 |
| 收件人 | 全体运营 |
| 必须写明 | 企业名称；上游资产编号；销毁的代币数量；销毁申请提交时间；需要进行销毁审核 |
| 打开后去哪 | 该笔销毁申请的审核（销毁审核、解除质押与代币台账，M4b） |
| 同一事实 / 新事实 | 每笔销毁申请一条；被驳回后企业再次发起，是新的一条 |

<a id="NT-A03"></a>
### 4.3 铸造失败待重试（NT-A03）

| 项目 | 规则 |
| --- | --- |
