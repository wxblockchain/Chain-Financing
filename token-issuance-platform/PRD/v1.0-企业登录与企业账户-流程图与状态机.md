## 登录与身份判定（图 1）

```mermaid
flowchart TD
    A[未登录访问者点击连接钱包<br/>主动登录，或访问受保护内容时被要求登录<br/>登录入口说明使用在资产可信平台登记的钱包地址登录，支持网络 Ethereum] --> B{钱包可用且已解锁?}
    B -->|否| B1[说明原因：安装、启用或解锁钱包后重试<br/>仍为未登录]
    B -->|是| C[1 连接钱包：在钱包中选择 Ethereum 地址]
    C --> D{钱包在 Ethereum 网络?}
    D -->|否| D1[提示切换到 Ethereum 网络后重试<br/>不建立登录]
    D -->|是| C2[2 连接成功：展示本次连接的地址与网络<br/>尚未登录]
    C2 -->|取消或离开| C3[不建立登录，可重新连接]
    C2 --> E[3 确认签名：说明将请求一次登录签名<br/>不涉及转账或资金授权，用户确认]
    E --> F[4 钱包签名返回：用户在钱包中签名]
    F --> G{5 验签结果}
    G -->|拒绝、验签失败或地址不一致| G1[不建立登录，可重试]
    G -->|连接后或签名过程中钱包地址变化| G2[中止并说明地址已变化<br/>可用该地址重新登录]
    G -->|请求已过期或已使用| G3[准备新的签名请求，提示重新签名]
    G -->|通过| H[6 登录成功<br/>服务端按登录地址向资产可信平台调取]
    H --> I{调取结果}
    I -->|调取到唯一且可用的账户| J[企业用户：取得个人、企业信息与认证结论<br/>已认证可办理业务，未认证看到认证引导]
    I -->|调取不到| K[游客：显示游客引导]
    I -->|账户已锁定或禁用| L[本次登录结束，说明原因与解除信息]
    I -->|调取失败、超时或上游不可用| M[本次登录不成立<br/>说明暂时无法确认身份，请重试]
    I -->|一个地址对应多个账户| N[数据异常：本次登录不成立<br/>中性说明并告警]
    I -->|建立企业用户失败| O[建号失败：给出错误码<br/>可重试或退出]
    J --> P{登录前有原目标且仍有效?}
    K --> P
    P -->|是| Q[按当前身份重新判断权限<br/>有权即回到原目标，无权看到对应引导]
    P -->|否| R[进入登录后的默认页面<br/>原目标过期时说明链接已失效]
```

## 新增数币账户与地址归属签名（图 3）

```mermaid
flowchart TD
    A[已认证的企业用户选择新增数币账户] --> B[告知：只支持 Ethereum 地址<br/>只能登记本企业能签名的地址]
    B --> C[依次填写：区块链网络固定为 Ethereum，只展示<br/>数币地址、账户备注名]
    C --> D{数币地址符合 Ethereum 格式<br/>备注名不为空且不超过 100 个字符?}
    D -->|否| D1[指出具体原因，不能进入签名]
    D1 --> C
    D -->|是| E{本企业已有该地址，含登录地址?}
    E -->|是| E1[说明已存在，可查看已有那一条<br/>不能进入签名]
    E -->|否| F[说明签名用途：证明地址归本企业控制<br/>不发起交易、不改变当前登录]
    F --> G[用户在钱包中切换到被登记的地址并签名<br/>当前登录不变]
    G --> H{签名结果}
    H -->|钱包不可用或不在 Ethereum 网络| H1[说明原因，账户未登记，可重试]
    H -->|拒绝签名或验签失败| H1
    H -->|签名地址与被登记地址不一致| H2[说明签名的地址和要登记的地址不是同一个<br/>账户未登记，可重试]
    H -->|请求已过期或已使用| H3[提示重新签名]
    H -->|通过| I{保存成功?}
    I -->|否| I1[说明未登记成功，可重试<br/>不留下半条账户]
    I -->|是| J[验签通过，新增成功<br/>立即出现在列表和发行申请可选范围]
```

未认证的企业用户进入数币账户时只看到认证引导，不能进入本流程，见[图 6](#fig-6)。

## 面客端登录状态机

```mermaid
stateDiagram-v2
    state "未登录" as S0
    state "已登录·调取中" as S1
    state "企业用户·未认证" as S2
    state "企业用户·已认证" as S3
    state "游客" as S4
    [*] --> S0
    S0 --> S1: 签名验签通过
    S1 --> S0: 调取失败、账户锁定禁用、数据异常或建号失败
    S1 --> S2: 调取到账户，认证结论为未认证
    S1 --> S3: 调取到账户，认证结论为已认证
    S1 --> S4: 调取不到
    S2 --> S3: 调取时点发现认证通过
    S3 --> S2: 调取时点发现认证失效，向本人发认证失效通知
    S2 --> S0: 退出、到期、登录地址变更或账户锁定禁用
    S3 --> S0: 退出、到期、登录地址变更或账户锁定禁用
    S4 --> S0: 退出或到期
```

- 初始状态是未登录；没有终态，退出后可再次登录。
- 企业用户的有效期为 7 天，游客为 4 小时，均自登录成功起计算，不因操作延长；认证状态在已认证与未认证之间变化时不重新计算有效期。
- 游客与企业用户之间不直接转换：游客在上游完成注册并登记该地址后，须退出并重新登录，经过一次签名与调取才成为企业用户。

<a id="state-2"></a>
## 数币账户状态机

```mermaid
stateDiagram-v2
    state "填写与签名中（不是账户）" as A0
    state "有效·未被引用" as A1
    state "有效·被引用" as A2
    state "已删除" as A3
    [*] --> A0: 企业选择新增
    A0 --> [*]: 取消、校验不通过或签名失败，不产生账户
    A0 --> A1: 地址归属签名通过并保存成功
    A1 --> A2: 被处理中的发行申请选用，或有代币铸造到该账户
    A2 --> A1: 仅被申请引用，且该申请被驳回终止
    A1 --> A3: 企业确认删除
    A3 --> [*]
```

- 只有“有效”的两个状态是账户，可在列表中查看、在发行申请中选用；两者都可以修改账户备注名。
- “有效·被引用”不能删除。有代币铸造到该账户后，不论代币之后是什么状态（包括已销毁），都不再回到“有效·未被引用”。
- 已删除是终态，不可恢复；需要时重新新增并签名，产生新的账户。
- 登录地址这一条不走本状态机：由系统列入，始终有效，不能编辑或删除，随上游登录地址变更而更新；新的登录地址与企业新增账户相同时，那条企业新增账户并入登录地址这一条。
