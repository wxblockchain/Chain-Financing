# 销毁审核、解除监管与代币台账 · 验收

2026-10-30｜需求评审稿｜供测试使用

规则以[01 功能与业务规则](./v1.0-销毁审核与解除质押-PRD.md)及本册为准；原型用于核对布局。本册只写验收标准，测试用例、执行步骤及技术验证由后续测试小队编写。

共 39 条验收：本模块新增 AC-M4B-01～38；销毁结果消息的 AC-M7-31 沿用原编号。每条一行三列，编号与场景名称放在前提中；同条含多个场景须全部满足。标注“待验，不判通过”的边界须取得对应裁定后验收，不以文档对齐或演示数据代替真实业务结果。

## 0. 验收前准备

- 账号：两个运营账号；原监管机构 X、其他机构 Y；X 停用、首次待改密及登录邮箱更正前后身份；企业 A、B 的已认证与未认证身份、未登录身份。
- 代币与资产：成功铸造、尚未铸造成功、融资中、销毁申请中、已销毁；USD 两位小数数量及原地址、合约；原机构或合约改名、合约停用、企业登录地址改变；已到期已结清、未到期已结清、已到期未结清及到期依据缺失。
- 融资依据：下游与链上两项均无、均有、一有一无、任一或两项未知；审核或重试前事实变化；结果与另一笔代币相混、数量不符的数据。
- 申请与解除：待审、驳回、多笔历史驳回及新申请、销毁中、明确失败、执行结果未知、失败重试成功、成功待解除、已解除；关联字段缺失或结果矛盾；重复、并发及读取失败数据。
- 记录与消息：有／无失败说明、备注与凭证；上传失败、取消、重复送达和已读记录；中英文及时区差异、旧消息指向已处理申请。
- 未决：停用合约的提交／执行／重试依赖[停用合约影响（Q-M4B-01）](./v1.0-销毁审核与解除质押-PRD.md#Q-M4B-01)；文字上限与凭证格式、份数、大小依赖[填写与凭证边界（Q-M4B-02）](./v1.0-销毁审核与解除质押-PRD.md#Q-M4B-02)。
