# 企业登录与企业账户 · 消息通知

2026-10-29｜需求评审稿｜配套本模块[功能与业务规则](./v1.0-企业登录与企业账户-PRD.md)

本册逐项写明本模块发出的每类消息。消息的接收、展示、阅读、全部已读与前往规则，以及送达时效、同一件事只收一条、内容与语言等共同规则，由消息通知模块（M7）定义，见[来源接入要求（MSG-06）](./v1.0-消息通知-PRD.md#MSG-06)，本册不重复。

本模块只发 1 类站内消息，不发邮件。必发，用户不能关闭。

| 消息 | 端 | 分类 | 触发功能 |
| --- | --- | --- | --- |
| [认证失效通知（NT-C09）](#NT-C09) | 面客端 | 认证与合规 | [上游变化的同步（C-AUTH-06）](./v1.0-企业登录与企业账户-PRD.md#C-AUTH-06) |

以下情况不发送任何消息：登录与退出、登录失败、成为游客、登录到期；上游登录地址变更、上游账户锁定或禁用（这些情况直接结束登录并就地说明）；认证通过或恢复、一直未认证；资料或企业归属变化；数币账户的新增、编辑、删除。

<a id="NT-C09"></a>
## 认证失效通知（NT-C09）

依据：认证失效时通知企业，给本人发一条强制消息【确认】。

**识别与归属**

| 项目 | 规则 |
| --- | --- |
| 消息名称与事件编号 | 认证失效通知（NT-C09） |
| 发送来源 | 企业登录与企业账户（M1）；其他模块不发同义消息 |
| 端 | 面客端 |
| 分类 | 认证与合规 |
| 收件范围 | 本企业：认证失效前该企业用户所属的企业。每个企业只有一个登录地址，所以就是该企业用户本人。不发给其他企业、监管机构或运营 |

**触发与同一事实**

| 项目 | 规则 |
| --- | --- |
| 触发 | 本平台在调取时点确认企业用户由已认证变为未认证、并应用该变化时发送一次；以上游明确给出的当前有效认证结论为准。调取时点见[上游变化的同步（C-AUTH-06）](./v1.0-企业登录与企业账户-PRD.md#C-AUTH-06)。企业用户不在线时照常产生，登录后可见 |
| 不触发 | 首次登录时即未认证，或一直未认证；认证审核中但有效认证仍保留；认证通过或恢复；调取失败、超时、结论缺失或来源无法确认（异常不等于认证失效）；上游登录地址变更、账户锁定或禁用 |
| 同一事实的区分依据 | 本企业 + 认证失效 + 第几次失效。每一次从已认证变为未认证算一次：重复调取、刷新、重新登录都不新增；持续未认证期间不按天、登录或操作次数重复提醒；恢复认证后再次失效，是新的一条 |
| 合并规则 | 不合并 |
| 发生时间 | 本平台确认并应用这次认证失效的时间；不补记上游实际变更的更早时间 |

**内容与去向**

| 项目 | 规则 |
| --- | --- |
| 必须表达 | 认证状态已变更；代币发行等业务暂不可用；仍可查看用户信息、企业信息和消息；请前往资产可信平台查看当前认证状态 |
| 不得出现 | 证件号码、联系方式、钱包地址、认证材料、内部原因；不推测哪一项未通过 |
| 原业务识别信息 | 无。本消息不对应某一笔业务 |
| 打开后去哪 | 本端固定页面：本人的用户信息，见[查看用户信息与企业信息（C-PROFILE-01）](./v1.0-企业登录与企业账户-PRD.md#C-PROFILE-01)。不自动离开本平台；从那里前往资产可信平台仍须先确认 |
| 查看条件 | 该企业用户本人，已认证或未认证都能查看；游客和未登录不能查看 |

标题与正文（纯文本，没有动态变量）：

| 内容 | 简体中文 | English |
| --- | --- | --- |
| 标题 | 认证状态已变更 | Verification status changed |
| 正文 | 你的认证状态已变更，代币发行等业务暂不可用。你仍可查看用户信息、企业信息和消息。请前往资产可信平台查看当前认证状态。 | Your verification status has changed. Token issuance and other business actions are temporarily unavailable. You can still view your user information, company information and messages. Visit the Asset Trust Platform to check your current verification status. |

**与业务限制的关系**

- 业务限制在确认认证失效时立即生效，不等待消息送达；消息发送失败也不恢复业务资格。
- 读过这条消息不代表认证已恢复；认证恢复也不删除或改写这条消息。
- 能否办理业务始终按当前认证结论判断，见[认证资格与受限引导（C-AUTH-04）](./v1.0-企业登录与企业账户-PRD.md#C-AUTH-04)。
