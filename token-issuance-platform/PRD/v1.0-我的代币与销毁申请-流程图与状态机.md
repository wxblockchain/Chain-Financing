<a id="fig-1"></a>
## 企业查看与返回（图 1）

```mermaid
flowchart TD
    A[我的代币列表 或关联业务入口] --> B{当前身份及企业权限有效}
    B -->|否| C[登录或受限引导 不返回业务数据]
    B -->|是| D{代币读取结果}
    D -->|失败| E[说明读取失败 可重试]
    E --> D
    D -->|尚无代币| F[暂无铸造成功代币 可前往代币发行]
    D -->|成功| G[查看本企业代币与状态]
    G --> H[对应代币详情]
    H --> I[关联可信资产或发行申请]
    I --> H
    H --> J[该代币的销毁申请]
    J --> H
    H --> K[返回来源列表或原业务]
```

关联对象无权或不存在时，统一说明暂不可访问；读取依赖信息失败不等于代币不存在。字段未知时保留可查内容，资格不放行。

<a id="fig-2"></a>
## 校验与提交销毁申请（图 2）

```mermaid
flowchart TD
    A[查看选定代币] --> B{已销毁或已有处理中申请}
    B -->|是| C[查看原申请或结果 不能重复发起]
    B -->|否| D{已到期 已结清 双重无融资质押}
    D -->|不满足或无法确认| E[说明全部已知限制或缺失依据]
    E --> A
    D -->|满足| F[核对代币 资产 数量 地址 合约及后续流程]
    F -->|取消或离开| A
    F -->|提交| G{重新核对身份与全部资格}
    G -->|变化或无法确认| H[本次未提交 说明当前限制]
    H --> A
    G -->|通过| I{实际提交结果}
    I -->|已有处理中申请| C
    I -->|成功| J[产生待运营审核申请 代币进入销毁申请中]
    J --> K[向全体运营发送新的销毁申请消息]
    J --> L[查看本次申请 或返回我的代币]
    I -->|明确未成功| M[说明未完成 可重新校验后重试]
    M --> G
    I -->|尚未确认| N[获取本次实际结果 不重复生成申请]
    N --> I
```

融资两项结果均无质押才满足；任一有质押或两项不一致都不放行，任一未知也不放行。平台停用不阻断既有代币按原条件提交销毁或后续办理，仍使用原合约，见[停用与既有业务](./v1.0-合约管理-PRD.md#inflight)。

<a id="fig-3"></a>
## 销毁申请状态与解除监管（图 3）

```mermaid
stateDiagram-v2
    state "待运营审核" as Review
    state "驳回" as Rejected
    state "销毁中" as Burning
    state "销毁失败" as Failed
    state "销毁成功" as Burned
    state "待解除监管" as ReleasePending
    state "已解除监管" as Released
    [*] --> Review: 企业本次提交成功
    Review --> Rejected: 运营驳回并留意见
    Rejected --> [*]: 本次申请结束
    Review --> Burning: 运营审核通过
    Burning --> Failed: 销毁失败
    Failed --> Burning: 运营手动重试
    Burning --> Burned: 销毁成功结果确认
    Burned --> ReleasePending: 承接原监管机构解除事项
    ReleasePending --> Released: 原监管机构完成解除并留记录
    Released --> [*]
```

- 待解除监管、已解除监管分别对应简报的待解除资产质押、已解除质押；名称按用户后续确认映射。
- 销毁成功后即使当前进度已进入待解除监管，成功事实仍保留。
- 失败或未知结果不进入销毁成功；失败等待运营处理仍占用原申请，企业不能重新申请。
- 企业从驳回记录再次发起时，先重新校验并创建新申请，新申请从待运营审核开始；原申请仍为驳回。新旧记录用不同申请编号关联同一代币；驳回释放占用后按当前融资事实回退，未知时不放行，按 M4b [状态对应](./v1.0-销毁审核与解除质押-PRD.md#states)，不在同一状态机把驳回恢复成待审。
- 解除办理未成功或结果尚未确认时，不展示已解除监管，不替 M4b 增加失败终态或重试策略。

## 代币、融资与监管的关系（图 4）

```mermaid
flowchart TD
    A[铸造成功的本企业代币] --> B[监管由原所选机构承接]
    A --> C{当前融资情况}
    C -->|无融资质押| D[正常 未融资]
    C -->|有融资质押| E[融资中]
    D -->|下游发生融资质押| E
    E -->|下游及链上均确认无融资质押| D
    D --> F{到期 已结清 且无其他处理中申请}
    F -->|满足并提交成功| G[销毁申请中]
    G --> H{申请处理结果}
    H -->|驳回| I[原申请保留驳回 代币重新判断当前资格]
    I --> C
    H -->|待审 销毁中 或失败待重试| G
    H -->|销毁成功| J[代币已销毁]
    J --> K[仍由原机构监管 等待解除]
    B -.-> K
    K -->|监管机构完成解除| L[已解除监管]
```

融资与监管是独立信息；监管中不阻断满足条件的销毁，已销毁不等于监管已经解除。已销毁是代币终态，不能回到可申请。组合展示及未知信息以[功能册的资格组合](./v1.0-我的代币与销毁申请-PRD.md#C-TOKEN-03)为准。
