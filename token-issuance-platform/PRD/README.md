# 代币发行平台 · PRD

本目录存放代币发行平台的产品需求文档。各模块按 01 功能与业务规则、02 流程图与状态机、03 消息通知（仅自身发送消息时）、04 验收阅读；缺少 03 表示该模块自身不发消息。

## 目录约定

```
PRD/
├─ README.md
├─ 面客端/        只在企业端使用的模块
├─ 管理端/        只在管理端（运营、机构）使用的模块
└─ 两端共用/      同一套规则同时覆盖企业端与管理端的模块
```

- 模块目录以 PRD 模块号开头，命名为「模块号-模块名」，与[页面原型](../页面原型/README.md)的模块号一致，例如 `面客端/M1-企业登录与企业账户/`。
- 目录内文件以册号开头，命名为「册号-模块名-用途.md」，例如 `01-企业登录与企业账户-PRD.md`。册号固定，缺册不顺延。
- 一个模块号下有两套独立规则时，各占一个目录，模块号相同，例如 `管理端/M5-管理端登录与权限/` 与 `管理端/M5-机构管理/`。
- 两端共用的模块只有一套规则，放在 `两端共用/`；原型仍按端各一个目录，例如 M2 可信资产的原型分别在 `页面原型/面客端/M2-可信资产/` 与 `页面原型/管理端/M2-可信资产/`。
- 新模块交付时按所属端放入对应目录，并在下表增加一行。
