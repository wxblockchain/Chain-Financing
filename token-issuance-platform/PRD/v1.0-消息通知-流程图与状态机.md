## 一条消息从业务节点生效到收件人看到（图 1）

```mermaid
flowchart TD
    A["业务节点在来源模块真正生效"] --> B{"该节点在消息通知册中有对应事件?"}
    B -->|否| B1["不发消息"]
    B -->|是| C{"能确定收件人?"}
    C -->|否| C1["不发送，不改发给全体运营或其他机构"]
    C -->|是| D{"同一收件人已收到过同一事实?"}
    D -->|是| D1["保留原消息：不新增、不改顺序、不变回未读"]
    D -->|否| E["新增一条消息，对收件人为未读"]
    E --> F{"收件人"}
    F -->|某个企业| G["该企业在面客端可见"]
    F -->|某个监管机构| H["该机构在管理端可见"]
    F -->|全体运营| I["每位运营管理人员可见，各自记录已读"]
```

监管机构邀请邮件不走本图，见图 5。

## 发行流程中的消息（图 2）

```mermaid
flowchart TD
    A["企业提交发行申请成功<br/>待监管审核"] --> M1(["监管机构：新的待审申请 NT-R01"])
    A --> B{"监管一审"}
    B -->|驳回| C["监管驳回，申请终止"]
    C --> M2(["企业：监管审核驳回 NT-C02"])
    B -->|通过并上传协议| D["待运营审核"]
    D --> M3(["企业：监管审核通过 NT-C01"])
    D --> M4(["全体运营：待二审的申请 NT-A01"])
    D --> E{"运营二审"}
    E -->|驳回| F["运营驳回，申请终止"]
    F --> M5(["企业：运营审核驳回 NT-C04"])
    E -->|通过并选择合约| G["铸造中"]
    G --> M6(["企业：运营审核通过 NT-C03"])
    G --> H{"链上铸造结果"}
    H -->|成功| I["铸造成功，资产进入监管质押"]
    I --> M7(["企业：铸造成功 NT-C05"])
    H -->|失败| J["铸造失败"]
    J --> M8(["全体运营：铸造失败待重试 NT-A03<br/>每次失败一条"])
    J -->|运营手动重试| G
```

运营重试铸造不再发送“运营审核通过”。企业不收铸造失败消息。

## 销毁与解除质押流程中的消息（图 3）

```mermaid
flowchart TD
    A["企业发起销毁申请成功<br/>待运营审核"] --> M1(["全体运营：新的销毁申请 NT-A02"])
    A --> B{"运营销毁审核"}
    B -->|驳回| C["驳回"]
    C --> M2(["企业：销毁申请驳回 NT-C07"])
    C -->|满足条件时企业再次发起| A
    B -->|通过| D["销毁中"]
    D --> E{"链上销毁结果"}
    E -->|失败| F["销毁失败"]
    F --> M3(["全体运营：销毁失败待重试 NT-A04<br/>每次失败一条"])
    F -->|运营手动重试| D
    E -->|成功| G["销毁成功，待解除资产质押"]
    G --> M4(["企业：销毁成功 NT-C06"])
    G --> M5(["铸造时的监管机构：代币已销毁、待解除质押 NT-R02"])
    G --> H["监管机构在平台上解除质押并留记录"]
    H --> I["已解除质押"]
    I --> M6(["企业：资产已解除质押 NT-C08"])
```

再次发起的销毁申请是新的一笔，再次发送“新的销毁申请”。

```mermaid
flowchart TD

    F -->|是| G["对本人自动变为已读，未读数减少"]
    G --> H{"该类消息设有去向?"}
```

## 本人阅读状态（状态机 1）

```mermaid
stateDiagram-v2
    [*] --> 未读: 消息产生
    未读 --> 已读: 本人打开详情且展示成功
    未读 --> 未读: 详情加载失败或已读保存失败
    已读 --> 已读: 再次打开或同一事实重复送达
```

- 已读是终态，本期没有“标为未读”。
- 状态属于“本人与这条消息”：全体运营消息对每位运营管理人员各有一份阅读状态。
- 运营账号开通前已存在的全体运营消息，对新账号直接为已读，不计入未读数。
