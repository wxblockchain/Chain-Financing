# 我的代币与销毁申请 · 验收

2026-11-06｜需求评审稿｜供测试使用

本册只列验收标准，测试用例与执行步骤由测试小队编写。以[01 功能与业务规则](./01-我的代币与销毁申请-PRD.md)和本册验收，原型仅用于核对布局。

共 42 条验收，有效编号为 AC-M4A-01～25、28～44；AC-M4A-26～27 随已取消的运营驳回流程停用，不重新分配。每条名称放在前提中，表格只有前提、操作、预期结果三列；一条含多个场景时，所有场景都满足才算通过。

## 0. 验收前准备

- 账号：企业 A、企业 B 的已认证用户；未认证企业用户、游客、未登录身份；同一企业变更前后的登录地址；两个运营账号及原监管机构、其他监管机构。
- 钱包：当前地址分别为登录地址、代币铸造到账地址、后续受让地址及其他地址；当前网络为 Ethereum、为其他网络；可取消或拒绝签名；包含当前登录地址与铸造到账地址相同、不同的代币，以及企业无法控制铸造到账地址的样本。
- 链上记录：可读取销毁交易写入链上的内容，用于核对签名值与本次申请授权标识是否上链；包含直接执行成功、结果未确认和确认失败的样本。
- 代币：成功铸造、铸造尚未成功、已销毁；铸造后企业登录地址变化；合约名称变化；合约停用。已铸造样本包含完整数量超过两位小数的代币、代币符号 cou 及其图标、应收账款原值、铸造初始单位价值、与初始值不同的当前单位价值、当前资产估值、完整地址、关联资产及发行申请；至少两枚同为 Ethereum、cou 的代币；一个暂无对应图标的代币符号；铸造时间不同的多枚代币；原发行申请含多份监管协议文件，以及协议查看或下载失败的情况。
- 链上持有：未质押（质押地址为空）、质押中（有质押地址）、解除质押后回到原持有地址、融资违约后留在质押合约地址、质押地址与下游融资结果不一致、链上查询失败、持有地址不是铸造到账地址、已销毁。
- 资格：未到期但已结清、恰好到期且已结清、已到期未结清、逾期后结清；下游与链上无质押、有质押、相互不一致、任一或两项未知；身份或结清依据获取失败。
- 申请：无记录、销毁中、销毁失败、销毁成功、等待解除监管、解除完成；同一代币有一笔失败申请及一笔重新发起的新申请；有未使用、已使用、已失效及属于其他企业或其他提交的本次申请授权标识；提交结果未确认、读取失败、越权和不存在对象。
- 风险暂停：平台暂停新的销毁申请、恢复新的销毁申请；暂停前已进入确认或签名但尚未提交成功，以及已有销毁中、销毁失败和完成申请。
- 消息：同一提交重复送达、已读后重取、失败后新申请成功；中英文和不同时区。
- 配套依据：M4b [两端衔接字段清单](../../管理端/M4b-销毁审核与解除质押/01-销毁审核与解除质押-PRD.md#handoff)；平台停用与实际链上异常须有可区分的样本。

## 2. 代币详情

对应功能：[代币详情（C-TOKEN-02）](./01-我的代币与销毁申请-PRD.md#C-TOKEN-02)。

| 前提 | 操作 | 预期结果 |
| --- | --- | --- |
| <a id="AC-M4A-05"></a>铸造结果与当前价值承接（AC-M4A-05）：本企业已有完整数量超过两位小数、当前单位价值已调整的成功代币 | 从我的代币或关联资产、发行申请进入详情 | 发行数量可核对与原铸造结果一致的完整数量，单位为原合约的代币符号，不显示为 USD；应收账款原值与原资产一致；铸造初始单位价值不被后续调价改写；当前单位价值按“1 COU = X USD”展示并与最近一次链上成功值一致，当前资产估值按发行数量乘当前单位价值计算；到期时点、铸造到账地址、合约与原铸造结果一致；关联入口定位正确，可返回来源；以唯一代币编号与原发行申请、链上实际代币和合约固定对应，按 M4b 代币清单验收 |
| <a id="AC-M4A-06"></a>地址与名称变化（AC-M4A-06）：铸造后企业登录地址或合约名称改变 | 同一企业用新登录地址查看既有代币，并尝试申请销毁 | 仍可看见本企业历史，合约名取当前值；企业账户只展示新登录地址，原铸造到账地址不作为其他账户保留，但代币记录中的地址、合约身份及销毁发起权不变；不因两个地址不一致而拒绝查看，提交销毁时仍须由原铸造到账地址签名，新登录地址不能替代 |
| <a id="AC-M4A-07"></a>语言、时区与状态独立（AC-M4A-07）：有带时区到期日、融资与监管记录 | 切换中文、英文及时区，查看列表、详情 | 字段、状态支持中英文，原文意见等不翻译；时间换算但到期判断和业务事实不变；融资、监管、结清及销毁分别表达，不把监管当融资质押 |
| <a id="AC-M4A-08"></a>关联与会话边界（AC-M4A-08）：关联对象不可访问，或退出、切换钱包、有效企业归属变化 | 查看关联对象或返回业务 | 不可访问时保留返回路径；退出或身份变化不残留旧企业数据，迟到结果不显示旧企业内容 |
| <a id="AC-M4A-33"></a>详情最上方的识别信息（AC-M4A-33）：两枚同为 Ethereum、cou 的代币，其中一枚有多笔销毁申请；另有暂无对应图标的代币符号 | 分别查看代币详情和申请详情的最上方 | 代币详情最上方有所属网络、代币图标与代币符号、代币编号，网络、图标与符号优先于编号；申请详情最上方有所涉代币的网络、图标与符号，以及销毁申请编号和当前阶段，网络、图标与符号优先于编号；两处编号都不省略，能区分同符号代币与同一代币的不同申请；暂无图标时只展示代币符号，其余信息与可办理动作不受影响 |
| <a id="AC-M4A-34"></a>点击编号前往详情（AC-M4A-34）：代币有关联资产、原发行申请与多笔销毁申请；其中一个关联对象不可访问 | 在我的代币列表、代币详情、销毁申请列表、申请详情中点击各编号，再返回 | 代币编号进入代币详情，销毁申请编号进入对应申请详情，资产编号进入可信资产详情，发行申请编号进入原发行申请详情；不出现“查看发行申请”等前往其他对象的文字入口；列表操作列的“查看”进入本行对象自己的详情；当前所在详情的编号不指向自身，申请销毁的确认环节编号不可前往；目标不可访问时说明原因并可返回原页面；数币地址与合约地址不跳转 |
| <a id="AC-M4A-36"></a>发行时间与监管协议（AC-M4A-36）：本企业成功代币，原发行申请含多份监管协议；另有协议查看或下载失败、已解除监管的代币 | 查看代币详情的代币发行信息与监管信息，查看并下载协议 | 代币发行信息展示发行时间（铸造成功时间），并作为监管开始时间；展示原监管机构上传的全部协议，每份有原文件名称与上传时间，可单独查看和下载，与发行申请中的为同一份文件；企业不能上传、替换或删除；失败时说明本次未能打开并可重试，其余信息正常；不展示铸造交易哈希，也不展示解除监管的操作人、备注或凭证 |
| <a id="AC-M4A-39"></a>持有信息与融资状态（AC-M4A-39）：未质押、质押中、质押地址与下游结果不一致、链上查询失败、持有地址不是铸造到账地址、已销毁的代币各一枚 | 查看代币详情的持有信息和我的代币列表，并尝试申请销毁 | 持有信息以列表呈现，列为持有地址、质押地址、持有数量和融资状态，不展示账户备注名或登录地址标识，只有一条记录时也按列表展示，并展示链上查询时间；未质押时质押地址为空、融资状态为未融资；质押中同一行显示持有地址和质押地址、融资中，列表的持有地址仍为本企业持有地址；不一致时说明融资结果不一致并按有质押处理；查询失败时说明暂时无法获取并可重试，不用铸造到账地址代替，也不显示未融资；持有地址不是铸造到账地址时如实展示，说明代币不在原地址、请联系平台，不能申请销毁；解除质押后同一行回到原持有地址、质押地址为空、融资状态为未融资；已销毁时说明已销毁、没有持有记录，我的代币列表中该代币的持有地址为空，不用铸造到账地址代替；列表不展示质押地址和融资状态 |
| <a id="AC-M4A-41"></a>违约代币不能申请销毁（AC-M4A-41）：融资违约后代币留在质押合约地址，已到期、上游已结清、无处理中申请 | 查看我的代币列表和代币详情，并直接提交申请销毁 | 列表不出现“申请销毁”；持有信息同一行展示原持有地址和质押合约地址，融资状态按下游结果展示，不出现本模块自行增加的违约状态；详情说明代币仍在质押地址、不能申请销毁；绕过界面直接提交被拒绝，不产生申请、不发消息；融资状态只出现未融资或融资中，不出现违约标识；监管信息为监管中，没有解除监管结果 |
| <a id="AC-M4A-40"></a>代币发行信息与关联业务分开（AC-M4A-40）：本企业成功代币，之后经历单位价值调整、质押与解除质押、账户改备注名、登录地址变更、合约改名 | 查看代币详情各分区 | 代币发行信息展示代币编号、所属网络与代币类型、发行人、发行数量、应收账款原值、铸造初始单位价值、当前单位价值、当前资产估值、到期日、发行时间、铸造到账地址、所属合约和监管机构；单位价值调整只更新当前单位价值和当前资产估值，不改写发行数量、应收账款原值与铸造初始单位价值；质押、解除质押和登录地址变化不改变发行事实，合约名称取当前值；关联资产和发行申请编号在发行关联业务中，监管协议在监管信息中，不出现在代币发行信息里 |

| <a id="AC-M4A-09"></a>全部条件满足（AC-M4A-09）：原发行企业身份有效，已到期、上游已结清，下游明确无融资质押，链上显示代币完整位于铸造到账地址且质押地址为空，无处理中申请且未销毁 | 查看可办理动作并申请销毁 | 可以进入确认并由铸造到账地址完成一次钱包业务签名后提交；监管中不额外阻断，历史曾逾期不额外阻断 |
| <a id="AC-M4A-10"></a>到期边界与提前结清（AC-M4A-10）：未到期已结清、恰好到期已结清、已到期未结清 | 查看资格 | 未到期不能申请销毁；恰好到期在其他条件齐备时满足到期条件；未结清不能申请销毁；不同查看时区得到相同资格结论 |
| <a id="AC-M4A-11"></a>融资与持有结果判断（AC-M4A-11）：下游与链上共同满足、任一明确有融资质押或地址不满足、两者互相矛盾、任一必要结果未知 | 查看融资与持有条件及申请结果 | 只有下游明确无融资质押，且链上确认代币完整位于铸造到账地址、质押地址为空时通过；任一明确限制直接阻断，另一来源同时显示无融资质押时一并说明不一致并提示联系平台；没有明确限制但任一结果未知时说明无法确认并阻断，不当作确定无质押 |
| <a id="AC-M4A-12"></a>缺失与多重限制（AC-M4A-12）：未到期、未结清、有质押、持有地址不是铸造到账地址可同时出现；到期、结清或链上持有信息取不到 | 查看详情及尝试申请销毁 | 说明全部已知不满足原因及无法确认的依据；不能按余额为零或已有回款推断结清；旧值不放行新提交 |
| <a id="AC-M4A-13"></a>处理中与成功防重（AC-M4A-13）：分别有销毁中、销毁失败、成功待解除及已解除申请 | 申请销毁或直接提交 | 销毁中定位原申请，不生成新申请；销毁失败在重新满足当前资格后可新建申请；销毁成功后无论监管是否解除都不能再次销毁 |
| <a id="AC-M4A-42"></a>风险期间暂停新的销毁申请（AC-M4A-42）：平台暂停新的销毁申请，包含尚未进入申请、已进入确认或签名但未提交成功、已有销毁中／销毁失败／完成申请；之后平台恢复 | 查看代币与既有申请，尝试新申请；恢复后再次申请 | 暂停期间不产生新申请，未提交成功的授权失效；已有记录和已确认进度可查，不回滚或改阶段；运营没有审核、驳回或重试动作；恢复后重新校验当前资格，并取得新授权和新签名 |

## 4. 申请销毁

对应功能：[申请销毁（C-BURN-01）](./01-我的代币与销毁申请-PRD.md#C-BURN-01)。

| 前提 | 操作 | 预期结果 |
| --- | --- | --- |
| <a id="AC-M4A-14"></a>申请销毁的确认与取消（AC-M4A-14）：可申请销毁的本企业代币 | 从列表或详情点击“申请销毁”，核对后取消或离开 | 只读展示本次销毁的代币、数量、价值、持有地址及到期日；说明提交后由平台直接执行销毁、无运营审核、之后由原监管机构解除监管、提交后不能撤回，且须由铸造到账地址签名；取消不产生申请、不改状态、不发消息、不保存签名 |
| <a id="AC-M4A-15"></a>提交时重新校验（AC-M4A-15）：确认后身份、认证、企业归属或融资条件改变，或依赖获取失败 | 提交 | 按当前身份与资格限制，不能用先前结果放行，不产生成功申请；显示当前原因，身份变化按 M1 处理 |
| <a id="AC-M4A-16"></a>成功提交与对应结果（AC-M4A-16）：所有条件符合且无同代币销毁中申请，原代币完整数量超过两位小数 | 用该代币铸造到账地址完成一次钱包业务签名后提交，并查看结果 | 平台核对签名地址、完整数量和本次申请授权标识后，只生成一笔申请并立即进入销毁中；平台自动完成交易签名和提交，不要求企业第二次签名，不等待运营审核；生成唯一申请编号和提交时间，使用完整数量与代币符号，占用本次授权标识；向运营发送知会而非待审任务 |
| <a id="AC-M4A-17"></a>重复与结果未确认（AC-M4A-17）：重复点击、并发提交、刷新结果、本次结果暂未确认 | 再次触发提交或重新获取实际结果 | 同一代币至多一笔处理中的申请；已有申请则定位原申请；未确认时不虚报成功或失败、不生成新授权标识、不因重试新增申请；明确失败且未产生申请时，原授权失效，可重新校验、取得新授权并重新签名提交 |
| <a id="AC-M4A-37"></a>发行企业与铸造到账地址独占销毁发起权（AC-M4A-37）：可申请销毁的代币；登录地址与铸造到账地址相同或不同；非发行企业尝试发起；代币转给受让地址后又转回；原申请失败后重新发起 | 分别以铸造到账地址、登录地址、受让地址签名提交，并核对销毁交易 | 只有原发行企业可发起，且只有铸造到账地址签名可提交；代币转让或质押在外时不可发起，回到铸造到账地址且其他条件齐备后可申请；签名与授权写入销毁交易并由合约验证；失败后的新申请必须使用新授权和新签名，不存在运营重试 |
| <a id="AC-M4A-38"></a>签名或本次申请授权未完成、未通过（AC-M4A-38）：钱包当前地址不是本代币铸造到账地址、不在 Ethereum 网络；企业无法控制铸造到账地址、取消或钱包拒绝签名；签名无效、签名地址或内容不符；授权标识已使用、已失效、属于其他企业或其他提交；签名后身份、登录地址、资格改变或必要结果无法确认；签名记录读取失败 | 提交并完成或中断签名；复用旧授权或签名直接提交；查看申请详情 | 地址或网络不符时提示切换后重试，不接受当前登录地址、受让地址或其他地址代签；无法控制铸造到账地址时不能提交且没有替代发起人；取消、拒绝、核对不通过或授权不可用时说明未完成，不产生申请、不改状态、不发消息；取消或拒绝、离开后重新进入、身份或登录地址变化、资格变化、暂停新申请、核对不通过及明确提交失败均使原授权失效；重新提交须取得新授权并重新签名；已使用或不属于本次提交的授权及其签名不能复用；提交结果未知时先取原结果，不生成新授权；签名记录读取失败时可重试，不影响申请其他信息 |
| <a id="AC-M4A-18"></a>停用合约后的销毁继续（AC-M4A-18）：已铸造代币原合约被平台停用 | 在满足原条件时申请销毁，跟踪执行、失败后新申请及解除监管 | 既有代币可按原条件提交，平台直接执行，无需运营审核；原合约、数量及地址不变；失败结束本笔申请，企业重新满足条件后以新授权和新签名新建申请；不提供运营手动重试 |
