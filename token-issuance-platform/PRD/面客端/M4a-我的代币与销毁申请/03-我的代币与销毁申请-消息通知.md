本模块自身发送一类站内消息：[销毁已发起知会（NT-A02）](#NT-A02)，必发，用户不能关闭；不发送邮件。本事件由本册维护。接收、展示、已读、语言与前往的共同要求按[消息来源接入要求（MSG-06）](../../两端共用/M7-消息通知/01-消息通知-PRD.md#MSG-06)执行；发生后 60 秒内可见的已确认要求沿用[送达时效](../../两端共用/M7-消息通知/01-消息通知-PRD.md#delivery-time)。

## 销毁已发起知会（NT-A02）

| 项目 | 规则 |
| --- | --- |
| 发送来源 | 我的代币与销毁申请（M4a）唯一负责发送；其他模块不发同义消息 |
| 所在功能 | [申请销毁（C-BURN-01）](./01-我的代币与销毁申请-PRD.md#C-BURN-01)；[销毁失败后重新发起（C-BURN-05）](./01-我的代币与销毁申请-PRD.md#C-BURN-05)生成新申请时复用同一事件 |
| 触发 | 企业实际提交成功，生成新销毁申请并进入销毁中时发送一次，发生时间取本次提交成功时间 |
| 不触发 | 未提交、签名未通过、已确认提交失败；仅查看、刷新或重复提交只定位已有申请 |
| 收件人 | 管理端全体运营管理人员，各自记录已读；不发给企业、监管机构或游客 |
| 分类 | 业务办理进度 / Business progress |
| 必须包含 | 销毁申请编号、企业名称、资产编号、申请销毁的完整代币数量及代币符号、提交时间、平台已开始执行销毁的说明 |
| 打开后去哪 | 管理端 M4b 该笔[销毁记录详情（A-BURN-02）](../../管理端/M4b-销毁审核与解除质押/01-销毁审核与解除质押-PRD.md#A-BURN-02)；仅查看当前记录，不提供审核、驳回或重试动作 |
| 当前权限与状态 | 运营有权时查看当前结果；本消息只是知会，不产生待办、不要求运营处理 |
| 同一事实 | 同一笔申请的这次成功提交只产生一条；重复送达、结果重取、刷新或重新登录不新增，也不重置已读 |
| 新事实 | 销毁失败后，企业重新满足条件并成功生成新申请，是新的提交事实，另发一条；原消息保留 |
| 内容边界 | 业务值取本次提交事实；不含完整钱包地址、钱包签名、联系方式、凭证原件或下载地址 |

### 中文与英文内容

| 内容 | 中文 | English |
| --- | --- | --- |
| 标题 | 销毁已发起 | Token burn initiated |
| 正文 | 企业 {企业名称} 已发起销毁申请 {销毁申请编号}。资产：{资产编号}；代币数量：{代币数量} {代币符号}；提交时间：{提交时间}。平台已开始执行销毁，请知悉。 | {企业名称} has initiated token burn application {销毁申请编号}. Asset: {资产编号}; token quantity: {代币数量} {代币符号}; submitted at: {提交时间}. Platform execution has started. For your information. |

动态值取本次提交成功的申请记录，时间以查看者当前时区展示；业务事实不因后续进度变化改写。

## 本模块不负责发出的消息

销毁成功、销毁失败、解除监管结果及监管待办由 M4b 的[消息通知册](../../管理端/M4b-销毁审核与解除质押/03-销毁审核与解除质押-消息通知.md)维护；企业在 M4a 查看当前进度，不因访问本模块而重新发送结果消息。
