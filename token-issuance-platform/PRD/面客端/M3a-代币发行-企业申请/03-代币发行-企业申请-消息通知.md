# 代币发行 · 企业申请 · 消息通知

2026-11-04｜需求评审稿｜配套本模块[功能与业务规则](./01-代币发行-企业申请-PRD.md)

本册逐项写明本模块发出的每类消息。消息的接收、展示、阅读、全部已读与前往规则，以及送达时效、同一件事只收一条、内容与语言等共同规则，由消息通知模块（M7）定义，见[来源接入要求（MSG-06）](../../两端共用/M7-消息通知/01-消息通知-PRD.md#MSG-06)，本册不重复。

本模块只发 1 类站内消息，不发邮件。必发，用户不能关闭。

| 消息 | 端 | 分类 | 触发功能 |
| --- | --- | --- | --- |
| [新的待审申请（NT-R01）](#NT-R01) | 管理端 | 审核任务 | [确认并提交申请（C-ISSUE-04）](./01-代币发行-企业申请-PRD.md#C-ISSUE-04) |

以下情况不发送任何消息：企业提交发行申请时给企业本人和运营；提交不成功、离开或取消；查看申请列表、申请详情和监管协议。发行申请提交之后的审核、铸造结果消息由代币发行·审核与铸造（M3b）发送，打开后进入本模块的[申请详情（C-ISSUE-06）](./01-代币发行-企业申请-PRD.md#C-ISSUE-06)。

<a id="NT-R01"></a>
## 新的待审申请（NT-R01）

依据：监管机构需知道有新的待审申请【建议·已采纳】（简报 4.5）；站内消息为主（BR-24）【确认】；监管机构只能看到本机构的申请（BR-15）【确认】。

**识别与归属**

| 项目 | 规则 |
| --- | --- |
| 消息名称与事件编号 | 新的待审申请（NT-R01） |
| 发送来源 | 代币发行·企业申请（M3a）；其他模块不发同义消息 |
| 端 | 管理端 |
| 分类 | 审核任务 |
| 收件范围 | 本机构：这笔申请所选的监管机构。不发给其他监管机构、运营或企业 |

**触发与同一事实**

| 项目 | 规则 |
| --- | --- |
| 触发 | 企业提交发行申请成功、申请进入“待监管审核”时发送一次 |
| 不触发 | 提交不成功（包括未完成签名或签名未通过核对，认证、资产条件、监管机构或接收账户核对未通过，保存失败），此时不发送；离开或取消 |
| 同一事实的区分依据 | 本机构 + 申请编号 + 提交。一笔申请只有一次提交，只发一条；重复送达、刷新不新增 |
| 合并规则 | 不合并 |
| 发生时间 | 申请提交成功的时间 |

**内容与去向**

| 项目 | 规则 |
| --- | --- |
| 必须写明 | 企业名称（提交时的企业名称）；申请编号；资产编号；资产价值（含币种）；提交时间；需要进行一审 |
| 不得出现 | 企业的接收账户地址、登录地址；企业用户的个人信息 |
| 原业务识别信息 | 申请编号、资产编号 |
| 打开后去哪 | 原业务：M3b 的该笔[申请详情（R-ISSUE-02）](../../管理端/M3b-代币发行-审核与铸造/01-代币发行-审核与铸造-PRD.md#R-ISSUE-02)，按当前状态展示可做的操作；待监管审核时可以办理一审，已完成一审时查看当前进度与结果，不重复办理 |
| 查看与办理条件 | 该监管机构账号正常、已登录、已完成首次登录强制改密；查看与办理一审的条件按 M3b 的[谁能使用](../../管理端/M3b-代币发行-审核与铸造/01-代币发行-审核与铸造-PRD.md#access)及[数据范围（F-LG-11）](../../管理端/M5-管理端登录与权限/01-管理端登录与权限-PRD.md#F-LG-11)。机构在提交后被停用，仍可查看本机构的申请并办理待监管审核的申请，见[停用与启用（F-RG-05）](../../管理端/M5-监管机构管理/01-监管机构管理-PRD.md#F-RG-05) |

标题与正文（纯文本；花括号内为动态值，取事件发生时的值）：

| 内容 | 简体中文 | English |
| --- | --- | --- |
| 标题 | 有新的发行申请待审核 | New issuance application to review |
| 正文 | {企业名称} 提交了代币发行申请 {申请编号}，资产 {资产编号}，资产价值 {资产价值}，提交时间 {提交时间}。请进行一审。 | {企业名称} submitted token issuance application {申请编号} for asset {资产编号} with an asset value of {资产价值}, at {提交时间}. Please complete the first review. |

动态值：

| 动态值 | 含义 |
| --- | --- |
| 企业名称 | 提交申请的企业名称，按上游原文展示，不翻译 |
| 申请编号 | 提交成功时生成的申请编号 |
| 资产编号 | 申请所用资产的资产编号 |
| 资产价值 | 申请所用资产的资产价值，即应收账款金额与币种，按两位小数展示，例如 50,000.00 USD |
| 提交时间 | 申请提交成功的时间，按收件人当前所选时区展示 |

**与业务的关系**

- 申请提交成功即生效，不等待消息送达；消息发送失败也不撤销申请。
- 读过这条消息不代表已审核；审核在 M3b 的申请详情中完成。
