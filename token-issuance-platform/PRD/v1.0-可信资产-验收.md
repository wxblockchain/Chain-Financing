# 可信资产 · 验收

2026-10-30｜需求评审稿｜供测试使用

本册只写验收标准，测试用例与执行步骤由测试小队编写。规则见[功能与业务规则](./v1.0-可信资产-PRD.md)，各节顺序与功能册一致。

怎么读：

- 共 39 条验收。编号沿用原值，已删除的条目不再占号，所以编号不连续，缺号不代表遗漏。
- 一条验收写了多个场景时，全部场景都满足才算通过。

## 0. 验收前准备

账号：

- 企业 A、企业 B：两个已认证的企业用户，分属注册在不同国家 / 地区的企业。
- 一个未认证的企业用户；一个游客（已用钱包登录、但在上游没有匹配账户的地址）。
- 运营管理人员一个。
- 监管机构 C：有本机构关联的发行申请，覆盖待监管审核、本机构驳回、运营驳回、铸造成功等申请状态。
- 监管机构 D：没有任何关联申请。

数据（均在上游平台或下游借贷平台准备，同步到本平台）：

- 企业 A 的资产，覆盖全部发行状态：可发行、发行申请中（含铸造中、铸造失败待重试）、已驳回（监管驳回与运营驳回各一笔）、已发行（含对应代币处于融资中、销毁申请中、已销毁的各一笔）。
- 企业 A 的可发行、USD、L1 完整的资产：未到期、已逾期、已结清、先逾期后结清各一笔；一笔到期日已过但上游未提供最新状态的资产；一笔上游到期时点与测试账号所选时区不在同一天的资产（例如上游到期时点为 UTC+4 的 3 月 31 日 23:30，查看者选 UTC+8）。
- 企业 A 的一笔未确权应收账款；一笔可发行后被上游撤销确权的资产；一笔被上游删除的资产。
- 企业 A 的一笔非 USD 计价、L1 完整、未到期的可发行资产；一笔缺少 L1 字段（例如缺确权日期）的资产；一笔没有销售发票的资产；一笔 L2 字段全部缺失、L1 完整、未到期的 USD 资产；一笔没有采购账款的资产。
- 一笔有多条标的物明细的资产；一笔有多条回款记录（每条带支付凭证）的资产；一笔有多张销售发票的资产；一笔没有回款记录的资产；一笔结清状态或逾期状态取不到的资产。
- 带全部材料文件的资产；一个无法打开的材料文件。
- 企业 B 的资产若干。
- 企业 A 的数币账户：登录地址这一条，加企业新增的账户至少一个；一个已被企业删除的账户。
- 上游平台可模拟暂时不可用；可在上游修改资产的回款信息与状态。
- 测试账号可在中文、英文两种界面语言和不同时区之间切换；一笔上游同时提供企业中文名称和英文名称的资产。
- 资产筛选样本：编号只有部分字符相同的不同资产；债权人、债务人的中文与英文名称；不同币种、发行状态、回款状态及到期时点的资产；先逾期后结清的资产；只有其他企业或其他监管机构有权查看的同名资产。
- 状态异常样本：结清依据缺失但逾期为已逾期；已结清但逾期依据缺失；未结清且到期兜底后上游新回传仍为未逾期；无回款记录但尚未到期，以及已有部分回款但到期未结清的资产。
