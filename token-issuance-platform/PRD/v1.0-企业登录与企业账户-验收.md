# 企业登录与企业账户 · 验收

2026-10-29｜需求评审稿｜供测试使用

本册只写验收标准，测试用例与执行步骤由测试小队编写。规则见[功能与业务规则](./v1.0-企业登录与企业账户-PRD.md)，各节顺序与功能册一致。

怎么读：

- 共 30 条验收，编号连续。
- 一条验收写了多个场景时，全部场景都满足才算通过。
- 依赖待确认事项的验收注明“待验，不判通过”及所依赖的待确认编号；确认前只核对已写明的部分。

## 0. 验收前准备

账号与地址：

- 企业地址 A：已在资产可信平台登记，能匹配到个人信息和企业信息；测试人员控制其私钥。
- 企业地址 B：与 A 属于不同企业，同样能匹配。
- 未登记地址：在资产可信平台没有登记的以太坊地址。
- 只有个人信息、没有企业信息的地址一个；在测试数据中同时匹配到两个企业的地址一个。
- 测试人员控制私钥、未被任何企业使用的以太坊地址至少两个（用于新增数币账户）。
- 用于登录地址变更的企业一个：可在资产可信平台把其登录地址从旧地址改为新地址。

数据与环境：

- 钱包环境：未安装钱包、钱包已锁定、钱包处于以太坊以外网络三种情形。
- 地址格式样本：0x 加 39 位、0x 加 41 位、含非十六进制字符的字符串；其他网络格式的地址；同一以太坊地址的全小写与大小写混合写法。
- 无法签名的地址样本：交易所充值地址或合约地址一个。
- 上游资料样本：部分可选字段未提供的企业；可模拟资产可信平台不可用或超时。
- 引用样本：一笔处理中的发行申请选择了某个企业新增账户；一个已有代币铸造到的企业新增账户；一个只被已驳回申请选择过的企业新增账户。

| <a id="AC-M1-01"></a>AC-M1-01 | 未登录 | 查看可用的登录方式 | 只有连接钱包登录；没有注册入口，也没有账号密码、邮箱、验证码等其他登录方式 |

| <a id="AC-M1-05"></a>AC-M1-05 | 未登录，使用企业地址 A | 分别：拒绝签名；签名过程中在钱包里切换到另一地址后签名；使用已失效的签名请求 | 都不建立登录；拒绝时可重试；地址变化时说明钱包地址已变化，可用当前地址重新登录，不静默改用新地址；请求失效时提示重新签名。签名请求有效期的具体时长待验，不判通过（Q-M1-02） |
| <a id="AC-M1-06"></a>AC-M1-06 | 未登录 | 分别用企业地址 A 的全小写写法和大小写混合写法登录 | 两次都匹配到同一企业并进入企业态 |
| <a id="AC-M1-07"></a>AC-M1-07 | 未登录，使用未登记地址 | 签名登录 | 进入游客态，看到游客引导；不按企业名称等信息近似匹配到任何企业 |
| <a id="AC-M1-08"></a>AC-M1-08 | 未登录 | 分别用“只有个人信息没有企业信息”的地址、“匹配到两个企业”的地址签名登录 | 前者进入游客态；后者本次登录不成立，仍为未登录，说明暂时无法确认身份、请联系平台管理人员，不展示任一企业的资料。待验，不判通过（Q-M1-03） |
| <a id="AC-M1-09"></a>AC-M1-09 | 资产可信平台不可用或超时 | 用企业地址 A 签名登录 | 本次登录不成立，仍为未登录，说明暂时无法确认身份并可重试；不进入游客态。待验，不判通过（Q-M1-04） |
| <a id="AC-M1-10"></a>AC-M1-10 | 企业地址 A 已登录企业态 | 主动退出；再用企业地址 B 登录 | 退出后回到未登录，受保护内容不能继续查看；地址 B 登录后只看到 B 企业的资料与数币账户，没有 A 的任何残留 |
| <a id="AC-M1-11"></a>AC-M1-11 | 企业地址 A 已登录企业态 | 不经新增数币账户流程，直接在钱包中切换到另一地址；先不选择，再选择用新地址重新登录 | 提示钱包地址与登录地址不一致；未选择前仍按地址 A 显示数据，不自动改用新地址；选择后结束当前登录，需对新地址重新签名并重新匹配 |
| <a id="AC-M1-12"></a>AC-M1-12 | 企业地址 A 已登录企业态 | 登录到期后继续操作 | 回到未登录并说明，受保护内容不能继续查看，需重新签名登录。登录有效期的具体时长待验，不判通过（Q-M1-01） |

| <a id="AC-M1-24"></a>AC-M1-24 | 企业新增账户一个 | 分别把账户名称清空、填入超出上限的名称后保存；再取消一次修改 | 清空时指出原因并保留原值；取消后原值不变。超出上限的部分待验，不判通过（Q-M1-12） |

| <a id="AC-M1-27"></a>AC-M1-27 | 一个未被引用的企业新增账户，删除确认前，另一会话用该账户提交了发行申请 | 确认删除 | 不删除，说明已被处理中的发行申请引用 |
| <a id="AC-M1-28"></a>AC-M1-28 | 企业已有登录地址这一条和两个企业新增账户；其中一个已在尚未提交的发行申请中被选中后删除 | 在发行申请中查看可选接收账户；不选择直接提交；提交那笔已选中被删账户的申请 | 可选范围包含登录地址这一条和未删除的企业新增账户，不预选任何账户，也没有在申请中新增或手输地址的方式；不选择不能提交；已选中被删账户的申请提交不成立，要求重新选择 |
| <a id="AC-M1-29"></a>AC-M1-29 | 已登记过企业新增账户的企业 | 依次完成一次新增、编辑、删除，然后查看本企业消息与管理端待办 | 变更保存即生效，不进入审核；本企业没有收到任何消息，管理端没有新增待办 |
| <a id="AC-M1-30"></a>AC-M1-30 | 用于登录地址变更的企业，已有代币铸造到登录地址这一条 | 在资产可信平台把登录地址改为新地址；用新地址登录；再用旧地址登录 | 新地址登录后进入同一企业的企业态，原有企业新增账户、申请与代币全部保留；登录地址这一条更新为新地址；已铸造的代币仍显示旧地址；旧地址登录进入游客态，看不到该企业数据。登录期间发现变更的时点待验，不判通过（Q-M1-06、Q-M1-07） |
