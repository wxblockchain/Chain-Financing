# 企业登录与企业账户 · 验收

2026-10-30｜需求评审稿｜供测试使用

本册只写验收标准，测试用例与执行步骤由测试小队编写。规则见[功能与业务规则](./v1.0-企业登录与企业账户-PRD.md)，各节顺序与功能册一致。

怎么读：

- 共 45 条验收。编号沿用原值，新增条目接续编号，所以表格中的编号不按顺序排列，但没有缺号。
- 一条验收写了多个场景时，全部场景都满足才算通过。
- 依赖资产可信平台真实接入的场景（来源校验、调取时点、锁定禁用后 60 秒失效），可在模拟环境中核对页面行为，不能据此判定真实联调通过。

## 0. 验收前准备

账号与地址：

- 已认证企业地址 A：已在资产可信平台登记，调取到的账户有个人信息、企业信息，认证结论为已认证；测试人员控制其私钥。
- 已认证企业地址 B：与 A 属于不同企业。
- 未认证企业地址：有企业归属但认证审核中或未通过的地址各一个；有个人信息、没有企业归属的地址一个。
- 未登记地址：在资产可信平台没有登记的 Ethereum 地址。
- 上游账户已锁定或禁用的地址一个；在测试数据中对应两个上游账户的地址一个。
- 测试人员控制私钥、未被任何企业使用的 Ethereum 地址至少两个（用于新增数币账户）。
- 用于上游变化的企业一个：可在资产可信平台更改其登录地址、认证结论、锁定或禁用状态和资料。

数据与环境：

- 钱包环境：未安装钱包、钱包已锁定、钱包处于 Ethereum 以外网络三种情形；可延迟确认的钱包（如硬件钱包）。
- 地址格式样本：0x 加 39 位、0x 加 41 位、含非十六进制字符的字符串；其他网络格式的地址；同一 Ethereum 地址的全小写、大小写混合、不带 0x 前缀三种写法。
- 无法签名的地址样本：交易所充值地址或合约地址一个。
- 上游资料样本：部分可选字段未提供的企业；可模拟资产可信平台不可用、超时，以及返回来源无法确认的结果。
- 文本样本：恰好 100 个字符和 101 个字符的备注名。
- 引用样本：一笔处理中的发行申请选择了某个企业新增账户；一个已有代币铸造到的企业新增账户；一个只有已销毁代币铸造到的企业新增账户；一个只被已驳回申请选择过的企业新增账户。
- 登录地址变更样本：原登录地址分别未被引用、被处理中的发行申请引用、有代币铸造到（含只有已销毁代币）的企业；新登录地址分别未登记、已作为普通账户登记的情形；可连续更换登录地址并改回仍保留的原地址。
- 一条发给某企业的消息链接，用于验证登录后返回原目标；平台联系邮箱已配置。
- 偏好样本：一个从未保存过语言偏好的企业用户；首次登录时浏览器时区为 Asia/Shanghai 的企业用户，以及浏览器时区无法推断的情形；可模拟偏好保存失败。

| <a id="AC-M1-32"></a>AC-M1-32 | 未登录 | 模拟客户端提交伪造的上游数据，或上游返回来源无法确认的结果 | 伪造数据不被采信；来源无法确认的结果不参与判定，不改变已有登录，并产生安全告警 |
