<a id="fig-1"></a>
## 运营审核与执行（图 1）

```mermaid
flowchart TD
    A[企业提交成功的待运营审核申请] --> B[运营核对原代币和前置条件]
    B --> C{审核决定}
    C -->|驳回| D[填写必填驳回意见]
    D --> E{仍待审且驳回提交成功}
    E -->|否| F[保留原状态或显示已被处理的结果]
    E -->|是| G[原申请驳回并释放处理中占用]
    G --> H[通知本企业 原记录保留]
    H --> I[企业重新符合资格后创建新申请]
    C -->|通过| J{当前到期 结清 双重无质押及对应关系均满足}
    J -->|否或无法确认| K[保持待审 说明限制 可重取或主动驳回]
    J -->|是| L[记录通过 进入销毁中并执行]
    L --> M{原代币执行结果}
    M -->|仍进行或未确认| N[保持销毁中 取得原执行结果]
    M -->|确认失败| O[销毁失败 留存记录 通知全体运营]
    O --> P{运营主动重试且当前条件满足}
    P -->|否或无法确认| Q[保留销毁失败及限制 不自动执行]
    P -->|是| R[记录本次重试 回到销毁中]
    R --> M
    M -->|与原代币完整数量一致的成功| S[留存销毁成功 代币已销毁]
    S --> T[形成原机构待解除事项]
    T --> U[通知企业成功 通知原监管机构待解除]
```

重复与并发操作按[共同异常](./v1.0-销毁审核与解除质押-PRD.md#common-errors)只承认一次实际办理；成功事实已确认后，读取或通知异常不能让流程重回销毁。平台停用合约相关通过和重试见[停用合约影响（Q-M4B-01）](./v1.0-销毁审核与解除质押-PRD.md#Q-M4B-01)，该分支尚未裁定。

<a id="fig-2"></a>
## 销毁申请状态（图 2）

```mermaid
stateDiagram-v2
    state "待运营审核" as Review
    state "驳回" as Rejected
    state "销毁中" as Burning
    state "销毁失败" as Failed
    state "销毁成功" as Burned
    state "待解除监管" as PendingRelease
    state "已解除监管" as Released
    [*] --> Review: 企业提交成功
    Review --> Rejected: 运营驳回生效
    Review --> Burning: 运营通过并执行
    Burning --> Failed: 确认执行失败
    Failed --> Burning: 运营手动重试受理
    Burning --> Burned: 确认原代币完整数量销毁成功
    Burned --> PendingRelease: 承接原监管机构待办
    PendingRelease --> Released: 原机构解除并留记录成功
    Rejected --> [*]
    Released --> [*]
```

- 初始为待运营审核；驳回是本笔申请终止，重新发起属于另一笔申请，不画驳回回到待审。
- 销毁失败尚未结束，等待运营手动重试；未确认的执行结果保留销毁中，不因等待而进入失败。
- 销毁成功是持续保留的结果事实，随后为待解除进度；可同次承接，不要求出现独立中间画面。
- 失败说明、次数及解除记录的可见范围以[两端衔接字段清单](./v1.0-销毁审核与解除质押-PRD.md#handoff)为准。

<a id="fig-3"></a>
## 代币及监管承接（图 3）

```mermaid
stateDiagram-v2
    state "正常（未质押）" as Normal
    state "融资质押中" as Financed
    state "销毁申请中" as Applying
    state "已销毁" as Destroyed
    [*] --> Normal: 铸造成功且融资事实为无质押
    Normal --> Financed: 当前融资事实变化
    Financed --> Normal: 当前确认无融资质押
    Normal --> Applying: 到期结清且双重无质押 企业提交成功
    Applying --> Normal: 申请驳回 当前确认无质押
    Applying --> Financed: 申请驳回 当前确认有质押
    Applying --> Destroyed: 确认销毁成功
    Destroyed --> [*]
```

融资信息未知时说明无法确认，资格不通过，不新造“未知”业务终态。申请销毁失败时继续为销毁申请中；驳回释放占用以后依据当前事实判断，新申请不会改写旧驳回记录。

| 代币事实 | 监管事实 | 业务含义 |
| --- | --- | --- |
| 未销毁，包含正常、融资中及销毁申请中 | 监管中 | 原机构持续监管，不能提前解除 |
| 已销毁 | 监管中 | 销毁成功，原机构待解除 |
| 已销毁 | 已解除监管 | 原机构解除成功并留记录，完整业务可回看 |
| 未销毁或销毁结果无法确认 | 出现已解除结果 | 矛盾或缺失，按[共同异常](./v1.0-销毁审核与解除质押-PRD.md#common-errors)核查，不能当作正常可办理 |

监管从原代币铸造成功开始，解除提交成功才结束。资产发行状态始终按 M2 保持已发行，不由销毁或解除回退。

## 原监管机构解除监管（图 4）

```mermaid
flowchart TD
    A[从本机构列表 台账或消息进入原事项] --> B{当前机构归属与查看权限有效}
    B -->|否| C[统一不可访问 可返回来源]
    B -->|是| D{已确认销毁成功且仍待解除}
    D -->|已解除| E[只看原解除记录 可返回列表或消息]
    D -->|依据缺失或矛盾| F[保留已确认事实 说明无法办理]
    D -->|是| G[核对企业 资产 代币 销毁数量与成功时间]
    G --> H[选填备注与凭证]
    H --> I{所选文件均已上传成功}
    I -->|否| J[重试文件或移除失败文件]
    J --> H
    I -->|是或未选文件| K[主动确认解除]
    K --> L{本次提交结果}
    L -->|取消| M[保持待解除 不留生效记录]
    L -->|明确失败| N[保持待解除 可恢复填写后重试]
    L -->|未确认| O[取得原提交实际结果 不重复解除]
    L -->|成功| P[记录原机构 操作人 时间 备注及可选凭证]
    P --> Q[已解除监管 代币仍已销毁]
    Q --> R[通知所属企业 展示原记录 可返回列表]
```

文件格式、数量和大小的边界见[填写与凭证边界（Q-M4B-02）](./v1.0-销毁审核与解除质押-PRD.md#Q-M4B-02)；未填备注或未选文件不阻断解除。并发处理中若已由同机构完成，只显示原生效结果，不另留第二份解除记录。
