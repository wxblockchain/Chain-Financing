# 借贷平台（lending-platform）

负责展示已对接的代币资产并完成融资（融资需求、代币质押、授信报价、放款与还款）；资产方通过资产可信平台授权登录。

当前工作分支为 `cly-4.0.0`。面客端包含公开首页及金融业务工作区，运营端为管理平台，两者独立部署。

## 目录

- [`PRD/`](PRD/README.md) —— 本平台的产品需求文档
- [`页面原型/`](页面原型/README.md) —— 本平台的页面原型，原型底座与设计规范在其下的 `_shared/`

## 原型底座与设计规范

本平台自持的底座位于 [`页面原型/_shared/`](页面原型/_shared/README.md)。面客端与运营端共用 token、公共组件与壳层运行时，各自持有页面登记表与导航。组件规则统一从[设计系统入口](页面原型/_shared/design-system/README.md)读取。

## 当前资料与读取顺序

以 `cly-4.0.0` 当前文件及用户已确认反馈为准：

1. [PRD 目录](PRD/README.md)：定位模块需求、流程、消息通知及验收文件；字段术语查[对照表](PRD/00-字段命名与术语对照表.md)。
2. [设计系统](页面原型/_shared/design-system/README.md)：先读共享组件规范，再读面客 / 运营规范和目标模块说明。
3. [页面原型](页面原型/README.md)：源码、运行及导出入口；现行模块为已有页面的继承基线，样板用于公共组件示例。

维护来源为本目录内的 PRD、模块源码和共享层。历史分支、旧 commit 与 issue 附件只记录当时状态；尚未补齐的库外依赖以当前 PRD 的待确认项为准，不要求从旧分支补全业务规则。
