# 借贷平台 · PRD 阅读入口

2026-10-23｜需求评审稿

本目录包含面客端 9 个、运营端 9 个业务模块。各模块按 01 功能与业务规则、02 流程图与状态机、03 消息通知（仅自身发送消息时）、04 验收阅读；缺少 03 表示该模块自身不发消息。目录序号沿用现值，面客端 07 不再使用，其余目录不重排。

本入口只列阅读路径，不复述业务规则。当前规则以所属模块功能册为准，验收与图册配套阅读；业务事实的变更由来源模块定义，其他模块链接使用。
