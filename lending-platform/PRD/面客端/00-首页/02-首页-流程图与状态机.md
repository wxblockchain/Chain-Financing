<a id="FL-HM-02"></a>
## 存证校验（FL-HM-02）

```mermaid
flowchart TD
  O["打开存证校验，不显示上一次结果"] --> I["输入代币编号或存证哈希"]
  I --> S["提交"]
  S --> E{"去掉首尾空格后是否为空"}
  E -->|"是"| E1["提示需要输入内容，不发起校验"] --> I
  E -->|"否"| B["校验中：告知正在读取记录，不能重复提交，输入不可编辑"]
  B --> F{"是否与资产广场展示范围内某笔代币的登记记录完全一致，不区分大小写"}
  F -->|"是"| MATCH["一致：逐笔展示代币编号与链上存证信息，缺项显示“—”"]
  F -->|"否，含待审核、已退回与不存在"| MISS["未找到：提示核对后重试，不说明原因"]
  MATCH --> I
  MISS --> I
  B -->|"关闭"| Q["本次校验结束，不显示结果"]
  I -->|"关闭"| Q
  MATCH -->|"关闭"| Q
  MISS -->|"关闭"| Q
  Q --> H["回到首页原浏览位置"]
```

<a id="ST-HM-01"></a>
## 存证校验状态（ST-HM-01）

一次存证校验从打开到关闭。关闭是终态；再次打开是一次新的校验，从“待输入”开始。

```mermaid
stateDiagram-v2
  state "待输入" as Idle
  state "输入为空" as Empty
  state "校验中" as Checking
  state "一致" as Matched
  state "未找到" as Missing
  state "已关闭" as Closed
  [*] --> Idle: 打开存证校验
  Idle --> Empty: 提交空内容
  Empty --> Checking: 输入内容后提交
  Idle --> Checking: 提交非空内容
  Checking --> Matched: 匹配到登记记录
  Checking --> Missing: 没有匹配
  Matched --> Checking: 修改内容后再次提交
  Missing --> Checking: 修改内容后再次提交
  Idle --> Closed: 关闭
  Empty --> Closed: 关闭
  Checking --> Closed: 关闭，本次结果不再显示
  Matched --> Closed: 关闭
  Missing --> Closed: 关闭
  Closed --> [*]
```
