## 1. 模块是什么

<a id="scope"></a>
资产广场是面客端公开、只读的代币展示区。任何人（包括未登录的游客）都可以在这里查看平台上全部已准入代币：每笔代币由谁发行、对应哪笔应收账款（买卖双方、金额、账期）、价值多少、是否有效、现在由哪些链上地址持有、其中有多少已质押到哪个融资项目，并可以拿着链上凭证到区块浏览器自行查验。代币能否出现在这里，只由运营端[代币准入审核](../../运营端/06-代币准入审核/01-代币准入审核-PRD.md)决定。本模块只有代币列表和代币详情两类页面，没有任何办理动作。

基本原则：

- 先准入后展示：只有准入状态为已通过的代币才出现在资产广场；待审核和已退回的代币在列表、详情、汇总和搜索中都不出现。
- 全部只读：本模块不提供上架、下架、隐藏、推荐、估值或评级，也不向代币发行平台或资产可信平台写入任何信息。
- 只公开非隐私信息：链上公开数据和不涉及隐私的业务数据可以公开，买卖双方企业名称也公开；单据号码、文件原件、自由文本、主体标识和个人与账户资料一律不展示，见[公开哪些信息](#public-fields)。
- 所有角色看到的内容完全相同：登录与否、什么角色，都不增加或减少可见的代币、字段或筛选排序能力，见[角色与权限](#roles)。
- 一笔代币只有一个发行方，可以同时有多个持有方；持有方以链上地址表示，不展示持有方的身份。
- 代币的事实（数量、价值、状态、铸造与合约信息、持有分布）以代币发行平台为准；底层应收账款信息以资产可信平台为准；质押状态和所属融资项目以借贷平台为准，只在详情的持有方清单中逐个持有方展示。本平台不自行判断代币是否有效，也不重估价值。

**一个完整的例子。** 代币发行平台 A 把代币 TK20260919000123 推送到借贷平台，运营管理员在代币准入审核中通过了它；这笔代币随即出现在资产广场。游客打开平台，默认进入资产广场。页面顶部显示当前有效代币的合计：代币数量 41,900,000.75 枚、代币价值 41,900,000.75 USD（按各笔签发时汇率折算），失效代币不计入；下方是按铸造时间倒序的前 20 笔代币，其中也有标为失效的代币。仍在待审核的代币不在列表里。游客把列表放大，在网络（以太坊）、代币编号等信息之外，又看到每笔代币的代币发行合约与资产槽位。游客把发行方筛为“甲企业”、按代币价值从高到低排序，列表与合计一起更新，继续往下浏览时自动追加下一批。游客点开 TK20260919000123：概览显示代币状态“有效”；代币信息显示来源发行平台 A、发行方甲企业、代币价值 100.00 USD 与签发汇率、铸造链以太坊、链 ID、代币发行合约地址、资产槽位、铸造交易哈希与合约审计情况，铸造交易哈希可以打开区块浏览器自行查验；基础资料信息显示卖方甲企业、买方乙企业、应收账款金额 100.00 USD、账期 2026-10-01～2027-03-31、无追索、已确权；页面上没有合同号、发票号或任何文件。持有方清单列出 2 个持有方，分别持有 60.00 枚和 40.00 枚，合计等于代币数量 100.00 枚，两者的质押状态都是未质押。游客复制了浏览器地址发给同事，同事打开看到同一笔代币。另一笔代币 TK20260920000045 整笔在某融资项目的质押合约中，详情的持有方清单只有该质押合约地址一条，质押状态“已质押”，所属融资项目可以进入借贷广场中该项目的详情。资金方登录后看同一笔代币，看到的内容与游客完全相同。

### 1.1 本期不做

- 申请、认购、下单、收藏、订阅、评论、导出、下载、铸造或销毁。
- 估值、评级、排行榜或可信度评分。
- 在本模块对代币做上架、下架、隐藏、置顶、推荐或精选；代币能否展示只由代币准入审核决定，本期也没有下架。
- 展示准入状态、准入审核过程、审核结论或退回原因。
- 按角色区分展示内容；为登录用户提供更多字段。
- 按链分组展示或按链筛选。
- 登录、注册、成为资产方或成为资金方的引导。
- 展示单据号码、法律协议文件与佐证材料的原件或文件清单。
- 展示持有方或发行方的企业资料、联系人、认证材料。
- 历史持有方、零余额地址和代币流转记录。
- 有效质押额、质押率等额度信息。
- 本模块发送的任何消息或提醒。
- 数据获取方式：信息如何从上游取得、何时刷新，由研发决定，本册只定义需要哪些信息和展示结果。

## 2. 术语

| 术语 | 含义 |
| --- | --- |
| 已准入代币 | 在运营端代币准入审核中准入状态为已通过的代币，即本模块名称中的“已上架代币”。只有已准入代币出现在资产广场。定义见[代币准入审核术语](../../运营端/06-代币准入审核/01-代币准入审核-PRD.md#terms) |
| 一笔代币 | 代币准入审核中一条准入记录对应的代币；一笔代币可以有多枚。列表和合计里“笔”只用于计数，“枚”只用于代币数量 |
| 平台代币标识 | 借贷平台为一笔代币生成的唯一标识，用于定位代币详情，见[详情地址、分享与返回](#F-AM-06)。它不是代币编号，也不是链上的代币 ID |
| 代币编号 | 代币发行平台给出的业务编号。不同发行平台的代币可能同号，因此不用于定位详情 |
| 发行方 | 发行这笔代币的企业。一笔代币有且只有一个发行方 |
| 来源发行平台 | 把这笔代币推送到借贷平台的代币发行平台。借贷平台可以对接多个代币发行平台 |
| 持有方 | 当前持有这笔代币某一部分数量的链上地址。一笔代币可以有一个或多个持有方，持有方可能是企业地址，也可能是某融资项目的质押合约地址 |
| 铸造链 | 代币铸造所在的链，本期为以太坊。持有方地址、代币发行合约地址和铸造交易哈希都在这条链上。列表中展示铸造链的信息项称“网络” |
| 资产槽位 | 代币发行合约在链上归集同一类资产的标识（slot），只在同一份合约内唯一；本期代币为 ERC-3525 代币，一笔代币对应一个资产槽位 |
| 存证链 | 资产可信平台的链上存证记录所在的链 |
| 默认态、放大态 | 代币列表的两档信息。默认态只展示核心信息；放大态在当前页面内展开列表，展示全部列表信息项 |
| 签发价值 | 代币铸造时按当时汇率折算的 USD 价值，之后不再变动，不是实时市值 |
| 铸造时间 | 代币在铸造链上完成铸造的时间，与铸造交易哈希对应同一笔交易。本模块统一称铸造时间，不称发行时间或签发时间 |
| 基础资料信息 | 代币对应的应收账款的业务信息，如买卖双方、金额币种、账期，来自资产可信平台 |
| 链上存证 | 资产可信平台为该笔应收账款在链上留下的存证记录，与铸造交易是两笔不同的交易 |
| 已质押、未质押 | 一个持有方所持数量的质押状态的两个对外取值。已质押表示该数量在某融资项目的质押合约中，且未被业务释放。代币本身不设质押状态 |
| 业务释放待提取 | 融资项目关闭或结清后，平台已解除代币与项目的关系，但代币仍留在质押合约中、等待原持有方提取。此时显示未质押 |
| 访问状态 | 游客、登录未绑定角色、资产方、资金方四种，判定见[登录主干](../01-登录主干与资产方SSO接入/01-登录主干与资产方SSO接入-PRD.md#F-L34) |

## 3. 进入资产广场（F-AM-01）

适用角色与前提：所有访问状态，无需登录。

- 资产广场与借贷广场同为面客端一级入口，四种访问状态都能进入，可用性一致。
- 资产广场是面客端默认入口，没有独立首页。登录主干判定无效或不允许的返回目标时，也统一回到资产广场，相应提示由登录主干负责。
- 游客可以直接打开代币列表，也可以直接打开别人分享的代币详情，全程不要求登录。
- <a id="C-F-AM-07"></a>列表与详情都不提供单独的登录、注册、成为资产方或成为资金方的引导。用户只能通过面客端唯一的登录入口主动登录，登录、角色判定、返回目标和账户菜单都由[登录主干](../01-登录主干与资产方SSO接入/01-登录主干与资产方SSO接入-PRD.md)负责。
- 登录后回到资产广场，看到的内容与登录前相同，不会因登录自动执行任何融资业务。

流程参见：[查看详情与跳转（FL-AM-02）](./02-资产广场-流程图与状态机.md#FL-AM-02)。

## 4. 角色、权限与公开范围（F-AM-10）

<a id="roles"></a>
### 4.1 角色与权限

本模块按[业务权限的归属与共同底线（F-L10）](../01-登录主干与资产方SSO接入/01-登录主干与资产方SSO接入-PRD.md#F-L10)自行定义各角色的权限。资产广场是公开展示区，所有角色的权限相同：

| 角色 | 可以做什么 | 不能做什么 |
| --- | --- | --- |
| 游客（未登录） | 浏览代币列表与代币详情；筛选、排序、搜索；放大与收起列表；复制代币编号、地址和哈希；打开区块浏览器；进入已公开的所属融资项目 | 任何写操作；取得[公开哪些信息](#public-fields)中不展示的信息 |
| 登录未绑定角色 | 与游客相同 | 与游客相同 |
| 资产方（不论认证状态） | 与游客相同；本企业发行、作为买卖方或持有的代币也只看到同样的内容 | 与游客相同；在本模块取得本企业代币的不展示信息 |
| 资金方（不论入驻审核状态） | 与游客相同 | 与游客相同；参与某项目融资不因此在本模块取得更多信息 |

<a id="D-AM-69"></a>

- 四种访问状态取得同一组代币、同一组字段、同样的字段值和展示口径，以及同样的筛选、排序与搜索能力。这种一致必须体现在实际取得的数据上，不能只是界面上隐藏。
- 不展示的信息对任何角色都不返回，绕过界面读取同样取不到；不先把不展示的信息交给浏览者再遮盖。
- 本模块所有能力对所有角色都可见可用，没有“能看到但受限”的入口，因此不需要受限后的引导。
- 登录、退出、角色判定结果变化、认证升级或降级、资金方入驻审核结果变化，都不改变资产广场的内容。
- 进入所属融资项目后，项目详情能看到什么由借贷广场按[项目详情按身份的可见范围（F-LS-82）](../05-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#f-ls-82)决定；资产广场不为任何角色扩大或缩小这一范围。
- 运营端没有本模块的功能，本模块不定义运营端权限项；代币能否在资产广场展示由运营端代币准入审核办理，权限见该模块。

<a id="public-fields"></a>
### 4.2 公开哪些信息

资产广场公开链上公开数据和不涉及隐私的业务数据；单据号码、文件、自由文本、主体标识和个人与账户资料属于隐私敏感信息，一律不展示。

| 类别 | 信息 | 是否展示 |
| --- | --- | --- |
| 链上公开数据 | 铸造链与链 ID；代币发行合约名称与地址；资产槽位；代币符号；精度；铸造交易哈希；铸造时间；代币数量；每个持有方的地址与持有数量；链上存证五项（存证哈希、链上存证交易哈希、区块高度、存证链、存证时间） | 展示 |
| 代币业务数据 | 代币编号；代币名称与标识图；代币类型；来源发行平台；发行方名称及其注册国家或地区；代币价值（签发价值）、签发汇率及持有方对应价值；代币状态；合约审计情况（是否审计、审计机构、报告日期）；持有方的质押状态与所属融资项目 | 展示 |
| 底层应收账款业务数据 | 卖方（债权人）与买方（债务人）企业名称；买方注册国家或地区；应收账款金额与币种；底层应收账款账期；贸易类型；结算方式；追索安排；确权结论与确权时间；债权转让是否已登记及登记机构 | 展示 |
| 单据与文件 | 合同号、发票号、提单号、应收账款编号、债权转让登记编号；法律协议文件、底层资产佐证材料、审计报告等文件原件与文件清单；附件影像 | 不展示 |
| 自由文本 | 付款条件等合同约定原文；贸易背景自由文本；备注 | 不展示 |
| 身份与账户资料 | 企业主体标识；持有方的企业身份；铸造时的初始收币地址；个人姓名、联系方式；账户资料、证件、认证材料、成员关系 | 不展示；不能用持有方地址反查或展示账户身份 |
| 准入与过程信息 | 准入状态、提交序次、审核结论、退回原因、准入操作记录；确权与签发过程；质押转入转出凭证与费用；重试或释放处理过程；他人控制台数据；授信额度；数据更新时间；核对差异 | 不展示 |

- 不展示的信息在列表、详情、汇总、搜索、筛选、排序、分享链接和页面地址中都不出现，也不作为搜索命中的依据。
- 发行方、卖方、买方的企业名称完整显示，不脱敏，不附带企业资料或联系人入口。
- 本模块展示的数值都是公开信息，不属于敏感值，因此游客也按精确值筛选和排序；业务数值不做区间化。
- 页面不得以任何方式遮挡、模糊或截断公开信息，也不得暗示登录后能看到更多。
- 地址和哈希可以缩略展示，但都能复制到完整值。
- 将来如需展示任一不展示项，须重新批准公开范围。

## 5. 哪些代币出现在资产广场（F-AM-15）

适用角色与前提：所有访问状态。准入结论以运营端[代币准入审核](../../运营端/06-代币准入审核/01-代币准入审核-PRD.md)为准。

| 准入状态 | 列表与搜索 | 头部汇总 | 代币详情 |
| --- | --- | --- | --- |
| 待审核 | 不出现 | 不计入 | 打开地址显示“内容不存在”，与标识不存在无法区分 |
| 已退回 | 不出现 | 不计入 | 打开地址显示“内容不存在”，与标识不存在无法区分 |
| 已通过 | 关键字段齐全时出现 | 关键字段齐全且代币有效时计入 | 关键字段齐全时可打开 |

- 已通过准入的代币，关键字段齐全时在通过后即出现在列表和详情中；关键字段见[代币信息](#token-fields)。
- 已退回的代币重新推送后回到待审核，在再次通过之前始终不出现。
- 准入通过是终态，本期没有下架：通过后代币变为失效、持有方变化、质押或解押，都照常按事实展示，不因此从列表和详情中消失。
- 通过后代币发行平台又推送了资料变更的，本模块照常展示，内容以上游最新事实为准；运营端是否已知悉变更不影响展示。
- 已通过的代币只在关键字段缺失时不展示，规则见[代币信息](#token-fields)。
- 不同代币可能代币编号相同（代币准入审核对此只提醒、不限制通过）：它们各自出现、各自计入汇总，各有独立的详情地址，浏览者可以凭发行方、代币发行合约与资产槽位区分。
- 页面不展示准入状态、审核时间或“已审核”之类的标记；准入通过不代表平台对代币价值、真伪或交易有效性作出确认。

流程参见：[信息来源与公开浏览（FL-AM-01）](./02-资产广场-流程图与状态机.md#FL-AM-01)。

### 6.1 头部汇总（F-AM-02）

适用角色与前提：所有访问状态；汇总范围是当前筛选与搜索条件匹配的全部已准入代币中的有效代币，不是已加载的部分。

| 汇总项 | 计算与格式 |
| --- | --- |
| 代币数量 | 匹配的每笔有效代币的代币数量相加；单位枚，2 位小数 |
| 代币价值 | 匹配的每笔有效代币的签发价值相加；单位 USD，2 位小数；必须同时给出“按各笔签发时汇率折算”的说明 |

- 失效代币不计入汇总，汇总须标明只统计有效代币；失效代币仍照常出现在列表中。
- 一笔代币可以有多枚，代币数量不能按笔数、已加载条数、持有方个数或项目数计算。
- 待审核和已退回的代币不计入汇总。
- 持有方信息不是第二个统计来源：一笔代币有几个持有方、其中多少已质押，都不改变它在汇总里的数量和价值，每笔代币只计一次。
- 排序、继续加载、重试、返回和分享恢复都不改变汇总；改变筛选或搜索时，两项一起更新。
- 代币变为失效后，从当日起退出汇总。
- 没有匹配的有效代币时（含只筛失效代币）两项都显示 0，汇总不隐藏；缺值不当作 0。
- 本期只有一个代币类型。出现第二个代币类型或第二份发行合约时，必须分组汇总或停止混合求和。
- 代币数量与 USD 代币价值是两种量，不能相加。代币价值始终是签发快照，不显示为实时市值，也不再次折算。

| 代币类型 | 见[代币信息](#token-fields)中的代币类型；本期只有一个取值 | 不展示 | 展示 |
| <a id="L-AM-10"></a>铸造时间 | 按用户时区显示并标明时区；游客使用浏览器时区 | 不展示 | 展示 |
| 代币发行合约 | 代币发行合约地址，可缩略展示，可复制完整值并告知成功或失败 | 不展示 | 展示 |

<a id="list-expand"></a>
**默认态与放大态。**

- 进入资产广场时列表为默认态，展示上表中标为默认态展示的七项。
- 用户可以把列表放大为放大态，展示全部十一项；也可以随时收起回到默认态。
- 放大是在当前页面内展开列表，不弹出新的窗口或浮层，也不跳转到其他页面。
- 放大态下，头部汇总可以暂不展示，收起后恢复；筛选条件与各信息项名称始终可得。
- 放大与收起都不改变筛选、排序、关键词、已加载范围和浏览位置，也不改变头部汇总的数值；放大态中继续浏览照常连续加载。
- 默认态不展示的代币类型、铸造时间仍可用于筛选和排序：默认按铸造时间从新到旧，代币类型筛选照常可用。

- 默认态以代币编号辨识代币，因为它是业务往来中使用的编号；资产槽位只在同一份合约内有意义，所以与代币发行合约一起放在放大态和详情中，用于链上定位和区分同号代币。
- 对一笔代币除编号、代币发行合约复制以外的操作（包括代币标识图）进入该代币的详情；进入详情与复制是不同的动作，不能互相替代。
- 代币标识图不表达任何状态，它的替代文本是代币名称。
- <a id="L-AM-09"></a>底层应收账款账期不是列表信息项；详情展示账期，列表仍可按账期到期日排序。

### 6.3 筛选、排序与搜索（F-AM-04）

适用角色与前提：所有访问状态，能力完全相同。筛选、排序与搜索只在已准入代币范围内进行。

| 操作 | 规则 |
| --- | --- |
| 筛选 | 代币状态、代币类型、发行方三项，取交集，默认不限。本期代币类型只有一个取值，仍保留该筛选。不提供质押状态筛选和链筛选 |
| 搜索 | 一个关键词，命中代币编号、发行方名称或铸造交易哈希中任一项即返回；同号的不同代币都返回；不展示的信息（如合同号、发票号）不作为命中依据 |

### 6.4 连续加载（F-AM-05）

适用角色与前提：所有访问状态。

- 第一批最多 20 笔；继续浏览时自动追加下一批，每批 20 笔，最后一批按余量。
- 追加时保留已加载的记录，不重复、不遗漏；全部加载完后说明已到末尾并停止追加。
- 追加过程中，当前筛选条件和各信息项名称始终可得；默认态下头部汇总也始终可得，放大态按[默认态与放大态](#list-expand)处理。
- 不提供按页码定位，用户也不能改变每批条数。
- 追加中给出加载反馈；追加失败时保留已加载记录和浏览位置，可以重试同一批，不回到第一批、不重复追加。追加失败与没有结果、已到末尾要能区分。

## 7. 代币详情

<a id="F-AM-06"></a>
### 7.1 详情地址、分享与返回（F-AM-06）

适用角色与前提：所有访问状态，无需登录。

- <a id="P-F-AM-02"></a>详情中文名“代币详情”，英文名 Token Details，是可以分享、直接打开、被搜索引擎收录的独立页面。建议地址为 `/assets/{平台代币标识}`，在登录主干登记的站内允许前缀内。
- 详情按平台代币标识定位，不按代币编号定位。平台代币标识的要求：
  - 一笔代币一个，不同代币不重复；
  - 由借贷平台在代币准入审核形成这笔代币的准入记录时生成，不由代币发行平台提供；
  - 生成后终身不变：重新推送、待审核期间资料更新、通过后资料变更都不改变它，也不复用给其他代币；
  - 只用于定位详情，不作为业务字段展示，不含业务含义。
- 刷新或通过分享链接打开，看到的是同一笔代币的同一内容。
- 从列表进入后返回，或使用前进后退，都保留对应的列表视图。
- 标识不存在、格式不合法，或这笔代币尚未准入（待审核、已退回），统一显示“内容不存在”，不透露三者的差别。

流程参见：[查看详情与跳转（FL-AM-02）](./02-资产广场-流程图与状态机.md#FL-AM-02)。

<a id="F-AM-07"></a>
### 7.2 详情内容（F-AM-07）

适用角色与前提：所有访问状态。

- 详情完整给出概览、代币信息、基础资料信息、链上存证、持有方五部分，并按这个顺序讲述。
- 详情中没有任何办理动作，也不附登录或注册引导。
- 所有字段只读，没有手填项，也没有虚构的默认值。
- 详情只展示[公开哪些信息](#public-fields)中标为展示的信息。

**概览。** 包含代币标识图、代币名称、完整可复制的代币编号和代币状态。

- 代币状态给出判定依据；失效的依据须给出底层应收账款到期日。
- 概览不展示质押状态。代币状态与持有方的质押状态是两个独立的维度：代币失效时，其持有方仍可以是已质押，二者不合成新的状态。
- 状态要有文字表达，不能只靠颜色区分。

状态参见：[代币状态（ST-AM-01）](./02-资产广场-流程图与状态机.md#ST-AM-01)。

<a id="token-fields"></a>
**代币信息。** 以代币发行平台为准；本平台不判断铸造或失效，也不重估价值。

| 字段 | 含义与规则 |
| --- | --- |
| 代币编号 | 代币发行平台给出的业务编号，现行格式为 16 位文本：TK + UTC 日期 yyyyMMdd + 6 位序号；不是链上代币标识，也不是平台代币标识。完整展示、可复制 |
| 代币名称与代币符号 | 名称取合约配置，没有名称配置时为合约名称；符号取合约配置的简称，没有时显示“—”，不自造符号 |
| 来源发行平台 | 把这笔代币推送到借贷平台的代币发行平台名称 |
| 发行方 | 发行这笔代币的企业名称，一笔代币只有一个发行方；完整显示，不附带企业资料 |
| 发行方注册国家或地区 | 发行方登记所在的国家或地区 |
| 代币数量 | 本笔签发数量，不小于 0.01，2 位小数，单位枚；签发时 1 USD 对应 1 枚 |
| 代币价值 | 本笔签发时的 USD 价值，非负，2 位小数；不是融资额，也不是另算的质押价值 |
| 签发汇率 | 签发时应收账款币种对 USD 的汇率及汇率生效时间，按上游快照原值展示，不重算 |
| 代币类型 | 代币标准与底层资产类型合并的单一字段，取上游已配置的取值；本期统一为 `ERC-3525-应收账款`，只有一个取值。字段须能容纳将来的其他标准，不写死某一标准 |
| 代币状态 | 有效／失效。本期没有已销毁的来源，不新增第三种取值 |
| 铸造链 | 代币铸造所在的链，展示全称（中文“以太坊”，英文 Ethereum），不用缩写；只读，不能选择或修改 |
| 链 ID | 铸造链的链 ID，以太坊主网为 1；用于区分主网与测试网 |
| 代币发行合约 | 该代币实际部署的发行合约名称与地址。地址格式按铸造链定义（以太坊为 `0x` 加 40 位十六进制），完整展示、可复制，不缩略 |
| 资产槽位 | 本笔代币在代币发行合约中的资产槽位（slot），与代币发行合约地址一起定位链上的这笔代币；完整展示、可复制 |
| 精度 | 代币发行合约定义的小数位数 |
| 铸造交易哈希 | 格式按铸造链定义（以太坊为 `0x` 加 64 位十六进制）；可缩略展示，可复制完整值，可打开铸造链对应的区块浏览器 |
| 铸造时间 | 以 UTC 为基准，按用户时区显示并标明时区；游客使用浏览器时区 |
| 合约审计 | 代币发行合约是否经第三方审计；已审计时给出审计机构与报告日期。不提供审计报告文件 |

- 缺少代币编号、发行方、代币数量、代币价值、代币状态、铸造交易哈希或铸造时间任一项的代币，整笔不展示、不计入汇总，也不用占位记录代替。
- 其他字段缺失时逐项显示“—”，不猜测内容。
- 持有方信息缺失或核对不上时，按[持有方信息不可用](#holding-errors)处理，不影响这笔代币的其他信息展示。

**基础资料信息。** 以资产可信平台为准；全部只读，缺项显示“—”。

| 字段 | 含义与规则 |
| --- | --- |
| 卖方企业名 | 应收账款的卖方（债权人）企业名称，完整显示 |
| 买方企业名 | 应收账款的买方（债务人）企业名称，完整显示 |
| 买方注册国家或地区 | 买方登记所在的国家或地区 |
| 应收账款金额与币种 | 原币金额，2 位小数；币种为 3 位 ISO 4217 代码，金额与币种一起展示。原币金额与代币数量、代币价值是不同的量，不相加、不互相换算展示 |
| 底层应收账款账期 | 起始日至到期日，日期格式 yyyy-MM-dd；到期日与列表排序、失效依据使用同一个值 |
| 贸易类型 | 上游原值，本模块不扩充、不改写 |
| 结算方式 | 上游原值，本模块不扩充、不改写 |
| 追索安排 | 有追索／无追索，上游原值 |
| 确权情况 | 买方是否已确认该笔应收账款（确权结论）及确权时间；不展示确权凭证 |
| 债权转让登记 | 应收账款转让是否已在登记机构登记，以及登记机构名称；不展示登记编号 |

<a id="F-AM-08"></a>
### 7.3 链上凭证与自行查验（F-AM-08）

适用角色与前提：所有访问状态。

- 链上存证给出五项：存证哈希、链上存证交易哈希、区块高度、存证链（展示链的全称，不展示链 ID）、存证时间（标明时区）。哈希可缩略展示，可复制完整值。
- 五项中任一项缺失时，该项显示“—”，其余存证信息照常给出，不报整页错误。本模块不校验存证交易的真伪，也不补算缺项。
- 铸造交易哈希与链上存证交易哈希是两笔不同的交易，标签始终带上限定词，不能混用同一个值。
- 两种交易哈希都可以打开对应链的区块浏览器：铸造交易哈希按铸造链，链上存证交易哈希按存证链。
- 每个区块浏览器链接旁都同时给出“平台未核验该交易，链接仅供自行查验”，不需要额外操作才出现。不使用任何暗示平台已确认交易有效的说法。
- 站内跳转在当前窗口继续；只有区块浏览器在新窗口打开，用户不会因此丢失当前浏览位置。
- 公开浏览不跳转到代币发行平台或资产可信平台的页面。
- 复制成功或失败都有反馈；复制失败不改变浏览位置。

<a id="holding"></a>
## 8. 持有方与质押

<a id="F-AM-14"></a>
### 8.1 持有方（F-AM-14）

适用角色与前提：所有访问状态。持有事实以代币发行平台为准，质押状态与所属融资项目以借贷平台为准。

- 一笔代币当前可以有一个或多个持有方，每个持有方是一个链上地址，持有这笔代币的一部分数量。
- 持有方可能是企业地址，也可能是某融资项目的质押合约地址。持有方地址不代表企业归属或账户身份，也不能用铸造时的收币地址代替。
- 所有持有方的持有数量相加，必须等于这笔代币的代币数量。
- 同一个地址对同一笔代币只出现一次。
- 只列当前持有数量大于 0 的持有方；历史持有方、零余额地址和流转记录不列出。
- 一笔代币的持有方可以分属不同的融资项目，不限制一笔代币只对应一个项目。

每个持有方给出以下五项，顺序已确认；全部自动取得、只读，没有默认地址、数量或状态：

| 项目 | 规则 |
| --- | --- |
| <a id="H-AM-01"></a>持有方 | 持有方的链上地址，格式按铸造链定义（以太坊为 `0x` 加 40 位十六进制），按完整地址核对。可缩略展示，可复制完整值并告知成功或失败；缩略后相同的不同地址不能合并 |
| 持有数量 | 该持有方当前持有的本笔代币数量，大于 0，2 位小数，单位枚；不是该地址持有的全部代币 |
| 对应价值 | 持有数量 × 本笔代币价值 ÷ 代币数量，USD，2 位小数；按签发价值折算，不重估、不再换汇 |
| 质押状态 | 该持有方所持数量的质押状态：已质押或未质押，规则见[质押状态与所属融资项目](#pledge) |
| 所属融资项目 | 已质押时该数量所在的融资项目；未质押时显示“—”，规则见[质押状态与所属融资项目](#pledge) |

- 持有方清单不是第二个统计来源：持有方的增减、迁移或重复上报，都不改变头部汇总和这笔代币的数量、价值。
- 持有方的排列顺序由设计决定，同一条件下顺序稳定。

<a id="holding-errors"></a>
**持有方信息不可用。** <a id="E-AM-12"></a>持有方信息要区分加载中、读取失败可重试、正常、暂不可用四种结果。

| 情形 | 结果 |
| --- | --- |
| 读取中 | 显示加载中 |
| 读取失败 | 可重试的失败说明 |
| 持有方清单为空，或只有零余额地址 | 持有方信息暂不可用 |
| 持有数量合计与代币数量不相等 | 持有方信息暂不可用 |
| 某个持有方缺少地址或持有数量 | 持有方信息暂不可用 |
| 质押合约地址持有代币，但借贷平台没有对应的质押记录；或借贷平台有质押记录，但对应合约地址不在持有方中 | 持有方信息暂不可用 |
| 以上都不符合 | 正常展示全部持有方 |

- 暂不可用时保留持有方这一部分并说明暂不可用，不填 0、不编造地址、不默认未质押，也不写成正常的“暂无持有方”。
- 持有方信息不可用不影响这笔代币其他部分、列表和汇总的展示。

流程参见：[持有方与质押（FL-AM-03）](./02-资产广场-流程图与状态机.md#FL-AM-03)。

### 8.2 质押状态与所属融资项目（F-AM-09）

适用角色与前提：所有访问状态。质押的定义以借贷平台为准：借贷平台的“已质押”对外显示已质押，“可质押”和“已释放”对外都显示未质押。不使用代币发行平台的质押状态，不从地址形态推断质押结果。

**每个持有方的质押状态：**

| 该持有方的当前事实 | 质押状态 | 所属融资项目 |
| --- | --- | --- |
| 企业地址持有，没有质押记录 | 未质押 | — |
| 质押上链处理中或失败（代币仍在原地址） | 未质押 | — |
| 质押合约地址持有，代币仍属于该项目（含已失效、解押或撤回已发起但链上转出尚未成功） | 已质押 | 该融资项目 |
| 质押合约地址持有，项目关闭或结清后已业务释放、尚未提取 | 未质押 | — |
| 解押、撤回或提取已转出完成 | 未质押（持有方已变为转回的地址） | — |

- 质押状态只按持有方逐个展示；代币本身不设质押状态，列表、概览和筛选都不使用质押状态。
- 持有方信息暂不可用时，不展示任何持有方的质押状态，也不默认未质押，按[持有方信息不可用](#holding-errors)处理。
- 已质押只说明该数量在质押合约内；是否计入有效质押、有效质押额和质押率归融资需求与代币质押模块，本模块不展示。
- 不把融资需求的生命周期或额度冻结状态放到代币上。内部状态编号不出现在界面、页面地址和中英文文案中。

**所属融资项目的去向：**

- 项目已发布、公开可见时，给出项目名称，并可进入借贷广场中该项目的既有详情（地址由融资需求与代币质押模块定义），不增加新参数或办理动作；进入后能看到的内容按借贷广场对当前身份的规则。
- 项目已关闭或已结清时，仍可进入该项目详情并看到其当前状态，不报“内容不存在”、不静默跳回首页，也不让用户停在无法继续的页面。
- 项目已通过审核但尚未发布时，只显示“所属融资项目尚未公开”，不显示项目名称和链接。
- 项目关系核对不上时按持有方信息暂不可用处理，不能当作尚未发布。
- 未质押的持有方，所属融资项目显示“—”，不显示历史项目。
- 本模块不要求借贷广场或我的控制台新增指回资产广场的入口。

状态参见：[质押状态（ST-AM-02）](./02-资产广场-流程图与状态机.md#ST-AM-02)。

## 9. 信息来源与时效（F-AM-13）

适用角色与前提：所有访问状态。本节只定义各类信息以谁为准和展示结果；信息如何取得、何时刷新由研发决定。

| 信息 | 以谁为准 |
| --- | --- |
| 代币是否已准入、平台代币标识 | 运营端代币准入审核 |
| [代币信息](#token-fields)的全部字段 | 代币发行平台 |
| 持有方及各自的持有数量 | 代币发行平台 |
| [基础资料信息](#business-fields)、链上存证 | 资产可信平台 |
| 质押状态、所属融资项目、项目是否公开及其当前状态 | 借贷平台 |

- 代币进入资产广场的唯一前提是准入通过，规则见[哪些代币出现在资产广场](#F-AM-15)；本模块自身没有上架动作。
- 代币变为失效时，当日可见：列表与详情显示失效，头部汇总不再计入。
- 本地日期越过底层应收账款到期日，本平台也不自行把代币改为失效，以代币发行平台的事实为准。
- 较早的事实不能覆盖较新的事实；同一事实重复到达，不改变数量或状态。
- 上游暂时无法提供信息时，继续展示最近一次可用的信息，不清空，也不向用户显示同步故障、数据更新时间或核对差异。
- 本平台页面自身读取失败时，按[空结果与读取失败](#F-AM-11)给出可重试的说明，与上游暂时不可用的处理不同。

流程参见：[信息来源与公开浏览（FL-AM-01）](./02-资产广场-流程图与状态机.md#FL-AM-01)。

## 10. 共同要求与访问保护（F-AM-12）

| 要求 | 规则 |
| --- | --- |
| 金额 | 金额带币种，2 位小数 |
| 时间 | 以 UTC 为基准，按用户时区显示并标明时区；游客使用浏览器时区；不出现不带时区的时间 |
| 中英文 | 默认英文；切换语言不需要刷新，字段名称、状态、空结果说明、筛选、汇总和各类说明全部切换。只使用本平台术语表中的译法，新术语未收录前不自造译法 |
| 链的名称 | 铸造链、存证链和列表中的网络都展示链的全称，不用缩写 |
| 信息完整 | 在任何展示条件下，代币编号、代币价值和代币状态都不省略、不隐藏；每个持有方的五项信息都完整可得 |
| 页面信息边界 | 页面不展示规则编号、来源说明或依赖表 |
| 搜索引擎收录 | 列表和详情允许被搜索引擎收录，详情可直接打开；收录内容同样限于公开信息 |
| 防批量获取 | 列表每批 20 笔；限制单位时间内的访问频次，触发时给出友好提示，不硬性阻断正常浏览；不提供导出、下载或批量获取入口 |
| 性能 | 10 万笔代币时，列表首次可见结果不超过 2 秒。该目标为已确认约束，实现与验证归研发和测试 |
