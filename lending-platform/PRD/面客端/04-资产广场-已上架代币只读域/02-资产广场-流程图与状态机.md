<a id="FL-AM-01"></a>
## 信息来源与公开浏览（FL-AM-01）

```mermaid
flowchart TD
  T[代币发行平台推送代币] --> A{运营端代币准入审核结论}
  A -->|待审核或已退回| N[不出现在资产广场，不计入汇总，详情显示内容不存在]
  A -->|已通过| B{关键字段齐全?}
  S[资产可信平台提供基础资料信息与链上存证] --> D
  P[借贷平台提供质押状态与所属融资项目] --> D
  B -->|否| C[该笔代币不展示、不计入汇总，运营侧可察觉]
  B -->|是| D[进入资产广场的展示范围，含失效代币；只取公开信息]
  D --> Q[头部汇总只统计有效代币]
  D --> E[任一访问状态进入资产广场，看到的内容相同]
  E --> F[按当前条件给出头部汇总、匹配笔数与第一批 20 笔<br/>筛选每项可多选：同项取并集、项间取交集<br/>匹配笔数含失效代币，不属于头部汇总]
  F --> G[继续浏览时按同一条件追加；可在当前页面内放大为放大态，收起后视图不变]
  G --> H[打开某笔代币的详情]
  U[上游暂时无法提供信息] --> V[继续展示最近一次可用的信息，不显示故障]
  V --> E
```

准入通过是终态，本期没有下架；通过后代币失效、持有方变化或资料变更都照常按事实展示。代币变为失效当日可见，并从当日起退出头部汇总；较早的事实不覆盖较新的事实。信息如何取得、何时刷新由研发决定。

## 查看详情与跳转（FL-AM-02）

```mermaid
flowchart TD
  A[列表中的一笔代币或分享链接] --> B{按平台代币标识找到代币，且已准入、可展示?}
  B -->|否，含标识格式不合法、待审核、已退回| C[内容不存在]
  B -->|是| D[详情：概览、代币信息、基础资料信息、链上存证、持有方]
  D --> E{用户选择}
  E -->|已发布的所属融资项目| F[在当前窗口进入借贷广场项目详情]
  F --> G[按当前身份显示项目可见内容与当前状态，关闭或结清的项目仍可打开]
  E -->|尚未发布的所属融资项目| H[只提示所属融资项目尚未公开，无名称和链接]
  E -->|区块浏览器| I[在新窗口打开区块浏览器]
  E -->|经唯一登录入口主动登录| J[由登录主干处理，返回后内容不变]
  E -->|返回列表| K[恢复条件、已加载范围和浏览位置]
```

<a id="FL-AM-03"></a>
## 持有方与质押（FL-AM-03）

```mermaid
flowchart TD
  A[查看一笔代币的持有方] --> B{有持有方，且每个持有方都有地址和大于 0 的数量?}
  B -->|否| X[持有方信息暂不可用，其他信息照常展示]
  B -->|是| C{持有数量合计等于代币数量?}
  C -->|否| X
  C -->|是| D{质押合约持有与借贷平台的质押记录一致?}
  D -->|否| X
  D -->|是| E[逐个展示持有方]
  E --> F{该持有方是质押合约，且代币仍属于该项目?}
  F -->|是，含已失效、转出尚未成功| G{所属项目已发布?}
  G -->|是| H[已质押，给出项目名称与项目详情入口]
  G -->|否| I[已质押，只提示所属融资项目尚未公开]
  F -->|项目关闭或结清后已释放、尚未提取| J[未质押，项目为“—”，地址仍为质押合约]
  F -->|否，企业地址或上链处理中、失败| K[未质押，项目为“—”]
  H --> L[在持有方清单中逐行给出质押状态与所属项目]
  I --> L
  J --> L
  K --> L
```

质押状态只在持有方清单中逐个持有方展示；代币本身不设质押状态，列表与概览都不展示。一笔代币的持有方可以分属不同融资项目。

<a id="ST-AM-01"></a>
## 代币状态（ST-AM-01）

```mermaid
stateDiagram-v2
  state "有效" as Valid
  state "失效" as Invalid
  [*] --> Valid: 准入通过时代币发行平台给出有效
  [*] --> Invalid: 准入通过后首次取得即为失效
  Valid --> Invalid: 代币发行平台确认失效
```

图中起点是代币开始在资产广场展示（准入通过）。准入审核只能通过有效代币，但通过后到首次展示之间可能已变为失效，此时直接以失效展示。本地日期越过账期到期日不触发转换。失效后仍在列表和详情中展示，但不再计入头部汇总；本期没有销毁或恢复。

<a id="ST-AM-02"></a>
## 质押状态（ST-AM-02）

对象是一个持有方所持的数量。

```mermaid
stateDiagram-v2
  state "未质押" as Unpledged
  state "已质押" as Pledged
  [*] --> Unpledged: 不在任何质押合约中
  [*] --> Pledged: 已在质押合约中且仍属于该项目
  Unpledged --> Unpledged: 质押上链处理中或失败
  Unpledged --> Pledged: 质押上链转入成功
  Pledged --> Unpledged: 解押或撤回转出成功
  Pledged --> Unpledged: 项目关闭或结清，业务释放（待提取）
```

已质押不等于已通过审核。业务释放后，即使代币仍在质押合约中等待提取，也显示未质押。

<a id="ST-AM-03"></a>
## 列表视图状态（ST-AM-03）

```mermaid
stateDiagram-v2
  state "第一批加载" as Initial
  state "可浏览" as Ready
  state "追加中" as More
  state "追加失败，保留已加载记录和位置" as MoreError
  state "第一批失败，可重试" as Error
  state "全局无数据或筛选无结果" as Empty
  state "已到末尾" as End
  state "恢复条件、已加载范围和位置" as Restore
  state "恢复失败，保留原视图" as RestoreError
  [*] --> Initial: 没有历史视图
  [*] --> Restore: 刷新、分享、返回或前进后退
  Restore --> Ready: 恢复完成，还有后续
  Restore --> End: 恢复完成，没有后续
  Restore --> Empty: 当前结果为空
  Restore --> RestoreError: 读取失败
  RestoreError --> Restore: 重试
  Initial --> Ready: 成功且还有后续
  Initial --> End: 第一批已含全部结果
  Initial --> Empty: 没有匹配结果
  Initial --> Error: 读取失败
  Error --> Initial: 重试
  Ready --> More: 继续浏览需要更多记录
  More --> Ready: 追加成功且还有后续
  More --> End: 最后一批成功
  More --> MoreError: 追加失败
  MoreError --> More: 重试同一批
  Ready --> Initial: 修改筛选、搜索或排序
  End --> Initial: 修改条件
  Empty --> Initial: 修改条件或重置筛选
```
