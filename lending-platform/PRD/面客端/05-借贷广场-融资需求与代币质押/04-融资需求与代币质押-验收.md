## 0. 验收前准备

账号：

- 两家不同企业的资产方各一个（甲、丙），均已认证。
- 资金方两个：一个已认证、对甲有授信并能报价；一个已认证但与甲的项目无业务。
- 登录未绑定角色的账号一个；游客（未登录）状态。
- 运营账号一个，具备代币准入审核、融资参数配置、项目审核与合约配置权限。

数据：

- 甲名下多张 Ethereum 上的同类型已准入代币（ERC-3525-应收账款），含有效、失效各若干；其中地址 A 持有同一个代币发行合约铸造、资产槽位各不相同的 10 笔，另持有另一个代币发行合约铸造的若干笔；甲另有准入待审核、已退回的代币各一张；丙名下已准入代币若干。
- 被其他项目占用、正在上链处理中、带对账差异标记的代币各一张；已对某质押合约授权但未完成质押的份额一份。
- 融资参数组合：“Ethereum＋ERC-3525-应收账款”已配置，最高质押率 80%、最长项目期限 12 个月；另一已配置组合最长项目期限 6 个月；甲持有已准入代币、但组合未配置的代币类型一个。
- 共用合约：同一组合下已配置的两个项目（甲、丙各一个），共用同一份质押合约。
- 项目样本：待审核、已退回、合约配置进行中、可用（空池）、募集中、已锁定、融资中、已关闭、已结清各一个。
- 额度样本：质押充足、质押持平、质押不足的项目各一个；其中质押不足的项目合约内同时有有效抵押物与已失效代币。
- 一轮已成交（链上放款成功）且仍在还款中的业务；一轮已签名接受、链上放款处理中的报价。
- 平台执行钱包可用与不可用两种环境。
- 企业账户样本：甲已登记 Ethereum 数币账户两个（其中一个信息不完整）与法币账户一个；另一资产方未登记任何数币账户。
- 链上结果样本（授权、质押、发布与改额冻结、解押、提取分别准备）：明确成功、明确失败（已产生 gas、未产生 gas、gas 待核实）、长期未知。
- 日期样本：创建日为 11 月 30 日、8 月 31 日的项目；退回后间隔较长才重提的项目。

| <a id="AC-LS-76"></a><a id="ac-ls-76"></a>AC-LS-76<br>代币失效或对账差异 | 观察需求失效判断 | 先重算有效价值，再按较早保留的需求逐笔判断是否被覆盖，不用旧值放行 |
| <a id="AC-LS-77"></a><a id="ac-ls-77"></a>AC-LS-77<br>需求不再被有效质押额覆盖 | 观察需求 | 立即失效，没有缓冲、补质押倒计时或保留窗口 |
| <a id="AC-LS-78"></a><a id="ac-ls-78"></a>AC-LS-78<br>有多笔需求可失效的场景；没有需求可失效的场景 | 观察失效过程 | 按发布时间倒序失效最少必要的笔数，每笔后重算，满足即停；没有需求可失效时停止，不空转 |
| <a id="AC-FIN-26"></a><a id="ac-fin-26"></a>AC-FIN-26<br>多笔需求 | 逐笔判断是否失效 | 按发布时间正序累计已保留的金额；对每一笔，若“有效质押额 − 项目融资余额 − 更早已保留金额合计”小于本笔金额，则该笔失效 |
| <a id="AC-LS-79"></a><a id="ac-ls-79"></a>AC-LS-79<br>一笔需求失效 | 查看在途与融资余额 | 立即释放该轮在途占用，不计入融资余额 |
| <a id="AC-LS-80"></a><a id="ac-ls-80"></a>AC-LS-80<br>需求失效时有在途报价 | 资金方与资产方查看 | 需求与在途报价同时失效，不会出现需求已失效而报价仍可接受 |
| <a id="AC-LS-81"></a><a id="ac-ls-81"></a>AC-LS-81<br>一笔需求因质押水位不足失效 | 查看记录与项目状态 | 原融资申请编号与“自动失效·质押水位不足”原因可查；不新增项目状态 |
| <a id="AC-LS-83"></a><a id="ac-ls-83"></a>AC-LS-83<br>需求失效但债务仍被覆盖；质押不足但没有在途需求 | 观察两类事实 | 两者互不为前提：需求失效时项目可能并非质押不足；质押不足且没有在途需求时不触发失效动作 |
| <a id="AC-LS-25"></a><a id="ac-ls-25"></a>AC-LS-25<br>同一项目与代币 | 在我的控制台、资产广场、借贷广场查看 | 同一事实三处结论一致：资产广场持有方清单中的已质押／未质押与本模块的在池情况对应，控制台与本模块的额度、质押情况同值；各处按各自模块的展示范围呈现，不要求文案相同 |
| <a id="AC-LS-120"></a><a id="ac-ls-120"></a>AC-LS-120<br>一张已质押且上链成功的代币；所属项目分别为已发布与从未发布 | 在资产广场与本模块分别查看 | 所属项目已发布时，资产广场显示“已质押”并可跳转所属项目；从未发布时显示已质押但所属项目尚未公开、不可跳转；本模块显示已质押并计入有效质押；两处结论一致 |
