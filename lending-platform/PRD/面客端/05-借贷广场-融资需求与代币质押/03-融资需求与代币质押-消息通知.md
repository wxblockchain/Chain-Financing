# 融资需求与代币质押 · 消息通知

2026-10-22｜需求评审稿

本册写本模块发送的站内信，规则以[功能与业务规则](./01-融资需求与代币质押-PRD.md)为准。只有站内信，没有邮件、短信、浏览器推送或运营广播。

- 本模块自己发送 6 类：链上操作失败、融资需求链上操作失败、融资需求终结、质押不足、质押不足解除、项目届满前 7 天。
- 另有 2 类与本模块业务相关、但由相邻模块发送：项目审核通过与退回由[运营端项目合约管理](../../运营端/04-运营端项目合约管理/01-运营端项目合约管理-PRD.md)发送。它们的模板沿现行约定在本册维护，触发与收件以发送模块为准。
- 代币质押没有审核环节，质押成功不发送站内信（用户 2026-10-21 裁定，[Q-LS-02](./01-融资需求与代币质押-PRD.md#q-ls-02)）；授权结果也不发送。
- 资产广场、我的控制台和消息中心展示同一事实，不各自补发。
- 本期一个企业只有一个账号；发给“资产方”的消息即发给该企业的唯一账号。

编号说明：事件编号（N-LS-*）与模板编号（T-LS-*）被其他模块引用，沿用原值；缺号不代表遗漏。

## 3. 不发送的情况

- 创建项目提交、授权（成功或失败）、发起质押签名、发布、改额或撤下的签名确认、发布、改额与撤下成功、关闭等操作的当场结果。
- 冻结解除的处理与结果（由平台执行）。
- 项目审核过程中的提醒与催办。
- 上链已发起、处理中、成功（即质押成功）；批次整体进度。
- 链上结果长期未知、跨期、冲突，以及联系客服的进度。
- 可提取、提取成功。
- 项目到期前 30 天、到期当天。
- 质押不足持续期间仅金额变化。
- 项目长期停留空池、空池数量变化。
- 合约配置失败、结果待核实与再次发起（运营端内部处理）。
- 共用合约随版本更新。
- 浏览、复制、下载、页面读取失败与代币同步。

## 4. 重复与新事实

- 同一账号、同一事件、同一业务事实只收一条：项目审核按本次结论区分，链上失败按本笔交易，冻结失败按本次动作，需求终结按原轮次，质押不足按本轮触发或解除，届满提醒按项目有效期。
- 重复送达不新增未读、不恢复未读、不置顶、不改发生时间；补齐原因或费用不重发。
- 新的实际动作、新一轮质押不足、重新提交后的新结论，各自是新事实，各发一条。
- 同一笔交易涉及的多张代币失败只发一条，列出全部代币；不同交易的失败各发一条。
- 消息保存发生时的事实；点击时按当前权限与阶段判断。旧消息仍指向原对象，不开新轮、不自动执行；无权或目标不可用时按消息中心的既有降级处理，不泄露私有文件、钱包或下载链接。
- 资产方与资金方账号、面客端与运营端相互隔离；同钱包、同企业、同机构不自动串信。无法确定归属时不改投他人。
- 投递失败不回滚业务，用户仍可从业务本身查到结果。符合条件的消息在消息中心既有的 60 秒内可见。

## 5. 文案

固定文案提供中英两套，变量集合一致。时间按 UTC 判定、按收件人时区显示并标注；金额带币种；未知的 gas 写“待核实”，不写 0；人工原因原样展示，不截断。

| 变量 | 业务含义 |
| --- | --- |
| project_name / project_id | 发生事件的项目名称与项目编号 |
| token_ids | 本笔交易涉及的全部代币的完整业务编号，多张时全部列出、以顿号分隔（英文以逗号分隔），不是钱包地址或链上 tokenId |
| action_id | 本次实际链上动作的业务标识，用于区分同一代币的多次操作 |
| demand_id | 相关的那一轮融资申请编号：需求终结时为终结的那一轮，改额冻结失败时为被修改的那一轮 |
| approved_at | 项目审核真实通过时间 |
| occurred_at / expires_at | 事件发生时点；项目有效期至 |
| reason | 面客可读的原因全文：项目审核退回取退回原文，链上失败取失败说明 |
| shortfall / additional_value | 事件发生时的质押缺口与需追加资产价值，USD，两位小数 |
| fee_amount / fee_currency | 已确认实际产生的 gas 金额与币种 |
| contract_address | 本项目所配置的质押合约地址（同组合项目共用） |
| operation | 冻结失败的操作：“发布融资需求”（publishing a financing request），或“修改融资申请 {demand_id} 的金额”（changing the amount of financing request {demand_id}） |
| amount | 本次发布或修改后的需求金额，USDT，两位小数 |

### 5.3 融资需求链上操作失败

只有链上结果已明确失败才发送。{operation} 按变量表取值：发布失败时没有融资申请编号；改额失败时带出被修改那一轮的融资申请编号。冻结交易由平台执行钱包发送，资产方不承担费用，因此不分 gas 情形。
