```mermaid
flowchart TD
  A0["资产方创建融资项目<br/>先选区块链网络（本期以太坊）<br/>名称 + 代币类型 + 自填质押率 + 选择项目到期日<br/>+ 参考结算币种，核对还款方式与SPV机构名称"] --> A1["提交审核 · 项目待审核<br/>私有、不可质押、不可发布、零费用、无链上动作"]
  A1 --> A2{"运营核对创建信息"}
  A2 -- "退回并给出面客可读原因" --> A3["项目已退回<br/>资产方可修改后重新提交<br/>项目期限不重新起算"]
  A3 --> A1
  A2 -- "通过 · 由平台统一钱包部署质押合约" --> A4{"部署结果"}
  A4 -- "签名或部署失败" --> A5["视为审核未完成，仍为待审核<br/>由运营再次发起，不需要资产方重提<br/>部署 gas 由平台承担"]
  A5 --> A2
  A4 -- "部署成功 = 审核通过" --> A6["项目可用 · 产生唯一质押合约地址<br/>空池：可质押、暂不可发布"]
  A6 --> A["资产方在项目详情发起质押并勾选代币<br/>按本项目代币类型过滤，按质押份额整份勾选，不能拆分数量<br/>一次只能勾选同一持有地址的份额<br/>已选份数与价值随勾选更新"]
  A --> H["点击「签名并发起质押」· 唯一确认，点击即唤起钱包<br/>逐张复核资格；签名时可见已选汇总、预估 gas 合计与后果说明"]
  H -- "资格变化，尚未签名" --> I["不唤起签名，指明变化张<br/>更新集合与预估 gas，用户再次点击才发起"]
  I --> H
  H -- "取消签名、钱包不可用或未发起" --> J["本次无链上操作、无 gas，代币保持可质押"]
  H -- "用户签名发起" --> K["资产方地址向本项目质押合约转入<br/>逐张处理中，不计任何额度"]
  K --> L{"本张真实上链结果"}
  L -- "明确失败" --> N["本张未进入合约，保持可质押<br/>显示原因与已产生 gas，可重新发起"]
  L -- "结果未知、跨期或冲突" --> O["显示等待与已知 gas，提示联系平台客服<br/>不自动失败释放，不重复发起"]
  L -- "明确成功" --> M["代币进入质押合约 · PS-2<br/>计入待审质押额，暂不计入有效质押额"]
  M --> C["运营逐笔审核 · 无时效管控<br/>不因等待自动通过或自动失败"]
  C -- "本笔通过" --> P["计入有效质押额，参与质押情况判断<br/>从待审质押额移出；协议与审核人可查"]
  C -- "本笔驳回" --> Q["原因原文可见；代币仍在合约内<br/>继续计入待审质押额，须自助解押取回"]
  C -- "裁定前资产方自助撤回" --> R["资产方签名向合约发起解押<br/>gas 自担；本笔终结为已撤回"]
  Q --> S["自助解押取回原持有地址<br/>无占用后恢复可质押"]
  R --> S
  P --> T["项目按实际有效质押额可发布融资需求"]
```

三件事分别判断：项目审核决定项目能不能用，上链结果决定代币在不在合约里，逐张审核决定这张代币算不算有效质押额。全流程没有时限。

```mermaid
flowchart TD
  A["资产方 · 进入解除质押"] --> B["勾选份额 · 每份标明所属类别<br/>待审 · 已驳回 · 已失效 · 有效抵押物 · 已释放待提取<br/>一次只能勾选同一原持有地址的份额<br/>已选份数与价值随勾选更新，预估 gas 只给合计"]
  B --> C{"这张代币属于哪一类"}
  C -- "待审 / 已驳回" --> D["不受额度与质押水位约束<br/>仍须无处理中占用或对账差异"]
  C -- "有效抵押物 / 已失效代币" --> W{"质押水位不安全？<br/>有效质押额 < 项目融资余额＋在途"}
  W -- "是" --> X["已通过审核的代币一律不能转出<br/>不可选并说明原因"]
  W -- "否 · 已失效代币" --> D
  W -- "否 · 有效抵押物" --> E{"拟撤回价值 ≤ 可撤回上限 ?"}
  E -- "否" --> F["给出拟撤回价值 · 可撤回上限 · 差额<br/>两条出路：减少勾选 / 等待还款释放余额"]
  E -- "是" --> D
  C -- "已释放 · 待提取" --> G["提取 · 不做额度判定<br/>业务已在项目终态时释放"]
  D --> CONF["点击「签名并解除质押」或「签名并提取」<br/>唯一确认，点击即唤起钱包 · 逐张复核资格与预估 gas<br/>有变化则不唤起签名，指出后再次点击"]
  G --> CONF
  CONF --> H["资产方签名向本项目质押合约发起转出<br/>有效抵押物撤回立即预扣其有效价值"]
  H --> I["合约按记录转回质押前的原持有地址<br/>gas 自担，失败不退"]
  I -.-> J{"按张回写结果"}
  J -. "成功 · 解押或撤回" .-> K["转回原地址，质押记录已释放<br/>无占用后按资格可再质押，额度重算"]
  J -. "成功 · 提取" .-> L["转回原持有地址<br/>无占用后按当前资格可质押"]
  J -. "失败 · 解押或撤回" .-> M["仍在合约内，预扣撤销<br/>重新勾选后可再次签名发起"]
  J -. "失败 · 提取" .-> N["保持已释放待提取<br/>不影响项目额度，重新勾选后可再次签名发起"]
  J -. "未知、跨期或冲突" .-> O["保留真实状态、gas 与保护限制<br/>提示联系平台客服"]
```

质押水位不安全（有效质押额低于项目融资余额＋项目在途金额）时，已通过审核的代币（有效抵押物与已失效代币）一律不能转出；判据与需求失效（FL-LS-04）相同。待审、已驳回与已释放待提取的代币不受影响。
