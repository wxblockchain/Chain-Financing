```mermaid
  U --> Q
  S -->|"质押水位不安全已证实"| V["需求按融资需求模块规则自动失效<br/>不生成业务或占用"]

  S -->|"授信又不足"| D

  W --> Z["结束本次办理<br/>刷新申请与相关入口<br/>不自动打开详情"]
```

质押水位未知与已证实不安全走不同出口；授信保存独立生效，之后报价取消或失败都不回滚授信。

## 接受与拒绝（FL-CR-02）

```mermaid
%%{init: {"flowchart": {"htmlLabels": false, "wrappingWidth": 400}}}%%
flowchart TD
  A["资产方从融资业务入口<br/>选择本笔报价进入接受办理"] --> B{"本笔仍待接受？"}
  B -->|"否"| X["说明最新结果<br/>停用旧动作"]
  B -->|"是"| C["查看条款、当前池况与已锁定时长<br/>可按需查看预计还款计划"]
  C --> D{"资产方决定"}
  D -->|"拒绝"| R["填写 1～200 字拒绝原因"]
  R --> R1{"仍可拒绝且<br/>原因有效？"}
  R1 -->|"否"| X
  R1 -->|"是"| R2["已拒绝，释放本笔在途报价金额<br/>需求仍有效时回到待报价<br/>项目在途金额与质押不变"]
  D -->|"接受"| E["从企业账户已登记的账户中选用<br/>USD 选法币账户<br/>USDT / USDC 选数币账户<br/>逐笔显式确认"]
  E --> F{"账户可用<br/>并已确认？"}
  F -->|"否"| E1["说明原因：尚未登记、<br/>读取失败或信息不完整<br/>引导到企业账户"]
  E1 --> E
  F -->|"是"| G["查看商务摘要<br/>手续费与本金告知始终可得<br/>摘要不是合同<br/>合同由双方线下签署"]
  G --> J["资产方提交接受"]
  J --> K{"账户未变更、摘要已查看<br/>且本笔仍待接受？"}
  K -->|"需求已终结或本笔已处理"| X
  K -->|"账户已变更"| E
  K -->|"是"| L["待放款，两个维度的在途金额保持<br/>同一业务进入融资放款信息<br/>待放款无时限、无平台侧终止出口"]
```

账户确认与摘要查看只是待接受内的办理进度，停留多久都不改变结论；拒绝不需要先完成这些步骤。

```mermaid

  F --> F1["融资需求模块发送<br/>融资需求终结通知（N-LS-05）<br/>本模块不另发报价失效消息"]
  A2 --> G["保留原融资业务编号<br/>快照与终结原因"]
  F1 --> G
  G --> H{"需求与项目<br/>仍允许新报价？"}
  H -->|"是"| I["任何机构可重新报价<br/>新编号、新快照"]
  H -->|"需求已终结"| J["资产方按融资需求模块规则重新发布<br/>旧报价不能恢复"]

```

报价没有有效期，不存在自动到期分支。项目关闭不出现在本图：有待确认报价的项目不能关闭。失效记录需求的实际终结时刻与具体原因；同一笔只有一个正式结果。

<a id="st-cr-01"></a>
## 授信生命周期（ST-CR-01）

```mermaid
stateDiagram-v2
  direction LR
  state "生效中" as ACTIVE
  state "已到期" as EXPIRED
  [*] --> ACTIVE: 首次核定成功
  ACTIVE --> EXPIRED: 有效期至次日<br/>00:00 UTC
  EXPIRED --> ACTIVE: 报价流程内<br/>重新核定成功
  note right of ACTIVE
    追加：正数增加额
    有效期至保持
    或在五年上限内延后
    状态不变；协议均为选填
  end note
```

追加不重置五年上限的起点；授信到期只阻止新报价，不影响已有业务。

<a id="st-cr-02"></a>
## 融资业务本模块状态（ST-CR-02）

```mermaid
stateDiagram-v2
  state "待接受" as WAIT
  state "已拒绝" as REJECTED
  state "报价已失效" as EXPIRED
  state "待放款" as FUNDING
  [*] --> WAIT: 报价成功<br/>生成融资业务编号<br/>增加在途报价金额
  WAIT --> REJECTED: 资产方拒绝<br/>原因必填
  WAIT --> EXPIRED: 所属需求终结<br/>项目到期或<br/>质押水位不足
  WAIT --> FUNDING: 账户已确认<br/>摘要已查看<br/>资产方接受
  REJECTED --> [*]
  EXPIRED --> [*]
  note left of WAIT
    账户确认与摘要查看
    只是办理进度
    不改变状态，没有时限
  end note
  note right of FUNDING
    后续由放款、还款模块承接
    此处不是终态
    待放款没有时限
    唯一出口是资金方提交放款
  end note
```

待接受、已拒绝、待放款、报价已失效对应融资业务状态 S-FD-1、S-FD-2、S-FD-3、S-FD-11；已拒绝与报价已失效不能恢复。待放款之后的待放款确认（S-FD-4）与还款中（S-FD-6）由[放款与放款确认](../07-借贷广场-放款与放款确认/01-放款与放款确认-PRD.md)定义。本状态机没有按时间自动发生的转移。
