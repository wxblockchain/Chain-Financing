# 企业账户 · 验收

2026-10-15｜需求评审稿｜供测试使用

本册只写验收标准，测试用例与执行步骤由测试小队编写。规则见[功能与业务规则](./01-企业账户-PRD.md)，各节顺序与功能册一致。

怎么读：

- 共 37 条验收。编号沿用原值，已删除的条目不再占号，所以编号不连续，缺号不代表遗漏。
- 一条验收写了多个场景时，全部场景都满足才算通过。

## 0. 验收前准备

账号：

- 已认证资产方、已认证资金方各一个，分属不同企业。
- 未认证资产方一个；审核中资金方、已驳回资金方各一个。
- 已登录但未绑定角色的账号一个；游客（未登录）状态。
- 正常运营人员账号一个（含按运营角色工作的 SPV 职能）。

数据：

- 测试人员自己控制私钥的 ETH 地址和 TRON 地址各至少两个；另准备一个当前登录用的 ETH 地址，与待登记地址不同。
- 无法签名的地址样本：交易所充值地址或合约地址各一个。
- 法币账户样本：含空格、含小写字母的账号 / IBAN 与 SWIFT / BIC；7 位、8 位、11 位、12 位的 SWIFT / BIC。
- 企业名称样本：一个资产可信平台已同步企业名称的资产方、一个审核通过机构名称的资金方；一个取不到企业名称的账号，用于验证不能新增法币账户；一个之后会变更企业名称的企业（资产方由上游同步新名称，或资金方机构名称变更审核通过），并已有一笔使用其法币账户提交的业务记录。
- 长度样本：恰好 100 个字符和 101 个字符的文本；很长的、含中文与带重音字母的开户行地址文本。
- 一个缺少当前必填项的已登记法币账户（例如没有账户类型）。
- 一笔可以接受的报价和一笔可以登记放款的业务，用于选用与回流；一笔已经提交、使用了某个账户的业务记录。
