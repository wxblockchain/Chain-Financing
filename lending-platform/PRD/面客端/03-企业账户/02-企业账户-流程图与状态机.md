## 账户总览与新增入口（图 1）

对应[账户总览（F-EA-01）](./01-企业账户-PRD.md#f-ea-01)。

```mermaid
flowchart TD
    A[双侧用户进入企业账户] --> B{正常登录且角色已绑定?}
    B -->|否| C[按主干规则处理：不返回任何账户数据]
    B -->|是| D{当前业务资格为已认证?}
    D -->|否| E[可见入口与用途说明；给补齐资格引导<br/>不返回账户数据，不提供维护动作]
    D -->|是| F[读取本企业账户]
    F -->|读取失败| G[说明暂时不可用并可重试<br/>不表达为尚未登记，不要求重新录入]
    G --> F
    F -->|本企业无账户| H[明确空态并直接给新增出路]
    F -->|已有账户| I[按法币账户、数币账户两类分别呈现<br/>按登记时间倒序一页列全，不分页，无默认标记<br/>信息不完整的账户标注待补项]
    H --> J{新增哪类账户?}
    I --> J
    I --> K[对某账户：查看完整信息 / 修改 / 删除]
    J -->|法币| L[进入法币账户新增]
    J -->|数币| M[进入数币账户新增]
```

运营人员与 SPV 不出现在本图任何分支：任何入口与直接请求都被拒绝，见[谁能使用（P-EA-01）](./01-企业账户-PRD.md#p-ea-01)。

<a id="fig-2"></a>
## 法币账户新增与修改（图 2）

对应[新增法币账户（F-EA-02）](./01-企业账户-PRD.md#f-ea-02)与[修改账户（F-EA-04）](./01-企业账户-PRD.md#f-ea-04)。

```mermaid
flowchart TD
    A[已认证一侧进入法币账户新增或修改] --> A1{新增时能取到本企业当前名称?}
    A1 -->|否| A2[说明暂时无法取得企业名称，不能新增法币账户<br/>可稍后重试；不提供手填账户名称]
    A1 -->|是，或为修改| B[账户名称由平台按本企业当前名称带出，不可修改<br/>填写账户类型、账户备注名、账户币种（USD / EUR / GBP 可多选，只作标注）<br/>账号/IBAN、开户行名称、开户行地址、SWIFT/BIC<br/>无收款人名称、无中转行、无账户持有人信息和开户行国家]
    B --> C{必填齐备、已选账户类型且至少选一个账户币种?}
    C -->|否| D[逐项定位缺失项；不笼统报保存失败]
    D --> B
    C -->|是| E{SWIFT/BIC 为 8 或 11 位字母数字?}
    E -->|否| F[拒绝保存并定位到该项]
    F --> B
    E -->|是| K{本企业内已有同账号/IBAN 且同 SWIFT?}
    K -->|是| L[拒绝并可直接查看已存在那一条]
    K -->|否| M[提交保存]
    M -->|失败| N[保持上一次成功状态，不产生半条账户，可重试]
    N --> B
    M -->|成功| O[保存即生效：不进审核、不产生待办<br/>立即出现在总览与业务选用列表]
    O --> P[已提交业务记录中的账户快照不变]
```

修改与新增走同一套校验；除账户名称外的字段都可修改。企业名称变更后，已登记法币账户的账户名称随之更新，已提交业务记录的快照不变。账户币种只作标注：平台不核验银行是否支持、业务选用也不据此过滤或拦截。取消或离开不保留未提交内容，本模块不设草稿。

## 数币账户新增与地址所有权签名（图 3）

对应[新增数币账户（F-EA-03）](./01-企业账户-PRD.md#f-ea-03)。

```mermaid
flowchart TD
    A[已认证一侧进入数币账户新增] --> B[先告知可登记范围：只能登记你能签名的地址<br/>交易所充值地址、第三方托管地址、无法签名的合约地址不支持]
    B --> D[同一环节：选择结算收款链（ETH 或 TRON，不预选）<br/>并填写数币地址与账户备注名]
    D --> E{已选链且地址符合所选链的格式?}
    E -->|否| F[未选链时提示先选链；已选链则按所选链说明格式要求<br/>ETH 为 0x 加 40 位十六进制；TRON 为 T 开头 Base58<br/>不提示另一条链的规则]
    F --> D
    E -->|是| G{本企业内同链同地址已登记?}
    G -->|是| H[拒绝并说明该地址已登记]
    G -->|否| I[请求用被添加的那个地址签名<br/>说明用途为证明地址归属，并说明不改变登录方式]
    I -->|钱包环境不可用或不支持该链| J[说明原因与可执行下一步；本次不登记]
    I -->|用户拒签、失败或超时| K[本次未完成签名，账户未登记，可重试]
    I -->|签名地址与要登记的地址不同| L[明确签名地址与要登记的地址不是同一个]
    J --> D
    K --> D
    L --> D
    I -->|签名通过| M[地址所有权确认为已确认]
    M --> N[登记成功：可被业务选用<br/>记录登记时间]
    N --> O[结算收款链与数币地址此后不可修改<br/>换地址须新增并重新签名]
```

签名不建立登录会话、不切换登录钱包、不参与登录地址匹配、不改变角色绑定，也不改绑登录凭据；被添加地址可与登录地址不同、可在另一条链上。与登录的关系见[地址所有权签名不是登录](./01-企业账户-PRD.md#ownership-signature)。任何失败分支都不改变当前登录、不产生半条账户，也没有“稍后验证”“跳过验证”或运营代确认的出路。

## 删除账户与已提交记录的关系（图 4）

对应[删除账户（F-EA-05）](./01-企业账户-PRD.md#f-ea-05)与[已提交业务的账户快照](./01-企业账户-PRD.md#snapshot)。

```mermaid
flowchart TD
    A[已认证一侧选择某账户并删除] --> B{是该类最后一个可用账户?}
    B -->|是| C[确认时额外告知：将无可选的法币账户/该链数币账户<br/>相关业务办理无法提交，可重新登记]
    B -->|否| D[显式确认：删除后不再出现在任何选用列表<br/>已提交业务记录不受影响]
    C --> D
    D -->|取消| E[保持原状]
    D -->|确认| F{删除是否成功?}
    F -->|否| G[保持原状并可重试]
    F -->|是| H[该账户从总览与全部业务选用列表移除]
    H --> I[已提交业务记录：账户快照不变，双方按各业务权限只读可见]
    H --> J[尚未提交的办理：下次进入要求重新选用<br/>不静默替换]
```

删除不可撤销，无回收站；需要恢复时重新登记，数币账户须重新完成地址所有权签名。

## 业务办理中选用与回流（图 5）

对应[业务办理中选用账户（F-EA-07）](./01-企业账户-PRD.md#f-ea-07)。本图只画本模块与办理侧的衔接，办理动作本身的完整规则在相应业务模块。

```mermaid
flowchart TD
    A[当事方在业务办理中需要指定账户] --> B{本笔结算币种}
    B -->|USD| C[可选范围：本企业法币账户]
    B -->|USDT / USDC| D[可选范围：本企业数币账户<br/>带出其结算收款链与数币地址，本笔只读]
    C --> E{读取本企业账户成功?}
    D --> E
    E -->|失败| F[说明暂时不可用可重试<br/>不表达为尚未登记，不要求手输，不放行缺账户的提交]
    F --> E
    E -->|成功但无可用账户| G[说明尚未登记并指向企业账户<br/>不给空白表单]
    G --> H[在企业账户完成登记]
    H --> I[回到原办理的原位置，已填内容不丢失]
    E -->|成功且有可用账户| J[仅按该业务自身规则带出<br/>不设默认账户；带出不等于已选定]
    I --> J
    J --> K[本笔显式确认所选账户；办理内无新增/编辑/删除入口，不可手输替代<br/>信息不完整的账户标注待补项，选中后不能提交，引导去补齐]
    K --> L{提交瞬间该账户仍有效?}
    L -->|已被删除或修改| M[本次提交不成立：说明账户已变更并要求重新选用<br/>不拿旧值提交]
    M --> J
    L -->|是| N[提交成功：账户信息随业务记录固定为快照]
```

<a id="state-1"></a>
## 数币账户登记状态机

对象：一次数币账户的登记过程。初始状态为未开始，终态为已登记或本次未登记。

```mermaid
stateDiagram-v2
    [*] --> 未开始
    未开始 --> 待填写: 进入数币账户新增并已看到可登记范围告知
    待填写 --> 待签名: 同一环节内已选链，地址通过所选链校验且本企业内不重复
    待填写 --> 待填写: 未选链、格式不符或地址已登记，就地说明并可改；改选链时按新链重新校验
    待签名 --> 已登记: 被添加的那个地址签名通过
    待签名 --> 本次未登记: 拒签、签名失败或超时、签名地址不匹配、钱包环境不可用
    本次未登记 --> 待填写: 用户重试
    已登记 --> 已删除: 在账户总览删除该账户
    已登记 --> [*]
    本次未登记 --> [*]
```

只有已登记才产生可被选用的账户；待填写、待签名都不是账户，不落入总览、不占用去重判断、不可被业务选用。结算收款链与数币地址在进入已登记后不可修改；换地址须作为新账户重新从待填写开始。

<a id="state-2"></a>
## 企业账户生命周期状态机

对象：一个已登记的企业账户（法币账户与数币账户共用）。

```mermaid
stateDiagram-v2
    [*] --> 可选用: 法币校验通过保存 / 数币签名通过登记
    可选用 --> 可选用: 修改可编辑项（法币全部字段；数币仅备注名）
    可选用 --> 已删除: 删除并显式确认
    已删除 --> [*]
```

本期不设默认账户，生命周期只有可选用与已删除两种状态。已删除是终态：不出现在总览与任何选用列表，不可撤销、不可恢复；但已提交业务记录中的账户快照不随之变化，仍按各业务权限只读可见。本期不设“停用”这一中间状态——停止使用某账户的唯一方式是删除它。
