## 放款清单、只读详情与办理（P-L7-00）

```mermaid
%%{init: {"flowchart": {"htmlLabels": false, "wrappingWidth": 400}}}%%
flowchart TD
  A["资产方接受报价<br/>本笔进入待放款"] --> B["融资放款信息新增一条记录<br/>显示尚未提交放款记录"]
  B -->|"查看"| C["只读详情：放款信息、两侧账户、<br/>商务条款摘要与协议文件<br/>不提供办理或跨业务跳转"]
  C -->|"关闭"| B
  B --> D["从融资业务入口、控制台待办或站内信<br/>明确选定本笔"]
  D --> E{"当前角色与状态<br/>允许的动作"}
  E -->|"本笔资金方，待放款"| F["登记放款，见 P-L7-01"]
  E -->|"本项目资产方，待放款确认"| G["确认到账，见 P-L7-03"]
  E -->|"其他身份或状态已变"| H["说明当前结果<br/>不开启旧办理"]
  F -->|"提交成功"| I["本笔变为待放款确认<br/>生成放款编号"]
  G -->|"确认成功"| J["本笔变为还款中<br/>放款清单显示已放款<br/>还款信息清单入列"]
  I --> K["刷新本笔记录与办理入口<br/>不自动打开详情<br/>关闭后回到来源位置"]
  J --> K
  J -.->|"后续还款、逾期、结清"| L["只在还款信息中表达<br/>放款清单保持已放款"]
```

资金方在待放款时只有“提交放款”一个写动作，资产方在待放款确认时只有“确认到账”一个写动作；本模块没有终止、暂缓、重传或异议路径。

  L --> C
  M --> C

  P --> Q["资产方收到放款记录已提交站内信<br/>资产方另行按 P-L7-03 核实到账"]
```

资金转账发生在平台外，平台不审核合同或付款的真伪。质押水位不安全只阻止提交，不影响查看本笔资料；资产方追加质押使水位恢复后，提交入口自动恢复。水位不安全时待放款没有其他出口，见[Q-L7-09](./01-放款与放款确认-PRD.md#q-l7-09)。

  K --> L{"还款计划是否就绪"}
  L -->|"已就绪"| M["还款模块展示唯一一套定稿计划"]

```

质押水位不安全或项目到期都不阻止资产方确认。实收金额填与不填都能确认，不改变本金。业务日期按 UTC，切换展示时区只影响显示。计划就绪后不自动打开还款办理，报价时的预计计划不能当作定稿计划。

## 融资业务本模块状态（S-L7-01）

```mermaid
stateDiagram-v2
  state "待放款（S-FD-3）" as FD3
  state "待放款确认（S-FD-4）" as FD4
  state "还款中（S-FD-6）" as FD6
  [*] --> FD3: 资产方接受报价
  FD3 --> FD4: 本笔资金方成功提交唯一放款记录
  FD4 --> FD6: 本项目资产方确认到账，金额同时转移
  note right of FD3
    唯一出口是提交放款
    没有时限，可以长期停留
  end note
  note right of FD4
    唯一出口是确认到账
    没有时限，可以长期停留
  end note
  note right of FD6
    交给还款模块
    计划生成中不回退
    不是融资业务终态
  end note
```

- 初始箭头只表示本笔进入本模块，不是融资业务编号在此新建。
- 待放款与待放款确认都没有终止、撤回或驳回出边，也没有因时间到期产生的自环；本模块不产生任何业务标记。
- 放款异议处理中（S-FD-5）本期不可达，不画成可执行状态。

| 业务事件 | 融资业务状态 | 融资需求对外显示 |
| --- | --- | --- |
| 接受报价后，等待资金方付款 | 待放款（S-FD-3） | 放款中 |
| 放款记录提交后 | 待放款确认（S-FD-4） | 放款中 |
| 资产方确认到账 | 还款中（S-FD-6） | 已放款 |

需求对外状态由融资需求与代币质押模块派生，本模块只提供上表事实，不新增第六个需求状态。项目、需求与融资业务的状态分别表达。
