## 计划形成与查看（L8-F01）

```mermaid
flowchart TD
  A[资金方报价成功] --> B[按报价日生成预计计划，标注预计·未生效]
  B --> C[资产方接受并收款，重算告知须始终可得并记录展示时间]
  C --> D[链上放款成功]
  D --> E[本笔进入还款中，出现在还款信息清单]
  D --> N[授信报价模块告知双方已放款]
  E --> F{定稿计划已生成？}
  F -->|否| G[显示还款计划生成中，保留放款与本金事实]
  G -->|恢复| F
  F -->|是| H[以放款成功日为起息日，按双方约定的计息口径生成唯一定稿计划]
  H --> I[资产方收到计划定稿通知，含逐期对照]
  H --> J[双方在还款详情只读查看本期、计划、还款收款地址与记录]
  H --> V[非当事资金方只读查看非隐私履约信息]
  H --> K[按应还日、机构与放款编号逐笔选择业务]
  K --> L[资产方按期次条件进入授权并还款]
  P[项目尚无还款业务] --> Q[保留清单与办理入口的空态说明，不伪造待办]
```

- 预计计划不进入还款信息，不产生期次编号。
- 计划未生成时不回退已成立的链上放款。
- 还款收款地址取资金方报价时选定的还款收款地址；链上放款记录的明细在融资申请详情查看，还款信息只带编号识别同一笔。
- 平台计划采用的计息口径就是双方约定的计息口径，双方按定稿计划还款；预计计划采用同一口径但尚未生效。
- 游客、登录未绑定角色与其他企业的资产方看不到还款信息；非当事资金方可查看编号、机构、业务及期次状态、应还日、还款成功与结清时间、逾期信息，具体范围见[非隐私履约信息](./01-链上还款-PRD.md#non-private-performance)。金额、条款、地址与交易标识仍受限，不提供办理或本笔消息。

## 授权并还款与链上结果（L8-F02）

```mermaid
flowchart TD
  A[资产方从还款办理入口选择本笔] --> B[默认最近一期待还款，可改选已开放的期次]
  B --> C{本企业业务、待还款、已到应还日00:00 UTC，且本笔无处理中期次？}
  C -->|否| D[说明原因与开放时刻；只读查看，不开放签名]
  C -->|是| E[核对应还金额、币种与资金方还款收款地址]
  E --> F[从企业账户选定出账地址，查询本期结算币种余额]
  F --> G{余额不低于本期结算金额？}
  G -->|不足或查询失败| F
  G -->|是| H[点击授权并还款，签名前校验]
  H -->|未通过| E
  H -->|通过| I[唤起钱包，资产方用出账地址签名授权还款合约]
  I -->|未签名或取消| E
  I -->|签名发出| J[本期还款处理中：记录提交时间，冻结逾期天数]
  J --> K[授权上链后，平台执行钱包执行链上还款]
  K --> L{链上还款结果？}
  L -->|成功| M[本期结清：生成还款记录；累计已还更新；按本期本金减少两项占用；重判业务逾期标记]
  L -->|明确失败| N[本期回到待还款，冻结不成立，逾期按应到时点连续计算]
  N --> O[资产方收到本期还款未完成]
  O --> A
  L -->|长期未知或冲突| P[保持处理中，不能重复发起，提示联系客服]
  M --> Q{全部期次都已结清？}
  Q -->|否| R[资产方收到本期还款已完成，资金方收到本期还款已到账]
  R --> A
  Q -->|是| S[本笔业务结清，进入业务结清与项目衔接]
```

- 签名提交与还款处理中不减少本金占用；利息期链上还款成功也不减少本金占用。
- 每次提交都由资产方用出账地址签名授权一次，授权 gas 由资产方承担；链上还款由平台执行钱包执行并承担 gas。
- 重复点击、刷新或重复提交只产生一笔授权交易与一次链上还款。
- 没有资金方确认环节；平台不代签、不代付、不归集资金。应还临近提醒只用于准备，不开放还款。

<a id="l8-f03"></a>
## 业务结清与项目衔接（L8-F03）

```mermaid
flowchart TD
  A[本笔全部期次结清] --> B[本笔业务已结清，未偿本金与两项本金占用归零]
  B --> C[双方收到本笔融资业务已结清通知]
  B --> D[交融资需求与代币质押判断项目]
  D --> E{项目内还有未处理完成的业务？}
  E -->|有| F[项目不变，不释放，不按单笔释放代币]
  E -->|没有| G{项目已到期？}
  G -->|否| H[项目回到可用，可再次发布或主动关闭；不释放]
  G -->|是| I[项目自动终结为已结清，整池业务释放]
  I --> J[代币为已释放待提取，资产方自助提取并自付 gas]
```

- 业务结清不依赖提取成功；提取失败不回退结清，也不恢复额度占用。
- 链上结果未知或冲突时只提示联系客服，不新增处置流程。

## 还款期次状态机（L8-S01）

每一期独立适用。

```mermaid
stateDiagram-v2
  state "待还款 S-RP-1" as RP1
  state "还款处理中 S-RP-4" as RP4
  state "已结清 S-RP-3" as RP3
  [*] --> RP1: 定稿计划生成期次
  RP1 --> RP1: 应还日次日00时UTC仍未签名提交，形成或增加逾期天数
  RP1 --> RP4: 应还日开放后资产方签名授权发出，冻结本期逾期天数
  RP4 --> RP4: 授权或链上还款上链确认中，或结果长期未知
  RP4 --> RP1: 授权或链上还款明确失败，冻结不成立
  RP4 --> RP3: 链上还款上链成功
  RP3 --> [*]
```

- 逾期是并行标记，不是第四种状态；结清后逾期天数作为历史保留，不清零。
- 没有撤回、撤销、资金方确认或异议的状态转换；已结清不能回到其他状态。
- 本期是否已提交与业务整体是否仍有逾期分别判断，见[业务逾期标记（FD-44）](./01-链上还款-PRD.md#f-ls-68)。

<a id="l8-s02"></a>
## 融资业务状态机（L8-S02）

只画本模块负责的状态段。

```mermaid
stateDiagram-v2
  state "还款中 S-FD-6" as FD6
  state "已结清 S-FD-8" as FD8
  [*] --> FD6: 链上放款成功
  FD6 --> FD6: 计划生成中，或部分期次还款处理中或结清
  FD6 --> FD6: 逾期或链上结果待核实，主状态不变
  FD6 --> FD8: 全部期次结清
  FD8 --> [*]
```

- 业务逾期标记（S-FD-9，即 FD-44）是并行标记：只要仍有已逾期且未结清的期次（待还款或还款处理中）就保留；相关逾期期次全部结清后清除，未来尚未逾期的期次不影响清除；之后另一期又逾期可以再次形成。
- 融资申请的对外状态在整个过程中保持“已放款”；业务结清不等于项目结清。
