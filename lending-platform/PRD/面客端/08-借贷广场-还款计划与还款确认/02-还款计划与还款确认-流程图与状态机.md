## 计划形成与查看（L8-F01）

```mermaid
flowchart TD
  A[资金方提交报价] --> B[生成预计计划，标注预计·未生效]
  B --> C[资产方接受报价，重算告知须始终可得并记录展示时间]
  C --> D[资金方登记放款，资产方确认到账]
  D --> E[本笔进入还款中，出现在还款信息清单]
  D --> N[放款模块告知资金方已确认到账]
  E --> F{定稿计划已生成？}
  F -->|否| G[显示还款计划生成中，保留确认与本金事实]
  G -->|恢复| F
  F -->|是| H[以放款提交日为起息日，按双方约定的计息口径生成唯一定稿计划]
  H --> I[资产方收到计划定稿通知，含逐期对照]
  H --> J[双方在还款详情只读查看本期、计划、账户与记录]
  H --> V[非当事资金方只读查看非隐私履约信息]
  H --> K[按应还日、机构与放款编号逐笔选择业务]
  K --> L[按角色与期次条件进入还款或确认办理]
  P[项目尚无还款业务] --> Q[保留清单与办理入口的空态说明，不伪造待办]
```

- 预计计划不进入还款信息，不产生期次编号。
- 计划未生成时不回退放款确认事实。
- 平台计划采用的计息口径就是双方约定的计息口径，双方按定稿计划还款与确认；预计计划采用同一口径但尚未生效。
- 游客、登录未绑定角色与其他企业的资产方看不到还款信息；非当事资金方可查看编号、机构、业务及期次状态、应还日、还款与结清时间、逾期信息，具体范围见[非隐私履约信息](./01-还款计划与还款确认-PRD.md#non-private-performance)。金额、条款与付款材料仍受限，不提供办理或本笔消息。

<a id="l8-f02"></a>
## 还款提交与资金方确认（L8-F02）

```mermaid
flowchart TD
  A[资产方从还款办理入口选择本笔] --> B[默认最近一期待还款，可改选已开放的期次]
  B --> C{本企业业务、待还款且已到应还日00:00 UTC？}
  C -->|否| D[说明原因与开放时刻；只读查看，不开放录入]
  C -->|是| E[核对应还金额、币种与资金方还款收款账户]
  E --> F[填写还款时间；法币上传凭证或数币填写交易标识]
  F --> G{本次办理内最终确认，资料有效？}
  G -->|取消或校验未过，保留已填内容| F
  G -->|确认| H[提交成功：本期待还款确认，冻结逾期天数，不启动任何倒计时]
  H --> T[资金方收到还款记录已提交通知]
  T --> I[资金方进入本期确认办理，核对到账]
  I --> J{资金方确认收到还款？}
  J -->|尚未确认| L[本期停在待还款确认，本金占用持续，平台不自动确认]
  L --> M[双方线下商定时机，可联系客服，平台不代确认或裁决]
  M --> I
  L -->|核实到账后随时可确认| I
  J -->|确认| K{确认成功？}
  K -->|否| O[保持待还款确认与原金额，可再次办理]
  O --> I
  K -->|是| P[本期结清；累计已还更新；按本期本金减少两项占用；重判业务逾期标记]
  P --> Q{全部期次都已结清？}
  Q -->|否| R[资产方收到本期还款已确认通知，可继续下一期]
  R --> A
  Q -->|是| S[本笔业务结清，进入业务结清与项目衔接]
```

- 资产方提交不减少本金占用；利息期确认也不减少本金占用。
- 资金方迟未确认不是还款逾期，也不改变资产方已冻结的逾期天数。
- 失败、取消与重复提交都不会产生第二条有效还款记录。
- 平台只登记付款信息，不执行支付或签名；应还临近提醒只用于准备，不开放录入。

<a id="l8-f03"></a>
## 业务结清与项目衔接（L8-F03）

```mermaid
flowchart TD
  A[本笔全部期次结清] --> B[本笔业务已结清，未偿本金与两项本金占用归零]
  B --> C[双方收到本笔融资业务已结清通知]
  B --> D[交融资需求与代币质押判断项目]
  D --> E{项目内还有未处理完成的业务？}
  E -->|有| F[项目不变，不释放，不按单笔释放代币]
  E -->|没有| G{项目已到期？}
  G -->|否| H[项目回到可用，可再次发布或主动关闭；不释放]
  G -->|是| I[项目自动终结为已结清，整池业务释放]
  I --> J[代币为已释放待提取，资产方自助提取并自付 gas]
```

- 业务结清不依赖提取成功；提取失败不回退结清，也不恢复额度占用。
- 链上结果未知或冲突时只提示联系客服，不新增处置流程。

<a id="l8-s01"></a>
## 还款期次状态机（L8-S01）

每一期独立适用。

```mermaid
stateDiagram-v2
  state "待还款 S-RP-1" as RP1
  state "待还款确认 S-RP-2" as RP2
  state "已结清 S-RP-3" as RP3
  [*] --> RP1: 定稿计划生成期次
  RP1 --> RP1: 应还日次日00时UTC仍未提交，形成或增加逾期天数
  RP1 --> RP2: 应还日开放后资产方提交成功，冻结本期逾期天数
  RP2 --> RP2: 确认未成功或长期未确认，状态不变
  RP2 --> RP3: 资金方确认收到还款成功
  RP3 --> [*]
```

- 逾期是并行标记，不是第四种状态；结清后逾期天数作为历史保留，不清零。
- 没有撤回、撤销、自动确认或异议的状态转换。
- 本期是否已提交与业务整体是否仍有逾期分别判断，见[业务逾期标记（FD-44）](./01-还款计划与还款确认-PRD.md#f-ls-68)。

<a id="l8-s02"></a>
## 融资业务状态机（L8-S02）

只画本模块负责的状态段。

```mermaid
stateDiagram-v2
  state "还款中 S-FD-6" as FD6
  state "已结清 S-FD-8" as FD8
  [*] --> FD6: 资产方确认到账
  FD6 --> FD6: 计划生成中，或部分期次提交或确认
  FD6 --> FD6: 逾期或长期未确认，主状态不变
  FD6 --> FD8: 全部期次结清
  FD8 --> [*]
```

- 业务逾期标记（S-FD-9，即 FD-44）是并行标记：只要仍有已逾期且未结清的期次（待还款或待还款确认）就保留；相关逾期期次全部结清后清除，未来尚未逾期的期次不影响清除；之后另一期又逾期可以再次形成。
- 融资申请的对外状态在整个过程中保持“已放款”；业务结清不等于项目结清。
