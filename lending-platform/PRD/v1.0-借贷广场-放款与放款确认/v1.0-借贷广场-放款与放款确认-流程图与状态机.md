## P-L7-01 · 资金方核验、处置与放款

规则回链：[入口 F-LS-56](v1.0-借贷广场-放款与放款确认-PRD.md#f-ls-56)、[核验 F-LS-45](v1.0-借贷广场-放款与放款确认-PRD.md#f-ls-45)、[暂缓 F-LS-46](v1.0-借贷广场-放款与放款确认-PRD.md#f-ls-46)、[终止 F-LS-48](v1.0-借贷广场-放款与放款确认-PRD.md#f-ls-48)、[放款 F-LS-49](v1.0-借贷广场-放款与放款确认-PRD.md#f-ls-49)、[覆盖 F-LS-50](v1.0-借贷广场-放款与放款确认-PRD.md#f-ls-50)、[哈希 F-LS-51](v1.0-借贷广场-放款与放款确认-PRD.md#f-ls-51)。

```mermaid
flowchart TD
  A[已接受报价：S-FD-3 待放款] --> B[本笔资金方进入详情放款抽屉]
  B --> C[盖章件与商务条款并排核验]
  C --> D{资金方决定}
  D -->|暂不放款| H[填写原因；保留 S-FD-3 和四个金额]
  H --> C
  D -->|要求重传| R[填写原因；保留 S-FD-3；进入 P-L7-02]
  R --> C
  D -->|终止业务| T[填写原因并二次确认]
  T -->|取消| C
  T -->|确认成功| U[业务 S-FD-10；释放本笔在途报价金额；项目在途不变；质押不释放]
  U -.-> Z[项目及需求落点见 S-L7-02；特殊组合待 Q-L7-02]
  D -->|已在平台外付款，登记记录| F[核对只读币种金额及资产方账户；填发放时间与还款收款账户]
  F --> G{报价结算币种}
  G -->|USD| I[上传 1 至 5 个转账凭证；还款法币账户五项必填]
  G -->|USDT 或 USDC| J[填写交易哈希；ETH 只读；还款地址取绑定钱包]
  I --> K[二次确认：记录和还款账户不可改、时限不自动确认、平台未核验]
  J --> K
  K -->|取消| F
  K -->|确认提交| V{当前业务、字段与覆盖条件满足}
  V -->|覆盖不足| W[无记录无状态变化；提示缺口和追加；三个处置仍可用]
  W --> C
  V -->|字段不合格| X[具体提示；保留已成功材料]
  X --> F
  V -->|已有记录或业务已变| Y[返回当前详情并说明结果]
  V -->|满足且成功| N[唯一放款记录；S-FD-4；清暂缓与待重传；开始 168 小时；四个金额不变]
  N --> O[通知资产方；进入 P-L7-03]
```

核验不是审核状态；资金转账发生在平台外。覆盖校验只挡放款提交，不挡处置；重传等待不额外挡放款。依赖未知与账户缺失等未定恢复路径见正文第 7 章，图中不假定其能成功。

<a id="p-l7-02"></a>
## P-L7-02 · 要求重传与重传闭环

规则回链：[F-LS-47](v1.0-借贷广场-放款与放款确认-PRD.md#f-ls-47)。

```mermaid
flowchart TD
  A[本笔资金方：S-FD-3 内要求重传并填原因] --> B[待重传标记为真；通知资产方；业务与四个金额不变]
  B --> C[资产方在详情打开重传抽屉]
  C --> D[查看要求和历史版本；上传新盖章件]
  D --> E{上传结果及当前业务}
  E -->|格式、大小、数量或上传失败| F[就地说明；保留已有材料；未完成重传]
  F --> D
  E -->|业务已终止| G[返回详情：已终止，不再成功重传]
  E -->|业务仍待放款且成功| H[形成新版本并保留旧版；清待重传标记]
  H --> I[资金方核验区可看新版本；无需核验通过；不发完成通知]
  I --> J[按 P-L7-01 继续处置或放款]
  I -.-> Q[同次要求完成后能否再主动上传：Q-L7-03 待确认]
```

重传等待期间，资金方可以改为放款或终止；重传先完成不阻止之后终止。再次独立要求可再次触发此图；历史版本始终保留。

## P-L7-03 · 到账确认、超期出口与还款交接

规则回链：[确认 F-LS-52](v1.0-借贷广场-放款与放款确认-PRD.md#f-ls-52)、[实收 F-LS-58](v1.0-借贷广场-放款与放款确认-PRD.md#f-ls-58)、[时限 F-LS-53](v1.0-借贷广场-放款与放款确认-PRD.md#f-ls-53)、[线下出口 F-LS-54](v1.0-借贷广场-放款与放款确认-PRD.md#f-ls-54)、[交接 F-LS-55](v1.0-借贷广场-放款与放款确认-PRD.md#f-ls-55)、[通知 F-LS-57](v1.0-借贷广场-放款与放款确认-PRD.md#f-ls-57)。

```mermaid
flowchart TD
  A[S-FD-4 待放款确认；提交成功时间起算 168 小时] --> B[资产方查看记录、账户、凭证或哈希与商务条款]
  B --> C[看差额告知；可选填实收金额]
  C --> D{资产方是否已核实到账并决定确认}
  D -->|未确认| E[保留 S-FD-4 和全部金额；可联系对方或客服]
  E --> F{当前放款确认时限}
  F -->|到期前 24 小时且仍待确认| G[仅给资产方一档提醒]
  F -->|到期仍待确认| H[中性超期标记；双方各一条通知；无状态、金额或权限改变]
  F -->|其他等待时段| B
  G --> B
  H --> I[页面与通知提供客服邮箱及持续占用后果；不代确认、不自动作废]
  I -->|线下核实后返回| B
  I -->|仍未确认| E
  D -->|确认| J[二次确认：实际到账、不可撤销、进入还款]
  J -->|取消| B
  J -->|提交失败| K[保持 S-FD-4 和原金额；可再次确认]
  K --> B
  J -->|确认成功| L[S-FD-6；确认时间；两维度四个金额同时按融资本金转移；触发 L8]
  L --> M[通知资金方已确认及当前计划进度]
  L --> N{还款计划是否就绪}
  N -->|已就绪| O[由 L8 展示和管理还款计划]
  N -->|尚未就绪| P[展示还款计划生成中；保留已确认事实和金额]
  P -->|计划恢复就绪| O
```

覆盖不足、项目到期、确认超期均不阻断资产方确认。实收差额不阻断、不改变本金。长期未确认持续等待，不自动流向还款或终止。图中回到等待不表示周期推送。

stateDiagram-v2

这里只画 L7 相关片段，不声明项目如何首次创建或最终关闭；两个项目状态都不是本图所定义的终态。

| 业务事件 | 融资业务 | 融资需求对外显示 |
| --- | --- | --- |
| 接受报价后 / 暂缓 / 要求重传 / 重传完成 | S-FD-3 | 放款中 |
