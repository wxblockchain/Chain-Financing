## 15. 验收场景与预期结果

### 15.1 账号来源与开通（`F-AL-01`～`F-AL-03`）

| # | 角色 / 前置 | 场景 | 预期结果 |
| --- | --- | --- | --- |
| `AC-AL-01` | 任意访问者 | 在运营端寻找注册、入驻或申请开通入口 | **不存在任何自助注册 / 机构入驻入口**（`D-AL-04`） |
| `AC-AL-02` | 任意访问者 | 未登录访问运营端的任何受保护功能 | 被引导到登录页，并记住原目标；**不存在任何绕过登录的首次配置页或安装向导** |
| `AC-AL-03` | 部署完成、未初始化管理员 | 尝试登录运营端 | 无任何可用账号，系统**不提供自救入口** |
| `AC-AL-04` | 运营管理员 | 新建账号并选择邀请开通 | 账号创建为**待开通**；开通邀请发往所填工作邮箱；**全程未在任何在线渠道出现明文密码** |
| `AC-AL-05` | 被邀请人 | 打开有效邀请并设置密码 | 设置成功后账号转为**正常**，该邀请立即作废，要求用新密码登录 |
| `AC-AL-06` | 被邀请人 | 打开已使用 / 已过期 / 已被重发作废的邀请 | 展示失效说明并提示联系运营管理员重发；**不泄露该账号的其他信息** |
| `AC-AL-07` | 运营管理员 | 对同一账号重发开通邀请 | 此前所有未使用的邀请**立即作废**，只有最新一份可用 |
| `AC-AL-08` | 运营管理员 | 新建账号并选择初始密码开通 | 账号创建为**待开通**；初始密码线下交付，系统不通过邮件、站内消息或任何在线渠道下发 |
| `AC-AL-09` | 待开通（初始密码）账号 | 初始密码已过期后登录 | 登录被拒、**不建立登录态**，提示联系运营管理员重新发起开通 |
| `AC-AL-10` | 运营管理员 | 新建账号时填写已存在的工作邮箱 | 被拒绝；提示**不透露已有账号的状态、姓名、角色等任何其他信息** |

### 15.2 登录（`F-AL-04`、`F-AL-06`）

| # | 角色 / 前置 | 场景 | 预期结果 |
| --- | --- | --- | --- |
| `AC-AL-11` | 任意 | 查看登录页 | 登录方式为**工作邮箱 + 密码**；**无注册入口、无协议勾选、无「记住我」、无验证码登录、无钱包登录、无第三方登录** |
| `AC-AL-12` | 任意 | 用不存在的邮箱登录，与用存在的邮箱 + 错误密码登录 | **两种情形的提示文案、页面表现与响应快慢完全一致**，无法据此判断账号是否存在 |
| `AC-AL-13` | 任意 | 用未知邮箱登录 | **不会自动创建账号** |
| `AC-AL-14` | 停用账号 | 登录 | 被拒并提示联系运营管理员，不建立登录态 |
| `AC-AL-15` | 待开通（邀请方式，未设密）账号 | 登录 | 提示尚未完成开通、请通过开通邀请完成设置 |
| `AC-AL-16` | 正常账号 | 直接从登录页登录成功 | 落到总览页 `P-O-AL-07` |
| `AC-AL-17` | 正常账号 | 从某个受保护功能被引导登录后成功 | **回到原本要去的目标** |
| `AC-AL-18` | 正常账号 | 原目标不属于本运营端范围 | 原目标被丢弃，落到总览页 |
| `AC-AL-19` | 新账号 | 首次登录成功 | 按浏览器推断写入时区偏好；推断失败时为 UTC |
| `AC-AL-20` | 任意 | 密码输入框 | 带显示 / 隐藏切换，且该图标对读屏可识别 |

### 15.3 首次登录强制改密（`F-AL-03`）

| # | 角色 / 前置 | 场景 | 预期结果 |
| --- | --- | --- | --- |
| `AC-AL-21` | 初始密码开通账号 | 首次登录成功 | **立即**进入 `P-O-AL-03`，不经过总览页 |
| `AC-AL-22` | 同上，未完成改密 | 手工访问运营端其他任何功能 | 一律被带回改密页 |
| `AC-AL-23` | 同上，未完成改密 | **绕过界面**直接发起任一业务动作 | 同样被拒绝（界面拦截不是唯一防线） |
| `AC-AL-24` | 同上 | 查看改密页 | **无任何勾选项**；无左侧菜单、无面包屑；只有「退出登录」与语言切换两个出口 |
| `AC-AL-25` | 同上 | 新密码与初始密码相同 | 被拒绝并提示新密码不能与初始密码相同 |
| `AC-AL-26` | 同上 | 改密成功 | 账号转为**正常**、**全部会话失效**、回到登录页；触发密码变更通知 |

### 15.4 忘记密码（`F-AL-05`）

| # | 角色 / 前置 | 场景 | 预期结果 |
| --- | --- | --- | --- |
| `AC-AL-27` | 任意 | 提交工作邮箱并点击发送验证码 | **必须先通过人机校验，再经发送限频校验，才发码**；三步顺序不可调换 |
| `AC-AL-28` | 任意 | 分别用已注册与未注册邮箱走该流程 | **响应完全一致**，提示为中性文案，不透露该邮箱是否为运营端账号 |
| `AC-AL-29` | 任意 | 未通过人机校验直接发起发码 | **被服务端拒绝**，不发码 |
| `AC-AL-30` | 任意 | 用已通过的人机校验凭据去为另一个邮箱或另一种用途发码 | 被拒绝 |
| `AC-AL-31` | 锁定账号 | 输入正确验证码 | 仍能收到验证码邮件，但验证码正确后被告知**账号锁定与本次剩余时间**，流程终止 |
| `AC-AL-32` | 任意 | 观察锁定告知出现的时点 | **只在验证码校验通过之后**出现，不在输入邮箱或发码阶段暴露 |
| `AC-AL-33` | 正常账号 | 设置新密码成功 | **全部会话失效**、回到登录页，触发密码变更通知 |
| `AC-AL-34` | 任意 | 超出发送限频 | 不发码并提示稍后再试；**提示不因该邮箱是否存在而变化** |
| `AC-AL-35` | 任意 | 邮件发送失败 | 允许立即重试一次且该次不计入限频额度 |

### 15.5 密码规则

| # | 场景 | 预期结果 |
| --- | --- | --- |
| `AC-AL-36` | 输入长度不足 8 或超过 20 的密码 | 被拒绝 |
| `AC-AL-37` | 输入仅字母或仅数字的密码 | 被拒绝（须至少 1 字母 + 1 数字） |
| `AC-AL-38` | 密码前后带空格 / 中间带空格 | 前后自动去除；中间不被接受 |
| `AC-AL-39` | 开始输入后查看页面 | 展示规则实时校验清单，全部满足方可提交；**不展示强弱分档** |
| `AC-AL-40` | 新密码与原密码或初始密码相同 | **由服务端在提交后拒绝**并给出对应提示，前端不做预判 |
| `AC-AL-41` | 检查界面、日志、邮件与站内消息 | 任何位置**都不出现明文密码** |

| # | 场景 | 预期结果 |
| --- | --- | --- |
| `AC-AL-42` | 通过右上角账号下拉进入 | 下拉内展示工作邮箱与账号状态，提供消息中心、账户设置、退出登录；**消息中心排在账户设置之上** |

| `AC-AL-44` | 寻找修改工作邮箱的入口 | **界面上不存在**；绕过界面发起修改同样被拒绝 |
| `AC-AL-45` | 修改本人密码 | 在本页弹窗内完成，且**先做当前密码再认证** |
| `AC-AL-46` | 再认证时当前密码输错 | **计入登录失败计数**（与登录共用同一计数器） |
| `AC-AL-47` | 修改密码成功 | **全部会话失效**并触发密码变更通知 |
| `AC-AL-48` | 设置界面语言与时区 | 即时生效并持久化 |
| `AC-AL-49` | 查看账号信息字段 | **不存在部门、岗位、所属机构、机构编号等字段** |

### 15.7 账号与权限管理（`F-AL-14`～`F-AL-16`）

| # | 角色 / 前置 | 场景 | 预期结果 |
| --- | --- | --- | --- |
| `AC-AL-50` | 运营专员 | 寻找账号与权限管理入口 | **菜单与页面上均不出现**；绕过界面发起账号类动作同样被拒绝 |
| `AC-AL-51` | 运营管理员 | 查看账号列表 | 展示工作邮箱、姓名、角色、账号状态、开通方式、最近登录时间、创建时间；支持关键词检索与角色 / 状态筛选 |
| `AC-AL-52` | 运营管理员 | 停用某账号 | 二次确认后即时生效：该账号**全部会话立即失效**，此后不可登录 |
| `AC-AL-53` | 运营管理员 | 启用此前被停用的账号 | 恢复为停用前的状态；若停用前为待开通，仍需完成开通 |
| `AC-AL-54` | 运营管理员 | 停用系统内**最后一个正常状态的运营管理员** | **被拒绝**并给出明确原因，账号状态不变 |
| `AC-AL-55` | 运营管理员 | 将最后一个正常状态的运营管理员降级为运营专员 | **被拒绝**，角色不变 |
| `AC-AL-56` | 运营管理员 | 收回自己的「角色分配与功能权限授权」权限 | **被拒绝** |
| `AC-AL-57` | 运营管理员 | 对某账号重新发起开通 | 原密码立即失效、全部会话失效；该账号回到**待开通**并需重新完成开通 |
| `AC-AL-58` | 运营管理员 | 查看操作留痕 | 每次角色变更、权限授予与收回均可追溯到操作人、时间、对象与变更内容 |

### 15.8 功能权限矩阵与数据可见范围（`F-AL-16`、`F-AL-17`）

| # | 角色 / 前置 | 场景 | 预期结果 |
| --- | --- | --- | --- |
| `AC-AL-59` | 新建的运营专员（未额外授权） | 登录后查看可用功能 | 只有本人账户设置与运营端消息查看、运营业务数据查询（默认开通项）；其余入口不出现 |
| `AC-AL-60` | 运营专员被授予某审核处置权限 | 授权保存后**无需重新登录**再次操作 | 对应入口出现，动作可执行（**立即生效**） |
| `AC-AL-61` | 运营专员被收回某权限 | 收回后再次操作 | 入口消失；**绕过界面直接发起该动作被拒绝** |
| `AC-AL-62` | 运营专员 | 发起未被授权的动作 | 返回统一的无权限提示，**不透露该功能下是否存在具体业务记录** |
| `AC-AL-63` | 运营管理员 | 查看权限面板 | 全部功能权限项固定开通且不可取消；账号与权限管理三项对运营专员**不可授权** |
| `AC-AL-64` | 任意已授权账号 | 查看某功能下的数据范围 | **全量可见**：不存在「只看与本机构相关的项目」这类过滤，界面上无机构筛选项 |
| `AC-AL-65` | 任意 | 检查权限判定条件 | 判定只依据**角色与功能权限项 + 账号状态**；**不存在机构维度参与判定** |
| `AC-AL-66` | 任意 | 检查账号类型 | 运营端只有一套账号体系；**界面上不存在「SPV 机构」这一账号类别**，SPV 职责通过功能权限项体现 |
| `AC-AL-67` | 锁定 / 停用 / 待开通账号 | 任何业务动作 | 一律不生效，即使此前已被授权 |

### 15.9 会话、锁定与安全（`F-AL-12`、`F-AL-13`）

| # | 场景 | 预期结果 |
| --- | --- | --- |
| `AC-AL-68` | 登录后长时间不操作 | 达到无操作时长后自动登出并给出原因提示 |
| `AC-AL-69` | 页面只有后台轮询、无任何用户交互 | **无操作计时不被重置**，到点仍会自动登出 |
| `AC-AL-70` | 会话即将到期 | 到期前给出续期确认，可选择继续保持登录或立即退出 |
| `AC-AL-71` | 查看登录页与会话数据 | **不存在「记住我」** |
| `AC-AL-72` | 退出登录 / 改密 / 重置密码 / 首登改密 / 账号被停用 | 该账号**全部会话（含当前设备）失效** |
| `AC-AL-73` | 会话失效后 | 本地登录态被清除，但**语言偏好保留** |
| `AC-AL-74` | 同一浏览器多标签页 | 任一标签检测到失效后，其余标签一并回到登录页 |
| `AC-AL-75` | 后台请求遇到登录态失效 | 触发与前台一致的失效处理，**不被静默忽略** |
| `AC-AL-76` | 连续密码失败达阈值 | 账号锁定，**登录与忘记密码全部不可用**，无提前解除通道 |
| `AC-AL-77` | 多次触发锁定 | 锁定时长按阶梯递进；距上次触发满归零窗口后回到第一档 |
| `AC-AL-78` | 锁定期间查看登录页 | 页内展示剩余时间并实时倒计时，归零后表单**自动恢复可用、无需刷新** |
| `AC-AL-79` | 失败次数达提示阈值 | 开始提示剩余次数；第一档锁定提示中告知再次触发时间会更长 |

### 15.10 通知（`F-AL-18`）

| # | 场景 | 预期结果 |
| --- | --- | --- |
| `AC-AL-80` | 首登改密 / 忘记密码重置 / 账户设置内改密 | **三种情形均触发**密码变更通知，通过邮件与站内消息告知本人，并正确区分是「设置」「修改」还是「重置」 |
| `AC-AL-81` | 观察通知触发时点 | 新密码生效之后、会话批量失效之前 |

| `AC-AL-84` | 邮件发送失败 | **不阻断业务操作**（例如不因发不出邮件而让重置密码失败） |
| `AC-AL-85` | 查看站内消息 | 消息只落在本运营端，**看不到代币发行平台运营端或面客端的任何消息**，界面也不提供跨平台查看入口 |

### 15.11 国际化与全局交互（`F-AL-10`、`F-AL-11`）

> 规则正文在**三平台共享国际化基线**，本节只验收本模块的可观察结果。

| # | 场景 | 预期结果 |
| --- | --- | --- |
| `AC-AL-86` | 全新浏览器首次访问（无手动偏好） | 界面为**英文** |
| `AC-AL-87` | 把浏览器语言设为中文后全新访问 | 仍为英文（**不读浏览器语言**） |
| `AC-AL-88` | 手动切换语言 | 当前页面不刷新即完成全部文案替换，含菜单、面包屑、Toast、弹窗与倒计时；已填表单内容不丢失 |

## 16. 非功能与安全验收

### 16.1 非功能要求

| 性能 · 授权生效 | 授权或收回保存后，被调整人下一次操作即按新权限判定 |
| 可用性 | 登录相关能力可用性 ≥ 99.9%（目标值） |
| 浏览器兼容 | Chrome / Edge / Firefox / Safari 最近两个大版本 |
| 响应式 | **桌面优先**（控制台形态）；≥ 768px 完整布局，< 768px 单列布局；登录、开通、找回、账户设置全流程在移动端可完成；人机校验适配触屏 |
| 弱网 | 请求超时后按钮恢复可点、已填内容不丢失；倒计时以服务端返回的剩余时间为准 |
| 可访问性 | 表单标签可关联、键盘全流程可达、对比度符合 WCAG AA、图标按钮可被读屏识别、Toast 通过 live region 播报 |

| 部署前置 | **初始化第一个运营管理员账号**是系统可用的部署前置条件，须写入部署清单并在上线检查中确认 |
| 部署前置 | 运营端发信地址的域名认证配置须在首次发信前完成，**与另两个平台分开维护** |

| `DEP-AL-07` | **需求方** | 品牌与合规信息（产品名、发信地址、客服邮箱、公司主体与地址、隐私政策与服务条款链接）的实际取值。不阻塞设计与开发，上线前须到位 |

### 18.2 风险

| 编号 | 风险 | 影响 | 缓解 |
| --- | --- | --- | --- |
| `R-AL-01` | 部署时忘记初始化第一个运营管理员账号 | 运营端完全不可用，无自举入口 | 写入部署清单与上线检查单。这是「无自救入口」这一安全设计的必然代价，不做首次配置页来消除它 |
| `R-AL-02` | **最后一个运营管理员本人彻底无法登录**（邮箱不可达且密码丢失） | 账号与授权能力无人可用 | `D-AL-12` 的不变量保证至少有一个正常管理员；实操上**应初始化或开通至少两个运营管理员账号**；极端情况只能由部署 / 运维在数据层重新初始化 |
| `R-AL-03` | 依赖读屏的运营人员无法自助找回密码 | 人机校验无无障碍替代且无第二条找回路径 | 人机校验支持键盘操作；弹窗内提供求助入口；由运营管理员重新发起开通作为人工兜底，须写入运维手册 |
| `R-AL-04` | **锁定可被用于骚扰** | 知道某人工作邮箱者可用错误密码连续尝试锁住其账号 | 阶梯锁定本身限制单次影响时长；不对外公开运营端登录地址与工作邮箱；按 `R-AL-02` 保留多个管理员账号。根治需要「锁定来源而非锁定账号」的策略，本期不做 |
| `R-AL-05` | **账号被锁定、被停用、被收回权限时不发通知** | 当事人只能从界面得知，被爆破锁定时无外部告警 | 留痕完整，可通过 `M-AL-05` 监控；若需求方希望增加锁定告警邮件，是一条清晰的增项，改动很小 |
| `R-AL-06` | 权限项粒度与各业务模块最终定稿不一致 | 授权面板与实际动作对不上 | 权限项以各模块定稿为准（`DEP-AL-05`）；矩阵结构与授权规则不随粒度变化（`Q-AL-04`） |
| `R-AL-07` | **主体将来分家** | 需要机构维度时本期设计不支持 | 需求方已确认本期不预先设计（`D-AL-06`）；届时按「多机构 / 租户」独立立项，账号归属、数据域与可见范围一起定义 |
| `R-AL-08` | 共享国际化基线尚未落盘 | 本模块的语言、时区与脱敏口径暂无可引用的库内地址 | 事实源明确（参考基线原文），内容不变；落盘后本册只需替换引用路径（`Q-AL-01`） |
