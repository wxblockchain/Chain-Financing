## 15. 验收场景与预期结果

### 15.1 账号来源与交付（`F-AL-03`）

| # | 角色 / 前置 | 场景 | 预期结果 |
| --- | --- | --- | --- |
| `AC-AL-01` | 任意访问者 | 在运营端寻找注册、入驻或申请开通入口 | **不存在任何自助注册 / 机构入驻入口**（`D-AL-04`） |
| `AC-AL-02` | 任意访问者 | 未登录访问运营端的任何受保护功能 | 被引导到登录页，并记住原目标；**不存在任何绕过登录的首次配置页或安装向导** |
| `AC-AL-03` | 部署完成、未初始化管理员 | 尝试登录运营端 | 无任何可用账号，系统**不提供自救入口** |
| `AC-AL-08` | 建设方已交付账号与角色权限配置 | 使用初始账密 | 工作邮箱与初始密码来自建设方，账号为待首登改密；产品内没有邀请或开通方式选择，验证后只进入强制改密页 |
| `AC-AL-09` | 初始密码已过期 | 登录 | 凭据校验通过后说明过期，**不建立登录态**；提示联系建设方/运维在数据层重新初始化 |

### 15.2 登录（`F-AL-04`、`F-AL-06`）

| # | 角色 / 前置 | 场景 | 预期结果 |
| --- | --- | --- | --- |
| `AC-AL-11` | 任意 | 查看登录页 | 登录方式为**工作邮箱 + 密码**；**无注册入口、无协议勾选、无「记住我」、无验证码登录、无钱包登录、无第三方登录** |
| `AC-AL-12` | 任意 | 用不存在的邮箱登录，与用存在的邮箱 + 错误密码登录 | **两种情形的提示文案、页面表现与响应快慢完全一致**，无法据此判断账号是否存在 |
| `AC-AL-13` | 任意 | 用未知邮箱登录 | **不会自动创建账号** |
| `AC-AL-16` | 正常账号 | 直接从登录页登录成功 | 落到总览页 `P-O-AL-07` |
| `AC-AL-17` | 正常账号 | 从某个受保护功能被引导登录后成功 | **回到原本要去的目标** |
| `AC-AL-18` | 正常账号 | 原目标不属于本运营端范围 | 原目标被丢弃，落到总览页 |
| `AC-AL-19` | 新账号 | 首次登录成功 | 按浏览器推断写入时区偏好；推断失败时为 UTC |
| `AC-AL-20` | 任意 | 密码输入框 | 带显示 / 隐藏切换，且该图标对读屏可识别 |

### 15.3 首次登录强制改密（`F-AL-03`）

| # | 角色 / 前置 | 场景 | 预期结果 |
| --- | --- | --- | --- |
| `AC-AL-21` | 建设方交付的任一新账号 | 首次登录成功 | **立即**进入 `P-O-AL-03`，不经过总览页 |
| `AC-AL-22` | 同上，未完成改密 | 手工访问运营端其他任何功能 | 一律被带回改密页 |
| `AC-AL-23` | 同上，未完成改密 | **绕过界面**直接发起任一业务动作 | 同样被拒绝（界面拦截不是唯一防线） |
| `AC-AL-24` | 同上 | 查看改密页 | **无任何勾选项**；无左侧菜单、无面包屑；只有「退出登录」与语言切换两个出口 |
| `AC-AL-25` | 同上 | 新密码与初始密码相同 | 被拒绝并提示新密码不能与初始密码相同 |
| `AC-AL-26` | 同上 | 改密成功 | 账号转为**正常**、**全部会话失效**、回到登录页；触发密码变更通知 |

### 15.4 忘记密码（`F-AL-05`）

| # | 角色 / 前置 | 场景 | 预期结果 |
| --- | --- | --- | --- |
| `AC-AL-27` | 任意 | 提交工作邮箱并点击发送验证码 | **必须先通过人机校验，再经发送限频校验，才发码**；三步顺序不可调换 |
| `AC-AL-28` | 任意 | 分别用已注册与未注册邮箱走该流程 | **响应完全一致**，提示为中性文案，不透露该邮箱是否为运营端账号 |
| `AC-AL-29` | 任意 | 未通过人机校验直接发起发码 | **被服务端拒绝**，不发码 |
| `AC-AL-30` | 任意 | 用已通过的人机校验凭据去为另一个邮箱或另一种用途发码 | 被拒绝 |
| `AC-AL-31` | 锁定账号 | 输入正确验证码 | 仍能收到验证码邮件，但验证码正确后被告知**账号锁定与本次剩余时间**，流程终止 |
| `AC-AL-32` | 任意 | 观察锁定告知出现的时点 | **只在验证码校验通过之后**出现，不在输入邮箱或发码阶段暴露 |
| `AC-AL-33` | 正常账号 | 设置新密码成功 | **全部会话失效**、回到登录页，触发密码变更通知 |
| `AC-AL-34` | 任意 | 超出发送限频 | 不发码并提示稍后再试；**提示不因该邮箱是否存在而变化** |
| `AC-AL-35` | 任意 | 邮件发送失败 | 允许立即重试一次且该次不计入限频额度 |

### 15.5 密码规则

| # | 场景 | 预期结果 |
| --- | --- | --- |
| `AC-AL-36` | 输入长度不足 8 或超过 20 的密码 | 被拒绝 |
| `AC-AL-37` | 输入仅字母或仅数字的密码 | 被拒绝（须至少 1 字母 + 1 数字） |
| `AC-AL-38` | 密码前后带空格 / 中间带空格 | 前后自动去除；中间不被接受 |
| `AC-AL-39` | 开始输入后查看页面 | 展示规则实时校验清单，全部满足方可提交；**不展示强弱分档** |
| `AC-AL-40` | 新密码与原密码或初始密码相同 | 提交后被拒绝并给出对应提示，原密码不变 |
| `AC-AL-41` | 检查密码展示 | 除本人主动切换密码输入框显示外，界面、日志、邮件与站内消息均不泄露明文密码；初始账密按线下交付约定提供 |

### 15.6 账户设置（`F-AL-07`～`F-AL-09`、`F-AL-19`）

| # | 场景 | 预期结果 |
| --- | --- | --- |
| `AC-AL-42` | 通过右上角账号下拉进入 | 下拉内展示工作邮箱与账号状态，提供消息中心、账户设置、退出登录；**消息中心排在账户设置之上** |
| `AC-AL-43` | 查看账号信息区块 | 展示邮箱、姓名、角色、权限、状态；邮箱与密码有本人修改入口，姓名、角色、权限与状态只读 |
| `AC-AL-44` | 两个运营角色查看本人账户设置 | 均可发起本人邮箱修改（用户已确认），无修改他人邮箱入口；校验强度执行 §9.6.1 默认口径 |
| `AC-AL-45` | 修改本人密码 | 在本页弹窗内完成，且**先做当前密码再认证** |
| `AC-AL-46` | 再认证时当前密码输错 | **计入登录失败计数**（与登录共用同一计数器） |
| `AC-AL-47` | 修改密码成功 | **全部会话失效**并触发密码变更通知 |
| `AC-AL-48` | 设置界面语言与时区 | 即时生效并持久化 |
| `AC-AL-49` | 查看账号信息字段 | **不存在部门、岗位、所属机构、机构编号等字段** |

**本人修改邮箱（`F-AL-19`）：以下按功能正文 §9.6.1 的可调整默认口径验收；“允许本人修改”不是待确认项。**

| # | 角色 / 前置与场景 | 预期结果 |
| --- | --- | --- |
| `AC-AL-111` | 正常且已完成首登改密的本人，当前密码正确 | 再认证通过后可填新邮箱；密码错误计入既有失败次数，达阈值锁定；再认证过期必须重新验证 |
| `AC-AL-112` | 新邮箱格式错误、超过 254 字符、等于原邮箱或被占用 | 不变更邮箱；按去除前后空格、大小写不敏感后的值校验；提示占用时不泄露其他账号身份/状态 |
| `AC-AL-113` | 请求新邮箱验证码 | 人机校验、既有限频全部满足后只向新邮箱发码；不要求旧邮箱验证码；有效期及错误上限沿用既有参数 |
| `AC-AL-114` | 使用错误、过期、超限、已使用、旧目标邮箱或其他用途的验证码 | 不生效，旧邮箱仍有效；同用途重发后旧码不可用；可在既有限频约束下重试 |
| `AC-AL-115` | 验证码正确，提交时新邮箱被其他账号占用/再认证失效/账号锁定 | 拒绝修改，邮箱仍为旧值；按具体原因提示重新验证、等待或换邮箱 |
| `AC-AL-116` | 新邮箱验证及所有条件通过后提交 | 设置页和账号下拉显示新邮箱；新邮箱可登录与找回，旧邮箱不再作为本账号入口；身份、角色、权限、姓名、偏好不变；默认保留已有登录状态 |
| `AC-AL-117` | 修改邮箱生效后，使用旧邮箱未完成的找回验证码 | 旧码不能重置该账号密码；新发找回码只投递当前新邮箱；以旧邮箱提交找回仍得到统一中性提示 |
| `AC-AL-118` | 邮箱修改成功；分别观察新旧邮箱 | 两个地址均触发安全通知，包含修改事件、时间与求助方式，不含密码或验证码；某一通知投递失败不回滚修改 |
| `AC-AL-119` | 验证邮件发送失败、取消、未完成验证或操作期间登录失效 | 不变更邮箱、不显示成功；发信失败可按既有规则重试；登录失效返回登录页，重新登录后重新发起 |
| `AC-AL-120` | 旧邮箱不可达但仍能登录并验证密码；或密码与旧邮箱均不可用 | 前者可通过新邮箱验证完成修改；后者只能联系建设方/运维重新初始化，无产品内人工代改入口 |
| `AC-AL-121` | 待首登改密账号通过忘记密码重置当前有效密码 | 默认仍保持待首登改密，重新登录仍强制进入 `P-O-AL-03`；初始密码过期按人工兜底处理，不以找回绕过首登要求 |

| `AC-AL-62` | 运营专员 | 发起未被授权的动作 | 返回统一的无权限提示，**不透露该功能下是否存在具体业务记录** |

| `AC-AL-64` | 任意已授权账号 | 查看某功能下的数据范围 | **全量可见**：不存在「只看与本机构相关的项目」这类过滤，界面上无机构筛选项 |
| `AC-AL-65` | 任意 | 检查权限判定条件 | 判定只依据**角色与功能权限项 + 账号状态**；**不存在机构维度参与判定** |
| `AC-AL-66` | 任意 | 检查账号类型 | 运营端只有一套账号体系；**界面上不存在「SPV 机构」这一账号类别**，SPV 职责通过功能权限项体现 |
| `AC-AL-67` | 锁定 / 待首登改密账号 | 任何业务动作 | 一律不生效，即使此前已被授权 |

### 15.9 会话、锁定与安全（`F-AL-12`、`F-AL-13`）

| # | 场景 | 预期结果 |
| --- | --- | --- |
| `AC-AL-68` | 登录后长时间不操作 | 达到无操作时长后自动登出并给出原因提示 |
| `AC-AL-69` | 页面只有后台轮询、无任何用户交互 | **无操作计时不被重置**，到点仍会自动登出 |
| `AC-AL-70` | 会话即将到期 | 到期前给出续期确认，可选择继续保持登录或立即退出 |
| `AC-AL-71` | 查看登录页与会话数据 | **不存在「记住我」** |
| `AC-AL-72` | 退出登录 / 改密 / 重置密码 / 首登改密 | 该账号**全部会话（含当前设备）失效** |
| `AC-AL-73` | 会话失效后 | 本地登录态被清除，但**语言偏好保留** |
| `AC-AL-74` | 同一浏览器多标签页 | 任一标签检测到失效后，其余标签一并回到登录页 |
| `AC-AL-75` | 后台请求遇到登录态失效 | 触发与前台一致的失效处理，**不被静默忽略** |
| `AC-AL-76` | 连续密码失败达阈值 | 账号锁定，**登录与忘记密码全部不可用**，无提前解除通道 |
| `AC-AL-77` | 多次触发锁定 | 锁定时长按阶梯递进；距上次触发满归零窗口后回到第一档 |
| `AC-AL-78` | 锁定期间查看登录页 | 页内展示剩余时间并实时倒计时，归零后表单**自动恢复可用、无需刷新** |
| `AC-AL-79` | 失败次数达提示阈值 | 开始提示剩余次数；第一档锁定提示中告知再次触发时间会更长 |

### 15.10 通知（`F-AL-18`）

| # | 场景 | 预期结果 |
| --- | --- | --- |
| `AC-AL-80` | 首登改密 / 忘记密码重置 / 账户设置内改密 | **三种情形均触发**密码变更通知，通过邮件与站内消息告知本人，并正确区分是「设置」「修改」还是「重置」 |
| `AC-AL-81` | 观察通知触发时点 | 新密码生效之后、会话批量失效之前 |
| `AC-AL-82` | 账号被锁定 / 锁定自动解除 / 登录成功或失败 / 偏好变更 | **均不产生通知** |
| `AC-AL-83` | 查看找回密码与新邮箱验证邮件 | 文案中性、不透露该邮箱是否已有账号；**不含一键登录链接**；验证码**不出现在邮件主题与预览文本中** |
| `AC-AL-84` | 密码或邮箱修改生效后的安全通知发送失败 | 不回滚已生效操作；**验证邮件未送达、验证码未校验通过则不能完成依赖它的修改** |
| `AC-AL-85` | 查看站内消息 | 消息只落在本运营端，**看不到代币发行平台运营端或面客端的任何消息**，界面也不提供跨平台查看入口 |

### 15.11 国际化与全局交互（`F-AL-10`、`F-AL-11`）

> 规则正文在**三平台共享国际化基线**，本节只验收本模块的可观察结果。

| # | 场景 | 预期结果 |

## 16. 非功能与安全验收

### 16.1 非功能要求

| 维度 | 要求 |
| --- | --- |
| 性能 · 页面 | 登录页首屏可交互 ≤ 2s（正常网络，目标值） |
| 性能 · 关键操作 | 登录、发码、人机校验的响应 P95 ≤ 800ms（目标值） |
| 性能 · 邮件 | 验证码邮件 P90 在 30s 内送达（目标值） |
| 性能 · 语言切换 | 切换后界面完成重渲染 ≤ 300ms，不出现整页白屏 |
| 可用性 | 登录相关能力可用性 ≥ 99.9%（目标值） |
| 浏览器兼容 | Chrome / Edge / Firefox / Safari 最近两个大版本 |
| 响应式 | **桌面优先**（控制台形态）；≥ 768px 完整布局，< 768px 单列布局；登录、首登改密、找回、账户设置全流程在移动端可完成；人机校验适配触屏 |
| 弱网 | 请求超时后按钮恢复可点、已填内容不丢失；倒计时以服务端返回的剩余时间为准 |
| 可访问性 | 表单标签可关联、键盘全流程可达、对比度符合 WCAG AA、图标按钮可被读屏识别、Toast 通过 live region 播报 |
| **已知无障碍缺口** | 人机校验**不提供无障碍替代方案**，且运营端没有第二条找回路径。缓解：人机校验支持键盘操作；弹窗内提供求助入口，**不静默失败**；依赖读屏的运营人员可由建设方/运维在数据层重新初始化（`R-AL-03`） |
| 可观测 | 首登改密完成率、登录成功率、发码成功率、邮件送达率、锁定触发量与档位分布需可监控 |
| 部署前置 | **建设方交付初始账号、角色绑定与权限配置**是系统可用的部署前置条件，须写入部署清单并在上线检查中确认 |
| 部署前置 | 运营端发信地址的域名认证配置须在首次发信前完成，**与另两个平台分开维护** |
