## `FL-AL-02` 初始账密与首登强制改密

```mermaid
flowchart TD
    A["建设方交付初始邮箱与密码<br/>同时配置角色和初始权限"] --> B["本人在 P-O-AL-01 登录"]
    B --> C{"登录凭据验证通过且未锁定?"}
    C -->|否| D["按 FL-AL-03 处理<br/>不能进入业务功能"]
    C -->|是| E{"初始密码是否已过期?"}
    E -->|是| F["不建立登录态<br/>联系建设方或运维重新初始化"]
    E -->|否| G["P-O-AL-03 首登强制改密<br/>只允许改密、退出和语言切换"]
    G --> H{"当前密码与新密码校验通过?"}
    H -->|否| I["提示对应错误<br/>密码错误计入既有锁定规则"]
    I --> G
    H -->|是| J["新密码生效，账号转正常<br/>初始密码失效"]
    J --> K["触发密码变更通知<br/>全部会话失效，回登录页重新登录"]
```

所有交付账号必经此流程；人工重新初始化是线下兜底，无产品管理入口，且不能提前解除锁定。

## `FL-AL-03` 日常登录与落地

```mermaid
flowchart TD
    A["输入工作邮箱与密码"] --> B{"凭据正确?"}
    B -->|否| C["统一失败提示<br/>按既有规则计数、达到阈值锁定"]
    C --> A
    B -->|是| D{"账号状态?"}
    D -->|锁定| E["展示剩余时间与倒计时<br/>到期自动恢复表单"]
    D -->|待首登改密| F["按 FL-AL-02 检查有效期<br/>有效则强制进入 P-O-AL-03"]
    D -->|正常| G{"有本运营端内的原目标?"}
    G -->|是| H["回到原目标，仍须满足对应功能权限"]
    G -->|否| I["进入 P-O-AL-07 总览"]
    H --> J["按交付配置收敛菜单及动作权限"]
    I --> J
```

锁定告知仅在凭据校验通过后出现；不能从登录提示、页面表现或响应快慢辨别邮箱是否存在。达到提示阈值后的剩余次数提示遵守同一防枚举要求。

## `FL-AL-04` 忘记密码

```mermaid
flowchart TD
    A["登录页点忘记密码<br/>P-O-AL-04 输入当前工作邮箱"] --> B{"人机校验通过?"}
    B -->|否| C["不发码，可重试<br/>连续失败按既有规则冷却"]
    B -->|是| D{"发送限频通过?"}
    D -->|否| E["不发码，提示等待"]
    D -->|是| F["向当前工作邮箱发码<br/>对外统一中性提示"]
    F --> G{"验证码通过?"}
    G -->|否| H["提示验证码无效<br/>不透露账号存在性"]
    G -->|是| I{"账号是否锁定?"}
    I -->|是| J["告知锁定及剩余时间<br/>流程终止"]
    I -->|否| Q{"仍待首登改密且初始密码已过期?"}
    Q -->|是| R["联系建设方或运维重新初始化"]
    Q -->|否| K["P-O-AL-05 设置新密码"]
    K --> L{"满足密码规则且不同于原密码与初始密码?"}
    L -->|否| K
    L -->|是| M["新密码生效，触发密码通知<br/>全部会话失效并回到登录页"]
    M --> N["未完成首登改密者仍须完成 P-O-AL-03"]
```

锁定判定位于验证码校验通过之后；锁定账号仍可收到邮件但不能完成重置。待首登改密的衔接为默认口径。邮箱不可达且无法登录时，只能联系建设方/运维重新初始化。

## `FL-AL-06` 本人修改密码

```mermaid
flowchart TD
    A["账户设置选择修改密码"] --> B{"当前密码再认证通过?"}
    B -->|否| C["提示错误并计入既有失败次数<br/>达阈值锁定"]
    B -->|是| D["填写新密码及确认密码"]
    D --> E{"规则与原密码、初始密码比对通过?"}
    E -->|否| D
    E -->|是| F["新密码生效，触发密码通知"]
    F --> G["全部会话失效<br/>回登录页重新登录"]
```

<a id="fl-al-07"></a>

## `FL-AL-07` 本人修改邮箱

允许本人修改为用户确认需求；以下校验强度及衔接为**默认口径，可由用户调整**。

```mermaid
flowchart TD
    A["正常账号在账户设置点击邮箱修改"] --> B{"当前密码再认证通过?"}
    B -->|否| C["旧邮箱不变<br/>密码错误按既有规则计数和锁定"]
    B -->|是| D["填写新邮箱"]
    D --> E{"格式正确、不同于旧邮箱且唯一?"}
    E -->|否| F["提示错误或邮箱不可用<br/>不泄露占用账号信息"]
    F --> D
    E -->|是| G{"人机校验及发送限频通过?"}
    G -->|否| H["不发码，按既有规则重试或等待"]
    G -->|是| I["向新邮箱发送验证码"]
    I --> J["输入验证码并提交"]
    J --> K{"验证码有效、再认证有效<br/>账号正常且新邮箱仍唯一?"}
    K -->|否| L["旧邮箱不变<br/>按错误原因重新验证、等待或换邮箱"]
    K -->|是| M["新邮箱生效，更新设置及账号下拉<br/>用于后续登录、找回与安全通知"]
    M --> N["旧邮箱未完成的找回码失效<br/>身份、权限及当前登录保持原值"]
    N --> O["向新旧地址各发安全通知<br/>通知失败不回滚已生效修改"]
```

不要求旧邮箱收码。取消、未完成验证或会话失效时旧邮箱不变；验证码邮件不可达时不能完成验证。邮箱修改在账户设置内完成，不新增独立页面。

## `SM-AL-01` 运营账号状态

```mermaid
stateDiagram-v2
    [*] --> 待首登改密: 建设方交付初始账号
    待首登改密 --> 正常: 完成 P-O-AL-03 强制改密
    待首登改密 --> 锁定: 连续密码失败达到阈值
    正常 --> 锁定: 连续密码失败达到阈值
    锁定 --> 待首登改密: 到期自动解除且原状态待首登改密
    锁定 --> 正常: 到期自动解除且原状态正常
```

`ST-AL-1` 待首登改密仅可完成首次改密；`ST-AL-2` 正常按交付权限操作；`ST-AL-3` 锁定不能完成登录、找回或业务操作，无提前解除通道。本期不含停用/启用及产品内他人改密状态转换。

<a id="sm-al-02"></a>

## `SM-AL-02` 登录会话状态

```mermaid
stateDiagram-v2
    [*] --> 受限会话: 待首登改密账号验证通过且密码未过期
    [*] --> 有效会话: 正常账号登录成功
    受限会话 --> 已失效: 完成首登改密或退出或重置密码
    受限会话 --> 已过期: 达到有效期或无操作超时
    有效会话 --> 已过期: 达到有效期或无操作超时
    有效会话 --> 已失效: 退出或本人改密或重置密码
    已过期 --> [*]
    已失效 --> [*]
```

首登改密后必须重新登录，不能把原受限会话直接升级。全部会话失效包括当前设备及多标签页，语言偏好保留；只有真实用户操作计入活动，后台请求不延长无操作时长。邮箱修改默认保留现有会话，账号锁定时任何已有会话均不得执行业务动作。

<a id="sm-al-03"></a>

## `SM-AL-03` 验证码状态

仅适用于**找回密码、新邮箱验证**，详见功能册 §12.3。

```mermaid
stateDiagram-v2
    [*] --> 已签发: 发往本次用途的目标邮箱
    已签发 --> 已使用: 完成验证与对应操作
    已签发 --> 已过期: 超过有效期
    已签发 --> 已作废: 同用途重发或超过错误上限或密码变更
    已签发 --> 已作废: 邮箱修改生效使旧邮箱找回码失效
    已使用 --> [*]
    已过期 --> [*]
    已作废 --> [*]
```

同账号同用途仅最新验证码有效，不可跨用途或目标邮箱使用。更换待验证邮箱后，旧目标的验证码不能用于新目标；所有终态均不可重复使用。
