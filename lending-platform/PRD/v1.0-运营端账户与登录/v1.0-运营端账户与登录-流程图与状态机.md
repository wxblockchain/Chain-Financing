## `FL-AL-01` 账号开通 · 邀请方式

```mermaid
flowchart TD
    A["运营管理员：新建账号<br/>填工作邮箱 / 姓名 / 角色 / 功能权限"] --> B{"工作邮箱是否已被占用?"}
    B -->|是| B1["拒绝创建<br/>提示不透露已有账号的其他信息"]
    B -->|否| C["账号创建为「待开通」"]
    C --> D["系统向工作邮箱发出开通邀请"]
    D --> E["被邀请人打开邀请"]
    E --> F{"邀请是否有效?"}
    F -->|已使用 / 已过期 / 已作废| F1["展示失效说明<br/>提示联系运营管理员重发"]
    F1 --> G["运营管理员重发邀请<br/>此前未使用的邀请立即作废"]
    G --> E
    F -->|有效| H["P-O-AL-02 设置本人密码"]
    H --> I{"密码是否满足规则?"}
    I -->|否| I1["提示未满足的规则项<br/>停留在本页"]
    I1 --> H
    I -->|是| J["账号转为「正常」<br/>该邀请立即作废"]
    J --> K["跳转登录页，用新密码登录"]
```

> 关键分支：邀请失效只给中性说明；重发后**只有最新一份邀请有效**；全程系统不在任何在线渠道下发明文密码。

## `FL-AL-02` 账号开通 · 初始密码方式与首登强制改密

```mermaid
flowchart TD
    A["运营管理员：新建账号并选择初始密码开通"] --> B["账号创建为「待开通」"]
    B --> C["初始密码线下交付本人"]
    C --> D["本人在 P-O-AL-01 首次登录"]
    D --> E{"初始密码是否已过期?"}
    E -->|是| E1["不建立登录态<br/>提示联系运营管理员重新发起开通"]
    E -->|否| F["建立受限会话<br/>强制进入 P-O-AL-03"]
    F --> G["输入当前初始密码 + 新密码 + 确认"]
    G --> H{"新密码是否通过校验?"}
    H -->|与原密码或初始密码相同| H1["拒绝并提示<br/>停留在本页"]
    H1 --> G
    H -->|通过| I["账号转为「正常」"]
    I --> J["全部会话失效"]
    J --> K["触发密码变更通知"]
    K --> L["回到登录页重新登录"]
```

> 受限会话期间，除本页、退出登录与语言切换外**任何功能都不可用**，绕过界面直接发起业务动作同样被拒绝。

## `FL-AL-03` 日常登录与落地

```mermaid
flowchart TD
    A["P-O-AL-01 输入工作邮箱 + 密码"] --> B{"凭据是否正确?"}
    B -->|否| B1["统一提示：邮箱或密码不正确<br/>计入失败计数，达阈值起提示剩余次数"]
    B1 --> C{"连续失败是否达锁定阈值?"}
    C -->|否| A
    C -->|是| C1["账号锁定<br/>页内展示剩余时间并倒计时<br/>归零后表单自动恢复"]
    B -->|是| D{"账号状态?"}
    D -->|锁定| C1
    D -->|停用| D1["提示账号已停用<br/>请联系运营管理员"]
    D -->|待开通 · 邀请方式| D2["提示尚未完成开通<br/>请通过开通邀请完成设置"]
    D -->|待开通 · 初始密码方式| D3["强制进入 P-O-AL-03（见 FL-AL-02）"]
    D -->|正常| E{"是否存在被记住的原目标?"}
    E -->|有且属于本运营端范围| E1["回到原目标"]
    E -->|无 / 不属于本运营端范围| E2["落到 P-O-AL-07 总览页"]
    E1 --> F["按已开通的功能权限收敛菜单与入口"]
    E2 --> F
```

> 锁定的告知只在**凭据校验之后**出现；账号是否存在不得从提示、页面表现或响应快慢中被区分出来。

## `FL-AL-04` 忘记密码

```mermaid
flowchart TD
    A["登录页点「忘记密码」"] --> B["P-O-AL-04 输入工作邮箱"]
    B --> C["人机校验 C-O-AL-01"]
    C -->|失败| C1["复位重试；连续失败进入冷却<br/>不发码"]
    C1 --> C
    C -->|通过| D{"发送限频是否超限?"}
    D -->|超限| D1["不发码，提示稍后再试<br/>提示不因邮箱是否存在而变化"]
    D -->|未超限| E["发送验证码到工作邮箱<br/>提示为中性文案"]
    E --> F["输入验证码"]
    F --> G{"验证码是否通过?"}
    G -->|否| G1["提示验证码无效<br/>不透露账号是否存在"]
    G1 --> F
    G -->|是| H{"账号是否处于锁定?"}
    H -->|是| H1["告知锁定与本次剩余时间<br/>流程终止"]
    H -->|否| I["P-O-AL-05 设置新密码"]
    I --> J{"是否与原密码 / 初始密码相同?"}
    J -->|是| J1["拒绝并提示"]
    J1 --> I
    J -->|否| K["全部会话失效 → 触发密码变更通知 → 回到登录页"]
```

> **锁定判定必须位于验证码校验之后**：提前会重新打开账号枚举通道。锁定期间用户仍会收到验证码邮件，这是「防枚举」与「锁定期间全通道不可用」同时成立的唯一组合。

## `FL-AL-05` 角色分配与功能权限授权

```mermaid
flowchart TD
    A["运营管理员进入 P-O-AL-08 账号列表"] --> B["打开某账号 P-O-AL-09"]
    B --> C{"调整什么?"}
    C -->|切换角色| D["以新角色的默认权限集合覆盖当前勾选<br/>并提示本次变化"]
    C -->|逐项勾选功能权限| E["在 C-O-AL-07 面板内增减权限项"]
    C -->|停用 / 启用| F["二次确认"]
    C -->|重新发起开通| G["二次确认"]
    D --> H{"是否触碰不变量?"}
    E --> H
    F --> H
    G --> H
    H -->|"最后一个正常状态的运营管理员被停用 / 降级 / 收回授权权限"| H1["拒绝并给出明确原因<br/>不做任何变更"]
    H -->|"运营管理员收回自己的授权权限"| H1
    H -->|否| I["保存"]
    I --> J["立即生效：被调整人无需重新登录"]
    J --> K["入口随即出现或消失<br/>绕过界面发起未授权动作同样被拒绝"]
    I --> L["停用 / 重新发起开通：该账号全部会话立即失效"]
    I --> M["记录留痕：操作人 / 时间 / 对象 / 变更内容"]
```

## `SM-AL-01` 运营账号状态机

```mermaid
stateDiagram-v2
    [*] --> 待开通: 运营管理员创建账号 / 部署初始化首个账号
    待开通 --> 正常: 完成邀请设密 或 完成首登强制改密
    待开通 --> 锁定: 连续密码校验失败达阈值
    正常 --> 锁定: 连续密码校验失败达阈值
    锁定 --> 正常: 本次锁定到期自动解除（原状态为正常）
    锁定 --> 待开通: 本次锁定到期自动解除（原状态为待开通）
    正常 --> 待开通: 运营管理员重新发起开通（原密码与全部会话失效）
    待开通 --> 停用: 运营管理员停用
    正常 --> 停用: 运营管理员停用
    锁定 --> 停用: 运营管理员停用
    停用 --> 正常: 运营管理员启用（停用前为正常）
    停用 --> 待开通: 运营管理员启用（停用前为待开通）
```

| 状态 | 含义 | 该状态下的可用性 |
| --- | --- | --- |
| 待开通 `ST-AL-1` | 账号已创建，本人尚未设置自己的密码 | 只能完成开通；其他功能一律不可用 |
| 正常 `ST-AL-2` | 已完成开通 | 按已开通的功能权限正常使用 |
| 锁定 `ST-AL-3` | 连续密码校验失败达阈值 | 登录与忘记密码全部不可用，无提前解除通道 |
| 停用 `ST-AL-4` | 被运营管理员停用 | 不可登录，已有会话立即失效 |

> **不变量**：系统内最后一个处于「正常」状态的运营管理员**不可被停用、降级或收回账号与权限管理权限**（`D-AL-12`），因此上图中指向「停用」的转换对该账号不成立。

## `SM-AL-02` 登录会话状态机

```mermaid
stateDiagram-v2
    [*] --> 受限会话: 待开通账号（初始密码方式）登录成功
    [*] --> 有效会话: 正常账号登录成功
    受限会话 --> 有效会话: 完成首登改密后重新登录
    受限会话 --> 已失效: 退出登录 / 账号被停用
    有效会话 --> 已过期: 达到会话有效期 或 无操作超时
    有效会话 --> 已失效: 退出登录 / 本人改密 / 重置密码 / 账号被停用 / 被重新发起开通
    已过期 --> [*]
    已失效 --> [*]
```

| 状态 | 用户可见的表现 |
| --- | --- |
| 受限会话 | 只能完成首登改密、退出登录与切换语言 |
| 有效会话 | 正常使用；到期前给出续期确认 |
| 已过期 | 清本地登录态（语言偏好保留）、Toast 告知原因、回到登录页并记住原目标 |
| 已失效 | 同上；同一账号的全部设备与同一浏览器的全部标签页一并失效 |

> 只有真实的用户交互才重置无操作计时，**后台轮询、心跳与预取不计**。

## `SM-AL-03` 开通凭据状态机

适用于**开通邀请**与**找回验证码**两类一次性凭据。

```mermaid
stateDiagram-v2
    [*] --> 已签发: 发往工作邮箱
    已签发 --> 已使用: 本人完成设密 / 重置
    已签发 --> 已过期: 超过有效期
    已签发 --> 已作废: 重发邀请 / 重新发起开通 / 本人已完成密码变更
    已使用 --> [*]
    已过期 --> [*]
    已作废 --> [*]
```

> 同一账号**同时只有最新一份凭据有效**；已使用、已过期、已作废的凭据再次打开时只给中性的失效说明，不泄露账号信息。
