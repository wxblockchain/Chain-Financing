## 9. 页面与功能详情

### 9.1 页面与组件清单

**运营端页面共 9 个**：

| 编号 | 页面 | 形态 | 说明 |
| --- | --- | --- | --- |
| `P-O-AL-01` | 运营端登录页 | 整页 | 工作邮箱 + 密码。**无注册入口、无协议勾选、无「记住我」、无验证码登录、无钱包登录**。提供「忘记密码」入口。账号锁定时在本页内以状态态展示锁定提示与倒计时 |
| `P-O-AL-02` | 开通 · 设置密码页 | 整页 | 被邀请人从开通邀请进入，设置本人密码完成开通。页面上**无任何勾选项**，只保留语言切换 |
| `P-O-AL-03` | 首次登录 · 强制改密页 | 整页 | 初始密码开通方式下的首登页。未完成改密不得访问其他任何页面；只保留「退出登录」与语言切换两个出口 |
| `P-O-AL-04` | 忘记密码 · 提交工作邮箱 | 整页 | 输入工作邮箱 → 人机校验（`C-O-AL-01`）→ 发送验证码 |
| `P-O-AL-05` | 忘记密码 · 设置新密码 | 整页 | 验证码校验通过后设置新密码，带密码规则实时校验清单 |
| `P-O-AL-06` | 账户设置 | 整页 + tab 锚点 | 单页分「账号信息」与「偏好信息」两区块；修改密码在本页内以弹窗完成；通过右上角账号下拉进入 |
| `P-O-AL-07` | 运营端总览页 | 整页 | **本模块只出壳子**，作为登录成功后的落地目标与左侧菜单首项；页面内容归后续业务模块。壳子内给出简短说明文字而非完全空白 |
| `P-O-AL-08` | 账号与权限管理 · 账号列表 | 整页 | 账号检索、状态筛选、新建 / 邀请账号入口、停用与启用、重发开通邀请 |
| `P-O-AL-09` | 账号与权限管理 · 账号详情与授权 | 整页 | 单个账号的信息、角色与功能权限逐项授权、操作区（停用 / 启用 / 重发开通） |

**运营端组件**

| 编号 | 组件 | 用法 |
| --- | --- | --- |
| `C-O-AL-01` | 人机校验弹窗 | 发送验证码前置 |
| `C-O-AL-02` | 语言切换器（下拉形态） | 未登录在登录页右上角，已登录在顶部导航栏右侧 |
| `C-O-AL-03` | 顶部面包屑 | 顶部导航栏下方；最多三级，除当前页外各级可点击 |
| `C-O-AL-04` | 右上角账号下拉 | 展示工作邮箱与账号状态；提供「消息中心」（**条目由 WS-360 挂载**）、「账户设置」、「退出登录」三项，消息中心排在账户设置之上 |
| `C-O-AL-05` | Toast 轻提示 | 顶部居中，全站唯一轻提示载体 |
| `C-O-AL-06` | 密码规则实时校验清单 | 设置密码类页面与弹窗内使用，只展示规则是否满足，**不展示强弱分档** |
| `C-O-AL-07` | 功能权限勾选面板 | `P-O-AL-09` 内按功能域分组展示全部可授权项，逐项勾选 |

| （挂载位） | 通知铃铛 | 位于语言切换器左侧、账号下拉之前。**本模块只提供挂载位置，形态与行为归 WS-360** |

### 9.2 `P-O-AL-01` 登录页（`F-AL-04`）

| 项 | 口径 |
| --- | --- |
| 入口 | 运营端任意受保护功能在未登录时均引导到本页，并记住原本要去的目标 |
| 页面元素 | 工作邮箱、密码（带显示/隐藏切换）、登录按钮、「忘记密码」入口、语言切换器 |
| 明确不提供 | 注册入口、协议勾选、「记住我」、验证码登录、钱包登录、第三方登录 |
| 校验失败 | **邮箱不存在与密码错误返回完全一致的提示与页面表现**，不可从提示文案或响应快慢区分（`D-AL-17`） |
| 失败计数 | 密码错误计入失败计数；达到提示阈值（`N-AL-05`）后开始提示剩余次数；第一档锁定的提示中告知「若再次触发，锁定时间会更长」 |
| 账号状态分支 | **待开通（初始密码方式）** → 登录成功后强制进入 `P-O-AL-03`；**待开通（邀请方式，尚未设密）** → 提示该账号尚未完成开通，请通过开通邀请完成设置，**不透露密码是否正确以外的账号信息**；**正常** → 进入落地页；**锁定** → 本页内展示锁定提示与实时倒计时，归零后表单自动恢复可用、无需刷新；**停用** → 提示账号已停用，请联系运营管理员 |
| 初始密码已过期 | 提示初始密码已过期、请联系运营管理员重新发起开通，**且不建立登录态** |
| 落地（`F-AL-06`） | 有原目标且属于本运营端范围 → 回到原目标；否则 → `P-O-AL-07` 总览页。**原目标不属于本运营端范围时一律丢弃，落到总览页** |
| 首次登录成功 | 按浏览器推断并写入时区偏好，推断失败兜底 UTC（`F-AL-11`） |

### 9.3 `P-O-AL-02` 开通 · 设置密码页（`F-AL-02`）

| 项 | 口径 |
| --- | --- |
| 进入方式 | 被邀请人从工作邮箱收到的开通邀请进入。**该页面不可由未持有有效邀请的人到达**；邀请无效、已使用或已过期时展示失效说明并提示联系运营管理员重发 |
| 页面元素 | 工作邮箱（**只读展示**，来自邀请）、新密码、确认新密码、密码规则实时校验清单（`C-O-AL-06`）、语言切换器 |
| 页面上没有 | 任何勾选项、任何其他导航入口 |
| 提交成功 | 账号由**待开通 `ST-AL-1`** 转为**正常 `ST-AL-2`**；该邀请立即作废；跳转登录页要求本人用新密码登录 |
| 有效期 | 邀请有效期 `N-AL-06`；过期后须由运营管理员重发 |
| 重发规则 | 运营管理员重发邀请时，**此前所有未使用的邀请立即作废**，只有最新一份有效 |
| 安全要求 | 系统**在任何在线渠道都不下发明文密码**；邀请邮件文案保持中性，不透露该邮箱的账号状态细节 |

### 9.4 `P-O-AL-03` 首次登录 · 强制改密页（`F-AL-03`）

| 项 | 口径 |
| --- | --- |
| 触发 | 以初始密码开通的账号首次登录成功后**立即**进入本页 |
| 拦截范围 | 未完成改密前，**除本页、退出登录与语言切换外，运营端任何页面与任何业务动作都不可用**；绕过界面直接发起业务动作同样被拒绝，不依赖界面拦截作为唯一防线 |
| 页面元素 | 当前（初始）密码、新密码、确认新密码、密码规则实时校验清单；**无任何勾选项**；无左侧菜单、无面包屑 |
| 密码校验 | 见 11.3；**新密码不得与初始密码相同**，该比对由服务端在提交后返回 |
| 完成后 | 账号转为**正常 `ST-AL-2`** → **全部会话失效** → 回到登录页重新登录 → 触发密码变更通知（`F-AL-18`） |

### 9.5 `P-O-AL-04` / `P-O-AL-05` 忘记密码（`F-AL-05`）

**第一步 `P-O-AL-04` 提交工作邮箱**

| 项 | 口径 |
| --- | --- |
| 入口 | 登录页「忘记密码」 |
| 顺序 | 输入工作邮箱 → **人机校验（`C-O-AL-01`）** → **发送限频校验** → 发送验证码。三步顺序不可调换、不可豁免（`D-AL-22`） |
| 提示文案 | 中性表述：「若该邮箱为运营端账号，验证码已发送」。**已注册与未注册邮箱得到完全一致的响应**，含页面表现与响应快慢 |
| 人机校验失败 | 弹窗内复位重试；连续失败达 `N-AL-07` 进入冷却；**不签发凭据、不发码** |
| 限频超限 | 不发码，提示稍后再试或给出剩余等待时间；提示内容不因该邮箱是否存在而变化 |
| 发信失败 | 允许立即重试一次且不计入限频额度 |

**第二步 `P-O-AL-05` 设置新密码**

| 项 | 口径 |
| --- | --- |
| 前置 | 验证码校验通过 |
| **锁定判定时点** | **必须在验证码校验通过之后**，不得提前到输入邮箱或发码阶段——提前会重新打开账号枚举通道。锁定中则提示账号锁定与本次剩余时间，**流程终止** |
| 页面元素 | 新密码、确认新密码、密码规则实时校验清单 |
| 密码校验 | 见 11.3，含「不得与原密码相同」「不得与初始密码相同」双重比对 |
| 成功后 | **全部会话失效** → 回到登录页 → 触发密码变更通知 |
| 无法自助的兜底 | 工作邮箱收不到邮件时本流程无替代自助途径，由运营管理员重新发起开通（`PM-AL-03`）；**若当事人是最后一个运营管理员本人，只能由部署 / 运维在数据层重新初始化**（风险 `R-AL-02`） |

### 9.6 `P-O-AL-06` 账户设置（`F-AL-07`、`F-AL-08`）

- **进入方式**：右上角账号下拉（`C-O-AL-04`）→「账户设置」。
- **形态**：单页 + tab 锚点滚动；修改密码在本页内以弹窗完成。

| 区块 | 条目 | 操作 |
| --- | --- | --- |
| 账号信息 | 工作邮箱 | **只读**（登录账号，无修改入口，`D-AL-25`） |
| 账号信息 | 姓名 | 只读 |
| 账号信息 | 角色 | 只读（由运营管理员分配） |
| 账号信息 | 已开通功能权限 | **只读清单**，按功能域分组展示；本人可据此知道自己能做什么 |
| 账号信息 | 账号状态 | 只读 |
| 账号信息 | 登录密码 | 「修改」→ 弹窗内先**再认证当前密码**，再设置新密码 |
| 偏好信息 | 界面语言 | 下拉选择，即时生效并持久化（规则见共享国际化基线） |
| 偏好信息 | 时区 | 下拉选择；界面所有时间点按该偏好展示并带时区标注 |

> **修改密码成功后全部会话失效**（含当前设备），回到登录页重新登录，并触发密码变更通知。
> **再认证时当前密码输错计入登录失败计数**，与登录共用同一计数器。

### 9.7 `P-O-AL-07` 总览页（壳子）

登录成功后的默认落地页与左侧菜单首项。本模块只提供页面骨架与一段说明文字，**不预先编造业务卡片、统计数字或待办列表**；内容由后续业务模块补入。

### 9.8 `P-O-AL-08` 账号与权限管理 · 账号列表（`F-AL-14`、`F-AL-15`）

| 项 | 口径 |
| --- | --- |
| 可见条件 | 需被授权 `PM-AL-04`；新建、停用、启用、重发开通还需对应权限项 |
| 列表列 | 工作邮箱、姓名、角色、账号状态、开通方式、最近登录时间、创建时间 |
| 检索与筛选 | 按工作邮箱或姓名关键词检索；按角色、账号状态筛选 |
| 行内操作 | 查看详情（`P-O-AL-09`）、停用 / 启用、重发开通邀请 |
| 新建入口 | 「新建账号」→ 填写工作邮箱、姓名、角色，选择开通方式（邀请 / 初始密码），可同时逐项授权功能权限 |
| 停用 | 二次确认后即时生效：该账号**全部会话立即失效**，此后不可登录 |
| 启用 | 恢复为停用前的状态；若停用前处于待开通，则恢复后仍需完成开通 |
| **不变量** | **系统内最后一个处于正常状态的运营管理员不可被停用**（`D-AL-12`），界面给出明确拒绝提示 |
| 越权保护 | 未被授权者不可见本页入口；绕过界面直接发起账号类动作同样被拒绝 |

### 9.9 `P-O-AL-09` 账号详情与授权（`F-AL-16`）

| 区块 | 内容 |
| --- | --- |
| 账号信息 | 工作邮箱、姓名、账号状态、开通方式、创建时间、最近登录时间（均只读） |
| 角色 | 下拉选择 `RO-AL-1` / `RO-AL-2`；切换角色时，该角色的默认权限集合覆盖当前勾选结果，并提示本次变化 |
| 功能权限 | `C-O-AL-07` 面板：按功能域分组列出全部可授权项（10.2），逐项勾选。运营管理员角色下全部权限项固定开通且不可取消勾选 |
| 操作区 | 停用 / 启用、重发开通邀请、重新发起开通（改为初始密码方式时线下交付） |
| 保存 | 保存后**立即生效**（`D-AL-11`）；被调整人无需重新登录 |
| **不变量** | 不可将系统内最后一个正常状态的运营管理员降级为运营专员，也不可收回其 `PM-AL-01`～`PM-AL-03`（`D-AL-12`） |
| 自我保护 | 运营管理员**不可收回自己的** `PM-AL-02`（授权权限），避免把自己锁在授权能力之外；其余权限项可自行调整 |

## 10. 功能权限矩阵

### 10.1 组织方式（`D-AL-07`）

- 权限的基本单位是**功能权限项 `PM-AL-*`**：一个可被单独授权、单独收回的运营动作或一组同源动作。
- **角色是权限项的默认集合**（`D-AL-09`），不是权限的唯一来源；实际能力 = 角色默认集合 ± 逐项授权结果。
- **矩阵里没有机构维度**：不存在「本机构的」「其他机构的」这类过滤条件，也没有机构字段参与判定（`D-AL-05`）。SPV 职责通过权限项表达（`D-AL-13`）。
- **权限项的业务规则定义权不在本模块**：本模块定义「这是一个可授权项、谁默认有、授权后能进入哪个入口」；**动作本身怎么算通过、怎么算驳回，由对应业务模块定义**。

### 10.2 功能权限项清单

| 编号 | 功能权限项 | 覆盖动作 | 规则定义方 |
| --- | --- | --- | --- |
| `PM-AL-01` | 账号开通与停用 | 创建账号、发出与重发开通邀请、停用、启用 | 本模块（9.8、9.9） |
| `PM-AL-02` | 角色分配与功能权限授权 | 分配角色、逐项授权或收回功能权限 | 本模块（9.9） |
| `PM-AL-03` | 重新发起他人账号的开通 | 对已开通账号重新发起开通（重发邀请或改为初始密码方式），用于本人彻底无法登录时的兜底 | 本模块（9.9） |
| `PM-AL-04` | 账号信息查询 | 查看账号列表与账号详情 | 本模块（9.8、9.9） |
| `PM-AL-05` | 资金方机构认证申请查询 | 查看资金方机构认证的申请与材料 | **WS-358（L4）** |
| `PM-AL-06` | 资金方机构认证审核处置 | 对资金方机构认证申请作出审核结论 | **WS-358（L4）** |
| `PM-AL-07` | 代币质押申请查询 | 查看代币质押申请与其状态 | **WS-359（L11）** |
| `PM-AL-08` | 代币质押审核处置 | 对代币质押申请作出审核结论 | **WS-359（L11）** |
| `PM-AL-09` | 协议内容与版本查询 | 查看协议内容与版本记录 | **WS-361（L15）** |

### 10.5 授权与生效规则

| 规则 | 口径 |
| --- | --- |
| 授权变更的生效（`D-AL-11`） | 授权与收回**立即生效**，被调整人无需重新登录；入口随即出现或消失 |
| 最后一个运营管理员保护（`D-AL-12`） | 最后一个正常状态的运营管理员不可被停用、降级或收回账号与权限管理权限 |
| 界面收敛与动作拦截一致 | 未授权的功能在菜单与页面入口上不出现；**绕过界面直接发起该动作同样被拒绝**，界面隐藏不作为唯一防线 |
| 越权的表现 | 被拒绝时给出统一的「无权限」提示，**不透露该功能下是否存在具体业务记录** |
| 授权的记录 | 每次角色变更、权限授予与收回均留痕：谁在什么时间对谁做了什么变更，可供事后追溯 |
| 授权与账号状态的关系 | 权限判定的前提是账号处于**正常**状态；待开通、锁定、停用状态下所有业务权限一律不生效 |
| 角色切换的覆盖关系 | 切换角色时以新角色的默认集合为准并提示变化，避免遗留上一个角色的零散授权 |

### 10.6 数据可见范围

| 项 | 口径 |
| --- | --- |
| 总原则 | **同一主体，运营端数据全量可见**（`D-AL-05`）。可见范围只由功能权限项决定：**有该项权限就看该项下的全部数据，没有就完全看不到该入口** |
| 不存在的过滤 | 「只看与本机构相关的项目」「只看本人负责的申请」「按机构切分的数据域」——本期**均不存在**，也不预留机构字段（`D-AL-06`） |

| 后续分家的边界说明 | 若 SPV 与运营机构将来分为两家主体，需要的是一次「多机构 / 租户」立项（账号归属、数据域、可见范围三者一起定义），**不是在本模块里加一个机构字段**。本期不做任何相关设计 |

## 12. 业务状态与转换说明

> 图示见 [`v1.0-运营端账户与登录-流程图与状态机.md`](v1.0-运营端账户与登录-流程图与状态机.md) `SM-AL-01`～`SM-AL-03`。本节是规则正文，图册不另造口径。

### 12.1 运营账号状态（`SM-AL-01`）

| 编号 | 状态 | 含义 | 该状态下的行为 |
| --- | --- | --- | --- |
| `ST-AL-1` | **待开通** | 账号已创建，本人尚未设置自己的密码 | 邀请方式：只能通过有效邀请进入设密页；初始密码方式：可登录，但登录后**强制进入改密页**，其他功能一律不可用 |
| `ST-AL-2` | **正常** | 已完成开通 | 按已开通的功能权限正常使用运营端 |
| `ST-AL-3` | **锁定** | 连续密码校验失败达阈值 | **不可登录、不可走忘记密码**，无提前解除通道；到期自动解除，回到锁定前的状态 |
| `ST-AL-4` | **停用** | 被运营管理员停用 | 不可登录；已有会话立即失效；启用后回到停用前的状态 |

**转换规则**

| 从 → 到 | 触发 | 附带结果 |
| --- | --- | --- |
| 待开通 → 正常 | 完成邀请设密，或完成首登强制改密 | 相关邀请或初始密码立即作废；首登改密还会使全部会话失效并触发密码变更通知 |
| 正常 / 待开通 → 锁定 | 连续密码校验失败达 `N-AL-01` | 登录与找回全通道不可用；**不发任何通知**（`D-AL-27`） |
| 锁定 → 锁定前状态 | 本次锁定到期 | 自动解除，登录页表单自动恢复可用、无需刷新 |
| 任意状态 → 停用 | 运营管理员停用 | 全部会话立即失效；最后一个正常状态的运营管理员除外（`D-AL-12`） |
| 停用 → 停用前状态 | 运营管理员启用 | 若停用前为待开通，仍需完成开通 |
| 正常 → 待开通 | 运营管理员**重新发起开通**（`PM-AL-03`） | 原密码立即失效，全部会话失效；本人须重新完成开通 |

### 12.2 登录会话（`SM-AL-02`）

| 项 | 口径 |
| --- | --- |
| 建立 | 登录成功时建立；待开通账号首登时建立的是**受限会话**，只能完成改密、退出登录与切换语言 |
| 有效期与无操作登出 | `N-AL-09`；**不提供「记住我」**；到期前给出续期确认，可选择继续保持登录或立即退出 |
| **「用户操作」的判定** | 只有真实的用户交互（点击、键盘输入、表单提交、页面跳转）才重置无操作计时；**后台轮询、心跳、预取一律不计**，否则无操作登出永远不会触发 |
| 全局失效触发 | 退出登录、本人修改密码、重置密码、完成首登改密、账号被停用、被重新发起开通 |
| 失效范围 | 该账号的**全部会话，含当前设备**；未使用的验证码与人机校验凭据一并失效 |
| 失效后的表现 | 清除本地登录态（**语言偏好保留**）、中止进行中的请求、Toast 告知原因、回到登录页并记住原目标；同一浏览器多标签页一并失效 |
| 后台请求遇到失效 | 与前台请求一视同仁触发统一的失效处理，**不得静默忽略**，避免「页面还在、登录态已无」的假活状态 |

### 12.3 开通凭据（`SM-AL-03`）

开通邀请与找回验证码共用一条业务轴：

| 状态 | 含义 | 转换 |
| --- | --- | --- |
| 已签发 | 已发往工作邮箱且仍在有效期内 | → 已使用 / 已过期 / 已作废 |
| 已使用 | 本次开通或重置已完成 | 终态，不可重复使用 |
| 已过期 | 超过有效期（`N-AL-06` / `N-AL-03`） | 终态，需重新发起 |
| 已作废 | 运营管理员重发邀请、重新发起开通，或本人完成了密码变更 | 终态；**同一账号同时只有最新一份凭据有效** |

| `E-AL-02` | 登录 | 连续失败达阈值 | 账号锁定，登录与找回全通道不可用；登录页内展示剩余时间并实时倒计时 | 等待锁定到期 |

| `E-AL-04` | 登录 | 账号待开通（邀请方式，尚未设密） | 提示该账号尚未完成开通、请通过开通邀请完成设置 | 打开邀请或请求重发 |
| `E-AL-05` | 登录 | 初始密码已过期 | 不建立登录态，提示联系运营管理员重新发起开通 | 联系运营管理员 |
| `E-AL-06` | 开通 | 邀请无效 / 已使用 / 已过期 | 展示失效说明，**不透露该邮箱是否为有效账号之外的任何信息** | 请求重发邀请 |
| `E-AL-07` | 首登改密 | 未完成改密时访问其他功能 | 界面重定向回改密页；**绕过界面直接发起业务动作被拒绝** | 完成改密 |
| `E-AL-08` | 设置密码 | 新密码与原密码 / 初始密码相同 | 服务端拒绝并给出对应提示 | 换一个新密码 |
| `E-AL-09` | 发送验证码 | 人机校验失败 | 复位重试，不发码；连续失败达 `N-AL-07` 进入冷却 | 重试或稍后再试 |
| `E-AL-10` | 发送验证码 | 限频超限 | 不发码，提示稍后再试或剩余等待时间；**提示不因该邮箱是否存在而变化** | 等待 |
| `E-AL-11` | 发送验证码 | 邮件发送失败 | 允许立即重试一次且不计入限频额度 | 重试 |
| `E-AL-12` | 忘记密码 | 验证码错误 / 过期 / 超出单码错误上限 | 提示验证码无效，**不透露账号是否存在** | 重新输入或重发 |
| `E-AL-13` | 忘记密码 | 验证码正确但账号处于锁定 | 告知账号锁定与本次剩余时间，**流程终止** | 等待锁定到期 |
| `E-AL-14` | 账号与权限管理 | 停用 / 降级 / 收回权限的对象是最后一个正常状态的运营管理员 | **拒绝并给出明确原因**，不做任何变更 | 先设置另一位运营管理员 |
| `E-AL-15` | 任意受保护动作 | 无该功能权限 | 入口不出现；绕过界面发起时返回统一的无权限提示，**不透露该功能下是否存在具体业务记录** | 联系运营管理员申请授权 |
| `E-AL-16` | 任意受保护动作 | 会话过期 / 被全局失效 / 无操作登出 | 清本地态、Toast 告知原因、回到登录页并记住原目标 | 重新登录 |
| `E-AL-17` | 弱网 | 请求超时 | 按钮恢复可点、已填内容不丢失；倒计时以服务端返回的剩余时间为准 | 重试 |

### 13.2 术语表

| 术语 | 口径 |
| --- | --- |
| 运营端 | **运营管理平台的运营端**，借贷平台的管理端部署单元 |
| 运营账号 | 运营端的登录账号，一个自然人一个账号 |
| 运营管理员 / 运营专员 | 本模块的两个预置角色（`RO-AL-1` / `RO-AL-2`） |
| 功能权限项 | 可被单独授权与收回的运营动作单位（`PM-AL-*`） |
| SPV 机构 | 与运营机构**同一家主体**（`D-AL-03`）。**不是账号类型、不是数据域**，界面上不作为账号类别出现 |
| 开通 | 账号从待开通转为正常的过程：邀请设密或首登强制改密 |
| 开通邀请 | 发往工作邮箱、用于本人设置密码的一次性凭据 |
| 全局失效 | 使某账号的全部会话（含当前设备）立即失效 |

### 13.3 本模块不定义的内容（复述）

- 各业务动作的审核规则、结果口径与状态流转 —— 归 WS-358 / WS-359 / WS-360 / WS-361。
- 站内消息的页面、未读语义与可见范围 —— 归 WS-360。
- 语言、时区、数字、金额、链上地址与哈希、脱敏口径的正文 —— 归三平台共享国际化基线（`Q-AL-01`）。
- 运营端业务菜单项与业务页面 —— 各业务模块自行登记。
