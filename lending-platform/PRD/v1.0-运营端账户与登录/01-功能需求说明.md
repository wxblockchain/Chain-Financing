## 9. 页面与功能详情

### 9.1 页面与组件清单

**运营端页面共 6 个**：

| 编号 | 页面 | 形态 | 说明 |
| --- | --- | --- | --- |
| `P-O-AL-01` | 运营端登录页 | 整页 | 工作邮箱 + 密码。**无注册入口、无协议勾选、无「记住我」、无验证码登录、无钱包登录**。提供「忘记密码」入口。账号锁定时在本页内以状态态展示锁定提示与倒计时 |
| `P-O-AL-03` | 首次登录 · 强制改密页 | 整页 | 所有交付账号必经的首登页。未完成改密不得访问其他任何页面；只保留「退出登录」与语言切换两个出口 |
| `P-O-AL-04` | 忘记密码 · 提交工作邮箱 | 整页 | 输入工作邮箱 → 滑块人机校验（`C-O-AL-01`）→ 发送验证码 |
| `P-O-AL-05` | 忘记密码 · 设置新密码 | 整页 | 验证码校验通过后设置新密码，带密码规则实时校验清单 |
| `P-O-AL-06` | 账户设置 | 整页 + tab 锚点 | 单页上下分区：上方账号信息、下方偏好信息，不展示权限清单；修改密码与修改邮箱在本页内以弹窗完成；通过右上角账号下拉进入 |
| `P-O-AL-07` | 运营端总览页 | 整页 | **本模块只出壳子**，作为登录成功后的落地目标；页面内容归后续业务模块。壳子内给出简短说明文字而非完全空白 |

**运营端组件**

| 编号 | 组件 | 用法 |
| --- | --- | --- |
| `C-O-AL-01` | 滑块拼图验证弹窗 | 两个发码入口每次获取/重发前共用，交互、失败与冷却见 §9.1.1 |
| `C-O-AL-02` | 语言切换器（下拉形态） | 未登录在登录页右上角，已登录在顶部导航栏右侧 |
| `C-O-AL-03` | 顶部面包屑 | 顶部导航栏下方；最多三级，除当前页外各级可点击 |
| `C-O-AL-04` | 右上角账号下拉 | 展示工作邮箱与账号状态；提供「消息中心」（**条目由 WS-360 挂载**）、「账户设置」、「退出登录」三项，消息中心排在账户设置之上 |
| `C-O-AL-05` | Toast 轻提示 | 顶部居中，全站唯一轻提示载体 |
| `C-O-AL-06` | 密码规则实时校验清单 | 设置密码类页面与弹窗内使用，只展示规则是否满足，**不展示强弱分档** |
| （挂载位） | 通知铃铛 | 位于语言切换器左侧、账号下拉之前。**本模块只提供挂载位置，形态与行为归 WS-360** |

**已登录态的功能入口**

- 各管理模块共用菜单信息与权限语义，跨模块切换不得各自定义同名入口；当前已实现共享参考为 `lending-platform/页面原型/_shared/admin-menu.js`（`cd56360`），实际接入由设计与实现维护。
- 用户已明确删除侧栏账户展示；账户设置、消息与退出保留可达入口。菜单外观、排列与组件形式由 Hallmark 决定，不在本册提供线框布局。
- `P-O-AL-07` 仍作为已确认登录默认落地壳子；是否在共享菜单中独立展示不由本册预定，各业务内容归来源模块。
- 按 `F-AL-17` 收敛权限：无权动作不可达；仅有协议记录查看权者仍能进入记录，不要求额外授予内容查询。

### 9.1.1 获取邮箱验证码的滑块前置（`F-AL-13`、`D-AL-22`）

**用户已确认必须先过滑块。**直接依据资产可信平台 [《安全与风控》§12.3](https://github.com/wxblockchain/Chain-Financing/blob/ea56882a2d5c3680ed7220b9e1feb2a0d8fcb652/asset-platform/prd/v1.0-账户与登录/04-安全与风控.md) 与 [《验收标准》§18.11](https://github.com/wxblockchain/Chain-Financing/blob/ea56882a2d5c3680ed7220b9e1feb2a0d8fcb652/asset-platform/prd/v1.0-账户与登录/06-验收标准.md)，版本见主册。共用流程图：[FL-AL-08](v1.0-运营端账户与登录-流程图与状态机.md#fl-al-08)。

| 适用入口 | 发送目标 | 与业务流程的衔接 |
| --- | --- | --- |
| `P-O-AL-04` 忘记密码，含重发 | 当前工作邮箱 | 不新增验证码登录方式；验证码通过后才判定账号锁定 |
| `P-O-AL-06` 本人修改邮箱弹窗，含重发 | 此次填写的新邮箱 | 保留当前密码再认证和新邮箱校验；不要求旧邮箱验证码 |

| 环节 / 状态 | 产品行为与可验收结果 |
| --- | --- |
| 发起 | 验证码行保持**左侧输入框、右侧获取按钮**，初始即可见；邮箱格式等前置校验通过后，点击可用的获取/重发按钮打开滑块弹窗，**尚不发码** |
| 验证中 | 展示带缺口的拼图与滑轨；用户拖动拼图对齐缺口，**松手后验证**；等待结果期间不能重复提交，不能凭拖动距离直接判定通过 |
| 通过 | 滑轨变绿并显示“验证通过 / Verified”，弹窗自动关闭；随后检查发送限频，仅通过后才发码。滑块通过不等于邮件已发送 |
| 单次失败 | 滑轨变红、滑块抖动、拼图复位并自动换新图，提示“验证失败，请重试”；弹窗不关闭、不发码，可重新拖动 |
| 连续失败 | 连续 3 次失败提示点击右上角刷新换图；连续 5 次失败进入 60 秒冷却（`N-AL-07`），滑块禁用并显示剩余时间；冷却中不能通过重新打开弹窗、刷新页面绕过限制，到期才可重新验证 |
| 关闭 / 取消 | 不发码，返回原页面或邮箱修改弹窗；获取按钮恢复原状态，已填邮箱和表单内容保留。再次获取仍须重新过滑块 |
| 图片加载失败 | 弹窗内提示“加载失败，点击重试”，不发码、不展示验证通过，保留原表单；资源恢复后重新验证 |
| 结果适用范围 | 一次通过仅用于**随后一次**相同目标邮箱、相同发码用途及相同请求来源的发送，2 分钟内有效（`N-AL-13`）；已使用、过期或换邮箱/用途/来源均不能沿用。绕过界面发起发码也必须满足同样条件 |
| 获取、重发与发送失败重试 | **每次都重新通过滑块**。邮件发送失败仍允许立即重试 1 次且不计发送额度，但该重试不免除滑块验证 |
| 发送限频 | 沿用 `N-AL-08` 的邮箱、网络 IP、设备额度；不同用途共享同一邮箱额度，不能通过换入口绕过。参考规则中设备识别不可用时不阻断发送，邮箱与网络限制仍适用 |
| 限频与发送结果 | 间隔未满时获取按钮显示剩余秒数并不可点击；小时/日超限给出可读等待时长，网络/设备超限提示稍后重试，均不发码。发送成功后进入重发倒计时；刷新页面不能重置等待时间；提示不因邮箱是否已有账号变化 |
| 可访问性 | 支持 Tab 聚焦、方向键位移、Enter 提交；提供刷新与求助入口。无障碍替代方案仍按本期已知限制处理 |

滑块验证未通过不能触发邮箱发码；滑块失败冷却与密码错误导致的账号锁定是两种状态，不将滑块失败计入密码失败次数。相关参数直接引用资产平台 §12.3 和 §19.2（见 §11.4），本轮不改变既有账号锁定、防枚举或邮箱变更后的会话规则。

既定约束简要引用：参考基线 `D-27` 的自研滑块及 §12.3.3 的校验约束继续适用；本册仅定义用户行为和安全结果，不展开坐标、轨迹算法、票据字段或接口实现。

### 9.2 `P-O-AL-01` 登录页（`F-AL-04`）

流程图：[FL-AL-03](v1.0-运营端账户与登录-流程图与状态机.md#fl-al-03)。

| 项 | 口径 |
| --- | --- |
| 入口 | 运营端任意受保护功能在未登录时均引导到本页，并记住原本要去的目标 |
| 页面元素 | 工作邮箱、密码（以眼睛/划线眼睛图标切换显示，保留无障碍名称）、登录按钮、「忘记密码」入口、语言切换器 |
| 明确不提供 | 注册入口、协议勾选、「记住我」、验证码登录、钱包登录、第三方登录 |
| 校验失败 | **邮箱不存在与密码错误返回完全一致的提示与页面表现**，不可从提示文案或响应快慢区分（`D-AL-17`） |
| 失败计数 | 密码错误计入失败计数；达到提示阈值（`N-AL-05`）后开始提示剩余次数；第一档锁定的提示中告知「若再次触发，锁定时间会更长」 |
| 账号状态分支 | **待首登改密** → 凭据验证通过后强制进入 `P-O-AL-03`；**正常** → 进入落地页；**锁定** → 仅在凭据校验通过后显示锁定提示与倒计时，到期表单自动恢复、无需刷新 |
| 初始密码已过期 | 凭据验证通过后提示联系平台建设方/运维在数据层重新初始化，**不建立登录态**；本期无产品内恢复入口 |
| 落地（`F-AL-06`） | 有原目标且属于本运营端范围 → 回到原目标；否则 → `P-O-AL-07` 总览页。**原目标不属于本运营端范围时一律丢弃，落到总览页** |
| 首次登录成功 | 按浏览器推断并写入时区偏好，推断失败兜底 UTC（`F-AL-11`） |

### 9.4 `P-O-AL-03` 首次登录 · 强制改密页（`F-AL-03`）

流程图：[FL-AL-02](v1.0-运营端账户与登录-流程图与状态机.md#fl-al-02)。

| 项 | 口径 |
| --- | --- |
| 触发 | 全部交付账号首次登录验证成功后**立即**进入本页 |
| 拦截范围 | 未完成改密前，**除本页、退出登录与语言切换外，运营端任何页面与任何业务动作都不可用**；绕过界面直接发起业务动作同样被拒绝，不依赖界面拦截作为唯一防线 |
| 页面元素 | **新密码、确认新密码**（不再次输入当前密码，使用本次首登已验证身份）、密码规则实时校验清单；**无任何勾选项**；无左侧菜单、无面包屑 |
| 密码校验 | 见 11.3；**新密码不得与初始密码相同**，提交后给出对应校验结果 |
| 完成后 | 账号转为**正常 `ST-AL-2`**，初始密码失效 → 触发密码变更通知 → **全部会话失效** → 回到登录页重新登录 |

### 9.5 `P-O-AL-04` / `P-O-AL-05` 忘记密码（`F-AL-05`）

流程图：[FL-AL-04](v1.0-运营端账户与登录-流程图与状态机.md#fl-al-04)。

**第一步 `P-O-AL-04` 提交工作邮箱**

| 项 | 口径 |
| --- | --- |
| 入口 | 登录页「忘记密码」 |
| 顺序 | 输入工作邮箱 → 点击验证码行右侧获取/重发按钮 → **滑块拼图验证（`C-O-AL-01`）** → **发送限频校验** → 发送验证码。每次均按 §9.1.1 执行，不得复用上次验证通过状态 |
| 提示文案 | 中性表述：「若该邮箱为运营端账号，验证码已发送」。**已注册与未注册邮箱得到完全一致的响应**，含页面表现与响应快慢 |
| 滑块人机校验失败 | 按 §9.1.1 变红、抖动、复位换图，保留弹窗；连续失败达 `N-AL-07` 进入冷却；**不发码** |
| 限频超限 | 不发码，提示稍后再试或给出剩余等待时间；提示内容不因该邮箱是否存在而变化 |
| 发信失败 | 允许立即重试一次且不计入限频额度；该重试仍须重新通过滑块（§9.1.1） |

**第二步 `P-O-AL-05` 设置新密码**

| 项 | 口径 |
| --- | --- |
| 前置 | 验证码校验通过 |
| **锁定判定时点** | **必须在验证码校验通过之后**，不得提前到输入邮箱或发码阶段——提前会重新打开账号枚举通道。锁定中则提示账号锁定与本次剩余时间，**流程终止** |
| 页面元素 | 新密码、确认新密码、密码规则实时校验清单 |
| 密码校验 | 见 11.3，含「不得与原密码相同」「不得与初始密码相同」双重比对 |
| 成功后 | 新密码生效，触发密码变更通知，**全部会话失效**，回到登录页。**默认衔接口径**：尚未完成首登改密的账号找回后仍为待首登改密，下一次登录继续进入 `P-O-AL-03`；找回不跳过强制首登环节。已过期的初始密码按人工重新初始化处理 |
| 无法自助的兜底 | 当前工作邮箱不可达且无法登录时，没有替代自助找回渠道，只能联系**平台建设方/运维在数据层重新初始化**（`R-AL-02`）；所有运营角色相同，本期不存在由运营管理员操作的恢复入口 |

### 9.6 `P-O-AL-06` 账户设置（`F-AL-07`、`F-AL-08`、`F-AL-19`）

流程图：[FL-AL-06](v1.0-运营端账户与登录-流程图与状态机.md#fl-al-06)。

- **进入方式**：右上角账号下拉（`C-O-AL-04`）→「账户设置」。
- **形态**：单页 + tab 锚点滚动，上方账号信息、下方偏好信息；修改密码与修改邮箱在本页内以弹窗完成。

| 区块 | 条目 | 操作 |
| --- | --- | --- |
| 账号信息 | 工作邮箱 | 展示当前邮箱并提供「修改」入口（`D-AL-25`、`F-AL-19`），详见 9.6.1 |
| 账号信息 | 姓名 | 只读 |
| 账号信息 | 角色 | 只读（由建设方交付配置） |
| 账号信息 | 账号状态 | 只读 |
| 账号信息 | 登录密码 | 「修改」→ 弹窗内先**再认证当前密码**，再设置新密码 |
| 偏好信息 | 界面语言 | 下拉选择，即时生效并持久化（规则见共享国际化基线） |
| 偏好信息 | 时区 | 下拉选择；界面所有时间点按该偏好展示并带时区标注 |

> **修改密码生效后触发密码变更通知，随后全部会话失效**（含当前设备），回到登录页重新登录。
> **再认证时当前密码输错计入登录失败计数**，与登录共用同一计数器。

### 9.6.1 本人修改工作邮箱（`F-AL-19`）

**允许本人修改、获取验证码前必须通过滑块均为用户已确认需求。除该滑块前置外，当前密码再认证、新邮箱验证及后续衔接沿用已有默认口径，可由用户调整。**流程见图册 [FL-AL-07](v1.0-运营端账户与登录-流程图与状态机.md#fl-al-07)。

| 项 | 产品行为 |
| --- | --- |
| 角色与前置 | 两个运营角色均可在本人账户设置中修改；账号须正常且已完成首登改密，仅能修改本人的邮箱 |
| 入口与顺序 | 工作邮箱旁「修改」→ 弹窗内验证当前密码 → 填写新邮箱 → 点击验证码行右侧获取/重发按钮 → 滑块拼图校验（每次均按 §9.1.1）→ 发送限频校验 → 向**新邮箱**发验证码 → 输入验证码并提交 |
| 再认证 | 当前密码输错计入既有登录失败计数，达到阈值按既有阶梯锁定；再认证有效期沿用 `N-AL-10`，过期需重新验证，不能继续提交邮箱修改 |
| 新邮箱 | 邮箱格式、长度、去空格、大小写不敏感沿用 11.1；不得与当前邮箱相同，须在本运营端内唯一。格式错误、相同或不可用时给出对应提示；不可用提示不暴露占用账号身份或状态 |
| 新邮箱验证 | 验证码只发往此次新邮箱，**不要求旧邮箱收码**。验证码规则、有效期、错误次数、滑块人机校验与限频均沿用既有参数；与找回密码的验证码不可混用。更换新邮箱后，原目标的验证码不可用于新目标 |
| 生效条件 | 当前再认证仍有效、验证码属于本人本次新邮箱修改且校验通过、账号仍正常、新邮箱在提交时仍唯一，全部满足才生效；期间被其他账号占用则拒绝变更并提示该邮箱不可用 |
| 成功结果 | 显示成功提示，账户设置及账号下拉更新为新邮箱；之后仅新邮箱可用于本账号登录、找回与接收安全通知，旧邮箱不再是本账号登录或找回地址。账号身份、姓名、角色、权限及偏好保持原值 |
| 当前登录与旧验证码 | 默认保留现有登录状态，不因仅修改邮箱额外退出；发往旧邮箱但尚未使用的找回验证码失效，后续找回只认新邮箱；旧邮箱提交找回仍返回统一中性提示 |
| 安全通知 | **生效后向新旧邮箱各发一封安全通知**，告知邮箱已修改、发生时间及非本人操作时的求助方式；不含密码或验证码。某一地址投递失败不回滚已生效的修改 |
| 未成功 | 验证码错误/过期/超过错误上限，账号锁定、再认证失效、发送失败、取消或未完成流程时，邮箱保持原值；不得提示修改成功。可按对应错误重试或等待，重新发码仍受既有限频约束 |
| 会话失效 | 操作期间登录失效时返回登录页，未生效的修改不保留为已完成；重新登录后重新发起修改 |
| 已知限制 | 旧邮箱不可达但仍能正常登录、完成当前密码验证时可自助换邮箱；密码丢失且当前邮箱不可达时，只能由建设方/运维重新初始化，无产品内他人改密或改邮箱入口 |

### 9.7 `P-O-AL-07` 总览页（壳子）

登录成功后的默认落地页。本模块只提供落地壳子与必要说明，**不预先编造业务卡片、统计数字或待办列表**；内容由后续业务模块补入，菜单承载遵循共享导航。

## 10. 功能权限矩阵

### 10.1 组织方式（`D-AL-07`）

- 权限的基本单位是**功能权限项 `PM-AL-*`**；由建设方配置可配置项，固定开通或角色专属项不得按一般可选权限收回或扩给其他角色。
- **角色包含默认集合及固定边界**（`D-AL-09`）；实际能力由可配置项、固定开通及角色专属约束共同决定，建设方不能用个别配置突破角色专属边界；本期无授权配置界面。
- **矩阵里没有机构维度**：不存在「本机构的」「其他机构的」这类过滤条件，也没有机构字段参与判定（`D-AL-05`）。SPV 职责通过权限项表达（`D-AL-13`）。
- **权限项的业务规则定义权不在本模块**：本模块定义「这是何种权限项、谁可有或固定有、获准后能访问哪些对象」；**动作本身怎么算通过、怎么算驳回，由对应业务模块定义**。

| 最近登录时间 | 最近一次登录成功的时间 | 时间 | 否 | 只读 | 存 UTC，按本人时区展示并带时区标注 |
| 创建时间 | 账号被创建的时间 | 时间 | 是 | 只读 | 同上 |

> **本期不设的字段**：部门、岗位、所属机构、机构编号（`D-AL-24`、`D-AL-06`）。前两者本期没有消费方，后两者属于被本轮口径明确排除的机构维度。

### 11.3 密码规则（`D-AL-23`）

适用于全部设置密码的入口：首登强制改密、忘记密码重置、账户设置内修改密码，建设方交付的初始密码也须满足长度、复杂度和空格规则。

| 项 | 规则 |
| --- | --- |
| 长度 | 8～20 字符 |
| 复杂度 | 至少 1 个英文字母 + 1 个数字 |
| 空格 | 前后空格自动去除；**中间不接受空格** |
| 与原密码 | **不得与原密码相同** |
| 与初始密码 | **不得与平台发放的初始密码相同** |
| 密码显隐 | 全部密码框使用眼睛/划线眼睛图标，不用文字按钮；保留无障碍名称与键盘操作 |
| 校验呈现 | 输入过程中展示规则实时校验清单（`C-O-AL-06`），全部满足方可提交；**不展示强弱分档** |
| 判定归属 | 提交时校验与原密码、初始密码不同，不符合则拒绝变更并给出对应提示 |
| 明文 | 除本人在密码输入框主动切换显示外，界面、日志、邮件和站内消息均不得泄露明文密码；初始账密由建设方按线下交付约定提供 |

## 12. 业务状态与转换说明

> 图示见 [`v1.0-运营端账户与登录-流程图与状态机.md`](v1.0-运营端账户与登录-流程图与状态机.md) `SM-AL-01`～`SM-AL-03`。本节是规则正文，图册不另造口径。

### 12.1 运营账号状态（`SM-AL-01`）

状态图：[SM-AL-01](v1.0-运营端账户与登录-流程图与状态机.md#sm-al-01)。

| 编号 | 状态 | 含义与行为 |
| --- | --- | --- |
| `ST-AL-1` | **待首登改密** | 建设方已交付初始账密，本人尚未完成首次登录强制改密。登录验证通过后仅可改密、退出与切换语言，不可执行业务动作 |
| `ST-AL-2` | **正常** | 已完成首登改密，按交付配置的权限使用业务功能 |
| `ST-AL-3` | **锁定** | 连续密码校验失败达到阈值，不可登录或完成找回，无提前解锁通道；到期回到锁定前状态 |

| 从 → 到 | 触发 | 附带结果 |
| --- | --- | --- |
| 待首登改密 → 正常 | 完成 `P-O-AL-03` 强制改密 | 初始密码失效、触发密码通知、全部会话失效并要求重新登录 |
| 正常 / 待首登改密 → 锁定 | 连续密码失败达 `N-AL-01`（含账户设置再认证失败） | 登录与找回不可完成，已有登录不得执行业务动作；不发通知 |
| 锁定 → 锁定前状态 | 锁定到期自动解除 | 登录页表单自动恢复可用，无需刷新 |

忘记密码不会让待首登改密账号直接转正常（默认衔接口径，见 9.5）。本期没有产品内新增账号、停用/启用、他人改密或重新开通的状态转换。人工重新初始化属建设方/运维的线下兜底，重新交付后仍以待首登改密进入上述流程，不提供产品操作设计，也不得用于提前解除既有锁定。

### 12.2 登录会话（`SM-AL-02`）

状态图：[SM-AL-02](v1.0-运营端账户与登录-流程图与状态机.md#sm-al-02)。

| 项 | 口径 |
| --- | --- |
| 建立 | 登录成功时建立；待首登改密账号首登时建立的是**受限会话**，只能完成改密、退出登录与切换语言 |
| 有效期与无操作登出 | `N-AL-09`；**不提供「记住我」**；到期前给出续期确认，可选择继续保持登录或立即退出 |
| **「用户操作」的判定** | 只有真实的用户交互（点击、键盘输入、表单提交、页面跳转）才重置无操作计时；**后台轮询、心跳、预取一律不计**，否则无操作登出永远不会触发 |
| 全局失效触发 | 退出登录、本人修改密码、重置密码、完成首登改密 |
| 失效范围 | 该账号的**全部会话，含当前设备**；未使用的验证码与滑块人机校验凭据一并失效 |
| 失效后的表现 | 停止受保护操作（**语言偏好保留**）、Toast 告知原因、回到登录页并记住原目标；同一浏览器多标签页一并失效 |
| 后台请求遇到失效 | 与前台请求一视同仁触发统一的失效处理，**不得静默忽略**，避免「页面还在、登录态已无」的假活状态 |

### 12.3 验证码（`SM-AL-03`）

状态图：[SM-AL-03](v1.0-运营端账户与登录-流程图与状态机.md#sm-al-03)。

仅适用于找回密码与修改邮箱验证码，不含邀请凭据。

| 状态 | 含义 | 转换 |
| --- | --- | --- |
| 已签发 | 发往对应目标邮箱且仍有效 | → 已使用 / 已过期 / 已作废 |
| 已使用 | 此次验证与对应操作已完成 | 终态，不可重复使用 |
| 已过期 | 超过 `N-AL-03` | 终态，按原入口重新发码 |
| 已作废 | 同用途重新发码、超过错误上限、完成密码变更；或邮箱修改生效使旧邮箱找回验证码失效 | 终态，不再可用 |

同一账号同一用途仅最新验证码有效，不能跨用途或目标邮箱使用；换新邮箱后旧目标的码不能用于新目标。密码变更导致会话全局失效时，未使用验证码与滑块人机校验结果一并失效。

## 13. 边界、异常与术语

### 13.1 异常与边界总表

| 编号 | 环节 | 异常 | 系统行为 | 用户可做什么 |
| --- | --- | --- | --- | --- |
| `E-AL-01` | 登录 | 邮箱不存在 / 密码错误 | **两者返回完全一致的提示与页面表现** | 走忘记密码；无法自助时联系建设方/运维 |
| `E-AL-02` | 登录 | 连续失败达阈值 | 账号锁定，登录与找回全通道不可用；登录页内展示剩余时间并实时倒计时 | 等待锁定到期 |
| `E-AL-05` | 登录 | 初始密码过期 | 凭据通过后说明过期，不建立登录态 | 联系建设方/运维在数据层重新初始化，本期无产品自救入口 |
| `E-AL-07` | 首登改密 | 未完成改密时访问其他功能 | 界面重定向回改密页；**绕过界面直接发起业务动作被拒绝** | 完成改密 |
| `E-AL-08` | 设置密码 | 新密码与原密码 / 初始密码相同 | 服务端拒绝并给出对应提示 | 换一个新密码 |
| `E-AL-09` | 获取/重发验证码 | 滑块失败、取消、加载失败或冷却中 | 均不发码；分别按 §9.1.1 换图复位、返回原表单、加载重试或禁用倒计时处理 | 在原入口重试或等待，不绕过滑块 |
| `E-AL-10` | 发送验证码 | 限频超限 | 不发码，提示稍后再试或剩余等待时间；**提示不因该邮箱是否存在而变化** | 等待 |
| `E-AL-11` | 发送验证码 | 邮件发送失败 | 可立即重试一次且不计入发送额度；重试仍重新验证滑块 | 通过滑块后重试 |
| `E-AL-12` | 忘记密码 | 验证码错误 / 过期 / 超出单码错误上限 | 提示验证码无效，**不透露账号是否存在** | 重新输入或重发 |
| `E-AL-13` | 忘记密码 | 验证码正确但账号处于锁定 | 告知账号锁定与本次剩余时间，**流程终止** | 等待锁定到期 |
| `E-AL-15` | 任意受保护动作 | 无该功能权限 | 入口不出现；绕过界面发起时返回统一的无权限提示，**不透露该功能下是否存在具体业务记录** | 联系建设方核对交付配置 |
| `E-AL-16` | 任意受保护动作 | 会话过期 / 被全局失效 / 无操作登出 | 清本地态、Toast 告知原因、回到登录页并记住原目标 | 重新登录 |
| `E-AL-17` | 弱网 | 请求超时 | 按钮恢复可点、已填内容不丢失；倒计时以服务端返回的剩余时间为准 | 重试 |
| `E-AL-18` | 修改邮箱 | 再认证失败/过期、验证码无效、新邮箱不可用、操作取消 | 不改变当前工作邮箱，给出对应提示；密码错误仍计入既有锁定规则 | 重新验证、填写其他邮箱或按限频重试（见 9.6.1） |
| `E-AL-19` | 邮箱修改后通知 | 新或旧地址安全邮件投递失败 | 不回滚已生效邮箱、不误报验证失败；与验证邮件未完成验证不得生效相区分 | 已生效的新邮箱继续作为登录与找回地址 |
