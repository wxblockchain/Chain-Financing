# 资产广场与已上架代币只读域 · PRD

资产广场让游客、资产方和资金方查看全平台已同步代币，理解其底层业务、当前链上持有地址及质押去向，并自行查看链上凭证。本模块只有公开列表和独立详情页，全部只读。

**阅读顺序**：先按本文“进入广场 → 查找代币 → 查看详情 → 查看持有地址 → 数据更新”讲解；测试按文末同序验收。配套阅读[流程图与状态机](02-资产广场-流程图与状态机.md)及[消息通知](03-资产广场-消息通知.md)。开发主读第 1～6 章功能与规则，测试主读第 8 章同序验收；第 7 章列出真实依赖。Hallmark 同读三册，按已批准的共享规范承接关键状态。

## 1. 范围与共同边界
<a id="scope"></a>

本期展示代币发行平台同步且满足展示条件的全部代币，包含失效及未质押代币；同步到位即进入展示，无本平台上架、下架、隐藏、置顶、推荐或精选操作。不按登录主体过滤数据。既定约束：代币由独立发行平台通过 API 同步，沿用 WS-350 用户已确认的跨平台边界；本模块不展开接入实现。

资产广场是“全平台”，我的控制台是“我的”，两处同名字段使用同一权威口径，各自可见范围不混用。

本模块落实共同决策中的 P01 资料边界、P02 唯一链上地址及 P10 UTC/金额显示口径；融资端 P05 固定折算不回算签发价值，其他办理、审核和协议决策仍归所属模块。

业务主线是查看列表、筛选检索、打开代币详情，再按需要查看公开融资项目或区块浏览器。没有申请、认购、下单、收藏、订阅、评论、导出、下载、铸造或销毁；不提供估值、评级、排行榜或可信度评分，不按链分组展示。服务端能力也只读，对上游零写入。页面浏览、数据变化及异常均不产生本模块通知，具体边界见独立通知册。

<a id="visibility"></a>

<a id="F-AM-10"></a>**F-AM-10 · 公开范围与登录前后一致性**

<a id="D-AM-69"></a>游客、资产方、资金方取得同一公开字段集合、字段值、展示口径及筛选排序能力，不以登录增加记录条数或解锁字段。该一致性须对实际可取得的数据成立，不能只靠界面隐藏。业务数值不区间化，名称不脱敏；地址和哈希采用全册统一的展示口径，均可复制完整值。

| 代币身份、数量价值、状态、当前持有地址及项目关系 | 按本文字段展示；公开地址不用于反查或展示账户身份、个人姓名、联系方式 |

| 合同号、发票号、提单号、附件影像、贸易背景自由文本、备注、应收账款编号 | 列表、详情、搜索、筛选和分享条件均不包含；业务信息可展示不代表所有上游字段均可公开 |

## 2. 进入广场与主动登录
<a id="entry"></a>

<a id="design-boundary"></a>
本册只定义信息需求与业务行为；页面布局、组件形态、层级与视觉由 Hallmark 设计决定。本册措辞与设计稿冲突时以设计稿为准，业务口径仍以本册为准。

<a id="F-AM-01"></a>**F-AM-01 · 入口与公开浏览范围**

资产广场与借贷广场同为面客端一级入口，游客和登录用户可取得的入口相同、可用性一致。游客可直接打开列表或分享的详情，全程不需要跨平台登录态，不自动触发第三方授权。

游客只提供一个登录入口，不并列第二个登录入口；资金方的账户入口名称为“用户信息”，与资金方账户体系一致。用户主动使用登录入口或详情的引导入口时进入既有登录/注册链路，由该模块处理角色、资产方授权、首次引导、权限及返回目标；本模块不另建登录与回跳判断。返回目标后仍按目标当前权限处理，不因登录自动执行融资业务。

<a id="C-F-AM-07"></a>详情提供且仅提供一个登录/注册引导入口，游客和登录态都有，文案可按身份变化。该引导不得遮挡、模糊或截断任何公开信息，也不得暗示登录后可查看更多；列表不提供该引导。资产方授权登录是主动登录链路的一部分，不属于公开浏览的跨站跳转。

### 头部汇总
<a id="totals"></a>

<a id="C-F-AM-01"></a><a id="F-AM-02"></a>**F-AM-02 · 头部汇总**

| 项目 | 业务含义与格式 |
| --- | --- |
| 代币数量 | 当前筛选与搜索匹配全集中，各笔代币数量各加一次，含失效；单位枚、2 位小数 |
| 代币价值 | 同一全集中，各笔签发时 USD 价值各加一次，2 位小数；须与该数值同时给出“按各笔签发时汇率折算”的标注 |

<a id="D-AM-64"></a>一条代币记录可以有多枚，数量不能按记录条数、已加载条数、地址数或项目数计数。当前持有信息不是第二个统计来源；查看地址或历史项目的更多信息不能增加数量、价值。排序、追加、重试、返回与分享恢复不改变匹配全集，筛选或搜索改变时三项一起更新。空集合显示 0，不隐藏汇总，不将缺值当 0。

本期单一合约；出现第二类合约时必须分组或停止混合求和。代币数量、USD 代币价值、原币应收账款金额不可相加。代币价值沿用签发快照，不显示为实时市值、不再次折算；其他融资币种规则不回算本笔签发价值。

### 筛选、加载与恢复
<a id="view"></a>

<a id="C-F-AM-05"></a><a id="F-AM-04"></a>**F-AM-04 · 筛选、排序与搜索**

| 操作 | 正常结果与边界 |
| --- | --- |
| 筛选 | 代币状态、质押状态、代币类型、资产方企业四项；本期类型只有应收账款类仍保留筛选。不提供链筛选 |

<a id="F-AM-05"></a>**F-AM-05 · 连续加载**

追加过程中头部汇总、当前筛选条件和各项信息的名称须保持可得，不因继续加载而丢失。用户不能按页码定位，也不能改变每批条数；追加失败的重试口径见[筛选、排序与搜索](#F-AM-04)。流程见图册[列表视图状态](02-资产广场-流程图与状态机.md#ST-AM-03)。

<a id="F-AM-11"></a>**F-AM-11 · 空态与异常**

首批及详情读取失败均提供可重试反馈；恢复读取失败保留原条件与已有视图，重试后继续恢复，不擅自返回首批。

<a id="C-F-AM-06"></a>无任何代币是全局空态，不提供重置筛选；有数据但本次无匹配是筛选空态，可重置筛选。两者文案可辨且头部显示 0。首批加载失败单独给可重试错误态。

## 4. 查看代币详情
<a id="detail"></a>

<a id="F-AM-06"></a>**F-AM-06 · 独立寻址、分享与视图恢复**

<a id="P-F-AM-02"></a>详情中文名“代币详情”，英文名 Token Details，是可分享、可直达、可被搜索引擎索引的独立页面，建议地址 `/marketplace/assets/{代币编号}`。从列表进入、返回或前进后退均保留对应浏览视图。业务浏览路径见[FL-AM-02](02-资产广场-流程图与状态机.md#FL-AM-02)。编号不存在与格式非法统一显示“内容不存在”，不泄露存在性差别。

<a id="F-AM-07"></a>**F-AM-07 · 代币详情**

详情须完整给出概览、代币信息、原始资料信息、链上存证、代币持有地址五部分信息，并按此顺序讲述，末尾给出登录/注册引导入口；原单列的质押信息不再独立成块，其事实由当前持有信息承载。本模块全程只读，不为不存在的操作预留入口。

### 概览与代币信息
<a id="token-fields"></a>

状态图见[代币状态 ST-AM-01](02-资产广场-流程图与状态机.md#ST-AM-01)及[质押结果 ST-AM-02](02-资产广场-流程图与状态机.md#ST-AM-02)。

概览含代币标识图、名称、完整可复制编号、代币状态与质押状态。两个状态分别带判定依据，失效依据须给出对应应收账款到期日。代币状态与质押状态是独立维度，失效且已质押可同时出现，不合成新状态；状态须有文字表达，不得仅以颜色区分。

以下字段只读、无手填及虚构默认值。代币事实由发行平台负责，本平台不判断铸造或失效、不重估价值。

| 字段 | 含义、类型及校验/展示 |
| --- | --- |
| 代币编号 | 唯一业务编号，16 位文本：TK + UTC 日期 yyyyMMdd + 6 位序号；不是链上 tokenId。列表及详情完整展示、可复制 |
| 代币数量 | 本笔签发数量，数值 ≥ 0.01、2 位小数、枚；沿用签发时 1 USD 对应 1 枚规则 |
| 代币价值 | 本笔签发 USD 快照，非负金额、2 位小数；不是融资额或另行读取的质押价值 |
| 代币类型 | 上游枚举，本期应收账款类 |
| 代币状态 | 上游有效 / 失效；本期无已销毁来源，不新增第三种结果 |
| 合约 | 合约名称与地址；地址为 ETH 格式 `0x` + 40 位十六进制，完整值直接可得并可复制，不缩略 |
| 所属链 | ETH，只读信息，不可由用户选择或修改 |
| 铸造交易哈希 | `0x` + 64 位十六进制；缩略展示时仍可复制完整值，并可进入 ETH 区块浏览器 |
| 铸造时间 | 时间，按 UTC 基准、用户时区展示并标注时区；游客取浏览器时区，无裸时间 |

缺代币编号、数量、价值、代币状态、铸造交易哈希或铸造时间任一项：整条不展示、不计入汇总，也不以占位记录替代，运营应可察觉并推动补齐。合约、链、类型等展示字段也应由上游提供；其他非关键字段缺失逐项“—”，不猜测内容。持有事实缺失另按下一章处理，不剔除主记录。

### 链上存证与自行查验
<a id="evidence"></a>

<a id="C-F-AM-04"></a><a id="F-AM-08"></a>**F-AM-08 · 链上凭证与自行查验**

链上存证独立给出存证哈希（文本，缩略展示时可复制完整值）、链上存证交易哈希（交易哈希格式）、区块高度（整数）、链 ID（文本/整数）、存证时间（时间及明确时区）五项。上游应完整提供五项，不在本模块校验交易真伪或补算，缺项逐项“—”，不因个别缺项隐藏整组存证信息、不报整页错误。

“铸造交易哈希”与“链上存证交易哈希”属于两笔不同交易，须可分辨且始终保留限定词，不得混用同一个值。两者均缩略展示、可复制完整值、链接到 ETH 固定前缀区块浏览器；每个链接都须与“平台未核验该交易，链接仅供自行查验”同时可得，不需要额外操作才出现。不使用暗示平台确认链上交易有效的背书文案。

站内业务跳转在当前窗口继续；只有区块浏览器外链在新窗口打开，浏览者不因外链丢失当前浏览上下文。公开浏览不跳发行平台或资产可信平台页面。复制成败均有反馈，失败不改变浏览位置。

## 5. 查看当前持有地址与项目
<a id="holding"></a>

<a id="F-AM-14"></a>**F-AM-14 · 当前持有地址**

<a id="D-AM-65"></a>每笔代币当前只有一个实际链上持有地址，可能是企业地址，也可能是实际持币的合约地址；它不代表企业归属或账户身份，更不能用铸造时收币快照代替。正常情况下当前持有信息只有一条记录，数量与价值属于本笔整笔代币。

### 五项持有信息
<a id="holder-fields"></a>

### 质押结果与去向
<a id="pledge"></a>

<a id="F-AM-09"></a>**F-AM-09 · 质押结果与项目去向**

<a id="D-AM-68"></a>当前链上持有位置与本平台质押结果独立，按同一代币业务编号核对：

| 本平台当前事实 | 对外质押状态 | 项目及地址 |
| --- | --- | --- |
| 质押生效且链上转移成功 | 已质押 | 当前唯一项目，地址取实际持有事实 |
| 无生效质押，或链上处理中/失败 | 未质押 | 项目“—”；不把过程态公开为新质押状态 |
| 业务已释放但尚未实际转回 | 未质押 | 项目“—”；实际仍在合约则继续展示合约地址，不宣称已到账或已可再次质押 |
| 实际转回完成 | 按当前业务结果 | 更新为唯一新地址，旧地址不再作为第二条当前记录保留，整笔数量价值不增加 |

质押定义以借贷平台为权威：可质押、已质押、已释放收敛为上述二元展示；不消费发行平台旧质押状态，不维护第二套映射。不从地址形态推断质押结果，不把融资需求生命周期或额度冻结状态放到代币上。状态编号不出现在界面、URL 条件或双语文案。

所属项目已公开时使用既有 `project/{id}` 深链，不增加新参数或业务动作。目标已关闭/结清仍进入该项目详情并提示其当前状态，不报内容不存在、不静默跳首页，也不把浏览者带到无法继续的结果。草稿只显示“所属融资项目尚未公开”，无项目名称和链接；不能把项目关系不明当作草稿。无当前质押不显示历史项目。此模块不要求借贷广场或控制台新增反向入口。

## 6. 数据更新与共同体验
<a id="data"></a>

<a id="F-AM-13"></a>**F-AM-13 · 数据同步与每日核对**

页面只读本平台已同步资料和本平台质押结果，打开页面不实时读链、不临时向发行平台或资产可信平台取数。代币身份、数量、签发价值、代币状态、链上凭证及当前持有事实由发行平台供给；原始商务要素与存证事实来自资产可信平台，随代币传递。质押状态和当前项目由本平台质押业务负责，均按代币业务编号核对。

代币同步后自动展示，失效变化当日可见；列表、详情及失效汇总同步反映权威事实。本地日期跨过账期到期日也不自行翻转代币状态。每日至少核对一次代币数量合计、价值合计与逐笔状态，差异以上游最新事实修正；旧更新不能覆盖新事实，重复更新不能改变数量。

上游中断或当日核对未完成时保留最近可用数据，不清空、不呈现同步故障或数据同步时间；运营侧必须能察觉异常并处理，但不由资产广场新增运营通知。页面自身读取失败仍给正常可重试错误态，两类故障不可混淆。同步能力不足不得降级当作可上线。图册见[同步与浏览](02-资产广场-流程图与状态机.md#FL-AM-01)。
