## 结论

**资产方、资金方、运营方均为零发送事件、零模板，无模板待接入。** 资产广场是公开只读查询模块，本期不发送站内信，也不增加邮件、短信或浏览器推送。列表与详情中的提示、加载和复制反馈属于页面反馈，不是消息通知。

本册与[主 PRD](v1.0-资产广场-PRD.md)配套，只定义本模块的发送边界；无发送时点、收件人或跳转模板需要编造。

## 场景与发送归属

| 场景 | 本模块处理及责任 |
| --- | --- |
| 查看、筛选、复制、分享、进入项目或区块浏览器 | 不发送；不增加未读，不改变既有消息的已读状态或排序 |
| 新代币同步、代币失效、数量价值/持有地址/质押关系更新 | 更新可见业务事实，不向持有人、融资参与方或全体用户群发；链上地址不是账户或收件人 |
| 数据缺失、关系冲突、加载重试、同步或核对异常 | 页面按主 PRD 处理；运营需可察觉数据异常，但本模块不新增运营广播、告警消息模板或补资料任务 |
| 登录资格、资金方账户与认证 | 由登录与账户、机构审核等所属模块按其通知规则发送；资产广场的零通知不取消这些事件，也不补发、转发 |
| 融资申请、代币质押与审核、释放等业务结果 | 由融资与质押、质押审核等源业务模块按其已有边界发送；本模块看到同一变化不再发送，也不改变原收件人或文案 |

本人资料与业务展示边界沿用主 PRD：自动取得业务信息不产生手动补填通知，不开放企业成员或联系方式，不因同企业或同钱包扩大发送对象。当前唯一链上地址的业务定义已确认；真实事实供给依赖仍保留，但无论数据是否就绪，本模块均不新增通知。

配套账户规则采用[登录主干当前消息通知](../v2.0-登录与账户体系/08-登录主干与资产方SSO接入-消息通知.md)及[WS-349 更新包](https://8.216.50.84.nip.io/api/attachments/01a0c79a-517f-75d3-8686-54d86d20d434/download)中的独立通知册；质押业务发送归属继续由[融资与质押通知](../v1.0-借贷广场-融资需求与代币质押/03-融资需求与代币质押-消息通知.md)和[质押审核通知](../v1.0-代币质押审核/01-代币质押审核-消息通知.md)各自定义。本册不复制它们的事件或模板。

<a id="5-验收需求"></a>

## 关键验收

| 场景 | 通过标准 |
| --- | --- |
| 游客及登录用户进行浏览、筛选、跳转、复制、重试 | 资产方、资金方、运营方均没有由资产广场产生的新消息；未读数、已有消息顺序及已读状态不因此变化 |
| 新同步、失效、持有地址及质押项目变化 | 列表和详情可更新，无资产广场发送或补发；正常单地址、释放未转回、缺失/冲突分支均适用 |
| 加载失败、供给不完整、同步核对异常 | 页面反馈与运营察觉职责保留，无三方广播、补资料消息或非站内信渠道新增 |
| 来源模块有真实通知事件 | 按来源规则发送一次，资产广场不重复、不拦截、不改收件人；公开地址/企业名不被转换成消息收件对象，无本模块模板待映射 |

通知验收不替代主 PRD 的真实持有事实、同步能力及登录回跳验收。
