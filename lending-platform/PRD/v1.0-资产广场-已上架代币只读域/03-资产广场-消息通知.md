# 资产广场 · 消息通知

<a id="conclusion"></a>

## 结论

**资产方、资金方、运营方均为零发送事件、零模板，无模板待接入。** 资产广场是公开只读查询模块，本期不发送站内信，也不增加邮件、短信或浏览器推送。列表与详情中的提示、加载和复制反馈属于页面反馈，不是消息通知。

本册与[主 PRD](01-资产广场-PRD.md)配套，只定义本模块的发送边界；无发送时点、收件人或跳转模板需要编造。

<a id="ownership"></a>

## 场景与发送归属

| 场景 | 本模块处理及责任 |
| --- | --- |
| 查看、筛选、复制、分享、进入项目或区块浏览器 | 不发送；不增加未读，不改变既有消息的已读状态或排序 |
| 新代币同步、代币失效、数量价值/持有地址/质押关系更新 | 更新可见业务事实，不向持有人、融资参与方或全体用户群发；链上地址不是账户或收件人 |
| 数据缺失、关系冲突、加载重试、同步或核对异常 | 页面按主 PRD 处理；运营需可察觉数据异常，但本模块不新增运营广播、告警消息模板或补资料任务 |
| 登录资格、资金方账户与认证 | 由登录与账户、机构审核等所属模块按其通知规则发送；资产广场的零通知不取消这些事件，也不补发、转发 |
| 融资申请、代币质押与审核、释放等业务结果 | 由融资与质押、质押审核等源业务模块按其已有边界发送；本模块看到同一变化不再发送，也不改变原收件人或文案 |

本人资料与业务展示边界沿用主 PRD：自动取得业务信息不产生手动补填通知，不开放企业成员或联系方式，不因同企业或同钱包扩大发送对象。当前唯一链上地址的业务定义已确认；真实事实供给依赖仍保留，但无论数据是否就绪，本模块均不新增通知。

配套账户规则采用[登录主干当前消息通知](../v2.0-登录与账户体系/03-登录主干与资产方SSO接入-消息通知.md)及[资金方当前消息通知](../v2.0-登录与账户体系/03-资金方登录与账户体系-消息通知.md)；质押业务发送归属继续由[融资与质押通知](../v1.0-借贷广场-融资需求与代币质押/03-融资需求与代币质押-消息通知.md)和[质押审核通知](../v1.0-代币质押审核/03-代币质押审核-消息通知.md)各自定义。本册不复制它们的事件或模板。

## 关键验收
<a id="acceptance"></a>

| 编号 | 可观察结果 |
| --- | --- |
| <a id="AC-AM-N01"></a>AC-AM-N01 | 资产方、资金方、运营人员均不存在本模块新增的站内信事件；游客不会因浏览产生收件身份或消息 |
| <a id="AC-AM-N02"></a>AC-AM-N02 | 新代币可见、失效、质押/释放及持有信息展示变化不产生资产广场消息，不新增到期预告、关注订阅或资产推荐；既有数据显示和时效要求仍成立 |
| <a id="AC-AM-N03"></a>AC-AM-N03 | 列表与详情的搜索、筛选、排序、每批 20 条自动追加、刷新、返回恢复、复制与项目跳转保留原反馈；正常结果和失败重试均不新增消息或由本模块改变未读 |
| <a id="AC-AM-N04"></a>AC-AM-N04 | 同步异常、核对差异和关键字段缺失仍能被运营察觉，并按原要求处理；不以无站内信代替该项验收，不将内部异常向资产方或资金方推送 |
| <a id="AC-AM-N05"></a>AC-AM-N05 | 持有资料缺失或冲突按主 PRD 持有不可用规则处理，不能被解释为到账、资产损失、解除质押或需补材料的新事件；不得根据持有地址选择收件人 |
| <a id="AC-AM-N06"></a>AC-AM-N06 | 其他模块已确认的通知仍由其负责发送；资产广场展示相同事实、刷新或反复打开页面不补发、不重置原消息已读、不改变原消息排序 |
| <a id="AC-AM-N07"></a>AC-AM-N07 | 消息中心无资产广场的新增模板或事件登记，无“暂无通知”占位记录，无为填满三方范围而增加的广播；公共消息入口和其他模块消息不受影响 |
| <a id="AC-AM-N08"></a>AC-AM-N08 | Q-AM-55 已关闭，按当前唯一链上地址展示；Q-AM-56 仅保留实际事实供给核对依赖。地址从企业转到合约、业务释放但未转回、实际转回后的展示均不新建广场通知；不以地址推断收件人、不启用多地址或多项目正常事件 |
| <a id="AC-AM-N09"></a>AC-AM-N09 | P01 下业务字段自动取得且只读，个人/企业账户资料不随公开业务展示、消息或通知变量泄露；不因缺资料产生补填站内信，不给所有企业成员广播。三方零事件结论不变 |

通知验收不替代主 PRD 的真实持有事实、同步能力及登录回跳验收。
