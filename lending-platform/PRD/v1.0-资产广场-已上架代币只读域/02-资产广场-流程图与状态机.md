# 资产广场 · 流程图与状态机

配套[主 PRD](01-资产广场-PRD.md)。图只表达业务流转；字段、权限、异常与验收由正文定义。阅读顺序为同步浏览、详情跳转、当前持有事实，再查看两类业务状态与列表视图。

本册只定义信息需求与业务行为；页面布局、组件形态、层级与视觉由 Hallmark 设计决定。本册措辞与设计稿冲突时以设计稿为准，业务口径仍以本册为准。图中节点是业务环节与信息域，不表示页面或组件。

## FL-AM-01 · 同步与公开浏览
<a id="FL-AM-01"></a>

关联功能：[F-AM-13](01-资产广场-PRD.md#F-AM-13)。

```mermaid
flowchart TD
  S[资产可信平台提供确权商务要素与存证事实] --> A
  A[发行平台同步代币及业务资料] --> B{关键字段齐全?}
  B -->|否| C[记录不展示不统计，运营察觉并补齐]
  B -->|是| D[自动纳入展示集合，含失效代币]
  D --> E[游客或登录用户进入资产广场]
  E --> F[按筛选搜索全集汇总并显示首批]
  F --> G[按当前条件连续追加后续批次]
  G --> H[打开独立代币详情]
  I[发行平台状态变化及每日核对] --> J[按最新权威事实修正，不回退]
  J --> D
  K[上游中断] --> L[保留最近可用资料，运营察觉]
  L --> E
```

打开页面只读本平台已同步数据及本平台质押事实，不临时读链或向上游取数；同步故障不对外显示，页面自身读取失败仍可重试。业务规则见[数据更新](01-资产广场-PRD.md#data)。

## FL-AM-02 · 查看详情与跳转
<a id="FL-AM-02"></a>

关联功能：[F-AM-01](01-资产广场-PRD.md#F-AM-01)、[F-AM-06](01-资产广场-PRD.md#F-AM-06)、[F-AM-07](01-资产广场-PRD.md#F-AM-07)、[F-AM-08](01-资产广场-PRD.md#F-AM-08)、[F-AM-09](01-资产广场-PRD.md#F-AM-09)、[F-AM-10](01-资产广场-PRD.md#F-AM-10)。

```mermaid
flowchart TD
  A[列表行或分享链接] --> B{代币可展示?}
  B -->|否| C[内容不存在]
  B -->|是| D[独立详情五部分信息]
  D --> E{用户选择}
  E -->|公开当前项目| F[在当前窗口进入既有项目详情]
  F --> G[反映项目当前状态，终态仍可打开]
  E -->|草稿项目| H[仅提示尚未公开，无名称和链接]
  E -->|区块浏览器| I[新窗口自行查验，保留未核验提示]
  E -->|主动登录或详情引导入口| J[既有登录与账户链路]
  E -->|返回列表| K[恢复条件、已加载范围和浏览位置]
```

公开浏览不触发登录或授权；主动登录后的引导、权限与回跳归登录模块。对应[进入广场](01-资产广场-PRD.md#entry)、[详情](01-资产广场-PRD.md#detail)与[项目去向](01-资产广场-PRD.md#pledge)。

## FL-AM-03 · 当前持有事实与项目
<a id="FL-AM-03"></a>

关联功能：[F-AM-14](01-资产广场-PRD.md#F-AM-14)。

```mermaid
flowchart TD
  A[查看本笔持有信息] --> B{当前唯一地址、整笔数量价值及关系可核对?}
  B -->|否或冲突| C[持有信息暂不可用，其他可用资料保留]
  B -->|是| D[仅给出当前真实地址一条记录]
  D --> E{本平台当前质押生效且转移成功?}
  E -->|是| F{唯一当前项目已公开?}
  F -->|是| G[已质押，项目名称及既有深链]
  F -->|否，草稿| H[已质押，仅提示尚未公开]
  E -->|否| I[未质押，项目为横线]
  I --> J{业务已释放但尚未实际转回?}
  J -->|是| K[仍显示真实合约地址，不宣称到账或可再质押]
  K --> M[实际转回后仅更新唯一地址]
  J -->|否| L[按当前真实地址展示，数量价值及统计不增加]
  M --> L
```

加载失败可重试；无数据、历史零余额、多个当前地址/有效项目不能当作正常的空结果。关系不明走不可用，不能走草稿分支。图中地址不是用户身份或企业归属。详见[持有信息](01-资产广场-PRD.md#holding)。

## ST-AM-01 · 代币状态：跟随发行平台
<a id="ST-AM-01"></a>

关联功能：[F-AM-13](01-资产广场-PRD.md#F-AM-13)。

```mermaid
stateDiagram-v2
  state "有效" as Valid
  state "失效" as Invalid
  [*] --> Valid: 上游首次提供有效事实
  [*] --> Invalid: 上游首次提供失效事实
  Valid --> Invalid: 上游确认失效
```

这里只表达本期已确认的状态；本地日期不能触发转换，失效后仍展示并统计，不新增销毁或恢复流程。同步修正始终取上游最新事实，详见[数据更新](01-资产广场-PRD.md#data)。

## ST-AM-02 · 质押结果：只呈现二元
<a id="ST-AM-02"></a>

关联功能：[F-AM-09](01-资产广场-PRD.md#F-AM-09)。

```mermaid
stateDiagram-v2
  state "未质押" as Unpledged
  state "已质押" as Pledged
  [*] --> Unpledged: 无生效质押
  [*] --> Pledged: 已有生效且转移成功的事实
  Unpledged --> Unpledged: 处理中或失败
  Unpledged --> Pledged: 质押生效且转移成功
  Pledged --> Unpledged: 业务释放
```

这是本平台质押结果的对外呈现，不是新建质押流程。地址留在合约不表示仍已质押，未质押也不表示已到账或能再次质押；代币失效不替代这一维度。见[质押去向](01-资产广场-PRD.md#pledge)。

## ST-AM-03 · 列表视图状态
<a id="ST-AM-03"></a>

关联功能：[F-AM-04](01-资产广场-PRD.md#F-AM-04)、[F-AM-05](01-资产广场-PRD.md#F-AM-05)、[F-AM-06](01-资产广场-PRD.md#F-AM-06)、[F-AM-11](01-资产广场-PRD.md#F-AM-11)。

```mermaid
stateDiagram-v2
  state "首批加载" as Initial
  state "可浏览" as Ready
  state "末尾追加" as More
  state "追加失败，保留已加载记录和浏览位置" as MoreError
  state "首批失败，可重试" as Error
  state "全局空态或筛选空态" as Empty
  state "已全部加载" as End
  state "恢复条件、已加载范围和浏览位置" as Restore
  state "恢复读取失败，保留原视图" as RestoreError
  [*] --> Initial: 无历史视图
  [*] --> Restore: 刷新、分享、返回或前进后退
  Restore --> Ready: 恢复完成，仍有后续
  Restore --> End: 恢复完成，无后续
  Restore --> Empty: 当前结果为空
  Restore --> RestoreError: 读取失败
  RestoreError --> Restore: 重试恢复
  Initial --> Ready: 首批成功且仍有后续
  Initial --> End: 首批已含全部结果
  Initial --> Empty: 没有匹配结果
  Initial --> Error: 读取失败
  Error --> Initial: 重试
  Ready --> More: 继续浏览需要更多记录
  More --> Ready: 追加成功且仍有后续
  More --> End: 最后一批成功
  More --> MoreError: 追加失败
  MoreError --> More: 重试本批
  Ready --> Initial: 修改筛选、搜索或排序
  End --> Initial: 修改条件
  Empty --> Initial: 修改条件或重置筛选
```

更换条件始终从新条件的首批重新开始，旧结果不混入；每批 20 条不改变全集汇总范围。用户不能按页码定位，也不能改变每批条数；具体规则及恢复失败后应保留的原条件见[列表视图](01-资产广场-PRD.md#view)。
