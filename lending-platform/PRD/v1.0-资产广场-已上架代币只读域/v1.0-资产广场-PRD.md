# 资产广场 PRD · V2.3

资产广场让游客、资产方和资金方查看全平台已同步代币，理解其底层业务、当前链上持有地址及质押去向，并自行查看链上凭证。本模块只有公开列表和独立详情页，全部只读。

**阅读顺序**：先按本文“进入广场 → 查找代币 → 查看详情 → 查看持有地址 → 数据更新”讲解；测试按文末同序验收。配套阅读[流程图与状态机](v1.0-资产广场-流程图与状态机.md)及[消息通知](03-资产广场-消息通知.md)。原功能册、验收册已合入本文，旧路径仅保留兼容索引。
