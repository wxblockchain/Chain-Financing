## `FL-AM-01` 代币从确权到在资产广场可见

关联：`F-AM-13`、`D-AM-47`（本平台只持副本、不做代币权威）、`D-AM-48`（无上架闸门）、`D-AM-57`（新代币同步到即可见、失效当日可见）、`D-AM-58`（失效判定不在本平台）、`D-AM-59`（每日至少核对一次、差异以上游为准）。

```mermaid
flowchart LR
  A1(资产可信平台<br/>应收账款确权 + 上链存证) --> A2(代币发行平台<br/>铸造代币 · 代币事实权威)
  A2 -->|代币及展示所需业务信息同步过来| B1(借贷平台<br/>持有只读副本)
  A2 -->|代币失效 · 当日同步| B1
  B1 --> C1[P-F-AM-01 资产广场列表页]
  B1 --> C2[P-F-AM-02 代币详情页]
  P1(本平台质押业务<br/>融资事实权威) --> C1
  P1 --> C2
  B1 -.->|每日至少核对一次<br/>张数 / 代币价值合计 / 逐张代币状态<br/>差异以上游为准| A2
  B1 -.->|不存在：上架审核 / 运营挑选| GATE["本平台无此环节"]
  C2 -.->|不存在：打开页面时向上游临时取数| A2
```

> 两条标注「不存在」的虚线是显式声明：本平台**没有上架闸门**（`D-AM-48`、`X-AM-11`），页面**不向上游临时取数**（`D-AM-49`、`X-AM-13`）。核对虚线是本平台对自身数据的日常校准，**不是用户可见的页面动作**，核对状态也不对外展示（`D-AM-59`、`D-AM-54`）。

## `FL-AM-02` 访客浏览与跳出路径

关联：`F-AM-01`（入口）、`F-AM-06`（可寻址）、`F-AM-08`（自行查验）、`F-AM-09`（所属融资项目）、`F-AM-10`（登录/非登录一致与授权边界 `D-AM-52`）、`X-AM-10`（无反向入口）。

```mermaid
flowchart LR
  E1(顶栏导航 · 资产广场) --> LIST[P-F-AM-01 资产广场列表页]
  E2(外部分享链接 / 搜索引擎结果) --> LIST
  E3(外部分享的详情页链接) --> DETAIL
  LIST -->|点击任一行| DETAIL[P-F-AM-02 代币详情页]
  DETAIL -->|返回 / 浏览器后退<br/>条件、已加载范围与内嵌滚动位置恢复| LIST
  DETAIL -->|已质押 · 所属融资项目已发布| LS[借贷广场 · 融资需求详情]
  DETAIL -->|已质押 · 项目为草稿<br/>提示尚未公开 · 不给跳转| DETAIL
  DETAIL -->|区块浏览器 · 新窗口| EXP[[外部区块浏览器]]
  LIST -->|区块浏览器 · 新窗口| EXP
  DETAIL -->|页尾 CTA · 用户主动点击| LOGIN(登录 / 注册)
  LIST -.->|不提供反向入口| LS
  LIST -.->|游客浏览全程不触发授权跳转| LOGIN
```

> 游客与登录用户走**同一条路径、看同一套信息**（`AC-AM-10`）；页尾 CTA 两种身份都展示，文案可不同（`AC-AM-15`）。

## `ST-AM-01` 代币状态轴（业务对象：代币）

关联：`D-AM-11`（状态取上游、本平台只呈现）、`D-AM-58`（失效判定不在本平台）、`D-AM-16`（与质押状态正交、不合并）、`L-AM-07`。权威方：代币发行平台。

```mermaid
stateDiagram-v2
  [*] --> 有效: 代币铸造完成并同步到本平台
  有效 --> 失效: 对应应收账款已过到期日，（上游当日判定并同步）
  失效 --> [*]
  有效 --> 已销毁: 本期无来源 · 页面上不会出现
  已销毁 --> [*]
  note right of 失效
    页面展示「失效」并以小字给判定依据
    （对应应收账款的到期日）
    仍计入头部「代币数量」与「代币价值」
    另立「其中失效」一项单独说明
  end note
```

## `ST-AM-02` 质押状态轴与对外二元映射（业务对象：质押记录）

关联：`D-AM-12`（质押状态业务定义以本平台为准）、`D-AM-13`（对外收敛为二元）、`D-AM-14`（链上转移过程不对外）、`F-AM-09`、`L-AM-08`。权威方：借贷平台。

```mermaid
stateDiagram-v2
  [*] --> 可质押: 代币在本平台可见且无生效质押
  可质押 --> 已质押: 质押进入某融资项目资产池，且链上转移成功
  已质押 --> 已释放: 项目结清 / 关闭 / 审核驳回
  已释放 --> 可质押: 代币回到可质押
  可质押 --> 可质押: 质押发起但链上转移处理中或失败
  note right of 已质押
    对外展示「已质押」+ 所属融资项目跳转
    项目为草稿时只提示"尚未公开"、不给跳转
  end note
  note left of 可质押
    对外展示「未质押」
    处理中 / 失败 / 已释放一律归入此展示
  end note
```

> 对外只有 `未质押` / `已质押` 两个取值；链上转移状态、待提取、对账差异、gas、失败原因、撤回预扣**一律不对外**（`D-AM-15`）。一枚代币可以同时是「失效 + 已质押」，两个标签各自成列（`D-AM-16`、`AC-AM-43`）。

## `ST-AM-03` 列表页视图状态（页面视图）

关联：`D-AM-22`（条件、已加载范围与内嵌滚动位置恢复）、`F-AM-04`～`F-AM-06`、`E-AM-01`（全局空态）、`E-AM-02`（筛选空态）、`E-AM-08`（加载失败）。完整规则见[分册 01 9.1.3](01-功能需求说明.md#913-筛选排序搜索与内嵌滚动加载)，验收见 `AC-AM-18`、`AC-AM-19`、`AC-AM-30`、`AC-AM-47`。

```mermaid
stateDiagram-v2
  [*] --> 首批加载中: 无历史视图进入列表
  [*] --> 视图恢复中: 刷新或打开分享视图
  首批加载中 --> 可继续浏览: 首批最多20条且仍有更多
  首批加载中 --> 全部加载完毕: 首批已包含全部结果
  首批加载中 --> 全局空态: 本平台尚无已同步代币
  首批加载中 --> 筛选空态: 当前筛选或搜索无结果
  首批加载中 --> 首批加载失败: 加载失败
  首批加载失败 --> 首批加载中: 重试
  可继续浏览 --> 追加中: 内嵌列表向下滚动至已加载末端
  追加中 --> 可继续浏览: 追加20条且仍有更多
  追加中 --> 全部加载完毕: 追加剩余记录且无更多
  追加中 --> 追加失败: 保留已有记录与位置
  追加失败 --> 追加中: 用户重试本批
  state 列表浏览 {
    可继续浏览
    追加中
    追加失败
    全部加载完毕
  }
  列表浏览 --> 首批加载中: 筛选或排序或关键词变化，回到列表顶部
  列表浏览 --> 详情页: 点击已加载记录
  详情页 --> 视图恢复中: 返回或浏览器后退
  列表浏览 --> 视图恢复中: 刷新或前进后退到对应列表视图
  视图恢复中 --> 列表浏览: 恢复条件和已加载范围，再恢复内嵌滚动位置
  视图恢复中 --> 全局空态: 对应视图为全局空态
  视图恢复中 --> 筛选空态: 对应视图为筛选空态
  筛选空态 --> 首批加载中: 调整条件或重置筛选
  note right of 全部加载完毕
    末批不足20条时按实际余量展示
    显示结束提示，停止追加
  end note
  note right of 视图恢复中
    筛选、排序和关键词支持URL分享
    恢复已加载范围和内嵌滚动位置
    不用页码表示进度
  end note
  note right of 全局空态
    头部三项显示 0、不隐藏整块
    不出现「重置筛选」
  end note
```
