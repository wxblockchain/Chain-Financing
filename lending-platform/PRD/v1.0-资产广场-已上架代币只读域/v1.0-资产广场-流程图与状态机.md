## 同步与公开浏览

```mermaid
flowchart TD
  S[资产可信平台提供确权商务要素与存证事实] --> A
  A[发行平台同步代币及业务资料] --> B{关键字段齐全?}
  B -->|否| C[记录不展示不统计，运营察觉并补齐]
  B -->|是| D[自动纳入展示集合，含失效代币]
  D --> E[游客或登录用户进入资产广场]
  E --> F[按筛选搜索全集汇总并显示首批]
  F --> G[内嵌列表连续追加]
  G --> H[打开独立代币详情]
  I[发行平台状态变化及每日核对] --> J[按最新权威事实修正，不回退]
  J --> D
  K[上游中断] --> L[保留最近可用资料，运营察觉]
  L --> E
```

打开页面只读本平台已同步数据及本平台质押事实，不临时读链或向上游取数；同步故障不对外显示，页面自身读取失败仍可重试。业务规则见[数据更新](v1.0-资产广场-PRD.md#data)。

## 查看详情与跳转

```mermaid
flowchart TD
  A[列表行或分享链接] --> B{代币可展示?}
  B -->|否| C[内容不存在]
  B -->|是| D[独立详情五区块]
  D --> E{用户选择}
  E -->|公开当前项目| F[同窗进入既有项目详情]
  F --> G[反映项目当前状态，终态仍可打开]
  E -->|草稿项目| H[仅提示尚未公开，无名称和链接]
  E -->|区块浏览器| I[新窗口自行查验，保留未核验提示]
  E -->|主动登录或页尾引导| J[既有登录与账户链路]
  E -->|返回列表| K[恢复条件、已加载范围和位置]
```

公开浏览不触发登录或授权；主动登录后的引导、权限与回跳归登录模块。对应[进入广场](v1.0-资产广场-PRD.md#entry)、[详情](v1.0-资产广场-PRD.md#detail)与[项目去向](v1.0-资产广场-PRD.md#pledge)。

## 当前持有事实与项目

```mermaid
flowchart TD
  A[查看本笔持有信息] --> B{当前唯一地址、整笔数量价值及关系可核对?}
  B -->|否或冲突| C[持有信息暂不可用，其他可用资料保留]
  B -->|是| D[仅展示当前真实地址一行]
  D --> E{本平台当前质押生效且转移成功?}
  E -->|是| F{唯一当前项目已公开?}
  F -->|是| G[已质押，项目名称及既有深链]
  F -->|否，草稿| H[已质押，仅提示尚未公开]
  E -->|否| I[未质押，项目为横线]
  I --> J[业务释放未转回仍显示真实合约地址]
  J --> K[实际转回后仅更新唯一地址]
  K --> L[数量价值及头部统计不增加]
```

加载失败可重试；无数据、历史零余额、多个当前地址/有效项目不能当正常空表。关系不明走不可用，不能走草稿分支。图中地址不是用户身份或企业归属。详见[持有信息](v1.0-资产广场-PRD.md#holding)。

<a id="st-am-01-代币状态轴业务对象代币"></a>

## 代币状态：跟随发行平台

```mermaid
stateDiagram-v2
  state "有效" as Valid
  state "失效" as Invalid
  [*] --> Valid: 上游首次提供有效事实
  [*] --> Invalid: 上游首次提供失效事实
  Valid --> Invalid: 上游确认失效
```

这里只表达本期已确认的状态；本地日期不能触发转换，失效后仍展示并统计，不新增销毁或恢复流程。同步修正始终取上游最新事实，详见[数据更新](v1.0-资产广场-PRD.md#data)。

<a id="st-am-02-质押状态轴与对外二元映射业务对象质押记录"></a>

## 质押结果：只呈现二元

```mermaid
stateDiagram-v2
  state "未质押" as Unpledged
  state "已质押" as Pledged
  [*] --> Unpledged: 无生效质押
  [*] --> Pledged: 已有生效且转移成功的事实
  Unpledged --> Unpledged: 处理中或失败
  Unpledged --> Pledged: 质押生效且转移成功
  Pledged --> Unpledged: 业务释放
```

这是本平台质押结果的对外呈现，不是新建质押流程。地址留在合约不表示仍已质押，未质押也不表示已到账或能再次质押；代币失效不替代这一维度。见[质押去向](v1.0-资产广场-PRD.md#pledge)。

<a id="st-am-03-列表页视图状态页面视图"></a>

## 列表视图状态

```mermaid
stateDiagram-v2
  state "首批加载" as Initial
  state "可浏览" as Ready
  state "末尾追加" as More
  state "追加失败，保留记录和位置" as MoreError
  state "首批失败，可重试" as Error
  state "全局空态或筛选空态" as Empty
  state "已全部加载" as End
  state "恢复条件、范围和位置" as Restore
  state "恢复读取失败，保留原视图" as RestoreError
  [*] --> Initial: 无历史视图
  [*] --> Restore: 刷新、分享、返回或前进后退
  Restore --> Ready: 恢复完成，仍有后续
  Restore --> End: 恢复完成，无后续
  Restore --> Empty: 当前结果为空
  Restore --> RestoreError: 读取失败
  RestoreError --> Restore: 重试恢复
  Initial --> Ready: 首批成功且仍有后续
  Initial --> End: 首批已含全部结果
  Initial --> Empty: 没有匹配结果
  Initial --> Error: 读取失败
  Error --> Initial: 重试
  Ready --> More: 内嵌滚动至末端
  More --> Ready: 追加成功且仍有后续
  More --> End: 最后一批成功
  More --> MoreError: 追加失败
  MoreError --> More: 重试本批
  Ready --> Initial: 修改筛选、搜索或排序
  End --> Initial: 修改条件
  Empty --> Initial: 修改条件或重置筛选
```

更换条件始终从新条件首批顶部开始，旧结果不混入；每批 20 条不改变全集汇总范围。无页码、无常规加载按钮，具体规则及恢复失败后应保留的原条件见[列表视图](v1.0-资产广场-PRD.md#view)。
