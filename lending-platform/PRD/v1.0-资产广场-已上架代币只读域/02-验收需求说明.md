## 14. 非功能需求

> **本章全部继承平台既有基线，不新设一套。**

| 维度 | 要求 |
| --- | --- |
| **性能** | 10 万条数据量下列表页首屏 ≤ 2 秒；**头部汇总与首批列表同时展示**，不让汇总迟到；追加批次不改变汇总统计范围 |
| **数据时效** | 页面取本平台已同步的数据，准实时；**代币失效当日可见**，本平台与代币发行平台**每日至少核对一次**、差异以上游为准（分册 01 第 10 章）。**打开页面不向上游临时取数、不读链** |
| **时区** | UTC 存储，按时区渲染 **+ 显式时区标注**，**无裸时间**；**游客无账户时区，取浏览器时区** |
| **金额** | 数值 + 币种代码；**代币数量、代币价值（USD）、应收账款原币金额三者不得相加**；代币价值 2 位小数，**本平台不二次折算** |
| **脱敏** | 交易哈希缩略前 10 后 8；链上地址缩略前 6 后 4，**合约地址完整展示为唯一例外**；**完整地址不进日志、不进导出**（本模块无导出） |
| **安全 · 只读** | 本模块对应的服务端能力**必须只读**，不得提供任何写入语义；对上游**零写入**（`X-AM-12`）；一致性校验在服务端成立，前端隐藏 / 置灰不构成校验 |
| **安全 · 不暴露存在性** | 代币编号不存在与格式非法**返回同一结果**，不暴露编号是否存在 |
| **安全 · 授权边界** | 游客浏览两个页面的全程**不触发第三方授权跳转**（资产方登录才走资产可信平台授权），不要求任何跨平台登录态（`D-AM-52`） |
| **双语** | 中英，切换**不刷新**即完成全部替换（含表头、状态标签、空态、汇总标签、标注文案、筛选项）；**默认英文** |
| **可访问性** | 状态标签**不以颜色为唯一区分**，必须含文本；logo **不承担状态语义**，点击随列表行进入详情，替代文本取代币名称；键盘可达 |
| **移动端** | **必须适配**；窄屏列表转摘要卡，摘要卡上**代币编号、代币价值、两个状态标签不得被折叠隐藏** |
| **组件** | 全用借贷平台自持的面客端组件规范中的既有组件，**本模块不新设计组件**；公共层沿用本平台 `页面原型/_shared/` |
| **SEO 索引** | **允许搜索引擎索引列表页与详情页**（公开集合已收窄到不含单据号与影像件） |
| **防批量抓取** | **限制单位时间的访问频次 + 每批固定 20 条 + 不提供任何导出。** 触发频次限制时给提示、**不阻断**正常浏览 |
| **通知** | **本模块不产生任何站内信或邮件**。纯只读门户没有需要通知的事件；数据同步异常由**运营侧**察觉处理，不对外展示（`D-AM-54`）；场景与 `AC-AM-N01～09` 见独立《03-资产广场-消息通知》 |

## 15. 指标

## 18. 验收标准汇总

> **逐条可独立执行。**【红线】= 不可削弱；【反向】= 检查"不存在"，构造出即不通过。
> 角色：除特别注明外，**游客态与登录态（资金方 / 资产方）都要各跑一遍**；前置条件：本平台已同步到可用的代币数据。

### 18.1 编号与术语（`F-AM-01`；规则见主册 2.1、5.5、5.7）

| 编号 | 条款 |
| --- | --- |
| `AC-AM-01` | 本 PRD 使用的全部前缀与任何已入库文档的编号**零重复**；本 PRD **不新增、不改写**其他平台前缀下的编号 |
| `AC-AM-02` |【反向】全文检索本 PRD 正文、字段表、界面文案与双语文案，**「代币定价」「代币期限」零出现**（中英皆然） |
| `AC-AM-04` |【反向】界面文案、URL 参数与双语文案**不出现任何状态值编号**（`PS-` / `TS-` 形态）；质押状态对用户只呈现「未质押 / 已质押」两个取值 |
| `AC-AM-05` |【反向】页面、字段表与双语文案**不出现**「冻结」「报价冻结」「锁定中」「处理中」「待提取」「对账差异」「gas」「失败原因」等质押过程取值或列；普通页面加载与复制失败反馈不在此限制内 |
| `AC-AM-06` |【红线 · 反向】两个页面**不出现** `待报价`/`已报价待确认`/`放款中`/`已放款`/`已失效／已关闭` 任一取值，也不出现任何以代币为主体的第二套状态机 |

| `AC-AM-08` | 顶栏「资产广场」入口在游客态与登录态**同一位置、同一可用性** |
| `AC-AM-09` | 游客直达两个页面**不触发登录回跳** |

### 18.2 数据来源、上架口径与同步跟随（`F-AM-13`；规则见主册 5.1～5.3、分册 01 第 10 章，流程见图 `FL-AM-01`）
