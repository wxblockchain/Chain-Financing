## G-L358-01 从填写到提交及重提

规则：[F-L80～82](./资金方机构认证审核-PRD.md#f-l80)、[F-L86](./资金方机构认证审核-PRD.md#f-l86)、[F-L87](./资金方机构认证审核-PRD.md#f-l87)。注册步骤编排沿用 WS-349 P-L21；机构字段及材料按正文 4.1.1 同源表：机构名称、注册地、标识类型/编号、机构类型、注册地址及机构证明材料必填；监管机构、金融牌照编号、业务联系人邮箱选填。账户联系邮箱在第 1 步验证，不与材料邮箱混用。

```mermaid
flowchart TD
    A[资金方进入 P-L21] --> B{当前注册状态}
    B -->|draft 草稿| C[填写邮箱与机构资料]
    B -->|rejected 已驳回| D[预填上版内容；对照驳回原文修改]
    B -->|verified 已认证| E[编辑机构资料变更草稿]
    B -->|submitted 审核中| R[P-L22 只读进度与材料]
    D --> C
    E --> C
    C --> F{模版与材料可用}
    F -->|否| G[说明缺项或失败并保留草稿]
    G --> C
    F -->|是| H[核对全部信息及协议]
    H --> I[C-L30 提交确认；已认证变更增加降级告知]
    I -->|取消| C
    I -->|确认| J{邮箱、资料、查重、协议及提交频次符合要求}
    J -->|否| K[定位原因；原状态与草稿保留]
    K --> C
    J -->|是| V{本次提交结果能否确认}
    V -->|已确认成功| L[本次提交成功；形成唯一新版本]
    V -->|未知| W[原注册流程保留本次资料只读快照；查询结果]
    W -->|查询失败，可重试| W
    W -->|确认未收到| C
    W -->|确认已收到| L
    L --> M[submitted / L1；机构资料锁定]
    M --> N{是否由已认证变更而来}
    N -->|是| O[WS-349 发 EV-L46；下次进入说明降级]
    N -->|否| R
    O --> R
    R --> S[运营审核；结果见 G-L358-02]
```

补充：首次成功版本为 1，后续成功提交加 1；重复返回同一次成功结果不加版本或次数。编辑变更草稿仍为 L3，编辑驳回草稿仍为 L2。提交未知不是新认证状态；确认结果前原注册状态不变、本次快照只读，刷新/重登仍可继续查询，确认未收到才恢复编辑。材料失败可定位重试，取消替换保留原件，失败/中断刷新不视为成功。审核中可按 WS-349 修改账户联系邮箱，不能修改申请中的业务联系人邮箱。客服联系不改变状态。

## G-L358-02 运营审核与结果生效

规则：[F-L81](./资金方机构认证审核-PRD.md#f-l81)、[F-L83～84](./资金方机构认证审核-PRD.md#f-l83)、[F-L88～89](./资金方机构认证审核-PRD.md#f-l88)。正常运营登录后即可查询和处置；不区分查询岗与审核岗，不配置权限。只读来自历史版本或已出结论状态，不能取消正常登录、本人资料归属或材料锁定要求。

```mermaid
flowchart TD
    A[运营进入申请列表 P-L40] --> B{已正常运营登录}
    B -->|否| C[先完成正常登录；不显示材料或执行审核]
    B -->|是| D[筛选并打开 P-L41]
    D --> E[查看提交版本、模版、字段、材料与历史]
    E --> F{当前版是否待审核}
    F -->|否| G[已结论或历史版只读；可返回当前版或列表]
    F -->|是| H{审核判断}
    H -->|材料暂不可读| I[重试或返回；不当作申请人缺件]
    I --> E
    H -->|拟通过| J[C-L31 确认通过及影响]
    H -->|拟驳回| K[一个必填驳回原因输入框]
    K --> U{去除首尾空白后是否非空}
    U -->|否| V[就地提示填写原因；不出结论]
    V --> K
    U -->|是| L[C-L31 核对申请、版本与完整原因原文]
    L -->|返回修改，保留输入| K
    J --> M{登录有效、当前版仍待审核且机构唯一性满足}
    M -->|重复机构冲突| N[本次通过不生效；仍待审核，核实原因]
    N --> H
    M -->|版本变化或登录失效| O[拒绝旧动作；登录有效后查看当前状态]
    M -->|是| P[唯一通过结论；verified / L3]
    L -->|确认| Q{登录有效、当前版仍待审核}
    Q -->|否| O
    Q -->|是| R[唯一驳回结论；rejected / L2]
    P --> S[保留本版材料与决定记录；触发结果通知]
    R --> S
    S --> T[面客结果及通知见 G-L358-04]
```

取消不出结论，返回修改保留输入；失败或结果暂不确定不显示成功。新驳回不选择字段/分类、不分别填写中英文或额外补充说明；确认预览、双端详情、修改页和本版历史使用同一原因原文，保留正文换行，切换语言不自动翻译。空白校验与字段本身的表单校验是不同规则，取消字段级驳回不取消必填/上传错误定位。同一版本的后到动作不能覆盖既有结论。已通过/驳回及历史版本只能查看，不能从本页翻转结论。客服反映材料有误时由运营核实并使用上述驳回动作，不新增特殊解锁路径。

呈现沿用正文 D-L187：P-L40 列表不展示版本；P-L41 详情历史在最下方，左右布局时右侧只放审核操作，材料和机构信息放主内容。列表隐藏版本不删除提交版本记录，审核仍须明确判断的是哪一版。

## G-L358-03 注册认证状态机与分档

规则：[F-L85](./资金方机构认证审核-PRD.md#f-l85)、[F-L86](./资金方机构认证审核-PRD.md#f-l86)、[F-L87](./资金方机构认证审核-PRD.md#f-l87)。与 WS-349 07 图册 §3.2 及 WS-348 主干 §6.3 同源，本图聚焦审核闭环。

```mermaid
stateDiagram-v2
    state "未提交注册 draft / L0" as Draft
    state "审核中 submitted / L1" as Submitted
    state "已驳回 rejected / L2" as Rejected
    state "已认证 verified / L3" as Verified
    [*] --> Draft: WS-349 首次签名建号
    Draft --> Submitted: 首次提交成功
    Submitted --> Verified: 本模块审核通过
    Submitted --> Rejected: 本模块审核驳回
    Rejected --> Submitted: 修改后重新提交成功
    Verified --> Submitted: 变更资料并确认提交成功；降级告知
    note right of Submitted
        机构资料锁定
        不能回到 draft
        只有审核结论能离开
    end note
    note right of Verified
        不是终态
        编辑未提交草稿仍保留 L3
    end note
```

| 条件 | 可执行动作 | 不允许的结果 |
| --- | --- | --- |
| L0 / draft | 填写、保存、核对提交 | 未提交直接通过或驳回 |
| L1 / submitted | 只读进度、材料、联系客服；账户邮箱按账户规则修改 | 编辑申请、撤回、删除、再次提交、回 L0 |
| L2 / rejected | 看原因、修改、重新提交 | 保存草稿重置为 L0，或不重提直接认证 |
| L3 / verified | 看当前认证、发起资料变更 | 成功变更提交后继续保留 L3，或运营直接改为 rejected |

T1/T2/T3 是登录主干状态，不能与本图混为同一状态轴。有效会话下 L0/L1/L2 为 T2，L3 为 T3；无会话或账户不可用按 WS-349 回 T1，不清除认证资料、不因审核通过自动恢复登录。停用/恢复操作不在本模块新增。认证生命周期无终态，每一提交版本的生效结论则不可从审核页面改写。

## G-L358-04 结果查看与有效通知邮箱

规则：[F-L85](./资金方机构认证审核-PRD.md#f-l85)、[F-L89](./资金方机构认证审核-PRD.md#f-l89)。本图只表达通知接收与业务效果，不规定送达机制。

```mermaid
flowchart TD
    A[当前版本审核结论生效] --> B[通过为 verified；驳回为 rejected]
    B --> C[P-L22 与后续业务权限采用当前结果]
    B --> D[触发 EV-L60 或 EV-L61]
    D --> E[站内信]
    D --> F{账户邮箱修改是否已生效}
    F -->|尚未生效或未修改| G[邮件发当前旧邮箱]
    F -->|已生效| H[新产生的邮件发新邮箱]
    E --> I[用户查看通知或进入结果页]
    G --> I
    H --> I
    I --> J{身份有效且为申请本人}
    J -->|否| K[先完成登录；不能因通知自动授权]
    J -->|是| L[查看当前结果和驳回原文；可进入修改]
    D --> M[若送达失败：结论保留，结果页仍可查]
```

本轮不使用模版内业务联系人邮箱代替账号联系邮箱；邮箱改变不重发历史通知。提交成功 EV-L42、变更提交降级 EV-L46 归 WS-349，不由本模块重复发送。驳回通知和引导不要求问题数量，查看原因进入 P-L22 读取原文；不将单一原因解析成字段问题或分类。邮件不带完整敏感材料，不透露审核员个人信息。

P-L22 呈现与正文 4.3/4.6 一致：上下分区、驳回原因及重提在首屏，当前审核中刷新位于状态提示内，历史在提交信息内默认折叠；不恢复进度侧栏或底部快捷行。审核中不承诺天数，客服靠近驳回/原因缺失/加载异常；无真实渠道时反馈“暂不可用”，不编造联系地址。依据为正文 S1 第 4 项、S6 最新布局及 S8 原有不承诺口径。

## G-L358-05 模版升级与提交历史

规则：[F-L80](./资金方机构认证审核-PRD.md#f-l80)、[F-L86](./资金方机构认证审核-PRD.md#f-l86)、[F-L88](./资金方机构认证审核-PRD.md#f-l88)。模版版本与申请提交版本是两个不同概念，不要求它们同步加号。

```mermaid
flowchart TD
    A[模版新版本生效] --> B{正在处理的内容}
    B -->|已提交或历史版本| C[按提交时模版只读查看及审核]
    C --> D[新增必填不追溯判旧申请缺项]
    B -->|草稿或新一轮重提| E[按当前生效模版核对]
    E --> F[兼容字段保留；删除项停止展示并说明调整]
    F --> G[新必填为空；不兼容内容提示重新核对]
    G --> H[驳回原文保留；既有字段级目标删除则说明调整]
    H --> I[补齐并经完整提交门槛]
    I --> J[新提交版本固定本次模版、内容和材料]
    J --> K[历史版本及其结论仍只读可查]
```

新驳回只有一个原因，不与字段建立目标关系，模版升级不改写原因。此前已有的字段级原因和补充说明仍按原版本只读展示；旧字段已删除不强求补填，不据历史兼容恢复新审核的字段勾选、原因目录或双语填写。

未定边界见[正文第 6 章](./资金方机构认证审核-PRD.md)：机构证明材料的具体可接受证件与审核判据、未定细化校验及字数上限、上传阈值、真实客服渠道。原因分类目录不再需要。字段表及必填性已采纳；DEMO-2 删除联系人邮箱和监管转必填仅为升级演示，不据此改本期字段。SPV 不另建认证已收口；审核沿用不承诺天数的说明，不在图中新增超时判定或虚构联系方式。
