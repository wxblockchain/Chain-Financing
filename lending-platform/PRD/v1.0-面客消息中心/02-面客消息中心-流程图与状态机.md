<a id="fig-nc-01"></a>
## FIG-NC-01 来源到本人阅读

关联IF-NC-01～07、D-NC-59。[消息池](01-面客消息中心-PRD.md#f-nc-01)。消息中心不从当前页面状态推导新事件，以下是来源职责与用户可观察结果。

```mermaid
flowchart TD
    A["来源业务的正式事实成立"] --> B{"来源规定需要告知本人？"}
    B -->|否| C["仅业务场景反馈，不新增消息"]
    B -->|是| D{"属于已明确可选且用户已关闭？"}
    D -->|是| C
    D -->|否| E{"原收件账号与必要内容明确？"}
    E -->|否| F["来源补齐，不能猜人或发空白信；该分支待验"]
    E -->|是| G{"该账号已收到同一事件？"}
    G -->|是| H["保留原条，不改变原有次序、不恢复未读、不改原时间"]
    G -->|否| I["按来源合并及迟到规则告知；不同真实事件分别保留"]
    I --> J["事件后60秒内列表与未读计数一致可见；冲突分支不得报达标"]
    J --> K["本人阅读消息，或进入原业务"]
    H --> K
    K --> L["读信不办理业务；业务结果以来源为准"]
```

可选清单未明确时不以“关闭全部通知”屏蔽关键通知；强制通知始终接收。消息延迟不回滚业务或顺延期限。

## FIG-NC-02 阅读路径与返回

关联F-NC-11～21、27。[入口与信息域](01-面客消息中心-PRD.md#f-nc-11)。

```mermaid
flowchart TD
    A["正常登录且已完成必办前置"] --> B["壳层消息入口"]
    B --> C["最近10条预览，打开或浏览经过不已读"]
    A --> D["账号菜单：消息中心"]
    D --> E["完整消息列表"]
    C -->|查看全部| E
    C -->|选择消息| F["消息详情"]
    E -->|从消息条目或键盘打开| F
    E -->|分类与阅读筛选| E
    E -->|加载更多20条| E
    E -->|全部已读| ALL["FIG-NC-03"]
    F --> G{"可读内容成功展示？"}
    G -->|否| H["保持未读，加载失败可重试"]
    H --> F
    G -->|是| I{"自动已读成功？"}
    I -->|否| J["正文仍可读，真实未读保留，提供重试"]
    J --> I
    I -->|是| K["同步已读与未读计数，不执行业务"]
    F -->|返回列表| R["恢复原筛选、批次、所在位置与焦点；无上下文回默认列表"]
    R --> E
    F -->|原业务入口| T["按FIG-NC-04访问原对象"]
    T -->|后退| F
    F -.->|会话失效| S["清除本人内容，游客态；SM-NC-03"]
    E -.->|会话失效| S
```

不提供逐条标为已读的动作；自动已读失败重试只处理阅读结果。业务后退不通过中转自动再进入业务。

<a id="fig-nc-03"></a>
## FIG-NC-03 全部已读

关联F-NC-19、D-NC-42。[阅读与全部已读](01-面客消息中心-PRD.md#f-nc-18)。

```mermaid
flowchart TD
    A["本人消息列表与当前筛选"] --> B["选择全部已读"]
    B --> C["确认分类、阅读筛选及将改变的未读条数；包括未加载项"]
    C -->|取消| A
    C -->|确认| D["仅处理本次确认范围，避免重复提交"]
    D -->|成功| E["范围内就地已读，列表与未读计数同步"]
    D -->|失败| F["失败可见、保持原状态，可重试；无静默部分成功"]
    F --> C
    E --> G["业务状态不变；本次范围外的新消息仍未读"]
```

没有未读时不宣称改变了其他消息；已加载消息不因刚变已读自动消失，重新筛选/刷新再依最新状态匹配。

<a id="fig-nc-04"></a>
## FIG-NC-04 原动作与原对象分开判断

关联F-NC-23～24、D-NC-53/55/56/64。[业务目标与可访问性](01-面客消息中心-PRD.md#f-nc-23)。

```mermaid
flowchart TD
    A["本人可读消息详情"] --> B{"已登记本平台目标？"}
    B -->|无目标或类型未登记| C["只读正文与返回，无伪业务入口或错误说明"]
    B -->|静态页面| D["可前往该页面，落地判权"]
    B -->|业务对象| E{"原对象当前可读？"}
    E -->|不可访问| F["统一不可访问说明，禁用业务入口；不泄露存在性"]
    E -->|检查超时或失败| G["可尝试前往，由目标重新判权"]
    E -->|可读| H{"提醒仍有效且原动作仍适用？"}
    H -->|是| I["按来源提供原对象查看或有效办理入口"]
    H -->|否| J["查看原对象结果；停用旧提醒动作，不换下一期"]
    D --> K["用户主动前往，落地重新判权"]
    G --> K
    I --> K
    J --> K
    K -->|有权| L["原对象当前事实及真实可用动作"]
    K -->|已登录无权| M["既定受限引导，不泄漏私有内容"]
    K -->|未登录| N["既有登录及合法回跳"]
```

消息自身过期只终止其提醒效力并退出未读计数，不删除正文，也不取消业务允许的超期办理。本人消息可读不代表目标可读。旧信说当时发生的事实，目标呈现当前事实。

## FIG-NC-06 登记与适配

关联F-NC-06、F-NC-10、RG-NC-01～14。[触发登记与来源要求](01-面客消息中心-PRD.md#f-nc-06)。

```mermaid
flowchart TD
    A["来源给出完整事件、收件、模板与原对象规则"] --> B["按登记项核对唯一归属、分类、偏好及同次结果合并"]
    B --> C{"必要依赖已明确？"}
    C -->|否| D["记录对应分支待确认或待验；不猜定、不发重复任务"]
    C -->|是| E["汇入唯一共享登记"]
    E --> F["按角色核验真实账号、正文、原目标、计数及可见时效"]
    F --> G{"实际证据满足？"}
    G -->|否| H["仍待适配；可读降级不等于完成"]
    G -->|是| I["对应分支标已适配"]
```

新业务只扩展来源与共享登记，不追加框架业务章节。本轮核对并不自动完成共享登记或真实投递。

<a id="sm-nc-01"></a>
## SM-NC-01 消息提醒有效性

对象是一条消息的提醒效力；与原对象状态、账号阅读状态分开。关联F-NC-24、D-NC-22/23/64。[未读与消息有效性](01-面客消息中心-PRD.md#f-nc-03)。

```mermaid
stateDiagram-v2
    [*] --> 有效: 消息成立且在来源有效期内
    有效 --> 已过期: 到达来源明确的提醒失效时点
    有效 --> 已主动失效: 来源正式终止该提醒效力
    note right of 有效
        未读才计未读计数；原动作失效不自动使消息到期
    end note
    note right of 已过期
        历史保留，不计未读计数；有权原对象可查看
    end note
    note right of 已主动失效
        历史保留，不计未读计数；不代表业务被撤销
    end note
```

原对象的可办、可读和不可访问按FIG-NC-04判断，不作为消息提醒状态互相覆盖。没有由重复送达恢复有效的路径。

<a id="sm-nc-02"></a>
## SM-NC-02 本人阅读状态

对象为一个收件账号对一条消息。关联F-NC-18～19。[阅读与全部已读](01-面客消息中心-PRD.md#f-nc-18)。

```mermaid
stateDiagram-v2
    [*] --> 未读: 新消息属于本人
    未读 --> 已读: 详情成功展示且自动已读成功
    未读 --> 已读: 全部已读成功且在本次确认范围内
    未读 --> 未读: 加载失败、已读失败或仅预览
    未读 --> 未读: 同事实重复到达
    已读 --> 已读: 再次阅读、同事实补齐或重复到达
    note right of 已读
        无标未读入口、无系统重复恢复未读路径
        阅读不执行业务、不影响他人消息
    end note
```

真正新的业务事件产生另一条消息，不能用旧条“已读→未读”代替。消息到期只影响未读计数资格，不改变是否读过的事实。

<a id="sm-nc-03"></a>
## SM-NC-03 会话与消息可达性

关联F-NC-27及[会话规则D-NC-26～33](01-面客消息中心-PRD.md#d-nc-26)。[会话、越权保护与异常](01-面客消息中心-PRD.md#f-nc-27)。

```mermaid
stateDiagram-v2
    [*] --> 游客: 未登录
    游客 --> 受限会话: 登录后仍有必办前置
    游客 --> 正常登录: 登录成功且前置完成
    受限会话 --> 正常登录: 完成必办前置
    受限会话 --> 游客: 退出或失效
    正常登录 --> 游客: 退出、到期或被动失效
    note right of 游客
        无入口和本人内容；深链先登录再回原处
    end note
    note right of 受限会话
        不开放消息数据；先完成前置
    end note
    note right of 正常登录
        可读本人消息；业务资质不足另由目标限权
        自动消息更新不延长会话
    end note
```

失效时入口、预览、列表、正文和未读计数同时清除，迟到结果不重新显示；须真正清除，不能只是遮蔽而数据仍可取得。
