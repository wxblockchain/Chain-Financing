### 2.2 资料、金额与日期

P01：本人账户档案不扩大可见范围，业务必要名称、编号及金额自动同源展示；原凭证、完整账户和私人资料去原业务按权限读取，不复制到通知正文。

P08/P09按2.1承接；P10统一UTC业务日期与连续时长，具体时刻按偏好显示并标注。数币精度与尾差没有批准取值就保持依赖。P11/P12归后续审核、协议与运营阶段，本轮不编造机构审核政策、运营访问权或协议下线通知。

## 4. 开关、收件与来源目标

账户开关政策以D-NC-59及WS-348 D-L120为准。来源要允许关闭某类事件，必须先明确具体种类、接收人、默认及补送政策；分类筛选不是退订设置。“业务提醒”分类不能自动等同可选通知。没有可选事件时不靠新增日常提醒为开关制造用途。

| 角色／情况 | 本轮承接 |
| --- | --- |
| 资产方 | 单笔审核/执行沿原提交或发起账号；多成员需求、项目与融资业务责任账号沿Q-LS-N01，不猜为报价接受人、还款提交人、管理员或全员 |
| 资金方 | L6相关消息发原报价账号；L7/L8沿本笔放款登记账号LN-14，其他员工办理不自动改投或增加副本；L5按其相关报价/债权范围并对同账号同项目事件去重 |
| 运营/SPV | 当前L5～L8面客事件不因此产生运营广播，控制台和本模块无独立发送；WS-359已有审核职责与管理消息不能由本册删除或扩权 |
| 停用、交接、归属不明 | 不任意改投，不转移历史。来源明确该分支后再验收，不暂停业务计时或回滚业务事实 |

目标沿来源原项目、原申请、原业务以及必要的原单笔申请、执行动作、RP期次/重传要求。状态变化时旧动作停用、原对象按当前权限可读；未登记仍可读无跳转，不把通用默认页当成已经准确定位。若来源目标为控制台，保留其只读详情与唯一“前往借贷广场”，不从消息框架恢复列表广场链接、刷新按钮或办理入口。
