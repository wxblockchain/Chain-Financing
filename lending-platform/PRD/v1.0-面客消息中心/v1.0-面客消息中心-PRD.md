# 借贷平台 · 面客消息中心 PRD V1.1

所属：WS-356 / L10；角色：资产方、资金方；日期：2026-09-21；产品经理：许楚清。文档状态：需求评审修订稿，来源接入与最终验收依赖见验收册第19章。

消息中心承接借贷平台面客端本人站内信，提供消息池、触发登记规则、阅读与业务跳转。各业务模块决定发生什么事件、何时告知、告知谁；本模块没有独立发送事件。接入一个已符合框架的新业务，只更新来源通知与共享登记，不在四册框架正文追加业务事件章节。

## 3. 定位与目标

用户需要知道发生过什么，并能查看相关原业务或在仍可办理时主动进入办理。消息不是业务本身，也不是已办凭证。读信与业务提交、付款、确认、审核互不替代。

本平台已经有实际业务通知需求，本期不能再以“接入方为零”推断全链路可上线。框架可用、文档登记完整、真实账号与投递可用是不同结果，验收分别给证据。来源未决项只阻塞相应分支，不阻塞本轮其余文档交付。

## 5. 统一业务规则

### 5.1 平台、端与来源

| 编号 | 当前规则 |

| D-NC-08 | 只接收借贷平台面客端消息；其他平台与本平台管理端分别承接 |
| D-NC-09 | 无跨平台聚合入口、合计、开关或默认混入 |
| D-NC-10 | 同一自然人在不同平台各有消息中心、未读数与已读状态，互不影响 |

| D-NC-13 | 非本池异常记录不显示、不计未读、不可直达，并可供来源排查 |

### 5.2 正文与业务事实

消息保留事件时点事实，相关业务页面显示当前状态。后续业务变化不能覆盖旧消息的金额、时间、原因和原对象身份。来源明确的事实补齐可沿同一条完善，但不能倒退、置顶或恢复未读；不同事实不得借补齐覆盖。读取失败或未知结果不得显示为0、失败或成功。

### 5.3 本人可见与资料边界

| 编号 | 当前规则 |
| --- | --- |
| D-NC-14 | 可见范围为本平台面客端且收件账号为当前账号 |
| D-NC-15 | 归属使用本平台账号；不得用邮箱、钱包、他平台身份代替。同钱包双身份仍隔离 |
| D-NC-16 | 企业业务共享不等于共享员工消息；多收件人各自一条、各自已读 |
| D-NC-17 | 已登录且非受限会话可阅读本人消息；资质不足不自动抹掉本人历史，目标业务另行判权 |
| D-NC-18 | 访问他人消息与消息不存在使用相同不可用语义，不泄漏其存在性；不得借猜测编号或批量访问取得他人消息 |
| D-NC-19 | 同企业成员可见相同业务、消息未读数不同是正常表现；不补造企业广播 |
| D-NC-60 | 个人/企业账户档案仅本人可查；通知可展示来源已经授权的必要业务名称、金额和编号，不复制他方完整档案、证件、凭证、私人联系方式。资料自动取同源结果，不让用户在消息页手填。收信不授予查看或办理权 |

资产方、资金方分别接收来源明确的本人事件；运营/SPV不因管理身份访问面客池，也不因客服、线下核实或三方核对收到面客副本。账号缺失、停用及人员交接由来源业务明确，未明确时不能任取管理员、最近操作人或全员。

### 5.4 未读计数

`D-NC-20`：未读数以本人可见且有效消息中尚未读的条数为准，列表与角标一致。`D-NC-21`：角标合计全部分类。`D-NC-22`：消息自身已过期或主动失效不计入；不删除其历史。`D-NC-23`：原动作失效、对象不可访问、业务类型未登记本身不等于消息过期，仍按消息有效性计未读。`D-NC-24`：0不显示角标，超过99显示99+。`D-NC-25`：读取失败保留最后一次已知值，不清零、不干扰当前操作。

### 5.5 会话

`D-NC-26`：退出或失效后清除列表、正文、预览及角标，不用遮罩代替清除。`D-NC-27`：消息入口与账号菜单条目同时消失。`D-NC-28`：游客态停止更新本人消息，迟到结果不重现旧内容。`D-NC-29`：详情整体退出本人阅读态。`D-NC-30`：游客直达先走既有登录，成功回原列表或原详情，不丢目标。`D-NC-31`：自动消息更新不算用户主动活跃，不延长会话。`D-NC-32`：任何消息读取发现失效，均触发统一游客态。`D-NC-33`：未完成协议等必办前置的受限会话先完成前置，不开放消息数据；不能将“资质不足”与“受限会话”混为一类。

### 5.8 跳转与跨平台边界

`D-NC-34`：本平台已登记页面正确落原目标，未登录先登录再返回。`D-NC-35`：落地重新判断访问权，权限不足使用平台既定受限引导，不泄漏私有详情。`D-NC-36`：未知平台或页面落本平台默认资产广场，不恢复首页，不白屏。`D-NC-37`：本期消息无跨平台跳转；正文仍可读，无跳转不显示“暂不支持”等错误提示。`D-NC-38`：未来跨平台能力复用平台统一离站规则，本期不扩展。`D-NC-39`：仅定义可观察落点，编号解析等由实现决定。

### 5.9 通知偏好与时间金额

`D-NC-59`：通知偏好无历史值默认开启，只影响来源明确列出的可选通知；强制通知始终接收。未明确可选的关键事件不能被笼统“关闭通知”屏蔽，也不由本册将所有事件永久归类为强制。当前没有已确认可选清单时，账户不提供无实际效果的可操作开关，消息中心不另建一个。关闭不删除旧信、不改已读、不隐藏业务提醒、不停业务计时；重新开启不自动批量追补，后续可选事件须由来源明确其补送政策。

`D-NC-61`：业务日期统一UTC；连续时长不受时区、送达或阅读影响。具体时刻沿平台偏好展示并标注时区，无明确偏好时沿平台规则、缺省UTC。历史金额、期限、币种取事件时点事实，不能按当前行情或当前计划重算。来源未定的数币精度与尾差保持未定。

## 6. 角色场景

资产方与资金方均可通过壳层消息入口预览或进入完整列表；游客无入口，直达需登录；受限会话先完成前置。新信不弹窗打断，不抢焦点。本人查看详情后自动已读，可一次处理当前筛选的全部未读。用户可通过同一返回路径恢复列表；从业务页后退不能被中转页再次送走。
