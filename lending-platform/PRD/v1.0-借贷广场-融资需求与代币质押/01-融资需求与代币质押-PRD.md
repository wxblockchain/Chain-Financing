# 融资需求与代币质押 PRD · V1.6

资产方先创建融资项目、提交代币质押申请，运营逐笔审核，资产方确认费用后由发行平台执行入池。只有实际入池且有效的代币才支持发布融资需求；资金方随后报价，成交后继续放款与还款。项目是一只资产池，可承接多轮申请及多笔存量业务。

**主阅读入口就是本文。** 产品与研发按“浏览项目 → 建池与质押 → 发布需求 → 查看融资记录 → 撤回与提取 → 覆盖变化”顺序阅读；测试集中阅读文末同序验收。按需打开[流程图与状态机](02-融资需求与代币质押-流程图与状态机.md)和[消息通知](03-融资需求与代币质押-消息通知.md)。功能规则见第2～8章，验收见第9章。三册共同作为设计输入；已确认呈现约束沿用，常规视觉布局和组件由设计师决定。

## 1. 范围与角色
<a id="scope"></a>

本模块负责项目、质押申请、质押事实、额度及覆盖判断，以及四类项目记录的查看与办理入口。运营审核在质押审核模块；链上执行由代币发行平台承担；授信报价、放款、还款由各自模块定义，本文保留必要衔接。不新增代币上架审批、部分数量质押、平台代签代付、抵押物处置或异常处置系统。

| 角色 | 可以做什么 | 边界 |
| --- | --- | --- |
| 游客 | 浏览已公开项目及公开融资、抵押物与覆盖事实 | 无写权限、私有资料或私有待办；草稿不暴露存在性 |
| 本企业资产方 | 建池、申请质押、确认执行、发布及管理需求、按条件撤回或提取；承接本方履约办理 | 按当前有效身份、企业归属及业务资格判断；发起融资前实时核实有效认证，无法确认不放行 |
| 资金方 | 浏览公开项目；按自身资格办理本机构报价、放款及还款确认 | 私有资料只向相应业务当事方开放，注册或待审核不等于可出资 |
| 平台运营 | 在运营端逐笔审核、查看既有覆盖待办及监控 | 不在本面客模块裁定审核或代资产方执行 |

个人与企业账户档案仅本人查看。业务必要的项目、企业名称、代币等信息可自动获取并按本业务权限展示；不能据此开放对方整份账户档案。授信、账户、协议、凭证、联系方式、底层合同号/发票号及运营诊断不是公开融资信息。查看、下载和直接提交均检查权限，隐藏按钮不能代替权限控制。

共同登录资格与本人资料沿[登录主干](../v2.0-登录与账户体系/01-登录主干与资产方SSO接入-PRD.md)及[资金方账户](../v2.0-登录与账户体系/01-资金方登录与账户体系-PRD.md)；本模块公开业务字段范围按本文。上游代币事实沿[资产广场](../v1.0-资产广场-已上架代币只读域/01-资产广场-PRD.md)。不因精简改变既有权限。

## 2. 浏览项目与进入办理
<a id="browse"></a>

### 找到项目

<a id="F-LS-10"></a><a id="f-ls-10"></a>**F-LS-10** 借贷广场一行一个项目，草稿不出现；没有当前需求时显示“暂无融资需求”。展示项目名称、企业、质押额度（有效质押价值）、当前需求金额/币种及状态、覆盖情况。只显示中性的覆盖事实与缺口，不新增健康评分、风险等级、黑名单或评价性标签。

支持既有币种、期限、关键词筛选，默认发布时间倒序，可按需求金额、池内资产价值排序。定高列表内滚动，每批20条，保留可聚焦的“加载更多”和已显示数量，窄屏交还整页滚动；不改成页码分页。换排序或重置筛选回第一批和顶部，追加加载不跳位置。整行可点击或键盘进入详情，无操作列；返回恢复筛选、已加载范围、滚动和原行焦点。暂无项目、筛选无结果和读取失败分别呈现，后两者提供清空筛选或重试。

### 查看与办理分开
<a id="interaction"></a>

<a id="F-LS-11"></a><a id="f-ls-11"></a>**F-LS-11** 项目摘要包含名称、项目编号、资产方企业、有效期、项目状态；当前需求金额与状态单独辨认。<a id="F-LS-18"></a><a id="f-ls-18"></a>**F-LS-18** 统计只常驻五项：有效质押代币张数、有效质押价值、本轮融资需求、已融资余额（业务含义为项目融资余额）、固定质押率80%。审核中、通过待执行和执行中均不增加统计。融资上限、项目在途金额、可融金额只在办理需要时说明，不增加额度尺、额度进度条或公式折叠区。

<a id="F-LS-20"></a><a id="f-ls-20"></a>**F-LS-20** 已确认的交互继续保留：左侧“质押代币清单 → 融资申请信息 → 融资放款信息 → 还款信息”四区纵向自然滚动；定位标签只滚动定位，不隐藏其余清单。右侧固定“质押 / 融资 / 还款”操作页签，超高内容可滚动、主要入口可达。游客保留页签，仅有统一“立即登录”动作，不展示私有待办。各清单独立保留筛选和页码，空态与失败区分，不增加全项目操作日志。

| 用户动作 | 结果 |
| --- | --- |
| 从记录查看详情 | 右侧只读抽屉展示当前记录、历史、计划、账户和文件；没有办理、跨业务跳转或重复快捷查看按钮。历史、预览在当前容器展开，文件按权限下载 |
| 从右侧操作区办理 | 先明确申请、业务或期次，再进入居中操作弹窗；多笔待办不能默认代选“最新一笔”。步骤、必要确认与放弃修改都在本次容器内完成，不叠层 |
| 返回或关闭 | 返回上一步保留已填内容和成功附件；关闭有未提交编辑时就地确认放弃，取消放弃继续编辑。关闭恢复来源筛选、分页、滚动及行焦点；只读详情关闭不改业务 |
| 成功、失败或结果未知 | 成功只更新本笔和操作区，不自动打开详情、下一笔或下一阶段。失败保留可复用输入；未知显示待核实，不假报成功或引导重复提交 |

发布、质押成功发起、报价成功均关闭本次弹窗；授信保存成功关闭并提示“已授信，请继续报价”，用户再次点“立即报价”才进入报价。报价表单说明必要后果后直接提交，无二次确认；其他动作原有必要确认保留。具体尺寸、视觉排列与窄屏适配由设计师决定。见[查询与办理图](02-融资需求与代币质押-流程图与状态机.md#fl-ls-07)。

<a id="D-LS-61"></a><a id="d-ls-61"></a>平台已知且有权使用的本笔信息自动带入，优先本笔已确认事实，其次同企业、用途及币种的有效登记资料；仅补业务必需缺项。只读事实不能改写，可编辑项仍校验，逐笔确认不能省略。不得串用不同机构、企业、用途的账户，或把旧合同、旧转账凭证默认用于新业务；缺失/失败不填示例或零值。

## 3. 建池、逐笔审核与确认入池
<a id="pledge"></a>

### 创建项目并选择代币
<a id="create"></a>

<a id="F-LS-01"></a><a id="f-ls-01"></a>**F-LS-01** 本企业资产方从广场或控制台进入创建，填写项目名称、选择代币类型及至少一张代币后提交质押申请。<a id="F-LS-12"></a><a id="f-ls-12"></a>**F-LS-12** 提交成功即进入项目详情，项目为私有草稿；不等待审核或链上结果、不收费。后续可中断再继续，无需重复质押或付费。首笔全部驳回、撤回或执行失败，保留空池草稿并提示“本项目暂无有效质押，请重新提交质押申请后再发布”，禁止发布；可以重新申请或按既有条件关闭项目。

| 信息 | 必填与校验 |
| --- | --- |
| <a id="FP-02"></a><a id="fp-02"></a>项目名称（FP-02） | 文本，必填1～60字符，同企业不要求唯一，可修改 |
| 企业与项目编号 | 当前企业自动取得；项目编号创建时生成、全局唯一、终身稳定，只读 |
| <a id="FP-29"></a><a id="fp-29"></a>代币类型（FP-29） | 创建必选，本期仅应收账款，其他类型不可选并说明边界；同一项目后续只能追加同类型 |
| 代币选择 | 至少一张、不重复、整张勾选，无数量输入；显示数量/币种、签发价值、账期、买方及有效性，不显示合同号/发票号 |

<a id="eligibility"></a>

<a id="F-LS-04"></a><a id="f-ls-04"></a>**F-LS-04** 可选代币必须同时满足六项：已同步至本平台只读代币域；归属当前企业；无有效质押、不在质押合约内、无其他在途申请或执行占用；发行平台判为有效；本期属于应收账款；与本项目类型一致。无需本平台上架动作。其他企业代币不可见；本方被在途申请/执行占用的代币可只读提示占用来源但不可选；并发选择同张只有一笔成立。确认本笔时，不把本笔自身申请占用误作他笔占用。

<a id="D-LS-62"></a><a id="d-ls-62"></a>每张代币只有**一个当前真实链上持有地址**，对应整笔数量和签发价值；企业归属、当前地址、质押前原持有地址分别表达。业务释放未提取不能把地址提前改回企业地址，不能将原地址和合约地址重复计量。当前有效质押项目至多一个，历史项目不算当前占用。地址、归属或数量价值不可靠时不猜测放行。代币价值不二次折算，失效只取发行平台结果；本平台质押事实不反向读取上游同名状态。

### 提交后逐笔查看审核结果
<a id="review"></a>

<a id="F-LS-05"></a><a id="f-ls-05"></a>**F-LS-05** 建池和追加共用同一条链路；项目草稿、募集中、已锁定、融资中均按资格允许追加，终态不允许。创建页、追加入口和提交确认步骤均告知两次操作：现在提交审核不付费；通过后回来确认并承担链上费用。提交确认首句明确“本次提交的是质押申请，此刻不发生链上操作、不产生任何费用”，无支付或签名按钮。

<a id="F-LS-21"></a><a id="f-ls-21"></a>**F-LS-21** <a id="D-LS-49"></a><a id="d-ls-49"></a>每张本次申请独立审核，提交批次仅用于追溯。同批可有不同审核人、结果、协议和截止；一笔通过即可确认，不等全批。审核状态在申请上，不能将人工通过直接视为代币已质押。运营端负责结论，资产方在本项目“质押审核与确认”查看：一行一张当前代币，当前有效申请优先，否则显示最近结果；重提生成新单笔，旧结果留在逐币历史。

| 本笔结果或动作 | 用户所见与后续 |
| --- | --- |
| 待审核 | 显示等待时长及提交成功后连续48小时的准确截止，可撤回本笔；查看、上传、编辑不重置期限 |
| 通过 | 展示本笔审核人、时间、协议及独立七个自然日入池截止；提示通过不等于已入池，可核对后确认执行 |
| 驳回 | 原样完整展示面客原因，不能截断改写或暴露内部备注；只解除本笔申请占用、零费用，可按资格重提 |
| 待审撤回 | 与审核同时发生仅一个结果成立；已通过不能借撤回取消结论。撤回保留记录、解除本笔占用、零费用 |
| 连续48小时仍待审 | 无人打开页面也自动质押失败，原因“48小时未完成审核”；释放申请占用，代币未转入、零费用，无提取/退款。恰好截止及之后的审核不生效，已处理笔不改变 |
| 通过后仍未发起即到截止 | 本笔入池许可失效，原人工通过及协议存档，未执行零费用；可按资格新笔申请 |
| 发起前复核不通过 | 只作废本笔许可并说明原因，无执行费用，不作废同批其他笔；原人工通过保留 |

审核清单展示代币标识/已有Logo或缺省标识、数量、金额、状态、提交时间及勾选，无操作列，默认提交倒序。默认全部当前代币，可按审核状态、后续情况及代币编号筛选，筛选/重置在右侧。对应协议文件名可直接下载；账期、买方、审核人、准确截止及执行明细在同容器详情，提交编号在历史可查。分页沿平台组件，翻页保留勾选并显示已选张数；换项目、改筛选或关闭清空选择并提示，重开默认未勾选。

本笔协议通过后必有1～5个有效关联文件，只向本企业相应资产方提供；文件关联失效仅存档，不连带作废其他笔共用文件。审核通过、驳回和审核超时各由运营审核模块发送一条站内信，L5不双发。见[建池质押图](02-融资需求与代币质押-流程图与状态机.md#fl-ls-01)与[申请状态机](02-融资需求与代币质押-流程图与状态机.md#st-ls-03)。

### 同项目批量确认，逐张执行
<a id="execution"></a>

<a id="F-LS-08"></a><a id="f-ls-08"></a>**F-LS-08** <a id="D-LS-50"></a><a id="d-ls-50"></a>资产方可以跨提交批次勾选本项目已有效通过、未过期、复核合格、未执行且无重复占用/差异的代币。其他行不可选并说明原因；至少一张，同次不能跨项目，不自动带入未勾选代币。

1. 在原容器核对目标项目、代币、张数、价值及各张截止，同时展示逐张费用预估、费用币种及按币种合计。协议已在审核清单可下载，本步不重复入口。
2. <a id="F-LS-14"></a><a id="f-ls-14"></a>**F-LS-14** 一次“确认并发起入池”同时确认内容和费用，不再重复费用确认。承担方为资产方；平台不收服务费、不代付、不垫付、不返还，执行失败已产生的费用也不退。
3. <a id="D-LS-51"></a><a id="d-ls-51"></a>确认时逐张复核。任一资格、状态、截止或费用变化，指明变化并更新集合/费用，此时任何张都未发起；保留有效选择，由用户确认更新后再执行，不静默剔除、补选或改费执行。
4. 发行平台实际发起后逐张显示处理中，成功发起即关闭容器并定位质押代币清单，不等待全部结果。未发起、取消、费用不足或入口不可用，明确无执行费用、不标处理中，保留原有效申请占用及截止；不确定是否发起则先待核实。

| 实际结果 | 业务变化和反馈 |
| --- | --- |
| 正常成功且资格成立 | 本张已质押，满足有效性等条件才计覆盖；可核对完成时间、费用和成功凭证 |
| 明确失败且确认无占用 | 本张不计覆盖，按当前资格可在本池或其他池新笔申请；显示原因、是否产生费用/金额、下一步。失败通知定位本次动作 |
| 结果未确认 | 本张处理中，不计新增覆盖，不可重押、撤回、提取或重复发起；显示等待时长、已知费用，未知费用标待核实。其他张和项目操作仍按各自资格，不锁整池 |

同次2成1败分别呈现，不回滚成功张、不给批次一个笼统结果；重复点击、刷新或重复提交同次操作不得二次转移或收费。执行成功不另发通知。审核48小时仅用于待审，不能用它把执行未知判失败。见[质押与执行状态图](02-融资需求与代币质押-流程图与状态机.md#st-ls-02)。

<a id="exceptions"></a>

<a id="D-LS-63"></a><a id="d-ls-63"></a>**异常仅联系客服。** 长期未知、已发起跨入池截止或项目终态、事实冲突及混合结果中的待核实笔，提示“执行结果待核实，请联系平台客服人员”，保留业务编号、代币、动作、已知费用和凭证及保护限制。差异代币不计有效覆盖、冻结其新动作并重算。无工单、自动升级、人工改判/补记、强制释放、补偿、换地址或恢复资格流程；不编造联系方式、处理时限。客服介入不等于自动完成、退款或恢复。普通晚到且无跨期/冲突的结果按原笔更新；终态项目晚到转入保留真实持有位置，不恢复项目或覆盖，也不设计自动异常退回。

当前质押状态由借贷平台定义：PS-1 可质押、PS-2 已质押、PS-4 已释放；PS-3为作废编号，PS-0不是合法值。业务释放后尚在合约内为已释放待提取，实际转回原地址且无占用后才按当前资格可质押。执行状态独立为未发起（CT-0）、处理中（CT-1）、成功（CT-2）、失败（CT-3），成功不替代代币有效性及项目资格判断。内部状态号不出现在面客文案。

### 质押业务信息查阅

## 4. 发布与管理融资需求
<a id="publish"></a>

<a id="F-LS-02"></a><a id="f-ls-02"></a>**F-LS-02** 本企业资产方从“融资”办理。建池后发布入口持续可见，但必须已获得实际有效质押。提交时重新核实当前身份和最新额度；项目未到期、未终态，有效质押价值大于0，无另一笔在途需求，金额不超过可融金额才可成功。

| 办理 | 输入与结果 |
| --- | --- |
| 发布 | 必填USD需求金额，正数、最多2位小数，无默认建议金额；必选参考结算币种。办理时展示当场可融金额，不足给出差额。成功生成本轮申请编号，占用在途金额，状态待报价；首次发布确定一年有效期 |
| <a id="F-LS-03"></a><a id="f-ls-03"></a>修改（F-LS-03） | 仅尚未被报价且仍可修改的当前轮；带出金额和参考币种，按最新额度复核本轮更新后的占用，不把原占用重复计算。成功保留轮次编号，已锁定或进入履约的条款不可在此改写 |
| 撤下 | 仅尚未被报价且仍有效的本轮；本容器确认后终结本轮、释放其占用并保留原编号及原因，不清除其他债务或整池质押 |
| <a id="D-FIN-76"></a><a id="d-fin-76"></a>再次发布 | 原需求失效后无冷却；在项目未到期、未终态并重新满足发布条件时创建新轮次、新编号。旧报价/成交记录保留，不重建项目、不重置项目期限、不清除存量债务 |

发布成功关闭弹窗、定位申请清单该行，不自动打开报价；失败保留输入和原因，不回滚已完成质押、不再次收费。首次成功发布之前仍是草稿，对外不可见。见[发布图](02-融资需求与代币质押-流程图与状态机.md#fl-ls-02)。

<a id="FP-30"></a><a id="D-LS-60"></a><a id="d-ls-60"></a>参考结算币种（FP-30）为必填多选，USD（法币）、USDT/USDC（数币）至少一项，可跨类选择，首次默认空；不支持项不能提交。同轮编辑带原值，新轮可带本企业上一轮选择供确认修改并独立留存，历史无值显示“未提供”。它只供参考，不限制机构选择任何已支持报价币种，不决定实际币种、额度或合同。实际结算以成功报价及接受条款为准；本期固定1:1:1及具体结算规则由L6～L8承接。

| <a id="FP-23"></a><a id="fp-23"></a>关闭原因（FP-23） | 枚举 / 系统 | `资产方主动关闭` / `有效期到期` / `全部业务结清`；仅终态展示 |
| <a id="FP-25"></a><a id="fp-25"></a>空池标记（FP-25） | 布尔（派生） / 系统 | `有效质押价值 = 0 且项目处于草稿` 时为 `true`，发布入口不可点并常驻提示 |
| <a id="FP-27"></a><a id="fp-27"></a>本轮需求终结原因（FP-27） | 枚举 / 系统 | `资产方撤下` / `成交` / `项目关闭` / `自动失效 · 覆盖不足`；仅在需求已终结时有值 |
| <a id="FP-28"></a><a id="fp-28"></a>融资申请编号（原需求编号）（FP-28） | 文本 / 系统 | = **项目编号 + 两位轮次序号**，每轮发布成功时生成且终身不变；沿用既有号段，不因展示更名另发号。报价重试不改本轮编号；再次发布生成新轮次。编号不是融资业务编号或放款编号 |

## 5. 查看四类记录与衔接履约
<a id="records"></a>

每类项目记录清单固定每页5条，不提供条数切换，分别保留页码。私有字段始终按本笔当事方授权。全部使用真实编号：项目编号标识池；申请编号为“项目编号＋两位轮次序号”；报价业务、放款、还款期次和还款提交各有自己的稳定编号，不相互替代。代币符号取上游配置，不自造符号；未确定时取合约名称，本期链仅ETH，只展示不提供选择。

| 清单 | 一行及排序 | 展示与查看内容 |
| --- | --- | --- |
| 质押代币 | 一张代币 | 编号、数量/代币符号、签发USD价值、账期、买方、有效/失效。已有公开Hash在编号副行，点击复制完整值，独立图标打开浏览器，无“查看凭证”按钮；不显示合同号/发票号。执行状态仅本企业资产方可见 |
| 融资申请信息 | 一轮申请，发布时间倒序 | 申请编号、本轮金额/币种、申请状态、当前有效或已接受报价的机构/年化利率、本轮发布时间；不能用项目首次发布时间重复填历史行。改额不增行，无有效报价明确空态 |
| 融资放款信息 | 一笔已接受报价业务，接受时间倒序 | 申请编号、业务编号、机构、金额/币种、放款进度。接受即入清单；放款登记成功才有放款编号，之前显示“尚未生成放款记录” |
| 还款信息 | 一笔已确认到账业务，到账确认时间倒序 | 申请编号为主，业务/放款编号关联，三者任一可检索同笔；显示机构、当前应还金额/币种、日期、期次状态及适用逾期提示，结清后保留 |

### 融资申请详情
<a id="application-detail"></a>

按“金额与申请状态 → 需求信息 → 当前报价及授信摘要 → 报价历史 → 协议文件”展示。需求信息含申请/项目标识、企业、本轮金额、参考币种、时间和项目有效期。申请状态保留待报价、已报价待确认、放款中、已放款、已失效/已关闭五类事实展示，终结同时说明原因；不拼入还款逾期或结清状态，不新增一套申请审批。

只展示当前有效或已接受的一笔报价；历史默认折叠，每条展开自身条款，不替换当前报价、不提供恢复或接受旧报价动作。授信摘要仅当前报价机构对企业的总授信和已用授信，不等于本项目额度，不常驻历次授信/追加明细，不增加“授信详情”快捷入口。预计还款计划在报价区按需看，明确“预计·未生效”，接受前可读。报价和授信的完整条款见[授信报价PRD](../v1.0-借贷广场-授信报价与接受拒绝/01-授信报价与接受拒绝-PRD.md)。

协议用表格，已有文件按名称、用途、业务/版本及已有上传时间展示；点击文件下载。当前适用版本与历史版本可辨，同文件在放款详情复用，不生成另一份事实。无文件、无权、读取失败分别反馈，不新增签署或审核。

### 放款与还款详情
<a id="fulfilment"></a>

放款详情先说明金额、阶段和当前处理方，再展示放款信息、凭证/Hash、已有定义账户、适用协议；申请编号仅展示，无跨业务跳转或嵌套申请详情。待放款、暂缓、待重传、待确认、确认超期及终止原因沿[放款PRD](../v1.0-借贷广场-放款与放款确认/v1.0-借贷广场-放款与放款确认-PRD.md)。**资产方确认到账后，放款列表显示“已放款”并保持；后续还款、逾期或结清归还款列表。** 终止不冒充成功，登记不等于到账。

还款详情展示本期应还/待确认摘要、定稿计划（一期一行）、账户及还款/确认记录；选期仅办理本期。正式计划生成中、不存在待还期次或已全部结清分别说明，不填虚假金额，不拿预计计划充正式计划，不回滚到账事实。期次、金额、期限及办理资格见[还款PRD](../v1.0-借贷广场-还款计划与还款确认/l8-repayment-prd.md)。只在进入还款的成交笔中申请/业务/放款编号为1:1:1，报价阶段可先后多笔；期次编号与一次成功还款提交编号分别识别。

放款收款账户属资产方，由接受报价时确认、放款沿用；还款收款账户属资金方，由放款登记确定、还款沿用。本期不新增双方出账账户必填，不把付款账户默认等同其收款账户；原有付款凭证保留。文件与账户不因新增清单而公开。

## 6. 撤回、业务释放与自助提取
<a id="withdraw"></a>

<a id="F-LS-06"></a><a id="f-ls-06"></a>**F-LS-06** 本企业资产方从“质押—解除质押”统一进入，区分已失效、有效抵押物、已释放待提取三区。撤回和提取不走运营审核；执行仍需确认费用，由发行平台转回**质押前原持有地址**，不能人工指定其他地址。见[解除质押图](02-融资需求与代币质押-流程图与状态机.md#fl-ls-03)。

| 对象 | 准入与结果 |
| --- | --- |
| 有效抵押物 | 撤回后仍须“剩余有效质押价值×80% ≥ 项目融资余额＋项目在途金额”。有效区常驻可撤回上限，勾选实时累计；提交以最新值校验。有在途报价本身不阻止符合额度的撤回 |
| 已失效代币 | 已不计覆盖，撤回无需额度判定；仍受真实占用、执行中和差异保护，不因失效绕过安全条件 |
| <a id="F-LS-17"></a><a id="f-ls-17"></a>已释放待提取（F-LS-17） | 项目实际关闭/结清时即时解除池内业务关系，零费用、无链上动作；之后资产方自助提取，可批量、自己付费、无时间限制。未提取不属于任何池、不计覆盖且不能再质押 |

撤回超限必须显示拟撤回价值、当前上限、差额，并给出减少勾选/等待还款释放余额两条路径。额度不足的对应动作可见不可点并说明原因，不能隐藏整个入口而妨碍有资格的失效代币撤回或待提取操作；游客/非本方无私有动作。

正常撤回实际发起即预扣该张有效价值，并发报价按扣后池值判断。明确失败保持在池、撤销预扣并重算；成功按真实转出移出池，不先假报已释放。提取失败仍已释放待提取，不恢复池占用；成功确认转回原地址。记录保留实际凭证、时间、费用和原因；未知/冲突按第3章联系客服与保护，不自动重试。

有待提取代币，入口提示张数和金额，明确自付费用、可批量、不自动回钱包。每次提交前告知张数与预估费用；24小时提交超过5次提示频繁操作费用较多，不硬性阻断。单笔业务结清只降低项目融资余额、提高可撤回上限，不自动释放“对应代币”。

## 7. 覆盖变化、需求失效与通知
<a id="coverage"></a>

发行平台判代币失效或后台标记持仓差异后，先从有效质押价值排除并权威重算，再判现有需求和债务覆盖。代币失效不自动转出，产生既有运营待办，可由资产方按上章清出；差异保护不新增异常处置队列。

| 当前情况 | 判据及用户结果 |
| --- | --- |
| 覆盖有余 | 融资上限足以覆盖项目融资余额及在途，且可融金额大于0；按资格正常办理 |
| 覆盖持平 | 已有占用仍满足覆盖，可融金额为0；不新增发布，有效抵押物可撤回上限为0；原有效申请报价按已有覆盖及授信条件，不一概禁止 |
| 覆盖不足 | 融资上限小于项目融资余额，即已存在债务本身不足；禁止新增占用并触发覆盖提醒 |

**需求失效与债务提醒是两种事实。** 新增准入比较“项目融资余额＋项目在途金额”，债务提醒只比较“项目融资余额”。需求失效后可能债务仍被覆盖；无在途需求时债务仍可能不足。

<a id="invalidation"></a>

<a id="F-LS-19"></a><a id="f-ls-19"></a>**F-LS-19** 需求重算后不能满足占用覆盖时，立即按发布时间倒序使最小必要的需求失效，每失效一笔释放其在途并重算；满足即停止。等价校验为：按发布时间正序保留较早需求，对每笔比较“融资上限－项目融资余额－更早已保留金额”是否足够。本期单一在途需求仍遵守此口径，不借多笔兜底规则开放并行发布。无需求可失效而仍不足就停止，保留债务提醒，不空转。

<a id="D-FIN-75"></a><a id="d-fin-75"></a>该轮需求与在途报价在同一事实变更内失效，用户不能看到需求失效而报价仍可接受。记录原编号及“自动失效·覆盖不足”终结原因，不新增项目状态、缓冲期或补质押倒计时；原轮不可恢复，满足资格可立即新轮发布。通知只由L5发送，L6不为同一覆盖原因再发一封报价失效信。见[需求失效图](02-融资需求与代币质押-流程图与状态机.md#fl-ls-04)。

<a id="F-LS-16"></a><a id="f-ls-16"></a>**F-LS-16** 覆盖不足时显示缺口＝项目融资余额－融资上限，以及需追加资产价值＝缺口÷80%。资产方项目/控制台有提示、待办和追加入口，明确“追加质押先审核，提交不即时生效”；债权机构可见缺口及触发时间，平台运营有既有待办与监控。广场向游客和全部资金方公开中性覆盖事实。条件反转自动解除，无需人工确认；触发与解除保留时间、当时有效质押价值/融资上限/项目融资余额、诱因及解除时间。见[覆盖提醒图](02-融资需求与代币质押-流程图与状态机.md#fl-ls-06)。

主动通知仅八类：审核通过、驳回、48小时审核超时（运营审核模块唯一发送）；明确执行失败、需求自动失效、覆盖不足及解除、项目届满前7天（L5唯一发送）。执行未知、链上成功、可提取、许可过期及持续不足不新增消息；页面事实始终可查。收件范围、去重、原对象落点和17对双语模板统一见[通知册](03-融资需求与代币质押-消息通知.md)，多成员项目通知账号仍待确认。

## 8. 共用体验、来源与真实依赖
<a id="quality"></a>

| 项目 | 既定要求 |
| --- | --- |

<a id="F-LS-13"></a><a id="f-ls-13"></a>**F-LS-13** 控制台、资产广场及消息可定位项目和原申请/业务/期次，终态仍可寻址。保留既有建池、详情、追加、解除质押、发布、提取、审核确认入口的含义；只打开一个适当容器，绝不自动勾选执行。每次重新核验权限和阶段：已完成/失效显示该对象当前事实及原因，不跳新轮、不白屏或静默回首页。草稿仍不暴露存在性，非本方不得打开私有操作层。来自控制台保留返回对应位置入口，非该来源不显示。资产广场可单向进入项目，本模块不新设反向入口。
