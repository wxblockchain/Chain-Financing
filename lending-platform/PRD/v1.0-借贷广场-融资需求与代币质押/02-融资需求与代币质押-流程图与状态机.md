```mermaid
flowchart TD
  A0["资产方创建融资项目<br/>项目名称 + 本企业已有代币类型<br/>+ 代码层面维护的平台默认SPV机构名称"] --> A1["创建成功即进入项目详情<br/>私有草稿 · 空池 · 零费用 · 无审核<br/>发布不可提交，可随时关闭"]

  F --> G["资产方打开代币清单，一行一张<br/>同项目不同提交的合格代币可一起勾选"]
  G --> H["核对项目、代币、逐张费用和合计<br/>一次确认并发起入池"]
  H -- "资格或费用变化，尚未发起" --> I["指明变化张，更新集合与费用<br/>留在本次办理内，由用户确认新集合"]
  I --> H
  H -- "取消、费用不足或未实际发起" --> J["本次无执行费用，原审核与截止保留"]
  H -- "资格有效且用户明确确认当前集合" --> K["发行平台实际执行选中张<br/>逐张处理中，不计覆盖，不重复执行<br/>发起成功即结束本次办理，回到质押代币清单"]
  K --> L{"本张真实执行结果"}
  L -- "正常成功且当前资格成立" --> M["PS-2，符合有效性等资格才计覆盖"]
  L -- "明确失败且无占用" --> N["本张失败，PS-1，按资格可新笔申请"]
  L -- "结果未知" --> O["显示等待与已知费用，提示联系平台客服<br/>不套审核48小时，不自动失败释放或异常处置"]
  L -- "跨期或冲突" --> O
  F -- "七天到期仍未发起" --> P["本笔许可失效，原审核保留<br/>未执行零费用，协议存档"]
  M --> Q["逐币结果可见，不回滚其他成功张<br/>项目按实际覆盖可发布"]
  N --> Q
```

项目创建与代币质押是两件事：创建不提交申请、不收费，也不因长期未质押自动关闭项目；空池草稿数量本期不设上限，不做创建拦截。审核48小时、通过后UTC七个自然日和执行等待互不替代。已发起跨期、未知或冲突保留事实与保护并联系客服；不据晚到转入恢复终态项目或有效覆盖。

```mermaid
  S_FP_5 --> [*]
```
