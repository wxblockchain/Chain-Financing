flowchart TD
  A0["资产方创建融资项目<br/>名称 + 代币类型 + 自填质押率 + 自填项目期限<br/>+ 参考结算币种，核对还款方式与SPV机构名称"] --> A1["提交审核 · 项目待审核<br/>私有、不可质押、不可发布、零费用、无链上动作"]
  A1 --> A2{"管理端核对创建信息"}
  A2 -- "退回并给出面客可读原因" --> A3["项目已退回<br/>资产方可修改后重新提交<br/>项目期限不重新起算"]
  A3 --> A1
  A2 -- "通过 · 由平台统一钱包部署质押合约" --> A4{"部署结果"}
  A4 -- "签名或部署失败" --> A5["视为审核未完成，仍为待审核<br/>由管理人员再次发起，不需要资产方重提<br/>部署 gas 由管理端承担"]
  A5 --> A2
  A4 -- "部署成功 = 审核通过" --> A6["项目可用 · 产生唯一质押合约地址<br/>空池：可质押、暂不可发布"]
  A6 --> A["资产方在项目详情勾选代币<br/>按本项目代币类型过滤，整张勾选"]
  A --> H["核对项目、代币与预估 gas<br/>告知：本次发生链上操作、需本人签名、gas 自担且失败不退"]
  H -- "资格变化，尚未签名" --> I["指明变化张，更新集合与预估 gas<br/>留在本次办理内，由用户确认新集合"]
  I --> H
  H -- "取消签名、钱包不可用或未发起" --> J["本次无链上操作、无 gas，代币保持可质押"]
  H -- "用户签名发起" --> K["资产方地址向本项目质押合约转入<br/>逐张处理中，不计任何额度"]
  K --> L{"本张真实上链结果"}
  L -- "明确失败" --> N["本张未进入合约，保持可质押<br/>显示原因与已产生 gas，可重新发起"]
  L -- "结果未知、跨期或冲突" --> O["显示等待与已知 gas，提示联系平台客服<br/>不自动失败释放，不重复发起"]
  L -- "明确成功" --> M["代币进入质押合约 · PS-2<br/>计入待审质押额，暂不计入有效质押额"]
  M --> C["运营逐笔审核 · 无时效管控<br/>不因等待自动通过或自动失败"]
  C -- "本笔通过" --> P["计入有效质押额，参与覆盖判断<br/>从待审质押额移出；协议与审核人可查"]
  C -- "本笔驳回" --> Q["原因原文可见；代币仍在合约内<br/>继续计入待审质押额，须自助解押取回"]
  C -- "裁定前资产方自助撤回" --> R["资产方签名向合约发起解押<br/>gas 自担；本笔终结为已撤回"]
  Q --> S["自助解押取回原持有地址<br/>无占用后恢复可质押"]
  R --> S
  P --> T["项目按实际有效质押额可发布融资需求"]
```

三条判断相互独立：项目审核决定项目能不能用，上链结果决定代币在不在合约里，逐笔审核决定这张算不算有效质押额。全链路没有任何时限——项目审核与逐笔质押审核都不因等待自动改变结论，上链等待也不设截止。空池项目数量本期不设上限，不做创建拦截。未知或冲突保留事实与保护并联系客服；不据晚到转入恢复终态项目或有效覆盖。

  S_FP_4 --> S_FP_2: 项目未到期未终态、按全部剩余事实满足资格并发布
  S_FP_4 --> S_FP_6: 全部融资业务结清 · 释放全部质押
  S_FP_1 --> S_FP_5: 资产方主动关闭
  S_FP_2 --> S_FP_5: 主动关闭 或 到期且无在途与未结清业务
  note right of S_FP_4
    单笔业务无中途终止出口
    在途占用只在放款确认时转为融资余额
    其他存量继续履约
    已到期不恢复新融资资格
    不因某笔停在待放款而回募集中或释放整池
  end note
  S_FP_5 --> [*]
  S_FP_6 --> [*]
```

可用状态包含尚未质押的空池项目；空池不自动转移状态，也不自动关闭。待审核与已退回都不出现在广场、不可质押、不可发布，且都可由资产方主动关闭。项目有效期自创建时间起算，退回重提不重新起算。到期是并行标记，存量继续履约。单笔业务没有中途终止出口，其在途占用只在放款确认时转为项目融资余额；全部剩余事实满足资格才可再发布，终态不恢复。
