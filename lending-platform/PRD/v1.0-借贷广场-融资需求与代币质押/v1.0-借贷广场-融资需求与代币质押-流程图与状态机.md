## 1. 流程图

### `FL-LS-01` 建池与首笔质押（跨平台）

> 关联：`F-LS-01`、`F-LS-12`、`F-LS-21`、`D-FIN-60`、`D-FIN-80`～`D-FIN-82`、`D-LS-29`～`D-LS-33`、`D-LS-47`、`E-1`/`E-2`/`E-5`/`E-13`/`E-16`。正文见分册 01 [9.1](01-功能需求说明.md#91-p-ls-03-创建融资项目建池) 与 [9.4](01-功能需求说明.md#94-代币质押面客端全链路)。追加质押走同一条链路，区别只在入口与 `PA-04` 申请类型。

```mermaid
flowchart TD
  A["资产方创建或进入当前项目<br/>从可质押清单批量勾选代币"] --> B["提交成功：每张生成独立申请<br/>零费用，批次仅供追溯"]
  B --> C["项目草稿可续做，统计不增加<br/>运营逐笔审核"]
  C -- "本笔驳回或待审撤回" --> D["本笔原因与记录保留<br/>解除本笔占用、零费用，可按资格重提"]
  C -- "提交成功后连续 48 小时仍待审" --> E["本笔质押失败：审核超时<br/>释放申请占用、零费用、无提取动作"]
  C -- "本笔通过" --> F["审核清单可下载本笔协议<br/>同抽屉详情查看审核人、时间与七天截止<br/>不等待同批其他笔"]
  F --> G["资产方打开代币清单，一行一张<br/>同项目不同提交的合格代币可一起勾选"]
  G --> H["同一抽屉核对项目、代币、逐张费用和合计<br/>不再放协议下载按钮<br/>一次确认费用并发起入池"]
  H -- "资格或费用变化，尚未发起" --> I["指明变化张，更新集合与费用<br/>留在同一抽屉，由用户确认新集合"]
  I --> H
  H -- "取消、费用不足或未实际发起" --> J["本次无执行费用，原审核与截止保留"]
  H -- "资格有效且用户明确确认当前集合" --> K["发行平台实际执行选中张<br/>逐张处理中，不计覆盖，不重复执行<br/>发起成功即关闭抽屉，定位质押代币清单"]
  K --> L{"本张真实执行结果"}
  L -- "成功" --> M["PS-2，符合有效性等资格才计覆盖"]
  L -- "明确失败且无占用" --> N["本张失败，PS-1，按资格可新笔申请"]
  L -- "结果未知" --> O["显示等待与已知费用<br/>不套审核 48 小时，不自动失败释放"]
  F -- "七天到期仍未发起" --> P["本笔许可失效，原审核保留<br/>未执行零费用，协议存档"]
  M --> Q["逐币结果可见，不回滚其他成功张<br/>项目按实际覆盖可发布"]
  N --> Q
```

本图区分审核 48 小时、每笔通过后的七天许可与链上执行等待。查看或编辑不重置审核时钟；同批已处理笔不受超时影响。已发起跨期及执行长期未知见 Q-LS-07 / 08；本期无异常释放流程。验收见分册 02 AC-LS-127～136。

```mermaid
flowchart TD
  A["资产方 · 打开解除质押合并入口"] --> B["单抽屉分三区展示<br/>已失效 · 有效抵押物 · 已释放待提取"]
  B --> C{"这张代币属于哪一区"}
  C -- "已失效" --> D["不做任何额度判定，直接放行"]

  E -- "否" --> F["拒绝并给出三个数<br/>拟撤回价值 · 可撤回上限 · 差额<br/>并给两条出路"]
  E -- "是" --> D
  C -- "已释放 · 待提取" --> G["提取路径 · 不做额度判定<br/>业务已在项目终态时释放完毕"]
  D --> H["本平台 · 发起解除质押执行<br/>撤回路径立即预扣该部分价值"]
  G --> H
  H --> I["代币发行平台 · 承担链上执行<br/>转回质押前的原持有地址"]
  I -.-> J{"按张回写结果"}
  J -. "成功 · 撤回" .-> K["移出池，PS-4 已释放<br/>派生量重算"]
  J -. "成功 · 提取" .-> L["回到资产方地址，PS-1 可质押"]
  J -. "失败 · 撤回 E-3" .-> M["回到 PS-2 在池，预扣撤销<br/>可重试"]
  J -. "失败 · 提取 E-4" .-> N["保持 PS-4 待提取<br/>不影响任何项目额度，可重试"]
```

| 谁 | 负责什么 | **不负责什么** |
| --- | --- | --- |
| **借贷平台（本模块）** | 业务决策：谁能质押、哪几张、进哪个池、算不算进覆盖、额度够不够、结果怎么呈现；质押事实的权威与回写 | 不执行链上动作、不持有代币事实、不托管代币、不自建上架闸门 |

| **运营端 WS-359** | 每张本次申请的独立审核结论、协议与留痕 | 不代发起链上执行、不改清单；同批各笔允许不同结论 |
| **只读代币域（资产广场）** | 代币候选来源与代币事实展示 | 不判定可质押性、不持有质押状态 |

| 说明 | 口径 |
| --- | --- |
| **并行标记不是状态** | 「已到期 · 存量处理中」是 `FP-05` 并行标记，不新增状态；该标记必须**按正常状态呈现**（中性样式），不得做成告警（`D-FIN-47`） |
| **终态仍有动作** | `S-FP-5`/`S-FP-6` 下「追加质押」「关闭项目」不可点，但**「解除质押」仍可用**——未提取的代币还在合约里（`D-FIN-57`） |
| **需求不是独立对象** | 融资需求没有自己的状态机；对外 5 值是同一批事实的展示视角，映射由本平台派生下发（分册 01 11.6） |

### `ST-LS-02` 代币在本平台的质押状态机 `PS-*` 与链上执行轴 `CT-*`

> 关联：`PS-1`/`PS-2`/`PS-4`、`CT-0`～`CT-3`、`D-LS-22`～`D-LS-25`、`D-LS-30`～`D-LS-33`、`D-LS-47`、`D-FIN-54`、`E-1`～`E-5`。正文见主册 5.1、5.3 与分册 01 9.4.5。
>
> **两根正交轴**：`PS-*` 回答"这张在不在池里"（权威在本平台）；`CT-*` 回答"链上这一步走到哪"（由代币发行平台按张回写）。**审核态不在这张图上**——它挂在质押申请上（`ST-LS-03`）。**代币自身是否失效是第三根独立的轴，取只读代币域的代币状态，不在本图。**

```mermaid
stateDiagram-v2
  PS_1: PS-1 可质押 · 在资产方地址
  PS_2: PS-2 已质押 · 在质押合约 · 池内
  PS_4: PS-4 已释放 · 不再计入覆盖
  PROC: 质押处理中 · CT-1 · 不计入覆盖
  [*] --> PS_1
  PS_1 --> PROC: 审核通过并确认后发起转入 · CT-1
  PROC --> PS_2: 该张执行成功回写 · CT-2
  PROC --> PS_1: 该张执行失败回写 · CT-3 · E-1
  note right of PROC
    无明确结果不自动失败或释放
    审核 48 小时不适用于执行
    长期未知收口见 Q-LS-07
  end note
  PS_2 --> PS_4: 撤回通过额度判定且转出成功
  PS_2 --> PS_4: 失效代币撤回 · 不做额度判定
  PS_2 --> PS_4: 项目关闭或结清 · 业务即时释放 · 链上待提取
  PS_2 --> PS_2: 撤回执行失败 · 预扣撤销 · 保持在池 · E-3
  PS_4 --> PS_1: 自助提取成功 · 回到资产方地址
  PS_4 --> PS_4: 提取执行失败 · 保持待提取 · E-4
```

| 说明 | 口径 |
| --- | --- |
| **计入覆盖的充要条件** | **审核通过 且 转入执行成功回写**（`D-FIN-82`）。处理中、审核期、失败、对账差异、撤回预扣一律不计入 |
| **按张独立结算** | 同一次确认的多张代币各自沿本图走，**互不牵连**：一张走到 `PS-2`、另一张回到 `PS-1` 是正常结果（`D-LS-30`） |
| **`PS-0` 非法** | 值域只有 `PS-1`/`PS-2`/`PS-4`，`PS-3` 作废占位（`D-LS-23`）；编号不透出对外面（`D-LS-25`） |
| **无新增代币冻结状态** | 额度冻结仍在项目维度；执行中或差异张的操作限制只是业务保护，不新增 PS 枚举 |

### `ST-LS-03` 质押申请状态机 `PA-05`

> 关联 PA-05、PA-11～15、D-LS-33 / 48～51、D-FIN-81 / 84。正文见 [功能 9.4](01-功能需求说明.md#94-代币质押面客端全链路) 与 [11.3](01-功能需求说明.md#113-质押申请与逐笔审核事实pa-权威方借贷平台)。主体为一张代币本次的单笔申请，审核状态不写回代币本体。

```mermaid
stateDiagram-v2
  SUBMIT: 待审核
  APPROVED: 通过
  REJECTED: 驳回
  CANCELED: 已撤回
  TIMEOUT: 质押失败（审核超时）
  [*] --> SUBMIT: 提交成功形成单笔，零费用
  SUBMIT --> REJECTED: 截止前本笔有效驳回，原样原因
  SUBMIT --> CANCELED: 待审时资产方有效撤回
  SUBMIT --> TIMEOUT: 提交成功起连续 48 小时仍待审，自动失败
  SUBMIT --> APPROVED: 截止前本笔有效通过，独立七天期限
  APPROVED --> [*]
  REJECTED --> [*]
  CANCELED --> [*]
  TIMEOUT --> [*]
  note right of APPROVED
    仅终结本笔审核轴
    审后许可、复核、执行分别记录
    通过不等于执行成功
    可跨提交批量确认，不等全批审完
  end note
```

| 说明 | 口径 |
| --- | --- |
| 审核与执行分开 | PA-05 与 WS-359 RV-20 同源；许可过期、复核作废、执行成功或失败均不改写人工通过。详情用 PA-15 / PA-10 展示后续情况 |
| 清单按代币 | 当前项目一行一张当前代币，可跨提交选择合格笔；批次只留追溯，不是一个审核对象或执行门槛 |
| 超时释放 | 只释放仍待审笔申请占用，代币未转入，保持 / 恢复 PS-1、零费用，无 X-05 或待提取；已处理笔不回退 |
| 重新提交 | 生成新单笔，旧笔留在该代币历史；不翻转旧超时、驳回或撤回记录 |
| 范围 | 异常释放本期不考虑；正常已入池撤回、终态业务释放和提取仍见 FL-LS-03 |
