# 借贷平台 · 字段命名与术语对照表

14 册 PRD 共用一套业务名称。本表是 R19 字段表述优化的前置基线：**先在这里确定名称与释义，各册再按本表落地**，避免同一业务量在不同册出现两种叫法。

**使用规则**

- 本表只规定**业务名称、英文对照与释义**。**编号锚点一律不动**——14 册靠 `FP-09` 这类锚点交叉引用，改号会使全库引用失效。更名时正文写“业务名称（编号）”，编号保持原值。
- 一个业务量只能有一个现行名称。旧名称进“原名”列备查，正文不再使用；确需说明沿革时只在该量的定义处写一句“原名 X，口径不变”。
- 废止的名称进最后一节，任何册都不得再出现，包括界面文案、消息模板与验收。
- 新增或更名先进本表，再改各册；本表与某册冲突时以本表为准，业务口径仍以该量所属册的定义为准。
- 英文取国际金融业务常用表述，不逐字直译；已在用且无歧义的英文不重译。

## 4. 本批废止的名称

以下名称随业务规则取消而废止，任何册的正文、界面文案、消息模板与验收都不得再出现；对应编号锚点保留在原位并标注废止，不分配给新含义。

| 废止名称 | 原编号 | 废止原因 |
| --- | --- | --- |
| 质押失败（审核超时） | `PA-05` 原取值、`N-LS-03`／`T-LS-03` | 质押审核 48 小时时效取消，不再存在超时结论 |
| 审核截止 / 入池截止 | `PA-14` | 审核无时效管控，通过后也不再有入池许可与截止 |
| 审核通过·待入池（Approved · pending deposit） | 原术语 | 链路反转后上链发生在审核之前，不存在“待入池”阶段 |
| 入池有效期（Deposit window） | 原术语 | 同上 |
| 发起前复核 | `PA-08` | 不存在待执行许可，无可复核对象 |
| 已融额度 = 可融额度 + 在途额度 | 原公式 | 随本批额度命名作废；已融额度仍等于项目融资余额 |
| 收款人名称 | 各册账户字段 | 平台不再采集与校验，法币与数币账户均取消 |
