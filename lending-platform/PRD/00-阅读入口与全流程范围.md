| 业务 | 主定义及衔接 |
| --- | --- |
| 项目、融资申请与质押 | L5定义项目资格、申请发布及逐张质押事实；运营审核规则读取对应质押审核模块 |
| 企业授信、报价与接受拒绝 | L6定义授信期限、固定USD/USDT/USDC 1:1:1折算和逐笔快照、报价及付款业务资料；接受后交给L7 |
| 放款登记与到账确认 | L7定义合同、付款账户、凭证、重传和确认；终止单笔不直接恢复整项目资格，确认后衔接L8 |
| 计划、还款信息录入与确认 | L8定义预计/定稿计划、各期应还日00:00 UTC开放录入、提交与确认、逾期标记及结清 |
| 项目终态释放与正常提取 | L5定义项目终态和提取；单笔融资结清不等同整池释放，执行异常按最新客服边界处理 |
| 关键站内信 | 各模块独立通知册定义事件、发送责任和接收范围，结合两端消息框架读取；控制台及消息中心不据此新增独立业务事件 |
