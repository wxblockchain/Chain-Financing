# 登录主干与资产方 SSO 接入 · 流程图与状态机

图仅表达业务流程和状态；具体分支、字段与验收统一见[主 PRD](./00-登录主干与资产方SSO接入-PRD.md)。资金方节点仅表示 资金方账户模块的接续边界。

<a id="flow-1"></a>
## 图 1 · 从游客浏览到恢复原操作

对应[入口](./00-登录主干与资产方SSO接入-PRD.md#F-L02)与[返回](./00-登录主干与资产方SSO接入-PRD.md#F-L04)。

```mermaid
flowchart TD
    G["游客浏览：默认资产广场"] -->|顶部登录| P["整页身份选择"]
    G -->|受限操作| C["原页身份弹层，保留操作意图"]
    P --> R{"明确选择身份"}
    C --> R
    R -->|资产方| L["离站确认：资产可信平台"]
    L -->|取消| O["回原载体，恢复焦点和浏览上下文"]
    L -->|确认| A["资产方授权及协议，见图 2"]
    R -->|资金方| W["直接连接钱包"]
    W -->|取消或不可用| O
    W -->|连接成功| F["资金方：用户明确签名后完成登录"]
    F -->|首次建号| B["先进入机构注册引导"]
    B --> NEXT{"前置条件满足后的有效原目标"}
    F -->|老用户| NEXT
    A -->|完成登录及必需协议| NEXT
    NEXT -->|无或不允许| M["资产广场；无效返回给中性提示"]
    NEXT -->|有效| Q{"当前资格允许原动作吗"}
    Q -->|是| BACK["回原触发点并恢复操作"]
    Q -->|否| GUIDE["受限引导，不执行业务"]
    GUIDE -->|前往上游补齐| L
```

取消登录不执行原业务；跨平台返回未满足对端确认时按资产广场兜底，不阻止本身符合条件的授权登录。

<a id="flow-2"></a>
## 图 2 · 授权结果与必需协议

对应[授权与协议](./00-登录主干与资产方SSO接入-PRD.md#F-L25)。两个授权发起入口共用此流程。

```mermaid
flowchart TD
    START["授权返回，立即显示处理中"] --> AUTH{"本次身份可信、有效且稳定标识可用"}
    AUTH -->|否| FAIL["不建立新登录；中性错误及继续/重试出口"]
    AUTH -->|是| ACTIVE{"上游账户可用"}
    ACTIVE -->|否| BLOCK["不建新登录，结束该主体旧登录；就地游客视图"]
    ACTIVE -->|是| ACCOUNT{"本平台账户建立或更新成功"}
    ACCOUNT -->|否| ERROR["唯一建号失败页：重试、游客继续"]
    ACCOUNT -->|是| SIGNIN["建立当前账户登录，隔离不同旧账户"]
    SIGNIN --> AGREED{"已同意当前必需协议"}
    AGREED -->|是| LAND["按图 1 返回与资格规则继续"]
    AGREED -->|否| RESTRICT["受限登录：仅协议页、正文及退出"]
    RESTRICT -->|同意成功| LAND
    RESTRICT -->|加载或保存失败| RETRY["就地可重试，仍受限"]
    RETRY --> RESTRICT
    RESTRICT -->|拒绝或关闭| GUEST["结束受限登录，恢复合法游客浏览"]
    ERROR -->|游客继续| GUEST
    ERROR -->|重试| START
```

普通授权失败不结束与本次失败无关的有效登录；原页游客不可读的数据仍不可读。协议阅读不代替同意。

<a id="flow-3"></a>
## 图 3 · 资产方登录状态

对应[退出与失效](./00-登录主干与资产方SSO接入-PRD.md#F-L27)。

```mermaid
stateDiagram-v2
    [*] --> 游客
    游客 --> 协议受限: 授权成功但必需协议未完成
    游客 --> 正常登录: 授权成功且协议已完成
    协议受限 --> 正常登录: 同意成功
    协议受限 --> 协议受限: 阅读或失败重试
    协议受限 --> 游客: 拒绝、关闭或登录失效
    正常登录 --> 游客: 主动退出
    正常登录 --> 游客: 登录到期
    正常登录 --> 游客: 上游退出
    正常登录 --> 游客: 上游账户锁定或禁用
```

退出均就地降为游客且解释原因，不自动弹登录；主动退出不退出上游，只有账户菜单提供主动出口。上游退出联动须在 60 秒内结束对应登录，含告知失败兜底。

<a id="flow-4"></a>
## 图 4 · 认证资格与发起融资

对应[状态与资格](./00-登录主干与资产方SSO接入-PRD.md#F-L29)。必需协议先完成；申请审核进度不代替当前有效综合认证。

```mermaid
flowchart TD
    S{"登录有效且已完成必需协议"} -->|否| OUT["游客或协议受限，按各自访问范围"]
    S -->|是| V{"当前有效综合结论为已认证"}
    V -->|否或未知| UNVERIFIED["未认证资产方：可浏览、本人账户及消息；受限动作给引导"]
    V -->|是| VERIFIED["已认证资产方"]
    UNVERIFIED -.->|确认已认证并刷新| VERIFIED
    VERIFIED -.->|确认认证失效，页面说明及图 6 通知| UNVERIFIED
    VERIFIED -->|发起融资申请| WAIT["正在确认资格，不重复发起"]
    WAIT --> CHECK{"当前登录、认证及原操作仍有效"}
    CHECK -->|是| GO["允许继续融资申请"]
    CHECK -->|已未认证| UNVERIFIED
    CHECK -->|无法确认| RETRY["申请尚未发起，可重试"]
    RETRY --> WAIT
    CHECK -->|退出、过期、换身份或离页| STOP["丢弃旧操作结果，不恢复权限或旧页面"]
```

## 图 5 · 本人资料与偏好

对应[本人账户与企业信息](./00-登录主干与资产方SSO接入-PRD.md#F-L32)。

```mermaid
flowchart TD
    MENU["正常资产方登录的账户菜单"] --> P["账户设置 / 企业信息"]
    P --> OWNER{"本人账户及当前有效企业归属可确认"}
    OWNER -->|否| DENY["不展示他人或待审主体资料；保留可达出口"]
    OWNER -->|是| LOAD{"读取结果"}
    LOAD -->|有值| SHOW["只读显示获准信息"]
    LOAD -->|确实缺失| EMPTY["可选项隐藏；整组空态保留上游查看出口"]
    LOAD -->|失败| FAIL["失败说明及重试，不伪装空数据"]
    P -->|上游查看/修改| LEAVE["离站确认；取消返回原页和焦点"]
    P -->|语言改选| SAVE["选择即保存，锁定该项"]
    SAVE -->|成功| OK["生效并反馈，后续回显最后成功值"]
    SAVE -->|失败| ROLLBACK["选项与生效值恢复旧值，可重试"]
    P --> NOTICE["关键通知始终接收；无可选事件，无可操作开关"]
    B["已有业务需要上游信息"] --> AUTO["自动取得该业务必要字段，按已有角色可见"]
    AUTO --> NEED{"必要信息及主体有效"}
    NEED -->|是| USE["继续相应业务，不开放整份档案"]
    NEED -->|否| LIMIT["仅限制依赖动作，说明并保留返回及适用重试"]
```

退出、换账户或离页后，旧资料/操作结果不得恢复旧身份或页面；未成功保存无草稿，已成功值不因离页撤回。资料多少不决定认证资格。

<a id="flow-6"></a>
## 图 6 · 认证资格失效站内信

对应[独立消息通知](./08-登录主干与资产方SSO接入-消息通知.md#event)。

```mermaid
flowchart TD
    V["取得上游当前有效综合认证结论"] --> CHANGE{"确认由有效已认证变为非已认证"}
    CHANGE -->|否或无法确认| NONE["不发认证失效消息；资格/异常按原规则处理"]
    CHANGE -->|是| APPLY["立即应用降级及页面说明"]
    APPLY --> SAME{"同次变化已通知"}
    SAME -->|是| KEEP["不新增、不置顶、不恢复未读"]
    SAME -->|否| SEND["一条强制站内信，仅受影响资产方本人"]
    SEND --> READ["合法访问后阅读历史告知"]
    READ --> TARGET["按当前权限查看本平台账户；不重放旧资格"]
```

降级不等待通知成功；持续未认证不催促，恢复后再次真实失效是新事件。资金方和运营人员不接收本模块事件。
