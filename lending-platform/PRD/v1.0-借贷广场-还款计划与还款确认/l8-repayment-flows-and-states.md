## L8-F01 · 计划形成与阅读入口

返回：[功能 §3.1/§3.2](l8-repayment-prd.md#f-plan)。计划未生成时不回退放款事实；初始计划不进入还款区。

```mermaid
flowchart TD
  A[报价成功形成预计未生效计划] --> B[接受前明确日期将重算]
  B --> C[完成放款及资产方确认到账]
  C --> D[放款清单显示已放款；还款清单按FD入列]
  C --> N[通知资金方确认事实，计划未就绪不称已生成]
  D --> E{定稿计划完成？}
  E -->|否| F[显示生成中，保留确认及债务事实]
  F -->|恢复| E
  E -->|是| G[以放款提交UTC日期起息，沿本笔快照形成计划]
  G --> H[清单详情只读查看本期、计划、账户及记录]
  G --> I[右侧按日期、机构和放款编号下拉选择业务]
  I --> J[按角色与期次开放条件进入录入或确认操作]
  J --> K[带入同笔同期期次及账户；计划默认折叠原位展开]
  K --> L[保留必要最终确认，成功更新本笔不自动开详情]
  P[无还款业务] --> Q[保留清单及操作区空态，不伪造待办]
```

访客只读公开信息，操作区仅“立即登录”；非当事方不能读取双方私有资料。全部已结清的业务保留清单行与只读详情、计划入口。未到期、待确认或计划生成中也可查看对应事实，无待还期次不虚构应还金额；待确认记录可与下一待还期并存。

<a id="l8-f02"></a>
## L8-F02 · 还款提交、确认及超期出口

返回：[功能 §3.3](l8-repayment-prd.md#f-repay)、[§3.5](l8-repayment-prd.md#f-confirm)。适用资产方与本业务资金方。

```mermaid
flowchart TD
  A[资产方从右侧还款操作区进入居中弹窗] --> B[本笔默认最近待还期，保留放款编号，可改选已开窗期次]
  B --> C{本人业务、待还款且已到应还日00:00 UTC？}
  C -->|否| D[展示具体原因；未到期只读，不开放录入或上传]
  C -->|是| E[核对本期金额、币种及资金方账户]
  E --> F[填写还款时间；上传法币凭证或填写数币哈希]
  F --> G{同一容器内最终确认：资料有效且显式同意提交？}
  G -->|取消或校验未过，保留填写| F
  G -->|是| H[提交成功：待还款确认；逾期天数冻结；逾期未结清仍保留业务标记；开始168小时]
  H --> T[显示本期提交结果及待资金方确认进度；更新原清单，不自动开详情]
  T --> I[资金方进入本笔确认弹窗；显示已提交、待确认、当前处理方及确认期限]
  I --> J{同一容器内最终确认：资金方确认收到还款？}
  J -->|尚未确认| K{还款确认时限已届满？}
  K -->|未届满| I
  K -->|已届满| L[双方一次提醒；保持待确认与冻结天数]
  L --> M[可通过客服邮箱线下沟通，不代确认或裁决]
  L -->|核实到账后仍可直接确认| I
  M --> I
  J -->|明确确认| N{确认办理成功？}
  N -->|否| O[保持待确认及原金额，可再次办理]
  O --> I
  N -->|是| P[期次结清；累计已还更新；按本金减少两项占用；重判业务逾期标记]
  P --> Q{该笔所有期次均结清？}
  Q -->|否| R[原清单与详情更新，保留其他期次查看入口]
  R -->|用户主动选择| A
  Q -->|是| S[业务已结清；进入项目终态衔接 L8-F03]
```

资产方提交不减少本金占用；利息期确认也不减少本金占用。确认超期不是还款逾期。失败、取消、重复提交均不能凭空生成第二条有效还款记录。普通利息期及末期均到应还日00:00 UTC开放录入；平台仅登记付款信息，不执行支付或签名。到期前三日提醒只帮助准备，不开放表单。提交与确认各有真实事实，确认超期不增加资产方该期期次逾期天数。

<a id="l8-f03"></a>
## L8-F03 · 结清、关闭与跨平台质押释放

返回：[功能 §3.6](l8-repayment-prd.md#f-release)。项目终态同刻业务释放采用 L5 D-FIN-49/57；异常仅联系客服，保留真实事实与保护限制，不设计后续处置流程，不影响已定释放时点。

```mermaid
flowchart TD
  A[L8：单笔业务全部期次结清] --> B[L5：结合其他业务和在途判断项目]
  C[L5：到期检查或允许的主动关闭] --> B
  B --> D{满足项目关闭或结清条件？}
  D -->|否| E[保留项目存量处理；不按单笔自动释放代币]
  D -->|是| F[项目终态同刻解除全部业务占用；PS-4 已释放待提取]
  F --> G[资产方从L5解除质押入口自助提取，承担gas]
  G --> H[代币发行平台执行链上提取]
  H --> I{实际执行结果明确？}
  I -->|明确成功| J[按真实结果展示已提取；不再计作待提取]
  I -->|明确失败| K[保留业务已释放与待提取，不回退业务结清]
  I -->|未知或尚未完成| L[不宣称已提取，不将未知当失败或成功]
  K --> M[沿现有客服指引核对，不新增异常处置流程或恢复资格]
  L --> M
  I -->|部分结果| V[按每笔真实结果呈现；未知笔保持待核实]
  V --> M
  F --> N[同一对象重复业务释放：成功反馈已释放，不重复改变占用]
  N --> O[重复释放不重复发起链上提取]

```

X-05 受理不代表链上提取成功；项目终态的本平台业务释放已确定，不能混同为跨平台转回成功。未知执行结果不能伪装失败或成功；P03明确执行结果待核实则联系客服，不自动重试、补偿、改判或整批回滚，不放开未知占用的重押资格。正常明确失败的提取仍保留PS-4及L5既有办理条件；Q-L8-01只留真实结果、渠道和联验依赖。

<a id="l8-s01"></a>
## L8-S01 · 还款期次状态机

返回：[§3.3](l8-repayment-prd.md#f-repay)、[§3.4](l8-repayment-prd.md#f-overdue)、[§3.5](l8-repayment-prd.md#f-confirm)。每一期独立适用。

```mermaid
stateDiagram-v2
  state "S-RP-1 待还款" as RP1
  state "S-RP-2 待还款确认" as RP2
  state "S-RP-3 已结清" as RP3
  [*] --> RP1: 定稿生成期次
  RP1 --> RP1: 应还日次日00时UTC仍未提交，增加逾期标记
  RP1 --> RP2: 应还日开放后资产方成功录入提交，冻结该期天数
  RP2 --> RP2: 确认超期或办理失败，状态不变
  RP2 --> RP3: 资金方成功确认收到还款
  RP3 --> [*]
```

逾期天数结清后作为历史保留，不归零。无撤回、撤销、自动确认或异议状态迁移；S-RP-4 本期不可达，不绘成可操作分支。本期是否已提交与业务整体是否仍逾期分别判断，见[L8-REV-05](l8-repayment-prd.md#f-overdue)。

## L8-S02 · 融资业务状态机

返回：[§3.6](l8-repayment-prd.md#f-release)。只覆盖 L8 负责的状态段。

```mermaid
stateDiagram-v2
  state "S-FD-6 还款中" as FD6
  state "S-FD-8 已结清" as FD8
  [*] --> FD6: 放款确认完成
  FD6 --> FD6: 计划生成中、部分期次提交或确认
  FD6 --> FD6: 逾期或确认超期，均不改主状态
  FD6 --> FD8: 全部期次成功结清
  FD8 --> [*]
```

S-FD-9 / FD-44 为业务并行标记：只要仍有已逾期未结清期次（S-RP-1或S-RP-2）就保留，提交冻结天数但不清标记；相关逾期期次全部确认后清除当前标记，未来正常期未结清不阻止清除，历史仍保留。当前最早期次及最长天数只取未结清逾期集合。新的期次后来逾期可重新形成标记，不增加主状态。需求对外状态“已放款”在整个图中不变。业务结清不直接等于项目结清。

<a id="l8-s03"></a>
## L8-S03 · 项目终态与释放后的提取

返回：[§3.6](l8-repayment-prd.md#f-release)、[待确认项](l8-repayment-prd.md#questions)。项目状态由 L5 定义，本图只引用会触发释放的局部段，不新增项目状态号。

```mermaid
flowchart TD
  A[项目到期] --> B{有在途或未结清业务？}
  B -->|无| C[S-FP-5 已关闭]
  B -->|有| D[原项目状态加已到期·存量处理中标记]
  D -->|存量全部走完| E[S-FP-6 已结清]
  F[S-FP-1或S-FP-2满足允许的主动关闭条件] --> C
  C --> G[触发全部释放，跨平台衔接见 L8-F03]
  E --> G
```

以下从**项目终态同刻完成业务释放且资产仍在合约**的事实开始，引用 L5 D-FIN-57 两段式约束；业务释放时点不依赖链上提取结果。本平台 PS 值域采用 L5 主册 §5.1：PS-1 可质押、PS-2 已质押、PS-4 已释放，PS-0 非法；采用已定编号不代表跨平台执行已经联验。

```mermaid
stateDiagram-v2
  state "PS-4 业务已释放，代币待提取" as Released
  state "代币已转回资产方地址" as Returned
  [*] --> Released: 项目终态同刻业务释放，尚未提取
  Released --> Released: 重复释放，成功反馈已释放
  Released --> Released: 自助提取失败，业务终态不回退
  Released --> Returned: 资产方自助提取成功并承担gas
  Returned --> [*]
```

未提取代币不计入任何池覆盖且不能再次质押；提取可批量且无时限。未知链上执行结果不改变已定业务释放事实，也不能被标为“已转回资产方地址”。图示用于产品评审，未宣称本轮完成浏览器或 Mermaid 渲染验收。
