## L8-F01 · 计划形成与阅读入口

返回：[功能 §3.1/§3.2](l8-repayment-prd.md#f-plan)。计划未生成时不回退放款事实；初始计划不进入还款区。

```mermaid
flowchart TD
  A[资金方提交报价] --> B[报价环节展示初始计划：预计且未生效]
  B --> C[资产方接受报价：看到日期重算告知]
  C --> D[完成放款及资产方确认到账]
  D --> R[还款信息清单新增本笔业务；以申请编号为主标识]
  D --> Notice[同时通知资金方已确认到账<br/>进入同笔详情可查看计划生成进度]
  R --> E{定稿计划已生成？}
  E -->|尚未完成| F[清单与详情显示计划生成中；保留已完成放款事实]
  F -->|生成恢复| E
  E -->|完成| G[按放款提交日期重算并锁定计划]
  G --> H[资产方收到定稿对比<br/>双方在同笔详情查看正式安排<br/>不重复向资金方发定稿提醒]
  H --> I[还款信息清单与右侧还款办理区使用同一业务]
  I --> J[清单行直接定位；办理区多笔时先选择业务]
  J --> K[一个右侧抽屉：本期应还、定稿计划、收款账户、还款记录]
  K --> L[同容器查看计划、记录或关联详情]
  K --> M[同容器按角色选期、办理、最终二次确认]
  L --> N[返回原业务和期次]
  M --> N
  N --> O[关闭回原清单并保留位置；有未提交内容先在原容器确认放弃]
  P[项目尚无还款业务] --> Q[还款信息清单与右侧还款页签均保留空态]

```

访客只读公开信息，操作区仅“立即登录”；非当事方不能读取双方私有资料。全部已结清的业务保留清单行与只读详情、计划入口。未到期、待确认或计划生成中也可查看对应事实，无待还期次不虚构应还金额；待确认记录可与下一待还期并存。

<a id="l8-f02"></a>
## L8-F02 · 还款提交、确认及超期出口

返回：[功能 §3.3](l8-repayment-prd.md#f-repay)、[§3.5](l8-repayment-prd.md#f-confirm)。适用资产方与本业务资金方。

```mermaid
flowchart TD
  A[资产方从还款清单或办理区进入同一业务抽屉] --> B[同一容器默认最近一期待还，可改选已开窗期次]
  B --> C{本人业务、待还款且已开窗？}
  C -->|否| D[展示具体原因；未开窗给开启日期]
  C -->|是| E[核对本期金额、币种及资金方账户]
  E --> F[填写还款时间；上传法币凭证或填写数币哈希]
  F --> G{同一抽屉内最终确认：资料有效且显式同意提交？}
  G -->|取消或校验未过，保留填写| F
  G -->|是| H[提交成功：待还款确认；逾期天数冻结；开始168小时]
  H --> T[同一抽屉回详情并更新原清单；不自动打开另一业务]
  T --> I[资金方从原业务进入同一抽屉核对记录、期次和到账情况]
  I --> J{同一抽屉内最终确认：资金方确认收到还款？}
  J -->|尚未确认| K{还款确认时限已届满？}
  K -->|未届满| I
  K -->|已届满| L[双方一次提醒；保持待确认与冻结天数]
  L --> M[双方通过客服邮箱线下沟通]
  M --> I
  J -->|明确确认| N{确认办理成功？}
  N -->|否| O[保持待确认及原金额，可再次办理]
  O --> I
  N -->|是| P[期次结清；累计已还更新；按本金减少两项占用]
  P --> Q{该笔所有期次均结清？}
  Q -->|否| R[原清单与详情更新，保留其他期次查看入口]
  R -->|用户主动选择| A
  Q -->|是| S[业务已结清；进入项目终态衔接 L8-F03]
```

资产方提交不减少本金占用；利息期确认也不减少本金占用。确认超期不是还款逾期。失败、取消、重复提交均不能凭空生成第二条有效还款记录。末期窗口的跨条款冲突见 Q-L8-03，本图不裁定例外。

<a id="l8-f03"></a>
## L8-F03 · 结清、关闭与跨平台质押释放

返回：[功能 §3.6](l8-repayment-prd.md#f-release)。项目终态同刻业务释放采用 L5 D-FIN-49/57；虚线仅表示跨平台执行异常后续办理仍待补齐，不影响已定释放时点。

```mermaid
flowchart TD
  A[L8：单笔业务全部期次结清] --> B[L5：结合其他业务和在途判断项目]
  C[L5：到期检查或允许的主动关闭] --> B
  B --> D{满足项目关闭或结清条件？}
  D -->|否| E[保留项目存量处理；不按单笔自动释放代币]
  D -->|是| F[项目终态同刻解除全部业务占用；PS-4 已释放待提取]
  F --> G[资产方从L5解除质押入口自助提取，承担gas]
  G --> H[代币发行平台执行链上提取]
  H --> I{实际执行结果明确？}
  I -->|明确成功| J[按真实结果展示已提取；不再计作待提取]
  I -->|明确失败| K[保留业务已释放与待提取，不回退业务结清]
  I -->|未知或尚未完成| L[不宣称已提取，不将未知当失败或成功]
  K -.-> M[跨平台执行异常的具体后续办理待补齐 Q-L8-01]
  L -.-> M
  F --> N[同一对象重复业务释放：成功反馈已释放，不重复改变占用]
  N --> O[重复释放不重复发起链上提取]

```

X-05 受理不代表链上提取成功；项目终态的本平台业务释放已确定，不能混同为跨平台转回成功。未知执行结果不能伪装失败或成功；具体执行异常反馈及后续办理见 Q-L8-01，不重新裁定业务释放时点。

<a id="l8-s01"></a>
## L8-S01 · 还款期次状态机

返回：[§3.3](l8-repayment-prd.md#f-repay)、[§3.4](l8-repayment-prd.md#f-overdue)、[§3.5](l8-repayment-prd.md#f-confirm)。每一期独立适用。

```mermaid
stateDiagram-v2
  state "S-RP-1 待还款" as RP1
  state "S-RP-2 待还款确认" as RP2
  state "S-RP-3 已结清" as RP3
  [*] --> RP1: 定稿生成期次
  RP1 --> RP1: 次日零时仍未提交，增加逾期标记
  RP1 --> RP2: 资产方成功提交，冻结该期天数
  RP2 --> RP2: 确认超期或办理失败，状态不变
  RP2 --> RP3: 资金方成功确认收到还款
  RP3 --> [*]
```

逾期天数结清后作为历史保留，不归零。无撤回、撤销、自动确认或异议状态迁移；S-RP-4 本期不可达，不绘成可操作分支。

## L8-S02 · 融资业务状态机

返回：[§3.6](l8-repayment-prd.md#f-release)。只覆盖 L8 负责的状态段。

```mermaid
stateDiagram-v2
  state "S-FD-6 还款中" as FD6
  state "S-FD-8 已结清" as FD8
  [*] --> FD6: 放款确认完成
  FD6 --> FD6: 计划生成中、部分期次提交或确认
  FD6 --> FD6: 逾期或确认超期，均不改主状态
  FD6 --> FD8: 全部期次成功结清
  FD8 --> [*]
```

S-FD-9 是业务并行标记，其提交后清除边界待 Q-L8-03；业务终态时清除已确定。需求对外状态“已放款”在整个图中不变。业务结清不直接等于项目结清。

<a id="l8-s03"></a>
## L8-S03 · 项目终态与释放后的提取

返回：[§3.6](l8-repayment-prd.md#f-release)、[待确认项](l8-repayment-prd.md#questions)。项目状态由 L5 定义，本图只引用会触发释放的局部段，不新增项目状态号。

```mermaid
flowchart TD
  A[项目到期] --> B{有在途或未结清业务？}
  B -->|无| C[S-FP-5 已关闭]
  B -->|有| D[原项目状态加已到期·存量处理中标记]
  D -->|存量全部走完| E[S-FP-6 已结清]
  F[S-FP-1或S-FP-2满足允许的主动关闭条件] --> C
  C --> G[触发全部释放，跨平台衔接见 L8-F03]
  E --> G
```

以下从**项目终态同刻完成业务释放且资产仍在合约**的事实开始，引用 L5 D-FIN-57 两段式约束；业务释放时点不依赖链上提取结果。本平台 PS 值域采用 L5 主册 §5.1：PS-1 可质押、PS-2 已质押、PS-4 已释放，PS-0 非法；采用已定编号不代表跨平台执行已经联验。

```mermaid
stateDiagram-v2
  state "PS-4 业务已释放，代币待提取" as Released
  state "代币已转回资产方地址" as Returned
  [*] --> Released: 项目终态同刻业务释放，尚未提取
  Released --> Released: 重复释放，成功反馈已释放
  Released --> Released: 自助提取失败，业务终态不回退
  Released --> Returned: 资产方自助提取成功并承担gas
  Returned --> [*]
```

未提取代币不计入任何池覆盖且不能再次质押；提取可批量且无时限。未知链上执行结果不改变已定业务释放事实，也不能被标为“已转回资产方地址”。图示用于产品评审，未宣称本轮完成浏览器或 Mermaid 渲染验收。
