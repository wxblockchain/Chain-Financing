## 3. 功能需求说明

<a id="f-mc-01"></a>
### 3.1 F-MC-01 统计区

资产方看到资产与融资全貌；资金方看到授信与出资全貌。所有指标限定当前主体全部业务，不因当前tab分页或筛选缩成当前页合计。进入页面、从广场返回或浏览器刷新当前网址时更新；同一组数量、金额和副行保持同批事实一致。相关流程见[FL-MC-01](v1.0-我的控制台-流程图与状态机.md#fl-mc-01)。

| 业务字段／编号 | 类型与业务意义 | 范围、必有值与显示 |
| --- | --- | --- |
| 全部代币张数、代币价值合计 | 非负整数张数、USD金额；本平台快照中属于本企业且符合展示条件的代币总量 | 资产方必有；含失效；资金方不展示；正常空集合为0 |
| 其中已质押代币张数、代币价值合计 | 已满足本平台“已质押”口径的代币子集；账面金额含失效 | 以“其中”从属于全部代币，不能与总量画成互斥同级卡片（`D-MC-47`） |
| 其中已失效张数、金额 | 上述已质押子集中代币已失效的部分 | 必有副行，标注“不计入覆盖”；不能用全部代币失效量冒充此子集 |
| 总授信额度、授信笔数（`CR-05`） | USD金额、非负整数；资产方各机构授信／资金方授予各资产方的授信 | 双方可见；沿用授信域统计结果 |
| 已融额度、业务笔数（`FP-13`／`CR-08`） | 当前项目融资余额／本机构授信占用额与未结清融资业务数 | 双方可见；不把在途报价当成已融额度 |
| 剩余可用授信（`CR-11`） | 当前可用授信汇总，USD | 双方可见；不是“还能融资多少”的承诺 |

`D-MC-43`、`D-MC-44`、`D-MC-126`、`D-MC-127`：代币价值按各笔签发时既定金额汇总（发行侧代币价值与借贷三币种固定折算是两项事实，不互相改写），旁注“按各笔签发时汇率折算”，不实时换汇。已质押账面值不等于项目有效质押价值，不能以简单减失效值强行对平；项目侧还受已确认有效覆盖条件约束。剩余可用授信旁说明“实际可融金额以发布需求时的核定结果为准”。

不常驻展示融资上限、可融金额、项目在途金额、可撤回上限，不做额度尺或规则公式区。动作受限时仍保留归属模块给出的必要差额、原因与出路（`H-03`），不能为隐藏中间量而删掉用户解决问题所需的信息。

指标失败时仅该组显示暂不可用，提示可用浏览器刷新当前网址重试，不伪装成0；无机构主体按3.10整页引导，不进入正常统计空态。

<a id="f-mc-02"></a>
### 3.2 F-MC-02 代币列表

仅资产方可见。范围为本平台只读代币域中“属于本企业”的集合，与资产广场是同一套事实的主体过滤视图。点击代币记录进入本控制台代币详情 `P-MC-02`；列表不提供广场链接，详情仅按3.9前往关联项目。详情沿用本节字段边界，不因新增详情而开放额外资产资料，不扩展资产广场未约定的反向入口。

`D-MC-195`【自己的全部代币】：自己的指当前已确认资产方企业主体，不是当前员工个人、个人钱包或当前选中的融资项目。同企业员工共享这一企业全集。默认不限状态及项目，包含跨项目、未关联项目、未质押、已质押、有效及失效的所有可展示代币；不能只从融资项目、已质押记录或发生融资的资产中取子集。按唯一代币编号展示一次，跨页合起来覆盖该集合；“全部”不要求单页取消分页。筛选只改变浏览结果，清除后恢复企业全集，统计区始终采用未筛选全集及对应子集。代币当前唯一链上持有地址不等于本企业归属，不通过钱包、合约地址或地址变动推断“自己的”范围；本tab仍不新增持有地址/份额表。资金方仍无代币tab或代币统计；不扩大他企业、机构或员工权限。快照范围与完整性要求继续依D-MC-175/178，不能把未同步、关键缺失或归属未知的数据冒充可展示代币。对应验收AC-MC-105，状态范围见[ST-MC-01](v1.0-我的控制台-流程图与状态机.md#st-mc-01)。

`D-MC-189`【项目与申请】：融资项目列表一行仍是一个 `FP-01` 项目，跨项目看覆盖、当前融资申请和存量债务；不因同项目多轮申请或多笔报价复制项目行，不新增第六个资产方tab。项目详情中的融资申请信息一轮 `FP-28` 一条，发布成功才出现，改额保留本轮编号，再次发布生成新轮次；每轮使用自己的发布时间，不用项目首次发布时间替代。

申请信息包括申请编号、申请金额USD（2位小数）、申请对外五值状态及终结原因、本轮发布时间（发布成功必有、只读并标时区），以及当前有效或已接受报价的机构全称与年化利率（QT-06百分比、只读）；无当前报价时机构/利率不补造默认值。当前报价取本轮真实有效或已接受的那笔；没有时显示“暂无有效报价”，不把最近已拒绝/失效的历史报价充当当前值。历史按各笔 `FD-01` 保留机构、时间、条款和终结结果，不覆盖当前报价，不提供接受或恢复历史报价的动作。当前授信摘要仅向有权用户显示该机构对企业的总授信与已用授信，跨项目合计，不是本申请独享额度；详细授信仍在F-MC-04读取。

申请详情在控制台项目详情中可按明确编号定位和阅读；报价完整信息、预计计划、对应融资合同从控制台项目详情进入对应广场项目后，由用户选择原申请/报价查看。预计计划标明“预计·未生效”，不产生有效还款期次；不把放款记录或正式还款计划堆进申请信息。融资申请、放款、还款的衔接见[FL-MC-05](v1.0-我的控制台-流程图与状态机.md#fl-mc-05)。

### 3.10 F-MC-10 准入、空态与异常

### 3.11 F-MC-11 分页、筛选、排序与刷新恢复

`D-MC-198`【刷新当前网址】：控制台统计、各tab、详情及详情内计划/记录区域一律不设置刷新按钮或刷新图标；错误态不以“重试／重新加载／刷新状态”等名称变相保留同类取数按钮。需要更新或重试时，用户使用浏览器刷新当前网址；失败状态可用文字说明此方法。浏览器刷新保留当前tab、筛选、编号检索、排序、页码、每页数；详情保留类型、对象、原选定申请/期次及已有来源列表上下文。重新读取后按最新权限与真实结果展示，越界页按MC-04收敛；链接不转让权限，会话失效先处理登录。直接访问无来源的详情依3.13回默认tab。正常进入、筛选翻页、从广场返回仍取得所需结果，不要求用户先额外刷新，不新增周期刷新或延长会话。移除按钮不改变数据同步时效及错误/空态区分。对应AC-MC-108，见[ST-MC-04](v1.0-我的控制台-流程图与状态机.md#st-mc-04)、[ST-MC-05](v1.0-我的控制台-流程图与状态机.md#st-mc-05)。

控制台列表沿用默认20条、可切20／50／100的分页，显示按当前列表业务粒度计算的总数；还款总数为业务笔数，项目总数为项目数。借贷广场项目内清单每页5条及公开项目列表连续加载，不自动改变本企业跨项目台账分页。分页信息可访问，具体容器和控件由设计师决定。

| 当前tab（`MC-01`） | 单选枚举，必有；按角色默认2.1所述tab | 只允许本角色tab；非法值回角色默认，不泄露另一角色视图 |

### 3.12 F-MC-12 语言、展示质量及共同约束
