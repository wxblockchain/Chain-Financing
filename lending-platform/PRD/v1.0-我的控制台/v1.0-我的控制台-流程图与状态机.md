## FL-MC-01 准入与聚合视图

关联 `F-MC-01`、`F-MC-10`、`D-MC-11`、`D-MC-179`、`D-MC-180`；验收 `AC-MC-31`、`AC-MC-41`、`AC-MC-42`、`AC-MC-47`、`AC-MC-86`、`AC-MC-87`。规则回查[正文3.10](v1.0-我的控制台-PRD.md#f-mc-10)。

```mermaid
flowchart TD
  A[访问我的控制台] --> B{是否具备正常登录态}
  B -- 未登录 --> C[按登录域选择角色并完成登录]
  B -- 协议未完成 --> D[先完成必要协议步骤]
  C --> E{正常登录且允许进入}
  D --> E
  E -- 失败或取消 --> Z[回游客可见界面 无个人数据]
  E -- 成功 --> F{本企业归属是否可确定}
  B -- 是 --> F
  F -- 资金方尚无主体 --> G[机构资料整页引导 不显示数字卡片]
  G --> H[去机构注册或进度页面]
  F -- 资产方归属暂不可用 --> I[不展示企业数据 说明暂不可用并可重试]
  F -- 可确定 --> J[读取本主体统计与角色适用列表]
  J --> K{是否有有效浏览位置}
  K -- 有 --> L[恢复可访问的tab和视图]
  K -- 无 --> M[资产方默认代币列表 资金方默认我的报价]
  L --> N[各数据块显示结果或独立错误态]
  M --> N
  N --> O{会话是否失效}
  O -- 是 --> P[移除统计 列表 详情信息及控制台菜单]
  P --> Z
```

图例：未认证不等于未登录；只读菜单不因此消失。两角色会话规则引用各自登录域，不统一时长。资料被驳回但仍有企业主体时，保留允许查看的业务，用对应引导承接。

## FL-MC-02 从列表或详情到广场并返回

关联 `F-MC-03`、`F-MC-05`、`F-MC-06`、`F-MC-07`、`F-MC-09`、`F-MC-11`、`F-MC-13`；验收 `AC-MC-32`、`AC-MC-34`、`AC-MC-38`、`AC-MC-66`～`AC-MC-68`、`AC-MC-92`、`AC-MC-93`。回查[正文3.9](v1.0-我的控制台-PRD.md#f-mc-09)。

```mermaid
flowchart TD
  A[用户查看本企业业务列表或控制台详情] --> B{当前业务动作判定}
  B -- 不适用或未知 --> C[不显示该业务按钮 保留适用的只读导航]
  B -- 暂不可执行 --> D[显示受限原因和出路]
  B -- 可执行 --> E[点击前往对应项目 业务或期次]
  E --> F{广场核对最新权限与业务事实}
  F -- 已退出 --> G[按登录域重新认证]
  F -- 无权或对象不存在 --> H[内容不存在或无权访问]
  F -- 有权但动作已失效 --> I[留在可读详情 说明当前结果]
  F -- 允许操作 --> J[打开对应业务操作承载]
  J --> K[用户在广场完成或取消业务]
  K --> L[停留对应广场详情 可返回我的控制台]
  I --> L
  L --> R{原入口位置}
  R -- 控制台详情 --> S[返回同一控制台详情 更新业务事实]
  S --> T[用户返回来源列表]
  T --> M[恢复原tab 筛选 排序 分页并更新业务事实]
  R -- 列表快捷入口 --> M
  M --> N{更新记录仍匹配当前视图}
  N -- 是 --> O[目标行附近可见 状态时限为最新]
  N -- 否 --> P[说明记录已更新 可清除过滤查看]
```

控制台全程无业务提交。具体抽屉／弹窗形态属于 `Q-MC-53` 的待统一内容，图不将其中一个画成已定。关闭业务操作后停留广场详情；“返回我的控制台”回到原发起位置。控制台详情是独立只读页面，不能混同为广场操作页或嵌入业务表单。详情完整规则见[正文3.13](v1.0-我的控制台-PRD.md#f-mc-13)。

## ST-MC-01 代币生命周期结果

关联 `F-MC-02`、`D-MC-175`、`D-MC-178`；验收 `AC-MC-48`、`AC-MC-83`～`AC-MC-85`。回查[正文3.2](v1.0-我的控制台-PRD.md#f-mc-02)。

```mermaid
stateDiagram-v2
  state "有效" as Valid
  state "失效" as Void
  [*] --> Valid: 首次进入展示集合且上游结果有效
  [*] --> Void: 首次进入展示集合时已失效
```

状态权威为代币发行平台；控制台读取本平台快照，不按本机日期迁移。失效后记录仍保留并纳入账面统计，不代表销毁或自动解除质押。本期没有已销毁展示状态，不画无依据的恢复有效边。

## ST-MC-02 质押对外展示状态

关联 `F-MC-02`、`D-MC-176`、`D-MC-177`；验收 `AC-MC-48`、`AC-MC-83`。回查[正文3.2](v1.0-我的控制台-PRD.md#f-mc-02)。

```mermaid
stateDiagram-v2
  state "未质押" as NotPledged
  state "已质押" as Pledged
  [*] --> NotPledged: 本平台当前结果未质押
  [*] --> Pledged: 首次展示时已有有效质押结果
  NotPledged --> Pledged: 本平台确认转入成功且已质押
  Pledged --> NotPledged: 本平台确认已释放
```

这是对外二元视图，不是内部执行状态机。入池处理中、失败或已释放未提取都不新增可见状态；仍显示未质押。与ST-MC-01正交，一枚代币可为“失效＋已质押”。本页不因状态标签推断是否可再次质押，操作资格由对应业务判定。

## ST-MC-03 还款期次业务状态

关联 `F-MC-06`、`F-MC-08`、`T-MC-05`、`T-MC-06`、`T-MC-08`、`T-MC-09`；验收 `AC-MC-55`～`AC-MC-61`、`AC-MC-80`。回查[正文3.6](v1.0-我的控制台-PRD.md#f-mc-06)。

```mermaid
stateDiagram-v2
  state "待还款" as Due
  state "待还款确认" as Confirming
  state "已结清" as Settled
  [*] --> Due: 还款计划形成期次
```

## ST-MC-04 控制台视图可用状态

关联 `F-MC-10`、`F-MC-11`；验收 `AC-MC-31`、`AC-MC-47`、`AC-MC-69`～`AC-MC-72`、`AC-MC-86`、`AC-MC-88`。回查[正文3.10](v1.0-我的控制台-PRD.md#f-mc-10)与[正文3.11](v1.0-我的控制台-PRD.md#f-mc-11)。

```mermaid
stateDiagram-v2
  state "读取当前主体视图" as Loading
  state "有业务数据" as Ready
  state "本主体确无该类业务" as Empty
  state "当前筛选无结果" as FilterEmpty
  state "对应数据块暂不可用" as Error
  state "游客视图且已移除个人数据" as Guest
  [*] --> Loading: 正常登录且主体已确定
  Loading --> Ready: 读取成功且有结果
  Loading --> Empty: 读取成功且主体业务集合为空
  Loading --> FilterEmpty: 主体有业务但当前筛选无匹配
  Loading --> Error: 该数据块读取失败
  Error --> Loading: 用户重试
  FilterEmpty --> Loading: 清除或修改筛选
  Ready --> Loading: 浏览条件变化或用户刷新
  Empty --> Loading: 用户刷新
  Loading --> Guest: 会话失效
  Ready --> Guest: 会话失效
  Empty --> Guest: 会话失效
  FilterEmpty --> Guest: 会话失效
  Error --> Guest: 会话失效
```

本图按一个统计或列表数据块表达加载与失败，不能推导为某块失败就清空整页。无主体或主体不可确定先走FL-MC-01，不进入“真空集合”。会话失效是整页数据清除，覆盖所有块；上游同步不可用但本平台快照可读时仍属于有数据状态。

## ST-MC-05 单个详情的可用状态

关联 `F-MC-13`、`F-MC-10`、`D-MC-184`、`D-MC-186`、`D-MC-187`；验收 `AC-MC-90`、`AC-MC-94`、`AC-MC-95`。回查[正文3.13](v1.0-我的控制台-PRD.md#f-mc-13)。本图描述可读性，不改变项目、代币、融资或还款的业务状态。

```mermaid
stateDiagram-v2
  state "读取当前对象 不显示上一对象内容" as Loading
  state "详情可读 显示当前事实" as Ready
  state "暂不可用 可重试" as Error
  state "内容不存在或无权访问" as Unavailable
  state "无有效会话 已移除详情数据" as Guest
  [*] --> Loading: 正常会话及主体已确定
  Loading --> Ready: 对象存在 有权且读取成功
  Loading --> Error: 读取失败
  Loading --> Unavailable: 对象不存在或无权读取
  Error --> Loading: 用户重试
  Ready --> Loading: 换对象 刷新或从广场返回
  Unavailable --> Loading: 导航至其他可访问对象
  Loading --> Guest: 会话失效
  Ready --> Guest: 会话失效
  Error --> Guest: 会话失效
  Unavailable --> Guest: 会话失效
  Guest --> Loading: 重新认证且主体已确定
```

Ready可以包含“尚无放款记录”等局部空内容；正常已终结记录仍属于Ready。可读但业务动作失效时留在Ready并说明当前结果；只有对象本身不可读才进入Unavailable。重新登录不直接恢复旧详情内容，必须重新确认当前主体可读。

图示交付为Mermaid源文；正文编号、图号与相对链接进行静态核对，未做图形渲染验收。既有默认排序及对方操作承载的待对齐项不在图中伪装成已确定规则。
