# 我的控制台 · 消息通知

2026-09-24｜需求评审稿｜配套当前 PRD 与图册。本批按需求诊断简报 V4 修订：随报价有效期、放款确认时限、还款确认时限取消及待放款四项动作取消，来源模块的临期提醒、确认超期、要求重传、暂不放款与放款前终止五类事件废止，控制台对应的 `T-MC-02`、`T-MC-04`、`T-MC-09` 一并废止，现行提醒为 11 类；废止清单见[第 7 节](#retired-notify)。

**控制台本期没有独立发送事件，不新增站内信模板。** 本册定义三方边界、行级提醒归属和跨入口验收；通知的承载形式与视觉由设计决定（见[统一条款](01-我的控制台-PRD.md#design-boundary)）。业务事件由来源模块发送，控制台展示同一事实，消息中心承接本人消息。没有独立发送不等于删除上游关键通知，也不等于删除控制台行级状态。

没有本模块新增发送节点，因此没有待编造的中英发送模板、模板变量、通知种类或发送时限。下表中的N-LS/N-CR/N-LN/N-RP是来源模块现有产品编号，不登记第二套N-MC同义事件；中英文内容沿来源完整模板。普通空态、错误提示和行级事实属于页面文案，不包装为站内信。

## 3. 三方收件、权限与少干扰

<a id="mc-nr-02"></a>`MC-NR-02`【业务共享与个人消息】：同企业员工共享既定企业业务视图，消息属于借贷平台本人账号；共享业务不共享未读数、不默认全员收副本，不以谁正在查看控制台决定收件人。账户个人/企业档案、必要交易资料与消息可见性分别判定。收信不授予项目、账户、凭证或办理权限。

| 角色 | 当前结论 |
| --- | --- |
| 资产方 | 只接收来源业务为其明确归属的事件。逐张审核/执行按原提交/发起账号。**本期一个企业只有一个员工、不开放员工管理，原多成员收件归属分支（`Q-LS-N01`）随本批闭合**；仍不按最近登录、还款提交人或企业管理员推断收件人 |
| 资金方 | L6事件按原报价提交账号；L7及L8相应事件沿本笔放款登记账号LN-14，不能同时给报价人/登记人增副本。相关企业其他员工可看台账或办理，不因此自动变收件人；本页不展示LN-14内部人员字段 |
| 运营管理人员及SPV | 控制台无管理视图或独立发送事件，面客事件不抄送全体运营；SPV按运营同等处理，没有新增代付、代确认、裁决或资金通知权 |
| 游客、无关企业、其他平台/其他端身份 | 不接收、不串信，不按钱包/邮箱相同合并账号或转移历史消息 |

归属缺失、账号停用或访问权变化不得自动改投同事；由来源业务解决其收件分支，控制台不造责任人。通知缺失/延迟不回滚业务事实、不暂停期限，不以“页面能看见”代替真实投递验收。

<a id="mc-nr-03"></a>`MC-NR-03`【重复与历史】：同一事实按来源仅发一次；刷新、再次读取、统计重算或标记消失/再呈现不新增、不置顶、不恢复未读、不改原发生时间。来源独立发生的新事件仍按原规则，例如新一期首次逾期；控制台不自行判断为新的推送事件。已送达消息保留当时事实，打开看原对象当前结果；本批废止的临期与超期信不再产生，历史已送达的同类消息按原事实保留可读，控制台不补发也不重写。

<a id="mc-nr-04"></a>`MC-NR-04`【通知开关】：本模块无独立通知种类，不新建控制台通知开关或无实际作用的偏好项。账户开关默认开启、仅作用于已明确可选种类；强制通知不能关闭的规则沿账户/来源模块，不借关闭开关隐藏业务行级提醒、改变业务计时或关闭关键通知。哪些来源种类可选须由其自身定义及消息框架最终比对，本文件不自行把L5～L8全部归为可选或强制。

## 4. 提醒阅读、消息落点与返回

<a id="mc-nr-05"></a>`MC-NR-05`：控制台不新增“待办”这类独立对象——无待办清单、待办类列表分类或待处理计数，也无归档。还款一笔FD一条记录，可同时展示本期待还与其他期待确认；待确认逾期显示提交完成、冻结天数、仍未结清和当前处理方，不能将消息已读当作已确认。其他员工办完后，本页下次进入、返回、浏览器刷新取得真实结果，按条件更新提醒；本人旧信可以仍未读，二者不强行对齐。

<a id="mc-nr-06"></a>`MC-NR-06`：来源业务的已确认通知目标可以是原业务查看或有效办理，其完整目标由来源通知册规定。本控制台不是新的发送或转发层，不统一重写这些目标，也不将本页详情导航改为自动进入办理。若既有查看消息以控制台为目标，按原类型及稳定编号到对应只读详情；原期次仍定位原FD+RP，不自动切本期、首期或最新申请。浏览器刷新当前网址保持对象、期次与来源视图，未登录先认证，失去归属或对象不存在统一提示，不泄露存在性。

详情仍只有一个“前往借贷广场”，进入对应融资项目详情；列表无广场快捷入口，各处也不提供页内重新取数动作。返回保持原控制台对象/期次和列表浏览条件。已结清或动作失效时可以查看有权原记录，不以动作失效一律禁止阅读；消息目标未登记依消息框架既有可读降级，不伪造链接。来源通知按其已确认目标承接；控制台只提供本册定义的只读详情及项目级导航。
