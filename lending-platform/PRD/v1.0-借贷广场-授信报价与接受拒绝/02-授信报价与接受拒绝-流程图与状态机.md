## FL-CR-01 授信与报价

关联需求：F-LS-20～F-LS-26、F-LS-36。 [功能正文](01-授信报价与接受拒绝-PRD.md#credit-entry) · [验收](01-授信报价与接受拒绝-PRD.md#accept-credit)

```mermaid
flowchart TD
  A[资金方在融资业务入口选择申请，发起立即报价] --> B{身份、项目和需求可报价？}
  B -->|否| X[说明当前原因，不打开详情或错误对象]
  B -->|是| C{授信当前有效且充足？}
  C -->|否| D[授信意图确认：无额度、到期或不足原因及差额]
  D -->|取消| E[结束本次办理回项目，不生成授信或报价]
  D -->|确认| F[带入授信对象业务名称，填写额度/UTC日期及本次协议]
  F --> G{校验及保存成功？}
  G -->|否| F
  G -->|是| H[授信独立生效；结束本次办理并提示已授信，请继续报价]
  H -->|用户再次发起立即报价| A
  C -->|是| Q[进入报价：需求和只读条款自动带入]
  Q --> R[独立选择实际币种和利率，核对本期固定1:1:1及必要后果]
  R -->|直接提交，无二次确认| S{当前资格及数据满足？}
  S -->|固定依据不完整或覆盖未知| U[保留输入并说明可重试，无新报价]
  U --> Q
  S -->|覆盖不足已证实| V[原需求按既有规则失效，无新业务或占用]
  S -->|需求已锁定或终结| X
  S -->|授信又不足| D
  S -->|成功| W[新FD、锁定汇率、开始168小时及增加在途报价额]
  W --> Z[结束本次办理，刷新申请与相关入口，不自动开详情]
```

覆盖未知与已证实不足走不同出口；授信保存独立生效，之后报价取消/失败不回滚。完整文件、金额和UTC校验见正文。

## FL-CR-02 接受与拒绝

关联需求：F-LS-28～F-LS-30。 [功能正文](01-授信报价与接受拒绝-PRD.md#respond) · [验收](01-授信报价与接受拒绝-PRD.md#accept-respond)

```mermaid
flowchart TD
  A["资产方：从融资业务入口<br/>选择目标报价并进入接受办理"] --> B{"本笔仍待接受且未届满？"}
  B -- "否" --> X["当前操作内说明最新结果，停止过期动作"]
  B -- "是" --> C["查看条款、当前池况、锁定信息与倒计时<br/>预计计划可按需查看，实际放款后重算告知始终可得"]
  C --> D{"资产方决定"}
  D -- "拒绝" --> R["填写1至200字拒绝原因"]
  R --> R1{"仍可拒绝且原因有效？"}
  R1 -- "否" --> X
  R1 -- "是" --> R2["已拒绝；本笔在途报价金额释放<br/>向L5提供解锁结果<br/>项目在途金额与质押不变"]
  D -- "接受" --> E["填写法币账户或查看统一数币地址<br/>按本笔内容显式确认"]
  E --> F{"账户校验通过并已确认？"}
  F -- "否" --> E1["具体原因与可行动出路<br/>户名不符不可绕过"]
  E1 --> E
  F -- "是" --> G["查看商务条款摘要<br/>手续费与本金告知清楚可见"]
  G --> H["双方在线下拟定并签署合同"]
  H --> I["资产方上传本笔融资合同盖章件：1至5份<br/>单份不超过10MB，勾选条款一致性声明"]
  I --> J["资产方确认接受"]
  J --> K{"三步齐备且报价仍有效？"}
  K -- "状态已变或到期" --> X
  K -- "内容不完整" --> I
  K -- "是" --> L["待放款；报价计时停止<br/>两类在途金额保持<br/>融资放款清单形成同一业务待放款记录<br/>用户主动选择进入放款，资金方核验合同"]
```

三步是待接受内的填写进度，计时不停；拒绝无需完成三步，授信协议不替代融资合同。已失效报价不能接受，有效接受先成立后的覆盖由放款承接。

## FL-CR-03 两类失效及释放

关联需求：F-LS-27、F-LS-34、F-LS-35。 [功能正文](01-授信报价与接受拒绝-PRD.md#demand-invalid) · [验收](01-授信报价与接受拒绝-PRD.md#accept-lifecycle)

```mermaid
flowchart TD
  A["报价成功后168小时届满"] --> C{"该笔是否仍待接受？"}
  B["L5确认所属需求因覆盖不足失效<br/>包括L6报价终检发现"] --> C
  C -- "已接受 / 已拒绝 / 已失效" --> N["不按待接受报价再次处理<br/>不重复释放或通知"]
  C -- "仍待接受" --> D{"失效原因"}
  D -- "有效期届满" --> E["同一事件：L6报价已失效<br/>本笔在途报价金额全额释放<br/>L5解锁有效需求<br/>项目在途金额不变，质押不释放"]
  D -- "所属需求失效" --> F["同一事件：L5需求终结并释放其项目在途金额<br/>L6报价已失效并释放本笔在途报价金额"]
  E --> E1["L6 N-CR-03：双方各一次正常到期通知"]
  F --> F1["L5 N-LS-05：合并通知需求与报价影响<br/>L6不另发报价失效消息"]
  E1 --> G["保留原业务编号、快照与失效原因"]
  F1 --> G
  G --> H{"需求与项目仍允许新报价？"}
  H -- "是" --> I["任何机构可新报：新编号、新快照、新期限"]
  H -- "需求失效" --> J["资产方按L5补足覆盖并重发<br/>旧报价不能恢复"]
  H -- "项目到期等其他条件不满足" --> K["展示当前条件与不可报价原因"]
```

届满记原截止，需求失效记实际发生时间；只有一个正式结果，重复不再释放或发信。发送归属见[通知](03-授信报价与接受拒绝-消息通知.md#ownership)。

## FL-CR-04 固定折算与逐笔沿用

关联需求：F-LS-26。 [功能正文](01-授信报价与接受拒绝-PRD.md#quote-rate) · [验收](01-授信报价与接受拒绝-PRD.md#accept-quote)

```mermaid
flowchart LR
  A["本期固定规则<br/>1 USD = 1 USDT = 1 USDC"] -. "业务依据" .-> B["资金方选择币种，核对结算金额"]
  B --> C{"固定依据完整且其他条件通过？"}
  C -- "否" --> D["拒绝并说明原因，无新报价<br/>不改用旧业务快照或外部行情"]
  C -- "是" --> E["报价成功，锁定本笔金额与快照<br/>值 / 规则生效时间 / 来源 / 版本"]
  E --> F["本笔放款复用锁定金额及依据"]
  E --> G["本笔还款按已定应还额和原依据折算"]
  E --> H["各笔在途及未偿本金沿各自快照计量"]
```

固定比率不代表数币精度已定，Q-CR-09保持；每笔沿原快照，不改历史。

## FL-CR-05 查看记录与办理交接

关联需求：F-LS-32、F-LS-33。 [功能正文](01-授信报价与接受拒绝-PRD.md#records) · [验收](01-授信报价与接受拒绝-PRD.md#accept-presentation)

```mermaid
flowchart TD
  A[从融资申请清单选择FP-28] --> B[只读申请详情]
  B --> C[当前有效报价及核心授信摘要]
  B --> D[按需查看本条历史或预计计划]
  B --> E[按权限读取融资协议]
  B -->|关闭| P[回项目，保持原清单位置]
  P -->|明确选择业务和动作| Q[进入本次办理]
  Q --> R{动作结果}
  R -->|授信保存成功| S[结束办理并提示继续报价]
  R -->|报价提交成功| T[结束办理并刷新，不开详情]
  R -->|接受成功| U[同笔FD进入待放款，相关办理入口更新]
  R -->|拒绝成功| V[更新原申请及报价历史]
  R -->|失败| Q
  S -->|用户再次发起立即报价| Q
  U -->|关闭| P
  V -->|关闭| P
```

详情只读；查看历史、计划和文件不改变当前办理对象。失败保留内容，关闭后回到来源；成功后的结束行为按正文。

## ST-CR-01 授信生命周期

关联需求：F-LS-21、F-LS-22。 [功能正文](01-授信报价与接受拒绝-PRD.md#credit-term) · [验收](01-授信报价与接受拒绝-PRD.md#accept-credit)

```mermaid
stateDiagram-v2
  state "生效中" as ACTIVE
  state "已到期" as EXPIRED
  [*] --> ACTIVE: 金额、有效期及协议齐备，首次核定成功
  ACTIVE --> ACTIVE: 正金额追加与本次协议齐备，日期保持或在原五年边界内延长
  ACTIVE --> EXPIRED: 有效期至的次日00:00 UTC
  EXPIRED --> ACTIVE: 报价流程内金额、日期及协议齐备，重新核定成功
```

生效中/已到期分别沿S-CR-1/S-CR-2；追加不重置五年起点，到期只阻止新报价，不动存量。

## ST-CR-02 融资业务本模块状态

关联需求：F-LS-25、F-LS-27～F-LS-30、F-LS-34、F-LS-35。 [功能正文](01-授信报价与接受拒绝-PRD.md#lifecycle) · [验收](01-授信报价与接受拒绝-PRD.md#accept-lifecycle)

```mermaid
stateDiagram-v2
  state "待接受" as WAIT
  state "已拒绝" as REJECTED
  state "报价已失效" as EXPIRED
  state "待放款" as FUNDING
  [*] --> WAIT: 成功报价，产生业务编号与在途报价金额
  WAIT --> WAIT: 账户确认、摘要查看、盖章件上传，仅填写进度
  WAIT --> REJECTED: 资产方有效拒绝，原因必填
  WAIT --> EXPIRED: 168小时届满仍待接受
  WAIT --> EXPIRED: 所属需求失效且本笔仍待接受
  WAIT --> FUNDING: 三步齐备且有效接受
  REJECTED --> [*]
  EXPIRED --> [*]
  note right of FUNDING
    后续状态与时限由放款、还款模块承接
    此处不是融资业务终态
  end note
```

待接受、已拒绝、待放款、报价已失效分别沿S-FD-1/2/3/11；拒绝/失效不能恢复，待放款继续计入机构在途。后续待放款确认/异议处理沿S-FD-4/5，转本金以放款确认结果为准。

```mermaid
flowchart LR
  A["待报价"] -->|"L6报价成功"| B["已报价待确认"]
```
