# 授信报价与接受拒绝 PRD · V1.6

借贷平台面客端 · L6 / WS-375 · 2026-09-22 · 许楚清

资金方先检查对资产方的授信，必要时核定或追加，再对一轮融资需求提交全额报价。资产方在报价成功后168小时内确认收款资料和合同后接受，或填写原因拒绝；无人处理则报价到期失效。接受后转入放款，尚不代表资金到账。

**本文是产品、前后端研发及测试的共同入口。** 第2～6章按业务顺序讲功能，第8章按同序集中验收。按需打开[流程图与状态机](02-授信报价与接受拒绝-流程图与状态机.md)或[消息通知](03-授信报价与接受拒绝-消息通知.md)。开发主读第2～6章与第7章依赖，测试主读第8章及通知册验收。Hallmark同时读取三册，沿用现有借贷广场组合模块与共享设计基线。

<a id="scope"></a>
## 1. 范围、角色与共同入口

本模块负责授信核定与追加、报价锁定、接受/拒绝、报价失效以及相关记录和通知。没有授信审批、额度主动调低/冻结、多家同时报价、部分融资、报价修改/撤回/展期、平台生成或审核合同、多账户管理。上述操作不触链、不产生gas；真实放款、还款由后续模块办理。

| 角色 | 可做与可见 |
| --- | --- |
| 资金方本企业登录员工 | 代表机构核定授信、报价；不可向本机构自己的需求报价，不可代资产方接受。只见本机构的授信与相关私有业务资料 |
| 资产方本企业登录员工 | 接受或拒绝本企业的报价；可查看各机构对本企业的授信及本方协议，不能查看机构内部备注 |
| 游客和其他企业 | 只看公开需求、商务条款和锁定事实。授信额度、账户、文件、私人档案、联系方式均非公开；游客操作区仅“立即登录” |
| 运营（含SPV） | 保留既有异常授信待办与监控；无面客代报价、代接受入口，无本模块新增通知广播 |

沿用户已确认的查看与办理分离方式，项目记录的四区纵向清单、定位标签及右侧固定操作区沿[L5查看与办理](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md)。从“融资”操作区选定申请再进入居中办理弹窗；清单与右侧详情只读，没有办理或跨业务快捷入口。多个待办先明确对象，不能猜测“最新一笔”。无记录保留空态，读取失败可重试。融资操作区保留“发布需求—机构报价—确认签署—融资放款”四阶段进度，分别识别已完成、当前和后续；已结束需求不标为进行中。接受三步是报价内填写进度，不能替代项目融资进度。

<a id="d-cr-58"></a>`D-CR-58`
**D-CR-58 · 办理上下文。** 步骤、必要确认和放弃未保存修改在本次容器内完成，不叠层。返回上一步保留输入和成功附件；有修改时关闭先确认放弃，无修改直接关闭。关闭恢复来源筛选、分页、滚动与行焦点。成功更新本笔与操作区，不自动打开详情、下一笔或下一阶段；失败保留可复用内容，结果未知不假报成功。授信保存与报价提交的具体退出行为见下文。

个人/企业账户档案仅本人可查。业务需要的企业名称、编号、条款及适用账户自动取得：优先本笔已确认事实，其次同企业、用途和币种的有效登记资料；可编辑项仍校验，只读项不可改，逐笔确认不自动勾选。读取失败不伪装成未登记要求重填，不串企业、账户用途或历史文件；新授信协议、新合同不得默认套用他笔文件。

**协议与上传。** 10份是本次累计上限，不是每次选择上限，也不限制历次累计。选择前说明格式、大小和上限，显示已上传n/10；逐份显示名称、大小及文字状态。超额选择整批不加入，保留原列表并告知剩余名额；格式/大小不合格者不计数，其他成功文件保留。上传中可取消，未提交文件可移除重选、预览或下载；失败可重试或移除。有上传中/失败待处理文件不能提交，处理后仍至少一份成功；不能把文件名当作上传完成。

<a id="d-cr-56"></a>`D-CR-56`

### 2.3 有效期与到期（F-LS-22）

验收：[期限验收](#ac-cr-24)。

<a id="d-cr-19"></a>`D-CR-19` <a id="d-cr-20"></a>`D-CR-20`
首次、到期后正式重新核定：默认本次核定日+1年，最早+1年、最晚+5年，边界可选，越界拒绝并显示范围。普通追加可保持原日期或后延，不可提前、不强制延至追加日一年后；五年起点始终是首次或最近正式重新核定日，追加不重置，不开放提前重新核定入口。已到五年边界仍可只加金额；基点不可靠时不得猜测放行延期。

<a id="d-cr-62"></a>`D-CR-62`
核定日与范围按UTC业务日期；“有效期至”含当天，次日00:00 UTC进入已到期。加年取同月同日，目标年无该日取该月最后一日。正式重新核定建立新五年起点，原历史不变。授信只有“生效中/已到期”；到期只阻止新报价，既有在途、未偿本金和接受/放款/还款不受此到期阻断。项目到期不作废授信。

### 2.4 可用额度和再次校验（F-LS-23）

验收：[额度验收](#ac-cr-03)。

<a id="inv-cr-01"></a>`INV-CR-01` <a id="d-cr-17"></a>`D-CR-17`
授信占用额是本机构对该资产方的未偿本金；在途报价金额是尚未转成本金的报价；授信已用额为两者合计，不能再算作第四个占用量。可用授信显示为 `max(0, 授信额度−授信已用额)`。跨项目逐笔按各自锁定依据计量，必须满足 `授信占用额＋在途报价金额＋本次报价折USD金额 ≤ 授信额度`，不能扣减授信额度本身。

<a id="d-cr-21"></a>`D-CR-21` <a id="e-cr-02"></a>`E-CR-02` <a id="e-cr-11"></a>`E-CR-11` <a id="e-cr-12"></a>`E-CR-12`
再次点击立即报价和正式提交均重验授信、项目/需求状态及覆盖。其他项目占用导致不足时，重新显示金额、可用额、差额并进入追加，不重复增加上一笔额度；覆盖不足不能导向提额。若已用额已超过额度，停止该机构×企业全部新报价、形成既有运营待办，不自动改额度或抹金额。发现重复授信关系沿最早生效关系计量并交运营处理，不能把多条额度相加。每次变更可追溯由谁代表哪家企业、何时、因何项目改变了多少额度及有效期。

## 3. 提交报价，锁定需求与条款

前提：登录资金方不是该项目资产方；需求待报价且无在途融资业务；项目未到期；授信与当前覆盖同时通过。同一需求同刻只允许一家机构报价，先成功者锁定，不提供比价和部分融资。

### 3.2 固定折算与逐笔快照（F-LS-26）

验收：[折算与快照验收](#accept-quote)。

折算与沿用见[流程图](02-授信报价与接受拒绝-流程图与状态机.md#fl-cr-04)。

<a id="d-fin-17"></a>`D-FIN-17`
本期仅USD、USDT、USDC，固定 **1 USD = 1 USDT = 1 USDC**，标明为本期平台业务规则，不是外部市场价格或兑换承诺。无人工改价、审核发布、行情获取和汇率过期流程；外部行情及其可用性不影响报价。

<a id="d-fin-80"></a>`D-FIN-80` <a id="d-fin-81"></a>`D-FIN-81`
报价成功锁定结算金额和本笔快照，由平台保留，之后不重算。须能追溯四要素：值为该币种对USD的1；真实规则生效时间；来源为平台固定折算规则；稳定版本标识。规则生效时间不同于本笔报价锁定时间，不能填虚构行情机构或刷新时间，不让用户补填。

<a id="d-fin-82"></a>`D-FIN-82`
例如100.25 USD融资，选择三种币种的结算数值均100.25、单位分别正确，不收折算差额，预览和最终条款一致。放款复用锁定本金金额；还款按本期应还本息和原快照折算，不能把融资本金当每期本息。相同原金额、相同标识重复引用得到相同值。每笔在途与未偿本金用自己的成功快照，不追溯改写旧业务，也不能将旧业务快照借给新报价。

| --- | --- | --- |

对外五值由L5派生下发，列表/详情/控制台一致：L6报价推动待报价→已报价待确认，接受推动放款中；拒绝/届满仅对有效需求回待报价，需求失效取L5终结事实，后续已放款由下游承接。见[状态协作图](02-授信报价与接受拒绝-流程图与状态机.md#st-cr-03)，不由L6重建对外状态。
