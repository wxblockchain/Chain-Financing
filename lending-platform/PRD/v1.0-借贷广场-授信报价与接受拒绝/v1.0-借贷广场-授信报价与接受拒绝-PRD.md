## 2. 背景、目标与范围

L5 完成建池、质押与发布融资需求；L6 让资金方在报价路径内完成授信核定并提交一份报价，资产方再接受或拒绝。目标是让双方明确金额、期限与下一步，且同一笔业务不会重复计量或遗漏释放。

本期包含授信首次核定、追加与到期重新核定，以及核定前查看授信对象必要业务信息、提交授信协议附件；报价表单必要告知与直接提交；提交时锁定汇率；需求锁定；资产方收款账户确认、商务条款摘要、线下合同盖章件上传；接受、拒绝、报价七天失效、需求失效连带报价失效；展示、消息与跨模块验收要求。

本期不做授信审批、额度主动调低或冻结、独立授信管理入口、多机构同时报价、部分融资、报价修改/撤回/展期、平台生成或审核融资合同、多收款账户管理、技术分册。本次PRD工作不修改原型，设计师依据本组完整文件承接后续原型修订。放款与还款动作、计息与计划规则归对应模块；本册承接L8预计计划在报价详情/接受前的查看，以及接受后进入融资放款清单。报价、授信、接受、拒绝不触链、不消耗 gas。

**平台边界**：本期USD、USDT、USDC按平台固定1:1:1折算，这是业务约定，不是外部市场价格。资金方不能修改汇率，不建设人工汇率维护、审核、发布或行情取数流程。报价成功锁定并由本平台保留本笔依据，放款与还款同源复用；既有业务不重算。个人和企业账户档案仅本人查看，交易所需企业名称、条款及付款资料按用途和原业务权限自动取得。代币事实、质押与项目资格仍消费L5权威结果。

## 4. 角色、术语与编号

| 角色 | 可见与可做 |
| --- | --- |
| 游客 | 可看公开需求、公开商务条款与锁定信息；操作区只有“立即登录” |
| 资金方 | 本企业任一登录员工可代表机构核定授信、报价；不能给本企业自己的需求报价，不能处理资产方接受动作 |
| 资产方 | 本企业任一登录员工可处理本企业报价；接受或随时拒绝，无拒绝冷却期 |
| 运营（含SPV） | 本模块无面客写入口；接收已有异常授信等运营待办。SPV视同运营，不因此获得代报价或代接受权，亦不新增站内信广播 |

公开范围以 L5 `D-LS-10` 为准，不含授信额度、他人控制台数据、附件影像件与联系方式。资金方只能查看本机构对该资产方的授信，资产方只能查看各机构对本企业的授信；授信备注仅资金方本企业可见。

`授信额度` 属“机构 × 资产方”，跨项目共用；`在途报价金额` 是该二元组已报价且尚未转成未偿本金的业务金额；`授信占用额` 是该二元组未偿本金；`授信已用额` 为前两量之和。`项目在途金额`、`项目融资余额` 等按 L5 定义，使用全名。记账本位币 USD；结算币种不改变额度口径。
