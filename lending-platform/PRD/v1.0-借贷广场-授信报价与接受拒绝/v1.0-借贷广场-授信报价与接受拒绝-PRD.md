## 2. 背景、目标与范围

L5 完成建池、质押与发布融资需求；L6 让资金方在报价路径内完成授信核定并提交一份报价，资产方再接受或拒绝。目标是让双方明确金额、期限与下一步，且同一笔业务不会重复计量或遗漏释放。

本期包含授信首次核定、追加与到期重新核定；报价与提交前确认；提交时锁定汇率；需求锁定；资产方收款账户确认、商务条款摘要、线下合同盖章件上传；接受、拒绝、报价七天失效、需求失效连带报价失效；展示、消息与跨模块验收要求。

本期不做授信审批、额度主动调低或冻结、独立授信管理入口、多机构同时报价、部分融资、报价修改/撤回/展期、平台生成或审核融资合同、多收款账户管理、原型、技术分册。放款与还款动作、计息与还款计划归后续模块；本册只保留必须承接的业务结果。报价、授信、接受、拒绝不触链、不消耗 gas。

**三平台边界**：融资事实归借贷平台；报价汇率取代币发行平台的唯一汇率源，锁定后由借贷平台自持该笔快照；代币事实经本平台只读代币域消费。issue 描述中的“无跨平台依赖”和汇率待选项按本轮裁定收口。接口报文、接口字段清单、调用链、内部字段、存储设计均不在本册，也不另开技术分册。

## 3. 同源依据与冲突收口

| 规则 | 唯一来源与本模块责任 |
| --- | --- |
| 项目额度模型、`INV-FIN-01`、覆盖判据 | [L5 主册第 5.5～5.7 节](../v1.0-借贷广场-融资需求与代币质押/v1.0-借贷广场-融资需求与代币质押-PRD.md)；本模块引用，报价提交按当前事实执行覆盖判定，不再定义一套项目额度公式 |
| `AC-FIN-23` | 报价不新增 `项目在途金额`，不能在已发布需求的金额之外再扣一次；本模块新增的是 `在途报价金额` |
| `D-FIN-75`、`D-FIN-76` | [L5 功能第 9.6 节](../v1.0-借贷广场-融资需求与代币质押/01-功能需求说明.md)：需求侧失效与释放归 L5；报价侧状态流转由 L6 执行，同一事件内生效 |
| 对外五值状态 | [L5 功能第 11.6 节与第 13.3 节](../v1.0-借贷广场-融资需求与代币质押/01-功能需求说明.md)：L5 派生下发，L6 只提供报价、接受及拒绝/失效的业务结果，不自行拼装状态 |
| 两维度转移、只出不进 | 沿用基线 `AC-FIN-27`/`AC-FIN-28`，承接 L5 `AC-FIN-25`；本册仅规定本模块事件与后续环节的验收责任 |
| 质押与代币来源 | L5 主册第 5.1～5.4 节；`PS-1`/`PS-2`/`PS-4` 权威方为借贷平台，`PS-3` 作废占位；本模块只读引用，不重开裁定、不增加上架闸门、不把审核中或执行中的代币计入覆盖 |
| 报价机构收款账户 | 基线主册撤出裁定优先：`QT-07`/`QT-08` 作废。基线分册 6.4 的 `P-LS-05` “还款账户”及主册接受前置展示中的机构还款账户均不承接；报价表单、必填校验、接受摘要均不要求它。资金方收还款账户归放款时登记（基线 WS-326 `LN-15`/`LN-16`）；资产方接受时的收款账户继续必需 |
| 报价时池快照 | `AC-LS-27`、`AC-CR-14`、`QT-11` 保持作废，承接清单不得恢复；当前池况取 L5。汇率快照继续有效，两者不能混同 |
| 授信有效期 | 采用基线分册 `CR-07` 已确认的 1～5 年；主册残留的“五年上限待确认”不再沿用 |
| 失效与游客表现 | 到期效力以 `E-CR-14` 为准，不能因处理延迟继续接受；游客操作区按最新主册与 L5 只显示“立即登录”，不沿用旧分册逐动作不可点展示 |

基线条款中同号跨模块异义已存在。本轮按裁定**保留原号、不迁号**：本目录未注明来源的 `F-LS-*`、`D-LS-*`、`D-FIN-*`、`AC-LS-*` 指 L6 基线语义；引用 L5 时一律注明“L5”并给来源文件。例如 L6 `D-FIN-80` 是报价汇率快照，L5 `D-FIN-80` 是先审核后执行；不得只凭编号合并。`CR` 段位沿用，作废号不复用。

## 4. 角色、术语与编号

| 角色 | 可见与可做 |
| --- | --- |
| 游客 | 可看公开需求、公开商务条款与锁定信息；操作区只有“立即登录” |
| 资金方 | 本企业任一登录员工可代表机构核定授信、报价；不能给本企业自己的需求报价，不能处理资产方接受动作 |
| 资产方 | 本企业任一登录员工可处理本企业报价；接受或随时拒绝，无拒绝冷却期 |
| 运营 | 本模块无面客写入口；接收异常授信等运营待办 |

公开范围以 L5 `D-LS-10` 为准，不含授信额度、他人控制台数据、附件影像件与联系方式。资金方只能查看本机构对该资产方的授信，资产方只能查看各机构对本企业的授信；授信备注仅资金方本企业可见。

`授信额度` 属“机构 × 资产方”，跨项目共用；`在途报价金额` 是该二元组已报价且尚未转成未偿本金的业务金额；`授信占用额` 是该二元组未偿本金；`授信已用额` 为前两量之和。`项目在途金额`、`项目融资余额` 等按 L5 定义，使用全名。记账本位币 USD；结算币种不改变额度口径。

| 编号 | 用途 |
| --- | --- |
| `P-LS-04` | 授信核定，报价弹窗内前置步骤，无独立页面或菜单 |

| `FL-CR-01`～`FL-CR-04` | 授信报价、接受拒绝、失效、汇率业务流程 |
