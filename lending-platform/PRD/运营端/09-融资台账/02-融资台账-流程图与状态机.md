## 1. 业务记录出现在清单与详情中（FL-LG-01）

```mermaid
flowchart TD
    A[资产方创建项目并提交审核] --> B{合约配置成功}
    B -->|否：待审核、配置处理中、已退回或审核前关闭| B1[只在项目合约管理中查看]
    B -->|是：审核通过| C[融资项目清单新增一条项目记录]
    C --> D[资产方授权并签名质押]
    D --> E{质押上链结果}
    E -->|处理中| E1[项目详情的代币质押出现记录<br/>当前去向为质押上链处理中]
    E -->|明确失败| E2[不形成质押记录]
    E1 --> E3[成功后去向为已计入有效质押额<br/>之后的转出、释放只改变去向]
    E -->|成功| E3
    C --> F[资产方签名发布融资需求]
    F --> G{发布冻结结果}
    G -->|处理中| G1[融资需求清单与项目详情的融资需求出现记录<br/>编号尚未生成，清单申请状态为“—”]
    G -->|明确失败| G2[不入列]
    G1 --> G3[成功后生成融资申请编号<br/>申请状态为待报价]
    G -->|成功| G3
    G3 --> H[资金方授权并报价]
    H --> I{授权上链结果}
    I -->|处理中| I1[需求详情的报价放款出现记录<br/>报价上链确认中]
    I -->|明确失败| I2[不形成报价放款记录]
    I1 --> I3[成功后生成融资业务编号<br/>报价状态为待接受，申请状态为已报价待确认]
    I -->|成功| I3
    I3 --> J{资产方处理}
    J -->|拒绝或需求终结| J1[报价已拒绝或报价已失效<br/>记录保留]
    J -->|签名接受| K{链上放款结果}
    K -->|处理中| K1[申请状态为放款中<br/>报价放款记录另标链上放款处理中，只在详情可见]
    K -->|明确失败| K2[报价回到待接受，申请状态回到已报价待确认]
    K -->|成功| L[报价放款记录为已接受并写入放款信息<br/>申请状态为已放款，清单显示放款机构、放款金额与还款状态]
    L --> M[定稿还款计划生成]
    M -->|生成中| M1[还款 tab 说明还款计划生成中<br/>清单还款状态为还款中]
    M -->|完成| N[还款 tab 列出每一期]
    N --> O[每期链上还款成功即该期已结清<br/>全部结清后还款状态为已结清]
```

- 记录一旦出现就一直保留：已终结的需求、已拒绝或已失效的报价、已转回的质押、已结清的期次都可查询。
- 改额不新增需求记录；再次发布生成新一轮记录。同一份额再次质押生成新的质押记录。
- 链上处理中与链上结果待核实只在详情中展示，清单中只显示业务状态。

<a id="fl-lg-02"></a>
## 2. 查看、穿透与返回（FL-LG-02）

```mermaid
flowchart TD
    A[从共享导航进入融资台账] --> B{账号正常且具有融资台账查询}
    B -->|否| B1[不出现菜单；直接访问提示无权限]
    B -->|是| C[打开默认清单：融资项目清单]
    C --> D[切换清单、筛选、检索、排序或翻页]
    D --> E{从哪个清单打开}
    E -->|融资项目清单| F[项目详情<br/>项目基本信息、代币质押、融资需求]
    E -->|融资需求清单| G[需求详情<br/>需求信息、报价放款、还款]
    F -->|融资需求 tab 中的一轮| G
    G -->|所属项目| F
    F -->|项目审核详情| H{具有融资项目审核查询}
    H -->|是| H1[进入项目合约管理的审核详情]
    H -->|否| H2[不提供该入口]
    F --> K[返回]
    G --> K
    H1 --> K
    K --> L[回到来源清单或来源详情的原 tab<br/>保留筛选、排序、页码与所在位置]
    L --> M{来源记录仍满足筛选}
    M -->|是| D
    M -->|否| N[说明记录已更新，可清除筛选]
    N --> D
```

质押记录、报价放款记录与还款期次在所属 tab 内展开阅读。台账内的查看与穿透不产生任何业务变化，不进入面客端页面。

<a id="fl-lg-03"></a>
## 3. 读取与异常（FL-LG-03）

```mermaid
flowchart TD
    A[进入、切换清单、改变条件、打开详情或切换 tab、刷新或返回] --> B[读取当前事实]
    B --> C{读取结果}
    C -->|成功且有记录| D[展示记录与筛选结果合计]
    C -->|成功但清单或 tab 本身无记录| E[说明当前没有该类记录]
    C -->|成功但筛选无匹配| F[说明当前筛选未匹配，可清除]
    C -->|失败| G[仅失败部分暂不可用<br/>不显示为空或 0]
    G --> H[重试]
    H --> B
    C -->|记录不存在或无权| I[统一提示内容不存在或无权访问]
    C -->|权限收回或会话失效| J[停止展示，按账户模块处理]
    D --> K{详情中有链上结果待核实}
    K -->|是| K1[如实展示待核实与已知交易标识<br/>不推定成功或失败，无处理动作]
```

清单、筛选结果合计与详情的各 tab 分别反馈，其中一部分失败不影响其他已成功部分。
