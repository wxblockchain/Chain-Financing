## 1. 业务记录进入各清单（FL-LG-01）

```mermaid
flowchart TD
    A[资产方创建项目并提交审核] --> B{合约配置成功}
    B -->|否：待审核、配置处理中、已退回或审核前关闭| B1[只在项目合约管理中查看]
    B -->|是：审核通过| C[融资项目信息新增一条项目记录]
    C --> D[资产方授权并签名质押]
    D --> E{质押上链结果}
    E -->|处理中| E1[代币质押清单出现记录<br/>当前去向为质押上链处理中]
    E -->|明确失败| E2[不形成质押记录，不入列]
    E1 --> E3[成功后去向为已计入有效质押额<br/>之后的转出、释放只改变去向]
    E -->|成功| E3
    C --> F[资产方签名发布融资需求]
    F --> G{发布冻结结果}
    G -->|处理中| G1[融资需求清单出现记录<br/>融资申请编号尚未生成]
    G -->|明确失败| G2[不入列]
    G1 --> G3[成功后生成融资申请编号<br/>申请状态为待报价]
    G -->|成功| G3
    G3 --> H[资金方授权并报价]
    H --> I{授权上链结果}
    I -->|处理中| I1[报价清单出现记录<br/>报价上链确认中]
    I -->|明确失败| I2[不入列]
    I1 --> I3[成功后生成融资业务编号<br/>报价状态为待接受]
    I -->|成功| I3
    I3 --> J{资产方处理}
    J -->|拒绝或需求终结| J1[报价已拒绝或报价已失效<br/>记录保留]
    J -->|签名接受| K{链上放款结果}
    K -->|处理中| K1[报价仍为待接受<br/>另标链上放款处理中]
    K -->|明确失败| K2[报价回到待接受，放款清单不入列]
    K -->|成功| L[报价为已接受<br/>放款清单新增一条放款记录]
    L --> M[定稿还款计划生成]
    M -->|生成中| M1[放款详情说明还款计划生成中<br/>还款清单暂无期次]
    M -->|完成| N[还款清单新增本笔每一期]
    N --> O[每期链上还款成功即该期已结清<br/>全部结清后放款记录业务状态为已结清]
```

- 记录一旦入列就一直保留：已终结的需求、已拒绝或已失效的报价、已转回的质押、已结清的放款与期次都可查询。
- 改额不新增融资需求记录；再次发布生成新一轮记录。同一份额再次质押生成新的质押记录。
- 项目状态、质押情况、额度等随来源事实变化，融资项目信息按读取时的当前事实展示。

## 2. 查看、关联跳转与返回（FL-LG-02）

```mermaid
flowchart TD
    A[从共享导航进入融资台账] --> B{账号正常且具有融资台账查询}
    B -->|否| B1[不出现菜单；直接访问提示无权限]
    B -->|是| C[打开默认清单：融资项目信息]
    C --> D[切换清单、筛选、检索、排序或翻页]
    D --> E[打开一条记录的记录详情]
    E --> F{前往关联记录}
    F -->|关联对象只有一个| G[直接打开其记录详情]
    F -->|关联对象有多个| H[打开对应清单并按编号筛选]
    F -->|关联对象尚不存在| I[说明当前没有该类记录]
    F -->|项目审核详情| J{具有融资项目审核查询}
    J -->|是| J1[进入项目合约管理的审核详情]
    J -->|否| J2[不提供该入口]
    G --> K[返回]
    H --> K
    J1 --> K
    K --> L[回到来源清单或来源详情<br/>保留筛选、排序、页码与所在位置]
    L --> M{来源记录仍满足筛选}
    M -->|是| D
    M -->|否| N[说明记录已更新，可清除筛选]
    N --> D
```

台账内的查看与跳转不产生任何业务变化，不进入面客端页面。

<a id="fl-lg-03"></a>
## 3. 读取与异常（FL-LG-03）

```mermaid
flowchart TD
    A[进入、切换清单、改变条件、打开详情、刷新或返回] --> B[读取当前事实]
    B --> C{读取结果}
    C -->|成功且有记录| D[展示记录与筛选结果合计]
    C -->|成功但清单本身无记录| E[说明当前没有该类记录]
    C -->|成功但筛选无匹配| F[说明当前筛选未匹配，可清除]
    C -->|失败| G[仅失败部分暂不可用<br/>不显示为空或 0]
    G --> H[重试]
    H --> B
    C -->|记录不存在或无权| I[统一提示内容不存在或无权访问]
    C -->|权限收回或会话失效| J[停止展示，按账户模块处理]
    D --> K{记录有链上结果待核实}
    K -->|是| K1[如实展示待核实与已知交易标识<br/>不推定成功或失败，无处理动作]
```

清单、筛选结果合计与记录详情的各部分分别反馈，其中一部分失败不影响其他已成功部分。
