# 融资台账 · 功能与业务规则

2026-10-26｜运营端：运营管理员｜需求评审稿，所属端与运营查询范围待用户裁定，见末节

本模块共三册：本册定义功能与业务规则；[流程图与状态机](02-融资台账-流程图与状态机.md)说明记录何时进入各清单、查看与关联跳转；[验收](04-融资台账-验收.md)供测试使用。融资台账只读、自身不发送消息，所以没有 03 消息通知册，并非缺失。

<a id="design-boundary"></a>
本册只定义信息需求与业务行为。用户已指定的设计约束：融资台账是一个菜单，菜单内以多个 tab 承载各清单；本册所称“清单”即这些 tab。清单在菜单内的排列、列与详情的版式、筛选与跳转的交互承载由 Hallmark 决定。业务名称以[字段命名与术语对照表](../../00-字段命名与术语对照表.md)为基线。

## 1. 模块是什么

运营管理员在运营端“融资台账”菜单中，逐笔查看全平台的融资业务：已通过审核的融资项目、项目内的代币质押、每一轮融资需求、资金方的报价、链上放款，以及放款后的每一期还款。台账按业务对象分为六个清单，一条记录对应一个业务对象，记录之间可以按项目、融资申请、融资业务互相定位。台账只读，全部数据取来源模块的当前事实，用于对账、业务跟踪和协助客户核实链上结果；办理仍由资产方、资金方在面客端完成。

基本原则：

- **一个清单一种对象。** 六个清单分别对应融资项目、质押记录、一轮融资需求、一笔报价、一笔放款、一个还款期次。同一笔业务在不同清单中出现，是它在不同阶段的不同对象，金额不跨清单相加。
- **只读。** 台账不提供审核、代办、修改、撤销、关闭、催办或补记等任何动作，不改变任何业务状态，不发送消息。
- **不另定口径。** 字段、状态、金额、计息、逾期和质押情况全部采用来源模块当前结果；来源口径调整时台账随之一致。
- **全平台范围。** 同一主体不按机构隔离（[数据可见范围（D-AL-05）](../01-运营端账户与登录/01-运营端账户与登录-PRD.md#d-al-05)），查看需要本模块新增的[融资台账查询（PM-LG-01）](#pm-lg-01)。
- **与既有运营模块分工。** 项目审核与合约配置在[项目合约管理](../04-运营端项目合约管理/01-运营端项目合约管理-PRD.md)，平台合计与待办在[运营端总览](../08-运营端总览/01-运营端总览-PRD.md)；台账不重复审核队列，也不替代总览的统计。

**一个完整的例子。** 运营管理员打开“融资台账”，默认看到“融资项目信息”清单。甲企业的项目 P1 显示为融资中，有效质押额 1,000,000.00 USD，项目融资余额 500,000.00 USDT，项目在途金额 0.00 USDT，质押情况为质押充足。管理员打开 P1 的记录详情，看到它关联 12 条质押记录、2 轮融资需求、3 笔报价、1 笔放款、2 个还款期次。点击“报价”进入报价清单，清单已按项目 P1 筛选：第 1 轮的一笔报价已拒绝，第 2 轮有一笔已拒绝、一笔已接受。打开已接受的报价，可读报价机构乙、融资金额 500,000.00 USDT、结算币种 USDC、年化融资利率 8%，以及放款编号；点击放款编号打开该笔放款的记录详情：放款金额 500,000.00 USDC、放款成功时间、业务状态为还款中、未偿本金 500,000.00 USDT。再从放款详情进入还款清单，按该笔融资业务筛选出 2 期：第 1 期已逾期 3 天、期次状态为还款上链确认中，详情中可读提交时间、已等待时长和交易标识。甲企业来电询问这一期的链上结果时，管理员据此核对，但台账不提供任何处理动作。管理员返回融资项目信息清单，原来的筛选和页码保持不变。

### 1.1 本期不做

- 任何办理或处置动作：审核、代签名、代付、代报价、代接受、代还款、撤销授权、关闭项目、强制释放、补记或改判。
- 导出、打印与批量下载，见[台账导出（Q-LG-04）](#q-lg-04)。
- 统计图表、比率、排行与自定义指标；平台合计仍以运营端总览为准。
- 待审核、配置处理中、已退回以及审核通过前已关闭的项目，这些在项目合约管理中查看。
- 质押、发布、报价、放款或还款上链明确失败、未形成业务对象的发起记录。
- 授信关系、授信额度与占用、授信备注与授信协议文件。
- 企业账户档案（含法币账户与数币账户的账户备注名）、个人档案、机构认证资料、底层合同号与发票号。
- 链上授权清单与撤销授权；各类链上交易的 gas。
- 面客端的台账视图，见[所属端与可见范围（Q-LG-01）](#q-lg-01)。

## 2. 术语

| 术语 | 本册含义 |
| --- | --- |
| 融资台账 | 运营端模块与导航菜单名（英文 Financing ledger），按六个清单逐笔查看全平台融资业务 |
| 清单 | 融资台账内的一个 tab，只列一种业务对象 |
| 记录详情 | 一条记录的只读完整信息及其关联记录；具体承载由设计决定 |
| 关联记录 | 与当前记录同属一个项目、一轮融资申请或一笔融资业务的其他清单中的记录 |
| 链上处理中 | 来源模块已发起、链上结果尚未回写的过程，例如发布冻结处理中、报价上链确认中、链上放款处理中、还款上链确认中；不是新的业务状态 |
| 链上结果待核实 | 来源模块对长期未知或冲突的链上结果给出的事实，面客端此时提示“链上结果待核实，请联系平台客服人员”；台账只如实展示，不提供处理动作 |
| 筛选结果合计 | 当前清单在当前筛选条件下全部记录的数量与金额合计，不是当前页合计 |

## 3. 进入融资台账与权限（F-LG-01）

适用角色与前提：本期唯一角色为运营管理员，须完成首登改密、账号正常且会话有效，遵守[权限底线（F-AL-17）](../01-运营端账户与登录/01-运营端账户与登录-PRD.md#f-al-17)。

- 运营端共享导航中提供“融资台账”菜单（英文 Financing ledger）；进入后默认打开融资项目信息清单。
- 六个清单的业务顺序为：融资项目信息、代币质押清单、融资需求清单、报价清单、放款清单、还款清单。
- 会话失效、待首登改密或账号不可用时，立即停止展示台账数据并按账户模块引导；重新登录后重新判定权限，不直接恢复旧数据。

<a id="pm-lg-01"></a>**融资台账查询（PM-LG-01）。** 按[权限组织方式（D-AL-07）](../01-运营端账户与登录/01-运营端账户与登录-PRD.md#d-al-07)，本模块新增一项权限：

| 权限项 | 覆盖的业务能力 |
| --- | --- |
| 融资台账查询（PM-LG-01） | 进入融资台账，查看六个清单、筛选结果合计与全部记录详情；不含任何办理或处置动作 |

- 本期运营管理员固定具有（[本期预置角色（D-AL-08）](../01-运营端账户与登录/01-运营端账户与登录-PRD.md#d-al-08)）。是否新增这项权限待用户确认，见[运营端逐笔查询权限（Q-LG-02）](#q-lg-02)。
- 缺少该权限时不出现菜单；直接访问台账或任一记录详情统一提示无权限，不透露记录是否存在。
- 其他权限项（如[融资项目审核查询（PM-AL-17）](../04-运营端项目合约管理/01-运营端项目合约管理-PRD.md#permissions)、[平台融资统计查询（PM-OV-01）](../08-运营端总览/01-运营端总览-PRD.md#pm-ov-01)）都不覆盖本模块；本模块权限也不覆盖其他模块。
- 本模块权限只开放本册列明的信息，不因此取得企业账户档案、授信、个人档案或面客端办理能力。

<a id="f-lg-02"></a>
## 4. 清单划分与共同展示规则（F-LG-02）

适用角色与前提：满足[进入融资台账与权限（F-LG-01）](#f-lg-01)。

**六个清单。**

| 清单 | 一条记录是 | 纳入范围 | 不纳入 |
| --- | --- | --- | --- |
| [融资项目信息](#f-lg-03) | 一个融资项目（FP-01） | 审核通过（合约配置成功）的项目，含之后关闭或结清的 | 待审核、配置处理中、已退回、审核通过前已关闭的项目 |
| [代币质押清单](#f-lg-04) | 一份质押份额在一个项目中的一次质押（质押记录） | 质押上链处理中、已在合约内、正在转出、已转回或已释放的质押记录 | 质押上链明确失败、未转入合约的发起 |
| [融资需求清单](#f-lg-05) | 一轮融资需求（FP-28） | 发布成功的各轮，含已终结的；以及发布冻结处理中或结果待核实、尚未生成编号的发起 | 发布冻结明确失败、未签名或取消的发起 |
| [报价清单](#f-lg-06) | 一笔报价（FD-01） | 授权上链成功的报价，含已拒绝、已失效、已接受的；以及报价上链确认中、尚未生成编号的报价 | 授权上链明确失败、未形成报价的签名 |
| [放款清单](#f-lg-07) | 一笔链上放款（LN-01） | 链上放款成功的放款，与融资业务一一对应 | 链上放款处理中或明确失败的接受，这些在报价清单中查看 |
| [还款清单](#f-lg-08) | 定稿还款计划中的一期（RP-01） | 全部定稿期次，含已结清的 | 报价阶段的预计计划；计划尚未生成的业务暂无期次 |

**共同展示规则。**

- 各清单字段表的“清单 / 详情”列说明该信息在清单中直接可读，还是只在记录详情中可读；清单中可读的信息在详情中同样可读。
- 金额一律带单位：份额价值、总质押额、有效质押额等质押价值以 USD 计；融资需求金额、融资金额、项目在途金额、项目融资余额、本金、利息、应还合计以 USDT 计；结算金额、放款金额、还款金额以本笔结算币种（USDT 或 USDC）计。金额两位小数、千分位，按来源取值，不重新计算或换算；USD 与 USDT 只在来源已给出的质押情况判断中按 1:1 比较，台账不另做比较。
- 业务日期（有效期至、应还日、起息日、最终还款日等）为 UTC 日期并标注 UTC；具体时刻按本人偏好时区显示并标注时区，规则沿[界面语言与时区偏好（F-AL-10、F-AL-11）](../01-运营端账户与登录/01-运营端账户与登录-PRD.md#f-al-10)。切换时区不改变业务日期或排序。
- 网络以图标与名称同时展示，名称一律为“Ethereum”，中英文界面都不写“以太坊”或“ETH”。
- 地址与交易标识在清单中可缩写显示，在记录详情中给出完整值并可复制，标注平台未做链上核验；运营可见范围见[运营可见的地址与交易信息（Q-LG-03）](#q-lg-03)。
- 来源没有值时显示“—”，未知的链上结果标“待核实”；不以 0、示例值或其他记录的值补位。真实为 0 的金额显示 0.00。
- 状态都有文字，不只靠颜色区分。链上处理中、链上结果待核实与业务状态分开表达，不合成新的状态。
- 链上处理中的记录可读已等待时长；它只是如实计时，不表示超时或剩余时间，台账不展示任何截止时刻或倒计时。

## 11. 记录详情与关联跳转（F-LG-09）

适用角色与前提：满足[进入融资台账与权限（F-LG-01）](#f-lg-01)。

- 六个清单的每条记录都能打开记录详情；已终结、已结清、已移出的记录同样可以打开。记录详情只读，不提供任何办理动作。
- 详情以对象的业务编号作为识别：项目为项目名称与项目编号，其余为本对象的业务编号；尚未生成编号的链上处理中记录，以所属项目、金额与发起时间识别。
- 详情列出本记录的关联记录，可直接前往：

| 当前记录 | 可前往的关联记录 |
| --- | --- |
| 融资项目 | 本项目的质押记录、融资需求、报价、放款、还款期次 |
| 质押记录 | 所属项目 |
| 融资需求 | 所属项目、本轮报价、本轮放款（已放款时） |
| 报价 | 所属项目、所属融资需求、本笔放款（已接受时） |
| 放款 | 所属项目、所属融资需求、对应报价、本笔还款期次 |
| 还款期次 | 所属项目、所属放款 |

- 关联对象只有一个时，直接打开它的记录详情；有多个时，打开对应清单并按当前记录的项目编号、融资申请编号或融资业务编号筛选，筛选条件可见、可清除。
- 关联对象尚不存在时（例如尚未放款、计划尚未生成），说明当前没有该类记录，不提供空跳转。
- 融资项目的记录详情可前往项目合约管理中该项目的审核详情，仅对同时具有[融资项目审核查询（PM-AL-17）](../04-运营端项目合约管理/01-运营端项目合约管理-PRD.md#permissions)的账号提供；其他记录详情不提供台账以外的入口，也不进入面客端页面。
- 从详情或关联跳转返回时，回到来源清单或来源详情，保留原来的筛选、排序、页码与所在位置；来源记录因数据更新不再满足筛选时，说明记录已更新并可清除筛选。

流程见[查看、关联跳转与返回（FL-LG-02）](02-融资台账-流程图与状态机.md#fl-lg-02)。

## 12. 浏览、筛选与视图保持（F-LG-10）

适用角色与前提：满足[进入融资台账与权限（F-LG-01）](#f-lg-01)。

| 视图条件 | 类型与默认 | 规则 |
| --- | --- | --- |
| 当前清单 | 单选，默认融资项目信息 | 只允许六个清单之一；非法值回到默认清单 |
| 筛选 | 各清单定义的条件，均可不选，默认不限 | 多个条件取交集；日期范围按 UTC 日期，起止都包含当天，起点晚于终点时就地提示、不执行；筛选变化回到第 1 页 |
| 关键词 | 单行文本，默认空 | 去除首尾空格；编号按完整值精确匹配，名称可部分匹配，地址按完整值匹配；与筛选取交集；变化回到第 1 页 |
| 排序 | 各清单定义的字段与升降序 | 金额与时间按精确值排序；值相同时按本清单对象编号升序，保持稳定；变化回到第 1 页 |
| 页码、每页条数 | 默认第 1 页；每页条数沿用运营端现行取值 | 显示按当前筛选计算的总数；超出最新总页数时回到最后一个有内容的页并说明 |

- 每个清单各自保留自己的筛选、排序与页码；在清单之间切换时不互相带入。经关联跳转进入目标清单时，以关联条件替换目标清单原有条件。
- 浏览器刷新或复制当前地址后再打开，恢复当前清单、筛选、关键词、排序与页码；地址不转让权限，打开时仍按当前账号判权。
- 有筛选或关键词时，当前生效的条件可见，并可一次清除全部条件。
- 筛选结果合计按当前筛选条件下的全部记录计算，不随翻页变化；不同单位分别给出，不相加。筛选结果为空时，记录数为 0、金额合计为 0.00。
- 筛选结果合计只是台账查询结果，不替代运营端总览的平台统计；两者口径与统计范围以各自定义为准。

## 13. 读取状态与异常（F-LG-11）

适用角色与前提：满足[进入融资台账与权限（F-LG-01）](#f-lg-01)。进入台账、切换清单、改变视图条件、打开详情、浏览器刷新和从详情返回时读取当前事实；不设自动刷新周期。

| 情形 | 可观察结果 | 可继续的动作 |
| --- | --- | --- |
| 读取中 | 明确正在获取，未取得的数量与金额不先显示 0 | 等待结果 |
| 清单本身没有记录 | 说明当前没有该类记录，例如“暂无放款记录” | 可切换其他清单 |
| 筛选无结果 | 说明当前筛选未匹配，不说成平台没有该类业务 | 清除筛选 |
| 清单或合计读取失败 | 仅失败部分显示暂不可用，不显示成空清单或 0；其他已成功的部分照常可读 | 重试 |
| 记录详情部分信息读取失败 | 仅该部分暂不可用，其余信息照常显示 | 重试 |
| 记录不存在或无权查看 | 统一提示内容不存在或无权访问，不透露对象是否存在 | 返回来源清单 |
| 链上结果待核实 | 如实展示“链上结果待核实”、已知的交易标识与已等待时长；不推定成功或失败 | 无处理动作 |
| 权限在查看中被收回或会话失效 | 立即停止展示台账数据 | 按账户模块处理 |

- 记录状态在浏览期间被来源改变时，下次读取按新事实展示；不保留过期结果凑原位置。
- 台账不修改来源数据，读取失败不影响任何业务。

流程见[读取与异常（FL-LG-03）](02-融资台账-流程图与状态机.md#fl-lg-03)。
