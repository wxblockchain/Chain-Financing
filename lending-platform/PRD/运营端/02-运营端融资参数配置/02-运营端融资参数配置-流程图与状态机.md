<a id="fl-o-fc-03"></a>
## 组合的产生与配置（FL-O-FC-03）

```mermaid
flowchart TD
    A[一笔代币在代币准入审核中通过] --> B[按铸造链的链 ID 与代币类型确定组合]
    B --> C{该组合是否已存在}
    C -->|已存在| D[组合与参数不变 不产生变更记录]
    C -->|不存在| E[新增组合 配置状态为未配置 两项参数为空]
    E --> F[融资参数列表提示未配置数量]
    F --> G[运营管理员维护两项参数并确认保存]
    G --> H[组合变为已配置 记录一次首次配置]
    D --> I{组合是否已配置}
    I -->|否| F
    I -->|是| J[企业选该网络后可选到该代币类型]
    H --> J
    J --> K{该网络是否在创建融资项目的可选网络内}
    K -->|是| L[按组合参数校验自填值]
    K -->|否| M[暂不可选 等融资需求与代币质押开放该网络]
```

待审核、已退回的代币不产生组合。组合一经产生一直保留，代币失效或持有变化都不移除组合。

<a id="fl-o-fc-01"></a>
## 参数读取与维护（FL-O-FC-01）

```mermaid
flowchart TD
    A[运营账号进入融资参数配置] --> B{账号正常 已完成首登改密且登录有效}
    B -->|否| C[按账户状态引导 不开放参数内容]
    B -->|是| D{具备融资参数查询}
    D -->|否 只开通维护| E[拒绝进入 提示联系建设方修正配置]
    D -->|是| F[融资参数列表 一行一个组合]
    F --> G[参数详情 先当前参数后变更记录]
    F --> H[发起参数维护]
    G --> H
    H --> I[维护弹窗 载入当前值 未配置时为空]
    I --> J{两项参数均通过校验且有改动}
    J -->|否| K[按项说明允许范围 不可提交 不留痕]
    J -->|是| L[保存确认 变更前后与存量不变说明]
    L -->|取消| I
    L -->|确认| M{保存结果}
    M -->|成功| N[新值即时生效 记录一次变更 关闭弹窗回到发起位置]
    M -->|失败| O[两项都保持原值 保留输入可重试]
    M -->|结果未知| P[按当前事实展示 不伪报成功]
    M -->|他人已先行修改| Q[拒绝旧内容 提示重新取数]
```

两项参数要么全部采用新值，要么全部保持原值。未提交的编辑、校验拒绝、取消确认与保存失败都不产生变更记录。

<a id="fl-o-fc-02"></a>
## 创建融资项目的参数供给与锁定（FL-O-FC-02）

面客侧的选择、自填与提示规则以[融资需求与代币质押](../../面客端/05-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#f-ls-01)为准，本图只表达参数从哪个组合来、在哪个时点被取用。

```mermaid
flowchart TD
    A[资产方创建融资项目 选择区块链网络] --> B{组合与参数可读}
    B -->|否| C[说明暂不可办理并可重试 不以无上限或默认值继续]
    B -->|是| D[候选代币类型 取该网络下已配置的组合 与本企业在该网络上已准入代币的类型取交集]
    D --> E{存在可选代币类型}
    E -->|否 有已准入代币但组合未配置| F[不能提交 原因为该代币类型暂未开放融资]
    E -->|否 没有已准入代币| G[不能提交 按融资需求与代币质押现行提示]
    E -->|是| H[选择代币类型 自填项目质押率与到期日]
    H --> I[提交创建 以提交时点读取该组合的当前参数]
    I --> J{自填值是否越界}
    J -->|质押率超过最高质押率| K[不可提交并给出当前上限]
    J -->|到期日超出平台区间与最长项目期限中更小者| L[不可提交并说明可选范围]
    J -->|均未越界| M[创建成立 期限创建时锁定 质押率合约部署后锁定]
    M --> N[运营此后调整参数 不改写本项目锁定值]
```

校验与锁定用同一份提交时点的参数值。同一代币类型在不同网络上按各自组合取值。

<a id="st-o-fc-01"></a>
## 组合融资参数状态机（ST-O-FC-01）

对象是一个组合（区块链网络 + 代币类型）的融资参数配置，不是项目、代币或质押笔。状态取自[配置状态（FC-04）](./01-运营端融资参数配置-PRD.md#fc-04)。本模块没有草稿、待生效、停用或删除状态。

```mermaid
stateDiagram-v2
    state "未配置 两项参数为空 不可用于创建项目" as Unset
    state "已配置 两项参数均有有效值 可用于创建项目" as Configured
    [*] --> Unset: 代币准入通过 且该组合尚不存在
    Unset --> Unset: 校验拒绝 取消确认 或保存失败
    Unset --> Configured: 首次保存成功 两项参数同时写入
    Configured --> Configured: 再次保存成功 记录一次新的变更
    Configured --> Configured: 保存失败或被拒 两项参数保持原值
```

转换只由组合的产生与运营的保存成功触发；后续代币准入通过、代币失效、持有变化、项目创建、项目审核或时间流逝都不改变状态。组合没有终态，一经产生一直保留。

<a id="st-o-fc-02"></a>
## 项目参数取值的锁定（ST-O-FC-02）

对象是一个融资项目所采用的参数取值；项目自身的状态以[项目状态机](../../面客端/05-借贷广场-融资需求与代币质押/02-融资需求与代币质押-流程图与状态机.md#st-ls-01)为准，本图不重复。

```mermaid
stateDiagram-v2
    state "未取值 创建尚未提交" as Pending
    state "已锁定 随项目终身不变" as Locked
    [*] --> Pending: 资产方填写创建信息
    Pending --> Pending: 自填值越界被拒 仍未取值
    Pending --> Locked: 提交创建成功 以提交时点该组合的参数校验并锁定
    Locked --> Locked: 运营调高或调低参数 本项目取值不变
    Locked --> Locked: 审核退回后重提 质押率按当时上限重新校验 项目期限不重新起算
    Locked --> [*]: 项目进入终态 锁定值随项目留存
```

参数调整不触发额度重算、质押情况判断或到期日变化；上限调至低于存量锁定值不构成冲突，也不产生存量整改。
