# 运营端融资参数配置 · 验收

2026-10-23｜需求评审稿｜供测试使用

本册只写验收标准，测试用例与执行步骤由测试小队编写。规则见[功能与业务规则](./01-运营端融资参数配置-PRD.md)，各节顺序与功能册一致。

怎么读：

- 共 44 条验收（AC-O-FC-01～AC-O-FC-47）。编号沿用原值，已删除的条目不再占号，所以编号不连续，缺号不代表遗漏。
- 一条验收写了多个场景时，全部场景都满足才算通过。
- 标“待验，不判通过”的分支依赖额外网络开放；其余条目仍须通过实际验收，不能以需求文档一致代替产品行为验证。

## 0. 验收前准备

账号：

- 运营管理员账号两个（A、B），用于并发修改。
- 交付配置异常的运营账号：只开通融资参数维护（PM-AL-20）、缺融资参数查询（PM-AL-19）的一个；只有其他模块权限项（如融资项目审核查询（PM-AL-17）、资产准入审核查询（PM-TA-01））、没有本模块权限项的一个。
- 处于未登录、登录失效、待首登改密、账号锁定状态的运营账号各一个（可由同一账号切换状态）。
- 面客端账号：资产方甲企业（持有下列已准入代币）、资产方乙企业（在以太坊上没有已准入代币）、资金方、游客。

数据：

- 资产准入审核中可办理的代币：铸造链为以太坊（链 ID 1）、代币类型为 ERC-3525-应收账款的 T1（用于产生新组合）与 T2（同一组合的第二笔）；代币类型不同于 T1 的待审核代币 T3、已退回代币 T4；与 T1 代币类型相同、链 ID 不同的代币 T5；通过后会失效的代币 T6；通过后资料变更中改变了代币类型的代币 T7。
- 同一组合下的存量项目：已部署项目一个、待审核项目一个、已退回待重提项目一个，各自有已锁定的项目质押率与项目期限。
- 最高质押率输入样本：空、非数字、0、-1、0.01、79.99、79.999、100、100.01。
- 最长项目期限输入样本：空、2、3、12、13，以及非整月输入（若原型可输入）。
- 能让列表、详情、变更记录、保存分别读取失败或结果未知的环境状态；超过 20 条的参数变更记录。
