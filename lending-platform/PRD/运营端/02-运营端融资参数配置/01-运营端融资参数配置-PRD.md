## 1. 模块是什么

运营管理员按“区块链网络 + 代币类型”的组合，维护两项融资参数——最高质押率与最长项目期限。组合不由运营新建：一笔代币通过[代币准入审核](../06-代币准入审核/01-代币准入审核-PRD.md)后，若它所在的区块链网络与代币类型还没有对应的组合，本模块就新增一个未配置的组合。运营为组合配好两项参数后，企业在借贷广场创建融资项目时，才能在该区块链网络下选到这个代币类型；两项参数就是资产方自填项目质押率与项目期限的上限。参数改动只对此后新建的项目生效，已创建的项目沿用创建时锁定的值。

基本原则：

- **组合只来自已准入代币。** 准入审核通过是组合唯一的来源；运营不能新增、改名、合并或删除组合，也不能修改组合的区块链网络与代币类型。
- **先配置，后可选。** 未配置的组合不能用于创建融资项目；平台不设默认参数，不以默认值或“无上限”放行。
- **即时生效，存量不动。** 保存成功即为当前有效参数；已创建项目的锁定值终身不变，上限调低也不追溯。
- **当前参数只给当前值。** 当前参数不展示最近更新时间与最近更新人；何时、由谁、从什么改成什么，都在参数变更记录中查看（用户 2026-10-21 指定）。

**一个完整的例子。** 代币发行平台 A 为甲企业铸造了一笔 ERC-3525 代币，铸造链为以太坊（链 ID 1），代币类型为 ERC-3525-应收账款。运营管理员在代币准入审核中通过这笔代币；此前平台还没有“以太坊 + ERC-3525-应收账款”这个组合，于是融资参数配置中新增该组合，配置状态为未配置，两项参数显示“—”。这时甲企业在借贷广场创建融资项目、选择以太坊后，代币类型中没有 ERC-3525-应收账款，不能用这笔代币创建项目；这笔代币在资产广场照常展示。运营管理员打开“融资参数配置”，列表提示有 1 个组合尚未配置；在该组合上发起参数维护，弹窗中两项参数为空，填入最高质押率 70.00%、最长项目期限 12 个月，提交后确认“以太坊 + ERC-3525-应收账款”的变更前后（“—”→70.00%，“—”→12 个月）以及“仅对此后新建项目生效，不改变存量项目”，确认保存。组合变为已配置，参数变更记录新增一条首次配置记录，带发生时间与操作人。甲企业再次创建融资项目、选择以太坊后，可以选到 ERC-3525-应收账款，自填项目质押率不超过 70.00%、项目到期日不晚于创建日 + 12 个月；项目提交后两项取值随项目锁定。之后运营把最高质押率调为 60.00%，甲企业已创建的项目仍是原来的取值，此后新建的项目按 60.00% 校验。

<a id="out-of-scope"></a>
### 1.1 本期不做

- 运营新增、改名、合并、删除组合，或修改组合的区块链网络与代币类型。
- 平台默认参数、未配置时的兜底取值。
- 存量项目参数的调整、重算或整改；按企业或按项目的差异化参数。
- 利率、费率、额度、币种、质押率分档及审核类参数；质押率下限。
- 草稿、定时生效、生效计划、发布动作；回滚、撤销与历史值恢复。
- 审批复核、双人确认；批量编辑、复制到其他组合、导入导出。
- 逐笔质押的查询与处置（代币质押不经运营审核，用户 2026-10-21 裁定）；项目审核与合约部署（归[运营端项目合约管理](../04-运营端项目合约管理/01-运营端项目合约管理-PRD.md)）。
- 资产方创建融资项目时的选择、自填、校验提示与锁定（归[融资需求与代币质押](../../面客端/05-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md)）；面客侧的参数展示设计。
- 本模块发出的站内信、邮件或推送。

## 2. 术语

| 术语 | 含义 |
| --- | --- |
| 区块链网络 | 代币所在的链，即代币准入审核中的铸造链，按链 ID 区分；也就是资产方创建融资项目时第一项选择的[区块链网络（FP-39）](../../面客端/05-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#fp-39)。本期为以太坊 |
| 代币类型 | 代币标准与底层资产类型合并的单一字段，口径同[代币类型（FP-29）](../../面客端/05-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#fp-29)。本期为 ERC-3525-应收账款 |
| 组合 | 一个区块链网络与一个代币类型的搭配；一个组合一条融资参数配置。同一代币类型在两条网络上是两个组合 |
| 已准入代币 | 代币准入审核状态为已通过的代币，见[准入状态与叠加标记](../06-代币准入审核/01-代币准入审核-PRD.md#states) |
| 最高质押率 | 一个组合允许的项目质押率上限 |
| 最长项目期限 | 一个组合允许的项目期限上限，按整月计 |
| 配置状态 | 组合的两项参数是否都已配置：已配置／未配置 |
| 存量项目 | 已提交创建的融资项目，其项目质押率与项目期限已按提交时的参数锁定 |

<a id="common"></a>
## 3. 共同规则

适用于本模块全部功能。

<a id="d-o-fc-01"></a>
### 3.1 配置对象（D-O-FC-01）

- 配置对象是组合：区块链网络 + 代币类型。一个组合一条配置，只包含[最高质押率（FC-02）](#fc-02)与[最长项目期限（FC-03）](#fc-03)两项可维护参数。
- 区块链网络按链 ID 区分：链名相同而链 ID 不同（如主网与测试网）是两条网络、两个组合。
- 代币类型取已准入代币的代币类型原值，不写死 ERC-3525 或任何代币标准；代币标准或底层资产类型不同即为不同的代币类型。
- 组合的产生规则见[组合随代币准入产生（F-O-FC-06）](#f-o-fc-06)。平台不预置任何组合。
- 配置是创建融资项目时的取值上限，不是项目、代币或质押的业务事实；本模块不读取、不处置任何项目、代币或质押笔。

<a id="d-o-fc-02"></a><a id="permissions"></a>
### 3.2 权限（D-O-FC-02）

按[权限组织方式（D-AL-07）](../01-运营端账户与登录/01-运营端账户与登录-PRD.md#d-al-07)，本模块自行定义两项权限，并遵守[权限底线（F-AL-17）](../01-运营端账户与登录/01-运营端账户与登录-PRD.md#f-al-17)；编号沿用原值。

| 权限项 | 覆盖的业务能力 |
| --- | --- |
| 融资参数查询（PM-AL-19） | 查看融资参数列表、参数详情与参数变更记录；不含修改与保存 |
| 融资参数维护（PM-AL-20） | 发起参数维护并保存两项参数；必须同时具备融资参数查询（PM-AL-19），否则不能进入办理 |

- 本期运营端只有运营管理员一个角色，固定具备上述两项（见[本期预置角色（D-AL-08）](../01-运营端账户与登录/01-运营端账户与登录-PRD.md#d-al-08)）。
- 只开通融资参数维护、缺少融资参数查询的交付配置，进入即被拒绝，并提示联系建设方修正配置。
- 其他模块的权限项（如融资项目审核查询（PM-AL-17）、代币准入审核查询（PM-TA-01））都不覆盖本模块，不能据此进入。
- 未登录、登录失效、待首登改密或账号锁定时不开放本模块任何内容，按账户模块引导；此前已打开的维护弹窗中的提交同样被拒绝，不产生保存结果。
- 资产方、资金方、游客及其他平台账号不能读取本模块；面客侧只在创建融资项目时得到当前上限，见[创建融资项目的参数供给与未配置处理（F-O-FC-05）](#f-o-fc-05)。

<a id="d-o-fc-03"></a>
### 3.3 生效与存量隔离（D-O-FC-03）

| 规则 | 产品含义 |
| --- | --- |
| 即时生效 | 保存成功即为该组合的当前有效参数；没有草稿、待生效版本、定时生效或发布动作。保存失败则两项参数都保持原值 |
| 只约束此后的创建 | 新参数只作用于保存成功之后提交的项目创建；时点以资产方提交创建为准 |
| 存量锁定终身 | 已创建项目的[项目质押率（FP-34）](../../面客端/05-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#fp-34)与[项目期限（FP-35）](../../面客端/05-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#fp-35)是锁定值（项目质押率合约部署后锁定，项目期限创建时锁定）。运营此后调高或调低参数，都不改写存量项目，也不触发额度重算、质押情况判断或项目到期日变化 |
| 允许低于存量值 | 上限可调至低于某些存量项目已锁定的值；这不拦截保存，不产生整改任务或存量清单，存量项目也不因此变为违规 |
| 审核核对用快照 | 项目审核核对资产方最近一次提交的值，审核期间参数变动不影响核对结论，与[核对对象是创建时的快照（D-CM-17）](../04-运营端项目合约管理/01-运营端项目合约管理-PRD.md#d-cm-17)一致。[审核退回](../../面客端/05-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#f-ls-22)后重提时，项目质押率按重提当时该组合的最高质押率重新校验，项目期限仍按创建时锁定的最长项目期限 |

<a id="n-o-fc-01"></a>
### 3.4 展示、安全与质量（N-O-FC-01）

- 界面默认英文并支持中英切换；办理中途切换语言不丢输入，不改变已保存参数。
- 时间按运营人员偏好时区展示并标注时区。
- 运营人员身份按脱敏后的可读归属呈现，不展示完整邮箱与完整 IP。
- 最高质押率按保存的实际取值呈现，保留两位小数（如 70.00%），不另行截断或改写。
- 全部业务动作可仅用键盘完成；状态不只靠颜色表达。
- 本模块不提供文件上传与下载。
- 加载中、无数据、筛选无结果、读取失败、无权限、提交中各自有可辨认的呈现；读取失败可重试，不显示成 0 条。

## 4. 组合随代币准入产生（F-O-FC-06）

适用对象：代币准入审核的通过结果；本节是系统行为，没有运营动作。

- 一笔代币在[通过（F-TA-07）](../06-代币准入审核/01-代币准入审核-PRD.md#f-ta-07)生效时，按它的铸造链（链 ID）与代币类型确定组合：
  - 组合尚不存在：新增该组合，配置状态为未配置，两项参数为空，不产生参数变更记录。
  - 组合已存在：组合与参数都不变，不重置、不产生参数变更记录；已配置的组合，这笔代币随即可以按其参数用于创建融资项目。
- 待审核、已退回的代币不产生组合，也不影响任何组合。
- 已准入代币在[通过后的资料变更（F-TA-10）](../06-代币准入审核/01-代币准入审核-PRD.md#f-ta-10)中改变了代币类型时，按变更后的代币类型确定组合，同样适用上述两条；变更前的组合保留。
- 组合一经产生一直保留：准入通过本期不可撤销，代币之后失效、持有地址变化，或某组合下已没有有效代币，都不移除组合，也不改变其参数与配置状态。
- 组合的区块链网络还不在创建融资项目的可选网络内时（本期[区块链网络（FP-39）](../../面客端/05-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#fp-39)只有以太坊），组合照常出现、可以配置；企业要等融资需求与代币质押开放该网络后才能选用，见[融资需求与代币质押按组合取值（Q-O-FC-06）](#q-o-fc-06)。
- 新组合出现时不发消息，运营通过融资参数列表中的未配置提示察觉（用户 2026-10-21 确认），见[融资参数列表与检索（F-O-FC-01）](#f-o-fc-01)。
- 组合未配置期间，已准入代币在资产广场照常展示，只是不能作为创建融资项目的代币类型，见[创建融资项目的参数供给与未配置处理（F-O-FC-05）](#f-o-fc-05)。

流程参见：[组合的产生与配置（FL-O-FC-03）](./02-运营端融资参数配置-流程图与状态机.md#fl-o-fc-03)。

<a id="f-o-fc-01"></a>
## 5. 融资参数列表与检索（F-O-FC-01）

适用角色与前提：具备融资参数查询。融资参数列表（P-O-FC-01）一行一个组合。

- 每行展示：区块链网络、代币类型、最高质押率、最长项目期限、配置状态。不展示最近更新时间与最近更新人，这两项在[参数变更记录（FC-06）](#fc-06)中查看。
- 未配置的组合，两项参数显示“—”，不显示 0，也不显示任何默认值。
- 存在未配置的组合时，列表让运营一眼看到未配置的数量，并说明未配置的组合暂不能用于创建融资项目；可以一步只看未配置的组合。
- 检索：
  - 关键词模糊匹配代币类型名称，忽略大小写与首尾空格。
  - 按区块链网络、配置状态（已配置／未配置）筛选。
  - 查询应用条件，重置回到默认条件与第 1 页；筛选条件改变后回到第 1 页。
- 默认按区块链网络、再按代币类型名称升序；代币类型可升降序排列。
- 默认每页 20 条，可切 50、100。重新取数、浏览器前进后退保留筛选、排序与分页；从参数详情返回或参数维护完成后，回到原筛选、排序、分页与所在位置。
- 具备融资参数维护时，可以从列表中的组合直接发起参数维护，也可以进入参数详情。
- 列表没有新增、删除组合的入口，也没有逐笔质押、项目或代币的跳转。
- 三种结果分别说明：
  - 还没有组合：说明组合随代币准入审核通过产生，不提供新增入口。
  - 筛选无匹配：说明没有符合条件的组合，并提供重置。
  - 读取失败：说明失败并可重试，保留条件；不以空列表冒充“还没有组合”。

流程参见：[参数读取与维护（FL-O-FC-01）](./02-运营端融资参数配置-流程图与状态机.md#fl-o-fc-01)。

<a id="f-o-fc-02"></a>
## 6. 参数详情与变更记录（F-O-FC-02）

适用角色与前提：具备融资参数查询；读取不要求融资参数维护。参数详情（P-O-FC-02）包含“当前参数”与“参数变更记录”两部分，二者同时可得，先当前参数后变更记录，不另立独立的记录信息域。具备融资参数维护时在此发起参数维护。

<a id="current"></a>**当前参数。** 只展示以下五项，不展示最近更新时间与最近更新人：

| 业务信息 | 含义与类型 | 必填、可编辑与校验 | 默认值 |
| --- | --- | --- | --- |
| <a id="fc-07"></a>区块链网络（FC-07） | 网络名称与链 ID，见[配置对象（D-O-FC-01）](#d-o-fc-01) | 取自产生组合的已准入代币，只读 | 无 |
| <a id="fc-01"></a>代币类型（FC-01） | 文本，形如 ERC-3525-应收账款 | 取自产生组合的已准入代币，只读；不写死任何代币标准 | 无 |
| <a id="fc-02"></a>最高质押率（FC-02） | 百分比；本组合允许的项目质押率上限 | 具备融资参数维护时可编辑；保存时必填，取值大于 0 且不超过 100%，最多两位小数（精确到 0.01%）。管理端不配置质押率下限，“大于 0”是取值本身的要求，不是向资产方发布的下限。0、负数、超过 100%、小数超过两位均拒绝保存并给出允许范围；不自动四舍五入为合法值 | 未配置时为空，不补默认值 |
| <a id="fc-03"></a>最长项目期限（FC-03） | 整月数；本组合允许的项目期限上限 | 具备融资参数维护时可编辑；保存时必填，取值 3～12 的整数月。下界 3 个月与上界 1 年是[项目期限（FP-35）](../../面客端/05-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#fp-35)已确认的平台区间，配置值不得越出 | 未配置时为空，不补默认值 |
| <a id="fc-04"></a>配置状态（FC-04） | 枚举：已配置／未配置 | 系统判定、只读；两项参数都有有效值为已配置，否则为未配置。一次保存总是同时写入两项，所以已配置的组合不会回到未配置 | 未配置 |

<a id="fc-06"></a>**参数变更记录（FC-06）。**

- 每次保存成功产生一条，包含：发生时间（带时区）、操作人（脱敏后的可读归属）、变更前后的最高质押率与最长项目期限、本次结果。
- 首次配置记为从“—”到新值，不记成修改；两项中未改变的一项如实标出未变。
- 按发生时间倒序，默认 20 条，可以继续查看更早的记录；不按本人经办过滤。
- 记录只读，不可编辑或删除。
- 未提交的编辑、被校验拒绝的保存、取消确认、保存失败都不产生记录。
- 组合产生、代币准入通过等不是参数变更，不产生记录。
- 记录中不出现项目、代币、质押笔或企业信息，不提供任何逐笔质押跳转。
- 尚无记录、读取失败、登录失效分别说明。

## 7. 参数维护与保存（F-O-FC-03）

适用角色与前提：同时具备融资参数查询与融资参数维护。

- 参数维护（P-O-FC-03）直接以弹窗办理，不另开页面（用户 2026-10-21 指定）；可从融资参数列表的组合或参数详情发起。
- 弹窗载入该组合的当前值；未配置时两项为空，不预填任何演示值或默认值。区块链网络与代币类型只读展示。
- 一次只维护一个组合；不提供多行批量编辑、复制到其他组合或导入导出。

**保存。**

- 两项参数都通过校验才可提交；两项都未改动时不可提交（按取值比较，70 改写为 70.00 不算改动）。
- 提交进入保存确认（C-O-FC-01），展示区块链网络、代币类型、两项参数的变更前后，并说明“仅对此后新建项目生效，不改变存量项目”；首次配置时另说明保存后即可用于创建融资项目。
- 确认后保存；取消回到弹窗，保留输入，不改变任何已生效参数。
- 一次保存两项参数要么全部采用新值，要么全部保持原值，不出现一项已改、另一项仍旧。
- 提交中不能重复提交；同一次保存只生效一次、只产生一条记录。
- 保存成功后关闭弹窗，回到发起的位置，当前参数、配置状态与参数变更记录随即更新，并明确告知已保存。

**校验与拒绝。**

- 最高质押率不在“大于 0 且不超过 100%”内或小数超过两位、最长项目期限不在 3～12 整月内、任一项为空或格式不合法时，拒绝保存。
- 错误定位到具体一项，并说明该项的允许范围：最高质押率为“大于 0，最高 100%，最多两位小数”，最长项目期限为“3～12 整月”；只说“输入有误”不合格。
- 恰为 100%、恰为两位小数都合法，不按边界拒绝；小数超过两位如实拒绝，不替用户四舍五入后保存。
- 校验拒绝不产生变更记录。

**异常与边界。**

- 关闭弹窗时若有未提交的内容，先确认；取消则继续本次办理，确认才放弃输入。
- 该组合的参数已被他人先行修改时，后提交的旧内容被拒，并提示重新取数；重新取数会丢弃输入时先确认。
- 提交失败保留输入、可重试；结果未知时先按当前事实展示，不伪报成功，不产生虚假的变更记录。
- 提交时权限或账号状态已变化的，拒绝保存并按[权限（D-O-FC-02）](#d-o-fc-02)处理。

状态见[组合融资参数状态机（ST-O-FC-01）](./02-运营端融资参数配置-流程图与状态机.md#st-o-fc-01)。

<a id="f-o-fc-04"></a>
## 8. 参数生效与存量隔离（F-O-FC-04）

适用前提：保存成功后自动适用，运营无须再做动作。共同口径见[生效与存量隔离（D-O-FC-03）](#d-o-fc-03)，可观察结果如下：

| 场景 | 结果 |
| --- | --- |
| 保存成功 | 新值立即成为该组合的当前有效参数；本模块与创建融资项目读到同一份当前值，没有新旧并存的过渡期 |
| 保存成功后新建项目 | 提交时点在保存之后的创建，按新上限校验自填值 |
| 保存成功后回看存量项目 | 存量项目的项目质押率与项目期限保持锁定值；[有效质押额（FP-12）](../../面客端/05-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#fp-12)按锁定质押率计算，[有效期至（FP-09）](../../面客端/05-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#fp-09)不变 |
| 上限调低到存量值以下 | 保存正常成功；存量项目不被标记、拦截或强制关闭，本模块不产生存量清单或待办 |
| 待审核项目在审期间参数变动 | 按最近一次提交的快照核对，结论不因参数变动而改变；退回后重提时项目质押率按当时的最高质押率重新校验，项目期限不重新起算 |
| 保存失败 | 两项参数都保持原值；此后的创建仍按原上限校验，不出现部分生效 |
| 保存成功或失败 | 不发送任何站内信、邮件或推送；不通知其他运营人员、资产方或资金方 |

本模块不提供参数的回滚、撤销、历史值恢复或定时切换；需要改回原值时按正常维护重新保存，作为一次新的变更留痕。

项目侧取值的锁定关系见[项目参数取值的锁定（ST-O-FC-02）](./02-运营端融资参数配置-流程图与状态机.md#st-o-fc-02)。

## 9. 创建融资项目的参数供给与未配置处理（F-O-FC-05）

适用前提：资产方在借贷广场[创建融资项目（F-LS-01）](../../面客端/05-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#f-ls-01)，先选区块链网络，再选代币类型。本节只定义本模块向该环节供给什么，以及未配置时对企业的业务结果；选择、自填、提示文案与锁定动作归融资需求与代币质押，本册不改写其范围。

**供给内容。**

| 供给内容 | 规则 |
| --- | --- |
| 可选代币类型 | 资产方所选区块链网络下，配置状态为已配置的组合的代币类型。融资需求与代币质押再与本企业在该网络上持有的已准入代币的代币类型取交集 |
| 当前最高质押率 | 所选区块链网络与代币类型这一组合的当前值，供校验自填项目质押率，并在超限时给出当前上限 |
| 当前最长项目期限 | 同一组合的当前值，供限定项目到期日；平台区间 3 个月～1 年与配置上限同时成立，实际可选上界取两者中更小的值 |
| 取值时点 | 以资产方提交创建的时刻读取当前参数，校验与锁定用同一份值；办理过程中运营改动参数时，以提交时点的值为准 |

- 面客侧只得到可选代币类型与当前上限，不得到配置状态、变更记录、操作人、生效时间或运营端入口。
- 同一代币类型在不同区块链网络上的参数互不影响，按项目所选网络取对应组合。

<a id="unconfigured"></a>**组合未配置时，企业端的业务结果。**

| 企业在所选网络上的情况 | 结果 |
| --- | --- |
| 持有已准入代币，其组合已配置 | 该代币类型可选，按该组合的参数校验 |
| 持有已准入代币，其组合未配置 | 该代币类型不可选，不能用它提交创建；不以默认参数或无上限放行。企业端应能看出原因是“该代币类型暂未开放融资”，而不是“没有代币”，提示措辞归融资需求与代币质押，见[融资需求与代币质押按组合取值（Q-O-FC-06）](#q-o-fc-06) |
| 没有已准入代币 | 没有可选代币类型，按融资需求与代币质押现行规则提示 |

- 组合未配置不影响代币本身：已准入代币在资产广场照常展示，代币准入结论不变。
- 运营配置完成后立即可选：企业重新进入或刷新创建即可选到，不需要重新准入、重新发行或重新推送。
- 组合的区块链网络还不在创建融资项目的可选网络内时，即使已配置，企业也选不到，见[组合随代币准入产生（F-O-FC-06）](#f-o-fc-06)。
- 组合或参数读取失败时，创建侧说明暂不可办理并可重试，不以无上限或默认值继续；本模块不因此自动写入任何参数值。

流程参见：[创建融资项目的参数供给与锁定（FL-O-FC-02）](./02-运营端融资参数配置-流程图与状态机.md#fl-o-fc-02)。
