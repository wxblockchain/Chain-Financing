# 运营端总览 · 流程图与状态机

2026-10-26｜需求评审稿

<a id="fl-ov-01"></a>
## 1. 查看与办理回流（FL-OV-01）

```mermaid
flowchart TD
    A[登录后默认落地或从导航进入总览] --> B{账号正常且会话有效}
    B -->|否| C[按账户模块引导]
    B -->|是| D[按来源查询权限展示统计与待办]
    D --> E[选择一类待办]
    E --> F{仍有来源查询权限}
    F -->|否| G[说明无权限并可返回]
    F -->|是| H[进入原业务列表并应用待办条件]
    H --> I{当前仍有匹配记录}
    I -->|否| J[展示原业务空态]
    I -->|是| K[查看原业务详情]
    K --> L{原业务允许本人办理}
    L -->|否| M[按当前状态只读或说明限制]
    L -->|是| N[按原业务规则办理]
    G --> O[返回总览重新读取]
    J --> O
    M --> O
    N --> O
    O --> D
```

查看不认领待办；办理是否成功、是否进入配置处理中等，都按原业务事实处理，返回总览重新计数。

<a id="fl-ov-02"></a>
## 2. 数据读取与重试（FL-OV-02）

```mermaid
flowchart TD
    A[进入总览或主动刷新或业务返回] --> B[重新读取有权查看的各项数据]
    B --> C{本项读取结果}
    C -->|成功| D{数量是否为零}
    D -->|是| E[显示零及本项数据时间]
    D -->|否| F[显示准确数量及本项数据时间]
    C -->|失败| G{有上次成功数据}
    G -->|有| H[保留旧数字和旧时间并说明更新失败]
    G -->|无| I[说明暂不可用且不填零]
    H --> J[运营人员重试]
    I --> J
    J --> B
    C -->|权限失效| K[隐藏本来源数字和入口]
```

每项独立反馈，其他成功项不受单项读取失败影响；失败项不能用于宣告全部待办清空。核心统计、状态构成、提醒、近期审结与待办都按本图读取；某一构成项失败时，该来源合计同样暂不可用。
