## FL-PR-01 质押上链、逐张审核与两端结果

```mermaid
flowchart TD
  S["项目已通过审核并完成合约部署"] --> A["资产方用一个持有地址<br/>选定 A、B、C 三份质押份额"]
  A --> T["签名发起质押上链，gas 自担"]
  T -- "上链失败" --> TF["不形成申请，不进入审核队列<br/>gas 不退，可重新发起"]
  T -- "上链成功" --> B["一个提交批次、三张待审申请<br/>份额在合约内，计入待审质押额"]
  B --> C["运营逐张查看事实，线下判断"]
  C --> D{"本张仍待审核、不在撤回解押中<br/>项目未进入终态？"}
  D -- "否" --> E["不能裁定，展示当前事实与原因"]
  D -- "是" --> F{"只裁定当前这一张"}
  F -- "通过" --> G["上传协议、确认后果<br/>连接平台统一钱包签名解冻授权并提交"]
  G --> U{"解冻授权上链结果"}
  U -- "处理中" --> U1["仍为待审核，暂不可裁定<br/>资产方不能撤回，不发通知"]
  U1 --> U
  U -- "失败" --> U2["不算通过，回到可裁定的待审核<br/>协议保留，可再次签名或改为驳回"]
  U -- "长期没有结果" --> U3["结果待核实，不算通过<br/>回写后按结果处理"]
  F -- "驳回" --> H["填写原因、预览并确认后提交"]
  U -- "成功" --> J["本张通过 · 从待审质押额转为有效质押额<br/>满足有效性条件时计入，发送通过通知"]
  H --> K["本张驳回<br/>份额仍在合约内，待资产方自助解押"]
  J --> L["发送质押审核通过站内信"]
  K --> M["发送质押审核驳回站内信，带原因"]
  B -- "资产方待审撤回" --> RP["撤回解押中<br/>仍为待审核，运营暂不可裁定"]
  RP -- "解押成功" --> N["本张已撤回"]
  RP -- "解押失败" --> C
  B -- "所属项目进入终态" --> CL["本张默认审核不通过<br/>审核主体为系统，原因含项目关闭原因<br/>发送质押审核驳回站内信"]
  RP -- "解押结果未出时项目进入终态" --> CL
  CL --> K2["份额仍在合约内，待资产方自助解押"]
  B -- "无人裁定" --> W["一直停留在待审核<br/>不会自动失败"]
  W --> C
  J --> Q["批次汇总四类张数与去向摘要"]
  K --> Q
  N --> Q
  CL --> Q
```

## FL-PR-03 待审撤回、驳回后的自助解押与项目终态

```mermaid
flowchart TD
  A{"份额要退出质押合约"}
  A -- "仍待审核：资产方撤回" --> B["资产方用持有地址签名发起解押<br/>gas 自担"]
  A -- "已驳回：资产方自助解押" --> B
  B --> C["解押处理中<br/>不能重复发起<br/>待审张此时运营暂不可裁定"]
  C -- "解押成功" --> D["份额转回原持有地址<br/>退出总质押额与待审质押额"]
  D --> E{"此前的审核状态"}
  E -- "待审核" --> F["本张已撤回，不能再裁定"]
  E -- "驳回" --> G["驳回结论保留不变"]
  F --> H["按当前资格可重新发起质押<br/>形成新的一张"]
  G --> H
  C -- "解押失败，gas 不退" --> I{"此前的审核状态"}
  I -- "待审核" --> RO["恢复待审核，运营可以裁定"]
  I -- "驳回" --> G2["仍为驳回，待自助解押"]
  C -- "结果未出时项目进入终态（仅待审张）" --> CL["本张默认审核不通过<br/>此后解押结果只更新去向"]
  C -- "长期没有结果或与记录冲突" --> J["保持在合约内，保留事实与凭证<br/>提示联系平台客服"]
```

## ST-PR-01 单笔审核状态（RV-20）

```mermaid
stateDiagram-v2
  state "待审核" as Pending
  state "待审核 · 撤回解押中（暂不可裁定）" as Paused
  state "待审核 · 解冻授权处理中（暂不可裁定，资产方不能撤回）" as Unfreezing
  state "通过" as Approved
  state "驳回" as Rejected
  state "已撤回" as Withdrawn
  [*] --> Pending: 份额上链成功
  Pending --> Unfreezing: 运营连接平台统一钱包签名解冻授权并提交
  Unfreezing --> Approved: 解冻授权上链成功
  Unfreezing --> Pending: 授权上链失败，不算通过
  Unfreezing --> Unfreezing: 长期没有结果 · 结果待核实，不算通过
  Pending --> Rejected: 运营驳回
  Pending --> Rejected: 项目进入终态，系统默认不通过
  Pending --> Paused: 资产方发起待审撤回
  Paused --> Pending: 解押失败
  Paused --> Withdrawn: 解押成功
  Paused --> Rejected: 解押结果未出时项目进入终态
  Approved --> [*]
  Rejected --> [*]
  Withdrawn --> [*]
```

“撤回解押中”与“解冻授权处理中”仍属待审核，只是暂不可裁定，不是新的审核状态。解冻授权处理中（含结果待核实）资产方不能撤回，项目也不会进入终态（处理中的链上操作属于未处理完成的业务）。驳回含人工驳回与项目终态默认不通过两种来源。时间流逝不改变审核状态。

## ST-PR-02 本笔当前去向

取值同面客[本笔当前去向（PA-15）](../../面客端/05-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#pa-15)。

```mermaid
stateDiagram-v2
  state "待审核" as Pending
  state "已计入有效质押额" as Counted
  state "待自助解押" as ToRelease
  state "解押处理中" as Releasing
  state "已解押退回" as Returned
  [*] --> Pending: 份额上链成功
  Pending --> Counted: 审核通过且满足有效性条件
  Pending --> ToRelease: 审核驳回（人工或项目终态默认）
  Pending --> Releasing: 资产方发起待审撤回
  ToRelease --> Releasing: 资产方发起自助解押
  Releasing --> Returned: 解押成功
  Releasing --> Pending: 待审撤回的解押失败
  Releasing --> ToRelease: 驳回后的解押失败
  Counted --> [*]
  Returned --> [*]
```

审核通过但代币失效或有对账差异的，不进入“已计入有效质押额”，如实展示不计入的原因。已解押退回后再次质押形成新的一张，不覆盖旧记录。
