## ST-CM-01 项目审核轴

```mermaid
stateDiagram-v2
  PENDING: 待审核 · 面客 S-FP-7
  CONFIGURING: 配置处理中 · 面客仍为 S-FP-7 · 非结论 · 资产方不可关闭
  APPROVED: 已通过 · 面客 S-FP-1 · 终态
  RETURNED: 已退回 · 面客 S-FP-8
  [*] --> PENDING: 资产方提交审核
  PENDING --> CONFIGURING: 运营选定质押合约并确认提交
  CONFIGURING --> APPROVED: 配置成功 = 审核通过
  CONFIGURING --> PENDING: 配置失败 · 由处置人再次发起部署或改为退回
  PENDING --> RETURNED: 退回并给出原因
  RETURNED --> PENDING: 资产方修改重提 · 期限不重算
  CLOSED: 项目已关闭 · 资产方主动关闭或有效期到期
  PENDING --> CLOSED: 资产方关闭，或到达有效期至自动关闭
  RETURNED --> CLOSED: 资产方关闭，或到达有效期至自动关闭
  APPROVED --> [*]
  CLOSED --> [*]
```

结果待核实时审核轴停在配置处理中，不另成状态，回写真实结果后按配置成功或配置失败转换。项目已关闭是叠加标记：关闭后审核轴保留关闭前的取值，列表只显示该取值，“项目已关闭”与关闭原因在详情展示，不再可裁定。配置处理中资产方不能关闭，也不因到期立即关闭，部署结果回写后按结果处理：成功则审核通过，若已过有效期至，项目转为可用后立即自动终结；失败则回到待审核，若已过有效期至，随即自动关闭（[配置处理中资产方不能关闭项目（D-CM-21）](./01-运营端项目合约管理-PRD.md#d-cm-21)、[待审核或已退回时到期自动关闭](./01-运营端项目合约管理-PRD.md#expiry)）。

## ST-CM-02 合约配置执行状态

```mermaid
stateDiagram-v2
  NONE: 未发起
  RUNNING: 配置处理中
  SUCCESS: 配置成功 · 放款、还款合约都部署成功
  FAILED: 配置失败 · 任一份未部署成功
  UNKNOWN: 结果待核实
  [*] --> NONE: 项目提交审核
  NONE --> RUNNING: 运营选定质押合约并确认提交
  RUNNING --> SUCCESS: 链上明确成功
  RUNNING --> FAILED: 链上执行明确失败
  RUNNING --> UNKNOWN: 长期无结果或事实冲突
  FAILED --> RUNNING: 再次发起部署
  UNKNOWN --> SUCCESS: 回写为成功
  UNKNOWN --> FAILED: 回写为失败
  SUCCESS --> [*]
```

配置成功后不再发起部署；所配置的合约只读，无录入、修改、更换、重新部署或解除配置入口。本状态只属于一个项目，同一份质押合约上其他项目的配置状态互不影响。
