# 资金方机构认证审核 · 验收

2026-10-23｜需求评审稿｜供测试使用

本册只列验收标准，业务规则见[功能与业务规则](01-资金方机构认证审核-PRD.md)；一条验收包含多个场景时全部满足才算通过。编号沿用原值，缺号不代表遗漏。

## 验收前准备

- 账号：正常运营管理员；审核中、已驳回、已认证的资金方本人及其他资金方账号。
- 数据：当前及变更前模版、机构标识冲突、多份材料读取异常、并行审核、重复结论、提交与审核记录及通知样本。

<a id="acceptance"></a>
## 验收标准

以下按第 3 章功能顺序给出业务验收结果，不是操作脚本。审核判据由机构决定；验收检查平台正确承载其确认结论，不由测试制定准入标准。第 5 章未决依赖对应的分支须在真实条件齐备后验收，尚缺的实际材料说明不能用演示值冒充。AC-L610 为历史空号，不再分配。
