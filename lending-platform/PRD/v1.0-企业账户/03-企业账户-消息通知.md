# 企业账户 · 消息通知

版本：2026-09-24。需求：企业账户（WS-386）。配套[主 PRD](./01-企业账户-PRD.md)与[流程图与状态机](./02-企业账户-流程图与状态机.md)。本册只定义本模块的通知范围与边界；面客与运营消息中心负责框架、投递与目标页面，文档齐备不代表真实投递已实现。

本册只定义信息需求与业务行为；通知的承载形式与视觉由 Hallmark 设计决定。

<a id="scope"></a>
## 1. 本模块通知范围

**本期本模块没有独立发送事件，也没有新增消息模板。** 账户的新增、修改、删除与默认标记都是本企业本人对自己数据的即时维护：已确认口径明确“账户变更不需审核”，没有第二方需要处理，也没有任何已确认的裁定要求就账户变更向本人或运营发送站内信。因此本册不定义事件、不定义模板、不登记收件范围，也不为“可选通知开关”编造事件。

| 动作 | 通知处理 |
| --- | --- |
| 新增法币收款账户、新增数币收款账户 | 不发送。结果在本次操作内即时可见；不产生运营待办，不发欢迎或登记回执 |
| 修改账户、删除账户、设为或取消默认 | 不发送。见[待确认的安全告知](#pending)——这两处是唯一有理由考虑告知的场景，但尚无裁定，本期不发 |
| 地址所有权签名通过或失败 | 不发送。签名是本次登记流程内的即时结果，不是需要事后告知的业务事实 |
| 读取账户失败、保存失败、校验失败 | 不发送。属本次操作的即时反馈，不入消息池 |
| 账户被某笔业务选用、被选用后该账户被改动 | 不由本模块发送。业务进展的通知归发起该业务的模块；本模块不因自己的数据被引用而发消息 |

本模块也不向运营端产生任何消息或待办：运营既不查看也不维护企业账户，见[运营端不新增权限项（P-EA-02）](./01-企业账户-PRD.md#p-ea-02)。

<a id="ownership"></a>
## 2. 相关场景的通知归属

企业账户会出现在其他模块的业务流程里，那些提醒由来源模块发送，本模块既不重复发送、也不复述其规则：

| 场景 | 发送方 |
| --- | --- |
| 接受报价、登记放款等办理进展中涉及收款账户 | [授信报价与接受拒绝](../v1.0-借贷广场-授信报价与接受拒绝/03-授信报价与接受拒绝-消息通知.md)、[放款与放款确认](../v1.0-借贷广场-放款与放款确认/03-放款与放款确认-消息通知.md)按各自事件发送；通知正文不携带完整账户信息 |
| 账户维护入口因资格不足受限 | 属界面内的常驻提醒与引导，由登录主干与资金方账户模块定义，不是站内信 |
| 联系邮箱修改、账户停用／恢复、认证资格变化 | [资金方登录与账户体系](../v2.0-登录与账户体系/03-资金方登录与账户体系-消息通知.md)与[登录主干与资产方SSO接入](../v2.0-登录与账户体系/03-登录主干与资产方SSO接入-消息通知.md)的既有安全与资格通知，与收款账户无关，不因本模块改动 |

由于本模块零事件，[面客消息中心](../v1.0-面客消息中心/01-面客消息中心-PRD.md)的来源登记无需为本模块增行；其框架与未读口径不受影响。

<a id="privacy"></a>
## 3. 通知不得携带的内容

即使将来新增事件，也须遵守既有边界：企业账户属本企业档案，任何消息的预览、正文与目标页面都不得携带完整账号 / IBAN、完整收款地址或整组账户信息；对手方不得通过消息读取本模块账户。收件范围只归受影响的本企业账号，不按联系邮箱、业务联系人邮箱或钱包地址分发，也不向所有角色广播。

<a id="pending"></a>
## 4. 待确认的安全告知（本册建议，未自行写入）

对应[Q-EA-04](./01-企业账户-PRD.md#q-ea-04)。建议裁定是否新增一条“收款账户变更”强制安全站内信，与联系邮箱修改属同类：

- **理由**：收款账户直接决定资金去向，而平台已不再采集收款人名称、也不再具备“收款账户必须属于本企业”的自动校验能力（见[既定业务限制](./01-企业账户-PRD.md#limits)）。账户被改动或删除后，没有任何第二方会察觉。
- **风险集中在两处**：法币账户的修改、以及账户删除。数币账户的结算收款链与收款地址登记后不可修改、新增又必须由该地址本人签名，因此“地址被静默换掉”在本期不成立。
- **若裁定新增**：收件范围为本企业账号本人一条，属强制关键通知、不可退订；正文只说明“哪个账户备注名的账户发生了什么变化”，不携带账号或地址全文；同一次变更只一条，连续多次修改各为新事实。本册在取得裁定后补齐事件、模板与验收。
- **本期结论**：不发送。测试按零事件验收，不把“没有账户变更通知”判为缺陷。
