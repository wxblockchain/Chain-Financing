<a id="fl-o01"></a>
## FL-O01 共享入口、阅读与返回

规则：[功能 12.1](01-功能需求说明.md#entry)、[12.4](01-功能需求说明.md#detail)；验收 AC-O01～33、105～109。

```mermaid
flowchart TD
    A[运营人员位于本端任一模块] --> B{正常登录并有消息权限}
    B -->|否| X[按账户规则登录或拒绝消息访问]
    B -->|是| C[共享铃铛与本人邮箱角色菜单]
    C -->|铃铛| D[预览最近10条 仅展开不已读]
    C -->|消息中心| E[整页列表 分类与阅读筛选 分页]
    D -->|查看全部| E
    D -->|选择单条| F[进入消息详情并判断归属]
    E -->|整行阅读| F
    F -->|无权或不存在| N[不泄漏消息存在性]
    F -->|加载失败| R[保持未读 可重试或返回]
    R --> F
    F -->|内容成功呈现| G[仅本人自动已读 同账户各模块同步]
    G -->|查看原业务| H[按 FL-O03 与 FL-O05 判断]
    G -->|本人账户设置| I[进入本人设置 可返回原消息]
    I --> G
    G -->|返回列表| J[恢复筛选分页滚动与来源焦点]
    J --> E
```

列表无行内已读，预览无全部已读。详情刷新后同会话来源仍可恢复；切换账户不能恢复前一人内容。各模块共用个人已读不意味着跨端或跨人共享。

## FL-O02 已有来源与本端接收

规则：[功能 12.13](01-功能需求说明.md#sources)、[主册第 4 章](v1.0-运营端消息通知-PRD.md#4-既有消息来源与发送责任)；验收 AC-O71～83、100、112～116。

```mermaid
flowchart TD
    A[来源业务事实已确定] --> B{来源已定义本端通知及收件范围}
    B -->|仅面客或未定义| X[本端不复制 不推测新事件]
    B -->|已定义本端| C{已有同一事实的本端消息}
    C -->|有| D[沿用原消息 不改未读或发生时间]
    C -->|没有| E[按来源形成新的独立消息]
    E --> F{接收范围明确且属于本端}
    F -->|缺失或错端| Y[不猜收件人 保留供给依赖]
    F -->|全体运营或本人| G[合资格账户可见 个人阅读独立]
    D --> G
    G --> H[沿 FL-O01 阅读和进入原业务]
```

EV-L42 唯一由 WS-349 发送本端待审核；WS-357 负责本人密码安全站内信。WS-358/359 面客结果和 L5～L8 不复制运营。框架无独立事件、模板或邮件发送；共享登记和真实时效未完成不能标已接入。

## FL-O03 原业务目标、历史查看与动作失效

规则：[功能 12.6](01-功能需求说明.md#target)；验收 AC-O34～43、110～111。

```mermaid
flowchart TD
    A[本人合法消息详情] --> B{来源目标类型}
    B -->|无目标| C[正常阅读 无跳转入口]
    B -->|目标未登记| D[保留内容 无无效按钮 保留来源明确提示]
    B -->|静态页面| E[进入本端目标并按当前权限判断]
    B -->|原业务目标| F{原对象当前可读性}
    F -->|无权限| G[保留消息 说明目标无权限]
    F -->|删除或不可得| H[保留消息 说明原因 目标不可用]
    F -->|辅助判断失败或超时| E
    F -->|当前可读| I{原动作仍有效}
    I -->|否| J[保留原对象只读入口 不重演原动作]
    I -->|是| K[进入原业务 由原模块按当前状态办理]
    E --> L{目标自身权限和状态满足}
    L -->|否| M[拒绝无权内容或无效操作]
    L -->|是| N[仅提供当前允许的阅读或操作]
```

消息过期/主动失效不计未读，原动作不恢复；来源明确可留存的原对象仍按当前权限只读。旧机构提交不跳作新提交，不提供旧材料下载；协议历史与操作记录分别按 FL-O05。辅助判断超时绝不免除目标权限。

<a id="fl-o04"></a>
## FL-O04 当前筛选跨页全部已读

规则：[功能 12.5](01-功能需求说明.md#read)；验收 AC-O31～33、87、93～95、108。

```mermaid
flowchart TD
    A[用户发起全部已读] --> B{当前筛选存在未读}
    B -->|否| C[不可执行并说明]
    B -->|是| D[确认匹配未读数与筛选 说明跨页仅本人不可撤销]
    D -->|取消| A
    D -->|确认| E[处理本账户本端确认范围 暂停重复操作]
    E -->|成功| F[反馈实际处理结果 更新个人阅读与计数]
    E -->|失败| G[不报成功 不清零 可重试]
    E -->|会话失效| H[回本端登录 重登核实真实状态]
    F --> I[同账户跨模块同步 他人不变 新到消息未读]
```

列表总条数包含已读；确认数仅匹配未读。处理过程中到达的新消息不自动纳入范围，其他标签已读不重复计算。执行结果与业务完成无关。

<a id="st-o01"></a>
## ST-O01 单条消息的有效性

规则：[功能 12.6](01-功能需求说明.md#target)、功能 12.8；验收 AC-O05～06、42～43、91。

```mermaid
stateDiagram-v2
    [*] --> 生效中: 来源合法消息形成
    生效中 --> 已过期: 到达来源明确有效期
    生效中 --> 已主动失效: 来源明确失效事实
    note right of 生效中
        是否计未读还要判断本人阅读和历史边界
        原任务处理不自动改变本状态
    end note
    note right of 已过期
        不计未读 历史消息保留
        原动作停用 原对象按权限只读
    end note
    note right of 已主动失效
        不计未读 历史消息保留
        不清除个人阅读事实
    end note
```

无来源有效期不自设天数。本期不清理归档，故过期/失效后仍保留可查状态；目标无权、对象删除、业务已处理不是此状态机的转换条件。

<a id="st-o02"></a>
## ST-O02 一个账户对一条消息的阅读状态

规则：[功能 12.5](01-功能需求说明.md#read)；验收 AC-O25～33、51～53、75、108。

```mermaid
stateDiagram-v2
    [*] --> 未读: 新独立消息进入本人可见范围
    未读 --> 已读: 详情成功呈现后阅读成功 或确认全部已读成功
    未读 --> 未读: 只预览 加载失败 或同事实补送
    已读 --> 已读: 重复阅读 同事实补送 或本人邮箱变更
    note right of 已读
        不手动或自动改回未读
        首次阅读时间不覆盖
        不改变其他账户和其他端
    end note
```

新的真实业务事实有自己的状态机，不把旧消息改成未读。已读不完成审核、不改变资金状态、不关闭异常。失去消息资格期间不得使用阅读功能，资格恢复后沿用原阅读事实；无独立 SPV 阅读状态。

<a id="fl-o05"></a>
## FL-O05 消息准入与目标权限分别判断

规则：[功能 12.12](01-功能需求说明.md#permissions)；验收 AC-O44～64、101～103、111。

```mermaid
flowchart TD
    A[访问消息] --> B{正常登录并完成首次改密}
    B -->|否| C[进入本端账户流程 不泄漏内容]
    B -->|是| D{具有 PM-AL-12}
    D -->|否| E[拒绝消息功能 其他业务按自身权限]
    D -->|是| F{本端且属于本人可见范围}
    F -->|否| G[与不存在一致]
    F -->|是| H[可以阅读消息]
    H --> I{目标业务类型}
    I -->|本人设置| J[仅本人 PM-AL-14]
    I -->|机构认证| K[沿 WS-358 正常登录局部不分权]
    I -->|质押审核| L[沿 PM-AL-07 与 PM-AL-08 及逐笔状态]
    I -->|协议历史内容或文件| M[仅管理员 PM-AL-15]
    I -->|协议操作记录| N[正常管理员与专员 PM-AL-16 不以 PM-AL-09 为前提]
    I -->|协议当前内容或办理| O[沿 PM-AL-09 至 PM-AL-11]
```

无 PM-AL-12 者仍可从原业务入口读取 PM-AL-16 允许的操作记录；不因记录可读恢复消息准入。机构局部例外不扩展到质押或协议。所有分支仍受本人私人资料边界约束，不能把管理员称谓当作他人个人消息权限。
