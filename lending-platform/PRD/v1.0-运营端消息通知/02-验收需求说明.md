# 运营端消息通知 V1.1 · 02 验收需求说明

测试主读。统一规则见[功能册](01-功能需求说明.md)，范围、来源及依赖见[主册](v1.0-运营端消息通知-PRD.md)，业务分支见[独立图册](v1.0-运营端消息通知-流程图与状态机.md)。沿用 AC-O01～104 的对象及功能对应，相关口径按最新确认同步；补充 AC-O105～116。以下为可验收结果，不是测试脚本或实现检查清单。

## 13. 验收要求

共用前提：除拒绝/会话场景外，为本端正常运营账户、已完成首次改密、具有 PM-AL-12；分别覆盖管理员、专员及承担 SPV 职责的账号。真实来源事件验收须使用来源已定义事实及目标；演示记录只可验证交互，不能宣称真实投递、权限或时效通过。

### 13.1 M1 入口与未读提示（F-O01～F-O05）

规则回查：[功能 12.1～12.2](01-功能需求说明.md#entry)；图 FL-O01、FL-O05。目标是同账户在本端跨模块看到一致消息，跨端、跨账户不混用。

| 编号 | 场景与预期 |
| --- | --- |
| AC-O01 | 合资格账户在本端各业务页面可用共享铃铛；未登录不展示受保护消息入口 |
| AC-O02 | 铃铛与账户入口在各模块行为一致、可辨识；保留已采纳公共导航，不因模块切换丢通知 |
| AC-O03 | 无有效未读时不显示角标数字 0 |
| AC-O04 | 本人本端有效未读为 1～99 时显示真实数，超过时为 99+ |
| AC-O05 | 过期或来源主动失效的未读不计角标，历史仍可查，详情有对应说明；列表阅读标签仍仅已读/未读 |
| AC-O06 | 仅因目标删除、已处理或无权，不把消息自动置为过期或已读；计数服从真实消息状态 |
| AC-O07 | 账户菜单“消息中心”直接进入默认 P-O20，不先经过预览，不新增侧栏一级菜单 |
| AC-O08 | 预览最近 10 条含已读；再次点铃铛、外部点击、Esc、关闭操作等价收起，焦点还给铃铛 |
| AC-O09 | 仅展开、悬浮或滚动预览不已读；选中消息且详情成功展示后才已读 |
| AC-O10 | 后台暂停刷新，回到前台立即更新；普通刷新失败保留最后可信计数，会话失效走退出流程 |

| AC-O42 | 过期、原任务流转、目标删除和目标无权各有准确说明；原动作失效而原对象仍可读时保留只读查看，不恢复办理 |
| AC-O43 | 所有目标失败分支保留本人合法消息的标题、正文及原时间；原因对键盘、读屏可感知 |
