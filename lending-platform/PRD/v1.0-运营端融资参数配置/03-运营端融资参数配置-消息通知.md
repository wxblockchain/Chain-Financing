# 运营端融资参数配置 · 消息通知

2026-09-24｜需求评审稿｜配套本模块[主 PRD](01-运营端融资参数配置-PRD.md)与[流程图与状态机](02-运营端融资参数配置-流程图与状态机.md)。

本册只定义本模块的发送边界；站内消息的可见范围、未读计数、自动已读与跳转归[运营端消息通知](../v1.0-运营端消息通知/01-运营端消息通知-PRD.md)，本册不重复定义。通知的承载形式与视觉由设计决定（见[统一条款](01-运营端融资参数配置-PRD.md#design-boundary)）。

<a id="conclusion"></a>
## 1. 结论

**本模块零发送事件、零模板，运营方与面客侧均无新增通知。** 融资参数的维护是运营人员本人发起、本次办理内即时完成的同步动作：结果由办理结果与[参数变更记录](01-运营端融资参数配置-PRD.md#f-o-fc-02)当场告知，没有需要异步通知的事实。本模块也没有定时生效、待生效计划或发布环节，因而不存在“按计划成功／失败”这类时点事件。

本模块不新增站内信事件，也不新增邮件、短信或浏览器推送。列表与办理中的校验提示、保存结果、取数失败与重试属于页面反馈，不是消息通知；不为通知开关编造事件，不设“暂无通知”占位记录。

<a id="ownership"></a>
## 2. 场景与发送归属

| 场景 | 本模块处理及责任 |
| --- | --- |
| 查看融资参数列表、参数详情与变更记录 | 不发送；不增加未读，不改变既有消息的已读状态或先后顺序 |
| 保存最高质押率或最长项目期限成功 | 不发送。结果由本次办理结果与[参数变更记录](01-运营端融资参数配置-PRD.md#f-o-fc-02)告知；不向其他运营人员广播，不通知资产方或资金方 |
| 保存被校验拒绝、取消保存确认、离开办理放弃输入 | 均不发送；未成功的改动连变更记录也不产生，更不产生消息 |
| 保存失败或提交结果未知 | 不发送。按[参数维护与保存](01-运营端融资参数配置-PRD.md#f-o-fc-03)当场如实呈现并可重试，不以站内信替代办理结果，也不伪报成功 |
| 上限调至低于某些存量项目已锁定的值 | 不发送。存量项目按[生效与存量隔离（D-O-FC-03）](01-运营端融资参数配置-PRD.md#d-o-fc-03)不受影响，不产生整改提醒、存量清单或待办 |
| 上游新增代币类型、移出代币类型、取值或参数读取失败 | 不发送。运营须能在列表中察觉未配置行与取数失败（[代币类型供给与未配置处理](01-运营端融资参数配置-PRD.md#f-o-fc-06)），但本模块不新增运营告警模板或补配置任务 |
| 资产方创建项目时因超出上限被拒、或因无可选代币类型不能提交 | 由[融资需求与代币质押](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md)按其既有规则在办理中提示，不由本模块发送；本模块不向资产方推送参数变更 |
| 项目审核、合约部署及其结论 | 归管理端合约管理与[项目审核（F-LS-22）](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#f-ls-22)，按其所属册的通知规则发送；本模块看到同一事实不补发、不转发 |
| 逐笔代币质押的审核通过、驳回与自助解押 | 归[代币质押审核通知](../v1.0-代币质押审核/03-代币质押审核-消息通知.md)与[融资与质押通知](../v1.0-借贷广场-融资需求与代币质押/03-融资需求与代币质押-消息通知.md)；本模块不参与，也不改变其收件人或文案 |
| 运营账号、密码与工作邮箱安全事件 | 归[运营端账户与登录通知](../v1.0-运营端账户与登录/03-运营端账户与登录-消息通知.md)；本模块的零通知不取消这些事件 |

<a id="boundary"></a>
## 3. 收件与内容边界

本模块无事件，因而没有本模块的收件人。运营人员因其他模块事件收到的消息不得因本模块的参数变动而改变数量、时间或已读状态。参数值、变更记录、操作人与运营端入口不得出现在任何面客消息的正文或变量中；资产方在创建项目时只获得当前上限用于校验提示，见[创建项目的参数供给](01-运营端融资参数配置-PRD.md#f-o-fc-05)。

后续若确有需要新增本模块事件，须先补充已确认的触发事实、收件范围与时点，并在[运营端消息通知](../v1.0-运营端消息通知/01-运营端消息通知-PRD.md)完成唯一登记；在此之前不得以“参数已更新”之类的名义自行开设广播。

<a id="acceptance"></a>
## 4. 关键验收

| 编号 | 可观察结果 |
| --- | --- |
| <a id="ac-o-fc-n01"></a>`AC-O-FC-N01` 三方零事件 | 运营管理员、运营专员、资产方与资金方均不存在本模块新增的站内信事件；消息中心与运营端消息通知中没有本模块的事件或模板登记，也没有占位记录 |
| <a id="ac-o-fc-n02"></a>`AC-O-FC-N02` 保存成功不发信 | 最高质押率或最长项目期限保存成功后，不产生任何站内信、邮件、短信或推送；结果只由本次办理结果与参数变更记录告知 |
| <a id="ac-o-fc-n03"></a>`AC-O-FC-N03` 未成功的改动无消息 | 校验拒绝、取消确认、放弃未提交输入、保存失败与结果未知，均不产生消息，也不产生变更记录 |
| <a id="ac-o-fc-n04"></a>`AC-O-FC-N04` 上限调低不提醒 | 上限被调至低于存量项目锁定值时不产生任何提醒、整改待办或存量清单；存量项目锁定值与其有效质押额、有效期至均不变 |
| <a id="ac-o-fc-n05"></a>`AC-O-FC-N05` 供给异常仍可察觉 | 上游新增、移出代币类型及取数失败时，运营仍能在列表中察觉，但不以新增运营告警或补配置任务代替该项验收 |
| <a id="ac-o-fc-n06"></a>`AC-O-FC-N06` 面客零推送 | 参数变更不向资产方、资金方推送；创建项目被拒时的提示由融资需求与代币质押在办理中给出，不产生本模块消息 |
| <a id="ac-o-fc-n07"></a>`AC-O-FC-N07` 不改写他册事件 | 项目审核、逐笔质押审核、自助解押及账户安全事件仍由其所属册发送；本模块展示或读取相同事实不补发、不转发、不重置原消息已读或先后顺序 |
| <a id="ac-o-fc-n08"></a>`AC-O-FC-N08` 内容不外泄 | 参数值、变更记录、操作人与运营端入口不出现在任何面客消息的正文或变量中；面客侧只获得创建项目所需的当前上限 |

通知验收不替代主 PRD 的参数维护、生效隔离与供给验收。
