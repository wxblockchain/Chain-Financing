<a id="fl-o-fc-01"></a>
## FL-O-FC-01 参数读取与维护

回指[融资参数列表与检索](01-运营端融资参数配置-PRD.md#f-o-fc-01)、[参数详情与变更记录](01-运营端融资参数配置-PRD.md#f-o-fc-02)、[参数维护与保存](01-运营端融资参数配置-PRD.md#f-o-fc-03)。查询权与维护权分别判定；缺查询权的维护权配置不得绕过准入。

```mermaid
flowchart TD
    A[运营账号进入融资参数配置] --> B{账号正常 已改初始密码且登录有效}
    B -->|否| C[按账户状态引导 不开放参数内容]
    B -->|是| D{具融资参数查询权}
    D -->|否| E[说明无权并保留原入口返回]
    D -->|是| F[融资参数列表 按代币类型逐行读取]
    F --> G[进入代币类型参数详情 先当前参数后变更记录]
    G --> H{具融资参数维护权}
    H -->|否| I[只读 不提供参数维护动作]
    H -->|是| J[参数维护 载入当前值 未配置时为空]
    J --> K{两项参数均通过校验}
    K -->|否| L[按项拒绝 说明该项当前允许范围 不留痕]
    K -->|是| M[保存确认 展示变更前后与存量不变说明]
    M -->|取消| N[参数完全不变 继续本次办理]
    M -->|确认| O{保存结果}
    O -->|成功| P[新值即时生效 记录一条变更 回到参数详情]
    O -->|失败或结果未知| Q[两项参数全部保持原值 不伪报成功 保留输入可重试]
    O -->|他人已先行修改| R[拒绝旧内容 提示重新取数]
    O -->|代币类型已被上游移出| S[拒绝保存并说明 不写入不存在的类型]
```

仅有查询权时内容完整可读但无办理动作。未提交的编辑、被拒绝的保存与取消确认都不产生变更记录。两项参数要么全部采用新值、要么全部保持原值，不出现一项已改而另一项仍旧。

<a id="fl-o-fc-02"></a>
## FL-O-FC-02 创建项目的参数供给与锁定

回指[创建项目的参数供给](01-运营端融资参数配置-PRD.md#f-o-fc-05)、[参数生效与存量隔离](01-运营端融资参数配置-PRD.md#f-o-fc-04)。面客侧的自填与提示规则以[融资需求与代币质押](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#f-ls-01)为准，本图只表达参数从何而来、在哪个时点被取用。

```mermaid
flowchart TD
    A[资产方发起创建融资项目] --> B{参数与代币类型可读}
    B -->|否| C[说明暂不可办理并可重试 不以无上限或默认值继续]
    B -->|是| D[可选代币类型 取已配置类型与本企业已有代币类型的交集]
    D --> E{存在可选代币类型}
    E -->|否| F[不能提交 提示先完成代币发行与同步]
    E -->|是| G[资产方自填质押率与项目期限]
    G --> H[提交创建 以提交时点读取当前参数]
    H --> I{自填值是否越界}
    I -->|质押率超当前最高质押率| J[不可提交并给出当前上限]
    I -->|期限超出平台区间与配置上限中更小者| K[不可提交并说明可填范围]
    I -->|均未越界| L[创建成立 参数随项目锁定终身]
    L --> M[项目进入待审核 审核核对提交时锁定的快照]
    M --> N[运营此后调整参数 不改写本项目锁定值]
```

校验与锁定取同一份提交时点的参数值，不出现校验用旧值而锁定用新值。运营保存成功之后提交的创建适用新值；保存失败时仍按原上限校验。

<a id="fl-o-fc-03"></a>
## FL-O-FC-03 代币类型取值增减与读取失败

回指[代币类型供给与未配置处理](01-运营端融资参数配置-PRD.md#f-o-fc-06)。代币类型取值全集由代币发行与同步的上游供给，运营不能在本模块新增、改名或删除。

```mermaid
flowchart TD
    A[上游代币类型取值发生变化或读取异常] --> B{本次情形}
    B -->|新增取值| C[以未配置状态出现在列表 运营可察觉]
    C --> D[配置完成前不可用于创建项目]
    B -->|取值被移出| E[不再展示为可维护行 不再供给创建]
    E --> F[已创建项目按锁定值不受影响 其变更记录保留可追溯]
    B -->|读取失败| G[列表说明取数失败并可重试 不以空列表冒充暂无代币类型]
    G --> H[创建侧说明暂不可办理并可重试 本模块不自动写入任何参数值]
    B -->|取值齐备但均未配置| I[列表如实呈现未配置行 无新增入口]
    I --> J[创建侧无可选类型 不以平台默认参数兜底放行]
```

<a id="st-o-fc-01"></a>
## ST-O-FC-01 代币类型融资参数状态机

对象是**单个代币类型的融资参数配置**，不是项目、代币或质押笔。状态取自[配置状态（FC-04）](01-运营端融资参数配置-PRD.md#fc-04)：两项参数均有有效值为已配置，任一缺失为未配置。本模块没有草稿、待生效、已归档或已下线状态。

```mermaid
stateDiagram-v2
    state "未配置 两项参数任一缺失" as Unset
    state "已配置 两项参数均有有效值" as Configured
    [*] --> Unset: 上游供给新的代币类型
    Unset --> Unset: 保存被校验拒绝 保存失败 或 取消确认
    Unset --> Configured: 首次保存成功 两项参数同时写入
    Configured --> Configured: 再次保存成功 记录一次新的变更
    Configured --> Configured: 保存失败或被拒 全部参数保持原值
    Unset --> [*]: 代币类型被上游移出
    Configured --> [*]: 代币类型被上游移出 变更记录仍保留
```

转换只由运营的保存成功与上游取值增减触发，不因时间流逝、项目创建、项目审核或质押结果自动变化。取值被移出后该行不再可维护，但其变更记录不删除；同名取值再次出现时按新的未配置行处理，不恢复旧值。

<a id="st-o-fc-02"></a>
## ST-O-FC-02 项目参数取值的锁定

对象是**单个融资项目所采用的参数取值**，说明运营参数与项目锁定值之间的关系；项目自身的状态机以[项目状态机](../v1.0-借贷广场-融资需求与代币质押/02-融资需求与代币质押-流程图与状态机.md#st-ls-01)为准，本图不重复。

```mermaid
stateDiagram-v2
    state "未取值 创建尚未提交" as Pending
    state "已锁定 随项目终身不变" as Locked
    [*] --> Pending: 资产方填写创建信息
    Pending --> Pending: 自填值越界被拒 仍未取值
    Pending --> Locked: 提交创建成功 以提交时点参数校验并锁定
    Locked --> Locked: 运营调高或调低参数 本项目取值不变
    Locked --> Locked: 审核退回后修改重提 项目期限不重新起算
    Locked --> [*]: 项目进入终态 锁定值随项目留存
```

已锁定的[项目质押率（FP-34）](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#fp-34)与[项目期限（FP-35）](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#fp-35)终身不变：参数调整不触发额度重算、覆盖判定或到期日变化，[有效质押额（FP-12）](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#fp-12)始终按该锁定质押率计算。上限被调至低于存量锁定值不构成冲突，也不产生存量整改。
