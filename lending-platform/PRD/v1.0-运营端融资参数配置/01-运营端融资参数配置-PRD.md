# 运营端融资参数配置 · PRD

2026-09-24｜运营管理平台 · 运营端（运营管理员 `RO-AL-1`、运营专员 `RO-AL-2`）｜需求评审稿，真实未决项见[第 5 节](#questions)。

## 1. 目标与阅读入口

运营人员按代币类型维护平台的两项融资参数——最高质押率与最长项目期限，为资产方创建融资项目时的自填取值提供上限；参数改动只对此后新建的项目生效，已创建项目沿用其创建时锁定的值。

本期包含：按代币类型读取与检索融资参数、参数维护与保存、参数的即时生效与存量隔离、参数变更留痕、向创建融资项目供给可选代币类型与当前上限、代币类型供给缺失时的可识别处理。相邻模块负责：运营账号、会话与功能权限项的登记（[运营端账户与登录](../v1.0-运营端账户与登录/01-运营端账户与登录-PRD.md)）；资产方创建项目时的自填、校验与锁定（[融资需求与代币质押](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md)）；逐笔代币质押的查询与处置（[代币质押审核](../v1.0-代币质押审核/01-代币质押审核-PRD.md)）；运营端站内消息的可见范围与未读计数（[运营端消息通知](../v1.0-运营端消息通知/01-运营端消息通知-PRD.md)）。

本期不包含：**逐笔质押的查询与处置**（归代币质押审核）、项目审核与合约部署（归管理端合约管理，业务时点定义在[项目审核（F-LS-22）](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#f-ls-22)）、代币类型的新增／改名／停用、存量项目参数的调整或重算、按企业或按项目的差异化参数、质押率分档与利率类参数、定时生效与生效计划、审批复核与双人确认、参数的导入导出与批量编辑、面客侧的参数展示设计。

有效依据：需求诊断简报（2026-09-24 批 · V4 定稿）第 4.3 节——运营按合并后的代币字段配置最高质押率与项目期限；资产方创建项目时自填、不得超过上限、创建即锁定终身、运营后续调整不影响存量项目；项目期限 3 个月～1 年、自项目创建时间起算。已入库的[融资需求与代币质押](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md)、[代币质押审核](../v1.0-代币质押审核/01-代币质押审核-PRD.md)、[资产广场](../v1.0-资产广场-已上架代币只读域/01-资产广场-PRD.md)正文为业务口径来源，业务名称取[字段命名与术语对照表](../00-字段命名与术语对照表.md)。

## 2. 共同业务规则

<a id="design-boundary"></a>
本册只定义信息需求与业务行为；页面布局、组件形态、层级与视觉由 Hallmark 设计决定。本册措辞与设计稿冲突时以设计稿为准，业务口径仍以本册为准。

“融资参数列表”“代币类型参数详情”“参数维护”指本模块的信息域与办理入口，“保存确认”指其二次确认环节，均与界面上的位置和承载形式无关；`P-O-FC-*` 是信息域编号、`C-O-FC-*` 是确认环节编号，供跨册归属与权限挂靠引用，不指定其呈现方式。

<a id="d-o-fc-01"></a>
### 2.1 配置对象与单一取值来源（`D-O-FC-01`）

| 规则 | 产品含义 |
| --- | --- |
| 配置维度是代币类型 | 融资参数按[代币类型（FP-29）](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#fp-29)组织，一个代币类型对应一条融资参数配置。代币类型是代币标准与底层资产类型合并后的单一字段，形如 `ERC-20-应收账款`；字段形态须能容纳将来的其他标准（如 `TRC-20-应收账款`），本册任何位置都不写死 `ERC-20` |
| 取值域来自上游 | 代币类型的取值全集由代币发行与同步的上游供给，与[资产广场](../v1.0-资产广场-已上架代币只读域/01-资产广场-PRD.md)读到的是同一取值域。**运营不能在本模块新增、改名、合并或删除代币类型**，也不能凭手工输入造出一个取值 |
| 参数只有两项 | 一条配置只包含[最高质押率（FC-02）](#fc-02)与[最长项目期限（FC-03）](#fc-03)两项可维护参数，不含利率、费率、额度、币种、链或审核相关参数 |
| 配置不是业务数据 | 本模块维护的是创建项目时的取值上限，不是项目、代币或质押的业务事实。任何项目、代币或质押笔的读取与处置都不在本模块，读取归各自来源册，逐笔质押处置归[代币质押审核](../v1.0-代币质押审核/01-代币质押审核-PRD.md) |
| 本期规模 | 上游本期只有一个代币类型，**列表本期只有一行**；规格按多行编写，不因当前只有一行而省略检索、空态与分行维护，也不把该行写成平台唯一固定行 |

<a id="d-o-fc-02"></a>
### 2.2 角色与准入（`D-O-FC-02`）

“运营人员”指本端正常、已完成首登改密且登录有效的运营管理员与运营专员。账号与授权由[运营端账户与登录](../v1.0-运营端账户与登录/01-运营端账户与登录-PRD.md)承接，本模块不新增人员或授权管理功能。

本模块需要两个功能权限项，按该册[权限组织方式（D-AL-07）](../v1.0-运营端账户与登录/01-运营端账户与登录-PRD.md#d-al-07)的“一个动作一个可授权项”登记：

| 需要的权限项（业务名称） | 覆盖的动作 | 不包含的能力 |
| --- | --- | --- |
| 融资参数查询 | 进入融资参数列表（`P-O-FC-01`）与代币类型参数详情（`P-O-FC-02`），读取当前参数值、配置状态与参数变更记录 | 不含修改、保存；不含逐笔质押、项目或代币的业务查询 |
| 融资参数维护 | 修改并保存最高质押率与最长项目期限；须同时具备融资参数查询 | 不含新增或删除代币类型；不含项目审核；不含对存量项目的任何调整 |

两项权限的最终编号由[运营端账户与登录](../v1.0-运营端账户与登录/01-运营端账户与登录-PRD.md)在其修订批次于现有 `PM-AL-*` 段位末尾追加，本册只登记需要哪些权限及其可观察结果，不代该册分配编号、不代改权限矩阵；沿该册“某模块拆出更细动作时在本段位内追加”的既定做法，本册把简报所称的“融资参数配置”一类拆为查询与维护两项——只读岗位需要能核对当前上限而不能改值，合成一项无法表达。收口以该册正文为准，见[权限项登记（Q-O-FC-01）](#q-o-fc-01)。

已有的“运营业务数据查询”（`PM-AL-13`）是运营视角的业务数据只读查询，不覆盖本模块的参数配置；不得以该项代替融资参数查询。管理员固定具有本期业务权限，专员的可配置性沿该册规则。

未登录、登录失效、待首登改密或账号锁定时不开放本模块任何内容，按账户模块引导；有效账号无目标权限时说明限制并保留原入口返回。查询权与维护权分别判定，进入信息域与提交保存都不得绕过。资产方、资金方、游客及其他平台账号不能读取本模块，参数值对面客的可见范围只有创建项目时的当前上限提示，见[创建项目的参数供给（F-O-FC-05）](#f-o-fc-05)。

<a id="d-o-fc-03"></a>
### 2.3 生效与存量隔离（`D-O-FC-03`）

| 规则 | 产品含义 |
| --- | --- |
| 即时生效 | 保存成功即为当前有效参数，无草稿、无定时生效、无待生效版本、无发布动作。保存失败则全部参数保持原值 |
| 只约束此后的创建 | 新参数只作用于**保存成功之后**提交的项目创建；提交时点以资产方的创建提交为准 |
| 存量锁定终身 | 已创建项目的[项目质押率（FP-34）](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#fp-34)与[项目期限（FP-35）](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#fp-35)是创建时锁定的值，运营此后调高或调低都不改写存量项目，也不触发任何额度重算、覆盖判定或项目到期日变化 |
| 允许低于存量值 | 最高质押率可调至低于某些存量项目已锁定的质押率，最长项目期限同理。这不构成冲突、不拦截保存、不产生存量整改任务，也不使存量项目变为违规 |
| 审核核对用快照 | 待审核项目在提交创建时已锁定参数；项目审核核对的是该快照，审核期间运营改动参数不影响在审项目的核对结论与[审核退回](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#f-ls-22)后的重提 |

## 3. 功能需求

<a id="f-o-fc-01"></a>
### 3.1 融资参数列表与检索（`F-O-FC-01`）

适用角色与前提：运营人员完成准入且具融资参数查询权。

运营人员从“融资参数配置 / Financing parameters”进入融资参数列表（`P-O-FC-01`），列表按代币类型逐行呈现当前生效参数，并提供进入代币类型参数详情（`P-O-FC-02`）的动作。列表不提供新增、删除代币类型的入口，也不提供逐笔质押、项目或代币的跳转。流程见[参数读取与维护（FL-O-FC-01）](02-运营端融资参数配置-流程图与状态机.md#fl-o-fc-01)。

**列表信息**：代币类型、最高质押率、最长项目期限、配置状态、最近更新时间与最近更新人。未配置的代币类型，两项参数值显示“—”，不显示为 0、不显示为平台默认值；最近更新时间与最近更新人同样显示“—”。

**检索与排序**：关键词模糊匹配代币类型名称，忽略大小写与前后空格；配置状态可按已配置、未配置筛选。“查询”应用条件，“重置”清空并回第 1 页。默认按代币类型名称升序，最近更新时间可排序。默认每页 20 条，可切 50、100；重新取数、浏览器前进后退保留筛选与分页；办理完成返回列表时回到来源并保留原筛选、排序、分页与所在位置。

取数进行中须可识别，失败可重试且保留条件。三种空结果须可区分：无融资参数查询权限时说明无权并保留原入口返回；上游尚无代币类型时说明“暂无代币类型，代币类型由代币发行与同步提供”，并且不提供新增入口；筛选无匹配时说明“没有符合条件的代币类型”并提供重置。

<a id="f-o-fc-02"></a>
### 3.2 参数详情与变更记录（`F-O-FC-02`）

适用角色与前提：同上；具融资参数查询权即可读取，不要求维护权。

代币类型参数详情（`P-O-FC-02`）包含“当前参数”与“参数变更记录”两部分，二者须同时可得，顺序固定为先当前参数后变更记录，不另立独立的记录信息域。具维护权时在此进入参数维护（`P-O-FC-03`）；仅有查询权时不提供该动作，内容仍完整可读。

**当前参数与配置字段**：

| 业务信息 | 含义与业务类型 | 必填、可编辑与校验 | 默认值 |
| --- | --- | --- | --- |
| <a id="fc-01"></a>代币类型（`FC-01`） | 文本；代币标准与底层资产类型合并的单一字段，形如 `ERC-20-应收账款` | 取上游供给的取值，**运营只读**；不可新增、改名或删除；不写死 `ERC-20` | 无 |
| <a id="fc-02"></a>最高质押率（`FC-02`） | 百分比；本代币类型允许的项目质押率上限 | 具维护权可编辑；保存时必填且须落在允许取值范围内，超范围拒绝并给出当前允许范围。取值上下限与小数位数尚缺裁定，见[参数取值边界（Q-O-FC-02）](#q-o-fc-02) | 未配置时为空，不补平台默认值 |
| <a id="fc-03"></a>最长项目期限（`FC-03`） | 整月数；本代币类型允许的项目期限上限 | 具维护权可编辑；保存时必填，取值 3～12 的整数月——下界 3 个月与上界 1 年是[项目期限（FP-35）](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#fp-35)已确认的平台区间，配置值不得越出该区间 | 未配置时为空 |
| <a id="fc-04"></a>配置状态（`FC-04`） | 枚举：已配置 / 未配置 | 系统判定、只读；两项参数均有有效值为已配置，任一缺失为未配置 | 未配置 |
| <a id="fc-05"></a>最近更新时间与最近更新人（`FC-05`） | 时间点与运营人员归属 | 系统记录、只读；按读者时区展示并标注时区，人员按脱敏后的可读归属呈现 | 未配置时为“—” |

<a id="fc-06"></a>**参数变更记录（`FC-06`）**：每次保存成功产生一条记录，含发生时间、操作人（脱敏后的可读归属）、变更前后的最高质押率与最长项目期限、本次结果。首次配置记为从“—”到新值，不伪装成修改。记录只读、不可编辑删除，按发生时间倒序，默认 20 条；未提交的编辑、被拒绝的保存与取消确认不产生记录，不把未成功的输入记成已生效变更。记录不按本人经办过滤。尚无记录、取数失败与登录失效三种情形须可区分并分别表达。

变更记录中不出现项目、代币、质押笔或企业信息；读者不能从本模块的记录跳转到任何逐笔质押对象。

<a id="f-o-fc-03"></a>
### 3.3 参数维护与保存（`F-O-FC-03`）

适用角色与前提：运营人员完成准入，同时具融资参数查询与融资参数维护权；代币类型来自上游当前有效取值。仅有查询权者不提供本办理；仅被配置维护权而缺查询权时拒绝动作并说明须由建设方修正配置，修正前不得绕过准入。

从代币类型参数详情进入参数维护（`P-O-FC-03`），载入该代币类型的当前值；未配置时两项为空，不预填任何演示值或平台默认值。一次办理只维护一个代币类型，不提供多行批量编辑、复制到其他类型或导入导出。代币类型本身在办理中只读。

**保存规则**：两项参数须同时通过校验才可提交；提交进入保存确认（`C-O-FC-01`），确认内容展示代币类型、变更前后的最高质押率与最长项目期限，并说明“仅对此后新建项目生效，不改变存量项目”。确认后按完整成功结果执行，取消则不改变任何已生效参数。保存成功后回到代币类型参数详情并更新当前参数与变更记录，同时明确告知已保存。

未作任何改动时不可重复提交；正在提交时不重复执行；一次保存要么两项参数全部采用新值，要么全部保持原值，不出现一项已改、另一项仍旧的中间结果。

**校验与拒绝**：最高质押率超出允许取值范围、最长项目期限不在 3～12 整月区间、任一项为空或格式不合法时拒绝保存，错误须可定位到具体项并说明该项的当前允许范围；只说“输入有误”不合格。校验拒绝不产生变更记录。

**异常与边界**：离开办理时若有未提交内容须先确认，取消则继续本次办理，确认才放弃本次输入。该代币类型的参数被他人先行修改后，后提交的旧内容被拒并提示重新取数；失败保留可重试输入。重新取数将丢弃输入时先确认。提交失败或结果未知时不伪报成功，按真实状态展示并保留输入，不产生虚假的变更记录。代币类型在办理期间被上游移出有效取值时拒绝保存并说明，不静默写入一个已不存在的类型。

状态见[代币类型融资参数状态机（ST-O-FC-01）](02-运营端融资参数配置-流程图与状态机.md#st-o-fc-01)。

<a id="f-o-fc-04"></a>
### 3.4 参数生效与存量隔离（`F-O-FC-04`）

适用角色与前提：保存成功后自动适用，无须运营再做动作。

生效与隔离的共同口径见[生效与存量隔离（D-O-FC-03）](#d-o-fc-03)，本节定义可观察结果：

| 场景 | 成功结果与边界 |
| --- | --- |
| 保存成功 | 新值立即成为该代币类型的当前有效参数；本模块与创建项目读到同一份当前值，不存在新旧并存的过渡期 |
| 保存成功后新建项目 | 按新上限校验自填值；提交时点在保存之后的创建适用新值 |
| 保存成功后回看存量项目 | 已创建项目的项目质押率与项目期限保持创建时锁定值；有效质押额按该锁定质押率计算（[有效质押额（FP-12）](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#fp-12)），[有效期至（FP-09）](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#fp-09)不变 |
| 上限调低到存量值以下 | 保存正常成功；存量项目不被标记、不被拦截、不触发整改或强制关闭；本模块不产生任何存量清单或待办 |
| 待审核项目在审期间参数变动 | 按提交创建时锁定的快照核对；审核结论与退回后重提均不因参数变动而改变，项目期限不重新起算 |
| 保存失败 | 全部参数保持原值；此后的创建仍按原上限校验，不出现部分生效 |

本模块不提供参数的回滚、撤销、历史值恢复或定时切换；需要改回原值时按正常维护重新保存，并作为一次新的变更留痕。

项目侧取值的锁定关系见[项目参数取值的锁定（ST-O-FC-02）](02-运营端融资参数配置-流程图与状态机.md#st-o-fc-02)。

### 3.5 创建项目的参数供给（`F-O-FC-05`）

适用角色与前提：资产方在面客端创建融资项目，见[创建融资项目（F-LS-01）](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#f-ls-01)。本节只定义本模块向该环节供给什么，自填、校验提示与锁定动作的面客规则以该册为准，本册不改写。

| 供给内容 | 本模块的责任边界 |
| --- | --- |
| 可选代币类型 | 只有配置状态为已配置的代币类型才进入创建项目的可选范围；未配置的不可选。面客侧再按该企业已有代币的类型过滤，两层过滤取交集 |
| 当前最高质押率 | 供创建环节校验自填质押率并在超限时给出当前上限。面客侧只需要这一个数值，不暴露配置状态、变更记录、操作人或运营端入口 |
| 当前最长项目期限 | 供创建环节校验自填项目期限。平台区间 3 个月～1 年与配置上限同时成立，实际可填上界取两者中更小的值 |
| 取值时点 | 以资产方**提交创建**的时刻读取当前参数并锁定；办理过程中运营改动参数时，以提交时点的值为准，校验与锁定用同一份值，不出现校验用旧值、锁定用新值 |

本模块不向面客提供参数的浏览入口、历史值、生效时间或运营人员身份。

流程见[创建项目的参数供给与锁定（FL-O-FC-02）](02-运营端融资参数配置-流程图与状态机.md#fl-o-fc-02)。

<a id="f-o-fc-06"></a>
### 3.6 代币类型供给与未配置处理（`F-O-FC-06`）

适用角色与前提：上游代币类型取值发生增减或读取异常时。

| 情形 | 业务处理 |
| --- | --- |
| 上游出现新的代币类型 | 以未配置状态出现在融资参数列表，运营应可察觉并完成配置；在配置完成前该类型不可用于创建项目 |
| 全部代币类型均未配置 | 列表如实呈现未配置行；创建项目侧无可选类型，按该册既有规则不能提交并提示先完成代币发行与同步，不以平台默认参数兜底放行 |
| 上游移出某代币类型 | 本模块不再展示该类型的可维护行，其参数不再供给创建；**已创建项目不受影响**，仍按锁定值运行。该类型的参数变更记录保留可追溯，不因取值移出而删除 |
| 代币类型读取失败 | 列表说明取数失败并可重试，不以空列表冒充“暂无代币类型”；创建项目侧按该册的依赖不可用规则处理，不静默放行一个无上限的自填值 |
| 参数读取失败 | 创建项目侧不得以无上限或平台默认值继续，须说明暂不可办理并可重试；本模块不因此自动写入任何参数值 |

流程见[代币类型取值增减与读取失败（FL-O-FC-03）](02-运营端融资参数配置-流程图与状态机.md#fl-o-fc-03)。

### 3.7 展示、安全与质量（`N-O-FC-01`）

界面默认英文并支持中英切换，办理中途切换语言不丢输入、不改变已保存参数。时间按读者时区展示并标注时区；业务日期沿平台已确认的 UTC 口径。运营人员身份按脱敏后的可读归属呈现，不展示完整邮箱与完整 IP。全部业务动作须可仅用键盘完成，状态不只靠颜色表达。本模块不提供文件上传与下载，不承载协议、材料或凭据。

### 4.4 参数生效与存量隔离（关联 [3.4](#f-o-fc-04)）

前提：同一代币类型下已有创建完成的存量项目，且存在待审核项目。

| 场景与前提 | 应观察到的结果 | 验收定位 |
| --- | --- | --- |
| 保存成功后立即在本模块与创建项目侧读取参数 | 两侧读到同一份当前值，立即生效，无草稿、无待生效版本、无定时计划与发布动作 | <a id="ac-o-fc-18"></a>`AC-O-FC-18` 参数即时生效且无版本化流程（[D-O-FC-03](#d-o-fc-03)、[F-O-FC-04](#f-o-fc-04)） |
| 调高或调低上限后查看存量项目 | 存量项目的项目质押率与项目期限保持创建时锁定值；有效质押额仍按锁定质押率计算，有效期至不变；不触发额度重算、覆盖判定或到期日变化 | <a id="ac-o-fc-19"></a>`AC-O-FC-19` 存量项目锁定值不被参数调整改写（[D-O-FC-03](#d-o-fc-03)、[F-O-FC-04](#f-o-fc-04)） |
| 将最高质押率调至低于某存量项目已锁定的质押率 | 保存正常成功；存量项目不被标记为违规、不被拦截、不产生整改任务或存量清单 | <a id="ac-o-fc-20"></a>`AC-O-FC-20` 上限低于存量锁定值不产生存量整改（[D-O-FC-03](#d-o-fc-03)） |
| 在项目处于待审核期间修改参数，随后完成审核或退回重提 | 按提交创建时锁定的快照核对，结论不因参数变动改变；退回重提不重新起算项目期限 | <a id="ac-o-fc-21"></a>`AC-O-FC-21` 在审项目按提交时快照核对（[D-O-FC-03](#d-o-fc-03)） |
| 保存失败后再次创建项目，并在本模块寻找回滚入口 | 仍按原上限校验，不出现部分生效；不存在回滚、撤销、历史值恢复或定时切换入口，改回原值须作为一次新的变更留痕 | <a id="ac-o-fc-22"></a>`AC-O-FC-22` 失败不部分生效且无回滚入口（[F-O-FC-04](#f-o-fc-04)） |

| 在面客端寻找参数的浏览入口、历史值、生效时间与运营人员身份 | 均不可得；面客侧只获得当前上限用于校验提示 | <a id="ac-o-fc-27"></a>`AC-O-FC-27` 面客侧不暴露配置内情（[F-O-FC-05](#f-o-fc-05)） |

### 5.2 跨册标注（只标注不改写）

**权限矩阵的收口**：本模块所需的两项权限归[运营端账户与登录](../v1.0-运营端账户与登录/01-运营端账户与登录-PRD.md)登记，与[代币质押审核](../v1.0-代币质押审核/01-代币质押审核-PRD.md)已标注的“本批新增的项目审核、融资参数配置两类权限项归运营端账户与登录登记”一致。本册不代登记、不代改矩阵，也不因本模块上线自行扩张 `PM-AL-13` 的含义。

**参数配置与项目审核的分工**：审核与合约部署合为一步的业务时点定义在[项目审核（F-LS-22）](../v1.0-借贷广场-融资需求与代币质押/01-融资需求与代币质押-PRD.md#f-ls-22)，运营端的审核办理归管理端合约管理（WS-387）。本模块只供参数，不参与审核、不提供审核入口，也不把参数改动当作审核依据。

**逐笔质押的归属**：逐笔质押的查询与处置固定在[代币质押审核](../v1.0-代币质押审核/01-代币质押审核-PRD.md)，该册已声明本模块只提供参数、其自身只读消费结果。两册口径一致，本模块不设任何逐笔质押的只读副本。

**术语落地**：最高质押率与最长项目期限为本册新增业务名称，已按 R19 前置要求先进[字段命名与术语对照表](../00-字段命名与术语对照表.md)再落地；既有 `FP-*` 编号锚点一律不动，本册只引用不改写。
