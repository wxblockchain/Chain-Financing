# 用户中心偏好设置 · UI 视觉深化

2026-10-16 · WS-372 · existing-system adaptation / console，局部视觉修订。

基线为 `cly-4.0.0 @ 353cfcc`，包含 Hallmark 布局提交 `8376466bda0219e1179d6763d490381361398c23`。按用户“偏好设置模块的呈现方式好好设计下”的要求，在新骨架上继续，不恢复早先的多卡片或资金方私有分区结构。

## 呈现决定

保留 1040px 容器、每页单张资料卡、160px 区块标题列和 ≤900px 上下排列的 `.login-profile*` 骨架。偏好内部采用两条设置行，资产方、资金方使用同一套标记与样式：

- **语言**：左侧名称与用途说明，右侧原生紧凑选择框；值仍只有 English / 简体中文。
- **时区**：同样对齐，说明显示时区不改变业务时间；仍使用现有 IANA 选项与已保存值，鼠标停留可通过 title 读取完整当前值。
- **自动保存**：保持改选即保存，不增加保存按钮、二次确认或弹窗。为原有反馈保留空间；资产方继续逐项展示保存中 / 成功 / 失败并独立锁定，资金方继续使用原有组级结果。视觉统一不重写两侧的保存实现。
- **关键通知**：使用共享铃铛图标和轻底说明区，保留各自现行文案。它表达始终接收的规则，不是新增偏好项，没有开关或可点击外观。

设置行以细分隔组织，不给每项再套卡片。标题、正文、标签与说明依次继承当前语义字号；蓝白色板和 Geist / Noto Sans SC 不变。桌面选择框保持 280px / 36px，粗指针设备沿用 44px；≤600px 时说明和控件上下排列，控件按可用宽度收缩。

本轮新增说明仅解释已有选项用途。字段、值、权限、保存条件、存储键、失败回退、异步取消与事件处理函数均沿用现行实现；不增加语言、时区、通知事件、声音或消息渠道。

## 查看方式

附件 `借贷平台-用户中心偏好设置-UI设计.html` 为公共导出器生成的离线单文件，双击即可运行，字体与依赖已内联。打开右下“演示工具”，先选择资产方或资金方，再搜索“用户信息”；也可通过已有账号菜单进入。切换身份会影响实际可访问页面，沿用原工具规则。

维护源为本目录 `登录与账户体系.js`、`资金方账户.js` 和 `登录与账户体系.css`。共享视觉规格记录于[面客工作区组件规范](../../_shared/design-system/面客工作区组件规范.md)。截图只用于内部核验，不随交付附上。

## 实测与限制

Chromium 离线 149 项检查通过：

- 双角色 × 中英文 × 320 / 375 / 414 / 768 / 1280 / 1440 / 1920，共 28 组用户信息布局；设置行几何一致，无页面横向溢出或控件越界，均保留两个偏好选择器、单张资料卡及原生标签。
- 资产方原有逐项保存中、独立锁定、并发保存、成功、失败回退 / 重试、刷新回显与离页取消；资金方原有同步保存、组级反馈、失败回退 / 重试与刷新回显均可用。原字段与选项和优化前一致，标签点击、键盘焦点与说明关联有效。
- 资金方注册、审核中、驳回、已认证 × 中英文 × 375 / 768 / 1440，共 24 组骨架回归，保持单卡及 1040px 容器，页头不恢复状态标签。粗指针上下文选择框为 44px，源码入口与导出件使用同一设置行。
- 未发现脚本异常或 HTTP(S) 请求；两份 JS 的 `node --check`、`git diff --check` 通过。内部查看双侧中英桌面 / 窄屏、保存成功和失败截图，未附截图或录屏。

原型仍使用本地演示账户与浏览器存储。未做 Safari / Firefox、真机、屏幕阅读器、完整缩放、真实服务联调或完整业务 AC / WCAG 验收；资金方同步保存与资产方异步保存的既有机制差异未在本轮改写。
