# 资金方账户 UI 优化 · WS-443

2026-10-21，`existing-system adaptation` / 面客 console。基线为 `cly-v5.0.0 @ ef89d0f`，包含 `7d6eb6d` 的业务联系人与注册精简。业务依据沿用资金方登录与账户体系现行 PRD；本次不改业务定义。

本轮承接用户截图中驳回操作突兀的问题，同时检查本 issue 的机构注册、申请状态与审核记录、资金方用户信息三个页面。只读取本模块及必要共享规范和加载 / 导出入口，未审阅其他模块页面。

## 调整

- **状态与行动形成一个页内头部**：原来的“注册状态”整行改为紧凑标签与状态并排，动作移至该区右上角。修改重提和认证后变更用现有主要按钮，客服保留次级链接；审核中查询仍为次按钮且保留加载禁用。≤600px 状态与动作分行，按钮按可用空间自然展开，DOM 与键盘顺序仍是状态、动作、原因。
- **审核反馈保留语义、减少整块红字**：驳回原因保留危险色边界、背景和明确标题，具体原因用普通正文色；多段原因、补充文字和换行原样保留。没有把提示变为可关闭内容。
- **阅读分组与填写分组对应**：详情同一资料卡内依次为申请状态、提交信息、机构资料、业务联系人、机构证明材料，沿用 160px 分区标题列与 1040px 页面上限。机构字段值、联系人完整电话、证明材料操作及审核记录全部保留；旧资料缺联系人仍显示“—”。
- **表单更紧凑**：仅注册页字段网格 gap 从 20px 收至 16px，普通控件仍 44px。已上传材料保留文件行，去掉文件行之外的重复虚线容器和内边距；空上传区继续显示拖入边界，拖入高亮仍有效。提交栏用现有次级底色与编辑区分层，完成度、取消、二次确认及失败提示不变。
- **细节一致性**：账户事实行最后一条不再追加分隔线；变更资料的影响提示与表单留出 16px 间距；区号浮窗由不存在的阴影变量改为现有 `--shadow-lg`。字体、颜色、字号、按钮与输入状态继续引用唯一 token，没有新增公共视觉取值。

## 运行与维护

完整仓库可直接打开本目录 `登录与账户体系.html`。离线评审件用 `_shared/export.py` 从源文件生成，默认 `/login`，双击可运行；右下“演示工具”选择“资金方”视角，搜索“申请状态与审核记录”，切换“已驳回 / 审核中 / 已认证”；注册页的五个状态继续可用，无需另建演示页面。

实现仅在 `资金方账户.js` 和 `登录与账户体系.css`，说明同步本模块 README 及共享面客规范的 WS-443 条款；没有改全局 token 或共享运行时。导出按项目原有公共清单自动内联依赖，生成件不回存源码目录。
