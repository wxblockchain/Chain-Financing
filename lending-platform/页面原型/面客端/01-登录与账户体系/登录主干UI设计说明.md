# 登录主干 UI 设计

2026-10-23 · WS-442 · `existing-system adaptation`，面客 Web 的 `focus` 登录流程与钱包模拟弹窗。基线：`cly-v5.0.0 @ ff4a8e1`；业务依据为本模块现行 PRD 与“连接钱包 / Connect wallet”的已确认文案。

## 本轮设计

- **连接钱包 P-L01**：保留标题和主按钮的已确认叫法，步骤一具体写为“连接 MetaMask”。说明分为登录方式、三步流程、开始前的插件及链要求、安全披露；避免把所有辅助信息塞进一块浅底卡。桌面三步横排，≤480px 改为纵向连线，顺序与键盘顺序一致。卡片最大 560px，桌面内边距 40px，≤480px 为上下 24px、左右 20px；使用既有 token。
- **操作与反馈**：连接钱包 / 重试为通栏主要操作，继续浏览为次级链接；保留原操作的提示、全部错误原因、MetaMask 桌面插件与 Ethereum（ETH）要求，以及“不涉及转账或资金授权”披露。“演示数据”保留在卡片底部，通过分隔线区分。
- **匹配与异常 P-L10 / P-L04 / P-L13**：统一居中反馈层级。账户匹配用不表示百分比的等待轨道替换数据表格骨架，保留读屏状态文本；减少动态效果时停止运动。异常使用警示色标记与文字原因，参考码单独排列，重试和继续浏览位置一致。
- **钱包地址与签名**：地址按钮先显示演示地址名，再显示完整地址，以箭头提示可以继续；可操作边界使用 `--control-border`，hover 和 focus 明确。签名弹窗将完整登录地址作为只读事实展示，不再只显示缩写；确认签名独占操作区一行，原有两项模拟失败操作在上方并列并允许换行。

维护源为 `登录与账户体系.js / .css`。只调整上述展示 DOM、语义等价文案及局部样式；没有改动钱包结果、身份匹配、资格判定、回跳、动作保留、路由、会话、字段、权限或计时条件。未引入新字体、图标依赖、色值或全局 token；共享壳层与通用弹窗保持既有定义。历史的资金方及偏好设计说明继续适用于各自范围。

未验证 Safari / Firefox、真机、屏幕阅读器和浏览器完整缩放；200% 为文字放大检查。钱包、签名、身份调取和账户均为既有本地模拟，不构成真实接口联调、全量业务 AC 或完整 WCAG 验收。

## 审阅与运行

完整仓库打开本目录 `登录与账户体系.html#/login`。离线附件由共享导出器从维护源生成，双击默认进入连接钱包页；右下演示工具可切换页面和本页异常状态，界面语言从右上切换。

在仓库根目录执行（生成件保持在仓库外）：

```bash
python lending-platform/页面原型/_shared/export.py --source lending-platform/页面原型/面客端/01-登录与账户体系/登录与账户体系.html --output ../登录主干-UI设计.html --entry-route /login
```

附件内还包含共享组合的其他页面，以支持真实回跳；这些页面的存在不代表本轮完成了它们的 UI 重设计。
