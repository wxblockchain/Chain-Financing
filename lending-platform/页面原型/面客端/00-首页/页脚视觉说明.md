# 首页页脚

本轮为既有系统适配（existing-system adaptation），覆盖面客端首页最后一屏的页脚。基线为 `cly-v5.0.0` 的首页与资产广场原型，按 WS-441 用户截图及后续“内容也和资产广场保持一致”的要求调整。

- 采用资产广场的 Ft1 纵向结构：品牌、说明信息、内联链接、分隔线与底部披露。
- 直接复用 `_shared/base.css` 的 `site-foot`、`ft-in`、`ft-mark`、`ft-tag`、`ft-links`、`ft-meta`，字号、间距、背景、边框与窄屏边距由公共层维护。
- 首页通过 `CF.marketplaceFooterContent()` 复用资产广场同一份页脚内容：Harbour Credit、平台简介、服务协议 / 隐私声明 / 风险揭示 / 联系我们、演示数据提示与当前时区。中英文和时区均由运行时状态生成。
- 首页原有的合约行、校验器、审计报告、文档、法律声明、地域限制和长段披露不再出现在页脚。
- 存证校验入口位于“平台特点”屏的“自行查验”卡片内（“打开存证校验”），打开校验弹窗并聚焦输入框；首页 PRD 规定入口位置由设计决定。
- 资产广场将既有页脚内容提取成可复用渲染函数，保留原有输出、链接目标与入口反馈，不另维护一份首页文案。
- 本地样式仅衔接首页的字体、段落重置和最后一屏贴底；窄屏底部留出原型工具悬浮按钮的空间，避免遮挡时区。颜色沿用当前页面的语义 token，不切换首页主题。
- 首页保留分屏和动画进度时，仅刷新发生变化的页脚内容，使时区切换即时生效。

此次调整页脚布局与内容。首页其余文案、统计口径、播报与存证校验已在 WS-493 按首页 PRD（2026-10-27）改写，见源码。页面仍使用现有原型数据，不代表真实服务或正式合约部署。

从完整原型目录打开 `首页.html` 即可运行。独立评审件使用 `_shared/export.py` 从源码生成，不手工维护导出文件。
