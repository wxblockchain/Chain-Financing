# 借贷平台 · 首页

WS-432，2026-10-19。按用户最新反馈，以最初附件 `01a139ad-9cc5-7e79-b0e8-2daf6b868433`（`harbour-credit-portal-prototype-designer.html`）恢复首页的布局、结构与动画。类型：existing-system adaptation；surface：面客端公开官网页。此前自然滚动、连续信息板与首页菜单方案已被本次反馈替代。

## 打开与维护

双击 [首页.html](首页.html)，保持整个「页面原型」目录完整。默认英文，可切换中文。首页为 `#/home`；主导航只保留原资产广场、借贷广场及符合身份的控制台，不显示首页菜单。从任何面客模块点击左侧波纹品牌图标即可返回首页。其他模块仍默认打开资产广场，原深链保持有效。

源码由 `首页.html`（共享壳层）、`首页.css`（首版结构的局部样式）、`首页.js`（首页展示、动画生命周期及原本地校验器）、`首页演示数据.js`（原输入的只读快照）组成。首版首页专用的色彩、字阶和字体回退定义在 `_shared/tokens.css` 的 `.hc-home`；首页使用首版系统字体回退，不引入联网字体，其余业务页继续使用现有共享字体。首版品牌图标在 `_shared/shell.js` 定义一次；导航、语言、登录和模态仍复用共享实现。依赖由 `_shared/portal-entry.js` 唯一维护。

在仓库根目录导出自包含评审件：

```sh
python3 lending-platform/页面原型/_shared/export.py \
  --source lending-platform/页面原型/面客端/00-首页/首页.html \
  --output /tmp/借贷平台-首页-第一版布局与动画.html --entry-route /home
```

生成件不入库，可双击离线评审。源码是唯一维护源，修改后重新导出。

保留原错峰显现与流程动效，跑马灯关键帧按首页命名隔离。为持续运动增加暂停 / 继续按钮，并响应 `prefers-reduced-motion`：关闭路径、跑马灯及提示动画，数字直接显示终值。弹出菜单、读取消息等共享壳层刷新保留首页 DOM，避免重启动画或跳回首屏；切换语言保持内部滚动位置。离开首页时断开 observer、取消 timeout / interval / RAF，恢复工作区滚动与页脚；返回首页从首屏重新播放。
