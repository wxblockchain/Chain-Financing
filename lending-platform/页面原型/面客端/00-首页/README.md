# 借贷平台 · 首页

WS-432，2026-10-19。基于用户提供的 `harbour-credit-portal-prototype-designer.html`（附件 `01a139ad-9cc5-7e79-b0e8-2daf6b868433`）优化并适配当前 `cly-4.0.0` 原型系统。类型：existing-system adaptation；surface：面客端公开官网页。

## 打开与维护

双击 [首页.html](首页.html)；需保持整个「页面原型」目录完整。默认英文，可切换中文。首页独立入口为 `#/home`，其他面客模块仍默认进入资产广场，已有深链优先。公共导航新增首页，原六个模块和目录名保持原位。

源码由 `首页.html`（共享壳层挂载点）、`首页.css`（首页组合）、`首页.js`（展示及本地校验器）、`首页演示数据.js`（输入原型的只读快照）组成。样式、字体、图标、控件、语言切换、登录和模态宿主复用 `_shared`。资源仅在 `_shared/portal-entry.js` 的唯一清单维护。

导出自包含离线评审附件，在仓库根目录执行：

```sh
python3 lending-platform/页面原型/_shared/export.py \
  --source lending-platform/页面原型/面客端/00-首页/首页.html \
  --output /tmp/借贷平台-首页-UI评审.html --entry-route /home
```

生成件不入库。导出含本地字体及现有面客模块，可双击打开并通过导航访问两个广场。重新生成即可同步后续源码变化。

## 实现范围

保留原输入的六段信息：资产与融资介绍、六项业务汇总、四步机制、四项平台特点、三类合作网络、准入与风险披露。自然页面滚动取代全屏内层滚动；编号目录支持键盘定位且按真实顶栏高度避让。首尾提供双广场入口，原悬浮卡片改为连续的信息板，动态跑马灯改为可展开的八条演示记录。

首页演示快照不作为当前广场的数据源，不据此修改现行额度、权限或状态流。$3,707,026.43、37,777.4000 份、$1,350,000.00、8、3、1,284 保持输入值；前三项摘要支持点击「完整数值」展开原精度。右侧项目示例 $484,836.00 与融资上限 $387,868.80 源自原输入实际计算结果；流程段 $485,975 × 80% = $388,780 是原输入中的另一独立算例，已明确区分。9.20% 为原报价示例，不代表收益保证。

合作伙伴仍为原输入占位名称，旁边明确说明。页脚完整保留资金不归集、平台不定价与不提供信用、机构风险自担、利率非保证及地域 / 零售限制。旧附件中没有目标的审计报告、文档、法律和地区链接不再作为空链接展示，关键披露直接呈现。

存证校验器保留输入原型的本地匹配语义：代币 ID、可信资产编号和存证哈希大小写不敏感；空值、读取中、未匹配和匹配结果均可查看，保留版本、等级、时间、区块、完整哈希。明确标注仅演示，不发 RPC、不执行真实链上核验。账户和资金操作仍通过既有业务模块完成。
