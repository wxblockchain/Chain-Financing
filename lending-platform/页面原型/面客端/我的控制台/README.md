## 打开与操作

打开 `我的控制台.html`，由 `_shared/portal-entry.js` 组合当前公共壳层及各业务模块。默认资产广场、英文，无首页；顶栏进入控制台，登录域处理准入。演示工具默认关闭，可切换两角色、中英文及加载、空态、失败、失效场景。页脚标明演示数据。

六类详情使用纵向内容流，快捷导航放在页头，横向章节导航固定于公共顶栏下。点击导航滚到对应章节，手动滚动同步高亮；键盘和减少动态效果偏好可用。窄屏章节导航横向滚动，正文不横向截断。

还款列表按已确认到账业务去重；业务详情包含本期应还、所有待确认期次、定稿单版计划和收款账户摘要。展开期次查看明细；详情唯一“前往借贷广场”进入对应项目，不自动选择业务或期次。项目逐轮申请区分当前与历史报价；放款从接受报价即入列，明确约定金额、实际记录和两种收款用途。

单文件附件由公共导出器生成，不手工维护内联副本。在 `lending-platform/页面原型/` 执行：

```sh
python3 _shared/export.py --source 面客端/我的控制台/我的控制台.html --output /tmp/我的控制台-v1.3.html
```

## 覆盖与继承

| 角色／范围 | 本轮覆盖与保留 |
| --- | --- |
| 资产方五类、资金方四类列表 | 企业统计、20/50/100分页、金额/状态/标记、独立详情；放款/还款完整编号检索及业务粒度筛选 |
| 六类详情 | 单列分区、固定章节导航、加载/错误及浏览器刷新指引、无权/未知一致反馈、会话清除、唯一项目导航 |
| 项目与报价 | 每轮申请独立编号与发布时间；有效或已接受报价、历史报价分开；进入原所属项目，由用户选择业务 |
| 放款 | 接受报价即入列，无LN时显示尚无记录；提交/确认时间和账户用途分开；确认后关联同笔还款 |
| 还款 | 生成中、失败及浏览器刷新指引、待还与多个待确认并存、确认超期、未开窗、全部结清、按业务筛选及完整计划 |
| 返回与旧链接 | 旧RP映射同一FD及原期次；列表条件/目标行/滚动、详情期次/滚动、广场项目详情及返回，不自动打开抽屉或弹窗 |
| 继承的系统 | 共享 token/base/shell/router、资产广场、借贷广场L5～L8、登录和消息入口 |
| 不在本轮 | 真实接口、服务端鉴权、银行/链上执行、外部模块改造、PRD入库 |

## 演示与未决边界

- 全部代币从企业快照独立取集，涵盖跨项目、无项目、有效/失效及质押/未质押；必需字段完整且归属明确后按代币编号去重，列表和统计共用同一集合。演示新增从未关联项目的失效、处理中、失败、释放样例，明确补齐已知虚构记录的签发时间和铸造哈希，不能用于填补真实数据缺失。
- 两角色列表没有广场快捷入口；六类详情仅保留一个项目导航按钮。授信由机构×企业关联报价取得项目集合，多目标先选、无目标禁用并说明原因。全部控制台取数刷新/重试按钮撤除，浏览器刷新保留 URL 视图；原业务事实和阅读能力保留。
- 数据仍来自公共 `CF.LS` / `CF.CQ` / `CF.L7` / `CF.L8` 示例模型；控制台读取事实，业务表单只在广场办理。演示接入文件增补生成中、结清、多期待确认和历史报价样例。
- 真实主体映射、客服邮箱、银行账号掩码、时区/数币精度、末期窗口、整体逾期标记和跨平台异常仍以 V1.3 第5节为边界。银行账号仅提示受限，地址按已确认缩略口径展示；未取得资料显示缺失，不补造账户。
- 示例沿用L8本地日期与金额结果，不裁定正式精度。单期期次逾期与确认超期分开，不推导尚未裁定的业务整体逾期清除规则。
- 浏览器核验结果与提交见对应 issue 回帖；原型不是已接入真实后端的生产页面。
