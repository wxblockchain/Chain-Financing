# 我的控制台 V1.1

本次类型：existing-system adaptation / delta prototype，面客 `portal` 画布。输入为 WS-355 用户字段精简与独立详情反馈、V1.1 PRD/流程图；读取 `wxblockchain/Chain-Financing` / `cly2.0.0` 的 `6ee539526dc0328e87fa6d81bce4f1758896eb52`。

## 打开与操作

打开 `我的控制台.html`。沿用项目默认资产广场及英文，通过顶栏进入我的控制台；登录演示后显示资产方数据。右下角“演示工具”默认关闭，可切换资产方/资金方、中英文以及空态、失败、失效场景。控制台核验工具位于面板下方。

单文件 HTML 由公共 `_shared/export.py` 内联导出，源码为唯一维护源。导出命令在 `lending-platform/页面原型/` 执行：

```sh
python3 _shared/export.py --source 面客端/我的控制台/我的控制台.html --output /tmp/我的控制台-v1.1.html
```

## 本轮变化

列表拆开金额、币种和状态，移出完整条款与历史记录；还款的本金、利息、合计分别成列。六类列表进入独立控制台详情，复用公共详情分区与快捷操作栏。快捷操作进入现有借贷广场项目及 L6/L7/L8 操作容器，回到同一对象；详情面包屑再恢复原分页列表。

| 角色 | 功能 | 覆盖的关键状态 |
| --- | --- | --- |
| 资产方 | 代币、项目、授信、放款、还款 | 有效/失效与质押状态分开；覆盖不足；暂缓/重传；待到账；还款入口未开/已开；待确认、已结清 |
| 资金方 | 报价、授信、放款、还款 | 待接受报价、锁定时限；内部备注；去放款；去确认还款；状态变化后的返回 |
| 两角色 | 六类详情及异常 | 稳定对象/期次 ID；加载、失败、重试、未知/无权、登录失效、动作过期；列表与详情恢复 |

## 继承与范围

- 不复制公共层实现。加载当前共享 token/base/shell/registry；组合资产广场及借贷广场现有脚本。
- `我的控制台.js` 只读聚合 `CF.LS` / `CF.CQ` / `CF.L7` / `CF.L8`，详情不执行业务写入。外部操作继续由既有模块校验和提交。
- `控制台演示接入.js` 为控制台补充同一模型中的本地示例，编号使用 `*-MC-*`；已有模型缺少的签发时间用演示日期补齐。未创建第二套交易状态。
- 组件规范更新只涉及本轮控制台列表和详情约定。未修改 PRD、广场业务规则、公共 token、真实后端或跨平台模块。
- 路由、字段层级及返回参数见 `_shared/design-system/控制台列表与独立详情基线.md`。

## 演示假设与边界

1. 演示身份固定为资产企业 A / 资金机构 A；不代表真实跨平台用户或企业映射，也不是服务端授权实现。
2. 默认按时间倒序；授信按可用额度升序，还款按业务及期次。PRD 第 5 节排序冲突仍未裁定。
3. 引用当前广场已实现的操作容器，不以本次原型裁定正式外部承载方案。
4. 演示汇率为独立样例快照，初始计划编号带 `INITIAL-`；已生效期次使用 L8 生成的稳定编号。展示金额及 UTC 日计算继承现有原型，不裁定正式精度、币种 ticker 或日期口径。
5. 账户使用明显的演示值；真实字段脱敏与客服邮箱未定。缺失资料显示空值或空态，未生成的放款记录不伪装为已提交。
6. 真实接口性能、服务端鉴权、银行/链上付款和跨平台质押释放不属于本次浏览器核验结论。

入库状态与实际核验结果见本轮 issue 交付说明，不把下载的只读源码快照当作有效 checkout 或已提交内容。
