# 我的控制台

类型：existing-system adaptation / console。本轮按分支 `cly-v3.0.0` 上控制台三册现行正文修订，衔接 WS-375／WS-376／WS-377 已入库的报价、放款与还款原型；不修改也不代提交 PRD。

## 当前需求阅读入口

[主PRD](../../../PRD/v1.0-我的控制台/01-我的控制台-PRD.md)、[流程图与状态机](../../../PRD/v1.0-我的控制台/02-我的控制台-流程图与状态机.md)、[消息通知](../../../PRD/v1.0-我的控制台/03-我的控制台-消息通知.md)。三册只定义信息需求与业务行为，页面布局与组件由设计决定（见[统一条款](../../../PRD/v1.0-我的控制台/01-我的控制台-PRD.md#design-boundary)）。

## 打开与操作

打开 `我的控制台.html`，由 `_shared/portal-entry.js` 组合当前公共壳层及各业务模块。默认资产广场、英文，无首页；顶栏进入控制台，登录域处理准入。演示工具默认关闭，可切换两角色、中英文及加载、空态、失败、失效场景。页脚标明演示数据。

六类详情使用纵向内容流，快捷导航放在页头，横向章节导航固定于公共顶栏下。点击导航滚到对应章节，手动滚动同步高亮；键盘和减少动态效果偏好可用。窄屏章节导航横向滚动，正文不横向截断。

还款列表按已确认到账业务去重；业务详情包含本期应还、所有待确认期次、定稿单版计划和收款账户摘要。展开期次查看明细；详情唯一“前往借贷广场”进入对应项目，不自动选择业务或期次。项目逐轮申请区分当前与历史报价；放款从接受报价即入列，明确约定金额、实际记录和两种收款用途。

单文件附件由公共导出器生成，不手工维护内联副本。在 `lending-platform/页面原型/` 执行：

```sh
python3 _shared/export.py --source 面客端/我的控制台/我的控制台.html --output /tmp/我的控制台.html
```

## 本轮按现行正文调整

| 落点 | 结果 |
| --- | --- |
| 业务时限 | 放款确认、还款确认与报价有效期三处 168 小时全部移除。列表、详情、期次与提醒都没有截止时点、剩余时长、倒计时、临期或超期表达；等待只按“已提交 N 天／小时”“已锁定 N 天”如实累计，并说明确认无时限、逾期天数冻结、平台不代确认 |
| 待办呈现 | 收敛为待我还款、已逾期待我还款、待我确认三类；“已超期待我确认”及其筛选项撤除 |
| 还款录入开放 | 开启时点直接取期次 `open`（应还日 00:00 UTC），列表“开启于”与详情“还款入口开启时间”同源，不再自行提前三日 |
| 放款段 | 仅资金方提交放款 → 资产方确认到账两步。盖章件版本、要求重传、暂不放款、终止时间与原因全部移除；放款展示状态固定为待放款／待放款确认／已放款，还款中与已结清只在还款视图表达 |
| 收款账户 | 两侧账户改为读取企业账户快照，复用报价模块导出的 `CF.CQ.accounts / accountRows / accountName / accountMissing / accountSnapshot / accountKey / accountLabels` 与 `.cq-account-*` 口径；不再有收款人名称／户名字段 |
| 交易标识 | 字段名为交易标识，链取所选收款账户带出的结算收款链。ETH 给 etherscan 外链，TRON 只给复制；两种都固定说明“平台未核验该交易” |
| 项目指标 | 改用总质押额、待审质押额、有效质押额、本轮融资需求、已融资余额、项目质押率六项，数值一律走 `D.numbers(p)`；需追加资产价值按项目质押率换算，不再写死 80%。项目概况补齐代币类型、项目期限、还款方式、参考结算币种（`p.settle`）、质押合约地址与 SPV |
| 授信协议 | 放款详情按非必填呈现有无与最近提交时间，缺失只说明“本笔未提供” |

## 覆盖与继承

| 角色／范围 | 本轮覆盖与保留 |
| --- | --- |
| 资产方五类、资金方四类列表 | 企业统计、20/50/100分页、金额/状态/标记、独立详情；放款/还款完整编号检索及业务粒度筛选 |
| 六类详情 | 单列分区、固定章节导航、加载/错误及浏览器刷新指引、无权/未知一致反馈、会话清除、唯一项目导航 |
| 项目与报价 | 每轮申请独立编号与发布时间；有效或已接受报价、历史报价分开；报价提交后无有效期、不可撤回，只按已锁定时长累计 |
| 放款 | 接受报价即入列，无LN时显示尚无记录；提交/确认时间和账户用途分开；确认后关联同笔还款 |
| 还款 | 生成中、失败及浏览器刷新指引、待还与多个待确认并存、未开窗、全部结清、按业务筛选及完整计划 |
| 继承的系统 | 共享 token/base/shell/router、资产广场、借贷广场L5～L8、登录和消息入口 |
| 不在本轮 | 真实接口、服务端鉴权、银行/链上执行、外部模块改造、PRD入库 |

## 演示与未决边界

- 演示数据与借贷广场共用 `CF.LS` / `CF.CQ` / `CF.L7` / `CF.L8`，存储键 `hc-ws376-v1`，旧本地演示数据会重新播种。控制台读取事实，业务表单只在广场办理。
- 演示业务覆盖待放款、待放款确认、已确认到账、计划生成中、多期待确认、全部结清与被拒绝报价；数币样例含 TRON 与 ETH 两条结算收款链，分别演示无外链与有外链的查验表达。演示项目质押率刻意不统一，用于体现创建时自填并锁定。
- 全部代币从企业快照独立取集，涵盖跨项目、无项目、有效/失效及质押/未质押；必需字段完整且归属明确后按代币编号去重，列表和统计共用同一集合。
- 两角色列表没有广场快捷入口；六类详情仅保留一个项目导航按钮。控制台不提供取数刷新/重试按钮，浏览器刷新保留 URL 视图。
- 账户按共享脱敏口径展示，完整账户核对、协议文件与凭证正文到广场；未取得资料显示缺失，不补造账户。
- 仍未裁定、原型按现状呈现的事项：`Q-L7-08`／`Q-L8-06` TRON 区块浏览器查验入口取值（本原型只给复制与未核验说明）、`Q-EA-04` 收款账户变更是否强制安全站内信、`Q-O-FC-02` 最高质押率取值上下限与小数位。
- 真实主体映射、客服邮箱、银行账号掩码、时区与数币精度仍以主PRD第5节为边界。原型不是已接入真实后端的生产页面。
