# 我的控制台

2026-10-19 · WS-378 最终 UI。类型：**existing-system adaptation / console**。沿用用户 `328a96f7-4578-417a-ab61-b3a525cf3b0e` 的直接推进与持续入库授权，承接 Hallmark 功能原型 `3f21666` 及同名离线附件；最终 UI、源码和本说明交产品工坊汇总。

## 基线与维护源

正式输入为 `cly-4.0.0@2aa5719` 的 [01 功能与业务规则](../../../PRD/面客端/09-我的控制台/01-我的控制台-PRD.md)、[02 流程图与状态机](../../../PRD/面客端/09-我的控制台/02-我的控制台-流程图与状态机.md)、[04 验收](../../../PRD/面客端/09-我的控制台/04-我的控制台-验收.md)。没有 03 通知册；控制台不发送消息。

功能原型已整合 `339ee19` 的还款 UI 与 `52460e7` 的首页。本轮从 `cly-4.0.0@3f21666` 深化控制台视觉，唯一维护源是本目录 HTML / JS / CSS 及 `_shared/`；保留真实顶栏、独立详情、单列内容流、吸顶横向章节、公共路由与演示工具。字段组为两列标签 / 值，≤600px 单列。

视觉取自 `_shared/tokens.css`、`base.css`、`design-system/共享组件视觉规范.md` 及当前广场实现：`--accent #1D4ED8`、`--bg #F7F8FB`，本地 Geist / Noto Sans SC，普通值 14px、标签 12px、清单 13px、统计 `--ui-stat-size`，内容 padding 24px、普通卡片 `--radius-sm 8px`。控制台局部组合见 [控制台列表与独立详情基线](../../_shared/design-system/控制台列表与独立详情基线.md)。

## 本轮视觉变化

- 总览使用无独立卡片的等宽统计网格：有代币摘要时桌面五列，资金统计三列；≤1100px 收为三列，≤900px 两列，≤360px 单列。长说明在所属统计内换行，标签、数值、辅助说明分别对齐，金额、币种及原精度完整保留；代币统计失败时其余三项仍按三列组合。
- 清单数字表头与金额右对齐；还款列按识别、金额、日期、状态、全部待确认、确认时间、操作配置比例，减少编号和日期被挤碎。≤1100px 沿用带字段名的纵向记录；触控环境筛选控件使用共享 44px 高度。
- 详情页头的唯一广场操作与标题分居两端，窄屏自然换行。字段间距收紧，账户快照通栏，长编号和复制控件可换行。本期金额旁补齐原有应还日期的标签，不增业务字段。
- 相关期次的阅读按钮位于记录末端，选定原期用蓝色起始边线及原有“已选定阅读”文字标识；全部待确认与冻结逾期持续可见。数字仍使用共享 tabular numerals；章节与按钮沿用可见键盘焦点。

实现限于本目录 CSS、四处展示模板与首次定位前的尺寸测量，以及相应视觉文档。原期次 / 原申请的首次定位在滚动前先测量当前顶栏和章节栏，避免窄屏换行后遮住目标开头；状态集合、金额处理、筛选排序、权限、导航参数和来源读取器沿用功能基线。

## 打开与主要路径

完整目录打开 `我的控制台.html#/console`；附件默认控制台入口、英文，未登录依共享登录域引导。底部“演示工具”默认关闭，在其中切换资产方 / 资金方及企业、机构 A / B、当前页面和加载 / 空 / 无结果 / 错误 / 无权状态；“更多模拟”中有统计、代币、关联与计划局部故障、无关联 / 不可访问、仅同项目定位降级和会话失效。所有企业、金额、账户、客服与业务结果均为演示数据。

- 资产方五类清单，资金方四类清单；只进本控制台六类独立详情。全局广场导航沿用，列表和空态不加业务快捷入口。
- 六类详情只保留识别、金额币种、状态、处理方与风险摘要。授信仍是一机构 × 企业，保留额度拆分和期限；不按项目拆授信。项目八种状态、当前申请 / 指定原申请、六项指标及待审 / 驳回未解押摘要保留；不复制逐轮历史。
- 还款一笔 FD 一行。本期、全部待确认、当前未结清逾期和明确指定原期的并集逐个展示；原 RP 已结清仍可读。可选择某期阅读，选择写入 URL。完整计划、其他未来 / 历史期次、本息计息、付款材料归来源。生成中不造 RP，失败不回滚到账确认。
- 详情页头唯一“前往借贷广场”进入对应项目；无关联、不可访问或关联失败禁用并分别说明，多项目须明确选择，不能默认第一项。自有无关联代币 / 授信仍可读。
- 项目原申请 / 报价复用 `CF.CQ.openRequest`，放款复用 `CF.L7.openDetail`，还款复用 `CF.L8.openDetail`。为最后一个读取器补充可选 `period`，突出原期当前结果，保留最新还款 UI。只读详情不提供提交、确认或自动转办；关闭记录后从项目既有入口独立选择办理。
- 旧对象无权或不存在统一不可访问，不替换最新对象。来源没有读取能力时明确“仅到达同一项目，尚未定位原记录”，保留原编号和返回，不能称定位通过。
- 广场返回先回原类型 / 原对象 / 原选申请或期次，再用面包屑回来源列表。URL 保存分类、筛选、精确编号检索、排序、20/50/100、页码、内外滚动和触发行；记录更新后不匹配筛选时提示清除过滤。直接详情无来源则回该类默认列表。

还款样例 `FB-MC-0003` 同时含两期待确认（保留冻结逾期）、下一期待还；`FB-MC-0006` 为计划生成中，`FB-MC-0007` 已结清。旧申请路径 `#/console/projects?id=FP-MC-005&application=FP-MC-005-01`；旧报价 `#/console/quotes?id=FB-MC-HISTORY-01`（资金方）；多关联代币 `TK-MH-2610-01`，无关联 `TK-MC-UNLINKED-VOID`。

## 运行与最终 UI 导出

在 `lending-platform/页面原型/` 执行（生成件放仓库外，不能手改）：

```sh
python3 _shared/export.py --source 面客端/05-我的控制台/我的控制台.html --output /tmp/我的控制台-最终UI-WS378.html --entry-route /console
```

生成的单文件 HTML 可双击离线运行，默认控制台入口；首次按原登录域引导，可从演示工具切换身份与状态。继续维护时必须保留六类摘要的业务含义、只读边界、全部待确认和当前未结清逾期、旧对象定位、唯一项目导航、多项目明确选择及返回恢复；不得恢复控制台完整档案、实收金额、办理时限、账户维护或提交操作。

Q-MC-59（摘要范围）、Q-MC-60（原对象阅读定位）、Q-MC-61（整笔代币统计含义）均**建议执行、待确认**；Q-CR-16 沿来源现行逐笔账户确认，控制台不裁定。Q-MC-52/54/56/58、真实定位支持及性能条件仍待验，不判通过。已关闭的上游事项不重新列为待决。
