## 打开与主要路径

完整目录打开 `我的控制台.html#/console`；附件默认控制台入口、英文，未登录依共享登录域引导。底部“演示工具”默认关闭，在其中切换资产方 / 资金方及企业、机构 A / B、当前页面和加载 / 空 / 无结果 / 错误 / 无权状态；“更多模拟”中有统计、代币、关联与计划局部故障、无关联 / 不可访问、仅同项目定位降级和会话失效。所有企业、金额、账户、客服与业务结果均为演示数据。

- 资产方五类清单，资金方四类清单；只进本控制台六类独立详情。全局广场导航沿用，列表和空态不加业务快捷入口。
- 六类详情只保留识别、金额币种、状态、处理方与风险摘要。授信仍是一机构 × 企业，保留额度拆分和期限；不按项目拆授信。项目八种状态、当前申请 / 指定原申请、六项指标及待审 / 驳回未解押摘要保留；不复制逐轮历史。
- 还款一笔 FD 一行。本期、全部待确认、当前未结清逾期和明确指定原期的并集逐个展示；原 RP 已结清仍可读。可选择某期阅读，选择写入 URL。完整计划、其他未来 / 历史期次、本息计息、付款材料归来源。生成中不造 RP，失败不回滚到账确认。
- 详情页头唯一“前往借贷广场”进入对应项目；无关联、不可访问或关联失败禁用并分别说明，多项目须明确选择，不能默认第一项。自有无关联代币 / 授信仍可读。
- 项目原申请 / 报价复用 `CF.CQ.openRequest`，放款复用 `CF.L7.openDetail`，还款复用 `CF.L8.openDetail`。为最后一个读取器补充可选 `period`，突出原期当前结果，保留最新还款 UI。只读详情不提供提交、确认或自动转办；关闭记录后从项目既有入口独立选择办理。
- 旧对象无权或不存在统一不可访问，不替换最新对象。来源没有读取能力时明确“仅到达同一项目，尚未定位原记录”，保留原编号和返回，不能称定位通过。
- 广场返回先回原类型 / 原对象 / 原选申请或期次，再用面包屑回来源列表。URL 保存分类、筛选、精确编号检索、排序、20/50/100、页码、内外滚动和触发行；记录更新后不匹配筛选时提示清除过滤。直接详情无来源则回该类默认列表。
