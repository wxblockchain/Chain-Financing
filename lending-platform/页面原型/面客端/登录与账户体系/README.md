## 当前资产方账户口径（2026-09-21）

本轮为已确认方向内的 existing-system adaptation / console 修订，基线为 `cly2.0.0 @ 2a10a26` 和 WS-348 评论 `af69ead9-f427-4171-b0e9-9fb37815b17f` 的完整六册附件（尚未入库）。用户 `d1f27850` 要求开始调整，沿用原型修订入库授权。以下覆盖旧记录中的记忆快捷入口、账户保存按钮与登录状态分区；资金方审核衔接继续按下一节。

- 登录整页和受限操作弹层均由用户明确选择身份；不读取或新增身份记忆，启动时清理旧版身份记录。
- 钱包入口沿用公共壳层，前 6 / 后 4 缩写、不超过 10 字符完整显示；地址缺失显示「我的账户」。悬浮、点击、键盘可打开菜单，全文可核对；资产方菜单为「企业信息」，资金方仍为「用户信息」，仅菜单退出。
- P-L12 为账户、个人信息、偏好三个纵向分区；新增 P-L14 `/account/company` 只读企业资料页，由菜单进入并通过面包屑返回来源。两类资料区覆盖读取、缺失、失败重试及当前账户归属；不提供本地编辑、材料或认证提交。退出、身份变化及离页后的旧读取不能恢复资料。
- 语言与通知偏好逐项选择即保存；每项独立等待、成功反馈，失败回退、重新选择重试。成功值按模拟用户 ID 保存在本设备，刷新、重进及重登恢复；离页、退出、过期和换身份不接收迟到成功。无时区新增、保存按钮、登录状态分区或页内退出。

`Q-L01` 未关闭：个人姓名、英文姓名、国籍、证件类型，以及企业名称、英文名称、注册地、地址、适用注册标识及关系，均为参考字段和明确标注的模拟资料。当前用香港 CR/BR 模板演示，不代表上游实际供给；个人证件号码和材料影像不展示。`Q-L03` 通知默认及可关闭范围也未定，模拟偏好不关闭强制认证降级提示。评审工具默认关闭，提供资料空态、失败、可选字段缺失、另一账户和拒绝修改样例；这些不构成真实接口、权限或安全验证。

公共层改动：`_shared/shell.js` 补地址兜底、短地址规则、企业菜单及悬浮/键盘行为；`_shared/base.css` 仅新增菜单完整地址与聚焦提示样式；`_shared/design-system/面客工作区组件规范.md` 同步账户入口段落。模块修改资产方 JS、清理失效局部样式及本说明；资金方源码与 PRD 正文未改。
