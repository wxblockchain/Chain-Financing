# 登录主干与资产方 SSO · 页面原型

Stage 4，`existing-system adaptation` / `console`，继承面客端官网型画布。用户 2026-09-18「直接输出页面原型」授权合并 Stage 2–4；公共层补齐及规范修订范围见 WS-348 的 09:03 评论。

基线为 `lending-platform/PRD/v2.0-登录与账户体系/` 中登录主干与资产方 SSO 的六册（`ce68fa8`，与 08:45 附件一致）。默认英文，中英切换；双击源 HTML 从游客壳开始，右上角「登录 / 申请入驻」进入身份选择。样例身份、协议和响应均为演示数据。

本轮读取底座头为 `c7ef580`，交付前合入并复核 `7ed4d41` 的继承规范更新；原样板最后修改版本为 `d199040`，本次在其上追加 focus。

## 维护与导出

- `登录与账户体系.html`：沿用底座容器、仅定义登录域的局部组合样式。
- `登录与账户体系.js`：追加本模块流程页登记、组件内容与交互；共享路由、语言、弹层、Toast 和演示面板宿主。
- 公共层唯一来源为 `../../_shared/`。不手工维护内联副本，不修改 `registry.portal.js` 的正式业务页。

在 `lending-platform/页面原型/` 执行：

```sh
python3 _shared/export.py --source 面客端/登录与账户体系/登录与账户体系.html --output /tmp/借贷平台-登录主干与资产方SSO-页面原型.html
```

生成单文件离线附件；生成件不入库。导出无外部依赖，不发网络请求。

## 评审入口与覆盖

| 覆盖 | 进入方式 | 可检查状态 |
| --- | --- | --- |

| P-L03 / P-L04 | 离站弹层「切换身份」；演示工具「主干不可继续」 | 清除身份记忆、返回选择；可重试及游客出口 |
| P-L10 / P-L11 / P-L13 | 默认关闭的演示工具选择授权结果并运行，或离站边界模拟返回 | 回调处理中、首登协议、协议加载 / 保存失败与重试、唯一复选框、正文查看及下载、受限会话路由拦截、建号失败双出口 |
| P-L12 | 已登录账号下拉「账户设置」 | 暂定四项只读、缺失项整块隐藏、加载及重试、语言 / 通知偏好、保存反馈、退出 |
| C-L02 / C-L04 | 硬卡点、常驻条、账户跳链 | 未认证 / 驳回引导、目标平台告知、返回、键盘焦点约束 |
| C-L03 | 模拟资产方未认证；队列工具 | 壳层占位、不堆叠、计数清单、优先级、折叠可见、补齐接替、会话结束重置 |
| F-L31 演示页 | 工具「打开融资硬卡点演示」 | 游客 / 未认证引导、已认证实时复核等待、复核失败重试、旧快照已认证而实时结论失效仍拦截 |
| 回跳与会话可见结果 | 工具选择站内有效回跳 / 当前跨平台兜底；到期 / 上游登出 / 主体不可用 | 重新执行原动作前复核、首页 Toast、原页就地降级、无登录墙、无表单草稿保存 |

硬卡点页面只在本模块登记为 `DEMO-L-GATE`（`#/demo/login/financing`），明确为演示页；未占用 `P-MC-01`，未落入「我的控制台」目录。其他业务导航保留系统位置，交接边界在评审工具中说明，不实现其他模块正文。

## 边界

- `Q-L01` 仍未关闭：账户页四项暂定、已在页面标明，不作为字段验收依据。当前跨平台回跳默认走首页兜底；「有效站内回跳」仅为独立响应场景，不意味着已放行跨平台回跳。
- 资产方离站、钱包连接都只演示交接边界，不调用真实外部系统；不复刻授权中心 / 钱包界面。资金方到连接结果为止，`P-L20` 签名确认及以后、资金方机构与账户流程、资金方组件文案归 WS-349。
- 本原型覆盖 24 个功能点中适用的页面、组件与用户可见结果。服务端句柄、白名单判定、一次性授权、会话 / 权限强制、实时上游复核、登出通知、审计和告警未实现，也不能用此原型验证。
- 权限矩阵的待填格、业务字段级脱敏梯度、机构审核端、三平台真实域名不在本次范围。其他业务页由对应模块交付。

## 公共层增量

`base.css` 仅追加 focus 和 C-L03 样式；`shell.js` 仅追加 focus 渲染与 C-L03 队列 / 折叠 API；`页面继承参考.md` 增一条居中卡片 archetype；`样板/底座样板.html` 增容器及 `#/sample/focus` 样例；`面客工作区组件规范.md` 仅修订第 3 节：游客按矩阵展示，受限控件仍可引导，不放常驻登录条，补全条仅用于已登录缺失信息。原有 site / portal / app 规则无删除、无改写。

登录模块按 SSO PRD 将 Toast 放在顶部居中；此局部样式不改变其他模块 Toast 位置。弹层沿用公共宿主，键盘约束与焦点归还在模块交互中补齐。

共享回归覆盖样板 site / portal / app、追加 focus 及资产广场现有模块；共享 CSS/JS 的 diff 只有新增行。上述为原型浏览器验证，不是服务端安全、SSO 联调或完整 PRD 验收。
