## 视图状态与寻址

筛选、排序、搜索关键词与页码全部写在 URL 上，URL 是视图状态的唯一事实源：刷新、分享、浏览器前进后退、从详情页返回都原样恢复。

公共路由 `pageFromHash()` 按登记表做精确匹配，带参数的详情地址与带查询串的列表地址都匹配不上。本模块**不改公共层**，改为把当前地址回写进 `CF.ENTRY`（`syncEntry()`），让公共路由继续按它自己的规则工作。模块在 `CF.boot()` 前注册 URL 与输入监听，并以 URL 为键保存内外滚动位置（sessionStorage 不可用时退回内存）。公共层重绘后由 animation frame 恢复位置；焦点恢复使用 `preventScroll`。筛选、搜索、换排序、重置、主动翻页同时回到内外顶部；从详情返回、历史前进后退和刷新恢复当前会话的对应位置。外部分享冷启动恢复业务视图，未承诺跨会话像素位置。

  --source 面客端/资产广场/资产广场.html \

生成件不放回仓库。

## 尚未改动的公共层问题

1. **公共路由只支持精确匹配**。加一处前缀 / 查询串匹配能力后，本模块的 `syncEntry()` 就可以删掉；借贷广场详情与我的控制台将来会撞上同一堵墙。
2. **单端评审件里的部署单元开关**。面客端模块只加载 `registry.portal.js`，演示工具切到管理端时公共层落不到任何页面（地址会变成 `#undefined`）。本模块在那种情况下给了一句说明，但更合适的处置在公共层。
