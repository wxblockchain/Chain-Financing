## 视图状态与寻址

筛选、排序、搜索保存在 URL；`loaded` 表示已加载记录数，`scroll` / `outer` 是内外位置，`anchor` / `offset` 是记录锚点与偏移。追加和滚动用 `replaceState` 更新当前历史项，不为每次滚动制造后退步骤；条件变化建立新的历史项，清除进度并回首批顶部。恢复先重建已加载范围，再定位行锚点（缺失时回退到安全范围内的滚动值）。详情 URL 的 `return` 参数保留完整列表快照，因此详情刷新后返回仍可恢复。

恢复不读取 sessionStorage：新会话打开完整分享 URL 同样恢复条件、范围和位置。同一视口/语言下保留像素位置；不同排版下优先保留记录锚点及偏移。分享不冻结真实后端数据版本；本原型使用稳定的标注演示数据。

公共路由已支持查询串；本模块只为动态代币编号同步 `CF.ENTRY`。加载请求使用模块状态与单个可取消定时器模拟；条件或路由改变时取消旧请求。首批、追加中、失败与结束互斥，复用 `.loadmore` 外观与 `CF.moreFoot` 结束状态；正常下滑自动追加，没有加载按钮。仅失败时使用独立重试动作 `am-more`，不触发公共同步哨兵。追加完成后维持筛选全集汇总与旧记录顺序。

## 可达演示状态

默认关闭的公共演示面板里使用原有加载中/空数据/筛选无结果/加载失败入口；模块追加「下一批失败」和7/20/52条数据集。点击「下一批失败」后下滑到底，已有内容保留且末尾可重试；真实条件变化和初次进入均有短暂首批加载，追加有独立加载反馈。演示开关不在业务画布内。
