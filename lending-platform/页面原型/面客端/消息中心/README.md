# 面客消息中心原型

基线：`PRD/v1.0-面客消息中心/` V1.0 四册（`b0284c3`）；从消息原型 `65a22f2` 修订，共享层核对至 `5c6ad85`，入库前核对 `f8cf33b`（新增借贷广场局部调整，无共享改动）。按用户「直接输出页面原型」合并剩余设计阶段，并依据「消息中心不是内嵌页面，你自己判断怎么展示用户体验最好」改为独立整页。分类为 existing-system adaptation / console，继承面客端 asset · portal 画布，默认英文，可切中文。

## 使用与维护

打开 `消息中心.html` 即进入消息列表，默认资产方演示账号。右下角「演示工具」默认关闭，可切换资金方、游客、受限会话、页面状态及异常场景。所有消息、类型、分类和办理节点都是虚构演示数据，不是业务触发登记表。

页面登记：`P-F-MC-01` → `#/notifications`，`P-F-MC-02` → `#/notification?id=…`。不新增顶栏主导航。筛选写在 hash 查询串；所有宽度均随整页滚动，不设列表内滚。桌面筛选栏吸顶于平台顶栏下，≤900px 随页面流动以节省阅读空间。列表末尾可返回筛选。详情采用独立阅读页，打开时回顶，返回恢复筛选、批次、原消息位置及焦点；追加消息或切换语言按可见消息锚点保持位置。

加载规则仍为每批 20 条、点击「加载更多」、不自动触底加载。PRD 加载规则无需修改；应撤销 Stage 1 与首次交付说明中「桌面定高内置滚动区」的旧默认方案。此变化是页面呈现设计，不是新增业务规则。共享组件规范已同步该例外，资产广场等其他页面的内置列表约定不变。

源文件：模块 HTML（骨架与局部组合）、`消息中心.js`（页面和状态）、`演示数据.js`（分类、类型、双语模板、演示记录）。公共 token / 样式 / 壳层来自 `_shared/`，不手改导出附件。本轮把原 HTML 中的消息页面样式归入 `base.css` 的 `.nc-*` 作用域，使母版和资产广场装载同一消息模块时也采用一致布局；没有修改共享 token、壳层 JS、登记表或其他业务模块。

```bash
python3 _shared/export.py --source 面客端/消息中心/消息中心.html --output /tmp/借贷平台-面客消息中心-prototype.html
```

## 共享改动及影响

- `shell.js` 持有面客消息快照、归属过滤与未读计数；顶栏改为铃铛→语言→账号，含最近 10 条快捷面板与账号入口。零未读不画角标，超过 99 显示 99+。管理端入口保持原行为。
- 路由支持查询串，登记表新增两页且不进入主导航；消息两页切换保留列表批次。加入可选模块组合、渲染前后钩子与演示区扩展，使已登记页面复用同一个消息模块；未使用钩子的页面保持原接口。
- `base.css` 增加消息面板/元信息组件，不改 token。视觉取值直接复用：主色 `#1D4ED8`、页面底色 `#F7F8FB`、面客控件 44px、正文 15px、卡片内边距 22px、圆角 12px。
- 母版原有内容脚本抽到 `_shared/sample-pages.js` 单一源，保留首页、广场、控制台及管理端示例；消息附件引用它，未知深链能实际落首页。业务对象跳转使用母版借贷广场及其详情抽屉演示，目标页负责承载单元识别，未知锚点不打开抽屉；不代替目标业务模块最终页。
- 母版与已入库资产广场增加同一消息模块的加载，资产广场仅延后统一启动并暴露原页脚回调，原业务内容/筛选/加载规则不改。影响面为全部面客页顶栏；管理端不接入面客消息池。同期新增的登录独立原型未装载消息模块，保留其自有消息演示入口协议；本件回归了登录入口、focus 样板与补全条，未把登录模块的业务流程合并到消息附件。共享变更后旧的离线附件须重新导出。

## 验证与边界

本轮在 Chromium 实际打开导出 HTML，103 项浏览器断言通过，无 JS 异常。375 / 414 / 768 / 769 / 900 / 901 / 1280 / 1440 / 1920 九档检查列表与详情、滚轮只推动整页、桌面吸顶/移动端自然流、详情回顶、返回链接及浏览器前进后退定位；列表与详情均无横向溢出。已查看九档列表截图及桌面/手机详情、中文滚动状态。

专项检查：加载五批 100 条后的浏览器返回、返回筛选、筛选重置批次并刷新保持条件、单条/全部已读（覆盖未加载匹配项）、跨标签已读同步、追加消息和切换语言后保持可见行、有效/未登录/受限/未知深链；母版及资产广场的整页消息列表和详情返回。源码语法与离线导出检查通过。失败重试、过期、三类业务失效和超时等未修改场景沿用首次交付，不计入本轮重测范围。

这是可操作的前端原型。已读、轮询与跨标签同步使用本地演示状态；存储受限时本页仍可操作。真实鉴权/SSO、事件到达 60 秒 SLA、服务端幂等去重与越权防护、刷新不保活及真实后端异常未做集成验收。演示中的受限引导只交接账户必办事项，不实现账户模块。
