# 企业账户原型（面客 · 资产方与资金方双侧）

业务依据为本模块现行三册：[功能与业务规则](../../../PRD/面客端/03-企业账户/01-企业账户-PRD.md)、[流程图与状态机](../../../PRD/面客端/03-企业账户/02-企业账户-流程图与状态机.md)、[验收](../../../PRD/面客端/03-企业账户/04-企业账户-验收.md)（本模块不发消息，没有消息通知册）。三册定义信息需求与业务行为，页面布局、组件形态与交互由设计决定。本目录只交付页面原型。

当前对应 PRD `41d6134`（`cly-4.0.0`）。

## 现行口径

**入口与命名。** 页面 `P-F-EA-01` / `#/company-accounts`，不进主导航，从账号菜单第三项进入。模块与数据统一叫“企业账户”；展示名按侧区分：资产方 **Company accounts / 企业账户**，资金方 **Institution accounts / 机构账户**（页面标题、浏览器标题、报价与放款里的“前往…”一致）。两侧同一页面、同一套字段与维护动作。

**访问。** 游客与登录未绑定角色看到本页的登录或身份引导；已绑定但未认证的资产方 / 资金方看到补齐认证引导，不展示任何账户；已认证才可查看与维护。资格读主干的 `CF.portalEligible()`。

**总览。** 一张卡片内两个 Tab：法币账户、数币账户，带数量；当前 Tab 写入 query，刷新与分享可恢复，方向键可切换。Tab 栏右侧为当前类别的新增按钮。每个 Tab 一页列全，不分页、不设搜索，按登记时间倒序。

- 法币列：账户（备注名 + 账户名称）、账户类型、账户币种、开户行（名称 + 城市）、账号 / IBAN（掩码）、SWIFT / BIC、登记时间。
- 数币列：账户备注名、结算收款链、数币地址（缩略）、适用代币、登记时间。
- 行操作：查看、修改、删除。缺少必填项的账户标“信息不完整”并列出缺项（演示数据里有一个缺账户类型的法币账户）。
- 不设默认账户，界面没有默认标记或“设为默认”。≤768px 表格转卡片。

**法币账户（新增 / 修改）。** 居中对话框，两组：

- 账户信息：账户类型（一般账户 / 监管账户，单选、必选、不预选，只作标注，无额外限制）；账户名称（平台按本企业当前名称带出，只读：资产方为企业名称，资金方为审核通过的机构名称）；账户备注名；账户币种（USD、EUR、GBP 多选，至少一项，只作标注）。
- 开户行信息：开户行名称、账号 / IBAN、SWIFT / BIC、开户行地址（只填城市）。

没有收款人名称、中转行、账户持有人地址与开户行国家 / 地区。

校验：

- 各项必填，缺失逐项定位。
- 账户备注名、开户行名称不超过 100 个字符；账号 / IBAN 去除空格后不超过 100 个字符；超长在该项说明上限，不能保存。
- 账号 / IBAN 不按地区校验格式；开户行地址不限长度与字符种类。
- SWIFT / BIC 须为 8 或 11 位字母数字。
- 账号与 SWIFT 保存时去空格、转大写；本企业内两者都相同即视为重复（只差空格或大小写也算），拒绝保存并可查看已登记的那一条；账户名称不参与查重。
- 备注名与本企业已有账户重名时只提示、不阻断。

取不到本企业名称时不能新增法币账户：对话框说明原因并可重试，新增数币账户不受影响。企业名称变更后，本企业所有法币账户的账户名称随之更新；已提交业务记录保留提交时的名称。保存即生效，不进审核，不发通知；失败时账户保持原状并可重试。

**数币账户。**

- 新增分两步。第一步在同一环节选链（ETH / TRON，不预选）、填数币地址与账户备注名；填址前先告知只能登记可签名的地址。未选链或地址不符所选链格式（ETH 为 `0x` 加 40 位十六进制，TRON 为 `T` 开头共 34 位）不能进入签名；改选链时地址保留，按新链就地重新校验。第二步核对后在钱包中签名，结果覆盖通过、拒绝、签名地址不一致、钱包不可用。
- 查重：同链同地址不得重复；ETH 地址不区分大小写，TRON 地址区分大小写、按原样比较。
- 修改只开放备注名，链与地址锁定。

**详情与删除。**

- 只读详情用右侧面板，便于对照列表：本人可见完整账号 / 地址并可复制，IBAN 按 4 位分组展示、复制得到无空格原值；记录分节显示登记时间，修改过的账户另显示最近修改时间。
- 删除用居中确认对话框，危险色主按钮，列出后果：不再可选用；已提交业务保留当时的账户信息；若是该类最后一个可用账户（信息不完整的不算），提示相关业务办理将无法提交；不可撤销，数币再用须重新签名。
- 未保存离开时先确认放弃。

**业务选用侧。** 报价、放款选账户的列表与只读账户信息展示账户名称、账户类型与账户币种，不按这两项筛选。“前往企业账户 / 机构账户”进入本页并带回流参数，登记后可返回原办理，已填内容保留。已选账户被改动或删除时要求重新选用，不静默替换。报价选账户时如何显示信息不完整的账户，留给报价模块处理，本模块未改。

## 使用与维护

打开 `企业账户.html` 默认进入资产广场（与其他面客入口一致），通过账号菜单第三项或直接打开 `#/company-accounts` 进入本页。右下角“演示工具”默认关闭：展开后按“登录状态 → 页面 → 状态”选择；本页状态为默认、尚未取得认证资格、加载中、空数据、加载失败。“更多模拟”里有下次保存 / 删除响应、企业名称可取得 / 取不到、模拟企业名称变更与重置演示账户；签名的异常结果在模拟钱包对话框的“模拟 · 仅评审”一行选择。

所有账户、银行、地址与时间都是虚构演示数据；平台不验证账户真实性，页面不出现“账户已验证”一类结论。演示数据本地键为 `hc-ws386-v4`。

源文件：`企业账户.html`（骨架）、`企业账户.js`（页面、详情面板与对话框）、`企业账户.css`（本页局部组合）、`演示数据.js`（账户目录、字段与校验）。币种与网络图形及授权取共享文件 `_shared/asset-icons.js`，与资产广场共用；公共 token / 组件 / 运行时同样来自 `_shared/`，不手改导出件。

```bash
python3 _shared/export.py --source 面客端/02-企业账户/企业账户.html --output /tmp/借贷平台-企业账户-原型.html
```

## 验证与边界
