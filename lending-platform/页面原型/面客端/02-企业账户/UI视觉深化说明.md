# 企业账户 UI 视觉深化

本轮为既有系统适配（`existing-system adaptation`），面向资产方与资金方的面客工作区。原型基线 `ef89d0f`，目标分支 `cly-v5.0.0`。业务依据为本模块 PRD `0ab93c5`；网络名称按用户最新要求展示“以太坊 / Ethereum”。

## 继承与范围

沿用 `_shared/tokens.css` 的蓝白语义色、字号、间距和普通控件高度，沿用本地 Geist / Noto Sans SC、`base.css` 的 portal / modal / drawer / table、`asset-icons.js` 的原图及许可。共享层未修改，也没有新建 token、字体或图标副本。历史设计记录中的紧凑表单尺寸由本轮下述规格替代。

只修改本目录的呈现样式、三处页面 / 表格 class 与说明文档；没有修改账户目录、字段、权限、校验、数据精度、路由、默认选项、状态转换或业务流程。数币 Tab 在前，新增数币依然填写后签名；网络只读、地址锁定、只改备注名等规则保留。PRD 内网络缩写的同步交由 PRD 负责人处理。

## 运行与导出

保留完整原型目录时，打开 `企业账户.html#/company-accounts`。独立评审附件从源文件生成，不手改导出 HTML：

```bash
# 在 lending-platform/页面原型/ 下执行
python3 _shared/export.py --source 面客端/02-企业账户/企业账户.html --output /tmp/企业账户-UI视觉深化.html --entry-route /company-accounts
```

附件可双击离线打开；默认未登录时，使用右下角“演示工具”选择资产方或资金方已认证视角，再进入企业 / 机构账户。演示工具还可切换加载、空数据、失败与未认证状态。所有名称、银行和账户均为虚构演示样本。
