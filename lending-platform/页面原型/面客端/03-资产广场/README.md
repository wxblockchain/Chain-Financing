# 资产广场（已准入代币只读域）

面客端公开、只读的代币展示区：代币列表 `/assets` 与代币详情 `/assets/{平台代币标识}` 两页，所有访问状态（游客、登录未绑定角色、资产方、资金方）看到的内容相同。

- **业务基线**：资产广场 PRD 三册 2026-10-21 修订版（WS-445，`01` 功能与业务规则 / `02` 流程图与状态机 / `04` 验收）。修订版目前以 issue 附件交付，入库后以 `../../../PRD/面客端/04-资产广场-已上架代币只读域/` 为准。
- **界面口径**：[前端交付说明](前端交付说明.md)（当前规格）；PRD 衔接见[PRD 同步清单](本轮反馈与PRD同步清单.md)。
- **视觉基线**：沿用 `_shared/` 的 token、组件、`market.css` 两广场组合与 2026-10-16 UI 视觉深化结果（[UI视觉深化说明](UI视觉深化说明.md)）；本模块不另设 token。

## 当前实现要点

- **准入后展示**：只有已准入代币进入列表、汇总、搜索与详情。待审核、已退回代币打开详情地址与不存在的标识一样显示「内容不存在」；页面不展示准入状态。
- **详情定位**：按平台代币标识定位，不再按代币编号；同号代币（来自不同发行平台）各有独立详情，搜索编号两笔都返回。
- **头部汇总**：只剩代币价值、代币数量两项，只统计有效代币；失效代币仍在列表与详情中。
- **列表**：默认七项；放大态在页面内展开为十一项，新增代币类型、铸造时间、代币发行合约（缩略 + 复制）与资产槽位。网络、铸造链、存证链展示链全称（以太坊 / Ethereum）。
- **详情**：概览、代币信息、基础资料信息、链上存证、持有方五部分。代币信息补充来源发行平台、发行方注册地、签发汇率与生效时间、代币符号、链 ID、资产槽位、精度、合约审计；基础资料信息公开买卖双方，并补充买方注册地、追索安排、确权情况、债权转让登记。单据号码、文件、自由文本、主体标识与初始收币地址不展示。
- **代币类型**：`ERC-3525-应收账款`。

## 视图状态与寻址

筛选、排序、关键词、已加载条数与内外滚动位置写在列表 URL 里；追加与滚动用 `replaceState`，条件变化新建历史项并回到首批。详情 URL 的 `return` 参数带完整列表快照，刷新详情后返回仍可恢复。恢复不依赖 sessionStorage。

## 2026-09-20 · 下滑自动追加

首批 20 笔，列表框内下滑到底自动追加 20 笔，末批按余量；没有分页器。恢复时先按 URL 重建已加载范围再定位，不因恢复到尾部自动追加。追加失败保留已加载内容并在尾部提供重试（`am-more`），不自动循环重试。汇总不随追加变化。

## 2026-09-20 · 五点反馈增量

编号单击复制、整行其他区域进入详情（两种动作不互相替代）；数量单位「枚」写在表头与卡片字段名。该约定沿用至今，放大态新增的代币发行合约同样是复制动作。

## 演示工具

右下「演示工具」默认关闭，不属于产品界面：

- 列表：加载中、全局空、筛选无结果、首批失败；「下一批失败」与 7 / 20 / 全部样例条数。
- 详情：持有方各分支（加载中、读取失败、为空、只有零余额、合计不等、缺地址、质押记录核对不上、不可用）；打开典型样例、两笔同号代币，以及待审核 / 已退回 / 不存在标识的详情地址。

## 范围

原型只演示界面与交互：平台代币标识的生成、准入状态、上游同步、限流与真实接口都不在原型内实现。平台代币标识由代币准入审核在形成准入记录时生成，属该模块的依赖。
