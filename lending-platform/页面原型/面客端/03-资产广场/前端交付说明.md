# 资产广场 · 前端交付说明

面向前端实现的页面口径。业务规则以 [PRD 三册](../../../PRD/面客端/04-资产广场-已上架代币只读域/01-资产广场-PRD.md) 为准，本文只写界面怎么做。颜色、字号、间距、圆角一律取 `_shared/tokens.css` 的变量，组件取 `_shared/base.css` 的公共类，不另起样式值。原型源码：本目录 `资产广场.js` / `资产广场.css`。

## 1. 页面与路由

| 页面 | 路由 | 壳层 | 说明 |
| --- | --- | --- | --- |
| 资产广场（列表） | `/assets`，`/` 同样进入 | portal 顶栏工作区，一级导航「资产广场」 | 默认入口；筛选、排序、关键词、已加载条数与浏览位置写入 query，刷新与分享可恢复 |
| 代币详情 | `/assets/{代币编号}` | portal，面包屑「资产广场 › 代币详情」 | 不进导航；面包屑返回列表并恢复原视图，焦点回到原代币行 |

两页对所有访问状态（游客、登录未绑定角色、资产方、资金方）内容一致，没有受限视图、没有登录引导卡。登录入口只在顶栏。

## 2. 列表页

自上而下：页头 → 头部汇总 → 列表卡（筛选行 / 条数行 / 列表）。

**页头**：标题 `.page-title`；说明 `.page-desc` 一行。

**头部汇总** `.stat-strip`，三项横排：

| 项 | 取值 | 下方注释 |
| --- | --- | --- |
| 代币数量 | 当前筛选结果全集逐笔求和，含失效，`#,##0.00` | 枚 · 含已失效代币 |
| 代币价值 | 同上，前缀小号 `USD`，accent 色 | 按各笔签发时汇率折算（常驻，不可省） |
| 其中失效 | 失效记录数量合计，warn 色 | 枚 · 代币数量的子集 |

首批加载中三项为骨架；首批读取失败三项显示「—」；结果为空显示 `0.00`。追加批次不改变汇总。

**筛选行** `.filterbar`，一行内依次：代币状态 · 质押状态 · 代币类型 · 资产方企业（均为多选下拉 `.fb-menu`，选中后显示「名称 · 已选数」）→ 排序下拉 → 搜索框 → 重置 · 查询。

- 排序选项：最新铸造（默认）、最早铸造、价值从高到低、价值从低到高、到期日由近及远、到期日由远及近。非默认时下拉高亮。
- 搜索框占位「代币编号、资产方或哈希」，完整提示放 `title` 与 `aria-label`：代币编号、资产方企业名或铸造交易哈希；回车或「查询」触发。
- 1280 英文界面下这一行不换行（搜索框基准宽 176px）；选中筛选导致变宽时允许自然折行。

**条数行** `.list-full-bar`：左「共 N 条代币」，右「放大到整窗」图标按钮。

**列表** `.tablewrap.listbox.listbox-contained`（列表框内滚动，表头吸顶），九列：

| 列 | 内容与格式 | 对齐 |
| --- | --- | --- |
| 代币 | 标识图 24px + 代币名称（粗体，超长省略）；无标识图时留 24px 空位，名称对齐；无名称时显示发行合约名 | 左 |
| 代币编号 | 16 位完整显示，等宽小号 accent；本身是按钮，点击 / Enter / Space 复制完整编号并 toast 成败，不进详情 | 左 |
| 资产方企业 | 完整显示，可折行 | 左 |
| 代币类型 | 如 `ERC-20-应收账款` | 左 |
| 代币数量 | `#,##0.00 枚`，等宽 | 右 |
| 代币价值 | `USD #,##0.00`，等宽加粗；表头可点排序 | 右 |
| 代币状态 | `.tag`：有效（ok）/ 失效（中性） | 左 |
| 质押状态 | `.tag`：已质押（accent）/ 未质押（中性） | 左 |
| 铸造时间 | `yyyy-MM-dd HH:mm`，muted；表头第二行小字标时区（如 `Asia/Shanghai`）；表头可点排序 | 左 |

- 点击编号以外的任意区域（含标识图）进入详情；行可 Tab 聚焦，Enter / Space 进入详情。
- 连续加载：首批 20 条，列表框滚到底自动追加 20 条，末批按余量；尾部依次显示「下滑自动加载更多 · 已显示 x / N 条」→「正在加载更多…」→「已到末尾 · 共 N 条」。追加失败在尾部显示「加载失败，已显示内容保留。」+「重试」，不自动重试。
- ≤1200px 每行转为同序九字段卡片；≤600px 汇总单列。

**列表状态**

| 状态 | 表现 |
| --- | --- |
| 首批加载 | 汇总骨架 + 表格骨架 6 行 |
| 全局空 | 「暂无代币」/「代币同步到平台后会显示在这里。」，无按钮 |
| 筛选无结果 | 「没有符合筛选条件的结果」/「放宽范围，或清掉其中一个筛选条件。」+「清空筛选」 |
| 首批失败 | 「列表加载失败」+「重试」，汇总为「—」 |
| 访问频次受限 | 列表卡上方 warn 提示「操作较频繁，请稍后再筛选或搜索；已显示的内容不受影响。」，不阻断浏览 |

## 3. 详情页

单列全宽，五个卡片自上而下，卡片间距 `--sp-5`。卡片内字段用 `.dl`：≥1100px 每行两组「标签 · 值」，短字段在前成对排列，长值（合约地址、哈希）整行排在后面；≤600px 标签在上、值在下。

1. **概览**（无卡片标题）：标识图 48px（无图则不显示）+ 代币名称 `.page-title` 24px + 完整编号与复制图标；分隔线下并列两个状态，每个为 `.tag` + 一行小字依据：
   - 代币状态依据：有效「对应应收账款于 yyyy-MM-dd 到期」；失效「对应应收账款已于 yyyy-MM-dd 到期」。
   - 质押状态依据：已质押且项目已发布「质押于 {项目名称}」；已质押且项目未发布「所属融资项目尚未公开」；未质押「当前未质押于任何融资项目」。
2. **代币信息**：代币数量 | 代币价值；代币类型 | 质押链（链图标 + `ETH`）；铸造时间；代币发行合约（名称一行、完整地址一行 + 复制，地址不缩略）；铸造交易哈希。
3. **原始资料信息**：资产方企业名 | 买方企业名；应收账款金额（`币种 #,##0.00`）| 底层应收账款账期（`yyyy-MM-dd – yyyy-MM-dd`）；贸易类型 | 结算方式。
4. **链上存证**：区块高度 | 链 ID；存证时间；存证哈希；链上存证交易哈希。
5. **代币持有地址**：表格五列——地址（`0x` + 前 4 位 … 后 4 位缩略 + 复制完整值）、持有数量、对应价值、质押状态、所属融资项目（已发布为项目名称链接，当前窗口进入借贷广场项目详情；未发布显示「所属融资项目尚未公开」；未质押显示「—」）。

**哈希的统一写法**：缩略 `0x` + 前 8 … 后 8 的等宽胶囊 + 复制图标 + 外链图标（新窗口打开区块浏览器），下方紧跟一行小字「平台未核验该交易，链接仅供自行查验。」——铸造交易哈希与链上存证交易哈希都要；存证哈希只有复制，没有外链。

**时间**：详情每处时间为 `yyyy-MM-dd HH:mm (时区)`，时区用 muted 色。

**详情状态**

| 状态 | 表现 |
| --- | --- |
| 编号不存在或格式非法 | 同一个空态「内容不存在」/「请检查链接是否完整，或返回资产广场查找。」 |
| 持有信息加载中 | 卡片内骨架 2 行 |
| 持有信息读取失败 | 「持有信息加载失败」+「重试」 |
| 持有信息不可用 | 「持有信息暂不可用」。空集合、零余额历史地址、字段缺失、与质押事实对不上、多个当前地址都走这一个结果，不显示「暂无持有地址」，不补 0 或假地址 |
| 单个非关键字段缺失 | 该字段显示「—」，所在卡片照常展示 |

## 4. 通用交互与文案

- 复制：成功 toast「已复制。」；失败「复制失败，请手动选择后复制。」，不改变浏览位置。
- 只有区块浏览器外链新窗口打开，其余跳转都在当前窗口。
- 状态一律文字 + 色点，不只靠颜色；所有可点元素有 `:focus-visible` 焦点环。
- 中英文案成对写在 `资产广场.js` 的 `L(en, zh)` 调用里，默认英文，切换不刷新。
- 页面不出现规则编号、数据来源说明或审核状态、额度、质押率等字段。
