# 资产广场 · 前端交付说明

面向前端实现的页面口径，2026-10-21 按资产广场 PRD 修订版（WS-445，三册以 issue 附件为准，尚未入库）更新。业务规则以 PRD 为准，本文只写界面怎么做。字体、颜色、字号、间距、圆角取 `_shared/tokens.css`；组件复用 `_shared/base.css`，两广场组合复用 `_shared/market.css`。本模块源码为 `资产广场.js` / `资产广场.css` / `演示数据.js`。

## 1. 页面与路由

| 页面 | 路由 | 壳层 | 说明 |
| --- | --- | --- | --- |
| 资产广场（列表） | `/assets`，`/` 同样进入 | portal 顶栏工作区，一级导航「资产广场」 | 默认入口；筛选、排序、关键词、已加载条数与浏览位置写入 query，刷新与分享可恢复 |
| 代币详情 | `/assets/{平台代币标识}` | portal，面包屑「资产广场 › 代币详情」 | 不进导航；按借贷平台生成的平台代币标识定位，不按代币编号定位，标识不在页面上展示；面包屑返回列表并恢复原视图，焦点回到原代币行 |

两页对所有访问状态（游客、登录未绑定角色、资产方、资金方）内容一致，没有受限视图、没有登录引导卡。登录入口只在顶栏。只有已准入代币出现；待审核、已退回代币不进列表、汇总与搜索，打开其详情地址与标识不存在一样显示「内容不存在」。页面不展示准入状态。

## 2. 列表页

自上而下：页头 → 汇总 → 筛选工具条 → 代币清单标题及视图 / 计数 / 放大工具 → 卡片或表格。沿用 `cly-4.0.0` 已确认的蓝白、Geist / Noto Sans SC 和[共享组件视觉规范](../../_shared/design-system/共享组件视觉规范.md)。

**页头**：标题 `.page-title`，桌面 `--fs-28`、字重 600，小屏 `--fs-24`；删除重复描述性副标题。

**头部汇总** `.stat-strip`，两项并排靠左，只统计当前筛选与搜索全集中的**有效代币**；失效代币照常出现在列表中，不计入汇总。不再提供「其中失效」与代币数量构成图。

| 项 | 标签 | 取值 | 下方注释 |
| --- | --- | --- | --- |
| 代币价值 | 代币价值 | 有效代币签发价值逐笔求和；国旗图标 + 简写数值 + 小号 USD，accent 色；点击原位展开完整金额 | 按各笔签发时汇率折算（常驻，不可省） |
| 代币数量 | 代币数量 | 有效代币数量求和，`#,##0.00`，后接小字号「枚」 | — |

首批加载中两项为骨架；首批读取失败两项显示「—」；没有匹配的有效代币（含只筛失效）显示 `0.00`。排序、追加、返回不改变汇总。

**汇总排布**：两项 `repeat(2, max-content)`、列距与第二项左内距均为 `--sp-9`，以轻竖线分隔；同一汇总区右侧仅提示一次「仅统计有效代币」。≤600px 上下排列、去掉竖线，口径提示换到下方；重点数值使用 `--market-stat-size`。

**筛选工具条** `.filterbar.am-filters`，依次：代币状态 · 代币类型 · 发行方（均为多选下拉 `.fb-menu`，选中后显示「名称 · 已选数」）→ 排序下拉 → 搜索框 → 重置 · 查询。不提供质押状态筛选和链筛选。前四项收在 `.am-filter-options` 中，公共筛选交互不变；结果数、视图切换和放大保留在下方清单工具区。

- 排序选项：最新铸造（默认）、最早铸造、价值从高到低、价值从低到高、到期日由近及远、到期日由远及近。非默认时下拉高亮。
- 搜索只命中代币编号、发行方名称、铸造交易哈希；同号的不同代币都返回；不公开的信息不作为命中依据。
- 搜索框占位「代币编号、发行方或哈希」，完整提示放 `title` 与 `aria-label`：代币编号、发行方名称或铸造交易哈希；回车或「查询」触发。
- 搜索框使用剩余宽度。删除旧版「769～1399px 强制分行」规则，三项筛选与排序在桌面按内容自然排布；≤768px 搜索独占一行，动作在后。选中筛选或长翻译放不下时允许自然换行，不缩小文字硬塞。

**结果工具** `.mk-result-tools`：卡片 / 表格切换、「共 N 笔」与放大图标，位于清单标题右侧。一条记录是一笔代币，可含多枚；计数用「笔」，数量用「枚」。空结果显示 0 笔；加载或首批失败时不显示未经确认的结果数，放大入口仍可用。

**两种信息密度**（`.listzone[data-density]`）：
- 默认 `core`：只给核心信息——网络、代币、代币编号、发行方、代币数量、代币价值、代币状态。
- 放大 `full`：在原位置补出代币类型、铸造时间、代币发行合约与资产槽位，共十一项；卡片与表格同一规则（多出的列 / 行带 `.am-col-x`）。
- 放大是当前页面内的展开，不是弹窗：顶栏保留，页头、汇总和页脚收起，列表区（筛选行 + 清单）在顶栏下方占满整页高度，内容区放宽到整页宽，两侧留白 `--sp-7`、上下 `--sp-5`（≤768px 均为 `--sp-4`）；不加遮罩、不加浮层阴影，清单仍在列表框内滚动和连续追加。
- 放大按钮：默认态读作「放大，查看全部信息」，放大态图标变为关闭、读作「收起，回到精简列表」；Esc 同样收起。触控设备热区 `--ctrl-h` 44px，桌面 `--ctrl-h-sm`。
- 排序不受密度影响：铸造时间在默认态隐藏时，仍可从排序下拉按铸造时间排序。

**列表** `.tablewrap.listbox.listbox-contained`（列表框内滚动，表头吸顶），卡片 / 表格两种视图同一组字段：首列网络（取铸造链，展示全称：中文「以太坊」、英文 Ethereum），其后为 PRD 确认的八项及放大态新增的两项，标「放大」的四项只在放大态出现。列表不展示质押状态：

| 列 | 内容与格式 | 对齐 |
| --- | --- | --- |
| 网络 | 网络图标 + 链全称（以太坊 / Ethereum），即铸造链 | 左 |
| 代币 | 标识图 24px + 代币名称（500，允许完整折行）；演示几何图统一用链上数据蓝色，不承担状态语义；无图留同宽空位，无名称显示发行合约名 | 左 |
| 代币编号 | 16 位完整显示，沿公共字族与 `--market-row-value`，使用 `--hash-text` 区分复制动作；点击 / Enter / Space 复制完整编号并 toast 成败，不进详情 | 表格左，卡片与标签分列 |
| 发行方 | 发行方企业名称，完整显示，可折行 | 左 |
| 代币类型（放大） | 本期 `ERC-3525-应收账款` | 左 |
| 代币数量（枚） | 单位写在表头「代币数量（枚）」/ `Token amount (tokens)`，卡片字段名同样带单位；单元格只给数字 `#,##0.00`，等宽 / 500 | 右 |
| 代币价值 | 完整数值 + 小字号 USD，同一行可得、必要时自然换行；不带图标。卡片保留已确认的重点数字字号，表格沿清单字号；表头可点排序 | 表格右，卡片与标签左边界对齐 |
| 代币状态 | `.tag`：有效（ok）/ 失效（中性） | 左 |
| 铸造时间（放大） | `yyyy-MM-dd HH:mm`，`--fs-12` / muted；窄列允许在日期与时分之间换行；表头第二行完整标时区（如 `Asia/Shanghai`），可点排序 | 左 |
| 代币发行合约（放大） | `0x` + 前 4 … 后 4 缩略，同编号的复制样式；点击复制完整地址并 toast 成败，不进详情 | 左 |
| 资产槽位（放大） | slot 完整显示，等宽 `--fs-12`，不折行 | 左 |

- 点击编号、合约地址以外的任意区域（含标识图）进入详情；行可 Tab 聚焦，Enter / Space 进入详情。
- 连续加载：首批 20 笔，列表框滚到底自动追加 20 笔，末批按余量；尾部依次显示「下滑自动加载更多 · 已显示 x / N 笔」→「正在加载更多…」→「已到末尾 · 共 N 笔」。追加失败在尾部显示「加载失败，已显示内容保留。」+「重试」，不自动重试。
- 卡片视图与 ≤1200px 时每笔代币转为同序字段卡片：显式卡片视图将名称与网络放在首行，去掉重复的「网络」标签；表格窄屏变体仍按列顺序读取。编号 / 发行方 / 代币类型逐行，数量与价值并排，数值各与自己的标签左边界对齐；状态用轻行线独立为页内末行，铸造时间、代币发行合约、资产槽位在放大态底部各占一行「标签 · 取值」。卡片行距为 `--sp-2`，数量 / 金额区上下内距为 `--sp-2`。不降低已有重点金额字号。
- 放大态表格十一列宽度由 `资产广场.css` 重新分配（1280 下编号、状态、地址与槽位不折行，代币名称与类型可在词间折行）；默认态沿用 `market.css` 七列宽度。
- 桌面表格单元格上下内距为 `--sp-3`，保留复制与行导航的原热区；金额、数量右对齐。
- 卡片内容宽度≤360px时，数量 / 金额各占整行，避免完整大数被半栏裁切；大于该宽度并排，不改变字号、字段或数据精度。

**列表状态**

| 状态 | 表现 |
| --- | --- |
| 首批加载 | 汇总骨架 + 表格骨架 6 行 |
| 全局空（含只有待审核或已退回代币） | 「暂无代币」/「代币上架后会显示在这里。」，无按钮；汇总为 0 |

## 3. 详情页

单列全宽，概览、章节定位条与四个信息区自上而下。概览为开放页头，其余只读信息保持白色内容面与轻描边；区块标题使用真实 `h2` 和 `--market-section-title`，上下内距 `--sp-4`；字段区上下内距 `--sp-2`，横向内距桌面 `--sp-6`、小屏 `--sp-4`。

**章节定位** `.am-section-nav`：代币信息 / 基础资料信息 / 链上存证 / 持有方四个按钮；保留独立详情地址和所有内容，点击只滚动并将焦点移到对应分区。顶部吸附偏移由实际 `.portal-head` 高度读取，目标偏移再加定位条实测高度；随滚动更新 `aria-current`，窄屏定位条横向滚动。

**字段网格**（`.dl`）：每项由 `.am-fact` 包住已有 `dt` / `dd`，仍保留原顺序与语义。≥1100px 左右两栏等宽，每栏「标签 136px · 值」；每组上下内距 `--sp-3`，相邻行用 `--row-line` 轻分隔，首行无顶线。长地址、哈希留在各自半栏内并可换行，两个分栏共享行轨道；600～1099px 单列标签和值并排，≤600px 标签在上、值在下。**字号字重统一**：标签 `--market-field-label` / 400 / muted，取值 `--market-field-value` / 400 / 正文色；数字只用 tabular 数字，不加粗放大；地址与哈希沿 `--fs-12`。

1. **概览**（开放页头，两行）：第一行标识图 48px（无图则不显示）+ 代币名称 `--fs-24` / 600 + 代币状态 `.tag`；第二行 `--fs-13` muted：完整编号与复制图标，细竖线分隔后接状态依据——有效「底层应收账款于 yyyy-MM-dd 到期」，失效「底层应收账款已于 yyyy-MM-dd 到期」。概览不展示质押状态，也不再放发行方 / 账期 / 链的摘要条（这些只在下方分区出现一次）。
2. **代币信息**（十六项，成对相邻）：前八项归「发行与计价」，后八项归「链上标识」，每组独立字段网格，分组标题为 `h3`，字号 `--fs-12`、字重500；不增加业务字段。发行方 | 发行方注册国家或地区；来源发行平台 | 代币类型；代币数量 | 代币价值；签发汇率（`1 原币 = 汇率 USD`，下一行 muted「生效时间 yyyy-MM-dd HH:mm (时区)」，汇率按上游原值不补位）| 代币符号（无则「—」）；铸造链（网络图标 + 全称）| 链 ID；代币发行合约（名称一行、完整地址一行 + 复制，地址不缩略）| 资产槽位（完整 + 复制）；精度 | 合约审计（「已审计 · 机构」+ 下一行「报告日期」；未审计显示「未审计」；不提供报告文件）；铸造时间 | 铸造交易哈希。
3. **基础资料信息**（十项，五行两栏）：卖方企业名 | 买方企业名（完整显示，卖方与发行方分别展示）；应收账款金额（币种图标 + `#,##0.00` + 币种代码）| 买方注册国家或地区；底层应收账款账期（`yyyy-MM-dd – yyyy-MM-dd`）| 追索安排（有追索 / 无追索）；贸易类型 | 结算方式；确权情况（「已确权」+ 下一行确权时间，或「未确权」；无凭证）| 债权转让登记（「已登记 · 登记机构」或「未登记」；无登记编号）。不展示合同号、发票号、提单号、应收账款编号、登记编号、付款条件原文、备注、文件与初始收币地址。
4. **链上存证**（五项）：存证链（网络图标 + 链全称；不展示链 ID）| 区块高度；存证时间 | 存证哈希；链上存证交易哈希（按存证链打开对应区块浏览器）。
5. **持有方**：表格，每个持有方一行，五列——持有方（链上地址，`0x` + 前 4 位 … 后 4 位缩略，悬停 / 复制得完整值）、持有数量（枚）、对应价值（USD，= 持有数量 × 代币价值 ÷ 代币数量）、质押状态（`.tag` 已质押 / 未质押）、所属融资项目（已发布为项目名称链接，当前窗口进入借贷广场项目详情；已通过审核未发布显示「所属融资项目尚未公开」；未质押显示「—」）。行按持有数量从多到少，同量按地址排序。同一笔代币的不同行可以是不同质押状态、不同项目。不显示持有方数量或占比。

**哈希的统一写法**：缩略 `0x` + 前 8 … 后 8 的等宽胶囊 + 复制图标 + 外链图标（新窗口打开区块浏览器），下方紧跟一行小字「平台未核验该交易，链接仅供自行查验。」——铸造交易哈希与链上存证交易哈希都要；存证哈希只有复制，没有外链。

**时间**：详情每处时间为 `yyyy-MM-dd HH:mm (时区)`，时区用 muted 色。

**币种与网络图标**：全平台统一取 `_shared/asset-icons.js`——法币为圆形国旗（USD / EUR / GBP / JPY / CNY），数币与网络为官方配色圆标（ETH / TRON / USDT / USDC）；原图自带底色，不再叠加徽章底色或描边。金额格式全平台统一为「币种图标 + 数字 + 小字号币种代码」（代码 `--fs-11` muted，小于数字），由 `CF.market.amount` 输出：
- 详情：代币价值、应收账款金额、持有方对应价值都带图标，数字随字段 14px（持有方表格 13px）。
- 首页汇总：带图标，数字为统计字号，可简写并展开完整金额。
- 列表卡片 / 表格：按已定规则去掉逐行重复的图标，保留「数字 + 小字号币种代码」。
- 数量（枚）同样是「数字 + 小字号单位」，不带图标。

**详情状态**

| 状态 | 表现 |
| --- | --- |
| 标识不存在、格式非法、代币待审核或已退回 | 同一个空态「内容不存在」/「请检查链接是否完整，或返回资产广场查找。」，不透露差别 |
| 持有方加载中 | 卡片内骨架 2 行 |
| 持有方读取失败 | 「持有方信息加载失败」+「重试」 |
| 持有方不可用 | 「持有方信息暂不可用」。持有方为空、只有零余额地址、持有数量合计 ≠ 代币数量、某持有方缺地址或数量、质押合约与质押记录核对不上，都走这一个结果；不显示「暂无持有方」，不补 0、假地址或默认未质押。多个持有方是正常情形 |
| 单个非关键字段缺失 | 该字段显示「—」，所在卡片照常展示 |

## 4. 通用交互与文案

- 复制：成功 toast「已复制。」；失败「复制失败，请手动选择后复制。」，不改变浏览位置。
- 只有区块浏览器外链新窗口打开，其余跳转都在当前窗口。
- 状态一律文字 + 色点，不只靠颜色；所有可点元素有 `:focus-visible` 焦点环。
- 中英文案成对写在 `资产广场.js` 的 `L(en, zh)` 调用里，默认英文，切换不刷新。
- 页面不出现规则编号、数据来源说明、准入状态或「已审核」标记，也不出现额度、质押率等字段。

## 5. 演示件说明

评审件中的企业、金额、地址、哈希与项目均为演示数据（页脚已声明）；右下「演示工具」默认关闭，仅用于切换身份、语言、列表状态、持有方各分支，以及打开同号代币、待审核 / 已退回 / 不存在标识的详情地址，不属于产品界面，前端不需实现。
