## 变化与目的

- 卡片缩短无效留白，数量和金额与自己的标签左边界对齐；编号沿链上数据色表达复制动作，状态用轻行线单独分组。卡片内容宽度≤360px时，数量 / 金额顺排，避免大数挤入半栏；保持现有重点数字字号，不以缩字换密度。
- 表格收紧行内垂直留白，金额与数量继续右对齐。三项筛选与排序不再沿旧版 1399px 断点强制分行，移动搜索仍独占一行。
- 详情将每组标签和值包装为 `.am-fact`，保持原 `dl` / `dt` / `dd` 语义、字段顺序与两栏对称关系，以轻行线帮助阅读。标题区上下16px，字段区上下8px，每组上下12px，均取既有 spacing tokens；长地址和关键说明完整保留。

保留蓝白主题、本地 Geist / Noto Sans SC、现有字号语义与圆角；不新建 token 或图标。金额仍是图标 → 数字 → 小字号币种代码，列表逐笔金额无图标；数量单位仍在列表表头。法币国旗、数币与网络图标仍取企业账户使用的 `_shared/asset-icons.js`。
