## 当前视觉规格

- 页头删除泛化描述句；汇总仅保留价值和数量，「仅统计有效代币」提示一次；数量单位紧跟数值，签发汇率说明及完整金额展开保留。
- 显式卡片视图将代币名称和完整网络放在首行，移除重复网络标签，缩短卡片；编号 / 发行方仍有标签。完整数值、七 / 十一项密度、复制与整行详情入口保持。
- 详情增设四个章节定位按钮，吸附到实际顶栏下方；点击定位并移交焦点，滚动时同步当前位置，窄屏横向阅读。详情地址不变化，不新增路由或业务步骤。
- 十六项代币字段分为「发行与计价」「链上标识」两组，继续使用 `dl/dt/dd`，桌面等宽双栏、小屏单栏；普通字段不放大、不加粗。
- 清理模块 CSS 中累加的旧视觉覆盖、失效三项汇总和摘要条样式；本说明替换旧交付流水。历史冗余说明与 README 精简沿用上游附件改动。

颜色、字体、字号、间距、圆角只引用现有 token；组件尺寸与金额规则参见[共享组件规范](../../_shared/design-system/共享组件视觉规范.md)。本地新增的是章节导航与卡片身份行变体，不修改共享组件。实现与细节见[前端交付说明](前端交付说明.md)。
