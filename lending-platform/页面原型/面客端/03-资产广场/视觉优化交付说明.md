## Stage 2 · 设计方向与复用

端/角色：面客四类身份 · 模块：资产广场 · 功能点：14个 · 页面：列表 / 详情 · 状态：上表 · 视觉口径：当前借贷广场源码及共享设计系统。

- 列表沿用开放页头、数字汇总与白色列表内容面；结果数及放大并入筛选工具条。搜索采用剩余宽度，769～1399px 稳定分两行，不压缩英文标签。小屏保留完整九字段卡片和内滚。
- 三项汇总等列，失效数量改中性文字，蓝色价值保留；列表名称 / 编号增强层级，数量和价值使用等宽数字及次级单位，桌面同列右对齐。币种与金额始终同单元格可得。
- 详情保留概览 → 代币信息 → 原始资料 → 链上存证 → 持有地址的五区顺序。概览减去卡片边框 / 阴影，正文标题改 `h2`，标签与值拉开层级，长值独占整行。

量取的 canonical tokens：画布 `--bg`（#F7F8FB），内容 `--card`（#FFFFFF），正文 `--text`（#0D1526），次级 `--muted`（#4A5568），主色 `--accent`（#1D4ED8）；16px `--radius-lg`，列表阴影 `--shadow-soft`；标题28px / 小屏24px、数值24px / 小屏19px、正文与表头沿公共字号阶梯。字体仍为 `--sans` / `--mono`，项目规范优先于通用营销字体建议。源码颜色与字体均引用已有 token。
