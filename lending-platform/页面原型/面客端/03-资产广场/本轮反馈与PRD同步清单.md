# 资产广场 · 当前 PRD 与原型衔接

当前业务基线为 WS-373 的[主 PRD](../../../PRD/面客端/04-资产广场-已上架代币只读域/01-资产广场-PRD.md)、[流程图与状态机](../../../PRD/面客端/04-资产广场-已上架代币只读域/02-资产广场-流程图与状态机.md)和[消息通知](../../../PRD/面客端/04-资产广场-已上架代币只读域/03-资产广场-消息通知.md)。原型接续以三册及既有共享规范为准。

- Q-AM-55 已关闭：每笔代币当前只有一个真实链上持有地址；不是企业归属或铸造快照。
- Q-AM-56 保留真实资料供给与核对依赖：当前地址、整笔数量和签发价值、唯一当前项目按代币业务编号核对。不启用多地址分摊、多个当前项目或零余额历史地址的正常展示。
- 已质押表示代币在项目质押合约内且未被业务释放，含质押审核尚未通过、已驳回未解押，以及解押或撤回已发起但链上转出尚未成功；不代表已通过质押审核。
- 项目关闭或结清后业务已释放、代币尚未提取时显示未质押、项目“—”，地址如实显示质押合约地址，不宣称已到账或可再次质押；解押、撤回或提取转出完成后更新为唯一新地址。
- 所属项目已发布时进入借贷广场项目详情；已通过审核尚未发布时只提示“所属融资项目尚未公开”，无名称与入口。
- 待放款阶段无终止出口时，该笔代币在广场持续显示已质押并指向同一项目，不自行转为未质押，也不触发提示或通知。
- 质押链（代币与质押合约所在链，本期 ETH）与机构账户的结算收款链是两个概念，本模块只展示质押链，不合用同一个“链”字段。
- 同步与每日核对、本人资料/公开业务边界、列表枚数求和及三方零通知按主 PRD 与通知册核对。演示身份或虚构数据不能证明真实持有供给及登录回跳通过。

待 PRD 同步：用户 2026-10-12 要求详情页不再展示登录成为资金方的引导模块，原型已移除详情末尾引导卡；主 PRD `C-F-AM-07`、`F-AM-07` 末句与 `AC-AM-15` 仍写“详情末尾提供且仅提供一个引导入口”，需由 PRD 侧按用户裁定改写。登录入口仍只在顶栏。

跨模块待对齐：代币类型在本模块已按合并后的单一字段展示，借贷广场与我的控制台仍在用合并前的“应收账款”取值，随各自 issue 修订时对齐。

本文件只同步 PRD 阅读引用及已确认口径；原型实现情况见[模块接入说明](README.md)，前端实现口径见[前端交付说明](前端交付说明.md)。
