# 资产广场 · PRD 与原型衔接

业务基线：资产广场 PRD 三册 2026-10-21 修订版（WS-445），目前以 issue 附件交付、尚未入库；入库后以 [`01`](../../../PRD/面客端/04-资产广场-已上架代币只读域/01-资产广场-PRD.md) / [`02`](../../../PRD/面客端/04-资产广场-已上架代币只读域/02-资产广场-流程图与状态机.md) / [`04`](../../../PRD/面客端/04-资产广场-已上架代币只读域/04-资产广场-验收.md) 为准。本模块不发送消息，没有 03 册。

原型已按修订版对齐：

- 只展示已准入代币；待审核、已退回代币的详情地址显示「内容不存在」，不展示准入状态。
- 详情按平台代币标识定位；同号代币各有详情，搜索编号都返回。
- 头部汇总两项，只统计有效代币；不再有「其中失效」与构成图。
- 列表放大态十一项（新增代币发行合约、资产槽位）；链名展示全称。
- 详情按「公开哪些信息」补充代币信息与基础资料信息字段，不展示单据、文件、自由文本、主体标识与初始收币地址。
- 代币类型为 `ERC-3525-应收账款`。

依赖（不在本模块原型内解决）：

- 平台代币标识由运营端代币准入审核在形成准入记录时生成；原型用演示标识代替，相关验收在准入模块补齐前仍为待验。
- 持有方真实供给（`Q-AM-56`）仍待核实；演示数据与身份切换不能代替真实验收。

界面实现口径见[前端交付说明](前端交付说明.md)。
