# 资产广场 · 当前 PRD 与原型衔接

当前业务基线为 WS-373 的[功能与业务规则](../../../PRD/面客端/04-资产广场-已上架代币只读域/01-资产广场-PRD.md)、[流程图与状态机](../../../PRD/面客端/04-资产广场-已上架代币只读域/02-资产广场-流程图与状态机.md)和[验收](../../../PRD/面客端/04-资产广场-已上架代币只读域/04-资产广场-验收.md)（`cly-4.0.0` @ `7cba13c`）。本模块不发送消息，没有消息通知册。

- 一笔代币只有一个发行方，可以有多个持有方；持有方以链上地址表示，不展示身份。所有持有方的持有数量之和等于代币数量。
- 列表八项不含质押状态，也不提供质押状态筛选；概览只展示代币状态。质押状态与所属融资项目只在详情的持有方清单中逐个持有方给出，同一笔代币的持有方可以分属不同融资项目。
- 已质押表示该持有方的数量在某融资项目的质押合约中且未被业务释放（含质押审核未裁定、已驳回尚未解押、解押或撤回转出中），不代表已通过质押审核。项目关闭或结清后业务释放、尚未提取时显示未质押、项目“—”，持有方仍是质押合约地址。
- 持有方信息暂不可用的情形：持有方为空或只有零余额地址、持有数量合计不等于代币数量、某持有方缺地址或数量、质押合约与质押记录核对不上。多个持有方是正常情形。
- 详情代币信息展示发行方与铸造链（本期 ETH）；“原始资料信息”改称“基础资料信息”，其中卖方企业名与发行方分别展示，不假定相同。
- 统一称“铸造时间”。列表与详情都不提供登录、注册、成为资产方或资金方的引导。
- `Q-AM-56`（当前全部持有方及持有数量的真实供给）仍是依赖；演示数据与身份切换不能代替真实验收。

与 PRD 八项的差异：列表首列“网络”来自 WS-403 用户反馈（网络进首列，两个广场一致），取值即铸造链。PRD 列表信息项尚未收录这一列，需 PRD 侧确认是否补入。

2026-10-15 第二轮设计调整中，以下几处需要 PRD 侧同步（原型已按用户评论 `68e782ea` 落地）：

- **列表信息分层**：默认态展示网络、代币、代币编号、发行方、代币数量、代币价值、代币状态；放大后补代币类型与铸造时间。PRD `F-AM-03` 与验收 `AC-AM-26` 目前写“八项全部展示”，需改为两态划分；代币编号、代币价值、代币状态仍在任何状态下可见，与 PRD 共同要求一致。
- **放大的含义**：放大是同一列表的信息展开，不是另一页面；收起后恢复默认态，筛选、排序、已加载范围不变。
- **链上存证所在链**：存证五项中的“链 ID”改为“存证链”（链名），PRD `F-AM-08` 与对应验收需改写。
- **详情顶部**：概览只保留标识图、名称、代币状态及依据、编号；不再重复发行方、账期、链。PRD 概览项本就如此，无需改动，仅作知会。
- **网络列**：是否保留尚待用户答复，本轮维持现状。
