# 链上还款 · UI 设计与操作演示

2026-10-23 · WS-449 · existing-system adaptation · 面客 Web 工作区（console）

承接 Hallmark 设计师 `f5a2644` 的链上还款原型，当前整合基线为 `cly-v5.0.0@cce84d4`；业务依据为 `98d05c8` 的链上还款四册。保留蓝白视觉、本地 Geist / Noto Sans SC、共享字号与控件；只修改还款模块及借贷项目的演示入口。

## 变化

- 授权还款弹窗拓宽为 960px，金额区用轻底摘要明确“本期结算金额”，区分 USDT 应还合计；期次状态、应还日与逾期说明保持。
- 桌面收款地址与出账地址等宽并排，≤760px 纵排。选项复用共享图标下拉，选中后保留完整地址与复制；余额 / 所需金额并排，校验结果在下方单列。补齐余额区域的实际网格、标签与数值样式，避免使用浏览器默认 `dl` 排版。
- 定稿计划仍默认收起。办理页客服说明改为“需要帮助？联系客服”展开，邮箱与三类业务编号及复制全部保留；只读详情及异常状态客服继续常驻。
- 签名摘要、完整后果说明与主动作继续在固定底栏，正文可独立滚动。成功后办理区提供“查看还款详情”，可展开已结清期次查链上记录。
- 余额查询后重绘，在共享图标下拉增强完成后恢复原控件焦点；校验失败仍优先定位错误。

## 演示入口

入口文件仍为同目录 `借贷广场.html`，需保留完整“页面原型”目录；离线评审 HTML 可单独双击打开。默认英文，右上切中文。

1. 右下“演示工具” → “更多模拟” → **演示还款操作** → **开始还款演示**。
2. 自动准备资产方身份、已到应还日的本期及正常账户，直接打开“授权并还款”。出账地址保持未选，由评审人亲自选择。
3. 点击“授权并还款”，观察签名等待、上链确认中、本期结清，再从办理区“查看还款详情”查看记录。

项目详情的演示条“业务”行还提供 **演示还款操作 · 重置示例**，无需展开高级状态组。更多模拟提供 USDC、末期还本、链上失败、失败后重新还款与结果待核实的操作预设；原“5 · 链上还款状态与异常”保留未开放、计划生成中、多笔业务、逾期、账户 / 余额 / 合约等故障开关。

操作预设会重置本地示例并准备资产方身份，告知直接显示在入口旁；余额、钱包签名与链上结果均为本地模拟。普通角色切换和业务入口权限仍沿原规则。反复切换场景会展开还款办理区，不再把已经展开的区域切成收起；同时清除上次场景的表单、筛选与焦点上下文。

## 保留约束与覆盖

仍是一次签名提交本期还款，无新增勾选、二次确认或资金方确认。每期出账地址不预选；只从本企业 Ethereum 账户选用。应还日、余额 / 条款 / 合约校验、状态流、本金与利息计算、额度及本金占用、金额精度和失败 gas 规则未改。

| 角色 × 页面 / 状态 | 范围 |
| --- | --- |
| 资产方 × 还款办理 × 空白 / 已选地址 / 计划展开 | 修改；核验金额、地址、余额、客服、底栏、键盘与错误定位 |
| 资产方 × 操作演示 × USDT / USDC / 末期 / 成功 / 失败 / 未签名 / 待核实 | 修改入口，沿用原模拟执行；核验真实点击及前后状态 |
| 资产方 × 还款办理区 × 未开放 / 计划生成中 / 处理中 / 待核实 | 继承业务条件，核验不可重复提交与场景展开 |
| 双方 × 还款详情；非当事资金方 × 履约信息 | 信息结构继承；核验资金方只读及非当事方隐私边界 |
| 其他模块、真实钱包 / 链上 / 服务 / 消息投递 | 继承未改，不计入本轮完成设计或联调范围 |

## 实际核验

Chromium 149.0.7827.55 / Playwright，离线导出件阻断 HTTP(S) 请求。中英文 × 320 / 390 / 768 / 1280 / 1440 / 1920px × 空白还款、已选地址、计划展开、还款详情，共 48 组：无页面或浮层正文横向溢出，底栏在视口内，正文可滚动至末尾。窄屏保留完整签名说明，因此底栏较高；金额、地址、余额与客服通过正文滚动可访问。

实测演示工具与项目业务行两种真实入口；USDT / USDC 签名后经过处理中至本期结清、末期全部结清、授权失败、授权成功但还款失败、未签名及长期未知。余额不足 / 查询失败、合约不可用、地址未选仍阻止签名；未开放、计划生成中、处理中及待核实状态无重复提交入口。验证计划展开保留地址、键盘选址、余额回写后回焦、Tab 循环、客服展开、资金方只读和非当事资金方隐私边界。未捕获脚本异常，本地两款评审字体可用；补测 125% CSS zoom 下底栏可达，此项不等于原生浏览器缩放。

最终源码与导出件的字段、完整值、选项及签名说明比对一致；六个可见操作预设均从演示工具实际点击打开，失败后重新还款可成功结清；320px 地址菜单边界与 Escape 关闭复测通过。

入库整合了远端新增的控制台提交 `1c9c95e`，未改其文件；在整合版本重新导出并复测上述 48 组布局与主要还款行为，源码 / 附件比对再次通过。

未验证真实钱包、链上、接口、消息投递、真机、Safari / Firefox 或屏幕阅读器；不以本轮 UI 检查替代全量 PRD 验收。截图仅作内部核验，交付附件为从源文件生成的可交互 HTML。
