## 运行与导出

下载单文件 HTML，使用浏览器双击打开；默认进入借贷广场，不预设登录身份。右下角原有 Demo tools 可切换身份 / 状态；顶部导航可对照资产广场，显式 hash 深链照常生效。评审件自包含字体、样式和脚本，无需启动服务。

源码从完整目录打开 `借贷广场.html#/marketplace`。在仓库根目录重新导出：

```sh
python3 lending-platform/页面原型/_shared/export.py \
  --source lending-platform/页面原型/面客端/04-借贷广场/借贷广场.html \
  --output /tmp/WS-397-借贷广场-UI优化.html \
  --entry-route /marketplace
```

`--entry-route` 只设置无 hash 的离线评审初始入口，不更改源码路由、身份或产品默认设置。维护源仍是模块源码和 `_shared/`；生成件放在仓库外。
