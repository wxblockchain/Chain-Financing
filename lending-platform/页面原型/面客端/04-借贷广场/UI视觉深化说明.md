## WS-377 还款详情按期组织（2026-10-20）

Artifact class：**existing-system adaptation**；surface：**面客 Web 工作区（console / portal）**。基线 `cly-4.0.0@70484bd`（hallmark-GPT 页面重构）。用户反馈还款确认模块信息展示杂乱，要求比较当前呈现与“按每笔还款为列展示”。

### 判断与选型

| 方案 | 结论 |
| --- | --- |
| 现状（按信息类型分节） | 杂乱主因：同一期在“本期还款 / 待还款确认 / 还款计划表 / 还款记录”四处出现；两套两步进度上下叠放；计划标题重复详情头部编号；记录要到另一节再展开；确认办理的线下商定说明出现两次，复制按钮单独占行 |
