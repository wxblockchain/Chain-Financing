# 借贷广场 · 融资项目与代币质押

Stage 4 · `existing-system adaptation` / `console`。用户“直接输出页面原型”授权合并设计阶段、直接交付并提交既有模块目录。需求基线为 WS-351 四册 `c7ef580`；本轮以用户评论 `b03c51dd-2dfd-48e6-98b6-3973d06ca6a0` 的五项反馈覆盖先前列表与详情布局要求，业务规则与未确认事项保持原边界。

已同步 `cly2.0.0@04d96d3`。复用 `_shared/design-system/面客工作区组件规范.md`、`tokens.css`、`base.css`、`shell.js` 和共享路由。仅调整本模块 HTML、JS、README，不改公共组件、相邻页面或演示业务模型。

入口：[借贷广场.html](借贷广场.html)。默认英文、游客态；页头切换语言，默认关闭的演示工具切换资产方/资金方、审核结果、逐张执行结果、时钟和失败情形。演示数据保存在本地，工具内可重置；不发生真实链上操作。

## 本轮调整

| 页面 / 功能 | 最终表现 |
| --- | --- |
| `/marketplace` · P-LS-01 | 每行一个融资项目，突出项目名称、编号和所有者；项目池展示有效质押价值、总张数、计入/不计入覆盖张数与覆盖状态；当前需求单列展示金额、编号与状态，已放款/结束的历史需求不冒充当前需求 |
| 列表交互 | 整行点击、Enter 或空格进入详情；无操作列。币种/期限/关键词、更多筛选、排序、桌面定高内滚、吸顶表头、每批 20 条沿用现有约定；返回保留查询及加载位置 |
| `/project/{id}` · P-LS-02 | 标题、项目状态之下分为左侧信息与右侧操作；左侧五统计、质押清单、融资清单和操作记录独立滚动，右侧操作不跟随滚动 |
| 操作区 | 全局 / 融资 / 还款为内嵌标签页；支持方向键、Home、End。窄屏操作区置于信息上方，信息仍独立滚动；切换标签保留左侧位置 |
| 质押审核 | 仅所有者的全局标签显示“质押审核与结果”按钮及在途申请数；弹窗承载申请、审核历史、逐张执行结果。首次打开从顶部阅读；费用确认取消返回审核，关闭审核回到入口焦点 |
| 质押代币清单 | 编号下展示交易 Hash，点击复制完整值；相邻外链图标独立在新窗口打开区块链浏览器。移除“查看凭证”按钮；复制被拒时给出可选择的完整 Hash |
| `/project/new` · P-LS-03 | 保留建池、首笔申请、零费用提交和直接进入草稿详情的既有流程 |

公开清单与所有者私有审核/执行信息保持隔离。期限和利率仅展示当前需求已有数据，缺失值不推算；项目有效期不作为融资期限。示例 Hash 沿用已标注的演示数据，外链不代表存在真实交易。

## 继承的布局参考与边界

旧版实际分支名为 `cly-V1.0.0`，参考头 `ea56882a2d5c3680ed7220b9e1feb2a0d8fcb652`，目录 `financial-service-platform/prototypes/借贷广场-融资需求与代币质押/`，包含 `ls-module.js`。前轮已在浏览器打开两例详情，核对页头、五统计、信息清单和三段操作。此次按最新用户反馈将三段改为标签、审核移入操作弹窗，不再沿用“左侧审核首位”的旧安排，不复制旧版代码或 DOM 错位。

原型仍覆盖资产方建池/追加、审核撤回/驳回/失效、两次费用确认、逐张成功/失败、两自然日审核及执行超时、迟到回写冻结、发布/改额/撤下/关闭、解除质押预扣及失败回滚、终态提取、覆盖变化和主体权限。功能范围对应四册 F-LS-01～21（15 作废）；本轮未修改 PRD。

签名承载、主体映射、正式编号登记、对外审核承诺和消息分类保持未确认边界。运营审核、真实接口/链上签名与费用、授信报价/放款/还款、控制台和通知投递仍只提供演示事件或交接入口，不声称跨模块联调或生产验收完成。
