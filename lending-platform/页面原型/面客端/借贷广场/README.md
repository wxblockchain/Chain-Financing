# 借贷广场 · 融资需求与代币质押

Stage 4 · `existing-system adaptation` / `console`。用户“直接输出页面原型”授权合并四阶段。需求基线为 WS-351 最新四册 `c7ef580`，与触发线程四个附件逐字节一致；交付前同步 `cly2.0.0` 至 `65a22f2`。历史 `cly-V1.0.0@ea56882` 仅核对功能、交互和术语，没有复制旧模块代码。

入口：[借贷广场.html](借贷广场.html)。默认英文、游客态；页头可切换中英文。右下角默认关闭的演示工具可切资产方/资金方，输入审核结论、逐张执行结果、演示时钟与失败情形。金额、企业、凭证均为标注的演示数据，没有真实链上操作。演示状态保存在浏览器本地，可用“重置演示数据”清除。

## 边界与规范差异

- 最新公共规范要求游客不常驻登录提示，本模块已遵循；动作区按本册 D-LS-14 保留单个“立即登录”，不改为一组不可点业务按钮。真实登录/SSO 不在本模块，账号状态沿用底座演示能力，双角色评审使用独立工具。
- 费用确认只表达必要的业务确认，不代表费用确认/签名承载方已确定；Q-LS-02～06（签名承载、主体映射、正式编号登记、对外审核承诺、消息分类）保持原边界。执行超时沿用两自然日，不新增时限。
- 本次不改授信报价、放款、还款等后续页面，也不将其承载入口冒充已实现流程；不增加上架闸门、可调质押率、资产拆分、指定转出地址、延期、清算或平台代付。
- 资产广场保留独立样例数据，真实跨模块状态同步不属于离线原型；本次仅回归相邻页面能正常打开，不声称联调完成。
