## 边界与规范差异

- 最新公共规范要求游客不常驻登录提示，本模块已遵循；动作区按本册 D-LS-14 保留单个“立即登录”，不改为一组不可点业务按钮。真实登录/SSO 不在本模块，账号状态沿用底座演示能力，双角色评审使用独立工具。
- 费用确认只表达必要的业务确认，不代表费用确认/签名承载方已确定；Q-LS-02～06（签名承载、主体映射、正式编号登记、对外审核承诺、消息分类）保持原边界。执行超时沿用两自然日，不新增时限。
- 本次不改授信报价、放款、还款等后续页面，也不将其承载入口冒充已实现流程；不增加上架闸门、可调质押率、资产拆分、指定转出地址、延期、清算或平台代付。
- 资产广场保留独立样例数据，真实跨模块状态同步不属于离线原型；本次仅回归相邻页面能正常打开，不声称联调完成。
