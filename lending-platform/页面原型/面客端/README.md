**页面接入必读：** [面客工作区组件规范 §0：阅读顺序、样板版本、逐页继承](../_shared/design-system/面客工作区组件规范.md#0-必读入口顺序与样板版本) → [§5.1：内嵌布局与加载策略](../_shared/design-system/面客工作区组件规范.md#51-内嵌布局与数据加载必须分别决定) → [§8：浏览器验收](../_shared/design-system/面客工作区组件规范.md#8-响应式验收)。资产广场按已确认 PRD 使用全断点内嵌连续追加，每批20条；加载范围和位置随视图链接恢复。

## 2026-09-21 · 面客模块统一联通

既有 HTML 入口（账户、资产广场、借贷广场、我的控制台、消息中心，2026-09-24 起含企业账户）现在共享 `_shared/portal-entry.js` 的同一依赖清单。任一入口都可通过真实产品导航进入全部面客模块；默认进入资产广场，合法深链优先。源码与单文件导出加载同一组业务脚本，不再以 `sample-pages.js` 的示例页面替代业务模块。

借贷流程包含现有质押、授信报价、放款确认和还款计划；控制台六类对象读取同一演示数据并可跳回项目办理。消息跳转定位已有项目，保留返回原消息；账户菜单进入对应身份账户及同一消息中心，站内登录完成后恢复原业务页面。外部 SSO、钱包、真实签名、消息推送和服务端会话仍为既有模拟边界，未新增后台联调或业务规则。

依赖顺序、共享状态与钩子组合见 `_shared/portal-connect.js`；增删面客模块时更新唯一清单并回归全部入口。不要在个别 HTML 私增一套模块列表或恢复旧样板占位。
