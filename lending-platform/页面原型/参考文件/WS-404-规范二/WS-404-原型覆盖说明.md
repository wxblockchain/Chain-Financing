Stage 3 · **delta prototype / console** · WS-404 · 2026-10-14

已按用户“直接重构、直接输出、不逐步确认”的授权合并 Stage 1/2 评审并完成交互原型。交付以指定 Harbour Credit 附件为视觉口径；只重构本轮五个主体页及相关币种呈现，不宣称完整平台或生产交付。

## 打开与评审

下载 `harbour-markets-prototype.html` 后直接双击，用现代 Chrome / Edge / Firefox 打开。无需服务器、安装依赖或联网。入口为资产广场，顶栏切换借贷广场；列表点击或键盘 Enter 进入详情，面包屑返回。

默认英文、游客身份。顶栏语言菜单支持中文。右下角 **Demo tools / 演示工具** 默认收起，可切换游客、登录未绑定、资产方和资金方，定位页面与业务场景。“Interface feedback / 界面反馈”切换加载、空数据、筛选无结果、失败、权限反馈；“Advanced simulations / 高级模拟与外部事件”包含持有资料、提交失败、逐币执行与外部回写。

演示创建失败：切到资产方 → 创建融资项目 → 填写有效字段 → 打开高级模拟并勾选 Submission failure → 关闭工具后提交；失败保留输入，取消该开关后重试。该原生模拟开关本轮扩展至创建提交，沿用创建页原有错误处理，不新增业务规则。

HTML 中的企业、金额、地址、交易、利率及图表均为演示数据。离线运行不调用钱包、链、身份或业务服务。区块浏览器仅在主动点击外链时打开。

## 源文件与交付形式

维护形式为**共享源层 → 导出时内联**，两模块没有手抄一份 CSS：

- 原始业务 / 公共源来自上述仓库快照，保持原样。
- 本轮共享层在本地 `output/harbour-markets/source/`：`reference-token-map.css` 将参考映射到 canonical 名称；`market-components.css` 统一两模块组件；`market-design.js` 扩展现有 afterRender 并补创建失败模拟；`build.py` 调用原 `_shared/export.py` 后机械内联这些源文件。
- `harbour-markets-prototype.html` 为生成的评审件，不能作为第二份源层手改。
- 生成件包含相邻页面以维持已有跳转；这些页面未重构、未做完整验收。

本轮没有修改仓库文件、commit、push 或 PR。用户要求的是原型输出，目标入库分支尚未确认；未来正式集成应将已接受的改动适配到现有 token / 公共组件 / 模块路径，不能把评审 override 当作长期并存的第二套系统。
