本目录存放借贷平台的页面原型。原型底座与设计规范在 `_shared/` 之下，与模块原型同处本目录，不另开第三个子目录。

## 目录结构

```
页面原型/
  _shared/
    tokens.css                # 色板、字号阶梯、间距、圆角、控件高、动效、层级
    base.css                  # 四种整页骨架（site / portal / app / focus）与公共组件
    shell.js                  # i18n、路由、导航与面包屑、Toast、抽屉与弹窗宿主、演示工具
    registry.portal.js        # 面客端页面登记表与导航
    registry.admin.js         # 运营端页面登记表与导航
    export.py                 # 单文件评审件导出
    README.md                 # 接入顺序与模块接口
    design-system/            # 本平台自持的设计规范
    样板/底座样板.html          # 四种 shell 与状态表面的母版
  面客端/
    01-登录与账户体系/
    02-企业账户/
    03-资产广场/
    04-借贷广场/
    05-我的控制台/
    06-消息中心/
  运营端/
    01-账户与登录/
    02-融资参数配置/
    03-协议管理/
    04-项目合约管理/
    05-资金方机构认证审核/
    06-代币质押审核/
    07-消息通知/
```

端内目录按「登录 → 具体功能」排序，两位数前缀只表示端内次序，与 `lending-platform/PRD/` 的 `面客端/`、`运营端/` 同一分组与次序；序号不是业务标识，新增模块按业务位置插入、其后序号顺延。`_shared/` 是两端共用的底座，不参与端内编号。

面客端与运营端是两个独立部署单元，各自只加载自己那张登记表；两端共用同一份 token、组件规格与运行时，保留各自导航与业务布局；紧凑密度由筛选、分页等组件角色决定。接入方式见 [`_shared/README.md`](_shared/README.md)。

## 本地打开

- 双击任一模块目录下的 HTML 即可离线评审，无需本地服务；请保持 `页面原型/` 目录完整。
- 样式与运行时在 `_shared/` 下，**把单个 HTML 复制或下载到别处打不开**，页面会给出提示并说明该从哪里打开。
- 运营端各模块是独立文件，侧边栏跨模块跳转按整页加载：演示身份与临时状态会重新初始化，「总览／账户设置」按模块 README 的演示凭据重新登录。
- 需要单独发给他人评审时，用 `_shared/export.py` 导出自包含单文件，不把生成件放回仓库。
- 区块浏览器等外部链接指向站外，离线状态下打不开属正常。

## 从哪开始

新增或改造页面前先读 [`_shared/design-system/页面继承参考.md`](_shared/design-system/页面继承参考.md)，选定部署单元、shell 与 archetype，再做增量。母版是 [`_shared/样板/底座样板.html`](_shared/样板/底座样板.html) —— 它是底座样板，不是业务模块原型，字段集只是够用的样例。
