## 视觉调整

参考已有[借贷广场](../../面客端/04-借贷广场/借贷广场.js)与[资产广场](../../面客端/03-资产广场/资产广场.js)的 `.stat-strip`、`filterbar`、`CF.filterSelect`、`CF.filterSearch`。沿用运营端字体、语义字号和色彩，不复制面客端皮肤或即时多选交互。

- 模块标题、队列 / 台账切换同行，删去重复副标题。
- 两项统计无框、无卡片底色，失败数仍从属待审核；完整统计口径按需展开。UTC直接标于统计及日期标签，计算口径不变。
- 审核轴、排序、更多筛选、搜索、重置、查询合成单行工具条；仅更多筛选展开时占下一行。筛选仍由查询提交，排序仍即时切换，各列表独立保留上下文。
- 审核栏和办理弹窗统一「退回 / Return」，原因标签指向申请方。填写、全文核对、二次确认和提交原样保留。
- 精简重复提示和费用承担说明，保留实际gas、失败原因、权限 / 状态限制、参考币种含义与签名前关键后果确认。
- **v3详情头部**：面包屑收紧间距，桌面返回链接保留32px目标高度；项目编号24px、项目名称14px并排且允许长文本换行。审核轴、部署执行状态、本次提交、面客项目状态改为无框 `dl / dt / dd` 字段条，取消白底卡片、外边框及纵向分隔；保留审核人、结论时间、提交序次与时间、关闭原因等条件信息。≤1200px两列、≤700px单列沿用原缩窄方式，不删字段。

Chromium实测默认队列表头距视口顶部：1440px中英从约586px降至292px；1280px中文583px→290px，英文602px→290px；1920px同1440px。六个组合的主筛选条均53px高。测量包含共享壳层，不计展开更多筛选。

v2核验记录：源码与共享导出器生成的离线单文件，Chromium，中英双语、1280 / 1440 / 1920px的213个呈现与关键路径检查通过；另完成9组排序 / 查询 / 返回 / 日期校验、签名异常、退回提交、实际gas与失败事实保留、共享默认展示补测。无文档横向溢出、脚本异常或外部请求；宽表仍在容器内横滚，固定操作列、焦点及弹窗关闭返回可用。截图仅用于内部核验。

v3本轮核验：同样的中英三档桌面宽度，源码与离线件共144个详情呈现组合（12个已有示例项目 × 3宽度 × 2语言 × 2载体），另查队列 / 台账两种来源的面包屑返回保留筛选，以及长项目名称与125%放大，共146项通过。逐项目与v2比对全部可见文字（固定演示时钟），没有字段或条件信息丢失；摘要无卡框，字段无横向裁切，无文档横向溢出、脚本报错或外部请求。处理中、待核实、关闭项目的原操作禁用条件保持有效。办理和钱包处理代码未改，沿用v2结果，本轮未重新联调。

v3默认失败示例（DEMO-FP-002）的创建信息主区距视口顶部：1440 / 1920px中英以及1280px英文，约379px→275px，减少104px；1280px中文399px→275px，减少123px。以上来自浏览器实际DOM尺寸。

均为本地模拟；未接入真实鉴权、钱包、链上或消息服务，未验证真机、Safari / Firefox、屏幕阅读器和全量业务AC。本轮未扩展为移动端完整设计。

## 运行与维护

附件HTML可双击离线打开，默认英文进入队列，顶栏可切中文；右下角评审工具默认关闭。源码保持完整的 `页面原型/` 并打开本目录HTML。模块样式唯一来源为 `项目合约管理.css`，已同步[运营端组件规范](../../_shared/design-system/运营端组件规范.md)。

共享钱包 `start({showGasNotice:false})` 只省略费用说明，默认展示；不改变签名校验、状态或费用规则。仅本模块显式关闭。

从 `lending-platform/页面原型/` 导出，不手改生成件：

```bash
python3 _shared/export.py --source 运营端/04-项目合约管理/项目合约管理.html --output /tmp/项目合约管理-UI调整-v3.html
```

沿用已有授权直接推送 `cly-4.0.0`，不强推、不新开PR。实际提交见交付评论。
