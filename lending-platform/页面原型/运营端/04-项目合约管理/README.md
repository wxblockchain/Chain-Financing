## 页面组合

**项目审核队列。** 一行一个融资项目，退回重提仍是同一行。列：项目编号 / 名称、项目发布方 / 代币类型 · 区块链网络、项目质押率 / 项目期限、本次提交时间、已等待时长、审核轴、配置执行状态 / 质押合约地址、查看。默认待审核、按提交时间升序。审核轴、排序、关键词常驻；配置执行状态、项目发布方、代币类型、区块链网络、提交时间在「更多筛选」。关键词可用任一合约地址检索，列出配置在这份合约上的全部项目。统计：待审核（其中配置失败待再次发起）、近 7 个自然日人工审结。

**项目审核详情。** 摘要为审核轴、配置执行状态、本次提交、面客项目状态。主区依次为创建信息核对、项目发布方与参数上下文、合约区块、操作记录；右侧为审核处理。合约区块随状态变化：

- 待审核：适用的共用合约——适用组合（可进台账对应一套）、已配置项目数、三份合约地址；缺任一类标「暂无」并说明本项目暂不能通过。
- 配置处理中 / 配置失败 / 结果待核实：最近一次配置——三份所选合约、各自执行结果、配置交易凭证；失败时附失败原因与失败时点。
- 已通过：所配置的合约——适用组合、合约配置完成时间、三份地址与凭证。

**办理。** 通过与再次发起：逐类选定质押、放款、还款合约（候选只有本组合在用的那份）→ 勾选「配置成功即审核通过，不可撤销」→ 确认提交，不连接钱包、不签名。缺合约或稳定主体标识待核实时「通过」不可用，审核处理区写明原因，可退回。退回：10～500 字原因 → 全文核对 → 确认。

**共用合约台账。** 一行一套合约：代币类型 / 区块链网络、质押合约、放款合约、还款合约、已配置项目数、查看项目。「查看项目」在表下展开这套合约上配置成功的项目，可按合约配置完成时间升降序，进入详情后返回仍保留展开与筛选。台账只读，没有登记、编辑、停用或更换入口。

**状态。** 配置处理中不显示「已通过」、不可处置，资产方关闭被拒；三份都成功才变为已通过；任一份失败即配置失败、回到待审核；结果待核实时不可处置。已关闭项目标关闭原因、离开默认视图、只读。
