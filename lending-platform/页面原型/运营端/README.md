# 借贷平台 · 运营管理平台原型

**当前视觉（2026-10-20）：** 七个模块与面客端共用蓝白色板、Geist / Noto Sans SC、语义字号与同级控件规格；app 侧栏、表格 / 审核流程及权限沿用模块。现行规则见[共享规范](../_shared/design-system/共享组件视觉规范.md)与[运营规范](../_shared/design-system/运营端组件规范.md)，筛选组合与本轮覆盖见下文。

**2026-10-16 · WS-381 详情字段统一：** 账户资料（单列原位操作）、融资参数、协议定义与版本、项目合约、机构认证、代币质押的只读详情已接入共享 `.ops-facts-*`。标签与取值同行、轻实线分隔，按内容容器宽度切换单双列；源码唯一来源为 `../_shared/base.css`，规范、使用示例与适配 / 例外清单见[运营端组件规范 §4.1](../_shared/design-system/运营端组件规范.md#41-管理端详情字段行2026-10-16ws-381)。消息正文、记录表、时间线、表单与办理弹层保留各自结构；没有统一替换业务流程。

标准管理平台部署单元，本期只有运营管理员一个角色；SPV 职责按已确认功能权限表达。每个模块一个目录，模块内只放自己的页面 HTML、模块 JS、文案、演示数据与状态。

- 公共层（token / 组件 / 骨架 / 运行时 / 登记表 / 设计规范）：[`../_shared/`](../_shared/README.md)

- 继承母版与 archetype：[`../_shared/design-system/页面继承参考.md`](../_shared/design-system/页面继承参考.md)

## 2026-10-20｜WS-397 运营筛选补齐

交付类型为现有系统适配（`existing-system adaptation / console`），以 `cly-4.0.0` 的 `0aa31cb` 及其运营端附件为对照。上一轮机构认证、融资参数仍为上下标签栅格，协议自定义控件也未完整继承轻量规格；本次修正实际源页后重新导出全部运营模块。

| 运营管理员 × 页面 | 本次变化与覆盖 |
| --- | --- |
| 机构认证审核列表 | 修改且实测：状态标签 / 取值同排，搜索保留完整可访问名称，提交起止日期合为一组；1440px 筛选区由85px减为53px（含分隔线） |
| 融资参数列表 | 修改且实测：配置状态、关键词及查询 / 重置同排，取消上下标签栅格及铺满的大输入；1440px筛选区由85px减为53px（含分隔线） |
| 协议管理列表 | 修改且实测：状态多选、更多筛选、关键词和操作统一轻量外观；高级条件标签和值同排，勾选数量 / 颜色同步，菜单视口约束及 Escape 返回焦点 |
| 项目审核队列 / 质押合约台账 | 修改且实测：常用条件显示标签 / 取值，保留原排序入口，更多筛选轻量化，高级条件取消固定多列栅格、自然换行 |
| 代币质押审核队列 | 修改且实测：同项目审核；结论来源、去向、并列提示、资产方 / 项目 / 类型及 UTC 日期全部保留在原高级条件内 |
| 消息通知 | 继承未改、入口和筛选冒烟：仍为阅读状态下划线及分类下拉，不引入查询 / 重置表单 |
| 登录、详情、维护和审核 / 钱包操作 | 继承未改，非本次筛选视觉修订范围 |

实现统一在共享 `.ops-filterbar / .ops-filter-select / .ops-filter-fields`，规则见[运营规范 §4.2](../_shared/design-system/运营端组件规范.md#42-运营清单的轻量筛选2026-10-20ws-397)。各字段 ID、选项、默认值、查询 / 重置、日期校验、排序、分页、权限和路由保存继续由原模块负责。

核验使用 Chromium 的自包含离线附件：中英文、1440 / 1280 / 1024 / 768 / 390 / 320px，默认与已有高级条件展开、协议多选菜单、键盘焦点 / Escape、触屏44px规格；与旧附件对照字段及选项、默认结果、输入未查询、查询无匹配、重置与错误日期结果。这里只验证本地原型，不代表真实接口、链上及全部业务 AC 联验。

从原型根目录生成一份包含全部运营模块、离线字体及导航的附件，双击即可审阅：

```bash
python3 _shared/export.py --source 运营端/05-资金方机构认证审核/资金方机构认证审核.html --output ../../../WS-397-运营端筛选补齐-20261020.html
```
