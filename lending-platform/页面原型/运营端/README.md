# 借贷平台 · 运营管理平台原型

**2026-10-15 · WS-403 当前视觉：** 本端七个模块与面客端共用蓝白色板、Geist / Noto Sans SC、语义字号与同级控件规格。保留 app 侧栏、原表格 / 审核流程与权限；审核操作区采用统一主色强调。详见 [全平台视觉统一](../_shared/design-system/WS-403-全平台视觉统一.md)。

**2026-10-16 · WS-381 详情字段统一：** 账户资料（单列原位操作）、融资参数、协议定义与版本、项目合约、机构认证、代币质押的只读详情已接入共享 `.ops-facts-*`。标签与取值同行、轻实线分隔，按内容容器宽度切换单双列；源码唯一来源为 `../_shared/base.css`，规范、使用示例与适配 / 例外清单见[运营端组件规范 §4.1](../_shared/design-system/运营端组件规范.md#41-管理端详情字段行2026-10-16ws-381)。消息正文、记录表、时间线、表单与办理弹层保留各自结构；没有统一替换业务流程。

标准管理平台部署单元，覆盖运营管理员与 SPV 机构。每个模块一个目录，模块内只放自己的页面 HTML、模块 JS、文案、演示数据与状态。

- 公共层（token / 组件 / 骨架 / 运行时 / 登记表 / 设计规范）：[`../_shared/`](../_shared/README.md)
- 本端登记表：[`../_shared/registry.admin.js`](../_shared/registry.admin.js)
- 继承母版与 archetype：[`../_shared/design-system/页面继承参考.md`](../_shared/design-system/页面继承参考.md)

## 模块目录（登录 → 平台配置 → 日常审核 → 消息）

| 序号 | 模块 | 覆盖内容 |
| --- | --- | --- |
| 01 | [账户与登录](01-账户与登录/README.md) | 本期单一角色运营管理员，权限一致；SPV 职责通过功能权限表达 |
| 02 | [融资参数配置](02-融资参数配置/README.md) | 按代币类型维护最高质押率与最长项目期限（WS-388） |
| 03 | [协议管理](03-协议管理/README.md) | 协议版本、生效与归档，运营人员按功能权限使用（WS-361） |
| 04 | [项目合约管理](04-项目合约管理/README.md) | 项目审核与合约部署合为一步，含质押合约台账（WS-387） |
| 05 | [资金方机构认证审核](05-资金方机构认证审核/README.md) | 机构资料认证的查询、通过与驳回 |
| 06 | [代币质押审核](06-代币质押审核/README.md) | 逐笔质押的查询与处置（WS-382） |
| 07 | [消息通知](07-消息通知/README.md) | 复用账户宿主与消息阅读组件（WS-360） |

两位数前缀只表示端内次序，与 `PRD/运营端/` 同序；序号不是业务标识。代币域页面（`P-O-TC-*` / `P-O-TI-*` / `P-O-FX-*` / `P-O-DS-*`）已移交代币发行平台，不在本端范围内。
