# 代币质押审核 · UI 视觉深化

`existing-system adaptation · console`，WS-387，2026-10-16。基于远端 `cly-4.0.0` 的 `fb81829`，包含功能修订 `cbf9d7e`、`232a198`；视觉延续项目合约管理 `3410026`、`ba368fb`。业务字段、权限、状态、校验、计数与钱包签名流程继承基线。

## 视觉落地

- **审核队列**：沿用面客端 `stat-strip`，三项统计无框、无底色，数字与「张」同行。统计口径集中在可展开说明中，含待审处理分支、终态默认驳回、人工审结与筛选范围；计数公式不变。
- **筛选**：审核状态、排序、更多筛选、搜索与查询集中在一行，默认不显示重复字段标题。扩展字段与并列提示完整保留；UTC 标于日期标签。队列表格内滚动、操作列固定于右侧，不挤掉业务列。
- **详情**：面包屑、单笔标识与代币编号紧凑排列；审核状态／份额价值／本笔当前去向用无框三列摘要。通过处理中、结果待核实、结论来源仍就地显示。事实区复用共享 `ops-facts-body` 行式组件，审核栏沿用项目合约管理的主色边界。
- **办理**：760px 弹窗、只读事实与行分隔、知悉勾选浅蓝底与键盘焦点环；完整保留上传、备注、原因、归类、校验、全文确认、草稿放弃与钱包流程。
- **规范与源码**：局部样式从 HTML 抽至 `代币质押审核.css`，继承共享 token；不新增全局覆盖。共享规范 §10、§16 与本次实现同步。
