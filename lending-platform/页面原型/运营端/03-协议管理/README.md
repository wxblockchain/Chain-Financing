## 当前交互精简（2026-10-20）

WS-384 · existing-system adaptation / console · 已确认方向内的修订。用户反馈“逻辑交互做的太重了，进行简化”。基线为 `cly-4.0.0` 的 `11393053ff50e1314fd016367445c1592c80766b`，需求取同一提交的四册。本轮只精简交互，`2040d9c` 的列表工具条、详情字段行和视觉组合原样保留。本节与下文各轮记录冲突时，以本节为准。

- **二次确认只留三处**：立即生效（草稿立即发布、待生效改为立即生效）、撤销待生效、丢弃草稿。立即生效弹层只列协议、版本和文件名，已有生效版本时提示“将被立即替换并归档”。撤销弹层列协议、版本和原计划时间，丢弃弹层列协议和版本。删除确认里的生效方式、时间、需重新同意标记和修改前后对照。
- **定时直接提交**：保存草稿、定时发布、待生效调整后仍为定时，点主按钮直接提交，按钮显示“提交中…”。成功后回到基本信息，提示计划生效时间，变化记入操作进度。校验和提交失败在办理页就地展示，输入保留。“确认更新”仍是待生效版本的提交按钮，没有改动时不可用。
- **权限不再分出办理模式**：删除“当前权限下内容只读”和“需具备发布权限才能确认更新”两条提示。缺维护权限时字段不可编辑，缺发布权限时发布、确认更新和撤销不可用，其余照常。缺维护权限且没有草稿或待生效版本时，不提供“更新协议”入口，也不再提示“暂无可发布内容”。
- **删除草稿冲突**：去掉撤销时的草稿冲突提示和阻断、发布时的“已有待生效版本”拦截，以及演示工具里的“模拟已有草稿冲突”。
- **版本详情**：删除最近草稿保存、保存人、首次发布时间、首次发布人、最近确认调整、调整操作人六行。卡头改为“保存、发布与调整人员及时间见操作进度”，点击后回到基本信息并定位到操作进度。没有记录权限时不显示这个入口。
- **未裁定项保持现状**：`Q-O-AG-08`～`11` 未裁定，相关内容不变：更新协议和版本详情里的需重新同意标记、操作进度变更对照里的该项（确认弹层按 PRD 7.1 不再展示），操作进度里调整前、确认后文件的查看和下载，撤销告警，以及九列台账、全部筛选、排序和每页条数。

### 当前组合

- **列表**：主工具条复用 `.filterbar`，常驻协议状态（原多选）、更多筛选、关键词、重置与查询。类型、适用环节及更新日期保留在页内展开区；查询后的全部条件常驻回显，折叠不会清除条件或输入。选择仍由查询提交，原排序、分页、URL 与返回恢复不变。紧凑控件 36px、筛选文字 12px，取共享语义角色；页头演示标识置于操作区。
- **台账**：保留九列及固定操作列，取消上轮 1120px 最小宽度与滚动提示；1280 / 1440 / 1920 常规宽度按画布分配列宽。日期、时区、当前及待生效版本与状态文字均保留，长表头换行。表格正文、辅助文字、状态标记与行垂直对齐继承共享组件。
- **基本信息**：保留定义与操作进度两组，取消上轮单独前置的版本卡。当前生效 / 待生效 / 草稿的原查看入口并回定义卡底部，以共享 `.ops-facts-region` / `.ops-facts` 字段行表达，待生效时间仍可见；无相应版本时不新增占位事实。历史视图与权限保留。
- **更新协议**：恢复“协议文件 / 发布设置”两张普通卡，变更说明回到发布设置内，取消额外的变更说明卡与蓝色设置卡边界 / 标题。沿用文件行、原生字段、前置必填标识、计数、就地错误、底部操作与共享确认弹层。空上传、已有文件、只读、禁用与提交状态按原业务条件呈现。
- **版本详情**：取消上轮额外四组小标题，回到单一连续的共享字段行；完整保留原字段顺序、已取消版本条件字段、跨行完整指纹、复制、预览与下载。协议文件继续为独立内容区。
- **保留的修正**：筛选已选数量即时反馈、警告接入共享 warn 语义、危险最终确认、上传容器与子按钮的键盘事件隔离、弹层焦点保护保留；不回退功能、权限或校验。

## 本轮变化（2026-10-19）

- 本模块演示工具只呈现运营管理员，移除专员 / 后期角色切换；正常交付五项协议权限全部开通，账户菜单沿用共享账户模块的真实邮箱与“运营管理员”。

- 双击评审 HTML 默认进入协议列表；源码入口为 `协议管理.html`。列表“查看”→基本信息 / 版本历史；基本信息“更新协议”按当前版本打开办理；历史“查看”进入只读版本详情。
- 服务协议样本包含生效 v2 与待生效 v3，适合核验同版本调整；告知书可演示空草稿与发布校验；申请模板从空白首版开始；历史服务协议保留已归档 / 已取消样本。
- “演示工具”→“更多模拟”提供配置异常、会话失效、下一次请求故障、并发与定时结果。它们是本浏览器模拟，不能作为生产能力交付。
- UI 可继续优化列宽、分组、比例与节奏。保留共享详情字段行基线、状态文字、独立读写权限、同号待生效调整、发布前关键后果与未提交保护；不得重新加入来源版本或专员身份。需重新同意标记裁定前保留在更新协议、版本详情与操作进度变更对照中；二次确认只留立即生效、撤销待生效、丢弃草稿三处。
