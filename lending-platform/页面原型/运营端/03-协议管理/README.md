## 本轮变化（2026-10-19）

- 本模块演示工具只呈现运营管理员，移除专员 / 后期角色切换；正常交付五项协议权限全部开通，账户菜单沿用共享账户模块的真实邮箱与“运营管理员”。
- 五项权限仍由 `CF.opsAuth` 一处判定。高级模拟中的开关明确标为“交付配置核验”，可验证只查询、维护 / 发布的配套条件及独立的历史 / 记录读取，不再把异常配置当成本期角色。提供“恢复正常交付配置”和“模拟缺配套查询”。开关显示原始交付值，缺查询时维护 / 发布即使已开通也不能执行。
- 协议列表要求当前内容查询：无权时隐藏共享导航入口，直接访问给通用拒绝与返回账户，不混入“暂无协议”“筛选无结果”或加载失败。维护 / 发布缺配套查询时保留“请联系平台建设方修正交付配置”的说明。不再提供仅记录账号专用台账；记录在基本信息内仍按独立的 PM-AL-16 判定，保留现行四册 AC-O-AG-57 的配置核验边界。
- 删除版本详情的“来源版本”、办理页对应链接及新演示版本的无来源字段；旧浏览器数据残留该字段也不再呈现。
- `Q-O-AG-08` 尚未裁定：更新协议、发布确认、确认更新、版本详情继续保留需重新同意标记；不触发面客同意、弹窗或通知。
- 保留默认关闭的共享演示条，页面反馈在演示条切换，高级模拟不再重复页面状态选择器。页面标识演示数据。
- 修复英文窄列表表头覆盖相邻列的问题，调整本模块台账与操作进度的列宽和表头换行，保留九列、固定操作列与共享字号。

## UI 交接与到达方式

- 双击评审 HTML 默认进入协议列表；源码入口为 `协议管理.html`。列表“查看”→基本信息 / 版本历史；基本信息“更新协议”按当前版本打开办理；历史“查看”进入只读版本详情。
- 服务协议样本包含生效 v2 与待生效 v3，适合核验同版本调整；告知书可演示空草稿与发布校验；申请模板从空白首版开始；历史服务协议保留已归档 / 已取消样本。
- “演示工具”→“更多模拟”提供配置异常、会话失效、下一次请求故障、并发与定时结果。它们是本浏览器模拟，不能作为生产能力交付。
- UI 可继续优化列宽、分组、比例与节奏。保留共享详情字段行基线、状态文字、独立读写权限、同号待生效调整、发布前关键后果与未提交保护；不得重新加入来源版本或专员身份。需重新同意标记裁定前仍须保留四处。

## 核验与限制

2026-10-19 使用 Chromium 实测维护源与导出的离线评审件。四页 × 中英 × 1280 / 1440 / 1920 共 24 组布局检查无页面横向溢出、表头文字越界；台账操作列可达；检查详情字段行保留。核心办理、权限与会话范围见上表。离线评审件实际跨模块打开三类协议告警的既有目标并后退返回原消息，无远程请求或脚本异常。另执行 JS 语法与 `git diff --check`；截图只作内部核验，不交付。

演示数据、账号、文件与异步结果均为模拟。定时由本地页面计时器驱动，关闭页面后不执行；未验证真实服务的到点 5 分钟判定 / 6 分钟通知可见目标、性能、永久留存与平台隔离。文件前端校验不能替代服务端解析和安全检查。内置 PDF 提供安全文本预览；未接完整 PDF 排版器。未测其他浏览器、读屏器或 1280 以下宽度。

真实协议定义、允许格式与大小等资料仍待建设方提供（Q-O-AG-05），PDF / 5 MB 等只为演示值。需重新同意标记等待 Q-O-AG-08 裁定，当前保留不阻塞本轮。

本期不新增协议定义维护 / 下线动作、在线正文编辑、多语种文件、历史恢复、手动归档、审批复核、面客同意、邮件短信推送或跨平台管理。
