# 运营端协议管理原型

## 操作进度对齐代币准入审核（2026-10-23 · 当前）

本轮为 delta prototype / console，仅调整运营管理员的协议详情“操作进度”。按用户最新评论，将原先参照项目合约管理的呈现改为与 `06-代币准入审核` 的操作记录统一；本节取代下方历史视觉记录中关于结果标签、三列元信息与折叠详情的布局约定。参考与实现基线为 `cly-v5.0.0 / cedb9f4`。

- **相同骨架**：分区内缩标题与分隔线、单条倒序时间线、9px 语义节点、20px 左缩进与24px 节点间距；操作名称14px、元信息12px、结果13px，均引用共享 token。
- **相同阅读顺序**：操作名称 → 操作人 / 时间 → 结果文字 → 直接可读的浅底明细。关联版本追加在元信息行。取消“查看详情”的展开步骤，结果不再使用与标题并排的状态徽章。
- **协议专有信息保留**：变更摘要、状态变化、变更说明、失败原因、来源地区及覆盖前后对照均直接展示；没有删除记录字段、排序、去重、“待核实”、权限、空态、加载失败重试及每页20条分页。
- **范围**：仅本模块 HTML、JS、README；代币准入审核与 `_shared/` 均未改。基本信息、版本历史、上传及撤销流程继承不变。本次沿用本 issue 已有入库授权，直接推送到 `cly-v5.0.0`。

覆盖矩阵：协议详情操作进度的默认、失败记录、覆盖对照、长说明、缺操作人 / 时间、重复记录、分页及加载 / 空态 / 失败重试 / 无权限为本轮修改与核验范围；基本信息和版本历史只核对数据保真，上传流程仅回归用于产生覆盖记录。列表、消息与真实服务不在本轮验收范围。核验结果见下节“本轮操作进度核验”。

## 页面与交互（2026-10-21）

existing-system adaptation / console。端 / 角色：运营端 · 运营管理员（本期五项协议权限全部开通）。

| 信息域 | 承载 | 内容 |
| --- | --- | --- |
| P-O-AG-01 协议列表 | 页面 | 六项核心信息 + 查看；协议状态多选与关键词检索；固定每页 20 条；本轮未改 |
| P-O-AG-02 协议详情 | 页面 | 自上而下：基本信息 → 版本历史 → 操作进度。页头动作：撤销待生效（有待生效版本且具发布权限）、更新协议（具上传权限）；协议已下线时两项都不提供，并提示已下线 |
| P-O-AG-03 更新协议 | 协议详情上的上传弹窗 | 只有协议文件（必填）与变更说明（选填，≤500 字），并给出本协议的格式与大小要求；上传直接提交 |

- **基本信息**：只有协议名称、协议类型、适用业务环节、协议用途说明四项，全部只读；未填用途说明显示“—”。协议标识、格式与大小、上线状态、排序值及版本信息不在此展示。
- **版本历史**：按版本号从新到旧列出版本号、状态（生效失败附加提示）、生效时间（待生效标“计划”，已取消为“—”）、协议文件名、变更说明与下载；当前生效的一行有底色。除下载外没有其他动作，没有版本详情和在线预览。缺协议历史版本读取权限时只列已生效与待生效版本，并提示其余版本需相应权限。
- **操作进度**：与代币准入审核的操作记录同一形态——一条从新到旧的时间线，每条依次显示操作类型、操作人 / 操作时间 / 关联版本、结果文字；变更摘要、状态变化、变更说明、失败原因、来源地区直接展示，覆盖上传另附文件名与说明的前后对照。操作人或时间缺失时标“待核实”，同一事件重复到达只显示一条；超过 20 条时分页。
- **撤销待生效**：从协议详情页头发起，二次确认显示协议名称、版本号、原生效时间与后果。
- **离开保护**：弹窗中已选文件或已填说明时，Esc、关闭、取消或浏览器后退都会先确认；取消确认回到弹窗，内容保留。
- **旧地址兼容**：原 `/ops/agreements/edit` 与 `/ops/agreements/version` 地址（含共享消息样本中的告警目标）统一落到协议详情：前者自动打开上传弹窗，后者在版本历史中标出所指版本；该版本此后已归档、已取消或已不存在时，在版本历史上方说明变化。

## 到达方式

- 源码入口 `协议管理.html`，默认进入协议列表；列表“查看”进入协议详情。
- 演示样本：服务协议（已归档 / 已生效 / 生效失败的待生效）、隐私政策（仅已生效）、首版协议（仅待生效）、申请模板（无版本、无用途说明、PDF/TXT 2 MB）、告知书（已生效 + 待生效）、历史服务协议（已下线，已归档 + 已取消）。
- “演示工具”默认关闭，提供：交付配置异常（逐项开关五项权限、缺配套查询）、会话失效、版本历史与操作进度的加载中 / 无记录 / 失败、操作进度异常记录样本、下次提交失败、下次下载失败、他人先上传、24:00 生效成功 / 失败、47 条分页样本与重置。这些都是本浏览器模拟。

## 源码与共享依赖

维护源为本目录 `协议管理.html`（模块样式）、`协议管理.js`、`演示数据.js`；复用 `_shared/` 的 tokens、base、shell、registry、admin-menu、消息数据与铃铛、文件行、拼图，以及 `../01-账户与登录/` 的会话能力。本轮未修改 `_shared/` 与其他模块。

- 操作进度时间线的样式按 `06-代币准入审核` 的 `.ta-section` / `.ta-timeline` / `.ta-event` 取值在本模块以 `ag-` 前缀实现，未跨模块引用样式文件。标题、元信息、结果、明细面使用相同字号及间距；协议明细继续用有标签的字段行承载自身审计字段。
- 共享消息样本（`_shared/admin-message-data.js`）中“生效成功”告警仍指向旧版本详情地址，本模块已将其落到协议详情；共享层后续可直接改为协议详情地址（附版本号）。

## 保留约束

UI 可调整分组、比例、列宽、时间线与弹窗的视觉表现。须保留：详情三段顺序（版本历史在操作进度上方）、基本信息仅四项、弹窗仅文件与说明两项及格式 / 大小要求、版本历史仅下载、撤销在协议详情且需二次确认、上传直接提交、状态文字（不只靠颜色）、五项权限分别判定、“待核实”与去重规则、离开保护。不得重新加入版本详情、在线预览、文件内容指纹、生效时间选择、草稿或需重新同意标记。
