## 打开与源码

直接打开 `融资参数配置.html`，默认英文，可切中文。沿用当前 app 壳层、运营端统一导航、`tokens.css`、`base.css`、`shell.js`、`registry.admin.js`、公共详情字段行、公共可排序列头、共享弹层、状态表面与导出器；不新增第二套 token，不自建菜单或账户组件。

- `融资参数配置.html`：模块入口与共享壳层；列表、详情、维护弹窗由交互脚本渲染。
- `融资参数配置.css`：模块组合与响应式；引用共享 token，不新增色板或字体。
- `融资参数配置.js`：列表与检索、参数详情与变更记录、维护弹窗与保存确认、结果反馈。
- `演示数据.js`：本地示例组合、参数取值与变更记录。
- 路由：`P-O-FC-01` `/ops/financing-parameters`、`P-O-FC-02` `/ops/financing-parameters/detail?id=…`。`P-O-FC-03` 参数维护是弹窗，不占路由；保存确认（`C-O-FC-01`）是同一弹窗的第二步。

单文件评审件由现行导出器生成，生成件不回存源码目录：

```bash
python3 _shared/export.py --source 运营端/02-融资参数配置/融资参数配置.html --output ../借贷平台-运营端融资参数配置-页面原型.html
```

## 页面组合

**一个侧栏条目「融资参数配置」，列表 → 详情两层，维护在弹窗中办理。** 列表是模块落地页，不展示面包屑；详情沿父级链展示面包屑，返回时保留原筛选、排序、分页与所在位置。

**融资参数列表。** 一行一个组合，六列：区块链网络（网络名称，下附链 ID）、代币类型、最高质押率、最长项目期限、配置状态、操作。同一代币类型在不同链 ID 上是两行。最高质押率按两位小数呈现（如 `70.00%`）；未配置行两项参数为「—」，行首警示色竖条。存在未配置组合时，表格上方提示「有 N 个组合尚未配置，暂不可用于创建融资项目」，并可一键「只看未配置」。筛选为区块链网络、配置状态与代币类型关键词（忽略大小写与前后空格），查询与重置成对；默认先按网络、再按代币类型升序，代币类型列可升降序；每页 20 / 50 / 100 并入分页条。条件、排序与页码写进地址。操作列为「查看」与「维护／配置」，后者直接打开维护弹窗。三种空结果分别表达：还没有组合（说明组合随代币准入审核通过产生，不给新增入口）、筛选无匹配（给重置）、读取失败（可重试）。

**参数详情。** 先当前参数后参数变更记录。当前参数五项：区块链网络（含链 ID）、代币类型、最高质押率、最长项目期限、配置状态；卡头为「维护参数」（未配置为「配置参数」）。未配置时页面顶部给出一句后果提示。变更记录五列：发生时间（带时区）、操作人（脱敏）、最高质押率、最长项目期限、本次结果；倒序、默认 20 条可加载更多；首次配置记为从「—」到新值，未变的一项标「未变」；刚保存的一条标「本次保存」。尚无记录、加载中、读取失败与登录失效分别表达。

**维护弹窗。** 从列表行或详情打开。顶部只读字段行回显区块链网络与代币类型，下方两项并排：最高质押率（带「%」后缀，失焦即校验，为空 / 非数字 / 不大于 0 / 超过 100% / 小数超两位各有说明并附允许范围，边界值不报错，不替用户取整）与最长项目期限（3～12 个月下拉）。未配置时两项为空。改动按取值比较（`70` 与 `70.00` 视为未改），改过的项标「已修改」，未改动时保存不可用。保存进入同一弹窗的确认步骤：回显区块链网络、代币类型与两项变更前后，并写明「仅对此后新建项目生效，不改变存量项目」，首次配置另写「保存后即可用于创建融资项目」；「返回修改」保留输入。保存成功后关闭弹窗、留在原页面，列表行或详情与变更记录随即刷新并提示已保存。提交中禁用并防重；失败保留输入；结果未知与他人先行修改在弹窗内给「重新取数」（有未提交内容先确认）；提交时登录失效则拒绝保存并转登录。关闭按钮、Esc、遮罩与取消：确认步骤先回到表单，有未提交内容先确认放弃。

**不承载。** 无新增、删除、改名组合或修改网络 / 代币类型的入口；无草稿、定时生效、发布、回滚与历史值恢复；无存量项目清单与整改；无利率、费率、额度等其他参数；无逐笔质押、项目或代币跳转；无文件上传下载；不发任何消息。

## 会话与功能权限

会话与功能权限只读运营端账户与登录的一处登记（`CF.opsAuth` + `CF.deferOpsBoot`），模块不维护权限假数据。本期运营端只有运营管理员一个角色，`PM-AL-19` 融资参数查询、`PM-AL-20` 融资参数维护全部开通。交付配置异常（只开通维护、无本模块权限项）与仅查询的表现只在默认关闭的演示工具中切换。登录失效走共享运营登录页，重新登录后回到原来的列表或详情。

## 演示工具

右下角演示工具默认关闭，与产品画面分离。可切交付的账号配置、页面状态（默认 / 加载中 / 还没有组合 / 读取失败）、变更记录状态、保存反馈（成功 / 失败 / 结果未知 / 他人先行修改 / 提交时登录失效）；可模拟「代币准入通过 · 产生新组合」（以未配置出现）、运营登录失效与重置演示。演示条「参数详情」页另有「未配置」与「维护弹窗」两个业务状态可直达。

演示数据（以太坊 / 以太坊 Sepolia / BNB Smart Chain + ERC-3525-应收账款，以及参数与记录）均为浏览器本地虚构数据，刷新重置；真实配置读写、组合产生时机与权限登记仍需实机联验。企业端创建融资项目的可选与提示归融资需求与代币质押，不在本模块原型内。

## 2026-10-21 · WS-453 UI 深化

承接 Hallmark 附件补丁（基于 `e0e7329`），保留共享蓝白视觉、字体、壳层及业务行为。列表以网络主名称 / 链 ID 分层，代币类型用中等字重，参数数值右对齐；未配置横条删除重复状态标签，保留数量、后果与筛选入口。分页总数与每页条数在左侧成组，翻页在右。桌面筛选按可用空间分配四列，窄屏自然换行。

列表表格阅读下限 1000px、变更记录 840px，仅表格容器横滚；操作列固定在右侧，操作目标至少 36px，触屏 44px。详情使用共享五项字段行，容器可收缩，避免记录表撑宽详情而遮住维护按钮。记录时刻复用 `CF.fmtStamp`（当前时区换算、分钟精度），时区仅在表头标注，保留 `<time datetime>`。弹窗以只读字段行核对组合，两项输入与变更对照在桌面并排、≤600px 纵排；范围、错误和生效后果保留。
