# 代币准入审核原型

WS-439 · `existing-system adaptation / console` · 运营端 · 运营管理员。业务输入为 [PRD 06-代币准入审核](../../../PRD/运营端/06-代币准入审核/01-代币准入审核-PRD.md)（`cly-v5.0.0` · `d00ed39`，含平台代币标识）。

## 页面与入口

| 页面 | 路由 | 承载 |
| --- | --- | --- |
| 准入审核清单 `P-O-TA-01` | `#/ops/token-admissions` | 两项统计、紧凑筛选（准入状态常驻，其余在“更多筛选”）、高密度表格（首列平台代币标识 / 代币编号 / 代币名称）、排序与带总数分页；关键词可按平台代币标识搜索；清单只查看，进入详情办理 |
| 审核详情 `P-O-TA-02` | `#/ops/token-admissions/detail?id=…` | 页头为平台代币标识与代币名称；左侧依次为审核概况（平台代币标识与代币编号可复制，重复提醒给出对方的平台代币标识）、代币基本信息、底层资产信息、法律协议文件、操作记录；右侧粘性审核栏为平台代币标识、代币编号、准入状态与提交序次、不能通过的原因、通过 / 退回 |

侧栏条目“代币准入审核”位于机构认证审核与项目合约管理之间，由 `_shared/admin-menu.js` 统一声明；页面登记在 `_shared/registry.admin.js`。

## 组合来源

- 清单沿用项目合约管理审核队列：无框统计条 + `.ops-filterbar` + 固定操作列表格；返回时保留筛选、排序与页码，原页已空时回到最后一个有内容的页并说明。
- 详情沿用机构认证审核与项目合约管理的“左主区 + 右侧粘性审核栏 + 单条倒序操作记录”；字段行使用共享 `.ops-facts-*`，文件使用共享 `CF.fileRow`。
- 通过：身份摘要 → 勾选知悉后果 → 确认通过，无第二位审核人。退回：填写 10～500 字原因 → 全文预览 → 确认退回。“本处信息供审核人线下判定参考”只在这两个弹窗出现，不常驻页面。

## 平台代币标识

形成准入记录时生成，格式 PT + 当天 UTC 日期 yyyyMMdd + 当日 6 位序号；演示数据按每条记录首次提交的 UTC 日生成，各条不同，资料更新、重新推送与通过后变更都不改变它。它只用于在借贷平台内定位记录，不参与代币识别与重复判断。

## 内容精简（2026-10-21）

按用户反馈删去不必要的内容：审核栏的已等待时长与本页定位、通过弹窗的事实回显、退回框下的规则提示、操作记录中的规则解释，以及只弹提示的三项演示推送。

## 权限

PRD 第 3 节由本模块定义两项：代币准入审核查询 `PM-TA-01`、代币准入审核处置 `PM-TA-02`（须配套查询）。原型在运营端账户宿主的同一份权限清单中登记（内部键 21 / 22，`code` 为业务编号），本期运营管理员全部开通；仅开通处置时进入即拒绝并提示联系建设方，两项皆无时入口隐藏。异常配置只在默认关闭的演示工具中预演。

## 演示工具（默认关闭）

页面状态（加载中 / 无数据 / 筛选无结果 / 读取失败）、提交反馈（保存失败、已被他人作出结论、资料已更新、代币已失效、同一链上代币另一条已先通过、权限或账号变化）、审核结果回传失败、文件打开失败、操作记录状态；发行平台推送（资料更新、修改后重新推送、通过后资料变更、代币失效、缺少识别四项）；推送后平台代币标识不变；后期角色权限预演、运营登录失效与重置。

## 本期不做

按 PRD 1.1：不编辑、补录、上传或删除资料；系统不判断资料是否齐全；无批量审核、双人复核、审核时限；无评分或建议结论；不撤销准入、不下架、不重审；不发站内信；无审核备注；面客端资产广场、借贷广场的展示由对应模块承接。

## 限制

全部数据为虚构演示数据，页面标注“演示数据”。推送、回传、文件读取与区块浏览器链接均为本地模拟，不代表接口、链上核验或权限服务已实现。
