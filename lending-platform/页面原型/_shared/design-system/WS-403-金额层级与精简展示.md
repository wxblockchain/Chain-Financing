# WS-403 金额层级与精简展示

Stage 4 反馈修订 · existing-system adaptation / console。承接已批准的蓝白、Geist / Noto Sans SC 与 `cly-4.0.0`；本轮针对评论 `ba6d07d5-7e40-41d6-806e-694128e365e9` 及其借贷广场统计截图，统一金额的阅读顺序与信息密度。业务字段基线沿用本模块已确认 PRD 及上轮[网络与项目操作优化](WS-403-网络与项目操作优化.md)，本轮不更改业务计算。

## 视觉决策

- 首页统计统一为「币种图标 → 数字 → 小字号 ISO 币种代码」。保留 USD 等明确代码：国际用户使用的货币可能共享同一种符号，仅用 `$` 图标会有歧义。三个借贷统计使用相同字号、字重与图标尺寸，保留既有语义色。
- 只在首页的货币合计使用两位小数的 K / M / B 简写，例如 `6.28M USD`。完整金额在 title、可访问名称和可展开的原位浮层中可得，浮层支持点击、键盘、Escape 和点外关闭；展开不推移清单。K = 千，M = 百万，B = 十亿。简写不改变原始金额与计算口径。
- 资产数量仍为枚数，不把数量改成货币。失效数量仍是总量的子集，折算说明保留。
- 清单卡片 / 表格去掉每一笔金额旁重复的币种图标，保留「完整金额 + 小字号币种代码」。卡片金额更突出，表格保持紧凑。窄屏金额区改为整行，避免完整数字挤入相邻字段。
- 详情、项目办理与确认层保留完整金额；数值与小字号单位采用相同组件。独立币种标签、结算币种选择和网络图标继续保留。原有六位 gas 数值逐字保留，输入值与原校验不受装饰处理影响。

视觉口径直接来自 `_shared/tokens.css`、`_shared/market.css` / `market.js` 和两模块当前页面；本轮未引入新色板、字体或壳层。共享金额组件由 `CF.market.amount` 提供，原有字符串金额由共享装饰器归一，跳过输入框、已有金额组件和网络字段，避免重复装饰。离线附件由 `_shared/export.py` 内联生成，生成件不作为第二份源码入库。
