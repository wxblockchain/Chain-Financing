# WS-403 详情字号统一

Stage 4 反馈修订 · existing-system adaptation / console。响应评论 `35913681-3f0d-4db1-b34e-301a7c3e2067` 中资产详情的字号截图，承接已确认的蓝白 / Geist / Noto Sans SC 与 `cly-4.0.0`。

## 判断与修改

截图中的数量、铸造时间不是需要特别突出的业务数据。原因是 `_shared/market.css` 为资产详情的通用 `.num` 写了放大规则，导致时间、数量、区块高度、Chain ID 及应收账款金额变成 19px，而同级代币价值和普通文字为 14px。

本轮将该规则改为继承所在区域字号：普通详情字段值统一 14px，标签 12px；表格数值继承表格的紧凑字号。`.num` 仅承担数字字体、等宽数字和字重，不再以它判断字段重要性。数据、日期精度、时区与复制内容不变。

仍有明确的语义层级：标题和首页 / 项目汇总金额保持原有强调；币种单位保持较小字号；地址、Hash 及说明保留既有辅助样式。借贷项目的紧凑信息区、代币详情抽屉与业务表格按各自组件字号呈现，同一组件内的普通数值与文字同级，不将所有上下文强制改为同一个字号。

只修改 `_shared/market.css`，复用 canonical tokens、壳层及现有交互；未新增字体、色板或副本样式。附件由 `_shared/export.py` 同源内联生成。
