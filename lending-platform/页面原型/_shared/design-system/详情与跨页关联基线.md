## 承载方式

| 对象与目的 | 承载方式 | 返回与边界 |
| --- | --- | --- |

“查看详情”不再同时表示三种不同的容器。独立页面用链接，抽屉入口标“速览”，提交/确认说明具体动作。

## 项目左右分区

当前 WS-351 源码左侧是项目汇总、质押代币清单、融资信息清单；右侧是质押/融资/还款分类操作区。底座定义分区结构与阅读顺序，不预先加一份还款台账，也不改清单字段、费用或写权限。

样板以项目资料、质押代币清单、融资信息清单演示左侧可读分组，并演示代币独立详情、需求速览；右侧展示页内定位和与控制台的关联。样板为只读布局示例，不能用其右栏目录替换 WS-351 的业务操作区。项目主详情不展示操作记录；逐币质押历史、融资报价及放款记录留在各自已确认的业务容器中。WS-351 的自然页面滚动、固定操作区、七列项目列表、逐币弹窗及返回快照按[组件规范 §5.5](面客工作区组件规范.md#55-借贷广场已确认组合与关联入口)继承；汇总统计按具体 PRD，不照抄示例数据。

公共组合位于 `base.css`：`.detail-layout` / `.detail-stack` / `.detail-section` / `.detail-rail` / `.detail-index` / `.detail-actions`。全部显式接入；900px 以下收为单列。抽屉与弹窗继续使用已有宿主、640px 以下抽屉全屏。完整详情使用外页滚动，不套广场定高列表。

## 控制台与广场的关系

WS-355 已补齐六类业务详情原型，其字段层级、路由和组件接入见[控制台列表与独立详情基线](控制台列表与独立详情基线.md)。通用样板继续只承担组合示例，不替代业务源码。

控制台是与当前账户有关的业务台账；广场是项目上下文。台账 → 对象详情 → 关联项目 → 原对象详情 → 原台账，不能把“查看详情”直接等同于无上下文地打开广场首页。

- 链接携带对象 ID 和来源路径；来源只允许本地已登记路径，不能跳到任意外部地址。
- 列表保存筛选、页码或加载范围、内外滚动位置及触发行；返回先恢复数据范围，再恢复位置与焦点。样板在 URL 中携带恢复信息，新的浏览器上下文打开分享链接也能重建。
- 面客端详情通过父级面包屑回列表，不再添加同义的页内返回链接。跨模块回到来源记录属于另一条关联，保留独立入口。WS-350 详情返回沿用原列表快照；整宽纵向分区及返回焦点按[组件规范 §5.4](面客工作区组件规范.md#54-资产广场已确认组合与返回契约)回归，不以通用组合覆盖。
- 身份、企业权限与业务数据必须在目标模块重新验证；链接参数不能授予权限。样板只演示资产方/资金方的虚构记录集合，不能作为真实授权算法。
- 未知对象与无权记录显示不可用反馈；不得静默回到另一条记录。多项目授信、还款单期定位由 WS-355 最新反馈及对应模块处理，不能从示例单项目关系推断一对一约束。

## 接入与继承

关联样板保留在既有 `sample-pages.js` 单一来源，由底座 HTML 和消息中心既有组合入口共同引用；无需给业务 HTML 增加脚本依赖。它承接样板的广场、控制台及三个 `SAMPLE-*` 详情路由，不占业务登记 ID。`sample-pages.js` 保留历史 site 组件源码（首页不再登记或作为入口）、资产列表、管理端、focus、消息中心组合；移除旧的融资详情抽屉与模拟“报价已提交”成功反馈。
