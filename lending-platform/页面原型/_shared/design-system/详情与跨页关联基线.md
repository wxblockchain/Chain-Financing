## 承载方式

| 对象与目的 | 承载方式 | 返回与边界 |
| --- | --- | --- |
| 融资项目整体资料、多份清单及操作上下文 | 独立页面 | 广场是父级；浏览器前进后退、刷新和直接打开可寻址 |
| 代币完整资料 | 独立页面 | 保持 WS-350 已确认独立详情，不因项目里的一次点击改成弹窗 |
| 我的控制台台账的完整对象详情 | 独立页面 | 保留 WS-355 已确认的六类详情方向；本次仅演示一类记录关联，不替代六类业务实现 |
| 对当前列表或项目内一条记录快速核对 | 右侧只读抽屉 | 明确标为“速览”；关闭回原位置与触发按钮；需要完整上下文时跳独立详情 |
| 清空筛选等短确认 | 居中弹窗 | 表达后果，取消与确认；不能拿窄弹窗装长台账或复杂项目详情 |
| 报价、放款、还款、协议签署等业务流程 | 各模块既有承载单元 | 本次不统一改成抽屉或弹窗，不改变已确认费用、权限及确认步骤 |

“查看详情”不再同时表示三种不同的容器。独立页面用链接，抽屉入口标“速览”，提交/确认说明具体动作。

## 项目左右分区

当前项目详情左侧为紧凑统计、项目信息、分区 tabs 和代币 / 申请 / 放款 / 还款四个记录模块；外页自然滚动，信息卡与记录模块按断点固定高度并内部滚动，切换图表不推挤页面。右侧突出项目办理，追加 / 解除质押常驻，融资 / 还款流程保留；关闭项目在标题区右上，质押合约与项目编号同组。底座不据此更改清单业务字段、费用或写权限。

分区 tabs 滚动时紧贴实际顶栏；点击定位留出顶栏和标签空间。总质押额等明细浮窗高于 tabs，不被遮挡或误触后方标签。样板的只读右栏目录不能替换项目办理区；项目主详情不新增独立操作记录区，逐币历史、报价及放款记录留在既有容器。现行组合与返回快照见[组件规范 §5.5](面客工作区组件规范.md#55-借贷广场已确认组合与关联入口)，不照抄样板数据。

公共组合位于 `base.css`：`.detail-layout` / `.detail-stack` / `.detail-section` / `.detail-rail` / `.detail-index` / `.detail-actions`，按模块显式接入。通用分栏在窄屏收为单列，项目办理沿用其已确认上置 / 收起组合。抽屉与弹窗继续使用已有宿主、640px 以下抽屉全屏。完整详情使用外页滚动；项目内部固定记录区是已确认的局部容器，不将整个详情塞进列表内滚框。

## 控制台与广场的关系

WS-355 已补齐六类业务详情原型，其字段层级、路由和组件接入见[控制台列表与独立详情基线](控制台列表与独立详情基线.md)。通用样板继续只承担组合示例，不替代业务源码。

控制台是与当前账户有关的业务台账；广场是项目上下文。台账 → 对象详情 → 关联项目 → 原对象详情 → 原台账，不能把“查看详情”直接等同于无上下文地打开广场首页。

- 链接携带对象 ID 和来源路径；来源只允许本地已登记路径，不能跳到任意外部地址。
- 列表保存筛选、页码或加载范围、内外滚动位置及触发行；返回先恢复数据范围，再恢复位置与焦点。样板在 URL 中携带恢复信息，新的浏览器上下文打开分享链接也能重建。
- 面客端详情通过父级面包屑回列表，不再添加同义的页内返回链接。跨模块回到来源记录属于另一条关联，保留独立入口。WS-350 详情返回沿用原列表快照；整宽纵向分区及返回焦点按[组件规范 §5.4](面客工作区组件规范.md#54-资产广场已确认组合与返回契约)回归，不以通用组合覆盖。
- 身份、企业权限与业务数据必须在目标模块重新验证；链接参数不能授予权限。样板只演示资产方/资金方的虚构记录集合，不能作为真实授权算法。
- 未知对象与无权记录显示不可用反馈；不得静默回到另一条记录。多项目授信、还款单期定位由 WS-355 最新反馈及对应模块处理，不能从示例单项目关系推断一对一约束。

## 接入与继承

关联样板保留在既有 `sample-pages.js` 单一来源，由底座 HTML 和消息中心既有组合入口共同引用；无需给业务 HTML 增加脚本依赖。它承接样板的广场、控制台及三个 `SAMPLE-*` 详情路由，不占业务登记 ID。`sample-pages.js` 保留历史 site 组件源码（首页不再登记或作为入口）、资产列表、运营端、focus、消息中心组合；移除旧的融资详情抽屉与模拟“报价已提交”成功反馈。

`shell.js` 的 `CF.define` 组合新增父级 `breadcrumbRoute` 回退：后加载模块没有返回某父级路由时，继续使用前一个模块的上下文路由。避免消息中心组合后丢失样板返回参数。业务导航、层级和入口仍由各模块登记。
