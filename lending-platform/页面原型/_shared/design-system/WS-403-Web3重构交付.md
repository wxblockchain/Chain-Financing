# 资产广场、借贷广场 · Web3 重构原型

Stage 4/4 · existing-system adaptation · console（国际用户面客金融工作区）。本次直接交付两模块全范围**视觉评审原型**，不是生产系统业务验收。

依据 cuiluyao 的“直接重构原型”及“不要沿用当前的既有基线……全范围重构”要求，合并 Stage 1 / 2 的中间确认。本轮取代上一版 Stage 1 的浅色视觉提案，重新定义两模块的画布、token、信息层级、数据视图及交互表现；已有业务运行时用于承载功能，不作为本轮视觉限制。

## 打开与评审

双击同附件 `WS-403-资产与借贷广场-重构原型.html`，无需服务、CDN、远程字体或网络请求。默认英文、游客身份、资产广场；顶栏进入借贷广场，卡片或表格行进入详情。两页右侧布局按钮切换 Cards / Table；状态图例可直接筛选，再点当前项取消筛选。顶栏语言菜单支持中文，切换不清空表单。

右下 Demo tools 默认关闭；打开可切换游客、登录未绑定角色、资产方、资金方及异常状态。业务场景入口可定位报价、放款、还款等环节，“更多模拟”承接原有测试场景。资产方在借贷广场创建项目；本企业项目的右侧办理区提供质押、解押 / 提取、融资和还款操作。钱包、交易、企业、金额与所有金融数据均为已标注的本地演示。

本附件内联现有组合运行时，相关登录、账户、控制台、消息入口可衔接；这些相邻模块不是本轮重新设计范围。切入相邻模块时回到其自身主题。

## 视觉与组件

采用深炭绿画布、暖白正文、薄荷绿主操作；紫、蓝、琥珀分别辅助区分数据类别，状态仍提供文本。金额使用等宽数字，主金额与辅助金额拉开层级。没有装饰渐变、假行情或新增收益承诺。

- **资产广场**：签发 USD 价值为主读数，数量与失效数量作为次级数据；有效 / 失效构成按当前结果的代币数量计算，可点击筛选。默认资产卡片完整展示九字段，可切回表格；筛选、搜索、排序与内嵌连续追加保留。
- **借贷广场**：待报价金额与需求数为主读数，有效质押额、已融资余额在次级层；项目状态分布按当前结果的项目数计算。融资卡片突出项目身份、两项金额与业务状态，七字段表格用于逐行比较。
- **代币详情**：资产身份与状态置顶，以图标引导底层资产、账期、链上事实的阅读；五个信息区、完整地址、复制与未核验提示均可得。
- **项目详情**：四项核心数值与融资额度占用图先解释当前项目，再进入质押构成、融资申请、放款与还款记录。右侧当前办理与目标合约构成独立操作区；图表 / 列表及环节回看可交互。
- **创建与办理**：创建页重排为名称、并列参数、日期范围、币种选择与固定条款；办理弹层使用统一深色表面、清晰字段与主次操作，不新增业务确认步骤。
- **币种与链**：USD / EUR / JPY / CNY / GBP 用对应货币符号；USDT / USDC、ETH / TRON 用可识别的内联 SVG 标识并保留代码文本。原生币种选择框在选中后显示相应图标。币种、质押链与结算收款链保持不同业务含义。
- **动效**：构成图轻量展开、弹层淡入；只动画 `transform` / `opacity`，尊重 reduced motion，焦点环即时显示。

canonical token 的新主题仅在两模块及其业务路由启用：画布 `--bg` #0C100F、正文 `--text` #F1F5ED、次级 `--muted` #B0BDB5、主色 `--accent` #B6EF8A，控件 44px；全部颜色和字体从同一 token 文件取值。
