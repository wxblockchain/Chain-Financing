## 阅读顺序

1. 从[PRD 目录](../../../PRD/README.md)定位本模块需求、字段、流程和权限，再核对用户最新确认的反馈。
2. 读[共享组件视觉规范](共享组件视觉规范.md)：字体、颜色、语义字号、输入状态、筛选、金额与层级的共同入口。
3. 按页面选择[面客工作区](面客工作区组件规范.md)、[运营端](运营端组件规范.md)或[公开首页](官网层组件规范.md)规范，并读[页面继承参考](页面继承参考.md)。
4. 核对目标模块 README、HTML / CSS / JS 及共享实现；已确认的页面布局优先于样板示例。组件变更同步规范，业务歧义按模块 PRD 处理。

## 画布与继承

| 画布 | 当前使用与边界 |
| --- | --- |
| `site` | [公开首页](../../面客端/00-首页/README.md)，入口 `#/home`，按该模块已确认结构；不把首页展示型布局套给业务页 |
| `portal` | 面客业务工作区，顶栏导航、列表与独立详情，沿[面客模块目录](../../面客端/README.md)进入 |
| `app` | 运营固定侧栏与管理画布，当前只有运营管理员一个角色；沿[运营模块目录](../../运营端/README.md)进入，历史 SPV 职责不另设当前身份 |
| `focus` | 登录等居中表单；普通表单保留44px控件，不沿用紧凑筛选尺寸 |

业务字段、可见范围、查询策略和状态流来自各模块 PRD；组件统一不扩大权限，也不改变已确认的滚动、加载和返回方式。

## 国际化与可访问性

面客语言、时区偏好及其展示含义以[登录主干 PRD](../../../PRD/面客端/01-登录主干与资产方SSO接入/01-登录主干与资产方SSO接入-PRD.md)为准；资金方资料与脱敏见[资金方账户 PRD](../../../PRD/面客端/02-资金方登录与账户体系/01-资金方登录与账户体系-PRD.md)，运营偏好见[运营账户 PRD](../../../PRD/运营端/01-运营端账户与登录/01-运营端账户与登录-PRD.md)。其中仍标为库外依赖的国际化 / 脱敏细则继续按 PRD 待确认，不把旧分支路径当作已补齐的规范。

默认英文、支持简体中文；切换语言保留输入。显示时区不改变业务时点或时限，日期与时分一起转换并标注时区。金额保留原精度及币种，地址缩略仍保留完整可读 / 可复制值；具体敏感字段按所属模块已确认范围显示。运行时格式化入口为 `CF.fmtTime / CF.fmtDate / CF.fmtAmt`。

组件的键盘、焦点、读屏名称、触控、错误与加载反馈遵循[共享规范](共享组件视觉规范.md)。可见范围与禁用行为仍由业务权限决定；数字、长值和翻译不能裁掉关键披露。
