# 原型评审切换规范

2026-09-22 · WS-385。适用于借贷平台面客端、管理端及公共底座样板。依据用户确认的“先定登录状态，再选页面，最后选状态”要求，后续新增与修订原型统一遵循本规范；不改变业务 PRD、产品导航或权限规则。

## 1. 登录状态、页面、状态与步骤

- **登录状态是面客端的第一轴**：未登录访客与已登录身份（资产方、资金方、受限会话）在选页面之前确定，评审无需先走一遍登录流程。管理端身份来自其真实登录与权限，不在评审工具里就地切换。
- 未登录态下产品主导航不出现需登录的入口；这些页面仍可从评审目录打开，用于查看其登录引导界面，目录不改变产品导航与权限。
- **页面目录**按当前部署单元与模块分组；显示页面名称，页面编号为次要检索信息。只登记已有实现、可通过合法路径打开的页面。详情不是新的产品菜单项。
- **状态选择**跟随当前页面，只提供该页实际实现且适用的状态。业务状态与界面反馈分组；不得把“登录页·锁定态”等作为独立目录项，也不得向每个页面机械提供全部通用状态。
- **流程步骤**保留真实先后关系。例如“验证邮箱 → 设置新密码”属于重置密码流程，工具显示当前步骤，仍通过正常流程进入下一步；不通过评审目录跳过验证或权限前置条件。
- 授权回调、处理中和错误出口等辅助路由可用 `aliases` 归到同一页面；没有匹配预设时显示“当前流程状态”，不能假称默认状态。
- 当前身份下没有可打开记录的详情保留在目录中但不可选，并标注“需先从列表进入”，让评审者知道覆盖范围又不会选到打不开的条目；选中后仍无有效记录时提示先从列表选记录。

## 2. 工具呈现

评审工具独立、默认关闭，不占用产品业务内容区。面客端展开后的顺序固定为“1 · 登录状态 → 查找页面 → 2 · 页面 → 3 · 状态 → 恢复默认”，登录状态按“未登录／已登录”分组；管理端无身份选择器，顺序为“查找页面 → 1 · 页面 → 2 · 状态”。部署单元、请求响应、外部事件及复杂业务样例保留在默认折叠的“更多模拟”中，身份控件不再在其中重复出现；真实菜单、行操作与跨页流程继续可用。

普通模块只展示已装载且登记的页面；管理端模块入口使用现有共享导航清单，进入对应模块后再展示其详情与状态。目录的存在不授予权限。缺少详情记录时提示先从列表选记录，不能生成虚假记录或静默打开另一种页面。

控件复用共享 token 与组件，具有可见 label、键盘焦点和明确选中值。搜索支持名称和编号，保留当前选中页；页面变更后焦点回到页面选择器，状态变更后回到状态选择器。Escape 收起评审面板并归还入口焦点。弹层打开期间禁止用目录或状态控件越过未完成操作。

## 3. 切换与复位

1. 从评审目录切页时清理当前注入的模拟状态，并恢复目标页默认反馈；不清空业务记录、筛选持久化或整个演示数据库。
   切换登录状态同样清理模拟状态：当前页在新身份下仍可打开时留在原页，便于同一页面做登录／非登录对照；不可打开时落到该身份的默认入口。切换身份不等于绕过登录与权限——需要登录的页面在未登录态仍显示其登录引导界面。
2. “恢复默认”作用于当前页面的模拟状态，并清除该页在“更多模拟”中注入的局部故障。实际身份、有效业务数据和 PRD 定义的流程前置条件继续生效，不等同于重置账户或恢复权限。
3. 通过产品导航、面包屑或浏览器历史跳转时，选择器同步实际页面；已由统一选择器注入的模拟状态离页后清除。真实业务操作产生的反馈遵循模块既有状态机。
   跨文档切换管理端模块时评审工具保持展开，落地页仍按目标模块的权限与会话判定；未共享会话时可能要求重新登录，目录不代替登录。
4. 正在提交、编辑未保存、审核未完成等场景，复用原有离页保护；拒绝或取消切换后保留原页面和内容，不能先清除数据再询问。
5. 模拟状态必须落实到实际字段、按钮、状态表面或反馈。模块仍负责取消或隔离过期异步结果；不能只更新下拉框文字。
6. 整页状态统一由“2 · 状态”提供；局部组件故障、身份与请求响应模拟留在“更多模拟”，不在两处重复同一个整页状态。状态选项以该页现有覆盖为限。组合场景必须由模块提供有效预设或在“更多模拟”中按现有业务流程触发，禁止随意组合出不存在的权限、业务与异常状态。

## 4. 共享接入契约

唯一运行时：`../shell.js` 的 `CF.review`；唯一样式：`../base.css`。各模块在自己的维护源里登记适配器，继续调用原有状态与交互，不复制页面实现。

```js
CF.review.register(pageId, {
  group: ['Module', '模块'],
  states: ['default', 'loading', 'error'],
  route: () => existingRecordRoute(),
  get: () => currentViewState,
  set: value => { currentViewState = value; },
  reset: () => { currentViewState = 'default'; },
  beforeChange: proceed => existingLeaveGuard(proceed)
});
```

| 字段 | 约定 |
| --- | --- |
| `group` / `label` | 中英名称；页面名称省略时读取 `CF.PAGES` 的文案键 |
| `states` | 状态 ID 列表或返回列表的函数；自定义项为 `{id, label:[en,zh], group:'business'/'feedback'/'step'}`；始终提供 `default` |
| `route` | 已有合法路由或返回路由的函数；缺省使用 `CF.ENTRY`；无可用记录返回空值 |
| `get` / `set` / `reset` | 对接模块已有状态；缺省为共享 `CF.S.st`；复位仅清理模拟反馈，禁止重置业务资料 |
| `aliases` / `step` | 同页辅助路由 ID 与当前流程步骤文本；不新增产品菜单 |
| `visible` | 页面是否适用于当前身份或前置条件；不替代业务权限检查 |
| `beforeChange` | 必要时复用模块现有离页保护，确认允许后才调用 `proceed` |
| `navigate` | 仅跨文档模块入口使用，委托现有共享管理端导航；不能绕开权限或复制导航清单 |

旧模块仍可在原演示面板宿主中输出复杂模拟工具，公共层统一收纳至“更多模拟”。异步更新内容使用 `CF.review.setTools(html)`；重组复杂演示工具时仅操作 `.review-more-body`，不得整体搬走或销毁统一切换器与当前焦点。新的页面／整页状态入口必须使用 `CF.review`，不新增另一套页面画廊或常驻状态切换器。

## 5. 验收

- 初次打开评审工具关闭；面客端展开后先见登录状态，再见页面与该页状态，辅助工具默认折叠。
- 选定已登录身份后，该身份可访问的页面可直接打开，不需先在原型里走一遍登录流程；未登录态下需要登录的页面显示登录引导，不静默跳转。
- 目录搜索、选页、状态、恢复默认、中英切换和键盘操作正常，无重复切换器；不可打开的条目为禁用态。
- 列表、详情、登录和流程页仅显示适用状态；业务状态与异常反馈有明确分组；流程步骤不被当成异常状态。
- 切页不串用上一页模拟状态，业务记录不因恢复默认而清空；真实导航与浏览器前进／后退后位置同步。
- 未保存与进行中操作遵循原保护；真实登录和查询权限不被评审导航绕过。
- 面客端按项目既有 375 / 414 / 768 / 1280 / 1440 / 1920 宽度，管理端按 1280 / 1440 / 1920 检查，无裁切或横向溢出。
- 单文件附件由 `export.py` 从维护源生成；新共享规则要求重新导出，历史附件不会自动更新。截图只用于内部核验。
