# 管理端组件规范

## 1. 范围与视觉口径

本规范面向**运营管理平台**：账户设置及业务页使用 `layout: 'app'`；登录、首登改密、找回及重置密码使用 `layout: 'focus'`。范围包括运营端账户与登录、资金方机构认证审核、代币质押审核、消息通知、协议管理。

实现以 [`../base.css`](../base.css) 的 `.app` / `.sidebar` / `.topbar` / `.content` 与公共组件为准，token 以 [`../tokens.css`](../tokens.css) 为准；本文不复述数值。

核心特征：标准管理平台形态——固定左侧栏、紧凑顶栏、清晰的表格边界、高信息密度。与面客端**共用同一套色板与组件**，差别只在密度 token。

## 2. Shell

| 元素 | 规则 | 禁止用法 |
| --- | --- | --- |
| 应用框架 | 定宽左侧栏 + 右侧主内容区；侧栏全高、右边线清晰，内容区 `min-width: 0` | 把侧栏做成可无限展开的多级树 |
| 侧栏 | 品牌区、低强调分组标签、紧凑导航项、底部当前操作员上下文 | 模块自建菜单；把流程页登记成侧栏条目 |
| 顶栏 | sticky；轻量全局工具区靠右，不放面包屑 | 在顶栏堆业务操作 |
| 面包屑 | 位于页面内容区、标题上方，与正文左边界对齐并随内容滚动。按可用模块根页、父级、当前页逐级展示；上级可点、当前页不可点 | 放入顶部工具栏；同时附加「返回上级」按钮 |
| 画布 | 不设固定 `max-width`，铺满侧栏之外的可用宽度，只保留横向安全边距；标题区后接统计 / 筛选 / 内容卡，不压成一张巨型卡 | 用官网层的宽留白、展示型大标题或入口卡替代高密度画布 |

## 3. 页面形态

管理端的功能点基本是这几种，按一致的一套设计，不是各做各的：

| 形态 | 必须承载 |
| --- | --- |
| 列表 / 台账 | 与 PRD 筛选字段一一对应的筛选条、字段目录给的列集、排序、带总数的分页、行操作、需要时的批量操作、固定操作列 |
| 详情 | key / value 栅格、状态标记、附件预览与兜底、关联记录链接 |
| 表单 / 上传弹层 | 字段级校验与真实上限（大小、长度、格式）、被操作对象的只读反显、规则要求的二次确认、提交进度与幂等反馈 |
| 审批 / 复核 | 经办人提交 → 审核员复核、节点状态、驳回原因、每个角色在每个节点看到什么 |
| 记录 / 版本历史 | PRD 给的字段集与顺序、只增不改的语义、以及这本台账**不**记录什么 |
| 总览 | 只放 PRD 点名的卡片，不自造 KPI 砖 |

## 4. 组件

| 组件 | 规则 | 禁止用法 |
| --- | --- | --- |
| 数据表 | 浅色表头、大写小字距列名、紧凑行高、右对齐数值与结构化值、操作列固定在右 | 操作列在 1280px 下消失或被裁 |
| 行操作 | 文字链，主操作在前；不可用的操作保留并禁用，`title` 给出原因 | 把不可用的操作直接删掉，让不同行的操作列长短不一 |
| 筛选条 | 与表格同卡，位于表头之上 | 把筛选做成抽屉，让用户看不到当前条件 |
| 状态标记 | 色点 + 文字，语义色成套 | 只靠颜色区分状态 |
| 抽屉 / 弹窗 | 详情与二次确认用；弹窗层级高于抽屉 | 在抽屉里再开抽屉 |
| 空态 / 失败态 | 标题 + 一句原因 + 修复动作 | 用一张灰图配「暂无数据」四个字了事 |

## 5. 角色与权限

- 角色差异通过**可达的视图**体现：菜单、列集、操作、权限都要真的变。
- 越权写必须有可见反馈——按钮禁用并给原因，或提交后给明确拒绝提示，不是静默无事发生。
- 双人复核仅在对应模块明确要求时演示；不能据通用形态为 WS-358 增加查询岗、处置岗或复核岗。

## 6. 必须覆盖的状态

默认 · 加载中 · 空数据 · 筛选无结果 · 加载失败可重试 · 无权限 · 提交中 · 提交失败 · 异步等待接口返回。只实现该功能实际适用的那些。

## 7. 响应式验收

管理端默认验收 1280 / 1440 / 1920 三档：无横向溢出、侧栏不压内容、操作列可达、无控件被裁。模块已确认的响应式范围优先：运营端账户与登录同时保留 375 / 414 / 768；其余模块不据此自动扩大范围。

## 8. 运营端账户与登录：已确认组合

本节由 WS-357 已确认原型（`bc056bd`）及用户反馈反向整理；实现见 [账户与登录](../../管理端/账户与登录/README.md)、[模块样式](../../管理端/账户与登录/账户与登录.css) 与 [交互](../../管理端/账户与登录/账户与登录.js)。通用母版不得覆盖下列已定内容，不要求其他模块照搬。

| 页面 / 组件 | 已确认结构与交互 |
| --- | --- |
| 登录与受限流程 | 使用公共 focus 壳层，仅品牌、语言及必要退出入口。初始邮箱与密码由建设方提供；无注册、邀请、开户或角色选择入口。首登受限时不能进入业务页 |
| 首登改密 | 只展示新密码和确认新密码；不再次输入当前密码。成功后重新登录。账户内改密、换邮箱仍先以当前密码再认证 |
| 密码框 | 眼睛／划线眼睛图标切换；动态无障碍名称说明下一步动作。保留输入值和键盘焦点，不用“显示／隐藏”文字占据框内空间 |
| 密码反馈 | 规则就近展示；确认密码不一致时就地提示并阻止提交，修改任一输入使两者匹配后清除。空错误区不占额外一行，错误出现时展开；提交失败后定位首个错误字段 |
| 邮箱验证码 | 从初始状态即呈现同一行：输入框在左、获取验证码按钮在右；验证／确认主按钮在下方。发码前保留人机校验，发送后显示重发倒计时，失败后可重试；找回与换邮箱使用同一组合 |
| 账户设置 | 整页纵向两组：账号信息在上，偏好信息在下，不改回左右布局。保留邮箱、姓名、角色、状态、密码、最近登录与创建时间；不展示已开通权限清单 |
| 分区导航 | 账号信息／偏好信息用于跳转到同页分区，两组同时存在；不是互斥 tab 面板。键盘激活后焦点到达目标分区 |
| 邮箱与密码修改 | 账户页文字操作进入居中弹窗；再认证后进入编辑，人机校验结束回到当前编辑上下文。沿用共享弹层、关闭和焦点约束，不改为抽屉或新增菜单 |
| 偏好与角色 | 语言、时区在下方偏好区修改；两类角色共用本人账户页面，权限差异由可用功能与实际校验体现，不增设账号授权管理界面或 SPV 专属账号 |
| 运营落点 | 普通登录进入现有运营总览或恢复原受保护页面；首登先改密。面客端资产广场默认入口不适用于运营端；账户设置仍由账号菜单进入 |

视觉继承公共 token、focus/app 壳层、输入框、按钮、状态标记和弹窗。侧栏品牌名与副标题分行显示，避免副标题被挤断；业务页面不出现规则编号、字段来源或内部交付说明。演示工具默认关闭，认证、邮件与安全策略仍是本地模拟。

## 9. 资金方机构认证审核：已确认组合

本节由 WS-358 用户确认的布局、V2.2 文档与单框驳回原型反向整理；实现见 [模块说明](../../管理端/资金方机构认证审核/README.md)、[页面组合](../../管理端/资金方机构认证审核/资金方机构认证审核.html) 与 [交互](../../管理端/资金方机构认证审核/资金方机构认证审核.js)。不以通用详情母版替换下列结构。

| 页面 / 组件 | 已确认结构与交互 |
| --- | --- |
| 审核列表 | 六列：申请编号、机构标识 / 名称、提交时间、状态、结论时间、操作；不展示版本。筛选与列表同卡，提交时间升序，保留带总数的分页，不增设统计或批量审核 |
| 审核详情 | 独立整页及自然页面滚动；左侧依次为提交信息、机构资料、材料与结论，右侧仅审核操作。右栏固定宽度并随滚动保持可达，不放目录、版本或额外信息卡 |
| 字段展示 | 标签 / 值分组；注册地址与钱包地址整行展示，长值可换行。复用共享 token、card、detail-stack，模块保持已确认的密度与间距 |
| 版本历史 | 独立全宽表格放在详情所有分区之后；切换版本回详情顶部，历史与已出结论版本不显示审核操作栏。这是本模块对通用“不可用操作保留禁用”规则的已确认例外 |
| 列表与详情关联 | 行入口及版本入口为可寻址链接。详情通过父级面包屑返回，不重复摆放返回按钮；保留状态、关键词、日期、页码，返回后恢复触发行焦点与同页浏览位置。原行因结论不再满足筛选时回到筛选区，不显示另一条申请冒充原记录 |
| 历史寻址 | 地址包含申请及所看版本；刷新、前进后退维持版本上下文。未知申请或版本显示不可用态，不回落到另一条申请；无版本参数表示当前版 |
| 材料与确认 | 材料预览、通过确认、驳回输入及核对沿用居中弹窗，不改为抽屉。加载失败与未上传分开表达，原件不可用有兜底 |
| 单一驳回原因 | 只有一个必填多行框；无字段选择、分类、中英文分填或补充框。纯空白就地报错；核对后可返回修改且保留输入，取消不生效并将焦点还给审核入口。原文换行及字符在两端、修改页和历史一致展示，不自动翻译 |
| 角色与流程 | 正常运营会话可查看和处置当前待审核版本，不新增运营分权或 SPV 认证。审核中材料锁定；已认证变更成功提交才转待审核；旧版及已有结论不可再次处置 |
| 面客承接 | 继续使用资金方账户模块的注册 / 状态 / 修改页。演示工具才可切换运营与申请人，产品画面不出现跨端角色切换入口。面客结果保持上下分区、首屏原因与重提、提交信息内折叠历史 |

来源页面的确认组合优先于本规范其他通用规则。正式材料政策、审核判据及未确认上传阈值不由组件规范定稿；原型里的模拟会话与异步响应不是后端授权或并发实现。

## 10. 代币质押审核：已确认组合

本节由 WS-359 用户评论 `b7b51ec0-ff9e-480d-b48f-2c663d2aa5e1`、已交付 `55d902d` 与 V1.2 文档反向整理，实现见 [模块说明](../../管理端/代币质押审核/README.md)、[页面组合](../../管理端/代币质押审核/代币质押审核.html) 和 [交互](../../管理端/代币质押审核/代币质押审核.js)。不套用 WS-358 的历史置底、取消分类或无运营分权等业务规则。

| 页面 / 组件 | 已确认结构与交互 |
| --- | --- |
| 队列与统计 | 一行一笔代币申请，不以批次代替审核对象。七列保留单笔 / 代币、资产方、项目、价值、审核截止、状态、操作；批次、类型及执行明细留在详情。保留三项按笔统计与其筛选范围提示 |
| 筛选 | 关键词与审核状态常驻；其余条件向下展开，默认收起；提交后保留已应用条件。日期错误展开定位，Enter 可查询；排序与带总数分页沿用共享控件 |
| 详情 | 独立页面，顶部摘要；左侧概览 / 关联申请 / 操作记录页签，右侧粘性审核区。保留原英文布局及右侧已通过后续信息，不改为抽屉、不照搬其他模块分区 |
| 页签 | 互斥面板，使用 tab / tabpanel 语义，左右方向键及 Home / End 可切换。页签记入地址；刷新与浏览器往返恢复当前分区，打开另一笔默认概览 |
| 关联申请 | 同批及跨批表格的查看操作统一在最右侧，使用可寻址链接。新详情显示来源申请入口，可返回来源的关联页签；队列面包屑另行返回原筛选、排序及页码，同一会话恢复滚动和触发行焦点 |
| 审核弹窗 | 本笔对象反显 → 填写 → 核对 → 确认。通过仅上传本笔协议，不提供“选用同批协议”快捷入口；驳回仍为本模块已定的原因与选填归类。保留文件及文字边界、未提交内容放弃确认、失败保留输入，不把另一模块单框驳回规则移入本模块 |
| 权限与状态 | 保留查询 / 处置的已有区别、截止与唯一结论校验。已结束记录只读，关联跳转不授予权限。逐笔通过不触发链上动作；审核 48 小时与执行等待分开展示，不以同批一笔结论覆盖其他笔 |
| 跨模块边界 | 项目、代币及执行信息是本端只读事实，不用未装载的样板链接假装真实业务跳转。资产方面客执行仍由既有借贷广场承接，本入口不增加代确认、转移或异常释放能力 |

复用当前 token、app 壳层、表格、状态、弹层、详情纵向栈与导出器；保留本模块已确认间距和列宽。地址只保存浏览上下文，不能授予权限或保留刷新前的模拟裁定；文件、消息、鉴权及跨平台执行仍需真实服务联验。

| 消息列表 | 独立整页自然滚动，白底分隔行；标题、单行摘要、分类与时间分层，右侧固定已读 / 未读标签。整条使用原生链接，可键盘打开；可读名称包含阅读状态及完整标题 |

| 已读与批量确认 | 成功读取详情才自动已读，不提供行内已读或标为未读。未读筛选下刚读行原位保留到刷新 / 切换筛选。全部已读位于页头，居中确认明确筛选、条数、跨页、仅本人及不可撤销；执行中防重复，失败不更新 |
| 铃铛预览 | 最近 10 条，展开不标已读，无批量入口；关闭后焦点回铃铛。预览与列表使用不同 DOM 标识，避免同消息同时出现时返回焦点错误 |
| 目标与来源 | 账户类通知进入真实账户设置组合，显示返回原消息的来源链接；来源限定本地消息路由。示例业务抽屉标明“申请速览”，只演示只读摘要，不冒充 WS-358 完整审核页、不提供裁定 |
| 失效与请求 | 消息内容与目标权限分开处理；过期隐藏跳转，目标删除 / 流转 / 无权限禁用并解释，映射缺失 / 无目标不增加说明。页面或身份变化废弃旧模拟请求，不能让迟到响应重写新页面或标记另一账号的消息 |

沿用共享 `.nc-*` 与 `.om-*` 样式、token、账户宿主和弹层；本轮未修改公共运行时、业务登记或 PRD。旧 PRD 的行内已读入口差异继续见模块说明。真实跨模块记录跳转、后台权限、计数与投递仍需业务接入联验；本规范不新增消息触发规则。


## 12. 运营端协议管理：既有组合与本轮关联补齐

本节依据 WS-361 已交付 `bb2dec2`、V1.0 协议管理文档及 WS-365 串行修订整理。实现见 [模块说明](../../管理端/协议管理/README.md)、[页面组合](../../管理端/协议管理/协议管理.html) 与 [交互](../../管理端/协议管理/协议管理.js)。既有业务方向优先；以下浏览关联补齐不裁定文档第 5 章未决规则。

| 页面 / 组件 | 组合与关联约定 |
| --- | --- |
| 台账 | 预置协议九列，保留关键词、类型 / 使用环节 / 状态多选及日期筛选；带总数的 20 / 50 / 100 分页、排序与固定操作列。协议名称 / 标识、当前版本与待生效计划分层展示，时间仍带账号时区 |
| 详情 | 独立整页；基本信息中左侧只读定义、右侧当前生效摘要及计划。版本历史与操作记录是互斥页签，不套用审核页右侧操作栏，也不将历史改到基本信息底部 |
| 页签与寻址 | 对象和当前页签进入地址；刷新、浏览器往返保留分区。tab / tabpanel 关联，方向键与 Home / End 可切换；无独立记录权限时不展示操作记录页签 |
| 列表返回 | 行入口使用原生链接，详情和编辑使用父级面包屑，不重复上级返回按钮。地址携带经过校验的筛选、排序及页码；同一会话恢复列表滚动与触发行焦点。对象缺失或未知时显示不可用，不借用首条样本 |
| 版本与来源 | 版本只读详情保留右侧抽屉，来源版本是业务追溯字段，应保留。关闭回原页和触发入口；直接版本地址关闭后回该协议历史。此处“版本详情”是既有抽屉的明确业务名称，不因通用速览建议改名或改为整页 |
| 编辑与确认 | 文件 / 发布设置两列，底部保存、发布和丢弃。空错误区域不占位，已有错误在修正后消除；面包屑、浏览器返回及其他对象地址均先拦截未保存改动。异步提交期间不切换对象；发布后回版本历史 |
| 生命周期 | 沿用草稿、立即 / 定时发布、替换已有计划、撤销覆盖、回溯、只读历史与二次确认。维护、发布、查询权限分别演示；不新增审批或代签 |
| 范围边界 | 独立附件仅装载协议管理，隐藏未装载模块菜单与通知，不用样板页面冒充真实消息联动；共享消息目标仍待业务接入验证 |

复用当前 token、app 壳层、表格、状态件、弹层与导出器；模块样式只处理既有内容组合。操作记录权限、首版仅待生效标签、撤回再发布编号与凭据、下线计划、真实定义清单及三平台映射继续未决；规范不得将演示假设提升为产品裁定。
