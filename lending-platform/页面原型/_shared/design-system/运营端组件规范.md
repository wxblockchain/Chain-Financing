## 1. 范围与视觉口径

本规范面向**运营管理平台**：账户设置及业务页使用 `layout: 'app'`；登录、首登改密、找回及重置密码使用 `layout: 'focus'`。范围包括运营端账户与登录、资金方机构认证审核、代币质押审核、消息通知、协议管理、项目合约管理、融资参数配置。

实现以 [`../base.css`](../base.css) 的 `.app` / `.sidebar` / `.topbar` / `.content` 与公共组件为准，token 以 [`../tokens.css`](../tokens.css) 为准；本文不复述数值。

核心特征：固定左侧栏、紧凑顶栏、清晰的表格边界与业务画布。与面客端共用同一套色板、Geist / Noto Sans SC、语义字号和同级组件规格；高信息密度由清单与筛选组合承载，不再通过端别缩小正文、字段或按钮。

## 2. Shell

| 元素 | 规则 | 禁止用法 |
| --- | --- | --- |
| 应用框架 | 定宽左侧栏 + 右侧主内容区；侧栏全高、右边线清晰，内容区 `min-width: 0` | 把侧栏做成可无限展开的多级树 |
| 侧栏 | 品牌区、低强调分组标签、紧凑导航项；不展示底部账户信息。菜单由 `admin-menu.js` 统一声明 | 模块自建菜单；把流程页登记成侧栏条目 |
| 顶栏 | sticky；右侧依次为消息铃铛、语言、邮箱地址。账户悬浮菜单展示只读角色“管理员”（专员保留实际角色）、消息中心、账户设置、退出登录；复用 `admin-menu.js` 与 `admin-notifications.js` | 在顶栏堆业务操作；各模块复制账户或铃铛实现；用“我的账户”替代邮箱 |
| 面包屑 | 一级页面不展示面包屑或占位；详情位于页面内容区、标题上方，与正文左边界对齐并随内容滚动。只按真实父级、当前页逐级展示；上级可点、当前页不可点 | 放入顶部工具栏；同时附加「返回上级」按钮 |
| 画布 | 不设固定 `max-width`，铺满侧栏之外的可用宽度，只保留横向安全边距；标题区后接统计 / 筛选 / 内容卡，不压成一张巨型卡 | 用官网层的宽留白、展示型大标题或入口卡替代高密度画布 |

## 3. 页面形态

运营端的功能点基本是这几种，按一致的一套设计，不是各做各的：

| 形态 | 必须承载 |
| --- | --- |
| 列表 / 台账 | 与 PRD 筛选字段一一对应的筛选条、字段目录给的列集、排序、带总数的分页、行操作、需要时的批量操作、固定操作列 |
| 详情 | key / value 栅格、状态标记、附件预览与兜底、关联记录链接 |
| 表单 / 上传弹层 | 字段级校验与真实上限（大小、长度、格式）、被操作对象的只读反显、规则要求的二次确认、提交进度与幂等反馈 |
| 审批 / 复核 | 经办人提交 → 审核员复核、节点状态、驳回原因、每个角色在每个节点看到什么 |
| 记录 / 版本历史 | PRD 给的字段集与顺序、只增不改的语义、以及这本台账**不**记录什么 |
| 总览 | 只放 PRD 点名的卡片，不自造 KPI 砖 |

## 4. 组件

| 组件 | 规则 | 禁止用法 |
| --- | --- | --- |
| 数据表 | 浅色表头、自然大小写列名；表头使用 `--ui-field-label`，普通值使用 `--ui-row-value`；数值按列对齐，操作列固定在右。字段中的日期、数字与字母不单独缩放 | 操作列在 1280px 下消失或被裁；模块另定义一套字号 |
| 行操作 | 文字链，主操作在前；不可用的操作保留并禁用，`title` 给出原因 | 把不可用的操作直接删掉，让不同行的操作列长短不一 |
| 筛选条 | 与表格同卡或按现行页面相邻，位于表头之上；紧凑控件与标签角色遵循共享规格，复杂字段保留模块既有组织与展开方式 | 把筛选做成抽屉，让用户看不到当前条件；为统一外观改写查询与清空策略 |
| 状态标记 | 色点 + 文字，轻语义底与小圆角；与面客同级 Tag 采用同一规格 | 只靠颜色区分状态；用视觉新增业务状态 |
| 详情字段 | 统一使用下文 §4.1 的共享只读字段行：标签为 `--ui-field-label`，值为 `--ui-field-value`，按内容区宽度排布；长内容换行，普通等待时长、日期和金额同级 | 将普通数值当 KPI 放大；低对比标签替代业务值；给所有详情硬套同一个页面布局 |
| 审核操作区 | 项目、质押、机构审核的既有右侧操作区域用统一蓝色边界和标题强调，主操作在前；终态与权限仍由原模块决定 | 将等待时长渲染成期限或倒计时；新增角色、操作或确认步骤 |
| 抽屉 / 弹窗 | 共享标题、正文、圆角及头尾分隔；长正文内部滚动，操作可达；容器及替换 / 返回策略按已确认模块 | 在抽屉里再开抽屉；以组件统一为由增加或删除确认层 |
| 空态 / 失败态 | 标题 + 一句原因 + 修复动作 | 用一张灰图配「暂无数据」四个字了事 |

### 4.1 管理端详情字段行（2026-10-16，WS-381）

用户确认机构审核详情（`353cfcc`）后，要求「写入项目组件规范，并应用于管理端其他模块」。本节将该局部做法提升为管理端只读事实字段的共用组件，不改变各模块的分区、摘要、审核栏、路由、权限、字段或交互流程。当前实现唯一来源为 [base.css](../base.css) 的 `.ops-facts-*`；机构审核已移除原有私有栅格与断点定义。

| 部件 | 标准 |
| --- | --- |
| 语义结构 | `.ops-facts-region` 包住 `dl.ops-facts`；每对 `dt` / `dd` 在同一个 `div` 内，保持原字段顺序。显式接入，不按所有 `dl` 批量覆盖 |
| 标签 / 取值 | 标签宽136px，标签和值间距 `--sp-4`（16px）；标签用 `--ui-field-label` / `--muted` / 400，值用 `--ui-field-value` / `--text`，行高1.6。普通日期、编号、金额、百分比不额外放大；原币种、小数精度、时区、完整复制值、链接及必要披露保留 |
| 行与分隔 | 每个字段组上下 `--sp-3`（12px）；行间 `1px solid var(--row-line)`，第一行不加顶线，不加字段独立卡片或虚线框；两栏间距 `--sp-6`（24px）。整行字段之后的下一行仍有分隔 |
| 容器响应 | 按已经扣除卡片内距的 `.ops-facts-region` 内容宽度查询：≥762px 双列，433～761px 单列且标签 / 值同行，≤432px 标签在上 / 值在下、间距8px。762px内容宽度对应机构审核原810px主列（左右内距各24px），不能直接用屏幕宽度代替 |
| 长字段 | 原本跨行的地址、证据、原因等通过 `.ops-fact-wide` 占整行；普通长值在本字段内换行，不截断资料或挤压相邻字段。是否占整行只影响呈现，不重命名或重排业务字段 |
| 账户资料变体 | `.ops-facts-single` 固定单列；`.ops-facts-actions` 保留第三列原位修改动作。窄容器下动作放在值后、与字段同一组，原键盘顺序及再认证入口不变。账户偏好仍为原有表单 |
| 卡片与状态 | 标题、区块顺序、表单、状态说明及操作区域继续按模块组合。独立事实内容可用 `.ops-facts-body` 提供上下8px及原卡片横向内距；不把整个页面变为事实栅格。项目、质押详情在≤1100px时将审核栏按原DOM顺序放到主区之后，避免固定侧栏将资料列挤至不可读；不影响列表。加载、失败、只读、无权限沿用模块真实分支 |
| 边界 | 只读详情使用轻实线；上传区与表单内只读控件的虚线继续按[共享规范 §4.2](共享组件视觉规范.md#42-文本输入只读与必填标识项目共用)。事件时间线、变更对照、记录表、编辑表单及办理弹层不自动接入 |

新页面按以下结构使用，业务值继续由所属模块按原规则生成与转义：

```html
<div class="ops-facts-region">
  <dl class="ops-facts">
    <div><dt>字段标签</dt><dd>完整字段值</dd></div>
    <div class="ops-fact-wide"><dt>长字段</dt><dd>完整地址或说明</dd></div>
  </dl>
</div>
```

本次适配覆盖（`existing-system adaptation / console`）：

| 模块 | 接入范围 | 保持原组合及原因 |
| --- | --- | --- |
| 01 账户与登录 | 账户设置的账号信息，单列原位操作变体 | 登录 / 首登 / 找回与改密等为表单；偏好区是可编辑控件，均不转为只读字段 |
| 02 融资参数配置 | 代币类型详情的当前参数六项 | 参数变更记录保留表格，维护及保存确认保留表单 / 前后对照 |
| 03 协议管理 | 协议定义、独立协议版本详情（含条件出现的取消及来源版本字段） | 文件预览、版本历史、操作进度及调整对照保留各自组合 |
| 04 项目合约管理 | 创建信息、发布方与参数上下文、质押合约与部署事实、失败事实 | 摘要与审核栏不改；合约台账仍是列表，进入后沿用同一项目详情；操作记录和办理弹层保持原状 |
| 05 资金方机构认证审核 | 提交信息、机构资料、已有审核结论迁入同一共享实现 | 原材料文件行、记录时间线、单步驳回与通过确认保留 |
| 06 代币质押审核 | 申请概览、项目参数、代币事实、链上事实、终态结论与凭据字段 | 关联批次 / 申请保留表格，协议文件、记录时间线及办理弹层保留 |
| 07 消息通知 | 不转成字段栅格 | 消息详情是标题、元信息、正文及关联业务动作的连续阅读页，保留既有阅读组合，无需增加成组字段 |

源码与离线导出件检查中英文、1280 / 1440 / 1920px，以及共享字段的1024 / 768 / 390 / 320px缩窄表现、长值换行和必要的原操作入口。窄屏检查不扩大各模块的业务端适用合同；全量后端、链上与通知验收不在本次 UI 覆盖内。

## 5. 角色与权限

- **本期运营端只有「运营管理员」一个角色，所有运营账号权限一致**（用户 2026-10-08 口径）：登录后入口不按角色收敛，产品内没有角色选择与授权界面，账户设置也不展示权限清单。后期新增角色时按下列规则恢复差异演示。
- 角色差异通过**可达的视图**体现：菜单、列集、操作、权限都要真的变。演示本期不存在的角色时，一律标注为「后期角色预览」，不在产品画面里冒充当前角色。
- 越权写必须有可见反馈——按钮禁用并给原因，或提交后给明确拒绝提示，不是静默无事发生。
- 双人复核仅在对应模块明确要求时演示；不能据通用形态为 WS-358 增加查询岗、处置岗或复核岗。
- 处置类权限缺少配套查询权限时，动作被拒绝并说明须由建设方修正交付配置，不静默通过也不自动补授权。
- 同一业务模块只要还有一项可读能力，其入口仍须可达；能看到入口不等于能读取目标，目标权限在进入后单独判定。

## 6. 必须覆盖的状态

默认 · 加载中 · 空数据 · 筛选无结果 · 加载失败可重试 · 无权限 · 提交中 · 提交失败 · 异步等待接口返回。只实现该功能实际适用的那些。

## 7. 响应式验收

运营端默认验收 1280 / 1440 / 1920 三档：无横向溢出、侧栏不压内容、操作列可达、无控件被裁。核对两端同级组件 computed style、普通值 / 日期 / 字母层级、焦点与弹层头尾。模块已确认的响应式范围优先：运营端账户与登录同时保留 375 / 414 / 768；其余模块不据此自动扩大范围。

| 密码框 | 眼睛／划线眼睛图标切换；动态无障碍名称说明下一步动作。保留输入值和键盘焦点，不用“显示／隐藏”文字占据框内空间 |
| 密码反馈 | 规则就近展示；确认密码不一致时就地提示并阻止提交，修改任一输入使两者匹配后清除。空错误区不占额外一行，错误出现时展开；提交失败后定位首个错误字段 |

| 账户设置 | 整页纵向两组：账号信息在上，偏好信息在下，不改回左右布局。保留邮箱、姓名、角色、状态、密码、最近登录与创建时间；不展示已开通权限清单 |
| 分区导航 | 账号信息／偏好信息用于跳转到同页分区，两组同时存在；不是互斥 tab 面板。键盘激活后焦点到达目标分区 |
| 邮箱与密码修改 | 账户页文字操作进入居中弹窗；再认证后进入编辑，人机校验结束回到当前编辑上下文。沿用共享弹层、关闭和焦点约束，不改为抽屉或新增菜单 |
| 偏好与角色 | 语言、时区在下方偏好区修改；两类角色共用本人账户页面，权限差异由可用功能与实际校验体现，不增设账号授权管理界面或 SPV 专属账号 |
| 运营落点 | 普通登录进入现有运营总览或恢复原受保护页面；首登先改密。面客端资产广场默认入口不适用于运营端；账户设置仍由账号菜单进入 |

## 14. 运营端融资参数配置：本批新建组合

本节由 WS-388 现行三册正文（`e95d198`）与 2026-10-12 修订原型整理，实现见 [模块说明](../../运营端/02-融资参数配置/README.md)、[页面组合](../../运营端/02-融资参数配置/融资参数配置.html) 与 [交互](../../运营端/02-融资参数配置/融资参数配置.js)。本模块形态与协议管理的「台账 → 详情 → 维护」最接近，但业务规则以本册正文为准，不套用协议的版本、草稿与发布语义。

| 页面 / 组件 | 组合与关联约定 |
| --- | --- |
| 入口与层级 | 一个侧栏条目「融资参数配置」，落地页为融资参数列表（一级页面、不展示面包屑）；代币类型参数详情与参数维护是独立可寻址页面，沿真实父级链展示面包屑并原路返回，保留原筛选、排序、分页与所在位置。三页共用同一侧栏选中态（菜单条目的 `pages`） |

| 四类空结果 | 上游暂无代币类型（不给新增入口）、筛选无匹配（给重置）、取数失败（可重试且保留条件）分别表达，不互相冒充；无查询权限空态保留给后续细分角色，本期单一角色下不出现 |
