# 文件上传与展示组件规范

适用于管理端与面客端的文件选择、上传结果、核对页及只读详情。依据 WS-358 用户 `3393b5a2-a7ac-4e57-9c00-6984ee309c26` 和 WS-359 已确认文件行整理；不改变各模块的材料要求、权限及上传阈值。

## 统一结构

- 字段名称及必填标记由表单承载。空态显示“选择文件”，仅在业务已确认时显示格式、大小、数量限制；不拿预览支持格式当上传白名单。
- 选件后统一使用 [file-row.js](../file-row.js) 的 `CF.fileRow(file)`，样式位于 [base.css](../base.css)。左侧完整文件名、材料名称/大小、状态；右侧操作组。长文件名换行，不挤掉按钮；窄屏操作组换行到文件信息下方。
- 上传完成、核对页、详情页复用同一文件行，不再把文件名作为普通字段值或另造“查看材料”按钮。字段所属分区和页面原有布局保持。
- 操作统一为小号次要按钮，固定顺序：**预览、下载、重试、替换、移除**；按当前能力及状态筛选，不为不可用动作留假按钮。上传主入口仍使用“选择文件”。

## 多份材料集合

- 一个材料槽位可以承载多份文件时，按文件逐行渲染同一文件行，分区标题标注份数；不把多份文件压成一个字段值，也不为第二份另建入口。
- 新增文件追加到集合，替换与移除只作用于被操作的那一件，其余文件与已填字段保留；上传中与失败的单件在行内各自表达。空集合回到“选择文件”空态。
- 提交门槛按集合判定：至少一份成功且可读取，且本次拟提交的文件全部成功；仍在上传或失败的文件须成功、移除或替换后才可提交，校验错误定位到材料区而不是某一行。
- 只读侧（核对、当前详情、运营详情）展示同一集合，单件读取失败只影响该件并可重试，其余文件照常预览 / 下载。

## 状态与动作

| 状态 | 文件信息与反馈 | 可用动作 |
| --- | --- | --- |
| 未选择 | 保留材料槽位及必要提示 | 选择文件 |
| 上传中 | 文件名、大小、上传中及进度；没有真实百分比时用不定进度 | 适用时可移除取消；不提供预览/下载，不重复发起替换 |
| 上传失败 | 文件行内原因，其他字段及文件信息保留 | 重试、替换、移除；未成功文件不算已提交材料 |
| 已上传且可预览 | 文件名、材料名称/大小、已上传 | 预览、下载；可编辑草稿另有替换、移除 |
| 已上传但不可预览 | 同一文件行；不隐藏文件 | 下载；不展示禁用的预览占位 |
| 正在提交/结果待确认 | 保留文件行和明确状态 | 按提交锁禁用编辑与重复操作，不把未知结果当失败或成功 |
| 当前已提交/审核中/结论详情 | 展示当前已提交的文件，草稿不能覆盖 | 预览、下载；不出现替换、移除 |
| 原件不可得/下载失败 | 明确未完成读取，不提示下载成功 | 保留重试读取入口；不把加载失败写成未上传 |

预览失败与不支持预览不同：前者给出重试，下载仍可用时保留下载。关闭、Escape 或返回预览必须保留原表单值、所选文件、当前对象和滚动位置，焦点返回原预览入口；不触发放弃草稿。取消系统文件选择器保持原选件；替换后删除时，迟到上传回调不能恢复已删除文件。

每次预览、下载、替换、移除都由调用方重验身份、归属和状态。组件不授予权限、不推断文件保留政策；WS-358 仅最新已提交材料可读，记录节点没有旧材料入口。

## 接口与可访问性

`key/name/state/status` 指定身份及状态文案；`meta` 展示材料类别/大小；`previewable` 指定预览能力。`preview/download/retry/replace/remove` 传 `{act,value,disabled?}`，`disabled` 可整体禁用动作，`error` 提供文件行错误。

组件仅渲染，统一转义名称及属性；文件 IO、上传校验、权限、异步失效、错误恢复与焦点还原归调用模块。状态通过文字和 `role="status"` 表达，错误使用 `role="alert"`，按钮可键盘访问且包含文件名的可访问名称，不只依赖图标或颜色。

- WS-359：沿用已接入文件行，新增参数均为可选，不改变其既定文件数量/格式/大小限制与预览行为。
- 本原型内置材料可预览示意并下载明确标记为演示的 PDF。本地选件继续只保留名称、大小和模拟上传状态，不上传/持久化原件；读取不可得时给出反馈，不伪造用户原件或成功下载。真实文件服务与鉴权需后续接入。
