# 我的控制台：列表与独立详情

WS-355，2026-09-20。承接用户“精简字段下的内容、列表进入详情、快捷操作跳借贷广场”的反馈，以及 V1.1 正文与图册；源码读取基线为 `6ee539526dc0328e87fa6d81bce4f1758896eb52`。本规范补齐本模块的已确认方向，不反向覆盖其他模块布局，也不修改业务 PRD。

## 列表信息层级

列表负责识别、比较与发现待办。每个单元格承载一个主值，至多加一条必要识别信息；主状态旁可显示暂缓放款、重传盖章件、逾期等影响操作的短标识。历史原因、完整条款、账户和记录移到详情。

| 清单 | 独立字段 | 留在详情的信息 |
| --- | --- | --- |
| 代币 | 编号、数量、价值、代币状态、质押状态、应收账款到期日、所属项目 | 买方、完整账期、签发时间及关联信息 |
| 融资项目 | 名称/编号、状态、需求金额、融资余额、覆盖状态、项目截止日 | 质押统计、五项融资指标、覆盖缺口、追加价值、失效代币、融资轮次 |
| 授信 | 编号/对方企业、额度、可用额度、状态、有效期 | 本金占用、在途报价、已用合计、首次核定、资金方内部备注 |
| 放款 | 业务编号/对方企业、融资金额、结算币种、状态、确认时限 | 需求/项目关联、商务条款、合同摘要、处置原因、实际放款记录、收款账户 |
| 还款 | 业务/期次、应还日、本金、利息、合计、状态、办理时限 | 稳定期次编号、计息区间、定稿信息、结算金额、记录、收款账户、其他期次 |
| 报价 | 业务/需求、项目、资产方、融资金额、状态、报价有效期 | 锁定信息、完整报价条款、汇率快照、当前覆盖、后续放款记录 |

金额列的 USD 放在表头，结算币种单独展示；详情中金额随值标注币种。不同性质的金额不靠同一单元格里多行无标签数字表达。原始完整编号可复制；视觉换行不截断数据。

## 页面与组件继承

- 列表 `P-MC-01`：公共 `portal` 壳层、同卡 tabs/筛选/列表/分页。保留 20/50/100 条分页，不套用广场的连续追加。
- 六类详情 `P-MC-02`～`P-MC-07`：分别为代币、项目、授信、放款、还款期次、报价；登记为控制台子级，不进入主导航。
- 详情复用 `.detail-layout`、`.detail-stack`、`.detail-section`、`.detail-rail`、`.detail-index`、`.detail-actions`；主内容按对象分组，右栏提供快捷操作和页内定位。窄屏收为单列，详情使用外页自然滚动。
- 列表主链接和“查看详情”均进入独立页面，整行和键盘 Enter/空格可打开；不再用行内展开代替完整详情。链接支持另开页。
- 表格在窄屏改成带字段标签的卡片，状态、金额、时限和操作保留。适用但暂不可操作的入口置灰并说明开启时间；不适用动作不出现。
- 复用现有颜色、排版、间距、按钮、状态、空态和弹层宿主；不新增 token 或另建外壳。

## 关联与返回

默认入口为资产广场，无首页。控制台列表 → 控制台对象详情 → 借贷广场项目/操作 → 同一控制台详情 → 原列表。列表直接快捷操作 → 原列表。

详情路由为 `#/console/{tokens|projects|credits|loans|repayments|quotes}?id=...`；对象编号和返回列表快照随 URL 传递。快照保留 tab、筛选、排序、页码、每页数、内外滚动与触发行；详情快照另外保留自身滚动。父级面包屑返回列表，不重复放同义“返回上级”按钮。

跨模块 `mcReturn` 只接受登记的本地控制台路径。放款携带业务编号；还款同时携带业务编号和稳定期次编号，不能默认取首期。授信没有唯一项目关系时进入借贷广场列表。链接不赋予权限，目标业务模块再次检查当前身份、对象及可执行状态。

操作结果直接读取既有 L5–L8 演示模型。回到控制台后重新聚合；记录不再匹配原筛选时，保留筛选并显示清空筛选入口。无权、他人对象及不存在对象采用一致反馈。未登录不保留私有正文，初始计划明确区分于已生效期次。

本规范说明展示与交互组件，真实实体映射、接口鉴权、正式排序冲突、账户脱敏、客服邮箱、跨平台释放等未决业务问题仍归原 PRD。
