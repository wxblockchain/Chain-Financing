# 我的控制台：列表与独立详情

WS-355，2026-09-21，V1.3。功能输入为同轮正文与图册附件；布局采用用户“不要左右布局、点击章节滚动且导航固定可见”的明确反馈。继承当前分支 `a418374` 的公共入口、token、壳层及广场业务容器，不反向重排其他模块。

## 列表与详情分工

列表用于识别、比较及发现当前事项。单元格一个主值，可带一条必要标识；相关期次并行事实须可发现。完整条款、历史、账户摘要和记录放在详情，详细资料及办理前往借贷广场。

| 清单 | 一行对象 | 主要信息与详情分工 |
| --- | --- | --- |
| 代币 | 一个代币 | 数量、USD价值、状态与质押状态分别呈现；完整账期、买方、签发时间和关联项目在详情 |
| 融资项目 | 一个项目 | 当前申请、融资余额、覆盖与截止日；详情逐轮展示申请，区分有效/已接受报价和历史 |
| 授信 | 机构×企业 | 总额、已用、可用、状态及有效期；详情保留本金占用、在途、合计、首次核定与本机构备注 |
| 融资放款 | 一笔已接受FD | FP/FD识别、对方、融资额、约定/实际金额、状态/处理方和接受时间；LN及提交、确认事实留在详情，支持FP/FD/LN精确查找 |
| 还款 | 一笔已确认到账FD | FP为主识别、机构、本期应还、业务/计划状态、待确认情况并存；详情为整笔定稿计划，支持FP/FD/LN精确查找 |
| 报价 | 一笔本机构FD | 申请、项目、金额、业务状态及有效期；详情保留当时条款、锁定与历史结果，预计计划前往原报价 |

还款筛选按“包含该状态期次”的业务集合计算总数，不重复业务行；进入详情仍展示全部期次，标明匹配项。计划生成中不产生虚构期次或金额，全部结清保留计划而不显示0元本期应还。列表默认20条，可切换50/100条；时间排序使用V1.3已确定的各业务时间，不额外置顶。

## 单列详情组件

- 六类详情保持独立路由和公共面包屑，不进入主导航；正文复用 `.detail-stack` / `.detail-section`，不使用 `.detail-layout` / `.detail-rail` 左右组合。
- 详情页头摘要旁仅一个“前往借贷广场”（Go to lending marketplace）按钮，窄屏自然换行；各内容分区不重复广场动作。零关联或无可访问目标禁用并给出原因；读取失败另行提示。多关联用有标签的原生选择框，仅列当前主体可访问的真实关联项目，选择前禁用，不自动选择首项。控制台不出现业务表单、上传或提交确认按钮。
- `.mc-chapters` 横向章节导航固定于公共顶栏下。运行时测量顶栏及导航高度，章节滚动留出对应空间，不使用固定桌面像素猜测移动高度。
- 点击滚到章节并使标题可见；手动滚动同步当前位置，用 `aria-current="location"` 标示，键盘可操作，遵循 `prefers-reduced-motion`。窄屏仅导航自身横向滚动，正文不横向截断。
- 定稿计划以可展开期次行呈现日期、USD合计、结算金额、状态和本金标记；展开后查看本金/利息、计息区间、RP/RM及记录。多个待确认期次逐个保留阅读和原期次定位，不提供办理按钮。
- 固定导航只影响当前控制台详情；复用项目原有颜色、字号、间距、按钮、状态、空态与抽屉宿主，不新增token或第二套外壳。

## 定位与返回

列表 → 控制台详情 → 对应广场项目详情 → 同一控制台详情 → 原列表。列表只进本控制台详情，正常、空态、无结果和失败均不设广场快捷入口；保留壳层全局导航。详情唯一按钮仅携带项目及控制台返回地址，不传业务动作、不自动选择申请/报价/期次、不自动打开抽屉或办理弹窗。用户在广场继续选择业务，外部模块容器约定保持原样。

详情仍为 `#/console/{tokens|projects|credits|loans|repayments|quotes}?id=...`。还款 `id` 使用FD；旧RP编号入口解析到同笔业务并打开原期次，显式选期用 `period=RP`。原期次已结清时展示该期当前结果，不跳到下一待还期。项目申请可用 `application=FP` 定位对应轮次。

URL保存tab、筛选、编号检索、排序、页码、每页数、滚动与目标行。详情携带列表快照，跨模块携带 `mcReturn`，只接受登记的本地控制台路径。选择期次后返回保留目标期次及最新事实，记录不再匹配筛选时提示清除过滤。未知、无权或不属于该业务的RP采用统一不可用反馈。

演示主体、正式账号掩码、精度时区、末期窗口和跨平台执行等未决项仍归V1.3第5节；组件规范不裁定业务规则。


企业代币全集与统计共用完整、归属明确且按编号去重的快照，不由项目或质押子集反推。无项目和失效代币仍可阅读。控制台统计、列表、详情、计划生成中和错误态都不设刷新、刷新状态或重试取数按钮；失败给出浏览器刷新当前网址的文字指引。刷新恢复 URL 条件、对象、选定申请/期次、来源视图与已选关联项目，失效页码同步收敛；复制、章节导航、过滤分页和详情阅读操作保留。
