# 官网层组件规范

## 1. 范围

本规范面向面客端**整幅叙述页**（`layout: 'site'`），原用于首页；2026-09-20 用户已移除首页，默认进入资产广场。下文仅保留历史 site 组件参考，不作为当前产品入口要求。它管的是区块节奏与叙述型组件；具体业务页走[面客工作区组件规范](面客工作区组件规范.md)。

实现以 [`../base.css`](../base.css) 的 `.site*` 一族为准，token 以 [`../tokens.css`](../tokens.css) 为准；本文不复述数值。

官网层的核心特征：与工作区**同一根顶栏、同一套 token**，差别只在内容区——更宽的留白、更大的展示标题、叙述性的区块序列、全站页脚。

## 2. 页面形态

首页按「发现面并列」组织：页头是一段简短定位文字与入口，往下是若干条各自成带的发现面（已上架资产、在招标的融资需求），再往下是流程说明与身份路径，最后是页脚。

**发现面用列表，不用卡片网格。** 两个广场本身就是列表形态，首页的发现面是同一批数据的精简预览，用同一种语言——只是列更少、去掉表头、每行带一个进入箭头。

**禁止**：为了填首屏而编造指标、客户名、机构 logo、成交额或增长数字。没有可公开的真实数字时，换一个不需要该数字的结构，而不是放一个占位数字。

## 3. 区块

| 区块 | anatomy | 组合规则 | 禁止用法 |
| --- | --- | --- | --- |
| Hero（`.site-hero`） | eyebrow + 展示标题 + 一段说明 + 至多两个入口按钮 | 宽屏两栏：标题左、说明与入口右；窄屏收成单列。标题允许换行，用 `clamp()` 分档 | 巨型口号占满首屏而不给任何入口；同时放三个及以上同级主按钮 |
| 区块带（`.site-band`） | 段头（标题 + 一句说明 + 右侧「查看全部」）+ 内容 | 相邻带交替白底与浅灰底，靠 1px 下边线分隔 | 用彩色底或渐变分隔区块；在一条带里塞两个不相干的主题 |
| 发现面（`.mini-list`） | 精简列表：一行一条，左侧资产标识块 + 主名 + 一行副值，右侧 2 个关键值 + 箭头 | 官网层只列 3 条并给「查看全部」；窄屏主名占满一行、值改左对齐 | 把发现面做成卡片墙或运营端的高密度表格；在官网层放完整的多列表格 |
| 流程段（`.site-steps`） | 编号 + 短标题 + 一句说明，顶部一条分隔线标示进度 | 只表达顺序，不承载任何流程逻辑或状态 | 把编号当成可点的步骤器；在说明里写规则条款 |
| 身份路径（`.site-paths`） | 标题 + 三条要点 + 一个入口 | 两栏并列，窄屏单列 | 用它替代真正的注册/入驻流程页 |
| 页脚（`.site-foot`） | 品牌字标 + 一句说明 + 一行内联链接 + 一行元信息 | 全站每页都有；链接行横向排布，窄屏自然折行 | 做成四栏索引式页脚；把关键 CTA 放进低对比页脚文字 |

## 4. 叙述型排版

- 展示标题用 display 字族、更紧的字距，尺寸随视口 `clamp()`；内容层标题保持常规档位。
- 一段说明控制在 62 字符内，超出改成两段而不是拉长行长。
- 正文字号与行高由双端共享 token 承担，不在区块内另设“面客密度”。
- 结构化短值沿用 `.mono` / `.num` 角色和 tabular numbers；当前与正文共用字族，不能自行换独立等宽字体或放大普通字段。

## 5. 精简列表

- 历史发现面保留自身内容组合；容器外观继承当前共享圆角与表面 token，不为区分工作区而另造装饰阴影。
- 每行左侧是资产标识块 + 主名，下方一行副值（资产方、编号、期限一类）；右侧两个关键值各带小号列名；行尾一个箭头。
- 整行可点，hover 只做底色变化与箭头轻微右移，不做缩放、不做阴影跳变；`prefers-reduced-motion` 下取消。
- 数值使用共享字族与 tabular numbers；**文本型取值不强制等宽**，普通数字与日期继承字段字号。
- 行内不放实心按钮——一屏里出现六个实心按钮会抢走页头入口的主次；「查看全部」放段头右侧，用文字链。

## 6. 响应式

- 根节点 `overflow-x: clip`，任何一档不得出现页面级横向滚动。
- 发现面网格用 `minmax(0, 1fr)` 轨道；卡片内长值换行而不撑破轨道。
- 展示标题设 `overflow-wrap: anywhere` 与 `min-width: 0`。
- 顶栏在窄屏拆成品牌 / 主导航 / 工具区三行；主导航标签保持单行，容不下时整条横向滚动，不折行。
- 375 / 414 / 768 三档与桌面各档都要实际看过，不能只看源码。
