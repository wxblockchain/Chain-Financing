# 面客工作区组件规范

## 1. 范围与视觉口径

本规范面向面客端**业务页**（`layout: 'portal'`）：借贷广场、资产广场、我的控制台、账户与机构信息，以及由它们带出的详情与流程承载单元。

实现以 [`../base.css`](../base.css) 的 `.portal*` 与公共组件为准，token 以 [`../tokens.css`](../tokens.css) 为准；本文不复述数值。

核心特征：与官网层同一根顶栏、同一套 token，**按官网密度而不是控制台密度排布**——更高的控件、更大的正文、更松的卡片内边距，但仍然承载表格台账、抽屉与分步流程。

## 2. Shell

| 元素 | 规则 | 禁止用法 |
| --- | --- | --- |
| 顶栏 | sticky、白色表面、1px 下边线；品牌左、主导航中、工具区右。未登录时工具区是语言切换 + 登录 + 申请入驻；已登录是语言切换 + 铃铛 + 账号下拉 | 引入左侧导航；在同一页里再放第二套导航；把账户级页面塞进主导航 |
| 主导航 | 项目由登记表渲染，模块不自建菜单；标签单行不换行，容不下整条横向滚动 | 把一条流程的中间页登记成顶级导航项 |
| 面包屑 | 顶栏下独立一条，只有「首页 / 当前页」两级 | 用面包屑表达流程进度 |
| 内容容器 | 居中于宽容器，两侧安全边距；窄屏收紧 | 使用 `100vw` 造成滚动条溢出 |
| 右栏（`.portal-cols` + `.portal-rail`） | 主内容 + 右侧辅助列，辅助列吸顶；窄屏收成单列且不再吸顶 | 用右栏堆放与主内容无关的推广 |
| 页脚 | 与官网层同一个页脚，业务页同样带 | 业务页省掉页脚 |

## 3. 未登录态

这是面客端的常态之一，不是异常分支。

- **信息不因未登录而隐藏**：列表列、详情字段、状态、时间一条不少。
- **动作按钮保留在原位并禁用**，旁边给出简短原因（「登录后可提交报价」），不隐藏、不移除。
- 页面顶部给一条常驻提示说明「本页信息全量公开，登录后即可操作」，并带一个登录入口。
- 未登录访客点任何受限动作，落到登录，而不是静默失败。

## 4. 基础组件

| 组件 | anatomy / 尺寸 | variants 与状态 | 禁止用法 |
| --- | --- | --- | --- |
| Button | 图标（可选）+ 单行标签，高度取面客端控件高，触控区不小于 44px | primary、secondary、ghost、sm；loading 保留可读标签 | 一个信息区里多个同级 primary；长标签换行 |
| Input / Select | label 在上，控件高与圆角取 token | default、hover、focus、error、disabled | 用 placeholder 代替 label；为了好看移除 select 的键盘能力 |
| 语言切换 | 地球图标 + 当前语言缩写的胶囊下拉 | 当前项带选中标记 | 用国旗表示语言 |
| Tag / 状态标记 | 色点 + 短文本 | neutral / accent / positive / warning / danger / violet | 用多枚彩色标记代替信息层级 |
| 链上值 | mono + 专用底色与描边 | — | 用它装普通业务文本 |
| 文字链 CTA | accent 文本 + 箭头，hover 时箭头轻微右移 | hover、focus-visible | 小于 44px 的独立触控目标 |

## 5. 数据展示

| 组件 | 布局 | 组合规则 |
| --- | --- | --- |
| 头部汇总 | 小号 label + 大号 mono 值 + 一行单位/辅助说明；下方一行口径标注 | 2–4 列，小屏 1 列；只放 PRD 点名的指标，不自造 KPI。**空态显示 0，不隐藏整块**；折算类数值必须在旁标注折算口径 |
| 资产标识块 | 24×24 圆角方形首字母块 + 名称 | 没有 logo 时用首字母块兜底，**不用通用占位图**；标识块取有区分度的字符，整列一模一样等于没有信息 |
| 筛选条 | 与表格同卡，字段左、动作右 | 字段与 PRD 的筛选字段一一对应；窄屏字段占满一行、动作按钮等分 |
| 可排序列头 | 整格可点的按钮，当前排序列显示方向箭头并写 `aria-sort` | 只给 PRD 允许排序的列；默认排序键与方向跟 PRD；精确值排序，不区间化 |
| 数据表 | 浅色表头、右对齐数值与结构化值、固定操作列 | **窄屏转卡片式**：表头隐藏，每格靠 `data-label` 回填列名，一个单元格里的主值与副值上下堆叠。不横向截断关键内容 |
| 分页 | 左侧总数、右侧页码 | 总数必须给；上一页/下一页在边界禁用 |
| 详情组 | key / value 两列对齐 | 长值换行而不挤压 label；短值可用 mono |
| 空态 | 标题 + 一句原因 + 可选修复动作 | 区分「暂无数据」与「筛选无结果」，后者给「清空筛选」 |

## 6. 反馈与浮层

| 组件 | 布局 | 行为 |
| --- | --- | --- |
| 抽屉 | 右侧定宽；**640px 以下转全屏** | 遮罩、Escape、关闭按钮均可退出；打开后焦点进入内容 |
| 弹窗 | 居中、展示级圆角、内容可滚动 | 层级高于抽屉——二次确认是从抽屉里点出来的 |
| Toast | 视口底部居中、深色小表面 | 短句，可自动消退，不抢焦点 |
| 行内提示 | 左侧强调线 + 浅色语义底 | 信息 / 提示 / 错误 / 成功都配文字，不只用色带；错误带 `role="alert"` |
| 骨架屏 | 与最终内容形状一致 | 带 `role="status"` 与可读标签，避免页面跳动 |

## 7. 必须覆盖的状态

默认 · 加载中 · 空数据 · 筛选无结果 · 加载失败可重试 · 无权限 · 未登录 · 提交中 · 提交失败。全局空态与筛选空态**必须可区分**，后者提供「重置筛选」。只实现该功能实际适用的那些；一个在覆盖表里出现却在原型里到不了的状态算缺口，不算细节。

## 8. 响应式验收

375 / 414 / 768 / 1280 / 1440 / 1920 全验：无页面级横向滚动、操作列可达、抽屉在窄屏全屏、表格已转卡片、触控控件不小于 44px、焦点环可见。
