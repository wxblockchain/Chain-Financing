## 1. 范围与视觉口径

本规范面向面客端**业务页**（`layout: 'portal'`）：借贷广场、资产广场、我的控制台、账户与机构信息，以及由它们带出的详情与流程承载单元。

实现以 [`../base.css`](../base.css) 的 `.portal*` 与公共组件为准，token 以 [`../tokens.css`](../tokens.css) 为准；本文不复述数值。

核心特征：采用顶栏工作区，与运营端共用同一套 token、字体和同级组件规格。密度按普通表单、紧凑筛选、清单、统计等角色区分，不按端别额外放大正文或控件；模块保留各自表格、详情与办理布局。

## 3. 未登录态与登录未绑定角色

两者都是面客端的常态，不是异常分支。可见范围一致，差异只在能否退出，以及触发业务动作后的去向。

- 主导航只显示当前状态可用的入口：我的控制台等需绑定角色的页面在这两种状态下隐藏，绑定后出现。
- 可达路由直接渲染内容，不跳登录、不弹登录墙；字段按最新 PRD 权限矩阵显示或脱敏，不承诺全量公开。
- 需绑定角色的页面仍可由深链、回跳或评审目录打开：未登录时展示该页自身的登录引导；登录未绑定角色时说明「该页面不适用于当前身份」并给可继续浏览的出口，不再提示登录，也不伪造已登录视图。
- 受限动作保留在原位并置灰，仍可聚焦、可点击并读出受限原因；点击按当前状态给引导——未登录唤起钱包登录，登录未绑定角色按动作归属分流（资产方动作引导去上游注册认证，资金方动作进入入驻流程），不执行原业务操作，也不提供选择角色的入口。
- 登录提示仅在用户主动点击右上角「登录」，或触发受限操作时出现；**不放常驻登录提示条**。
- 已绑定角色但信息未补齐时使用 `C-L03` 壳层补全提示条：可折叠、不可永久关闭；最多一条，其余以计数与清单表达，与游客登录提示区分。登录未绑定角色没有本平台账户，不出补全提示条。

### 5.1 内嵌布局与数据加载必须分别决定

**内嵌布局是容器契约，连续追加是加载契约。** 资产广场已按 `fc8c529` PRD 四册统一为内嵌连续追加，不存在分页例外。两个广场都继承内嵌母版；具体断点行为按最新业务 PRD 核对。

| 维度 | 规则 |
| --- | --- |
| 广场桌面容器 | `.listzone` 组合筛选与清单，筛选在列表内滚区域之外；表格 / 卡片视图共享内嵌加载与恢复范围，容器高度按现有 `market.css` 和 `--list-h`。不强制套一张外层 card，也不补虚假数据 |
| 框内滚动 | 只滚动列表内容，表头在框内吸顶；页头、汇总、筛选的位置不随框内滚动改变。滚轮到框边界不连带滚动外页 |
| 外页滚动 | 默认态保留自身滚动，以访问标题、汇总和页脚；“不跟着滚走”只指框内滚动，不代表这些区域在任何外页滚动下都固定。资产列表页内展开时锁定外页并继续框内滚动；顶栏的 sticky 行为仍归 shell |
| 键盘 | 列表区域可聚焦并有可访问名称；方向键 / PageDown 可滚动。不能为了防滚动穿透而禁用页面或键盘滚动 |
| 窄屏 | 资产广场启用 `.listbox.listbox-contained`，全部断点保持内嵌滚动；卡片列数与表格转卡断点按当前 `market.css`，网络与原业务信息仍可得。转卡片不改变滚动归属，其他模块不擅自扩展为同一种滚动合同 |
| 独立详情 | 完整详情走外页滚动；项目内部固定记录模块沿用现有局部内滚，不把整个详情放进列表框。返回列表恢复原视图与位置 |

加载策略与容器布局分开记录：

| 策略 | 当前适用与行为 |
| --- | --- |
| 样板滚动加载 | 两个广场样板每批 20 条；尾部在 `.listbox` 内。滚到底自动追加，保留可聚焦的「加载更多」及已显示数量；全部加载后显示末尾状态。按钮不能吸底；资产广场所有宽度以列表框滚动为触发，不以外页滚动触发；其他样板按其滚动容器确定 root；追加后保住内外位置 |
| 分页台账 | 我的控制台、运营端台账使用总数 / 页码 / 上下页，边界禁用 |
| 资产广场业务连续追加（WS-350） | `F-AM-05` / `AC-AM-30` 及用户 2026-09-20 反馈：首批20条，内嵌下滑至末端自动追加20条，末批只取余量；正常状态不放「加载更多」按钮，也不放分页器、页码跳转或批量大小开关。首批骨架与汇总同批完成；追加中/失败均保留已有记录和位置，仅失败在末尾提供重试本批按钮，不自动循环失败请求；末尾无更多时停止追加。汇总始终对应筛选全集，不随已加载条数累加。正常加载不能依赖点击，须实测滚轮、触屏上滑和键盘连续下滚 |

位置规则：筛选、搜索、换排序、重置回到新结果首批顶部；普通重绘与追加保持当前内外位置。URL 包含筛选、排序、关键词、已加载范围及可恢复的滚动定位（如记录锚点与偏移），不以页码表示进度。刷新、**新会话打开分享链接**、前进后退、详情返回均先恢复范围再恢复位置，并能继续无重复追加；无恢复参数时从首批顶部进入。本地缓存只能作为优化，不能作为分享恢复的唯一依据。条件变化时取消或隔离旧请求，防止旧批次串入新条件。


### 5.2 资产广场编号与整行交互（2026-09-20）

资产广场默认为网络、代币、编号、发行方、数量、价值、状态七项，页内放大补代币类型与铸造时间为九项；两种视图均不展示质押状态和账期，详情资料保留账期。完整代币编号本身是可聚焦的文字按钮，鼠标、Enter、Space 复制完整值，必须阻止行跳转，并等待复制结果后显示成功或失败。列表不加第二个复制按钮；编号外其他区域含标识可进入详情，整行聚焦可由 Enter/Space 激活。复制动作和行导航必须分别做浏览器断言，不能只检验 onclick 源码。

三项汇总以筛选、搜索匹配全集统计，含失效代币：代币数量与其中失效分别对对应记录的代币数量求和（单位「枚」、两位小数），代币价值对各笔签发 USD 价值求和，均不能使用记录数、地址数或项目数。加载追加时不累加汇总；首批读取失败时三项给横线，不保留上一次的数字。当前 `F-AM-03` 按默认 / 放大信息分层，列序与数量单位见[共享规范 §8.1](共享组件视觉规范.md#81-列表信息密度与筛选)。共享 `market.css` 的卡片与列宽规则按列序书写，增删列时须同步。详情占满现有 portal 内容区，无辅助内容时不留右栏。排序依据含铸造时间、代币价值和账期到期日；账期不在列表信息项里，其排序由独立排序控件承载，不靠表头。来源、版本与待同步业务条款见[资产广场 README](../../面客端/03-资产广场/README.md)及[同步清单](../../面客端/03-资产广场/本轮反馈与PRD同步清单.md)。

### 5.3 资产广场持有方清单（2026-10-15）

详情第五区块为持有方清单，公共 `.tbl.resp` 每个持有方一行：持有方（地址）、持有数量、对应价值、质押状态、所属融资项目；按持有数量从多到少，同量按地址。该表随详情外页滚动，不继承主列表的定高内滚；窄屏按同序转卡片，五项不隐藏。地址前6后4缩略，原生按钮复制完整值并反馈结果；质押状态与所属项目在同一行，同一笔代币的不同行可分属不同项目。质押状态只在此处出现，列表与概览不展示。

一笔代币可以有多个持有方，持有数量之和等于代币数量；`Q-AM-56` 仍保留真实事实供给依赖。持有方（代币发行平台）与质押记录（借贷平台）是两个来源，按代币编号核对；异常响应只经默认关闭的演示工具制造。只呈现加载中、失败可重试、正常和「持有方信息暂不可用」四种结果：持有方为空或只有零余额、合计不等于代币数量、缺地址或数量、质押合约与记录核对不上一律收敛为不可用，不写成「暂无持有方」、不补 0 或默认未质押；多个持有方是正常情形。业务决策说明不放进产品页面。规范依据与未测边界见[模块说明](../../面客端/03-资产广场/README.md)。

## 7. 必须覆盖的状态

默认 · 加载中 · 空数据 · 筛选无结果 · 加载失败可重试 · 无权限 · 未登录 · 提交中 · 提交失败。全局空态与筛选空态**必须可区分**，后者提供「重置筛选」。只实现该功能实际适用的那些；一个在覆盖表里出现却在原型里到不了的状态算缺口，不算细节。

## 8. 响应式验收

共享主导航横向溢出时，Tab / Shift+Tab 聚焦的入口须完整滚入导航容器；容器四周保留 `--sp-1`，容纳 2px 焦点环及其 2px 外偏移。只调整导航横向滚动，不因露出入口而滚动整页，不改变导航项、顺序或路由。

粗指针设备（`pointer: coarse`）的共享主导航入口和两广场卡片 / 表格切换按钮，实际点击元素宽高均不小于 `--ctrl-h`（44px）。两广场在 ≤768px 时视图按钮使用同一 44px 高宽；桌面精细指针保留现有紧凑变体。图标与文字尺寸保持原规格，选中态与键盘操作语义不变。

320 / 375 / 414 / 768 / 1280 / 1440 / 1920 按本轮覆盖全验，并检查相关断点边界。无页面级横向滚动、操作列可达、抽屉在窄屏全屏、触控控件不小于已有最小热区、焦点环可见；同级字段 / 字体、金额单位、固定模块、吸顶标签和浮窗层级按[共享视觉规范](共享组件视觉规范.md)核对。

交付前必须在实际浏览器执行，报告浏览器、视口与结果；源码检查不能替代：

- 记录目标分支头、样板文件 commit、每页继承关系与必要例外；确认读取本规范 §0 所有入口。
- 桌面滚动列表：记录 `.listbox` 的 clientHeight / scrollHeight / scrollTop，确认确实内滚；比较页头、汇总、筛选与表头坐标，确认框内滚动时未移动。
- 内框滚到底再次滚轮，确认外页没有被带动；指针移到外页后仍能访问页脚。键盘聚焦列表后可滚动，Tab 可离开。
- 修改筛选、搜索、排序、重置，确认新结果首批回顶；验0/不足20/整20/多批末尾不足20，无重复漏项；追加中、失败重试和结束分别可达，汇总始终对应筛选全集。
- 非默认筛选下滚动，进入详情，再分别使用父级面包屑与浏览器后退/前进；核对 URL、筛选、排序、已加载范围、行锚点和偏移及内外 scrollTop。另验新会话分享打开、刷新、连续前进后退与恢复后继续追加；仅原会话缓存通过不算分享验收。
