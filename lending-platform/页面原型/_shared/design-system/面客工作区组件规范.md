## 1. 范围与视觉口径

本规范面向面客端**业务页**（`layout: 'portal'`）：借贷广场、资产广场、我的控制台、账户与机构信息，以及由它们带出的详情与流程承载单元。

实现以 [`../base.css`](../base.css) 的 `.portal*` 与公共组件为准，token 以 [`../tokens.css`](../tokens.css) 为准；本文不复述数值。

核心特征：与官网层同一根顶栏、同一套 token，**按官网密度而不是控制台密度排布**——更高的控件、更大的正文、更松的卡片内边距，但仍然承载表格台账、抽屉与分步流程。

## 2. Shell

| 元素 | 规则 | 禁止用法 |
| --- | --- | --- |
| 顶栏 | sticky、白色表面、1px 下边线；品牌左、主导航中、工具区右。未登录时工具区是语言切换 + 登录；已登录是铃铛 + 语言切换 + 账号下拉。申请入驻入口仅在资金方登录后提供，复用机构注册流程 | 引入左侧导航；在同一页里再放第二套导航；把账户级页面塞进主导航 |
| 主导航 | 项目由登记表渲染，模块不自建菜单；标签单行不换行，容不下整条横向滚动 | 把一条流程的中间页登记成顶级导航项 |
| 面包屑 | 顶栏下独立一条；按「首页 › 所属列表 › 当前页」表达层级，上级为链接、当前页为非链接；通过上级层级返回，不附加「返回上级」按钮，首页不显示面包屑；窄屏保留直接上级与当前页 | 用面包屑表达流程进度 |
| 内容容器 | 居中于宽容器，两侧安全边距；窄屏收紧 | 使用 `100vw` 造成滚动条溢出 |
| 右栏（`.portal-cols` + `.portal-rail`） | 主内容 + 右侧辅助列，辅助列吸顶；窄屏收成单列且不再吸顶 | 用右栏堆放与主内容无关的推广 |
| 页脚 | 与官网层同一个页脚，业务页同样带 | 业务页省掉页脚 |

资金方账号菜单的资料入口沿用最新登录模块 `资金方账户.js@4cd04af` 的「用户信息」，账户设置和退出入口保持分开。共享壳层负责导航呈现；实际账户状态、路由和回跳由登录模块接管，独立模块只同步标签不能宣称已经完成会话集成。

## 3. 未登录态

这是面客端的常态之一，不是异常分支。

- 游客可达路由直接渲染内容，不跳登录、不弹登录墙；字段按最新 PRD 权限矩阵显示或脱敏，不承诺全量公开。
- 受限动作保留在原位并置灰，仍可聚焦、可点击并读出受限原因；点击唤起类型选择引导，不执行原业务操作。
- 登录提示仅在用户主动点击右上角「登录」，或触发受限操作时出现；**不放常驻登录提示条**。
- 已登录但信息未补齐时使用 `C-L03` 壳层补全提示条：可折叠、不可永久关闭；最多一条，其余以计数与清单表达，与游客登录提示区分。

## 4. 基础组件

| 组件 | anatomy / 尺寸 | variants 与状态 | 禁止用法 |

| 文字链 CTA | accent 文本 + 箭头，hover 时箭头轻微右移 | hover、focus-visible | 小于 44px 的独立触控目标 |

## 5. 数据展示

| 组件 | 布局 | 组合规则 |
| --- | --- | --- |
| 头部汇总 | 小号 label + 大号 mono 值 + 一行单位/辅助说明；下方一行口径标注 | 2–4 列，小屏 1 列；只放 PRD 点名的指标，不自造 KPI。**空态显示 0，不隐藏整块**；折算类数值必须在旁标注折算口径 |
| 资产标识块 | 24×24 圆角方形首字母块 + 名称 | 没有 logo 时用首字母块兜底，**不用通用占位图**；标识块取有区分度的字符，整列一模一样等于没有信息 |

| 详情组 | key / value 两列对齐 | 长值换行而不挤压 label；短值可用 mono |
| 空态 | 标题 + 一句原因 + 可选修复动作 | 区分「暂无数据」与「筛选无结果」，后者给「清空筛选」 |

### 5.1 内嵌布局与数据加载必须分别决定

**内嵌布局是容器契约，连续追加是加载契约。** 资产广场已按 `fc8c529` PRD 四册统一为内嵌连续追加，不存在分页例外。两个广场都继承内嵌母版；具体断点行为按最新业务 PRD 核对。

| 维度 | 规则 |
| --- | --- |
| 广场桌面容器 | 同一 `.card` 内，`.filters` 在 `.listbox` 外；列表用 `.tablewrap.listbox`，高度上限取 `--list-h`，由公共层负责 overflow 和 overscroll。短列表自然收高，不补虚假数据或空白占位 |
| 框内滚动 | 只滚动列表内容，表头在框内吸顶；页头、汇总、筛选的位置不随框内滚动改变。滚轮到框边界不连带滚动外页 |
| 外页滚动 | 页面仍保留自身滚动，以访问标题、汇总和页脚；“不跟着滚走”只指框内滚动，不代表这些区域在任何外页滚动下都固定。顶栏的 sticky 行为仍归 shell |
| 键盘 | 列表区域可聚焦并有可访问名称；方向键 / PageDown 可滚动。不能为了防滚动穿透而禁用页面或键盘滚动 |
| 窄屏 | 资产广场启用 `.listbox.listbox-contained`，所有断点保持内嵌滚动；≤1200px 九列改为同形摘要卡，≤600px 汇总单列。转卡片不改变滚动归属。公共 `.listbox` 未启用该修饰类的其他模块仍按各自现有规则核对，不从资产广场擅自扩展业务要求 |
| 独立详情 | 走外页滚动，不套列表内滚框；返回列表恢复原视图与位置 |

加载策略与容器布局分开记录：

| 策略 | 当前适用与行为 |
| --- | --- |
| 样板滚动加载 | 两个广场样板每批 20 条；尾部在 `.listbox` 内。滚到底自动追加，保留可聚焦的「加载更多」及已显示数量；全部加载后显示末尾状态。按钮不能吸底；资产广场所有宽度以列表框滚动为触发，不以外页滚动触发；其他样板按其滚动容器确定 root；追加后保住内外位置 |
| 分页台账 | 我的控制台、管理端台账使用总数 / 页码 / 上下页，边界禁用 |
| 资产广场业务连续追加（WS-350） | `F-AM-05` / `AC-AM-30` 及用户 2026-09-20 反馈：首批20条，内嵌下滑至末端自动追加20条，末批只取余量；正常状态不放「加载更多」按钮，也不放分页器、页码跳转或批量大小开关。首批骨架与汇总同批完成；追加中/失败均保留已有记录和位置，仅失败在末尾提供重试本批按钮，不自动循环失败请求；末尾无更多时停止追加。汇总始终对应筛选全集，不随已加载条数累加。正常加载不能依赖点击，须实测滚轮、触屏上滑和键盘连续下滚 |

位置规则：筛选、搜索、换排序、重置回到新结果首批顶部；普通重绘与追加保持当前内外位置。URL 包含筛选、排序、关键词、已加载范围及可恢复的滚动定位（如记录锚点与偏移），不以页码表示进度。刷新、**新会话打开分享链接**、前进后退、详情返回均先恢复范围再恢复位置，并能继续无重复追加；无恢复参数时从首批顶部进入。本地缓存只能作为优化，不能作为分享恢复的唯一依据。条件变化时取消或隔离旧请求，防止旧批次串入新条件。


### 5.2 资产广场编号与整行交互（2026-09-20）

资产广场当前九列，桌面表格与窄屏摘要卡均移除账期展示；详情资料保留。完整代币编号本身是可聚焦的文字按钮，鼠标、Enter、Space 复制完整值，必须阻止行跳转，并等待复制结果后显示成功或失败。列表不加第二个复制按钮；编号外其他区域含标识可进入详情，整行聚焦可由 Enter/Space 激活。复制动作和行导航必须分别做浏览器断言，不能只检验 onclick 源码。

三项汇总按 V2.1（`6f5b947`）以筛选、搜索匹配全集统计；代币数量及其中失效分别对对应记录的代币数量求和，单位「枚」、两位小数，不能使用记录数、地址数或项目数。加载追加时不累加汇总。详情占满现有 portal 内容区，无辅助内容时不留右栏。来源、版本与待同步业务条款见[资产广场 README](../../面客端/资产广场/README.md#2026-09-20--五点反馈增量)及[同步清单](../../面客端/资产广场/本轮反馈与PRD同步清单.md)。

### 5.3 资产广场持有地址表（V2.1）

详情第五区块改用公共 `.tbl.resp` 五列表：地址、持有数量、对应价值、质押状态、所属融资项目，替换旧独立质押区。该表随详情外页滚动，不继承主列表的定高内滚；窄屏按同序转卡片，五项不隐藏。地址前6后4缩略，原生按钮复制完整值并反馈结果；状态与对应项目放在同一行。

当前地址语义与分布依据尚待 `Q-AM-55/56` 裁定。默认资料不可用；虚构单地址样例只经默认关闭的演示工具开启，表旁标注演示数据。缺失、无法可靠对应及超出现有整笔单项目约束的数据均不可渲染为正常分布，不均分、不拿历史铸造到账快照填补，不影响主列表记录与汇总。加载、失败重试、完整空集合、资料不可用分别呈现，业务决策说明不放进产品页面。规范依据与未测边界见[模块说明](../../面客端/资产广场/README.md)。

## 6. 反馈与浮层

| 组件 | 布局 | 行为 |
| --- | --- | --- |
| 抽屉 | 右侧定宽；**640px 以下转全屏** | 遮罩、Escape、关闭按钮均可退出；打开后焦点进入内容 |
| 弹窗 | 居中、展示级圆角、内容可滚动 | 层级高于抽屉——二次确认是从抽屉里点出来的 |
| Toast | 视口底部居中、深色小表面 | 短句，可自动消退，不抢焦点 |
| 行内提示 | 左侧强调线 + 浅色语义底 | 信息 / 提示 / 错误 / 成功都配文字，不只用色带；错误带 `role="alert"` |
| 骨架屏 | 与最终内容形状一致 | 带 `role="status"` 与可读标签，避免页面跳动 |

## 7. 必须覆盖的状态

默认 · 加载中 · 空数据 · 筛选无结果 · 加载失败可重试 · 无权限 · 未登录 · 提交中 · 提交失败。全局空态与筛选空态**必须可区分**，后者提供「重置筛选」。只实现该功能实际适用的那些；一个在覆盖表里出现却在原型里到不了的状态算缺口，不算细节。

## 8. 响应式验收

375 / 414 / 768 / 1280 / 1440 / 1920 全验，并检查 900/901 与 768/769 断点边界。无页面级横向滚动、操作列可达、抽屉在窄屏全屏、触控控件不小于 44px、焦点环可见。

交付前必须在实际浏览器执行，报告浏览器、视口与结果；源码检查不能替代：

- 记录目标分支头、样板文件 commit、每页继承关系与必要例外；确认读取本规范 §0 所有入口。
- 桌面滚动列表：记录 `.listbox` 的 clientHeight / scrollHeight / scrollTop，确认确实内滚；比较页头、汇总、筛选与表头坐标，确认框内滚动时未移动。
- 内框滚到底再次滚轮，确认外页没有被带动；指针移到外页后仍能访问页脚。键盘聚焦列表后可滚动，Tab 可离开。
- 修改筛选、搜索、排序、重置，确认新结果首批回顶；验0/不足20/整20/多批末尾不足20，无重复漏项；追加中、失败重试和结束分别可达，汇总始终对应筛选全集。
- 非默认筛选下滚动，进入详情，再分别使用页面返回与浏览器后退/前进；核对 URL、筛选、排序、已加载范围、行锚点和偏移及内外 scrollTop。另验新会话分享打开、刷新、连续前进后退与恢复后继续追加；仅原会话缓存通过不算分享验收。
- 窄屏确认资产广场摘要卡仍在内框滚动，页头、汇总、筛选区不被带动；桌面九列与编号完整可读，不以 `overflow-x:clip` 掩盖内容溢出。
- 默认、加载、空数据、筛选无结果、失败重试、三种身份和中英切换按模块实际范围检查；演示工具默认关闭。
- 导出的单文件也执行关键路径，确认无外部资源依赖、无脚本异常。未实测项与 PRD 冲突必须明确列出，不声称全部验收通过。

### 消息中心增量

消息中心从顶栏铃铛快捷面板或账号下拉进入，不占四项主导航。消息中心是独立完整页面：所有断点均随整页滚动，不套用内置定高列表。桌面筛选栏吸顶于平台顶栏下，≤900px 筛选栏随页面流动。每批 20 条、显式「加载更多」按钮，不使用滚动哨兵；其他业务模块的滚动约定不变。详情是整页，返回保留筛选、批次与滚动位置。按用户 2026-09-20 反馈，消息列表统一白底分隔，以标题、摘要、分类/时间建立层次；已读/未读用固定位置文字标签表达，不铺整行强调色。整条消息为可聚焦链接，打开详情成功后已读；不再提供逐条标为已读按钮，保留当前筛选范围的全部已读确认。状态筛选直接切换，与分类叠加。铃铛预览采用同样的标题优先顺序。面板与角标来自壳层，页面不可私建第二套计数。
