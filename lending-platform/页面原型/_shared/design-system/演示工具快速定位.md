## 2026-10-20 · 角色与账户状态联动修订

沿用 `cly-4.0.0` 演示条与当前视觉。切换视角时，登录模块通过 `CF.review.prepareIdentity(role)` 一并准备账户：资产方默认 L3 已认证；资金方默认已注册、已认证且会话有效；访客与未绑定角色无业务资格。再次点击当前视角也可恢复其默认账户。同标签页刷新或打开其他面客入口时，已保存角色按默认账户恢复。

切换清理旧身份的认证降级、驳回、字段缺失、断连、补全提醒和待处理响应，保持原项目及业务数据库不变。资金方视角预设只在内存中构造，不覆盖本地已保存的注册申请。“更多模拟”仍可主动选择未认证、注册未提交、审核中或驳回；这些场景不会被每次页面重绘自动恢复为已认证。历史业务记录的阅读权限沿用业务规则，不因认证降级被整库删除。

企业账户与授信报价统一读取账户事实判断资格：资金方必须账户存在、未停用且认证通过；资产方必须 L3 且未降级、未驳回。界面和权限不再各自假设认证成功。

## 结构

演示条默认关闭；点击右下 **Demo tools / 演示工具** 后停靠在页面底部，不再浮在右侧盖住项目操作栏，页面底部同步让出演示条高度。

| 行 | 内容 | 说明 |
| --- | --- | --- |
| 顶行 | 演示标识、当前页面、当前对象（如项目名 · 编号 · 资产方）、页面编号；`切换页面`、`更多模拟`、`恢复默认`、关闭 | 当前位置一眼可见；页面目录与模块高级模拟收进弹层 |
| 视角 | 访客 · 未绑定角色 ｜ 资产方：企业 A、企业 B ｜ 资金方：机构 A、机构 B | 面客端第一轴。每个视角带本页关系标签，例如借贷项目详情的「项目方 / 非项目方」「当前报价方 / 出资方 / 曾报价 / 其他资金方」 |
| 本页状态 | 业务：该页的业务阶段或记录场景；显示：默认、加载中、空数据、筛选无结果、加载失败、无权限 | 当前对象已处于的阶段标“当前”；其他阶段打开处于该阶段的示例记录并标编号；无记录的阶段置灰 |

运营端没有视角行：运营身份来自其真实登录与权限。

## 行为

- **切视角留在原页原对象**：同一项目、同一列表位置下切换视角，直接对照页面差异；新视角打不开当前页时（如访客打开需登录页），落到该身份的默认入口。
- **切阶段保留视角**：从“待确认报价”切到“待放款”时仍以当前选中的机构 / 企业观看，标签按新项目重新计算。
- **第二家企业只在区分企业的页面开放**：目前为借贷广场（列表、项目详情、创建）。在其余页面企业 B / 机构 B 置灰；带着企业 B / 机构 B 进入这些页面时自动回到默认企业，并在顶行提示，避免出现不成立的数据组合。
- 切页面、切视角、切状态都会先清掉上一次注入的模拟状态；“恢复默认”只清本页模拟与局部故障，不倒转真实业务步骤、不重建演示数据库。
- 弹层、未保存编辑与进行中操作的离页保护保持不变；弹层打开期间演示条收起，不能越过未完成操作。
- `切换页面` 弹层：按模块分组列出已登记页面，可中英搜索页面名、编号与业务状态，结果可直接打开；需先从列表进入的详情置灰并说明。运营端跨文档切换时演示条保持展开。
- `更多模拟` 弹层：模块原有的请求响应、外部事件、局部故障、部署单元等复杂模拟，原有“重置示例”等告知保留。
- 键盘：Tab 顺序为顶行 → 视角 → 本页状态；Escape 先关闭弹层，再收起演示条并把焦点还给入口；选中后焦点留在刚按下的选项上。视角按钮的读屏名包含完整企业名与关系标签。
- 窄屏（≤900px）每行改为横向滑动，演示条维持约三行高度，已选中的选项自动滚入可视范围。

## 适配器约定（新增字段）

在 `CF.review.register` 既有字段（`group`、`states`、`scenarios`、`route`、`get/set/reset`、`beforeChange` 等）之外：

| 字段 | 约定 |
| --- | --- |
| `parties` | `true` 表示该页能按企业 A / B 区分呈现，视角行开放企业 B 与机构 B |
| `subject()` | 返回 `[en, zh]`，在顶行显示当前对象（如项目名 · 编号 · 资产方） |
| `perspective(key)` | `key` 为 `guest / signed / asset-a / asset-b / fund-a / fund-b`，返回 `{label:[en,zh], tone:'key'|'warn'}` 或 `null`，即该视角与当前对象的关系标签 |
| `scenarios[].current` | 当前对象是否就处于该阶段；未提供时按完整路由比对 |
| `scenarios[].sample` | 打开的示例记录编号，显示在选项上 |

演示身份对应的企业保存在 `CF.S.party = {asset, fund}`（默认 `entity-demo-a`、`fund-a`）。借贷广场的“我方项目”判定 `D.mine` 与报价侧的当前机构 `CF.CQ.fund()` 均读取它；放款、还款沿用报价侧的当事方判断，因此一起跟随视角。其余模块仍以默认企业呈现。

## 验证（实际浏览器）

- Chromium 打开面客端 6 个、运营端 7 个原型与底座样板，在 1440 与 375 宽度下展开演示条，逐个点击全部“显示”选项和所有可用业务阶段：无脚本异常、无横向溢出。
- 借贷项目详情 FP-DEMO-003（已报价待确认，机构 A 报价）：机构 A 看到完整报价条款与“等待资产方回复”；机构 B 看到“报价条款仅融资双方可见”；企业 A 看到条款与“查看并回复”；企业 B 看到“质押由资产方管理”；访客看到登录引导。切到“待放款”示例项目后视角保持，标签更新为「出资方 / 其他资金方」。
- 带机构 B 进入我的控制台时自动回到机构 A 并提示；控制台各清单场景、访客切到需登录页落入口、运营端从“切换页面”跨文档进入代币质押审核后演示条保持展开；中英文、Escape 两级关闭、焦点归还均正常。
- 375 宽度演示条高约 225px，切换页面弹层完整落在视口内。
- 真实钱包、链上执行与后端仍为本地模拟；Safari、真机与屏幕阅读器未实测。
