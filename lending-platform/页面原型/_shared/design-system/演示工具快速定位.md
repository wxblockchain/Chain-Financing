## Stage 2 · 结构与文件计划

端/角色：面客四身份、运营当前账号 · 模块：共享演示工具与现有业务适配器 · 功能点：5 个（中英检索、模块筛选、场景定位、实际位置、异常收纳）· 页面 / 状态：上表 · 视觉口径取自 `_shared/tokens.css`、`base.css`、原型评审切换规范。

面客先选身份；随后以“搜索页面或业务场景 → 模块 / 页面 → 业务场景”定位。业务场景放在首层，通用反馈与原有请求 / 外部事件放在折叠区。检索同时匹配中英页面名、编号和状态名；搜索结果可直接打开页面与适用状态。默认勾选“定位场景后收起工具”，展示完整业务页面；取消勾选可持续对照。重新定位后面板回到顶部，避免查找入口滚出视野。工具默认关闭，不取代真实产品导航。

实现仍只使用 `_shared/shell.js` 的 `CF.review` 和 `base.css`。各模块在原适配器追加 `scenarios`（标签、说明、可用性、实际路由和进入动作），数据仍由模块提供。场景入口读取现有演示记录；当前身份下没有记录时不可选，并说明原因。页面 / 状态切换保留原离页保护，拒绝切换时不清状态，不清业务数据库。

原有复杂模拟继续保留于 `.review-more-body`，不复制模块运行时、不新增导航画廊、不另建 token。平台原有布局和业务页面保持，交付附件由共享导出器重新内联。

## 运行、使用与边界

- 下载面客端或运营端 HTML 后双击打开，点击右下 **Demo tools / 演示工具**。面客端先选身份；可直接搜索“待放款”“还款”“已撤回”或页面编号，再点击结果。查找范围受“模块”筛选影响，选“全部模块”可扩大范围。
- 运营端为多个独立文档：先从页面目录或搜索进入目标模块，再检索该模块的详情与业务场景；未加载模块的内部状态不伪装成全局已加载目录。切换仍使用共享菜单及原有会话 / 权限。
- 业务状态卡片来自已有记录；记录被处理或删除后，可能没有对应场景，此时显示不可用和原因。恢复默认只清反馈注入，不倒转真实业务步骤、不重建数据库。
- 原有授信 / 报价流程起点、放款 / 还款模拟、请求响应与外部事件继续放在“高级模拟与外部事件”；它们原有的“重置示例”等告知保留。验证、签名和审核等前置流程不通过目录跳过。
- 源码复用 `_shared/shell.js` / `base.css`，场景由原模块适配器提供；文档与工具样式同步，移除借贷模块对公共面板宽度的覆盖，未建立第二套工具或 token。维护源入库，附件由 `_shared/export.py` 生成，不入库生成件。
- 范围为演示工具和接入的场景，不代表重新验收整个平台业务规则。全部数据、账户、钱包与链上事件仍为本地模拟；真实接口、Safari / Firefox、真机与屏幕阅读器未验证。
