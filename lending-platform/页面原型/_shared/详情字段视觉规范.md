# 借贷平台详情字段视觉规范

本规范对应 WS-493，适用于借贷平台既有运营端和面客端原型。维护源为本目录的 `tokens.css`、`base.css`、`shell.js` 与各模块样式；离线 HTML 由 `export.py` 生成，不作为第二份源码维护。

## 字段与网格

- 详情主体采用标签在上、值在下的排列。同一行顶部对齐，完整地址、标识、原因在自己的格内换行。文件清单、持有地址列表和表格沿用整块布局。
- 标签沿用 `--ui-field-label`（12px）、`--muted`；值沿用 `--ui-field-value`（14px）、`--text`。不增加新的色彩或字体体系。
- 运营端 `.ops-facts-region` 按内容容器宽度切换：不足 400px 为一列，400px 起两列，600px 起三列；`.ops-facts-single` 保持单列。列间距 `--sp-6`（24px），字段上下内边距 `--sp-3`（12px），标签和值间距 `--sp-1`（4px）。
- 面客端资产详情和融资项目详情沿用模块的 3 / 2 / 1 列变体；资料页和账户查看面板沿用 2 / 1 列。不能从视口宽度推断所有容器都应三列。
- 报价轮次、协议操作记录明细、融资参数配置弹窗摘要沿用已确认的左右结构。

## 完整钱包地址

`CF.addrFull(value, label)` 在本格内显示完整值。地址使用原有 `--hash-text` 和 12px 字号；去掉包围多行文字的浅色边框，避免字段区反复出现小框。

- `.addr-end` 将末四位与复制图标绑定在同一行，长地址自然折行，图标不再垂直居中悬在多行地址旁。
- 复制动作始终使用 `data-v` 中的原始完整值，显示换行不插入字符、不截断复制值。
- 桌面复制按钮为 24px；视口不超过 600px 或粗指针设备为 `--ctrl-h`（44px）。保留可访问名称与焦点轮廓。
- 合约地址、交易哈希及列表缩写沿用各自组件，不套用本钱包地址组件。

## 三行长文本

`CF.clampText(html)` 只用于现有调用位置的退回、失败、拒绝、关闭原因，不自动截断页面上的其他文字。

- 默认最多三行，超出时显示图标按钮，在原格内展开 / 收起。不超过三行的内容不出现按钮，也不预留按钮宽度。
- 隐藏按钮使用显式 `[hidden]` 规则，避免 `.btn` 的 `display` 覆盖隐藏状态。
- 先按没有按钮的整格宽度测量，避免按钮自身把本来能放下的文本挤出三行。容器尺寸变化、窗口变化及字体加载完成后重新测量。
- 按钮设置 `aria-expanded`、`aria-controls` 和随状态变化的名称。Enter / Space 使用原生按钮行为；不增加可见文字。
- 桌面按钮 24px，窄屏 / 粗指针 44px。焦点轮廓采用 `--accent`；图标旋转采用 `--dur-fast`，减少动态效果偏好下禁用过渡。
- 页面重新渲染后释放已移除节点的尺寸观察，避免旧页面节点滞留。

## 代币单位价值与代币价值变动记录

WS-598 起，代币详情同时展示原始资产价值、代币价值和代币单位价值，并在代币信息内新增代币价值变动记录。

- 代币单位价值写作 `1 COU = X USD`，按上游完整值展示，不经金额格式化，不补零、不截断。面客端套用金额组件的“数字 + 小字号币种”结构（`.mk-money.am-unit`），不带币种图标；运营端沿用 `.ta-num`。
- 代币价值按完整值计算，展示两位小数。原始资产价值放在基础资料 / 应收账款要素中，单位 USD。
- 变动记录是代币信息分组内的整块表格（`.tablewrap` + `.tbl`），按生效时间倒序，铸造那一条的调整前值显示“—”；交易哈希沿用各模块已有的缩写、复制与区块浏览器组件。
- 面客端资产详情容器宽，六项信息各占一列（`.am-history`），窄屏沿用 `.tbl.resp` 卡片化；详情分区导航增加“代币价值变动记录”锚点。
- 运营端审核详情主栏约 690px，表格合为四列（`.ta-history`）：单位价值与代币价值各一列，调整后的值为主值，调整前的值用 `.ta-meta` 作第二行。`.ta-stack` 设为 `minmax(0,1fr)`，表格不撑宽主栏。
- 加载中、读取失败可重试的画面放在演示工具中切换，不影响详情其他部分。

## 审核侧栏

机构认证详情继承前次实现：待审核、已通过、已驳回均保留 240px 侧栏和相同主栏宽度。桌面滚动时吸附在顶栏下方；900px 以下回到正常文档流。只读状态显示摘要与只读提示，可审核状态显示原有操作，不修改权限条件。
