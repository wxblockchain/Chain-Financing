## 1. 调整内容

### 1.1 字段改为“标签在上、值在下”

第 2 节列出的详情主体字段采用“标签在上、值在下”的多列网格（参考图：Financing Application Information 样式）。原本已采用上下结构的区域继续沿用；第 3 节的小块摘要保留左右结构。

```text
分组标题
标签 A                标签 B                标签 C
字段值 A              字段值 B              字段值 C

标签 D                标签 E                标签 F
长值在本格内换行      字段值 E              字段值 F
末四位 + 复制图标
```

示意图只表示桌面三列形态；实际列数按 1.2 节切换，不改变字段顺序与分组。

| 项目 | 规则 |
| --- | --- |
| 标签 | `--muted`，12 px 字段标签字号；通过位置与字号建立层级 |
| 值 | `--text`，主体字段值通常 14 px；钱包地址与紧凑区域沿用各自字号；标签与值间距 `--sp-1`（4 px） |
| 分组 | 保留原有分组标题，网格只作用于组内字段 |
| 分隔 | 去掉字段之间的横向分隔线，用行距区分 |
| 列数 | 见 1.2；运营端按容器宽度、面客端相关模块按视口宽度切换，窄屏单列 |

运营端共享字段网格的列间距为 `--sp-6`（24 px），字段上下内边距为 `--sp-3`（12 px）。面客端沿用各模块的间距变体，不将所有区域强制设为同一密度。

### 1.3 长内容的处理

1. **不跨列**：地址、哈希、合约地址、注册地址等长值都在自己的格子里换行，可以在任意字符处断开。
2. **完整值的图标跟随末尾**：需要完整展示的长地址字段将末 4 位与复制图标绑定在不换行的片段里；提供区块浏览器入口的模块继续保留原入口。列表或交易记录里的既有缩写组件保持原样，显示与复制值分别遵循各自组件约定。
3. **占满整行的只有成块内容**：文件清单、持有地址列表、表格这类内容才占满整行。运营端通过 `.ops-fact-wide` 加上内容判断实现：只有包含 `.file-row`、`ul`、`ol` 或 `table` 时才跨列。
4. **长文字收起**：退回原因、失败原因、拒绝原因、关闭原因最多显示 3 行。
   - 超出时末尾显示省略号和一个**展开图标**（向下箭头，不用文字）。
   - 点击后在原位展开全文，图标旋转为向上，再点收起。
   - 不超过 3 行的不显示图标。
   - 读屏名称在“展开全文”和“收起”之间切换，使用 `aria-expanded` 表示状态、`aria-controls` 关联正文；Enter / Space 可操作。
   - 页面顶部状态提示里如果已经完整展示了原因，那一处不收起。

`78f3cf2` 补充了两项实际修正：

- **完整钱包地址**：`CF.addrFull` 去掉包围多行地址的浅色小框，以原有 `--hash-text`、12 px 显示完整值。末四位与复制图标一起换行，图标不再垂直居中悬在多行地址旁；复制仍使用完整原始值，不插入换行字符。合约地址、哈希与列表缩写继续使用原组件。
- **短原因的隐藏状态**：项目合约的短失败原因原先会误显示展开箭头，已补显式 `[hidden]` 样式。判断溢出时先按没有按钮的整格宽度测量，避免按钮自身把文字挤出三行；容器宽度变化、窗口变化、字体加载后重新测量。不自动给其他备注或说明新增收起行为，只影响已接入 `CF.clampText` 的字段。

### 1.4 图标与键盘操作

| 组件 | 桌面 | 窄屏 / 触控 | 焦点与反馈 |
| --- | --- | --- | --- |
| `CF.addrFull` 的复制按钮 | 24 × 24 px | 视口 ≤ 600 px 或粗指针设备：44 × 44 px | 保留完整可访问名称，焦点轮廓使用 `--accent`，复制完整值 |
| 长文本展开 / 收起按钮 | 24 × 24 px | 同上：44 × 44 px | 状态与可访问名称随展开变化；不足三行时隐藏且不占位 |

展开箭头沿用项目图标与 `--dur-fast` 过渡；系统偏好减少动态效果时取消旋转过渡。以上尺寸只针对这两个共享组件，不表示所有复制 / 外链图标都统一改为该尺寸。

### 1.6 审核详情的操作栏（运营端）

借贷平台运营端的三个审核详情（代币准入审核、项目合约管理、机构认证审核）统一使用**右侧吸附操作栏**，不改为标题行按钮。原因是栏内除了按钮，还承载拦截提示和状态说明。

机构认证审核本轮补齐为与另两页一致：

| 状态 | 操作栏内容 |
| --- | --- |
| 待审核（有权限） | 申请编号、机构名称、当前状态；“通过 / 驳回” |
| 待审核（无权限） | 同上信息；“当前账号仅可查看。” |
| 已通过 / 已驳回 | 申请编号、机构名称、当前状态、结论时间；“本次提交已出具结论，仅可查看。”（原在“审核结论”卡片内，已移入操作栏，不重复显示） |

布局细节：

- 机构认证操作栏宽 240 px，滚动时吸附在顶栏下方；其余两个审核页沿用各自侧栏宽度。
- 视口 ≤ 900 px 时，操作栏排到主内容下方。
