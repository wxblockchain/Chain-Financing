## 打开与源码

直接打开 `代币质押审核.html`，默认进入英文审核队列，右上角可切中文。

- `代币质押审核.html`：沿用管理端 `app` 壳层、共享样式，仅含模块局部组合样式。
- `代币质押审核.js`：队列、独立详情、处置弹窗、状态与校验。
- `演示数据.js`：本地示例记录，无真实企业或业务数据。
- 路由登记于 `../../_shared/registry.admin.js`：`P-O-PR-01` `/ops/pledge-reviews`、`P-O-PR-02` `/ops/pledge-reviews/detail?id=…`。
- 登记表只在入口声明 `data-module="pledge-review"` 时显示本模块导航，避免未装载本模块的底座样板和相邻原型新增空菜单。

继承 `../../_shared/样板/底座样板.html` 的管理端台账和公共详情组件，使用 `tokens.css`、`base.css`、`shell.js` 的导航、语言、格式化、弹层和状态表面。详情独立寻址，保留批次关联；处置限当前笔。没有新增全局样式、第二套 token、登录流程或面客页面。

## 评审路径

队列默认待审，按提交时间升序；三项统计按笔计数，支持筛选、三列排序和共享 `PAGE_SIZE=20` 分页。相关字段在单元格内分主副行，操作列固定可达。

查看 `DEMO-PR-001`，上传协议或明确选用同批协议后通过；查看 `002` 填原因驳回，`003` 可继续待审；`004` 是同批已通过示例。不同笔材料和结论独立，审批不触发链上执行。通过后的协议只读可预览、下载。相关申请保留稳定单笔 ID 和明确再申请关联。

右下角默认关闭的演示工具可切权限、加载／空／失败表面、上传失败、提交失败／并发／撤回／结果待确认、附件失败，并推进到审核截止前一分钟或恰到截止。已生效审核不被其他笔超时回退。结果待确认先查询当前结果，避免重复裁定。

清单切换到“全部”可查看执行成功、失败、处理中、结果待核实、差异、复核作废、未发起过期、审核超时和已撤回记录。执行结果和费用均只读，人工通过历史不随执行变化重写。
