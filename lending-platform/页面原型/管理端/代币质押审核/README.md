## 本轮变化与评审路径

队列保留七列、三项统计、20 条分页；关键词和审核状态常驻，其余筛选向下展开。筛选、排序、页码及来源保存在地址，同会话往返恢复滚动与触发行焦点。关联申请查看仍位于最右列。

详情仅保留概览 / 关联申请两页签；概览按申请、代币、结论凭据、操作记录依次排列。记录改为时间线式列表，沿用 WS-358 的 9px 节点、1px 连接线、sp-6 节点间距和标题 / 元信息层次，样式在当前模块适配，不引入资金方账户业务脚本。记录仍按实际时间倒序，同时间稳定排列，事件 ID 去重。旧 `tab=activity` 地址迁移为 `tab=overview&section=activity`，聚焦底部记录并保留原队列上下文；两页签支持方向键、Home / End。

审核后进度合入操作记录，结果在节点内展示；全文原因、发起 / 完成时间、实际费用及凭据在节点下方展开，使用整个节点内容宽度，时间 / 费用采用两列信息组，长原因与文件名称可换行；右侧仅保留当前状态、入池截止和适用的等待摘要。审核历史不随执行结果被改写。`025` 成功、`026` 失败、`027` 执行中、`028` 待核实、`029` 冲突差异、`030` 复核作废、`031` 未发起过期；`029` 保留此前失败响应与后来差异，`028` 演示未知事件时间 / 操作者 / 费用及尚无完成结果。示例时间来自明示演示事实，不把渲染时刻补入缺失事件。

`001` 上传本笔 1～5 个 PDF / JPG / PNG（单个不超过 10 MB）、选填内部备注、勾选关键后果后，“通过本笔申请”直接提交，无第二次确认。提交中禁用表单和重复动作，失败保留输入，结果待确认先查询。`002` 驳回仍需 10～500 字原因及后续核对确认。`003` 保持待审，`004` 是同批已通过笔；没有同批协议快捷选用。

已上传草稿、正式协议和失效存档统一为左侧文件名 / 状态、右侧并排预览 / 下载。不支持预览时仅下载；上传中 / 失败不提供读取动作。预览关闭及 Esc 回到原表单，保留文件、备注、勾选、当前申请、滚动和触发焦点。正式文件无移除按钮，失效存档仍只读可下载。

右下角演示工具默认关闭。可切权限、页面状态、操作记录加载 / 空 / 失败、提交失败 / 并发 / 撤回 / 待确认、上传失败、附件预览失败 / 不支持 / 不可得 / 下载失败，推进审核截止、重放最新事件检查去重，或在待核实示例接收迟到成功结果；接收后保留原历史，差异示例不提供该操作。文件失败后的重试模拟下一次成功响应，不代表实际服务恢复。

## 边界

- 所有记录、上传、异步反馈、文件能力及权限均为浏览器本地模拟；刷新重置业务数据。地址仅恢复浏览上下文。没有真实鉴权、文件保管、消息投递、签名或转移，不能据此宣称跨平台联验完成。
- 审核连续 48 小时；七天入池日期仍为演示快照 / 演示运算，不裁定业务时区。已发起跨期结果归属、长期未知终结及差异关闭责任沿用 V1.3 未决边界，无手工完成、异常释放或代执行入口。

**质押链路反转。** 队列一条记录对应一笔**已上链成功**的申请：代币在审核前已由资产方以持有地址签名转入质押合约并占用。列表列改为单笔 / 代币 / 批次、资产方 / 目标项目、申请类型、代币价值、上链时间与已等待时长、审核状态、留存情况、查看；默认待审核＋上链时间升序，排序可按上链时间、已等待时长、代币价值升降序。详情新增项目参数（创建时锁定的项目质押率、项目期限、起算点与有效期至，只读）与质押链上事实（质押链 ETH、质押合约地址、代币质押前原持有地址、本笔当前去向、上链时点、质押链上凭证、本次上链 gas），并逐笔说明额度归属——计入总质押额与待审质押额的哪一分项，或已计入有效质押价值。

**审核时效整体取消。** 48 小时截止、剩余时长、倒计时、质押失败（审核超时）与对应的自动终结、统计项、演示时钟全部删除。审核状态收敛为待审核 / 通过 / 驳回 / 已撤回四类，批次汇总为四类笔数加留存摘要。右侧只保留“已等待时长”，并明写是事实陈述而非期限；队列统计第二项改为已驳回待解押笔数，第三项近 7 个自然日人工审结与上链时间区间筛选都按 UTC 自然日判定。

**入池确认整体移除，改为自助解押只读追踪。** 通过后不再有资产方确认入池、七天入池截止、入池前复核或平台执行费用；通过文案写明该张从待审质押额转出、由借贷平台按有效性判定是否计入有效质押价值、不产生平台费用也不触发链上动作（演示数据含一笔通过但底层资产已失效、未计入有效质押价值的样例）。驳回与待审撤回后的解押由资产方自己发起，运营端只在本笔操作记录里承接质押上链、人工结论、解押发起、解押成功 / 失败与对账差异，并可取得时间、操作主体、原因、gas 与质押链上凭证；没有发起、重试、强制退回或手工完成进度的入口。结果未知与迟到冲突只保留事实、保持占用并提示联系平台客服。
