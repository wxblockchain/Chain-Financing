## 本次变化

- 基本信息整页单列：协议定义在上，操作进度表在下；删除右侧版本区及独立记录页签。
- 版本历史仅四列，行内只有查看与下载；版本详情改为可寻址的独立只读页，保留刷新、往返、位置及焦点恢复。移除历史新建、编辑、发布、撤销、丢弃入口。
- 统一“更新协议”。优先载入同一待生效版本，确认前不变更文件和计划，成功不增版本行。撤销与再次发布均保留编号；正常示例不再同时放入草稿与待生效。
- 确认弹窗展示变化前后；多次调整各自保存文件、凭据、说明和计划快照，可在操作进度展开核对并按记录权限读取文件。权限不足、并发修改、已到点生效、失败重试与异常草稿冲突分别处理。
- 文件展示接入当前公共 `file-row.js`；保持原上传校验、真实本地文件下载和安全预览兜底。保留中英切换、列表筛选 / 排序 / 分页及共享菜单。

## 尚未确认的边界

- 记录权限映射仍未定，演示采用独立开关，不扩大其他角色权限。
- 下线时计划处置、公开历史访问和移除后的恢复仍未定。管理侧下线只读；本地计时器暂不处理下线记录，仅为可撤销演示行为。
- 真实协议定义、文件限制、日期筛选端点及排序缺省仍需确认。样本使用 PDF / 5 MB、模板 PDF 与 TXT / 2 MB；日期按浏览器推断账号时区含首尾日，单侧开放。样本不是上线配置。
- 其他两平台的页面与权限映射未定，本轮不复制三平台。

旧版“首版待生效标未发布”“再发布重新编号”“另建版本替换待生效”“历史回溯创建”演示分支已移除，不再列为待定规则。既有来源关联保持只读。

## 验证与限制

2026-09-21 使用 Chromium 检查生成的独立 HTML 和源码入口：85 项功能 / 状态断言、75 项布局 / 键盘断言、16 项针对性补测通过，另验证原生文件选择器替换。涵盖中英、1280 / 1440 / 1920、详情与历史往返、权限、草稿 / 待生效生命周期、确认失败、并发、到点竞争、文件校验与记录分页。浏览器无脚本错误或外部请求；源码语法和 diff 检查通过。截图和测试脚本仅内部使用。

这是页面原型，不是后端验收：权限、并发和定时为单浏览器模拟，关闭页面后不执行计划；未接真实鉴权、业务端公开读取 API、永久审计存储、三平台隔离或定时消息投递。共享消息菜单仍是既有模块样本，未声称本次协议事件已接入其投递与旧计划消息校验。上传 PDF 可下载原件，内置 PDF 以安全文本预览；未集成完整 PDF 版式渲染器。前端格式校验不替代服务端解析和文件安全检查。未验证其他浏览器和性能目标，不宣称支持 1280 以下布局。

本期不新增在线正文编辑、正文多语种、协议定义维护、手动归档、复核、强制重新同意、邮件或面客交互。
