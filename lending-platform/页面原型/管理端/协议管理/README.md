## 本次变化

- 会话与功能权限改读运营端账户与登录一处登记：页面加载 `CF.deferOpsBoot` + `账户与登录.js`，模块自带的 `permission`／`audit` 假数据删除。协议当前内容与工作版本读 `PM-AL-09`、维护读 `PM-AL-10`、发布读 `PM-AL-11`、历史版本读 `PM-AL-15`（仅管理员）、操作记录读 `PM-AL-16`（管理员与专员固定开通，不以 `PM-AL-09` 为前提）。
- 登录失效进入共享运营登录页，重新登录后回到原来的列表、详情或办理页；未登录时不保留业务画布上的旧内容。
- 无权限与缺配套查询权限分开表达：未开通查询给空态；已开通维护或发布却缺查询时给拒绝说明并指明由建设方修正交付配置，不静默通过、不自动补授权。
- 只有操作记录权的账号入口仍可达，得到的是协议名称、协议标识、协议上线状态与该协议的完整操作记录，不带出协议定义、正文与版本历史。
- 版本历史页签仅管理员出现；已归档与已取消版本的版本详情、被替换文件的预览、下载与文件内容指纹同样仅管理员可读。专员从协议定义末尾的只读入口进入当前生效版本与工作版本。
- 共享消息铃铛在本模块正常显示，`adminContext` 里的 `hideNotifications` 删除；账户菜单显示本人真实邮箱与角色。
- 版本状态补“已取消”：协议下线时未生效版本转已取消、已生效版本转已归档，版本详情增加取消时间、取消前状态与取消原因，操作进度补下线、关联计划取消与自动归档三条系统记录。
- 业务名称按[字段命名与术语对照表](../../../PRD/00-字段命名与术语对照表.md)第 7 节统一：协议标识、协议名称（中／英）、协议类型编码、协议类型名称、协议用途说明、适用业务环节、允许上传格式、单文件大小上限、协议上线状态、默认排序值、需重新同意标记、文件内容指纹、操作类型、关联版本；列表列与筛选条件统一为协议类型／适用业务环节／协议状态。
- 演示工具改为切换演示账号（运营管理员／运营专员）与交付的功能权限项，并可模拟会话失效；页面状态、操作进度状态、下次操作结果、定时计划与分页样本沿用。

## 继承与覆盖

视觉口径读取 `_shared/design-system/管理端组件规范.md`、`详情与跨页关联基线.md`、`文件上传与展示组件规范.md`，复用 `tokens.css`、`base.css`、`账户与登录.css`、`shell.js`、`registry.admin.js`、`admin-menu.js`、`admin-message-data.js`、`admin-notifications.js`、`puzzle.js`、`file-row.js` 与导出器。主色 `--accent`、背景 `--bg`、238px 侧栏、36px 控件、9px 控件圆角、12px 卡片圆角、24px 画布边距均沿用共享定义；本轮未修改共享样式与壳层实现。

`_shared/admin-message-data.js` 只改了一处：定时生效失败的目标由协议详情的版本历史改为基本信息——待生效版本与当前仍生效版本在基本信息同屏可得，且不依赖仅管理员的历史版本读取权。路由 `/ops/agreements/version?id=…&v=…&tab=history`、`/ops/agreements/detail?id=…&tab=basic` 与演示协议 `DEMO-SERVICE`／`DEMO-PRIVACY`／`DEMO-FIRST` 未变。`_shared/账户与登录`（运营端账户与登录模块）只增加只读的 `CF.opsAuth.held(n)`，用于区分“未开通”与“已开通但缺配套查询权限”，权限项清单仍只在该模块维护。

| 角色 / 页面 | 本次处理 |
| --- | --- |
| 运营管理员 | 查询、维护、发布、历史、记录全部固定开通；版本历史页签、历史版本详情与调整文件核对可用 |
| 运营专员（具查询） | 基本信息与当前／工作版本只读可达；无版本历史入口，历史版本详情给出说明与返回；按交付配置可再开通维护、发布 |
| 运营专员（仅记录） | 协议列表与详情只提供名称、标识、上线状态与操作记录；无协议定义、正文与版本历史 |
| 缺配套查询权限 | 列表与内容页拒绝并说明由建设方修正交付配置 |
| 登录失效 | 进入共享运营登录页，重新登录后回到原页 |
| P-O-AG-01 台账 | 九列、筛选、排序、20 / 50 / 100 分页与固定操作列 |
| P-O-AG-02 详情 | 协议定义 + 当前与工作版本只读入口 + 操作进度；版本历史按权限 |
| P-O-AG-03 更新协议 | 草稿与待生效两种模式；保存 / 发布 / 更新 / 撤销 / 丢弃、上传及校验、等待 / 失败、并发与未提交离开保护 |
| P-O-AG-04 版本详情 | 完整只读字段、下载 / 复制文件内容指纹、预览及失败兜底、缺失对象与无权限、地址和往返恢复 |
| 确认弹窗 | 发布 / 同版本调整、主动撤销、丢弃、放弃输入 / 刷新；旧计划与草稿冲突不覆盖 |
| 其他现有模块 | 保留共享菜单、消息铃铛与原实现；本轮不改其业务规则 |

演示工具默认关闭。数据、文件、人员和权限均为演示；改动保存在本浏览器，可重置。

## 尚未确认的边界

- 真实协议定义、文件限制、日期筛选端点及排序缺省仍需确认。样本使用 PDF / 5 MB、模板 PDF 与 TXT / 2 MB；日期按浏览器推断账号时区含首尾日，单侧开放。样本不是上线配置。
- 下线由建设方执行，管理侧只读；本地计时器不处理下线记录，下线留存只以演示数据呈现。
- 其他两平台的页面与权限映射未定，本轮不复制三平台。
- 公开当前版本读取是业务端能力，本原型不承载。

## 验证与限制

2026-09-25 使用 Chromium 检查源码入口与导出的独立 HTML：协议列表 / 详情 / 更新协议 / 版本详情四个页面，管理员、具查询的专员、仅记录的专员、缺配套查询权限四种配置，登录失效与重新登录回原页，草稿保存、立即发布、待生效调整确认、撤销与丢弃，版本历史与历史版本详情的权限边界，中英切换，1280 / 1440 / 1920 三个宽度无横向溢出且固定操作列可达，以及从消息模块深链进入本模块的三类协议告警目标。浏览器无脚本错误，导出件无外部请求。截图仅内部核验，不随交付提供。

这是页面原型，不是后端验收：权限、并发和定时为单浏览器模拟，关闭页面后不执行计划；未接真实鉴权、业务端公开读取 API、永久审计存储、三平台隔离或定时消息投递。上传 PDF 可下载原件，内置 PDF 以安全文本预览；未集成完整 PDF 版式渲染器。前端格式校验不替代服务端解析和文件安全检查。未验证其他浏览器和性能目标，不宣称支持 1280 以下布局。

本期不新增在线正文编辑、正文多语种、协议定义维护、手动归档、复核、强制重新同意、邮件或面客交互。
