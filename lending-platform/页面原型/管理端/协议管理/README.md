# 运营端协议管理原型

Stage 4 · existing-system adaptation · console。依据 WS-361 的 V1.0 PRD 与《流程图与状态机》（2026-09-18 附件）。用户在 2026-09-20 明确授权直接输出原型，无需阶段确认，故合并四阶段。本目录不包含 PRD。

打开 `协议管理.html`；独立附件由公共 `_shared/export.py` 内联生成，不手工维护第二份源码。默认英文，右上角切换中文。所有协议、文件、账号、时间和权限均为演示数据；改动只保存在本浏览器。右下角演示工具默认关闭，可重置全部数据。

## 演示假设（待确认，均可撤销）

- 操作记录采用独立权限开关，演示默认开启；记录使用当时的脱敏邮箱。未据此授予全体运营人员或 SPV 权限。
- 首版仅待生效时暂标「未发布」，当前生效版本仍为「—」；此时新草稿从空白创建。
- 丢弃的编号不复用；退回的已发布草稿再次发布时使用下一个编号。旧凭据正式追溯规则仍未定；本地模拟只留动作记录，不代表后端永久审计实现。已有草稿时回溯被阻止，需先处理原草稿。
- 已下线协议保留管理侧历史，全部写操作关闭；演示计时器暂停处理其计划。公开历史读取及移除后的恢复入口未实现，不据此裁定产品规则。
- 示例目录不是上线清单：普通协议 PDF / 5 MB，模板 PDF、TXT / 2 MB。缺少真实格式、大小等定义的协议不得据此上线。日期筛选暂按账号时区含首尾日，单侧日期为开放区间；排序值使用演示顺序。
- 其他两平台的页面映射、权限与共享文档落点保持未决。本轮不复制、修改或提交 PRD，也不写回 `cly-V1.0.0`。

## 实际核验与边界

使用 Chromium 真实浏览器，通过文件路径直接打开独立 HTML。已核验英文/中文、1280/1440/1920 列表无页面横向溢出且操作列可达；详情、编辑、历史、抽屉及确认弹窗完成视觉检查。已验证查询与分页恢复、多选、文件大小/空文件/伪装扩展名、失败重试、500 字符、保存留页、未保存离开、发布替换、撤销覆盖、历史回溯、首版计划失败与生效模拟、查询/维护/发布权限、下线只读、焦点陷阱与 Escape 返回。浏览器无脚本错误，无外部网络请求。

正常、加载、无定义、筛选无结果、加载失败重试、无权限，以及上传/提交等待与失败可由正常操作或默认关闭的演示工具到达。47 条数据仅用于分页演示，行操作回到对应基础样本。

局限：内置 PDF 展示与其内容一致的安全文本预览；本地上传 PDF 下载查看，未集成完整 PDF 版式渲染器。格式检测是前端演示校验，不替代服务端解析、病毒检测和访问控制。权限、并发及定时均为单浏览器模拟，页面关闭后不执行计划；未接登录系统、业务端读取 API、三平台隔离、实际消息投递或后台调度，未测性能目标。未验证 Firefox/Safari/Edge，也不宣称支持 1280 以下布局。

本期不做：在线正文编辑、正文多语种、运营自建协议/类型、手动归档、审批复核、同意记录页、强制重新同意、邮件、面客交互或跨平台总控台。
