## 2026-09-25 · 按现行三册重建承接事件与业务目标

分类为 `existing-system adaptation / console`，在 `2cf3d46` 上按本模块现行 PRD 三册（2026-09-24 需求评审稿）修订，沿用已有的直接修订与入库授权。未改业务口径，未新增 PRD 未定义的能力。

**承接事件集重建。** 演示消息池按本册第 1 节现行登记重建为五类来源事实：全体运营为机构资料待审核，以及定时生效成功、定时生效失败、待生效计划撤销三类协议告警；本人为密码变更通知。原先泛化的“本期运营通知已发布”条目删除——本模块没有广播发布与公告编辑能力，该条目不对应任何已登记来源事件。本批废止的时点提醒（质押审核超时、报价与放款还款各类临期／超期、催办）在池内与文案中均不出现，也不因等待时长自造提醒。共享池存储键升位，旧浏览器缓存不会把旧事件带回。

**分类。** 收敛为审核待办／协议告警／账户安全，只列出本人实际有消息的分类；来源分类尚未登记时回落“其他”，合法消息不消失、不隐去。正式分类取值仍随来源共享登记未定。

**业务目标改为真实记录。** 三类目标各进真实页面，不再用示例抽屉代替：机构待审核进入机构认证审核的该申请详情并带上该模块的列表上下文；协议告警进入该协议的版本详情或协议详情，并按需另给协议操作记录入口；密码变更进入本人账户设置并保留返回原消息的入口。跨模块跳转走共享菜单的同一套导航与守卫，离线单文件版同样可达。正文之后新增“原业务关联”信息组，展示来源给出的定位事实（申请编号、机构名称、提交次数、协议名称与版本），无目标时不强造该组。

**目标逐项判权。** 消息准入仍只看运营端消息查看；目标分别按机构申请查询、协议当前内容查询、协议历史版本读取、协议操作记录查看判定，四者互不替代，权限取自共享账户模块的交付配置，本模块不另建权限清单、不自造编号。协议操作记录不以协议内容查询为前提：运营专员读到协议告警时，正文与操作记录仍可得，协议内容与历史版本给出“当前无权查看该记录”，消息本身继续可读并计数。

**目标可达性辅助判断。** 进入详情时对原业务对象做一次辅助判断，最长 3 秒；期间主按钮显示检查中，确认可达后恢复入口；超时或失败仍允许尝试进入并提示未能确认，目标页自身的权限与状态限制照常生效。静态页面目标不做该判断，列表不提前判断、不因此阻塞。

**失效与动作失效分开。** 结论已生效时说明原审核动作不再可用、保留原记录只读入口；目标删除、目标无权限、消息自身失效分别解释并停用入口；目标未登记时只说明尚未登记业务记录，不提供无效入口、不跳默认页；无目标不补“无法跳转”说明。

**版面。** 阅读卡改为纵向弹性布局，正文与“原业务关联”之间不再留固定空档，操作区贴底；新增关联信息组与目标说明的样式增量仍限定在 `_shared/base.css` 的 `.om-*`。

Chromium 核验：1280 / 1440 / 1920 三宽度的列表与详情无横向溢出、无脚本异常、无外部请求；中英切换正常。逐项走通目标可跳转、结论已生效只读、目标删除、目标无权限、消息失效、目标未登记、无目标、内容异常降级、纯文本安全、越权深链十种详情分支，以及目标检查超时后仍可尝试进入。以运营管理员与运营专员分别核验目标判权（专员保留操作记录入口）。核验铃铛预览 10 条、超过 99 的 `99+`、当前筛选跨页全部已读的确认与执行、翻页失败重试、已读标记失败保留未读、无消息权限空态与入口隐藏、会话失效回登录页、分类未登记回落，以及从消息进入账户设置后返回原消息。机构认证审核、代币质押审核、协议管理三个模块页面加载共享消息池无异常，预览内容同步。离线单文件版已重新导出核验，跨模块跳转可用、无外部请求。真实消息服务、投递时效、后台鉴权与跨平台联验仍未接入；截图仅用于内部核验。

**未在本轮定夺（按现状呈现）：** 机构认证“不做查询／处置分权”的业务口径与运营端权限矩阵登记的 `PM-AL-05`／`PM-AL-06` 并存，属来源侧未闭合的文档接缝；本模块不从消息侧恢复或取消分权，目标入口一律按共享账户模块的交付配置呈现。

- 详情来源写入本地消息地址，同一浏览器会话保存个人列表快照、页码、位置及触发行。详情刷新后通过面包屑、文末返回或浏览器往返可恢复来源；未读筛选下已读行保留到主动刷新。正常详情移除卡片上方重复返回链接，保留父级面包屑与文末操作。

## 页面与交互

- `P-O20`：`#/ops/notifications`，整页滚动；白底分隔行，标题、摘要、分类与时间分层，右侧已读/未读标签。分类元数据动态生成；状态与分类叠加。20 / 50 / 100 条分页、总数及 URL 状态保持，翻页加载/失败保留原页。
- `P-O21`：`#/ops/notification?id=…`，整页详情与深链，正文纯文本，绝对时间带账号时区。加载成功后自动已读；返回保持筛选、分页、滚动和焦点，在未读筛选下读过的行保留到主动刷新或切换筛选。
- 铃铛与账号菜单入口复用账户宿主，不新增侧栏消息菜单。铃铛展示最近 10 条，展开不算已读；无批量已读入口，支持关闭、Esc、外部点击和焦点约束。
- 全部已读按当前筛选跨页处理，明确条数、仅影响本人及不可撤销；取消默认焦点，执行期间不可关闭，失败不变更状态。零未读隐藏角标，超过 99 展示 `99+`。
- 权限撤回隐藏入口并拒绝访问/写入；其他端、其他个人与不存在消息使用同一不存在表面。已过期、目标删除、状态流转和目标无权限通过详情提示与按钮状态体现。消息内容和目标权限分开处理。

两类运营角色的上述页面与相应正常、加载、空、筛选空、失败重试、禁用、确认、会话失效状态均有演示入口。共享壳层、账户页、语言和弹窗为 preserved from existing；真实服务端状态为 out of scope。

## 核验与边界

Chromium 核心流程 72 项断言通过，零脚本异常、零外部请求。实测 1280 / 1440 / 1920、中英文列表与核心交互；核验分页/筛选刷新、键盘打开、详情返回上下文、全部已读确认/失败重试、加载失败不已读、状态与权限降级、跨标签同步、会话失效与登录回跳、纯文本安全及动态新增分类。账户独立原型登录与账户设置回归通过，抽离 CSS 与原样式逐字比对一致。未执行移动端验收。截图仅用于内部检查。
