# 管理端消息通知原型

Stage 4 · existing-system adaptation / console。按 WS-360 用户「参考下356……本次直接输出页面原型，无需等我确认」合并设计阶段；业务基线为本模块 V1.0 PRD 四册（交付 `f3684574-12a5-41af-a887-9b95be1e38f1`），视觉参考 WS-356 阅读优化版 `0a8c4ff` 及用户反馈 `5931b43e-65fa-4c66-8cd8-6c98c2744492`。源码从 `cly2.0.0 @ 4b07c5e` 读取。

打开 `消息通知.html`，默认直接进入已登录管理端消息中心；英文默认，可切中文。消息、分类、账号和业务记录均为演示数据。右下角演示工具默认关闭，可切换两类运营角色、无权限、空态、失败及失效场景。没有 SPV 独立身份、机构隔离或跨端消息入口。

## 页面与交互

- `P-O20`：`#/ops/notifications`，整页滚动；白底分隔行，标题、摘要、分类与时间分层，右侧已读/未读标签。分类元数据动态生成；状态与分类叠加。20 / 50 / 100 条分页、总数及 URL 状态保持，翻页加载/失败保留原页。
- `P-O21`：`#/ops/notification?id=…`，整页详情与深链，正文纯文本，绝对时间带账号时区。加载成功后自动已读；返回保持筛选、分页、滚动和焦点，在未读筛选下读过的行保留到主动刷新或切换筛选。
- 铃铛与账号菜单入口复用账户宿主，不新增侧栏消息菜单。铃铛展示最近 10 条，展开不算已读；无批量已读入口，支持关闭、Esc、外部点击和焦点约束。
- 全部已读按当前筛选跨页处理，明确条数、仅影响本人及不可撤销；取消默认焦点，执行期间不可关闭，失败不变更状态。零未读隐藏角标，超过 99 展示 `99+`。
- 权限撤回隐藏入口并拒绝访问/写入；其他端、其他个人与不存在消息使用同一不存在表面。已过期、目标删除、状态流转和目标无权限通过详情提示与按钮状态体现。消息内容和目标权限分开处理。

两类运营角色的上述页面与相应正常、加载、空、筛选空、失败重试、禁用、确认、会话失效状态均有演示入口。共享壳层、账户页、语言和弹窗为 preserved from existing；真实服务端状态为 out of scope。

## 复用与导出

复用 `_shared/tokens.css`、`base.css` 的消息阅读组件、app 壳层、`shell.js` 及 `registry.admin.js`；实测主色 `#1D4ED8`、底色 `#F7F8FB`、侧栏 238px、控件 36px、内容安全边距 24px。管理端列表不设面客端最大宽度，详情正文限制阅读行长。

新增模块 HTML、演示数据 JS、消息 JS；公共样式增量限定于 `.om-*` / `.ops-notification`。账户原 HTML 样式原样抽至同目录 `账户与登录.css`，供两模块引用，避免复制。账户脚本增加可选延后启动、宿主导出及本地演示身份接口；未加载消息模块的账户原型启动方式不变。登记两页，但不加入业务侧栏。

在 `lending-platform/页面原型/` 执行：

```sh
python3 _shared/export.py --source 管理端/消息通知/消息通知.html --output /tmp/借贷平台-管理端消息通知.html
```

附件由共享源内联生成，可离线双击打开；不维护第二份样式副本。不提交生成件、核验截图或测试脚本。

## 核验与边界

Chromium 核心流程 72 项断言通过，零脚本异常、零外部请求。实测 1280 / 1440 / 1920、中英文列表与核心交互；核验分页/筛选刷新、键盘打开、详情返回上下文、全部已读确认/失败重试、加载失败不已读、状态与权限降级、跨标签同步、会话失效与登录回跳、纯文本安全及动态新增分类。账户独立原型登录与账户设置回归通过，抽离 CSS 与原样式逐字比对一致。未执行移动端验收。截图仅用于内部检查。

原型内的已读状态使用本地存储，未读计算、刷新与权限均为演示；真实服务端归属校验、计数、并发、事件投递、去重、轮询 SLA 与安全验收未实现。业务资源目标使用示例申请抽屉，静态页面目标实际进入既有账户页；未合并其他业务模块或在其独立入口安装本模块。既有协议管理、机构审核的离线件不因本次交付自动更新。

本期不做：消息发布/触发规则、公告编辑、订阅偏好、删除归档、标为未读、待办认领审核流程、面客办理进度、另一端消息池、跨平台 SSO。
