## 覆盖与边界

| 端 / 角色 | 页面与功能 | 本轮覆盖 |
| --- | --- | --- |
| 运营查询与处置 | 列表、详情、材料、通过、驳回原因、历史 | 状态/编号/标识/名称/时间筛选、分页、返回保留条件；二次确认、单一必填原因、只读旧版、当前结论回写 |
| 运营会话 / 状态限制 | 列表、详情与处置边界 | 登录失效隐藏申请与材料、拒绝旧动作；重新登录后核对当前版，历史及已结论版仍只读；无运营分权切换 |
| 资金方本人 | 注册材料、结果、修改重提、变更 | 共用原账户流程；审核中锁定、L2 编辑不重置、重提版本递增、变更提交成功才 L3→L1、旧通过不恢复当前权限 |
| 两端异常 | 查询 / 材料 / 处置 / 提交 | 加载、空态、无结果、日期错误、失败重试；重复机构冲突、24 小时成功提交限频、未知结果查询、他人已处理；演示模版升级与旧版不受影响 |

本期字段与剩余演示边界：

- 同源字段及必填性按 V2.1 已确认：机构名称、注册地、标识类型/编号、机构类型、注册地址与机构证明材料必填；监管机构、金融牌照编号、业务联系人邮箱选填。不再将整份字段表列为待定。复用 WS-348/349 的表单、缺项定位与材料替换/删除/失败重试；运营与面客详情注册地址跨行展示，运营材料补充文件大小。账户联系邮箱与材料邮箱继续分离。
- 驳回使用单一原因，不任设未确认字数上限，不再要求原因分类或双语填写。通过仍由运营确认，不按材料齐备自动通过；选填空值仍不应被当作缺项。
- `DEMO-2` 只演示移除业务联系人邮箱、监管机构转必填，以及其他值保留、旧原因目标调整；不表示业务方已批准该模版变化。
- 内置材料可查看示意内容。本地选择文件仍沿用既有原型仅保存文件名/大小/上传状态的行为，不上传或保存原件，显示原件不可预览兜底；没有虚构正式格式、大小或数量限制。
- 未定项仅保留材料可接受证明及审核判据、其他细化校验、上传阈值、真实客服渠道。审核中使用已确认的不承诺天数说明；客服保持问题旁入口与暂不可用反馈，不以审核时长未赋值阻塞本轮。
- 钱包、邮箱投递、原件鉴权、并发锁、查重、提交限频、通知及权限均是本地模拟；不能代替后端安全与正式业务验收。演示状态可从工具重置，单文件内双端互通不等于两个真实部署单元已打通。
- SPV 与运营机构默认同主体，本期不另建 SPV 认证或运营分权配置；不做钱包更换/运营换绑、审核中编辑或删除材料、撤回、批量审核、双人复核、运营账户配置、正式模版配置、认证结论直接翻转及真实交易。
