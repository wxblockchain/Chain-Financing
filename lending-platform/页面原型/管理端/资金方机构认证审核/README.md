# 资金方机构认证审核原型

已确认方向内的增量修订：existing-system adaptation / console。依据用户决定 `ac25f6df-e08b-4dd0-9984-e85d84aeb8d0` 及 V2.3 PRD、流程图与状态机（`d98a614`），同步当前原型；保留 `2888117` 的布局、单框驳回和 `cd56360` 共享导航。沿用直接交付与修订入库授权，仅修改原型及关联组件说明，不修改 PRD。

## 打开与体验

默认打开运营审核列表。右下角默认关闭的演示工具提供“资金方本人 / 运营端”和异常切换。主申请 `DEMO-REG-001` 与既有资金方账户共用本地状态，可走完审核、修改重提、再次通过、已认证变更；其他 7 条示例用于筛选、分页与独立审核。

最终 HTML 由共享导出器内联生成，双击即可操作，无服务、CDN 或远程字体依赖。共享运营导航及账户入口保留，其他模块产物本轮未修改。刷新审核入口会重置演示样例；地址保留浏览上下文，不承诺跨刷新保留本入口的审核结果。

## V2.3 同步

- 每个账号仅维护最新已成功提交的机构资料、材料信息，以及独立编辑草稿。草稿、上传失败、提交失败或尚未确认的提交不替换当前资料；确认收到只覆盖一次。成功重提清空本次审核信息并新增一条待审核记录。
- 审核记录只含内部提交次序、提交人、提交时间、审核人、审核时间、结果与原因，不附表单、字段值、文件或模版内容副本。旧演示数据读取时转为记录，并移除历史资料快照。内部次序仅用于拦截旧审核动作，不呈现为版本列表。
- 运营详情最下方为全宽六列审核记录，从新到旧排列；右侧仍只放当前审核操作。列表不展示版本；详情、材料及确认弹窗取消资料版本标签和历史查看入口。旧版本地址明确提示不再提供历史资料，另给当前申请入口，不将最新资料冒充旧资料。
- 面客状态页保持纵向布局、首屏驳回与重提。审核记录位于提交信息内、默认折叠，展示提交人、两项时间、当次结果及原因，不展示审核员身份。已驳回修改直接进入资料步。
- 单框驳回、非空校验、二次确认、返回修改、取消与键盘焦点保留。原因原文及换行在两端与后续记录中可读；旧字段级原因仅保留原因文字。
- 已认证变更成功提交才转待审核。原机构绑定只存规范化标识，不存旧表单：新旧标识在重审期间占用；通过替换原绑定，驳回保留原绑定并释放候选标识，不恢复旧认证权限或旧资料。
- 列表筛选、页码、申请地址、返回原行焦点及滚动位置保留。旧提交次序、跨申请及离开页面后的审核响应不能处置新提交；正常登录及审核中锁定继续生效。

## 继承与边界

薄 HTML + 模块 JS 复用共享 token、壳层、运营菜单与账户模块。资料栈、字段分组、跨行地址、240px 操作栏沿用确认布局；审核记录组合同步至 `_shared/design-system/管理端组件规范.md` §9。面客仍复用 `面客端/登录与账户体系/资金方账户.js` 及现有 CSS，未另建注册流程。

本期字段和必填性按已确认资料保留。材料可接受证明与审核判据、上传格式/大小/数量阈值、其他未确认限制及真实客服渠道未自行定稿。`DEMO-2` 仅演示模版变化，不代表正式准入政策。材料只存演示文件名、大小、上传状态；内置文件可查看示意内容，本地选件不保存或上传真实原件。

登录、钱包、邮件、材料鉴权、审核、并发、查重、限频及通知均为本地模拟，不代表后端安全或真实业务验收。不新增 SPV 认证、运营分权、批量审核、撤回或钱包换绑，不操作真实数据库。
