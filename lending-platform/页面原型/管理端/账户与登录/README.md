## 打开与演示

打开[账户与登录.html](账户与登录.html)。源码通过相对路径加载本平台公共层；独立附件由 `_shared/export.py` 内联生成，无网络依赖。默认英文，右上角可切换中文。

右下角「演示工具」默认关闭。选择首次登录、运营管理员、运营专员、初始密码过期或锁定场景，会在登录表单载入虚构凭据；所有账号及通知均为演示数据。首次账号当前密码为 `Start1234`，正常账号为 `Harbour123`。完成密码修改后需使用自己刚设置的密码。验证码发送后，在演示工具中选择「填入演示验证码」，再提交业务表单。测试邮箱占用可使用 `taken@example.com`；也可模拟提交时才被占用。

账号和密码变更保存在当前页面内存，刷新重置。语言、时区、拼图冷却及发码额度保存在本地浏览器；注销通过浏览器 storage 事件同步到其他打开的标签页。演示工具提供超时、发信失败、限频、验证码失效、再认证过期、会话到期、通知投递失败与越权尝试。载入演示账号会明确重置这份演示环境的冷却与发码记录；普通刷新、取消或换入口不会重置。

源码实际读取基线：`cly2.0.0 @ 0dd8c7e`。视觉与组件来自 `_shared/tokens.css`、`base.css`、`shell.js`、`registry.admin.js`、`样板/底座样板.html`、`sample-pages.js` 及管理端组件规范；相邻表单参考面客端登录域。无新的色板或公共 CSS 副本。

实测：主色 `#1D4ED8`、底色 `#F7F8FB`、桌面控件 36px、输入圆角 9px、侧栏 238px、内容安全边距 24px。依据本模块验收册额外支持移动端；小屏收成单列，触控表单控件 44px。总览沿用 app 壳层，只提供简短欢迎与账户入口，不带样板业务指标。

## 接入边界与限制

- `CF.opsAuth.can(permissionNumber)` 与 `getIdentity()` 提供本地身份、权限及偏好快照。共享菜单按查询权限编号过滤入口；真实业务授权仍须服务端校验。
- `CF.opsNotifications.bell()` / `open()` 由 `_shared/admin-notifications.js` 提供，本模块与其余四个管理端模块加载同一份消息数据、预览及已读状态。邮箱账户菜单统一由 `_shared/admin-menu.js` 维护，悬浮显示只读角色，消息入口位于账户设置之前；无权限时隐藏相应入口。
- 公共运行时新增可选导航过滤、管理端工具/身份、独立演示面板和管理端错误文案参数；未使用这些接口的原型保持既有行为。
- 邮件、验证码、人机校验、限频、账号锁定、通知投递均为本地交互模拟。真实认证、IP/设备限频、验证码绑定/存储、跨设备会话注销与偏好同步、安全审计、初始凭据交付须由服务端实现；不能把本原型作为安全机制验证结果。验证码模拟器不是真实人机校验服务。
- 国际化继续引用 PRD 指向的共享基线原文，未决定或新增共享文档落盘位置。

## 核验

实际使用 Chromium 打开导出的 `file://` 单文件，覆盖首登与回跳、找回、两种密码变更、邮箱成功及异常、两类角色、语言/时区、锁定倒计时、会话续期/过期与多标签注销。确认无外部网络请求、无浏览器脚本异常。

检查 375 / 414 / 768 / 1280 / 1440 / 1920：登录、双语账户设置、换邮箱与验证码弹窗无横向溢出、控件可达；移动端完整走通换邮箱。检查键盘滑块、表单标签、错误关联、焦点圈与弹层焦点约束。公共样板管理端总览、focus 样板、面客登录和资产广场入口回归通过。未执行真实后端安全、邮件投递或多浏览器兼容验收。截图仅用于内部核验，不随交付。

## 2026-09-20 · 密码交互修订

## 2026-09-21 · 发码前置拼图修订

依据最新四册的功能 §9.1.1、FL-AL-08、AC-AL-122～131，并读取资产平台 `cly-V1.0.0 @ ea56882` 安全册 §12.3。忘记密码及本人修改邮箱均为「左侧码输入 / 右侧获取」→ 拼图对齐缺口、松手验证 → 绿色通过反馈、自动关闭 → 限频检查 → 发码。键盘通过方向键移动、Enter 提交；拖到最右端不会通过。刷新与求助入口可达。

失败显示红色轨道和抖动、复位换图；连续 3 次提示刷新，5 次进入 60 秒冷却。取消、加载失败、请求超时均不发码并保留表单。获取、重发、发信失败后的立即重试均重新验证；邮件连续两次失败后等待 60 秒，不计成功发送额度。演示工具新增拼图加载失败、通过结果过期、来源变化、设备识别不可用场景，默认仍关闭。

本地模拟一次性结果绑定邮箱、用途与请求来源，2 分钟有效；发码成功才占用邮箱 / 网络 / 设备额度。邮件用途共用邮箱额度，间隔等待和拼图冷却以绝对时间保存，刷新仍准确。设备识别不可用时保留其他维度检查。

拼图使用本地 SVG 与既有 token；图形、答案及校验在附件内仅用于可操作演示，不具备真实防自动化能力。服务端挑战与轨迹校验、票据防重放、实际 IP / 指纹识别、权威时间与跨设备冷却仍待真实服务接入；本地存储被清除或篡改不受保护。求助指向建设方或运维，未虚构联系地址或免验证通道。

Chromium 实际核验：鼠标拖动后松手、键盘方向键与 Enter、末端失败、3/5 次阈值、冷却重开/刷新/到期、换图、加载失败重试、取消及取消后无延迟发码；两个入口的获取、失败重试和重发、修改邮箱成功后保持会话、跨用途邮箱额度、邮箱/网络/设备的小时与日限频、设备不可识别、超时、结果过期/目标及来源变化。首登双密码、显隐无障碍名称、不一致纠正、找回重置、锁定凭据后判定、账户上下分组均回归通过。临时浏览器探针另验证无通过结果、结果重复使用、用途变化均被本地发码函数拒绝，探针不包含在交付文件中。这些检查只证明原型状态衔接，不证明服务端安全。
