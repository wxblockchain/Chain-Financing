# 运营端 · 账户与登录原型

`existing-system adaptation / console`。依据 WS-357 用户「直接输出原型，无需等我确认；上传到代码仓库」授权合并四阶段；功能基线为 `0e4cd5e` 的[四册 PRD](../../../PRD/v1.0-运营端账户与登录/v1.0-运营端账户与登录-PRD.md)。已逐册读取本轮附件，并核对与仓库文件一致。

## 打开与演示

打开[账户与登录.html](账户与登录.html)。源码通过相对路径加载本平台公共层；独立附件由 `_shared/export.py` 内联生成，无网络依赖。默认英文，右上角可切换中文。

右下角「演示工具」默认关闭。选择首次登录、运营管理员、运营专员、初始密码过期或锁定场景，会在登录表单载入虚构凭据；所有账号及通知均为演示数据。首次账号当前密码为 `Start1234`，正常账号为 `Harbour123`。完成密码修改后需使用自己刚设置的密码。验证码发送后，在演示工具中选择「填入演示验证码」，再提交业务表单。测试邮箱占用可使用 `taken@example.com`；也可模拟提交时才被占用。

账号和密码变更保存在当前页面内存，刷新重置。语言、时区保存在本地浏览器；注销通过浏览器 storage 事件同步到其他打开的标签页。演示工具提供超时、发信失败、限频、验证码失效、再认证过期、会话到期、通知投递失败与越权尝试。

## 继承与范围

源码实际读取基线：`cly2.0.0 @ 0dd8c7e`。视觉与组件来自 `_shared/tokens.css`、`base.css`、`shell.js`、`registry.admin.js`、`样板/底座样板.html`、`sample-pages.js` 及管理端组件规范；相邻表单参考面客端登录域。无新的色板或公共 CSS 副本。

实测：主色 `#1D4ED8`、底色 `#F7F8FB`、桌面控件 36px、输入圆角 9px、侧栏 238px、内容安全边距 24px。依据本模块验收册额外支持移动端；小屏收成单列，触控表单控件 44px。总览沿用 app 壳层，只提供简短欢迎与账户入口，不带样板业务指标。

## 接入边界与限制

- `CF.opsAuth.can(permissionNumber)` 与 `getIdentity()` 提供本地身份、权限及偏好快照。后续业务模块在登记表设置 `permission`，仍须接入其真实页面与服务端校验。当前只登记本模块总览为侧栏入口。
- `CF.opsNotifications.bell()` / `open()` 是运营消息模块挂载接口；未装载消息模块时不展示假铃铛或无效消息入口。装载后账号菜单中消息入口位于账户设置之前。
- 公共运行时新增可选导航过滤、管理端工具/身份、独立演示面板和管理端错误文案参数；未使用这些接口的原型保持既有行为。
- 邮件、验证码、人机校验、限频、账号锁定、通知投递均为本地交互模拟。真实认证、IP/设备限频、验证码绑定/存储、跨设备会话注销与偏好同步、安全审计、初始凭据交付须由服务端实现；不能把本原型作为安全机制验证结果。验证码模拟器不是真实人机校验服务。
- 国际化继续引用 PRD 指向的共享基线原文，未决定或新增共享文档落盘位置。

## 核验

实际使用 Chromium 打开导出的 `file://` 单文件，覆盖首登与回跳、找回、两种密码变更、邮箱成功及异常、两类角色、语言/时区、锁定倒计时、会话续期/过期与多标签注销。确认无外部网络请求、无浏览器脚本异常。

检查 375 / 414 / 768 / 1280 / 1440 / 1920：登录、双语账户设置、换邮箱与验证码弹窗无横向溢出、控件可达；移动端完整走通换邮箱。检查键盘滑块、表单标签、错误关联、焦点圈与弹层焦点约束。公共样板管理端总览、focus 样板、面客登录和资产广场入口回归通过。未执行真实后端安全、邮件投递或多浏览器兼容验收。截图仅用于内部核验，不随交付。

## 2026-09-20 · 验证码布局调整

参考 `cly-V1.0.0 @ ea56882` 运营端旧原型的验证码输入行，找回密码页和本人修改邮箱弹窗均调整为左侧验证码输入框、右侧获取验证码按钮；初始状态即可见。验证并继续／确认修改保留在下方，人机校验、限频与倒计时沿用现有交互。

## 2026-09-20 · 密码交互修订

按用户截图反馈，首登强制改密只输入新密码与确认密码，移除首登再次输入当前密码的字段及校验；账户内改密和换邮箱仍保留当前密码再认证。所有密码框采用眼睛／划线眼睛图标，保留动态无障碍名称和键盘焦点。确认密码不一致时就地提示并阻止提交，修改任一输入使两者一致后清除错误。

Chromium 实测首登保存后重新登录、账户内再认证、找回重置、换邮箱发码及保存通过；双语、六档屏宽检查无横向溢出，验证码左右布局与倒计时正常，密码图标支持 Enter／Space 操作。认证及邮件仍为本地模拟。

## 2026-09-20 · 账户设置布局修订

账户设置统一为上下分区：账号信息在上、偏好信息在下；不再展示已开通权限清单。权限校验与角色配置接口保留，修改邮箱、修改密码、语言和时区交互沿用现有实现。
