# 运营端融资参数配置原型

`existing-system adaptation · console`。2026-09-25（WS-388）本模块新建，基线为分支 `cly-v3.0.0` 上的[主 PRD](../../../PRD/v1.0-运营端融资参数配置/01-运营端融资参数配置-PRD.md)、[流程图与状态机](../../../PRD/v1.0-运营端融资参数配置/02-运营端融资参数配置-流程图与状态机.md)、[消息通知](../../../PRD/v1.0-运营端融资参数配置/03-运营端融资参数配置-消息通知.md)与[字段命名与术语对照表](../../../PRD/00-字段命名与术语对照表.md)，并衔接运营端账户与登录、合约管理、代币质押审核的已入库结果。三册只定义信息需求与业务行为，页面布局与组件由设计决定（见[统一条款](../../../PRD/v1.0-运营端融资参数配置/01-运营端融资参数配置-PRD.md#design-boundary)）。

## 打开与源码

直接打开 `融资参数配置.html`，默认英文，可切中文。沿用当前 app 壳层、管理端统一导航、`tokens.css`、`base.css`、`shell.js`、`registry.admin.js`、公共详情栈、公共可排序列头、状态表面与导出器；不新增第二套 token，不自建菜单或账户组件。

- `融资参数配置.html`：模块布局与局部组合样式。
- `融资参数配置.js`：列表与检索、参数详情与变更记录、参数维护、保存确认与结果反馈。
- `演示数据.js`：本地示例代币类型、参数取值与变更记录，以及尚未裁定的取值边界占位值。
- 路由：`P-O-FC-01` `/ops/financing-parameters`、`P-O-FC-02` `/ops/financing-parameters/detail?token=…`、`P-O-FC-03` `/ops/financing-parameters/edit?token=…`。

单文件评审件由现行导出器生成，生成件不回存源码目录：

```bash
python3 _shared/export.py --source 管理端/融资参数配置/融资参数配置.html --output ../借贷平台-运营端融资参数配置-页面原型.html
```

## 页面组合

**一个侧栏条目「融资参数配置」，台账 → 详情 → 维护三层。** 列表是模块落地页、一级页面不展示面包屑；详情与维护沿真实父级链展示面包屑并原路返回，保留原筛选、排序、分页与所在位置。

**融资参数列表。** 一行一个代币类型，七列：代币类型、最高质押率、最长项目期限、配置状态、最近更新时间、最近更新人、查看。未配置行的两项参数、最近更新时间与最近更新人一律「—」，不显示 0、不显示平台默认值。关键词模糊匹配代币类型名称（忽略大小写与前后空格），配置状态可筛已配置 / 未配置，查询与重置成对；默认代币类型名称升序，代币类型与最近更新时间两列可升降序；默认每页 20 条，可切 50 / 100。筛选、排序、页码与每页条数都写进地址，前进后退与从详情返回都保持原位置。列表没有新增、删除代币类型的入口，也没有逐笔质押、项目或代币的跳转。四种空结果分别表达：无查询权限、上游暂无代币类型（不提供新增入口）、筛选无匹配（给重置）、取数失败（可重试且保留条件）。

**代币类型参数详情。** 顺序固定为先当前参数后参数变更记录，不另立独立的记录页。当前参数六项：代币类型（只读、注明由上游供给）、最高质押率、最长项目期限、配置状态、最近更新时间（带时区）、最近更新人（脱敏后的可读归属）。参数变更记录五列：发生时间、操作人、最高质押率、最长项目期限、本次结果；每次保存成功一条，按发生时间倒序、默认 20 条可继续加载，首次配置记为从「—」到新值，两项中未变的一项标「未变」而不写成一次改动。记录只读、不按本人经办过滤，不含项目、代币、质押笔或企业信息，也没有任何逐笔质押跳转。尚无记录、加载中、读取失败与登录失效分别表达。

**参数维护与保存确认。** 一次只维护一个代币类型，代币类型只读反显；没有多行批量编辑、复制到其他类型与导入导出。未配置时两项为空，不预填演示值或平台默认值。两项均未改动时保存不可用并给出原因；校验拒绝定位到具体项并说明该项当前允许范围，不产生变更记录。保存进入确认环节：回显代币类型、两项参数的变更前后，并写明「仅对此后新建项目生效，不改变存量项目」；取消不改变任何已生效参数。提交中禁用表单并拦截重复提交，结果按真实状态呈现——失败保留输入可重试，结果未知提示先重新取数核对、确认前不要重复提交，他人先行修改则拒绝旧内容并提示重新取数（对方的保存正常留痕），代币类型在办理期间被上游移出则拒绝保存并说明未写入任何参数。离开办理与重新取数在有未提交内容时都先确认。

**上游取值增减。** 代币类型取值全集由上游供给，本期只有一个取值 `ERC-20-应收账款`，列表按多行规格编写。上游新增的取值以未配置状态出现在列表，配置完成前不可用于创建融资项目；被上游移出的取值不再出现在列表、不再供给创建，其参数变更记录在原地址上保留可追溯并标明已不在有效取值内、不再可维护。

**不做的事。** 本模块没有草稿、待生效、定时生效、生效计划或发布环节，也没有回滚、撤销与历史值恢复；没有存量项目清单、整改待办或强制关闭；没有利率、费率、额度、币种、链与审核类参数；没有截止时点、剩余时长、倒计时、临期强调或超期标记；不提供文件上传与下载。

## 会话与功能权限

会话与功能权限只读运营端账户与登录的一处登记（`CF.deferOpsBoot` + `CF.opsAuth`），模块不维护 `permission` 假数据、不自造权限编号：`PM-AL-19` 融资参数查询可读列表、详情与变更记录，不出现维护入口；加持 `PM-AL-20` 融资参数维护才出现维护动作。`PM-AL-20` 按 `D-AL-35` 须配套 `PM-AL-19`，所以仅开通维护的账号进入即被拒绝并说明须由建设方修正交付配置（共享菜单的 `reachable` 让该入口仍可达，账号能读到拒绝原因而不是静默消失）；两项皆无为无权限空态且菜单条目不展示。查询权与维护权分别判定，直接打开维护地址同样被拦。登录失效走共享运营登录页，重新登录后回到原来的列表、详情或办理页。

共享菜单沿用 WS-387 已有的 `pages` 字段，让三个页面共用同一个侧栏选中态，未新增第二套机制。

## 边界

- 本模块只供参数，不参与项目审核、不提供审核入口，也不把参数改动当作审核依据；合约管理只读引用当前配置值，并按创建时锁定的快照核对，两侧表述一致。
- 逐笔质押的查询与处置固定在代币质押审核，本模块没有入口、跳转与只读副本。
- 与企业账户无参数、字段或收件关系，不采集也不展示企业账户信息。
- 本模块零站内信事件、零模板，未改 `_shared/admin-message-data.js`；校验提示、保存结果、取数失败与重试是页面反馈，不是消息通知。
- 演示数据与异步反馈均为浏览器本地模拟，刷新重置业务数据；地址只保存浏览上下文，不授予权限。真实配置读写、上游取值供给与权限登记仍需实机联验。

## 演示工具

右下角演示工具默认关闭，与产品画面分离。可切交付的账号配置（管理员 / 未开通 / 仅查询 / 仅维护 / 查询＋维护）、页面状态（默认 / 加载中 / 空数据 / 读取失败）、参数变更记录状态（默认 / 加载中 / 尚无记录 / 读取失败 / 登录失效）、保存反馈（成功 / 失败 / 结果未知 / 已被他人先行修改 / 代币类型已被上游移出）；可模拟上游新增与移出代币类型、切换尚未裁定的取值边界占位值、运营登录失效与重置演示。

## 未自行定夺的事项

- **最高质押率的取值上下限与小数位数（`Q-O-FC-02`）尚未裁定。** 原型只落实可验收的行为——保存时必填、须落在允许取值范围内、超范围按项拒绝并给出当前允许范围；具体数值不在产品里写死，而是放进演示工具的占位取值边界（1%～100% 整数 / 10%～80% 一位小数 / 50%～95% 两位小数），三组都只用于演示越界拒绝与允许范围提示，都不构成上线口径。裁定后只需替换这一处取值。
- 最长项目期限的 3～12 整月已由 `FP-35` 确认，按硬区间校验，不在待裁定之列。
- `PM-AL-07` / `PM-AL-08` 的分权粒度在哪一册收口仍由用户裁定；本模块只使用自己的 `PM-AL-19` / `PM-AL-20`，未改其他模块的登记粒度。
- `F-O-FC-05` 创建项目的参数供给发生在面客端创建融资项目环节（WS-374 线），不属于本端画面；本模块在列表与详情用配置状态及其后果（未配置暂不可用于创建融资项目）表达供给边界，面客侧界面不在本模块内。
