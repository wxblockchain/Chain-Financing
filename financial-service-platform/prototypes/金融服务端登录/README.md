# 金融服务端登录 · 原型（WS-311）

金融服务端**登录相关**的可交互原型：登录主干、资产方 SSO 登录、资金方登录与账户体系。
单文件打开即用，无需服务器与网络。

- 文件：[`v1.0-金融服务端登录-原型.html`](v1.0-金融服务端登录-原型.html)
- PRD 基线：[`../../prd/v1.0-金融服务端登录/`](../../prd/v1.0-金融服务端登录/)（14 个文件，分支 `cly-V1.0.0`）
- 页面登记：[`../_shared/registry.js`](../_shared/registry.js)
- 视觉与运行时：`asset-platform/prototypes/_shared/` 的 `tokens.css` / `base.css` / `shell.js`

## 继承声明

按[现有页面继承参考](../../../docs/design-system/harbour-credit-page-prototype-reference.md)第 3 节的四项：

```
继承端别：面客形态（registry 的 end = asset，密度由 base.css 的 [data-end="asset"] 承担）
继承 shell：未登录页 focus（4.4 母版）／已登录页 app（4.1 母版，按 4.3 的口径复用）
继承母版：asset-platform/prototypes/账户与登录/v1.0-账户与登录-原型.html
继承 archetype：未登录 / 强制中断 → focus 版式母版；认证后工作台与资料页 → 资产端 app shell 母版
本页增量：只有内容区、弹层组合与状态差异；未新增整页骨架、未改导航与配色
```

**没有另起一套「公开门户」壳层。** 继承参考 4.2 / 4.3 明确写着面客公开层与认证后 subnav 版式
在仓库内尚无原型、**不得作为继承母版使用**，资产端目前走的就是 4.1 的 app shell。
本模块照此执行，等公开层母版落库后再统一切换。

## 怎么看

打开 HTML 即进入平台首页的**游客态**——这就是产品本身，不是演示脚手架。

| 想看什么 | 怎么走 |
| --- | --- |
| 切身份（游客 / 资产方 L0·L3 / 资金方 L0·L1·L2·L3） | 顶栏「原型 · 身份」下拉。同一个下拉里还能切资金方的邮箱 / 钱包凭据、以及跨域回跳是否放行 |
| 未登录页（类型选择、SSO 中转、资金方登录…） | focus 顶栏的「页面目录」按钮 |
| 每页的状态（加载 / 空 / 失败 / 无权限 / 提交中 / 锁定…） | 页面上的「原型 · 状态」切换条 |
| 本页对应的 PRD 条目 | 顶栏 `PRD` 按钮 |
| 回跳判定怎么判 | 首页底部「回跳判定 · DEP-M1」，点任一目标当场出判定结果与规则编号 |

## 导出独立评审附件

```bash
python3 financial-service-platform/prototypes/_shared/export.py \
  --source financial-service-platform/prototypes/金融服务端登录/v1.0-金融服务端登录-原型.html \
  --output ../deliverables/金融服务平台-金融服务端登录-原型.html
```

仓库版是**维护形态**（引用 `_shared/`），附件是**交付形态**（导出时内联）。
公共层更新后重新导出即可；**不要手改导出件**，否则快照与系统会各走各的。
