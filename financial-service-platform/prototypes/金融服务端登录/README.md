# 金融服务端登录 · 原型（WS-311 + WS-316）

金融服务端**面客侧**的可交互原型：登录主干、资产方 SSO 登录、资金方登录与账户体系（WS-311），
以及资金方机构认证审核的完整申请链路（WS-316，`P-F30`～`P-F34`）。
单文件打开即用，无需服务器与网络。

- 文件：[`v1.0-金融服务端登录-原型.html`](v1.0-金融服务端登录-原型.html)
- PRD 基线：[`../../prd/v1.0-金融服务端登录/`](../../prd/v1.0-金融服务端登录/)（分支 `cly-V1.0.0`）
  · WS-311 登录主干与资金方账户体系各册 · WS-316 的 `03-1` / `03-2` / `03-3` 三册（V1.1）
- 页面登记：[`../_shared/registry.js`](../_shared/registry.js)
- 视觉与运行时：`asset-platform/prototypes/_shared/` 的 `tokens.css` / `base.css` / `shell.js`

## 继承声明

按[现有页面继承参考](../../../docs/design-system/harbour-credit-page-prototype-reference.md)第 3 节的四项：

```
继承端别：金融服务端（registry 的 end = asset，密度由 base.css 的 [data-end="asset"] 承担）
继承 shell：登录页 focus（4.4 母版）／已登录页 portal 顶栏（4.3 母版）
继承母版：asset-platform/prototypes/账户与登录（focus 版式）
          asset-platform/prototypes/实名认证与审核（整卡认证入口、分步资料页）
          asset-platform/prototypes/应收账款录入与确权（表单 + 上传、只读详情 + timeline）
继承 archetype：未登录 / 强制中断 → focus 版式母版
                已登录资料页 → 4.3 header + subnav + main/right rail + 整卡入口
                已登录分步资料页 → 4.3 母版 + 步骤条 + 单组字段卡（WS-316 P-F30）
                提交前核对 / 只读进度 / 结论详情 → 4.3 母版 + 只读栅格 + timeline（WS-316 P-F31 / P-F33 / P-F34）
本页增量：只有内容区、弹层组合与状态差异；未改配色与 token，未在模块内重建导航
```

**已登录页用顶栏，不用左侧栏。** 继承参考 4.2 / 4.3 原先标着「暂无原型、不得作为继承母版」，
该限制已随 WS-311 那一轮解除——**本模块就是 4.3 顶栏母版的首个落库参考**。实现层是
`_shared/base.css` 的 `.portal*` 一族（纯新增，未修改该文件任何既有规则）。
4.1 的 238px 侧栏骨架一个字未动，另外 11 份原型继续用它。

**导航口径**：主导航只有「首页」；**账户设置与机构信息只在右上角账号下拉里**，不占主导航位；
**入驻引导页与 WS-316 的申请链路五页都不进任何菜单**——前者的入口来自资产方首登流程、
常驻补全提示条与受限操作引导弹层，后者的入口是「机构信息」页。

**原型里不放 PRD。** 页面上没有规则条文、没有编号追溯层、没有判定试验台，顶栏也没有
PRD 抽屉入口——原型呈现的是产品界面本身。规则与编号追溯放在交付说明文档里。

## 本轮范围说明

- **首页与登录后的落地页只有空壳版式**：首页归其他 issue，本原型只做登录与入驻。
- **资产方首次登录成功后落「入驻引导」页**（`P-F06`，不在菜单里），形态参考资产端个人 /
  企业认证的整卡入口，并用 4.3 母版的 main + right rail。资产方的认证权威在资产平台、
  本端只读，因此两张卡的去处都是资产平台（先过离站告知），本端不收资料。
- **资金方的入驻链路已完整实现**（WS-316 本轮新增）：入口仍是账号下拉里的「机构信息」
  `P-F27`，往下是模版驱动的资料填写 `P-F30`、提交预览 `P-F31`、二次确认弹窗 `C-F50`、
  提交结果 `P-F32`、只读审核进度 `P-F33`、申请详情与驳回回显 `P-F34`，以及客服入口
  `C-F52`。原先那张「归 WS-316」的说明层已删除。
- **运营端审核界面不在本原型内**：审核列表 / 详情 / 通过驳回操作归 WS-308，
  本原型只出资金方自己看到的那一侧。
- **跨域回跳默认放行**：资产方从资产平台回来落原触发点并重新执行被拦下的操作。

## 资金方入驻链路怎么看（WS-316）

顶栏「原型 · 身份」下拉切档位，页面上的「原型 · 状态」切该页的状态；两者是联动的，
切到「已入驻 · 更新审核中」这类状态会同时把身份带过去，不会出现顶部说已驳回、正文说
审核中的自相矛盾。

| 想看什么 | 怎么走 |
| --- | --- |
| 模版驱动的分步表单、草稿、稍后再维护 | 身份「资金方 · 未提交」→ 账号下拉「机构信息」→ 去填写（`P-F30`） |
| 联系邮箱的 RISK-01 常驻提示与登录邮箱解耦说明 | `P-F30` 第 3 步「业务联系人」，提示常驻在字段下方而不是悬浮 |
| 模版升级后的草稿迁移、并发编辑、上传失败、模版加载失败 | `P-F30` 的状态切换条 |
| 提交前完整预览、必填未完成、预校验退回、查重命中、提交限频 | `P-F31` 的状态切换条 |
| 二次确认弹窗（明写提交后不可修改不可撤回） | `P-F31` →「提交申请」 |
| 只读审核进度、节点、预计时长、超时出口、客服入口 | 身份「审核中」→ 机构信息 → 查看进度（`P-F33`） |
| 字段级驳回回显与 v+1 重提 | 身份「已驳回」→ `P-F34` →「编辑重提」→ `P-F30` 看高亮 |
| 通过后变更重审、被驳回后的降级说明 | 身份「已入驻」→ `P-F34` →「更新机构资料」；或直接切「更新被驳回（已降级）」 |

**撤回全线为零**：链路里没有撤回按钮、撤回状态、撤回字段，也没有任何「如需修改请撤回」
类文案；全文出现「撤回」二字的位置只有「提交后无法修改或撤回」这句禁止性说明。

  --source financial-service-platform/prototypes/金融服务端登录/v1.0-金融服务端登录-原型.html \

仓库版是**维护形态**（引用 `_shared/`），附件是**交付形态**（导出时内联）。
