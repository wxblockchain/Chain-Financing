# 金融服务端登录 · 原型（WS-311）

金融服务端**登录相关**的可交互原型：登录主干、资产方 SSO 登录、资金方登录与账户体系。
单文件打开即用，无需服务器与网络。

- 文件：[`v1.0-金融服务端登录-原型.html`](v1.0-金融服务端登录-原型.html)
- PRD 基线：[`../../prd/v1.0-金融服务端登录/`](../../prd/v1.0-金融服务端登录/)（14 个文件，分支 `cly-V1.0.0`）
- 页面登记：[`../_shared/registry.js`](../_shared/registry.js)
- 视觉与运行时：`asset-platform/prototypes/_shared/` 的 `tokens.css` / `base.css` / `shell.js`

## 继承声明

按[现有页面继承参考](../../../docs/design-system/harbour-credit-page-prototype-reference.md)第 3 节的四项：

```
继承端别：金融服务端（registry 的 end = asset，密度由 base.css 的 [data-end="asset"] 承担）
继承 shell：登录页 focus（4.4 母版）／已登录页 portal 顶栏（4.3 母版）
继承母版：asset-platform/prototypes/账户与登录（focus 版式）
          asset-platform/prototypes/实名认证与审核（整卡认证入口）
继承 archetype：未登录 / 强制中断 → focus 版式母版
                已登录资料页 → 4.3 header + subnav + main/right rail + 整卡入口
本页增量：只有内容区、弹层组合与状态差异；未改配色与 token
```

**已登录页用顶栏，不用左侧栏。** 继承参考 4.2 / 4.3 原先标着「暂无原型、不得作为继承母版」，
该限制已随本轮解除——**本模块就是 4.3 顶栏母版的首个落库参考**。实现层是
`_shared/base.css` 新增的 `.portal*` 一族（纯新增，未修改该文件任何既有规则）。
4.1 的 238px 侧栏骨架一个字未动，另外 11 份原型继续用它。

**导航口径**：主导航只有「首页」；**账户设置与机构信息只在右上角账号下拉里**，不占主导航位；
**入驻引导页不进任何菜单**——它是资产方首登后的落地页与流程页，入口只来自首登流程本身、
常驻补全提示条与受限操作引导弹层。

**原型里不放 PRD。** 页面上没有规则条文、没有编号追溯层、没有判定试验台，顶栏也没有
PRD 抽屉入口——原型呈现的是产品界面本身。规则与编号追溯放在交付说明文档里。

## 怎么看

打开 HTML 即进入游客态。这就是产品本身，不是演示脚手架。

| 想看什么 | 怎么走 |
| --- | --- |
| 切身份（游客 / 资产方未认证·已认证 / 资金方未提交·审核中·已驳回·已入驻） | 顶栏「原型 · 身份」下拉（窄屏只留下拉、收起文字标签）；同一下拉里可切资金方的邮箱 / 钱包凭据 |
| 登录相关页面（类型选择、资金方登录、SSO 中转…） | 顶栏或 focus 顶栏的「页面目录」按钮 |
| 每页的状态（加载 / 失败 / 提交中 / 锁定 / 停用…） | 页面上的「原型 · 状态」切换条 |

## 本轮范围说明

- **首页与登录后的落地页只有空壳版式**：首页归其他 issue，本原型只做登录。
- **资产方首次登录成功后落「入驻引导」页**（不在菜单里），形态参考资产端个人 / 企业认证的
  整卡入口，并用 4.3 母版的 main + right rail。资产方的认证权威在资产平台、本端只读，
  因此两张卡的去处都是资产平台（先过离站告知），本端不收资料。
- **资金方的入驻入口与机构信息展示在「账户 · 机构信息」页**（账号下拉进入）。申请表单、提交预览与
  二次确认、审核进度、字段级驳回重提归 **WS-316**：点过去是一张标注归属的说明层，
  **不画假页面充数**。
- **跨域回跳默认放行**：资产方从资产平台回来落原触发点并重新执行被拦下的操作。
