## 1. 这一页是什么

登录后的个人数据聚合页，**纯只读**。它做两件事：**把数聚起来**（统计区）、**把人送回广场去办**（各 tab 行上的快捷按钮深链）。

**页面上不存在任何业务提交入口**——每一个动作按钮要么是跳借贷广场的深链，要么是切换本页视图（tab / 筛选 / 排序 / 分页 / 展开）。这条可机械验收：全文没有任何 `submit` 语义的控件。

自上而下两段：**① 统计区 → ② tab 容器**（筛选条 / 排序 / 过滤条带 → 列表 → 分页）。

待办提示带原本在两者之间，**v1.1 按需求方裁定整块撤除**——不改成折叠、不改成浮层、不改成第六个 tab，那都还是把它放在这里。详见 §4。

**每个 tab 都分页**：单页 20 条起步，**每页条数可切 20 / 50 / 100**，页码与总条数常驻。视图状态（tab / 筛选 / 排序 / 页码 / 每页条数）全部写进 URL，可直接把当前视图发给别人。

| tab | 筛选 | 默认排序 | 可点排序列 | 演示行数 |
| --- | --- | --- | --- | --- |
| 代币列表 | 代币状态 · 融资质押状态 · 所属项目 | 签发时间倒序 | 代币价值 · 账期 | **37**（2 页） |

## 5. 快捷按钮与深链

按钮显示与否、可点与否**一律由服务端 `available_actions` 决定**，前端不按状态或日期推断，三态在原型里都能看到：

- **不返回 → 不渲染**（例：已结清业务行没有任何处置按钮）
- **可用 → 可点**（跳广场）
- **`⊘` → 可见不可点 + 展示服务端给的原因**（例：未开窗期次的「去还款」附「将于 YYYY-MM-DD 开启」；覆盖不足期间的「解除质押」附「可撤回上限 0.00 USD」）

**逾期期次的还款入口一直可点**，不因逾期而变灰。

深链语义统一是「**落详情页 + 打开右侧抽屉 760px**」，控制台不深链到任何提示类 560px 弹窗；控制台**不新增任何 action 取值与锚点**，全部消费 WS-324～327 已登记的：

| 按钮 | 锚点 | 承接模块 |
| --- | --- | --- |
| 发布融资需求 / 去追加质押 / 解除质押 | `project/{id}?action=publish` / `pledge` / `withdraw` / `redeem` | WS-324 |
| 去接受 / 拒绝报价（报价确认） | `deal/{id}?action=respond_quote` | WS-325 |
| 去放款 / 去重传盖章件 / 去确认收到放款（放款确认） | `deal/{id}?action=disburse` / `reupload_contract` / `confirm_disbursement` | WS-326 |
| 去还款 / 去确认收到还款（还款确认）/ 查看还款计划 | `schedule/{id}?action=repay` · `confirm_repayment` / `deal/{id}?action=view_schedule` | WS-327 |
| 查看项目详情 / 查看融资业务 | `project/{id}` / `deal/{id}` | WS-324 |
| 去提交机构资料 | WS-316 机构资料页 | WS-311 / WS-316 |

跨域两条（实名认证、应收账款重提）走**离站告知弹窗**再出站，控制台不自建跨域跳转。

顶部状态切换条（原型评审脚手架，不属于产品界面）可逐个切：

| 状态 | 看得到什么 |
| --- | --- |
| 默认 | 资产方 / 资金方两套完整数据（顶栏右上角切身份） |
| 加载中 | 统计区与 tab **各自独立骨架屏**，互不阻塞 |
| 分块降级 | 统计区「总授信」给"暂时取不到 + 重试"（**不展示 0**），还款 tab 就地给可重试错误态，**其余块照常可用**；点重试即恢复 |
| 空态 | 六种空态各自的文案与 CTA（CTA 一律指向借贷广场或资产平台） |
| 筛选无结果 | 与空态区分，给"没有符合筛选条件的记录"与一键清空筛选 |
| 深链带过滤 | 落放款 tab 且按"已超过放款确认时限"过滤，顶部出「已按 X 过滤 / 清除」条带 |
| 资金方 · 无主体 | `entity_id` 为 `null` 走整页空态，CTA 指向机构资料，**不报错、不渲染一排 0** |
| 会话失效 | 回落游客态：统计数字、各 tab 列表与展开区**全部从页面移除**，顶栏菜单不再渲染；不是弹层遮挡、不弹登录框、不进错误页 |
| 无权限 / 越权 | 一律落"内容不存在或无权访问"语义，不区分"没权限"与"不存在"（服务端行为，原型侧在 PRD 面板登记，界面不做第二套渲染） |

## 7. 角色与端

一份产物、两个视角，顶栏右上角切换。切换后**菜单、tab 集、列与动作全部跟着变**：

| | 资产方 | 资金方 |
| --- | --- | --- |
| tab 集 | 代币列表\* · 融资项目 · 授信明细 · 融资放款信息 · 还款信息 | 我的报价\* · 授信汇总 · 融资放款信息 · 还款信息（**不渲染代币列表**） |
| 统计区 | ①全部代币（内嵌②已质押 + 失效副行）· ③总授信 · ④已融额度 · ＋剩余可用授信 | ③ · ④ · ＋（**不渲染①②**） |
| 授信视角 | 各机构对本企业的额度与占用 | 本机构对各资产方的敞口；`CR-12` 备注**仅本方可见** |

## 8. 口径落点（逐条对得上）

- **统计区①②是包含关系**：②是①卡片里的嵌套块而不是并排的第二张卡；②下常驻失效副行并标「不计入覆盖」——②是跨项目账面口径（含失效），与项目侧的「质押代币价值」本就不是同一个数。
- **四个中间量不展示**：融资上限 / 可融金额 / 项目在途金额 / 可撤回上限一个都不出现，也不做额度尺或进度条。
- **剩余可用授信**旁常驻一句"实际可融金额以发布需求时服务端当场重算的结果为准"，不给"你还能融 X"的数字。
- **三个 168 小时分别命名**：报价有效期 / 放款确认时限 / 还款确认时限；界面上没有无限定词的"7 天""有效期""倒计时"。三个确认环节在英文下也各用各的词（Quote / Disbursement / Repayment confirmation）。
- **超期表述**一律「已超过放款（还款）确认时限 N 天」+ **可复制客服邮箱** + 编号指引，并写明超期不改变状态、权限与金额；不写"已失效""已逾期"。
- **档位与失效是两条线**：覆盖不足提醒挂项目行、失效结果（`自动失效 · 覆盖不足`）挂逐轮需求行，两处分开呈现、文案互不引用，**没有因果句**；提醒里**没有倒计时、进度条或"还来得及追加"**，并写明它救不回已失效的那笔、失效不是惩罚、可立即重新发布。
- **覆盖缺口与需追加资产价值成对给**（两个数都在，公式不写在界面上）。
- **链是常量**：只读展示 `ETH`，没有任何下拉或单选；哈希旁常驻「平台未核验该交易，链接仅供自行查验」。
- **还款收款账户**（法币五项含中转行 / 数币绑定钱包）只读脱敏、无修改入口，并标注"这是资金方将来收还款的账户，与本次出账账户无关"。
- **还款类型（定值）与还款性质（正常 / 逾期）**相邻出现时各自带标签，不混用一个词。
- **界面上不出现任何条款编号与验收编号**，也不出现判据公式与运行机制解释。编号只在顶栏「PRD」抽屉里，那是给实现方看的面板。
- **不自建消息中心**：铃铛、未读角标、消息列表都不在本模块，页面上也没有未读红点；v1.1 起待办带也不在本页。

### 10.1 为什么撤掉「我的融资项目」的导航位

`P-LS-90` 是原型侧内部页，当初的定位写得很清楚：**M-5 控制台尚未立项时，`AC-LS-54`「两段式可中断可续做」所必需的最小续做入口**。WS-328 就是 M-5，它的「融资项目」tab 已经完整承担了那个入口的全部职责：

| P-LS-90 原来提供什么 | 控制台里的落点 |
| --- | --- |
| 本方项目台账（只看"我的"） | 融资项目 tab，服务端按主体过滤，字段更全（五个数 + 覆盖状态 + 逐轮需求） |
| 草稿可续做 | 草稿行的「发布融资需求」→ `project/{id}?action=publish`，即 `AC-LS-54` 的续做入口 |
| 进项目详情 | 行内「查看项目详情」→ `project/{id}` |

两个入口并排出现，用户要先判断"我的项目"和"我的控制台"哪个才是自己要找的——这是没有必要的选择题。**处置：撤 `P-LS-90` 的 `nav`/`navKey` 登记，改登记 `crumb`；页面、编号与 `ENTRY` 一律保留不回收**，WS-324 原型内 `#/my-projects` 仍可直达，编号也不会被别人占用。

**已知代价（如实记）**：WS-324 的**单文件评审附件**里，`P-LS-90` 因此只剩 URL 可达（跨模块链接在单文件里会提示范围边界）。仓库版不受影响——点顶栏「我的控制台」即可。若 WS-324 希望在自己文件内保留一个页内入口，那是他们文件里的一行事，**本轮不代改他册**。
