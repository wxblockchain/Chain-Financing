# 金融服务平台 · 运营端 · 消息通知原型

**Stage 4/4 · console · delta prototype（基于 existing-system adaptation）**

根据已审阅原型及“入库”批复，按仓库既有模块结构完成接入。消息模块的 2 个页面和 4 个组件已经实现；其他模块的页面及真实后端接口不包含在单文件附件；仓库版已接通账户登录、账户设置、总览和协议管理入口，故不宣称完整系统闭环。

## 打开与评审

保留完整仓库目录，双击本目录 `v1.0-消息通知-原型.html`，用现代桌面浏览器打开。仓库版通过相对路径加载公共层；需要单文件附件时，按 [公共层说明](../_shared/README.md) 的命令导出。导出件自包含，无 CDN、远程字体、图片或网络接口依赖。默认英文，可在右上角切换中文，历史消息随语言切换。

默认进入消息中心。点右上角铃铛查看最近 10 条；账号菜单里的“消息中心”直接回到无筛选列表。点击消息进入整页详情；行内“标为已读”不跳页。列表下方可切换页码及每页 20 / 50 / 100 条。

展开页面内的 **Prototype scenarios / 原型状态演示**，可切换管理员 A/B/C、加载、空态、失败、失效及会话场景。A/B 为同一角色的两个演示账号；C 是新建账号样例，其创建前历史消息可见但不计未读。“132 条未读”会生成实际演示记录，不只是修改角标数字。“重置演示”恢复数据、管理员和每页条数。

演示数据保存在当前浏览器本地；禁止本地存储的浏览器仍可在当前页面内体验，但刷新和多标签页持久化可能不可用。跨标签页使用 BroadcastChannel / storage 事件，演示中不存在真实账号或业务事件。

## 基线与 design DNA

仓库 `wxblockchain/Chain-Financing`，分支 `cly-V1.0.0`，原型评审基线 `8c8b222`；入库适配基线 `00e132d`（含并行入库的协议管理与账户登录），已读取新入库的 WS-308 账户与登录 PRD 及国际化分册。

已读取并采用：

- `financial-service-platform/prd/v1.0-消息通知/` 三份 PRD；功能 F-O01～F-O18，验收以正文实际 83 条为准。
- `docs/design-system/README.md`、`harbour-credit-admin-components.md`、`harbour-credit-page-prototype-reference.md`。
- `asset-platform/prototypes/消息通知/v1.0-消息通知-原型.html` 及 README，重点继承管理端 P-M20 / P-M21。
- `asset-platform/prototypes/_shared/` 的 token、公共 CSS、页面登记与壳层运行时。
- 前一轮 `WS-309-消息通知-Stage1-范围基线.md`，以及共享数据契约与 `docs/notification-contract/接入指南.md`。

沿用冷白控制台画布、238px 侧栏、紧凑顶栏、36px 标准控件、28px 小控件、12px 卡片圆角、9px 控件圆角，主色 `--accent: #2557E8`，页底 `--bg: #F6F7FA`，正文 `--sans`，结构化值 `--mono`。所有值直接来自仓库公共源，未另建 token 系统。详情沿用整页消息详情 archetype，未改成弹窗或抽屉。

仓库维护源为本目录 HTML（只包含模块专有 CSS、页面、文案、演示数据与状态），加载 `asset-platform/prototypes/_shared/` 的 canonical token、CSS 和运行时。单文件附件由 `../_shared/export.py` 从当前源自动内联生成，不手工维护第二份公共样式。

页面、模块归属、导航和跨文件入口由金融服务平台自己的 `../_shared/registry.js` 登记，模块脚本不覆盖全局登记。仍使用 `registry.end = admin` 控制台形态，演示消息独立使用 `end = fs_ops`。资产平台登记表与五个模块的菜单不变。公共 `shell.js` 仅补充 `account().settings` 可省略的处理；账户设置参数省略时不生成 `undefined` 入口；消息模块已接入 P-O05，账户模块保留自身登录守卫。

入库时同步 WS-308 已定规则：

- 列表 / 详情使用 `#/ops/messages` / `#/ops/messages/{message_id}`，对应生产路径 `/ops/messages` / `/ops/messages/{message_id}`。原评审 `#/p-o20` 深链保留兼容；仓库版会话中断页可进入 `/ops/login?redirect=…`，演示登录成功后回到原消息深链；真实鉴权和跨模块会话共享仍未接入。
- 顶栏从左到右对应 C-O20 铃铛、C-O04 语言切换器、C-O11 账号下拉；消息中心在账号下拉中提供入口。
- 角色称谓统一为「运营管理员 / Operations Administrator」。英文日期如 `Sep 9, 2026, 15:00:00 (UTC+8)`，中文如 `2026-09-09 15:00:00 (UTC+8)`；复用现有 `CF.fmtTime`，大于 24 小时的列表消息展示绝对时间与时区，hover 可见 IANA 时区。演示账号固定 `Asia/Shanghai`，真实首次登录时区推断由 WS-308 实现。
- 显式语言偏好保存在本地 `fs-prototype-language`，包含 BCP 47 语言码与设置时间；刷新 / 退出演示后保留。账号端异步持久化与跨设备冲突合并未接入。
- 已知真实主体字段为 `ops_admin_id`、创建时间为 UTC `created_at`。原型 A/B/C 与 `readBy` / `owner` / `accountCreated` 仅是演示映射，不充当正式接口字段；真实接入必须映射到上述主体与共享消息契约。当前无真实个人信息、邮箱、IP 或凭据。

左侧不添加“消息中心”菜单，也不复制资产平台业务菜单。保留已入库的金融服务平台「总览」「协议管理」导航；仓库版可从消息中心进入相应文件，并从其他模块铃铛回到消息中心。单文件导出件保留该导航，但点击外部模块时明确提示使用完整仓库；账号下拉的账户设置指向已入库 P-O05，跨文件进入账户模块需重新走它的演示登录守卫。

## 规则判读及跨模块交接

- D-O03 / D-O07：共享消息与个人消息混排；读取只影响当前管理员；运营端数据与资产管理端隔离。
- D-O13～D-O19：双入口、分页器、计数、原位已读和按筛选跨页全部已读按 PRD 实现演示。新消息在确认执行期间加入时，不进入已冻结的本次批量集合。
- D-O20：按 `01` 7.7 与 AC-O42 的细则，**过期不渲染跳转按钮，删除 / 状态流转 / 无权限禁用按钮并解释**。正文保持可读。
- 映射缺失按运营端 `01` 7.6.3 / AC-O37 显示说明；资产管理端已有原型隐藏说明的特定裁定没有迁入运营端。
- 预检按 `01` 7.6.2 / AC-O40，在进入详情时执行，列表不执行；3 秒超时后放行。有效资源目标点击后明确展示“原型范围说明”，不伪造一个已完成的业务页。
- 自动已读失败不阻断详情、不弹错；显式行内操作失败给予反馈；全部已读失败保持列表及角标不变。
- WS-308 主文档 3.4 和分册 `01-国际化基线.md` 已落定账号字段、顶栏编号、`/ops` 路由及脱敏口径，本次按上节接入，不再把这些决策标为待确认。登录、账户设置页面已通过仓库链接接通；真实账号、首次登录时区写入、跨模块会话同步仍未接入。
- 接入方提供实际 biz_type、分类元数据、文案、业务目标和预检接口。附件中的业务标题和正文均为演示，不构成任何通知触发需求。
