# 金融服务平台原型登记与导出

`registry.js` 是本平台页面 ID、侧栏菜单、模块归属与入口的唯一来源。只登记已经交付的金融平台页面；不导入资产平台的路由、账户或演示数据。`end=admin` 代表控制台画布，通知契约中的业务端仍为 `fs_ops`。

token、公共组件和 shell 继续从仓库现有唯一实现 `asset-platform/prototypes/_shared/` 引用，不复制或另建一套。目录位置是历史归属，复用的是视图与运行时，不共享业务数据。

新增模块沿用资产平台公共层的 `CF.define` 接口及同级目录结构，在本文件旁的 registry 登记后引入公共 shell。账户与登录、消息通知尚未交付原型，因此目前不挂载其入口；后续在此接通本平台页面，不跳转到资产平台页面。

`export.py` 使用 Python 3.9+ 标准库，将协议管理 HTML 引用的 CSS/JS 内联成离线单文件。请在模块 HTML 和公共源上修改，然后重新导出，避免快照成为另一份维护源。用法见协议管理 README。
