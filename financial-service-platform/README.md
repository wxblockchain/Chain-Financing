# 金融服务平台（Financial Service Platform）

金融服务平台包含 **金融服务端** 与 **运营端** 两个端。

本目录收纳金融服务平台的全部 PRD 与原型，让仓库具备平台级边界，不与资产平台的内容混在顶层。已有运营端「协议管理」「账户与登录」「消息通知」「代币合约」原型，入口与覆盖说明见 [原型目录](prototypes/README.md)。

> **WS-313 可信数据同步的运营端两页（`P-O-DS-01` 资产清单 / `P-O-DS-02` 资产详情）不在本目录**：该模块跨资产管理端与运营端，为了让「推送 → 幂等 → 清单」这条跨端链路在同一份原型里连得上，两页随模块一起实现在 [`asset-platform/prototypes/可信数据同步/`](../asset-platform/prototypes/可信数据同步/README.md)，并登记在资产平台的 registry 里（画布端别 `ops`）。因此本平台各原型的侧栏暂时看不到「资产清单」。真正接入运营端控制台时，需决定由哪个平台的文件实现并把这两页补登进本平台 registry——见该模块 README 第 10 节。

## 目录结构

```text
financial-service-platform/
├── prd/          # 金融服务平台的产品需求文档，按模块建子目录
└── prototypes/   # 金融服务平台的原型与平台页面登记
```

## 约定

- 命名与组织方式沿用资产平台：PRD 每个模块一个子目录，入口文件为 `[版本号]-[功能名]-PRD.md`。
- 设计系统 `docs/design-system/` 为两个平台共用，位于仓库顶层，不在本目录内复制一份。
- **国际化、时区、金额、链上地址与哈希、脱敏基线是本平台自持的**，见 [`prd/v1.0-账户与登录/01-国际化基线.md`](prd/v1.0-账户与登录/01-国际化基线.md)；本平台的模块引用这一份，不引用资产平台的对应章节。
- **站内消息契约不自持**：数据契约、`biz_type` 命名空间与编号段位表四端共用一份，定义方是 WS-304，接入规范见 [`docs/notification-contract/接入指南.md`](../docs/notification-contract/接入指南.md)。本平台独立的是**模块、消息池与页面 / 组件编号**（`end = fs_ops`），不是契约。
- 资产平台的内容不要放进本目录，见 [`asset-platform/`](../asset-platform/README.md)。

## 维护规则

- 新增模块时，同一次提交里补上表的一行，并在 [`prd/README.md`](prd/README.md) 的文档索引里登记路径与入口文件。
- 端归属以 PRD 主文档的「覆盖端」字段为准（无该字段时以用户角色表的「所在端」列为准）；PRD 改了覆盖端，本表同步改。
