# 金融服务平台（Financial Service Platform）

金融服务平台包含 **金融服务端** 与 **运营端** 两个端。

本目录收纳金融服务平台的全部 PRD 与原型，让仓库具备平台级边界，不与资产平台的内容混在顶层。**原型目录目前仍为空壳，尚无已确认的原型产物。**

## 目录结构

```text
financial-service-platform/
├── prd/          # 金融服务平台的产品需求文档，按模块建子目录
└── prototypes/   # 金融服务平台的原型（占位目录，待补）
```

## PRD 模块清单与端归属

「端归属」不是推断出来的，优先取自每份 PRD 主文档「文档信息」表里的 **覆盖端** 字段；个别文档没有这一行时，取其用户角色表的「所在端」列。依据逐条写在下表末列，改动 PRD 时请一并核对本表。

| 模块 | 路径 | 对应需求 | 端归属 | 依据（文档内原文） |
| --- | --- | --- | --- | --- |
| 协议管理 | [`prd/v1.0-协议管理/`](prd/v1.0-协议管理/v1.0-协议管理-PRD.md) | WS-310 | **运营端**（金融服务端只读取口径，无界面） | 覆盖端：金融服务平台**运营端** Web（功能主体）；**金融服务端（面客端）**仅涉及「当前生效版本」的读取口径，不涉及界面 |

## 约定

- 命名与组织方式沿用资产平台：PRD 每个模块一个子目录，入口文件为 `[版本号]-[功能名]-PRD.md`。
- 设计系统 `docs/design-system/` 为两个平台共用，位于仓库顶层，不在本目录内复制一份。
- 资产平台的内容不要放进本目录，见 [`asset-platform/`](../asset-platform/README.md)。

## 维护规则

- 新增模块时，同一次提交里补上表的一行，并在 [`prd/README.md`](prd/README.md) 的文档索引里登记路径与入口文件。
- 端归属以 PRD 主文档的「覆盖端」字段为准（无该字段时以用户角色表的「所在端」列为准）；PRD 改了覆盖端，本表同步改。
