## 1. 语言支持

| 项 | 取值 |
| --- | --- |
| 支持语言 | 英文 `en`、简体中文 `zh-CN` |
| **默认语言** | **英文 `en`**（**运营端口径**：本平台独立落定，依据为运营团队含非中文成员；**不读浏览器语言**） |
| 语言码规范 | BCP 47（`en`、`zh-CN`），不使用「中文 / 英文」这类地区式表述 |
| 切换器位置 | 已登录：顶部导航栏右侧；未登录：登录页右上角 |
| **切换器形态** | **下拉选择**：收起态展示**语言图标 + 当前语言缩写**（`EN` / `中文`）与一个下拉箭头；点击展开选项列表，选项以目标语言的自称完整展示（`English` / `简体中文`），当前项带选中标记 |
| 图标 | 使用通用的语言/地球图标，**不使用国旗**（国旗代表国家而非语言） |

## 2. 即时生效

- 切换语言后**当前页面不刷新即完成全部文案替换**，包括导航、面包屑、左侧菜单、表单标签、占位符、按钮、校验错误提示、密码规则清单、Toast、弹窗内文案、空状态、日期与数字格式。
- 已展示在屏幕上的错误提示与倒计时，切换后也必须同步换语言。
- 用户已填写的表单内容在切换语言后**不丢失**。
- **邮件不受语言切换影响**：邮件一封信里同时含中英两份，不按语言偏好择一发送（见主文档 12.3），因此切换语言既不改写已发出的邮件，也不改变后续邮件的内容。**站内信**则按展示时的当前语言选取，切换后历史站内信随之变化。

## 3. 语言判定优先级与双态持久化

### 3.1 判定优先级（三级）

| 优先级 | 来源 | 说明 |
| --- | --- | --- |
| ① | **用户在本浏览器手动切换过的语言偏好** | 持久化在浏览器本地存储，长期保留 |
| ② | **已登录账号的语言偏好** | 未登录态跳过本级 |
| ③ | **英文 `en`（默认）** | 前两级都未命中时使用 |

- **未登录态**：只有 ①③ 生效。全新浏览器首次访问一律英文。
- **浏览器语言不参与判定**：判定链中不存在「读取 `Accept-Language` / `navigator.language`」这一级，**任何情况下都不据此决定界面语言**。
- 判定框架预留扩展位：若后续需要引入新的判定来源，在 ② 与 ③ 之间插入一级即可。

### 3.2 双态持久化

| 状态 | 写入位置 |
| --- | --- |
| **未登录** | 手动切换的语言写入浏览器本地存储，同时记录切换时间 |
| **已登录** | 同时写入浏览器本地存储与账号语言偏好（异步保存），两侧均记录设置时间 |

**冲突处理**：本地手动偏好与账号偏好不一致时，以**较晚的一次显式设置**为准，并回写另一侧，保证两端最终一致。账号偏好保存失败不阻断界面，下次进入静默重试。退出登录后**保留本地语言偏好**。用户显式切换过的语言，任何情况下都不被自动逻辑覆盖。

## 4. 时区与时间展示

| 项 | 规则 |
| --- | --- |
| 存储 | 所有时间以 UTC 存储，审计日志一律 UTC |
| 账号时区 | 账号可选 IANA 时区，在账户设置页的偏好信息区块设置 |
| **默认时区（运营端口径）** | 运营端账号由技术在数据层初始化，**初始化时无浏览器上下文**，`timezone` 初始为空；**首次登录成功时**按浏览器时区自动推断并写入账号；推断失败兜底 `UTC`。写入后不再自动改写，用户可在偏好信息中手工调整 |
| 未登录时区 | 按浏览器时区展示 |
| 展示原则 | 界面上所有时间点**必须带时区标注**，不出现裸时间 |
| 时区标注格式 | 优先展示 UTC 偏移，如 `(UTC+8)`；hover 展示完整时区名 |
| 相对时间 | 24 小时内可用相对时间，hover 展示绝对时间；超过 24 小时一律绝对时间 |
| 倒计时 | 按客户端本地秒数渲染，起点以服务端返回的剩余秒数为准（锁定剩余时间、验证码冷却等） |

> **时区按浏览器推断，这与语言不同**：语言是内容呈现的选择（有明确默认值更可预期），时区是客观事实（推断错了会导致时间显示错误）。

**日期时间格式**

| 场景 | English (`en`) | 中文 (`zh-CN`) |
| --- | --- | --- |
| 日期 | `Sep 7, 2026` | `2026-09-07` |
| 日期 + 时间 | `Sep 7, 2026, 14:30 (UTC+8)` | `2026-09-07 14:30 (UTC+8)` |
| 完整时间戳（审计） | `Sep 7, 2026, 14:30:52 (UTC+8)` | `2026-09-07 14:30:52 (UTC+8)` |
| 时钟制 | 24 小时制（两种语言统一） | 24 小时制 |

## 5. 数字、金额、地址与哈希展示

**数字**：千分位 `1,234,567.89`；小数点 `.`；百分比 `12.34%`；不做大数缩写。两种语言一致。

**金额**（账户与登录模块无金额展示场景，作为平台基线供业务模块引用）

| 规则 | 说明 |
| --- | --- |
| 展示形态 | 金额 + 币种代码，如 `1,234.56 USDT`；法币可用符号 + 代码 |
| 币种代码 | 大写 ISO 4217 或链上代币符号，不做翻译 |
| 符号位置 | 两种语言统一「数值在前、币种代码在后」 |
| 小数位 | 法币 2 位；链上代币默认保留 6 位有效小数并去尾零，详情展示完整精度 |
| 零与空 | 0 展示 `0.00 USDT`；无数据展示 `—` |

**链上地址（地址 / 哈希展示组件）**

| 规则 | 说明 |
| --- | --- |
| 存储 | 全小写 |
| 完整展示 | 按 EIP-55 校验和大小写渲染 |
| 缩略展示 | 前 6 位 + `…` + 后 4 位，如 `0x5aAeb6…eAed` |
| 复制 | 缩略与完整展示处均提供复制按钮（复制完整地址），Toast 提示 `Address copied / 地址已复制` |
| Tooltip | hover 展示完整地址 |
| 字体 | 等宽字体 |

**交易哈希 / 消息哈希**：缩略为前 10 位 + `…` + 后 8 位；复制、tooltip、等宽字体规则与地址一致。

## 6. 区块浏览器跳转

| 项 | 规则 |
| --- | --- |
| 入口呈现 | 复制按钮右侧的外链图标按钮（`↗`）；缩略与完整两种形态下都提供 |
| Tooltip | `View on explorer / 在区块浏览器中查看` |
| 多链 URL 确定方式 | 按数据所属**链 ID** 查「链 ID → 区块浏览器基址」映射表；地址拼 `{基址}/address/{完整地址}`，哈希拼 `{基址}/tx/{完整哈希}` |
| 映射表维护方式 | **由部署配置文件维护**（随部署下发），新增链只需补配置，不改前端代码 |
| 打开方式 | **新标签页**（`target="_blank"` + `rel="noopener noreferrer"`） |
| 降级表现 | 数据未携带链 ID / 链 ID 无对应浏览器 / 映射表未加载成功时，**不展示跳转入口**，只保留复制按钮，不展示置灰按钮或死链接 |
| 无障碍 | 图标按钮需有 `aria-label`，键盘可聚焦、可回车触发 |

> **本平台的映射表与资产平台各自独立配置**：两平台部署环境可能不同，配置项不共用；规则本身一致。

## 7. 文案与翻译规范

| 项 | 规则 |
| --- | --- |
| 术语一致性 | 登录统一用 `Sign in` / `Sign out` |
| 注册术语 | 界面上**不出现** `Sign up` / `Register` / `Create account` 等注册类术语——平台没有注册这个动作 |
| **钱包术语** | 入口与按钮统一用 **`Link external wallet` / 「链接外部钱包」**；地址称 `Wallet address` / 「钱包地址」；签名提示一律 `Sign message`，**禁止** `Confirm transaction` / `Approve`。**运营端登录模块无钱包场景**，本条作为平台基线供后续模块引用 |
| 验证码术语 | `Verification code`，动作 `Send code` / `Resend code` |
| **运营端角色术语（运营端口径）** | 角色统一称 **「运营管理员 / Operations Administrator」**。**不要用「管理员 / Administrator」**——那是资产管理端（WS-302）的角色称谓，两者是两套互不相通的账号体系，混用会在评审与文案上造成误认 |
| 平台与端的称谓 | 本平台文档中「运营端」一律指**金融服务平台运营端**。资产管理端的审核界面在 WS-303 中亦被称作「运营端」，那是另一个端，本平台文档不沿用该措辞 |
| 可选项标注 | 非必填项必须显式标 `Optional / 可选` |
| 变量插值 | 用占位符（`{n}`、`{m}`、`{t}`），不拼接句子片段 |
| 复数 | 英文需处理单复数；中文无复数变化 |
| 布局适配 | 中文文案通常比英文短 20~30%，按钮与标签需自适应宽度；英文长词需支持换行不截断 |
| 缺失兜底 | 缺少中文翻译时回落英文，**不展示文案键名**，构建期报告缺失项 |

## 8. 脱敏基线

> **本节是金融服务平台自己的脱敏基线**（WS-309 D-O23 / DEP-6 的落点），**不引用 WS-302 那份**。
> WS-302 没有集中的脱敏章节，其规则散在 12.4「日志脱敏」、12.6.1.3「邮箱与敏感信息的呈现」、13.5「地址与哈希展示」三处。本节把这些口径收敛成一张表并按运营端补齐，供本平台所有模块引用。

### 8.1 三个口径的定义

| 口径 | 含义 |
| --- | --- |
| **展示** | 出现在界面上（页面、Toast、弹窗、站内信正文、邮件正文）时的形态 |
| **传输** | 跨模块传递时的形态，尤其是**通知契约的 `params`**——消息可能被多人看到、被长期留存 |
| **日志** | 写入审计日志、应用日志、监控埋点时的形态 |

**总原则**：**默认脱敏，例外才明文。** 三个口径中只要有一个不确定，就取更严的那个。

### 8.2 字段清单

| 字段 | 展示 | 传输（含通知 `params`） | 日志 |
| --- | --- | --- | --- |
| **邮箱**（工作邮箱、任何用户邮箱） | 掩码 `a***@example.com`（首字符 + `***` + `@` + 完整域名）。**唯一例外**：本人在自己的账户设置页查看自己的工作邮箱时可完整展示；邮件的收件人字段是必然的明文 | **掩码。完整邮箱不得进入 `params`** | 掩码 |
| **账号主体标识**（`ops_admin_id` 等） | **不在界面上展示原值。** 需要指代某个人时展示 `display_name` + 掩码工作邮箱 | 可传（它是不可枚举标识，本身不含个人信息） | 可记 |
| **姓名**（`display_name`） | 本人查看自己时完整展示；跨人展示场景本期不存在，将来出现时按业务需要决定 | 可传 | 可记 |
| **密码**（任何形态） | **任何情况下不出现明文，也不出现密码提示** | **禁止传输** | **禁止入日志** |
| **验证码** | 只出现在邮件**正文**；不进主题行、不进预览文本、不在界面回显 | **禁止传输** | **禁止入日志** |
| **会话令牌 / 刷新令牌 / 滑块票据 / nonce** | 不出现在任何前端可见位置 | **禁止传输** | **禁止入日志** |
| **IP 地址** | **不展示完整 IP**，只给地区摘要（`Shanghai, CN` / 「中国 上海」） | **完整 IP 不得进入 `params`**，只传地区摘要 | 完整 IP **可记**（审计需要），但不得回流到任何展示口径 |
| **设备摘要** | 浏览器 + 操作系统 + IP 归属地，如 `Chrome on macOS · Shanghai, CN` | 同左（这就是脱敏后的形态） | 同左 |
| **链上地址** | 缩略：前 6 位 + `…` + 后 4 位（第 5 节）；完整值仅在用户主动「复制」时进入剪贴板 | 缩略形态 | 缩略形态 |
| **交易 / 消息哈希** | 缩略：前 10 位 + `…` + 后 8 位（第 5 节） | 缩略形态 | 缩略形态 |
| **证件号码、银行账号、手机号** | **本平台账户与登录模块无此类数据。** 其他模块引入时一律掩码展示（保留首尾、中间以 `*` 替代），具体位数由该模块定义并**回本表登记** | **禁止进入 `params`** | 掩码 |
| **金额** | 按第 5 节格式化展示 | **传数值 + 币种代码**，不传拼好的字符串 | 可记 |

### 8.3 兜底规则

| 规则 | 内容 |
| --- | --- |
| **未登记字段怎么办** | 未在 8.2 出现的敏感字段，接入方按「**不传未脱敏值**」自查（WS-304 `02` 9.5.2 的原则），从严处理，并**回本表登记**——本表是本平台唯一的脱敏基线，靠各模块补齐才不会漏 |
| **通知 `params` 的硬约束** | 通知契约的 `params` 会被展示层长期留存并可能被多人看到（运营端存在共享消息池）。**完整邮箱、完整钱包地址、完整 IP、证件号码一律不得进入 `params`**，由**触发方**脱敏后传入——展示层不负责补脱敏 |
| **内容渲染** | 消息与通知的标题、正文、参数一律按**纯文本**渲染并转义，**不支持 HTML / 富文本 / 外链自动识别**（呼应 WS-309 13.2：富文本渲染会直接构成存储型 XSS 入口） |
| **越权与审计** | 越权访问、敏感操作须记入安全审计日志；日志字段按本节脱敏，保留期遵循各模块的审计口径 |
