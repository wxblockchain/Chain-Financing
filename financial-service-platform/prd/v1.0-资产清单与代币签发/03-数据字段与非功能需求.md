## 14. 数据与字段

### 14.0 字段的归属原则

本模块**不新增独立的代币实体**。签发结果是**资产记录上的一组内聚字段**（`D-TI-xx`），汇率是**独立的配置实体**（`D-FX-xx`）。

| 字段组 | 编号段 | 挂在哪 | 说明 |
| --- | --- | --- | --- |
| 资产推送字段 | `D-DS-01`～`D-DS-19` | 资产记录 | **WS-313 已定义，本模块不重复、不修改。** D-DS-05 钱包地址在 WS-313 V1.3 已改为必填、且取值规则按**企业维度**写明，两边一致；本模块只消费，见 14.1a |
| **链上存证凭证字段【V1.1 新增】** | `D-DS-20`～`D-DS-24`，运营端以 `D-DS-36` 结构存储 | 资产记录 | **WS-313 V1.3.1 已定义，本模块只消费、不重算、不新增。** 五项为存证哈希 / 存证交易哈希 / 区块高度 / 链 ID / 存证时间。与本模块 `D-TI-06` 铸造交易哈希是两笔不同的交易，见分册一 10.5 |
| 运营端清单自有字段 | `D-DS-30`～`D-DS-35` | 资产记录 | **WS-313 已定义，本模块不修改**。其中 D-DS-31 同步状态与本模块的 D-TI-01 签发状态是两根轴、互不写 |
| **签发结果字段（本模块新增）** | `D-TI-01`～`D-TI-20` | 资产记录 | 设计成**内聚的一组**，日后若运营端取得代币生命周期职责，可整组迁出为独立实体 |
| **汇率字段（本模块新增）** | `D-FX-01`～`D-FX-12` | 汇率版本记录 | 独立实体 |

### 14.1a 【V1.1 新增】D-DS-05 数币地址在本模块的消费口径

> 该字段的**定义方是 WS-313**，本节不重复定义类型、必填、格式与取值规则，只写本模块消费它时的口径。**取值规则的唯一事实源是 WS-313 `D-DS-05`**——本 PRD 刻意不复制它的措辞，避免两边日后各自漂移。

| 项 | 本 PRD 的口径 |
| --- | --- |
| 取值维度 | **企业维度——币归公司。** 规则原文见 WS-313 `D-DS-05`：取该资产方企业下**最初完成企业认证的那位成员**绑定的钱包地址（WS-302 `wallet_address`） |
| 实质含义 | **同一企业的所有资产，铸出来的代币都进同一个地址。** 代币归属企业，不归属提交资产的那个人 |
| 运营端的处理 | **拿到哪个用哪个**，不做二次解析。签发前置校验取的就是该资产记录上随报文带来的这一个值（分册一 11.3 第 3 步） |
| 取值正确性由谁保证 | **资产平台侧。** 运营端**无从判断**收到的地址是否真的来自最初认证的那位成员——报文里没有企业下的地址集合，运营端不做这件它做不了的事（`R-TI-12`） |
| 快照性 | 地址随资产入库即固定；认证成员事后改绑钱包**不回溯**已入库资产，已铸代币更不会变动 |
| 对外应答 | J-4 场景的标准答法：代币进的是**企业的统一收币地址**，不是提交人个人绑定的地址。详情页已固定标注该口径（分册一 10.3） |
| 相关条目 | `DEP-TI-06`（已关闭）、`R-TI-01`（已关闭）、`R-TI-12`、分册一 8.1 / 10.3 / 11.3 / 11.7 |

### 14.1 签发状态与流程字段（D-TI-01～D-TI-10）

| 编号 | 字段 | 类型 | 必填 | 枚举 / 校验 | 默认值 | 业务意义 |
| --- | --- | --- | --- | --- | --- | --- |
| D-TI-01 | 签发状态 | 枚举 | 是 | `S-TI-1` 待签发 / `S-TI-2` 签发中 / `S-TI-3` 已签发 / `S-TI-4` 签发失败 / `S-TI-5` 结果待确认 / `S-TI-6` 不予签发。**须实现为可扩展枚举** | `S-TI-1` | 本模块的主轴。与 D-DS-31 同步状态互不写 |
| D-TI-02 | 拦截 / 失败原因码 | 枚举 | 否 | 见 15.1 `E-TI-01`～`E-TI-06` | 空 | 仅 `S-TI-4` / `S-TI-6` 有值；状态离开这两态时清空并在时间线留档 |
| D-TI-03 | 拦截 / 失败原因描述 | 文本 | 否 | ≤ 200 字 | 空 | 对原因码的补充（如链上回执原文摘要），面向 J-2 与 J-4 |
| D-TI-04 | 首次触发时间 | 时间 | 否 | UTC 存储 | 空 | 第一次进入签发前置校验的时刻 |
| D-TI-05 | 交易提交时间 | 时间 | 否 | UTC 存储 | 空 | 最近一次向链上提交交易的时刻 |
| D-TI-06 | **铸造**交易哈希 | 文本 | 否 | `0x` + 64 位十六进制 | 空 | 最近一次提交的**代币铸造**交易哈希；展示按脱敏基线缩略。**【V1.1 澄清】** 与 WS-313 `D-DS-21` 存证交易哈希是两笔不同的交易，页面上两者都必须带限定词（分册一 `B-02`） |
| D-TI-07 | 签发完成时间 | 时间 | 否 | UTC 存储 | 空 | 链上确认成功的时刻，仅 `S-TI-3` 有值 |
| D-TI-08 | 链上状态最近查询时间 | 时间 | 否 | UTC 存储 | 空 | 仅 `S-TI-5` 路径产生 |
| D-TI-09 | 重试次数 | 整数 | 是 | ≥ 0，**不设上限** | `0` | 人工重试的累计次数；补扫自动重发**不计入**该值，只在时间线留痕（避免把系统行为记成人的操作） |
| D-TI-10 | 签发时间线 | 结构数组 | 是 | 只增不改 | 空数组 | 见分册一 10.4。每条含时间、事件类型、操作人、关键值 |

### 14.2 代币与换算快照字段（D-TI-11～D-TI-20）

> 这一组在**提交链上交易之前**整组写入，写入后**永不修改**（分册二 12.9【红线】）。重试时整组覆盖重写，旧值在 D-TI-10 时间线留痕。

| 编号 | 字段 | 类型 | 必填 | 枚举 / 校验 | 默认值 | 业务意义 |
| --- | --- | --- | --- | --- | --- | --- |
| D-TI-11 | 代币数量 | 数值 | 否 | ≥ 0.01，2 位小数（`decimals=0` 时为整数） | 空 | = D-TI-18（1 美元 = 1 代币）。仅 `S-TI-3` 在列表展示 |
| D-TI-12 | 所属合约 | 文本 | 否 | 合约名称 + 合约地址 | 应收账款铸币合约 | 本期恒为应收账款铸币合约 |
| D-TI-13 | 所属链 | 文本 | 否 | 链名称 | 随合约配置 | 展示用 |
| D-TI-14 | 快照 · 汇率值 | 数值 | 否 | > 0，6 位小数 | 空 | 签发时刻该币种的当前生效汇率 |
| D-TI-15 | 快照 · 汇率生效时间 | 时间 | 否 | UTC 存储 | 空 | 所用汇率版本的生效时间 |
| D-TI-16 | 快照 · 汇率来源说明 | 文本 | 否 | ≤ 100 字 | 空 | 直接取自汇率版本的来源说明，面向 J-4 应答 |
| D-TI-17 | 快照 · 汇率版本标识 | 系统 | 否 | 指向 D-FX-01 | 空 | 用于从资产详情反查汇率历史版本页 |
| D-TI-18 | 快照 · 换算后美元金额 | 数值 | 否 | 2 位小数，向下截断后的值 | 空 | 换算结果 |
| D-TI-19 | 快照 · 被截断部分 | 数值 | 否 | ≥ 0，最多 6 位小数 | 空 | 显式展示；无截断时为 `0` 并展示「无截断」 |
| D-TI-20 | 实际收币地址 | 文本 | 否 | `0x` + 40 位十六进制 | 空 | 取自链上交易的实际到账地址，与 D-DS-05 并列展示、不一致时高亮 |

> **代币数量与法币金额不得混算**：D-TI-11 是代币计数，D-TI-18 是美元金额，D-DS-08 是原币金额。三者在任何汇总、排序、导出中**不得相加**（沿用 WS-313 CU-01～CU-05 的跨币种不求和原则）。

### 14.3 汇率版本字段（D-FX-01～D-FX-12）

| 编号 | 字段 | 类型 | 必填 | 枚举 / 校验 | 默认值 | 业务意义 |
| --- | --- | --- | --- | --- | --- | --- |
| D-FX-01 | 汇率版本标识 | 系统 | 是 | 全局唯一 | 系统生成 | 被 D-TI-17 引用 |
| D-FX-02 | 源币种 | 枚举 | 是 | `CNY` / `HKD` / `USD` / `KYD` / `NGN`（取 WS-313 D-DS-07 枚举，**不可自定义**） | 无 | 汇率表的组织维度 |
| D-FX-03 | 目标币种 | 枚举 | 是 | **恒为 `USD`** | `USD` | 本期不做多目标币种 |
| D-FX-04 | 汇率值 | 数值 | 是 | **> 0，最多 6 位小数** | 无 | `1 <源币种> = X USD` |
| D-FX-05 | 生效时间 | 时间 | 是 | 精确到分钟，UTC 存储；**不得早于提交时刻** | 无 | 版本生效的时点；禁止追溯生效 |
| D-FX-06 | 来源说明 | 文本 | **是** | ≤ 100 字 | 无 | 进入换算快照并展示给运营人员用于对外应答 |
| D-FX-07 | 备注 | 文本 | 否 | ≤ 200 字 | 空 | 仅内部可见，**不进入换算快照** |
| D-FX-08 | 版本状态 | 枚举 | 是 | 待生效 / 当前生效 / 历史 / 已被替换 / 已删除 | 按 D-FX-05 判定 | 「当前生效」为派生值，由 12.2 规则实时判定 |
| D-FX-09 | 币种启用状态 | 枚举 | 是 | 启用 / 停用 | 启用 | **挂在币种维度**，停用即该币种无有效汇率 |
| D-FX-10 | 创建人 / 创建时间 | 系统 | 是 | UTC 存储 | 系统写入 | 留痕 |
| D-FX-11 | 最近修改人 / 修改时间 | 系统 | 是 | UTC 存储 | 系统写入 | 仅待生效版本可被修改 |
| D-FX-12 | 操作留痕 | 结构数组 | 是 | 只增不改 | 空数组 | 新增 / 编辑 / 删除待生效 / 启用 / 停用，每条含操作人、时间、变更前后值 |

> **USD 内置行不是一条可维护的 D-FX 记录**：它由系统内置，汇率值恒为 `1.000000`、来源恒为「系统内置」，不可新增、编辑、停用、删除（分册二 12.8）。

## 15. 原因码与文案

### 15.1 签发拦截 / 失败原因码（E-TI-xx）

原因码由运营端产生，**面向运营人员展示在运营端页面**（与 WS-313 的 `E-DS-xx` 不同：那一组只在资产管理端呈现）。

| 编号 | 原因 | 落点状态 | 面向运营人员的文案（中） | 可否重试解决 | 页面附带动作 |
| --- | --- | --- | --- | --- | --- |
| E-TI-01 | 应收账款已到期 | `S-TI-6` | 该应收账款已过到期日，本期不予签发 | 否（终态） | 无 |
| E-TI-02 | 换算后金额小于 0.01 USD | `S-TI-6` | 换算后金额为 {X} USD，小于最小签发金额 0.01 USD，不予签发 | 否（终态） | 无 |
| E-TI-03 | **缺该币种有效汇率** | `S-TI-4` | 币种 {币种} 当前没有生效的汇率配置，无法换算金额 | **是**（补配汇率后） | **「去配置汇率」跳转（L-01～L-04）** |
| E-TI-04 | 链上回执失败 | `S-TI-4` | 链上交易执行失败：{链上回执摘要} | 是 | 「重试」 |
| E-TI-05 | 链上未查到该交易 | `S-TI-4` | 已确认该交易未上链，可以安全重试 | 是 | 「重试」 |
| E-TI-06 | 数币地址缺失（**防御性，常规不可达**） | `S-TI-6` | 该资产缺少数币地址，无法确定收币方，不予签发 | 否（终态） | 无（见分册一 11.6） |

### 15.2 `S-TI-5` 结果待确认的文案

`S-TI-5` **不使用原因码**——它不是失败，是"还不知道"。页面固定文案：

> 「链上回执超时，当前无法确定交易是否已上链。请先查询链上状态，确认未上链后方可重试。」

配「查询链上状态」按钮，**不配重试按钮**。

### 15.3 文案规范

| 项 | 规则 |
| --- | --- |
| 语言 | 中文为主，沿用 WS-308『01-国际化基线.md』第 1～7 节的双语口径与文案规范；本模块不另定义 |
| 不翻译的值 | 币种代码、来源资产 ID、交易哈希、合约地址、数币地址 |
| 占位符 | 文案中的 `{X}`、`{币种}` 等由系统按实际值填充，不得拼成整句再传输（沿用 WS-313 契约级约束 4） |
| 语气 | 陈述事实 + 给出下一步。**不使用"请联系管理员"这类无出路的兜底文案**，除非确实无出路（E-TI-01 / E-TI-02 / E-TI-06） |

## 16. 非功能需求

| 维度 | 要求 |
| --- | --- |
| **性能 · 列表** | 资产清单在 10 万条数据量下，默认筛选首屏加载 ≤ 2 秒；签发概况汇总条与列表同批返回，不额外阻塞首屏 |
| **性能 · 签发触发** | 收单成功到发起签发前置校验的延迟 ≤ 5 秒；定时补扫单轮处理不超过 10 分钟（即不与下一轮重叠，重叠时跳过本轮并记日志） |
| **性能 · 汇率页** | 汇率管理列表币种数量为个位数，无分页要求；历史版本页支持分页 |
| **性能 · 代币清单【V1.1 新增】** | 与资产清单同量级：10 万条数据量下默认筛选首屏加载 ≤ 2 秒；「查看对应资产」的深链定位须在目标页首屏内完成，不得让用户自行翻页查找 |
| **超时口径** | 链上交易 **30 分钟**未取得回执即判超时，落 `S-TI-5`；链上状态查询接口自身超时 15 秒 |
| **一致性【红线】** | 「来源资产 ID」在成功签发上唯一，约束在数据层强制，不得仅靠应用层判重；并发触发同一资产不得产生第二笔链上交易 |
| **幂等** | 同一资产的签发触发可被重复调用，第二次及以后在已有在途交易或已成功时**直接终止且不报错**（分册一 11.3 第 1、2 步） |
| **可追溯** | 签发时间线与汇率操作留痕**只增不改、永久保留**；任何状态变化都能追溯到"谁在什么时候因为什么触发了它" |
| **安全 · 权限** | 四个权限点（主文档 4.3）在服务端强制校验，前端不渲染不等于服务端放行 |
| **安全 · 脱敏** | 数币地址、实际收币地址、合约地址、交易哈希一律按 WS-308『01-国际化基线.md』第 8 节缩略展示；**完整地址不得进入日志、通知参数与导出** |
| **安全 · 不可逆动作** | 重试、停用汇率、删除待生效版本均需二次确认，且确认弹层必须展示影响面 |
| **时间与时区** | 一律 **UTC 存储**；页面按账户时区渲染并带时区标注，**无裸时间**；到期判定按 UTC 日期比较（分册一 11.3） |
| **数字与金额** | 沿用 WS-308『01-国际化基线.md』第 4 节；金额传数值 + 币种代码，不传拼好的字符串 |
| **兼容性** | 沿用运营端既有基线：主流桌面浏览器最新两个大版本；本模块为运营后台，不做移动端适配 |
| **可用性** | 链节点不可用时，签发触发失败不得把资产误判为"未上链"——一律落 `S-TI-5` 或保持原状态并记日志（分册一 11.5） |
| **可访问性** | 状态标签**不得仅靠颜色区分**，须同时有文字；异常行的警示样式须有文本说明；键盘可完成筛选、勾选、重试全流程 |
| **通知** | 【反向】本模块**不产出任何站内信与邮件**，不申请任何 `biz_type` |
| **跨端约束【反向】** | 运营端到资产平台方向**不存在任何接口调用**；本模块不修改、不写回任何资产端字段 |
| **链上约束【反向】【V1.1 新增】** | 运营端**不连链节点、不调区块浏览器 API、不比对存证哈希真伪**；链上存证凭证只存储、展示与跳转（与 WS-313 `AC-DS-74` 同向）。唯一的例外是本模块自己的**铸造交易**：提交交易与查询该交易的链上状态属于签发能力本身，不受此条约束 |
| **只读视图【V1.1 新增】** | 代币清单 `P-O-TI-01` 在服务端也必须是只读的：该页面对应的任何接口**不得提供写入语义**，绕过前端亦然 |
