# 金融服务平台 · PRD 目录

金融服务平台（金融服务端 / 运营端）的产品需求文档统一存放于此，按功能模块组织子目录。
模块的端归属清单见上一级 [`financial-service-platform/README.md`](../README.md)；资产平台的 PRD 不放这里，见 [`asset-platform/prd/`](../../asset-platform/prd/README.md)。

## 约定（沿用资产平台）

- 每个功能模块建独立子目录，入口文件命名为 `[版本号]-[功能名]-PRD.md`，与目录同名。
- 主文档之外的分册用数字前缀（`01-`、`02-`……），主文档开头写导航索引。
- 新增 PRD 时在本文件补一张文档索引表（路径 / 形态 / 对应需求 / 入口文件），参考 [`asset-platform/prd/README.md`](../../asset-platform/prd/README.md)。
- 端归属（金融服务端 / 运营端 / 两端都有）在 [`../README.md`](../README.md) 里用模块清单标注，不按端拆目录。
