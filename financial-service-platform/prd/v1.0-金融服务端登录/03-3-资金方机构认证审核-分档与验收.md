## 10. 完备度分档与权限框架 / Completeness Levels & Permission Framework

> 分档的**判定依据与切换时机**已在 [`03-1`](./03-1-资金方机构认证审核-主体.md) 3.2 定义（含 D-F130「按现行有效结论判定」）。本章只补三件事：留空的权限矩阵骨架、降级表达形式、本 PRD 提供的三条引导文案。

### 10.1 权限矩阵骨架 / Permission Matrix Skeleton（列定死，行由各功能 issue 填入）

| 能力（行）/ Capability | 游客<br/>Guest | 登录（未入驻）<br/>L0 | 登录（未入驻）<br/>L1 审核中 | 登录（未入驻）<br/>L2 已驳回 | 登录（已入驻）<br/>L3 |
| --- | --- | --- | --- | --- | --- |
| *（样例 1）* 填写 / 编辑机构资料 | ❌ | ✅ | **❌** | ✅ | ✅（变更须重审） |
| *（样例 2）* 查看审核进度（只读） | ❌ | **—** 不适用 | ✅ | ✅ | ✅（历史只读） |
| *…（其余业务能力行）* | ⬜ 待业务 issue 填 | ⬜ 待业务 issue 填 | ⬜ 待业务 issue 填 | ⬜ 待业务 issue 填 | ⬜ 待业务 issue 填 |

取值语义（主干分册定义，此处仅复述以便阅读）：✅ 完整 ｜ ◐ 脱敏 ｜ ⊘ 置灰（可见不可点，附引导）｜ ❌ 不可见或直接拒绝。

**两种「空」必须区分（统一段位表口径 `A-1`，硬性）**：**⬜ = 「待业务 issue 填」**（这一格该有取值，只是还没人填）；**— = 「不适用」**（该能力在这一档下不存在这个语义，例如尚未提交申请时无「审核进度」可看）。**不区分会让评审把待填格当成遗漏，或反过来把遗漏当成不适用。**

| 约束 | 说明 |
| --- | --- |
| 列 | **定死为上表五列**，不得增删或改名；L0 / L1 / L2 均属「登录（未入驻）」，L3 即「登录（已入驻）」 |
| 行 | 本 PRD **只提供上面两行**（它们是本 PRD 自己的能力，行归属见统一段位表第 4 章）。其余功能行**不在本 PRD 列举**，由持有该功能的 issue 按同一列定义填入 |
| **行归属界线**（统一段位表 `A-2`） | 资金方列的切分只有一条界线：**凡与「账号 / 凭据 / 会话」有关的行归 WS-315，凡与「机构资料 / 申请单 / 审核」有关的行归本 PRD（WS-316）**。按此判定不会有第三种情况 |
| **新增行** | 由**主干分册**登记行号与归属后，相应册才填取值；**任何册不得自行往总表加行**（统一段位表 `A-3`） |
| **D-F47** | **L0 / L1 / L2 三档的信息可见性完全一致**；差异只在**提示文案与可执行动作**——L0 可填写与提交、L1 只能查看进度、L2 可编辑重提 |
| **D-F77** | 矩阵中的 ⊘ 与 ❌ **全部由平台侧强制**。⊘ 只表示「界面上仍画着这个按钮」，平台侧收到请求照样拒绝 |
| 禁止 | 本 PRD **不臆造**哪些页面 / 字段在哪一档可见——字段级脱敏梯度已被明确移出本模块（简报 5.1 / N-11） |

### 10.2 降级表达形式 / Downgrade Presentation

| 形态 | 用在哪 | 要点 |
| --- | --- | --- |
| **置灰 + 引导**（⊘） | 用户能看到但不能用的能力 | 按钮**不隐藏**（隐藏会让用户以为功能没了），点击后弹受限引导 |
| **受限操作引导** | 用户主动触发受限操作时 | 主干分册组件，本 PRD 只提供文案（10.3） |
| **常驻补全提示条** | 全局 | 主干分册组件；可折叠、**不可永久关闭**，直到补齐（D-F75） |
| **显式降级说明** | L3 → 更低档时 | 站内信 + 下次进入时说明（ST-1、D-F141） |

### 10.3 本 PRD 提供的三条引导文案 / Guidance Copy (L0 / L1 / L2)

| 触发状态 | 缺什么 | 文案 | 主按钮 |
| --- | --- | --- | --- |
| **L0**（未提交 / 有草稿） | 机构资料 | `Complete your institution onboarding to start funding. It takes about {N} steps and your progress is saved as a draft. / 完成机构入驻审核后即可发起出资。现在去填写机构资料（约 {N} 步，可随时保存草稿）。` | `Start now / 去填写` → P-F30，**带回跳**（调用父 issue 的回跳能力） |
| **L1**（审核中） | 等结论 | **纯只读说明**：`Your institution application is under review, with a decision expected within {N} business days. It cannot be edited while under review — if any information is wrong, please contact support. / 机构资料审核中，预计 {N} 个工作日内出结论。审核中无法修改，如资料有误请联系客服。` | `View status / 查看进度` → P-F33；**无撤回、无编辑**；附客服入口 |
| **L2**（已驳回） | 修改资料 | 驳回摘要（问题项条数 + 首条）+ `Update the flagged items and resubmit — you do not need to fill in everything again. / 修改后可直接重新提交，不需重填全部内容。` | `Edit and resubmit / 编辑重提` → P-F30（带高亮回显） |

| 编号 | 文案原则（主干分册定义，本 PRD 遵守） |
| --- | --- |
| D-F71 | **说清缺什么**，不写「无权限」「请先登录」这类不含信息的文案 |
| D-F72 | **给出可点的去处**且**带回跳** |
| D-F73 | **说明补完之后能做什么**，成本与收益放在同一句 |
| D-F75 | 常驻提示条可折叠、不可永久关闭 |
| **D-F76** | **L1 的引导文案不得暗示可以修改**（「如需修改请撤回」属过期文案）。**这是跨状态的禁止性口径**，本 PRD 所有 L1 相关文案（引导、进度页、提交结果页、站内信）一体适用 |

## 13. 与资产端 WS-303 的差异对照 / Divergence from the Asset Platform Baseline

**同构且直接引用、不重写的部分**：状态机形态（11.1）、驳回原因的字段级结构与回显位置（7.5.2）、重提的通用规则与版本语义（7.5.3.1）、**提交限频 N-K05 的口径与数值（7.5.4）**、通过后重提期间原结论有效（7.5.3.3）、唯一键的「作用域 + 归一化编号」格式与归一化规则（9.2 / 9.3）、查重时点与占用释放（9.4）、草稿与分步保存（7.4）、审核留痕与只增不改（7.8.1）、境外编号宽松校验（8.4.3）。

| # | 差异点 | 资产端 | 本 PRD | 为什么 |
| --- | --- | --- | --- | --- |
| **Δ-1** | **主体范围** | 个人认证 + 企业认证两条轨道 | **只有机构（企业）主体一条轨道** | 资金方入驻审的是机构准入资格，本端不做实名认证（N-08）。经办人自然人身份不在本期采集范围 |
| **Δ-2** | **级联规则** | 个人未通过则企业默认不通过（F-K26，强制条款） | **不存在级联** | 无个人认证轨道，级联的前提不成立。审核结论**只由这一份申请单**决定 |
| **Δ-3** | **审核中的约束强度** | 提交后不可编辑（确认弹窗告知），但未把「平台侧硬拒绝 + 客服兜底 + 预览页」列为强制条款 | **提交即锁定为强制条款链**：完整预览页（D-F51'）+ 二次确认明写不可修改不可撤回（D-F52'）+ **平台侧拒绝一切编辑 / 撤回 / 删除**（D-F53'）+ 只读进度（D-F54'）+ 客服兜底（D-F56'） | 用户口径「审核中不允许撤销更改」把提交变成不可逆单向门。删掉撤回而不加强这四处，体验会明显劣于保留撤回的方案 |
| **Δ-4** | **唯一标识口径** | 六套法域模板各自的主注册号；美国另有 EIN 第二唯一键 | **境内 USCC；境外 LEI 优先，其次注册国 + 商业登记号**；LEI 走**全球作用域不带国别前缀** | 平台定位跨境链融，境外资金方是必然场景。LEI 是全球唯一的法人识别码，加国别前缀会让同一法人换注册地后被判成两家（D-F144） |
| **Δ-5** | **模版机制** | 六套**固定**法域模板，由「企业注册地」驱动，模板集合不变 | **可自定义模版 + 模版版本化**，申请单记录提交时的模版版本 | 用户明确「按需自定义模版，后续完善」。字段口径未定，机制必须先于字段就位；版本化是「模版会变」的必然配套（D-F63） |
| **Δ-6** | **驳回原因目录** | 预置问题项绑定固定模板 | 问题项目录**随模版配置下发并绑定模版字段**（D-F140） | 字段可自定义，固定目录必然对不上字段 |
| **Δ-7** ⚠️ | **审核时长的对外表达（本轮保留的有意偏离）** | DK-33：**明确不对用户承诺审核时长**，界面不出现「预计 N 个工作日」「排在第几位」等任何时限文案，也不做超时提醒 | **必须展示预计审核时长**，并在超出后给出提示与客服入口（D-F53'、E-34、[`03-1`](./03-1-资金方机构认证审核-主体.md) 8.4） | **这是全文唯一一条与「引用资产端通用口径、不改数值」直接冲突的偏离，为有意为之、非遗漏。** 理由：资产端用户在审核中虽同样不可编辑，但没有本端这种「已知资料填错却无任何自助出口」的锁定态；本端删除撤回后，审核时长**直接等于用户被锁在等待里的时长**（RISK-02），不做预期管理就只会全部转化为客服工单。**已就此单独向用户提示；若用户要求与资产端一致，改动点仅为 8.4 的「预计时长」一行、E-34 与本行，其余不受影响。** |
| **Δ-8** | **联系邮箱** | 无独立的联系邮箱概念 | 联系邮箱为申请单字段，**与登录邮箱解耦**（D-F69） | 机构对接人换人时改的是联系邮箱，不该被迫走「验旧邮箱 + 全部会话失效」 |
| **Δ-9** | **审核结论的作用域** | 驱动账户综合认证状态（四态），供 WS-302 与业务模块消费 | **只驱动资金方一侧的完备度分档 L0～L3**，按简报 5.2 契约输出 | 本端资产方走 SSO 快照、资金方走入驻审核，两条链路的完备度来源不同，不共用一套综合状态 |
| **Δ-10** | **审核界面归属** | 管理端审核台在同一份 PRD 内（7.6～7.8） | **审核界面归 WS-308**，本 PRD 只输出建议与通过前二次查重要求 | 拆分归属既定；参考了资产端管理端审核也不把界面收进本 PRD |

## 14. 非功能需求 / Non-Functional Requirements

| 类别 | 要求 |
| --- | --- |
| **强制条款：界面隐藏不构成防线** | 以下六条必须由平台侧强制，绕过界面直接发起的请求同样被拒绝：① 审核中拒绝一切编辑 / 撤回 / 删除（D-F53'）；② 提交动作独立校验凭据完备性（[`03-1`](./03-1-资金方机构认证审核-主体.md) 8.2）；③ 权限矩阵的 ⊘ 与 ❌（D-F77）；④ 唯一标识查重（提交时 + 通过时）；⑤ 模版必填与校验规则的平台侧复核；⑥ 审核中期间重提入口的拒绝 |
| 数据一致性 | 提交成功这一刻，申请单记录、唯一标识占用、审核留痕三者同时成立（D-F137）；草稿并发以最后一次保存为准（D-F68）；同一版本被重复提交不产生第二份申请（E-73） |
| 可用性 | 草稿保存在平台侧，跨设备续填；离开页面前有未保存提示；提交类操作有明确的加载与结果反馈，不出现「点了没反应」；关键按钮置灰而非隐藏，并说明置灰原因 |
| 安全与隐私 | 申请材料只能由申请人本人与运营审核员在授权后查看，**不得以任何人可直接打开的公开链接形式暴露**；查重命中提示**不透露占用方任何信息**；审核留痕只增不改不删 |
| 审计 | 提交、重提、通过、驳回、查重拦截、停用与恢复全部留痕并保留当时的提交内容快照；保留期沿用 N-21（180 天） |
| 兼容性 / 可访问性 / 国际化 | 按本平台平台级基线执行（Web 桌面优先；文案、时间、金额格式统一走基线）；本 PRD 全部界面文案提供中英两版 |
| 性能 | 模版配置的加载不阻塞页面首屏；材料上传支持进度反馈、失败重试与断点提示。**具体阈值见 [待确认 Q-04]**，未定前不写死数值 |

## 15. 指标 / Success Metrics

| 编号 | 指标 | 用途 |
| --- | --- | --- |
| **K-10'** | **提交确认页的放弃率**（进入预览页后未提交的比例） | 检验 D-F52' 的确认文案是否吓退了用户 |
| **K-11'** | 驳回率与「因资料填错而被动等待驳回」的占比 | 该占比升高说明提交前预览（D-F51'）没起作用 |
| K-12 | 机构资料一次通过率 | 模版与驳回文案质量 |
| K-13 | 审核时长中位数与 P90 | **本设计下权重最高**：直接决定用户被锁在等待里的时长 |
| K-14 | 身份 / 权限相关客服工单占比 | 客服是纠错兜底路径的唯一入口 |
| K-02 | 登录（未入驻）→ 登录（已入驻）转化率 | 本 PRD 对北极星指标的贡献项 |

> K-11' / K-13 / K-14 **同时升高**即说明「提交即锁定」的缓解措施不足，应重新评估 I-09（审核期自助撤回）。RISK-02 本期不做额外监控建设，指标沿用上表。

## 16. 异常分支 / Exception Branches

| 编号 | 场景 | 处理 |
| --- | --- | --- |
| **E-20** | 重复申请（机构标识码已存在有效主体） | 自动预校验当场拦截 + 客服入口；**不创建申请、草稿保留**；提示不透露占用方信息（[`03-2`](./03-2-资金方机构认证审核-模版与数据.md) 9.3、D-F46） |
| **E-21** | 驳回后重新提交 | 字段级回显，改动后 v+1 回审核中，重新查重（[`03-1`](./03-1-资金方机构认证审核-主体.md) 8.6） |
| **E-22'** | **用户在审核中尝试编辑 / 撤回（含绕过界面直接发起请求）** | **一律拒绝**；界面不提供入口；提示 `Your application is under review and cannot be edited. If any information is wrong, please contact support. / 审核中无法修改，如资料有误请联系客服。`（D-F53' / D-F76） |
| **E-23'** | **用户提交后立刻发现填错** | **无产品内自助路径**；走 8.5 兜底：客服 → 审核员主动驳回 → 修改重提。进度页必须让这条路径可见（D-F56'） |
| **E-25** | 停用后恢复 | 账号回 `active`；申请单结论原样生效，档位按现行有效结论恢复；协议版本未变则不需重新同意 |
| **E-28** | 通过后机构信息变更 | 审核期间原结论继续有效，**权限不中断**；新结论为驳回才降级（D-F50、[`03-1`](./03-1-资金方机构认证审核-主体.md) 8.7） |
| **E-34** | **审核长时间无结论** | 进度页展示预计时长；超出后展示「已超出预计时长」+ 客服入口，**不得让页面停在一个没有出口的等待态**（D-F53'） |
| E-70 | 模版配置缺失或加载失败 | 表单区错误态 + 联系客服；**不允许降级为「什么都不填也能提交」**（[`03-2`](./03-2-资金方机构认证审核-模版与数据.md) 9.1） |
