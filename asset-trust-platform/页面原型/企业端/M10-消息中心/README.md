# M10 消息中心 · 企业端原型

依据 [`PRD/两端共用/M10-消息中心/`](../../../PRD/两端共用/M10-消息中心/01-消息中心-PRD.md)（提交 `91db2ce`），页面结构参照代币发行平台 M7 消息通知原型。消息标题与正文取自来源模块现行 03 消息通知册：M7a（NT01～03）、M7b（NT01～02）、M9（NT01～02）。组件规范 v1.17。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。企业、编号、金额、时间与驳回原因均为演示数据。

## 打开与路径

双击 [`消息中心.html`](消息中心.html)，或使用离线单文件附件。默认进入消息列表；侧栏底部「画面目录 · 演示数据」默认关闭，可到达全部 34 屏，并提供「主流程下一屏」。

- 演示企业同时有债权人、债务人角色：两类消息进入同一个信箱、同一个未读数，正文写明本企业在这笔业务中的身份。
- 主流程：顶栏铃铛 → P01 最近消息 → 查看全部消息 → L01 消息列表 → D02「收到新的确权申请 · AP-DEMO-0041」（打开即已读，未读 4 → 3）→ 面包屑回 L09（该条原地变为已读）→ A02 全部已读确认 → A04 处理中 → A06 成功。
- 详情中的申请编号是前往原业务的入口（M7a / M7b 申请详情）。本平台尚无跨文件联看，点击提示“该入口尚未纳入原型。”。
- 顶栏铃铛同时接入 M1、M3、M7b 等企业端模块；入驻未完成、首登改密与未登录画面不显示消息入口。

## 本期不做与未出屏

- 按 PRD 本期不做：发送、编辑、撤回消息与模板；邮件、短信、浏览器推送；删除、归档；逐条标为已读 / 未读；通知开关；两端未读合计。
- 业务提醒、账户安全两类目前没有来源模块登记企业端消息，列表分类下拉只列出已有分类。
- 未单独出屏（以 PRD 为准）：未登录打开消息链接、登录失效、新消息自动插入、多标签页同步、加载更多（企业端演示不足一批 20 条，画法见运营端 L01 / L07 / L08）。

## 实际核验

Chromium / Playwright：

- 34 屏 × 中英文 × 1280 / 1440 / 1920 px：无脚本错误、无整页横向溢出、无失效跳转；英文模式除演示账号姓名与驳回原因原文外无中文。各屏铃铛未读数与画面一致（读后 4 → 3、全部已读后不显示数字）。
- 点击实测：铃铛开合与 Esc、预览进入详情、编号入口范围提示、面包屑返回、已读状态分段、分类下拉、全部已读确认与 Esc、无未读时全部已读不可用及原因。
- 离线单文件由 `_shared/export.py` 生成，打开时无外部请求。
- 未验证：1280 px 以下、屏幕阅读器、真实消息服务（送达时效、已读保存、权限判断）。
