# M7b 确权待办与确认处理 · 企业端（债务人）原型

依据 [`PRD/企业端/M7b-确权待办与确认处理/`](../../../PRD/企业端/M7b-确权待办与确认处理/01-确权待办与确认处理-PRD.md)，需求提交 `c4e7c34`（含 Q-M7b-01 裁定：债务人不展示出库进度）；申请状态、确权与审核进度环节、当次依据内容按 M7a（`6256723`）。组件规范 v1.15。

原型只用于评审页面、字段和主流程；规则、校验及异常分支以 PRD 为准。企业、编号、金额、VIN、日期和文件均为演示值，菜单待办数量为演示值。

## 打开与路径

双击 [`确权待办与确认处理.html`](确权待办与确认处理.html)，或使用离线单文件附件。默认进入“确权申请 · 待处理”；侧栏底部「画面目录 · 演示数据」默认关闭，可到达全部 22 屏。

- 主流程：L1 待处理 → D1 申请详情 → C1 确认 → D2 已确认（待运营审核，待办数量 4 → 3）。
- 驳回：D1 → R1 驳回（未填写）→ R2 原因为空 → R3 已填写 → D3 已驳回。
- 列表行的“确认”“驳回”打开同一弹窗，取消或 Esc 回到列表；演示只为 AP-DEMO-0031 提供处理画面，其他行提示演示范围。
- 应收账款编号、“查看应收账款当前资料”的去向是 M3 企业端债务人详情（[应收账款与发票](../M3-应收账款与发票/应收账款与发票.html) D1）；本平台尚无跨文件联看，入口按规范提示“该入口尚未纳入原型。”。

## 本期不做与未出屏

- 按 PRD 本期不做：批量确认或驳回、撤回或改结论、确认说明、上传或补正资料、钱包签名、向债务人展示出库进度、全部应付列表、到期前提醒。
- 未单独出屏（以 PRD 为准）：确认提交失败、结果未确认、重复提交 / 两窗口处理、角色被移除、登录失效、待办数量单独取数失败；它们沿用 R4、D8、L6 等画面的提示位置与结构。
- 消息（M7b-NT01～03）由 M10 消息中心承载，本原型不含消息入口。

## 共享层变动

- `frame.js`：画面可用 `data-pending-count` 指定本屏所在菜单的演示待办数量（空值不展示）；未使用该属性的模块不受影响。
- `tokens.css` / `components.css`：文末新增 M7b token 与 A34–A36。
