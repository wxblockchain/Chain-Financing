# M7b 确权待办与确认处理 · UI 设计说明

2026-11-25 · existing-system adaptation · 企业端桌面 console

## 基线与边界

从 `cly-v6.0.0` 的 `66e83e3d` 承接；本模块原型已包含 `7e8f9ca6`、`4b1510b2`。交付前衔接上游最新 PRD `ad5b130b`、原型同步 `c82ff07b`（保留其 README、源码注释及共享消息文案修订，画面仍为 29 屏），并同步 M7a UI `a12b458d` 和 `ddc82337` 的共享层。已核对本 issue 最新用户裁定、PRD、模块 README、共享组件规范与列表详情规范、token、壳层及分区导航。

本轮只深化当前 29 屏的视觉呈现。所有业务值、字段精度、申请状态、校验与处理条件、权限、路由、画面编号及演示导航保留。应收账款详情只读，不补编辑、上传、核实、发起或处理操作；当次依据仍按提交时资料展示，当前资料仍从既有入口查看。不补造原型缺失的业务场景或真实服务能力。

## 设计取舍与实现

沿用现有页面结构和系统字体，不更换品牌、壳层、状态色或进度组件。只调整间距无法解决英文状态被固定操作列遮住、申请入口不够明确、当次依据长页面缺少分组的问题；本轮采用模块内布局变体。没有另建主题或复制共享层。

| 部位 | 本轮变化 | 继承 |
| --- | --- | --- |
| 列表 L1 / L2 / L7 | 英文重分配列宽，金额表头可换行；宽度不足时表内滚动。确认加字重、驳回用危险色，保留三项文字操作。金额用正文字体及等宽数字，币种次要 | 原筛选、分页、固定编号与操作列、时间两行及表头时区、状态圆点、无法折算与原币金额 |

### 维护位置

- `m7b-ui.css`：仅本模块源页加载，所有选择器限定 `.m7b-ui`，使用共享 token，不覆盖全局 token 或共享组件定义。
- `确权待办与确认处理.html`：只增加样式作用域、等义导航短标签和分组标记；A 组原申请链接增加明确文字，原申请编号仍可见。
- `m7b-copy.js`：追加“进度 / Progress”“查看申请详情 / View request details”，业务值不翻译。
- `_shared/*`、`route.js`、PRD、Eval、其他模块未修改。共享视觉语义继续继承；本说明是 M7b 局部变体的维护依据，不取代共享规范。

### 完整值与无障碍

金额保持全值、千分位、小数与币种，不使用缩写。名称、详情字段、条款、长文件名允许换行查看全文；列表保留固定列和区域滚动，不通过隐藏字段换取适配。附件下载沿用图标与可访问名称，公共壳层的显示 / 隐藏与复制操作未改。焦点样式、弹窗焦点捕获及返回均复用共享实现。

### 本轮实测

- Chromium 149.0.7827.55 / Playwright：29 屏 × 中文 / 英文 × 768 / 1024 / 1280 / 1440 / 1920 CSS px，共 290 组。检查整页宽度、字段 / 状态可读性、固定操作列、弹窗边界与初始焦点，无脚本错误、整页横向溢出或状态超出单元格。密集列表在较窄宽度保留表内滚动；1440 px 的中英文待处理列表均完整展示。
- 代表截图人工检查：中英文 × 768 / 1440 px，待处理列表、待确认详情、非美元与差异详情、只读应收详情、驳回结果、确认 / 驳回弹窗。模块没有图表；车辆表核对 VIN 与内采单价两列，金额仍为完整值。
- 中英文实际点击：L1 → D1 → C1 → D2（待办 5 → 4）；R1 → R2、R3 → D3；D1 / D3 / D4 / D5 / D7 与 A1 / A2 / A3 / A4 的双向入口；全部七个分区锚点的定位、焦点与当前项。画面目录仍有 29 项。
- C1 / R1–R4 中英文 Tab / Shift+Tab 均保持在弹窗内，Esc 关闭并回到原触发按钮；列表入口的弹窗取消返回列表。另在 768 / 1440 × 600 px 检查确认和驳回失败弹窗的滚动与底部操作可达。
- 其他实际点击：更多筛选展开 / Esc 收起；D9 确认 / 驳回仍禁用，当次依据重试；A5 局部失败不显示申请状态，重试恢复；面包屑返回；D10 / D11 / A6 无业务资料。长英文公司名、长文件名作为浏览器临时夹具检查完整换行，不写回演示数据。
- 源码与原基线逐屏比较：29 屏 ID、原业务文字、原全部 data-go、画面 data-next / data-base / 身份 / 待办 / 面包屑等属性保持一致；`route.js` 未改。新增可见文字仅“查看申请详情”，分区导航增加等义短标签。
- 从最终源文件导出后检查单文件 29 屏 × 双语：仅加载附件自身，无外部资源请求或脚本错误。源页与导出件比较五个代表画面 × 双语 × 768 / 1440 px，共 20 组截图；关闭过渡动画后，布局与内容对照一致；原生下拉边缘的少量栅格像素差异不作为布局变化。

### 限制与继承

- 22 屏修改呈现；7 屏（L3–L6、D10 / D11、A6）继承原空 / 异常 / 无权结构，均纳入上述全量遍历，不计为本轮重新设计。
- 768 px 以下没有全量验收；独立审查抽查 390 / 600 px 时，390 px 英文共享进度的 Debtor confirmation 略超出步骤宽度，属于原有共享规则，本轮未将其扩成移动端改造。
- 未验证其他浏览器、屏幕阅读器、完整浏览器缩放、真实接口、并发 / 到期边界和实际附件服务。Q-M7b-04 已由上游关闭；到期临界处理引用最新 PRD 和 M7a F-M7a-08，真实业务验收仍由 PRD / Eval 跟踪。静态画面的成功与失败不代表真实服务能力已实现。
- 所有样式均由 M7b 专属文件加载；本轮无全局样式修改，无其他模块业务流程回归声明。共享层同步至 `ddc82337`、保留上游 `c82ff07b` 后完成本轮回归，保留并行产物。
