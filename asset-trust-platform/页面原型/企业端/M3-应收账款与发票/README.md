## 详情结构

页头：应收账款编号，下一行内销发票号与时区；右侧“返回申请”。

1. **概要**：应收账款金额（美元）；债权人、债务人、应收账款起算日、应收账款到期日（不展示剩余天数）、账期、已收款金额（美元）、待收款金额（美元）；右侧到期状态、回款状态、确权申请结果（申请状态与申请编号）。
2. **基础交易**：内销发票（号、原币金额、日期、附件）；内销合同（号，不可点击；附件）。

字段与写法以 M7b F-M7b-05 为准；本目录不再随 M3 PRD 增加企业端内容（如资料校验结果）。
