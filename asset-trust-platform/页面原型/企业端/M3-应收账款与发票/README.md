依据 PRD：[`PRD/两端共用/M3-应收账款与发票/`](../../../PRD/两端共用/M3-应收账款与发票/01-应收账款与发票-PRD.md)（提交 `e2f8eb3`）§11 企业查看应收账款详情。原型只说明页面布局和展示的信息；**规则、校验与异常分支以 PRD 为准**。运营端列表、详情与核实见 [`运营端/M3-应收账款与发票/`](../../运营端/M3-应收账款与发票/README.md)。画面中的企业、编号、金额、日期与文件均为演示数据。

## 打开

双击 [`应收账款与发票.html`](应收账款与发票.html)。企业从 M7a（债权人「应收账款」）或 M7b（债务人「确权申请」）进入本详情；这两个入口及申请详情尚未纳入原型，点击提示“该入口尚未纳入原型。”。在画面目录中切换债权人、债务人画面时，侧栏菜单随业务角色变化。

## 本轮视觉优化（v1.4）

既有系统适配，基于 `9d51dac`；继承原有品牌、组件、业务语义与演示数据。

- 详情页用应收账款编号作为标题，发票号置于副标题；阅读宽度最大 1360 px，分组 / 卡头 / 小节维持 20 / 16 / 14 px 层级，导航当前项加底线，多份合同间增加分隔。
- 摘要里的交易方与到期日逐行展示。平台记录时间在明细表中分为日期、时分两行；ERP 日期原样保留。
- 修复回款交易编号下“同一编号另登记”长说明不换行而覆盖相邻交易方的问题；明细顶部对齐、金额使用 14 px 等宽数字，保留原值与币种。
- 债权人与债务人的字段可见范围不变，运营专属信息仍不可见，债务人收款信息隐藏规则不变；无新增申请、编辑或资料维护入口。
