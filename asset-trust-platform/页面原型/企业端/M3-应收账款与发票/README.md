## 本轮更新与信息顺序

顶部展示应收账款编号、发票号码与到期 / 回款 / 核心资料三个状态；状态在下方字段中不重复。

1. 应收账款信息：编号、双方、金额、账款起算日、天数、到期日。ERP 时区跟随到期日，不单独列字段。
2. 确权与审核进度：进度条紧接应收信息；当前已有的申请保留编号与发起时间，无申请时显示未申请，不补造数据。
3. 发票信息与附件：发票号码、发票开立日期、发票金额、装船日期、附件；首次取得时间仅运营可见。装船日期从应收信息移到这里。
4. 车辆明细：先展示每车一行的列表，再展示数量、合计与附件；运营保留明细核对和 VIN 追溯。
5. 合同信息：多份合同、逐车 VIN / 单价、原值与附件保持。
6. 回款信息：先统计（应收金额、累计已收、未收金额，运营另有回款预警），后 ERP 收款明细。运营 / 债权人八列：交易编号、日期、收款方、付款方、银行、账号、金额、附件；债务人只展示上述可见四列。

删除旧“处理进度”、资料进度、债务人付款记录与付款合计、ERP 对账、同交易编号在其他应收的登记信息。资料补充记录中与已删除付款场景对应的演示记录一并移除；保留记录的来源时间及金额不改。运营的核心资料差异、补充记录、核实记录与风控入口置于底部“资料追溯”。

不改变 ERP 金额精度、币种、日期原值、角色可见范围及核实跳转。列表仍精简，查看固定在右；两端详情继续全宽。运营平台记录时间遵循已确认 PRD，在无运营时区设置时为 UTC；企业端沿用现有偏好。
