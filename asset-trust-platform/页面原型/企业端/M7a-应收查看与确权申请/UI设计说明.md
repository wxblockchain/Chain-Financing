# M7a UI 设计说明

2026-11-27 · WS-670 · 现有系统适配（existing-system adaptation）· 企业端桌面控制台。

依据：`cly-v6.0.0 @ 317f7636`，模块原型 `40b43a46`（39 屏）、PRD `8c40bbaf`、共享组件规范 v1.73 及《列表与详情规范》v1.3。基于前次 UI `a12b458d` 和后续原型同步继续修订，没有回退已确认成果。

## 本轮发现与修订

实测英文 D1b：1024 × 900 px 下，当次依据卡宽 736 px，编号、企业、金额、日期等短字段仍各占一整行，整页高约 3739 px，增加连续核对时的滚动。

本轮仅在现有 M7a 专用 CSS 块增加容器适配：

- `560–761 px` 的事实字段容器内，基础交易 `.basic-trade` 和当次依据 `.claim-snapshot` 的短字段成对排布，标签在上、值在下。
- 长字段和附件继续使用原 `.wide` 跨整行；金额、币种、精度和所有文字完整保留。容器不足 560 px 时继承单列，762 px 起继承既有两列 / 三列规则。
- 独立分区保持纵向排列、各占内容区整行。没有将卡片并排、折叠或固定高度，也没有改变分区顺序与导航。
- 当前申请卡、概要金额 / 状态、列表、批量条、流程弹窗和三环节进度均继承原样。

同条件下 D1b 整页高约 2932 px，减少约 807 px；所有字段与入口仍完整可达。只修改共享层中的 `[data-module="enterprise-claims"]` 限定规则，没有改通用组件阈值、token、壳层、HTML、文案脚本或路由。

本说明同时按最新原型纠正旧文档：M7a 已不展示推送信息或核心资料状态；“运营审核通过”为终态。当次依据仍含美元 / 原币金额、内销发票及附件、内销合同摘要、车辆清单、回款，非美元另有折算汇率。业务口径以现行 PRD 为准。
