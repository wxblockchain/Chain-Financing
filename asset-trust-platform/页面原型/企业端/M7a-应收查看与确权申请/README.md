# M7a 应收查看与确权申请 · 企业端（债权人）原型

依据 [`PRD/企业端/M7a-应收查看与确权申请/`](../../../PRD/企业端/M7a-应收查看与确权申请/01-应收查看与确权申请-PRD.md)，需求提交 `36f756a6`（2026-11-25：申请条件引用 M3“资料齐全且有效（F-M3-15）”、新增“暂无法判断”；列表默认无选择框、到期日与到期状态分两列、不展示申请编号；确权与审核进度三环节，推送进度单独展示）。组件规范见 [`_shared/design-system/`](../../_shared/design-system/组件规范.md)（A46–A48、A50、A90）。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。企业、编号、金额、汇率、日期、VIN、姓名、驳回原因和文件均为演示数据。界面中英双语，未设置语言时为 English（M1-F12）；业务值与驳回原因不翻译。

## 打开与入口

双击 [`应收查看与确权申请.html`](应收查看与确权申请.html)，或用 `_shared/export.py` 导出的离线单文件。左侧菜单“业务”下只有“应收账款”（双角色企业另有债务人的“确权申请”，属于 M7b）。债权人的路径全部在本模块内：

- 应收账款列表 →（编号或“查看”）应收账款详情 →（“确权申请”卡中的申请编号或“查看申请详情”）申请详情。
- 申请详情 →（概要中的应收账款编号）应收账款详情。列表不展示申请编号，也不直接进入申请详情。

M10 消息“前往原业务”按 `route.js` 登记的申请编号进入本模块申请详情。

主流程：

1. 单笔：L1 行内“发起申请” → S1 确认 → S2 提交成功（列表已刷新）→ D1 申请详情。
2. 批量：L1 页头“批量发起申请” → L2 批量选择（行首出现选择框）→ L3 已选 3 笔 → B1 确认（美元合计）→ B2 逐笔结果 → D1b 申请详情（NGN，当次依据含折算汇率）。“退出批量选择”回到 L1，选择框消失、已选清空。
3. 驳回后重新发起：L1“查看”AR-DEMO-0012 → A1 应收账款详情 →“查看申请详情”→ D4 债务人已驳回 →“重新发起”→ A1 →“发起申请”→ A2 确认 → A3 已提交（历次申请两笔）→ D1。

## 演示数据

- 编号沿用全平台的 AR-DEMO / INV / AP-DEMO，与运营端 M3、M9、M7b 和共享演示消息中同一笔记录对齐：AR-DEMO-0012（90,000.00 USD；AP-DEMO-0028 驳回后重新发起 AP-DEMO-0031）、AR-DEMO-0015（EUR）、AR-DEMO-0011 → AP-DEMO-0022、AR-DEMO-0005 → AP-DEMO-0021。AR-DEMO-0018 为本模块新增样本。
- 汇率取运营端 M11 的 FX-DEMO-0003（1 USD = 1,540.20 NGN）。

## 未单独出屏（以 PRD 为准）

- 单笔、批量“提交失败可重试”“提交结果未确认，请在应收账款列表中查看申请状态”，批量“本次没有提交任何申请”、一次提交超过 10 笔整批不处理，提交时登录已结束。
- 其他条件已不满足且资料校验暂无法判断时：申请资格为“不可申请”，在“资料齐全且有效”一条的位置注明“资料齐全且有效暂无法判断”，版式同 A5。
- 应收账款详情中当前申请为“已关闭”“运营审核通过 · 未推送”的写法同 A1、A6；按申请编号或 VIN 查找的结果、筛选无结果沿用 L6；申请详情某一部分读取失败；ERP 关联取消后申请只能从站内消息进入。
- 双角色企业：本模块页面与债权人相同，菜单多一项“确权申请”。
- 本期不做：单独的申请记录列表、撤回申请、申请时上传或补充资料、债务人批量确认、运营批量审核、运营审核不通过；企业端不展示资产健康度、当前车辆清单、回款记录明细与风控预警。

## 实际核验

Chromium / Playwright，导出的离线单文件，中英文 × 1280 / 1440 / 1920 px：34 屏逐屏加载无脚本错误、无整页横向溢出、无外部请求，英文模式除演示账号姓名外无未翻译文案，未设置语言时打开为 English。应收账款列表（含批量选择）中文 1440 px 起完整显示，1280 px 与英文 1440 px 在表内滚动，各宽度操作列可见。默认列表无选择框、无申请编号；三条主流程、“退出批量选择”、列表“查看”进入各应收账款详情均按按钮实际点击通过。共享层只改了 M7a 专用的 `.claim-*` 样式与 `--claim-*` token（选择器限定，其他模块不使用）。未验证 1280 px 以下、屏幕阅读器与真实服务。
