# M7a 应收查看与确权申请 · 企业端（债权人）原型

依据 [`PRD/企业端/M7a-应收查看与确权申请/`](../../../PRD/企业端/M7a-应收查看与确权申请/01-应收查看与确权申请-PRD.md)，需求提交 `6256723`。组件规范 v1.20（先用本平台已有组件，缺少的按代币发行平台基线补齐，见规范 A46–A50）。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。企业、编号、金额、日期、VIN、姓名、驳回原因和文件均为演示数据。

## 打开与入口

双击 [`应收查看与确权申请.html`](应收查看与确权申请.html)，或用 `_shared/export.py` 导出的离线单文件。左侧菜单“业务”下为债权人的两个入口：

- **应收账款**：本企业为债权人的全部应收账款，单笔、批量发起确权申请。
- **申请记录**：本企业发起的全部确权申请，进入申请详情（进度、处理记录、当次依据）。

“申请记录”为本次新增的共享菜单项（`_shared/menu.client.js`），债权人、双角色和入驻锁定菜单同步出现；双角色企业仍另有债务人的“确权申请”（M7b）。应收账款详情属于 M3：本文件内的“查看”与应收账款编号入口按共享层约定提示“该入口尚未纳入原型。”，M3 债权人详情里的“发起申请”见企业端 M3 原型。顶栏消息入口按 M10 共享层加载，预览内的消息跳转在本文件中给范围提示。

主流程：

1. 单笔：L1 行内“发起申请” → S1 确认 → S2 提交成功（列表已刷新）→ D1 申请详情。
2. 批量：L1 勾选 → L2 已选 3 笔 → B1 确认 → B2 逐笔结果（列表已刷新）→ R1 申请记录。
3. 驳回后重新发起：R1 → D4 债务人已驳回 → D5 确认 → D6 已重新发起。

## 画面清单（24 屏，均可从侧栏底部“画面目录”打开）

| 页面 | 编号 | 画面 |
| --- | --- | --- |
| 应收账款列表 | L1 | 默认：选择框、应收账款编号、发票号码、债务人、金额、到期日 / 到期状态、回款状态、申请状态（非“未申请”时带申请编号，可进入详情）、申请资格（不可申请时逐条列出原因）、操作（可申请时“发起申请”，均有“查看”）；批量选择条“已选 0 笔 · 单次最多 10 笔” |

| | B3 | 逐笔结果 · 部分未提交：成功的给编号，未提交的给原因（核心资料待核实、提交失败可重新发起） |
| 申请记录 | R1 | 默认：申请编号、应收账款编号、发票号码、债务人、金额、发起时间、申请状态、状态更新时间（平台时间按本人时区，表头标时区）；同一批量按申请编号排列 |
| | R2 / R3 | 暂无确权申请；申请记录读取失败 |

| | D3 | 运营审核通过（批量发起）；M9 出库进度定义前不展示 |
| | D4 | 债务人已驳回 · 可重新发起：处理记录中驳回原因原文，页头“重新发起申请” |
| | D5 | 重新发起确认弹窗（同单笔确认） |
| | D6 | 债务人已驳回 · 已重新发起：注明新申请编号 |
| | D7 | 债务人已驳回 · 不能重新发起：按钮不可用，原因“已到期”“已收清” |

| | D9 | 该内容不存在或无权查看 |

申请详情顺序：页头申请编号（主操作在右）→ 概要（金额、应收账款编号、发票号码、债务人、到期日；申请状态、发起方式）→ 确权与审核进度（三环节进度条 + 处理记录时间线，只列已发生的环节，运营不显示审核人）→ 当次依据（应收账款信息含三项状态、发票信息与附件、车辆信息明细、合同信息、回款统计）。

## 未单独出屏（以 PRD 为准）

- 单笔 / 批量“提交失败可重试”“提交结果未确认”、批量“本次没有提交任何申请”、提交时登录失效或角色被移除。
- 列表按 VIN、申请编号查找的结果，以及申请记录筛选无结果：沿用 L5 版式。
- 申请详情中某一部分（当次依据、处理记录）读取失败。
- 双角色企业：本模块页面与债权人相同，只是菜单多一项“确权申请”，未单独出屏。
- 本期不做：撤回申请、申请时上传或补充资料、债务人批量确认、运营批量审核、运营审核不通过。

## 实际核验

Chromium / Playwright，导出的离线单文件，中英文 × 1280 / 1440 / 1920 px：24 屏无脚本错误、无整页横向溢出、无外部请求，英文模式除演示姓名外无未翻译文案；1440 px 起中文应收账款列表十列完整显示，1280 px 与英文 1440 px 在表内滚动，选择框、应收账款编号与操作列固定。三条主流程按上述按钮实际点击通过，弹窗 Esc 返回底层画面，D7 重新发起按钮为不可用。共享层改动后，M1、M2、M3 两端、M4、M5、M6、M7b、M9、M10 两端、M11 在中英文 × 三档宽度回归加载、脚本错误与整页溢出，未重跑其业务流程。未验证 1280 px 以下、屏幕阅读器与真实服务。
