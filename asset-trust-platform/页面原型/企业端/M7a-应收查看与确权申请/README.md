# M7a 应收查看与确权申请 · 企业端（债权人）原型

依据 [`PRD/企业端/M7a-应收查看与确权申请/`](../../../PRD/企业端/M7a-应收查看与确权申请/01-应收查看与确权申请-PRD.md)，需求提交 `17f55c72`（2026-11-25：债权人的应收账款详情并入本模块，删去申请记录，金额改用美元，申请详情自带四环节进度）。组件规范见 [`_shared/design-system/`](../../_shared/design-system/组件规范.md)。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。企业、编号、金额、汇率、日期、VIN、姓名、驳回原因和文件均为演示数据。界面中英双语，未设置语言时为 English（M1-F12）；业务值与驳回原因不翻译。

## 打开与入口

双击 [`应收查看与确权申请.html`](应收查看与确权申请.html)，或用 `_shared/export.py` 导出的离线单文件。左侧菜单“业务”下只有“应收账款”（共享菜单 `_shared/menu.client.js` 已删去“申请记录”；双角色企业另有债务人的“确权申请”，属于 M7b）。债权人的路径全部在本模块内：

- 应收账款列表 → 应收账款详情（编号或“查看”）→ 申请详情（当前申请结果或历次申请中的申请编号）。
- 应收账款列表 → 申请详情（申请状态下的申请编号）→ 应收账款详情（概要中的应收账款编号）。

顶栏消息预览进入 M10；M10 消息“前往原业务”按 `route.js` 登记的申请编号进入本模块申请详情。

主流程：

1. 单笔：L1 行内“发起申请” → S1 确认 → S2 提交成功（列表已刷新）→ D1 申请详情。
2. 批量：L1 勾选 → L2 已选 3 笔 → B1 确认（美元合计）→ B2 逐笔结果 → D1b 申请详情（NGN，当次依据含折算汇率）。
3. 驳回后重新发起：L1 AP-DEMO-0028 → D4 债务人已驳回 → “重新发起” → A1 应收账款详情 → A2 确认 → A3 已提交（历次申请两笔）→ D1。

## 演示数据

- 编号沿用全平台的 AR-DEMO / INV / AP-DEMO。与其他模块同一笔记录对齐：AR-DEMO-0012（90,000.00 USD，到期 2026-12-19；AP-DEMO-0028 驳回后重新发起 AP-DEMO-0031）、AR-DEMO-0015（EUR，无法折算）、AR-DEMO-0011 → AP-DEMO-0022、AR-DEMO-0005 → AP-DEMO-0021，与运营端 M3、M9 和共享演示消息一致。
- 汇率取运营端 M11 的 FX-DEMO-0003（1 USD = 1,540.20 NGN）；EUR 没有汇率，因此显示“无法折算”。

## 待确认与未覆盖

- Q-M7a-03：M3、M7b 同步前，企业端 M3 原型（`企业端/M3-应收账款与发票/`）仍在，其中债权人画面与本模块 A 组画面并存；本模块不登记 `receivable:` 路由键，其他模块的应收账款入口仍进入企业端 M3。M3、M7b 中仍有“申请记录”的说法，由各自的 issue 修改。
- 未单独出屏（以 PRD 为准）：单笔、批量“提交失败可重试”“提交结果未确认，请在应收账款列表中查看申请状态”，批量“本次没有提交任何申请”，提交时登录已结束；按申请编号或 VIN 查找的结果、筛选无结果沿用 L5；应收账款详情中当前结果为“已关闭”“运营审核通过 · 未推送”的写法同 A1、A6；申请详情某一部分读取失败；ERP 关联取消后应收账款不再出现在列表中、申请只能从站内消息进入。
- 双角色企业：本模块页面与债权人相同，菜单多一项“确权申请”，未单独出屏。
- 本期不做：单独的申请记录列表、撤回申请、申请时上传或补充资料、债务人批量确认、运营批量审核、运营审核不通过；企业端不展示资产健康度、车辆清单（当前资料）、回款记录明细与风控预警。

## 实际核验

Chromium / Playwright，导出的离线单文件，中英文 × 1280 / 1440 / 1920 px：32 屏逐屏加载无脚本错误、无整页横向溢出、无外部请求，英文模式除演示账号姓名外无未翻译文案；未设置语言时打开为 English。应收账款列表、确认弹窗中的表格在 1280 px（英文到 1440 px）出现表内滚动，操作列在 1280 px 可见。三条主流程及列表“查看”、申请详情中的应收账款编号均按按钮实际点击通过。共享菜单删去“申请记录”后，企业端 M1、M3、M7b、M10 与 index.html 按中英文在 1440 px 回归加载：无脚本错误、无整页溢出，菜单不再出现“申请记录”；未重跑这些模块的业务流程。未验证 1280 px 以下、屏幕阅读器与真实服务。
