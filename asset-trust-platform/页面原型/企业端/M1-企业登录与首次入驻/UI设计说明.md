# M1 · UI 布局深化

2026-11-25｜existing-system adaptation｜企业端桌面 Web，补充窄屏重排检查。

依据原型 `5e5e5b1c`、PRD `1e8a658b` 及用户已确认意见。保持 51 屏、业务字段、演示数据、中英文文案、控件属性和跳转目标；没有新增业务状态或校验。

## 布局变化

- 账户信息：从左侧标题列改为标题上置、编辑同排；宽屏账号与钱包并列，安全与偏好设置并列，个人信息及企业资料通栏。保留细分隔线，以阅读顺序组织内容。
- 完善资料：以连续分区表单呈现个人、企业和组织资料；企业身份信息的标题、说明和字段集中为一个只读面，与补充填写区区分。提交栏保持吸底，上传中说明和禁用按钮同排。
- 企业资料：查看、编辑标题保持同一层级；修复只读登记信息上方半列分隔线。文件改为连续行，完整文件名、大小、时间及时区、下载和移除均保留。
- 绑定钱包与修改邮箱：主操作贴近输入区，说明栏为辅助层；顶部步骤条紧凑，邮箱页面只保留步骤条吸顶。≤1100 px 改为单列；≤600 px 表单单列。
- 登录与密码流程：轻调字段标签和说明间距，密码弹窗步骤与表单间增加分隔。沿用已有可见性、错误、禁用与成功画面。

采用现有系统字体、颜色与间距 token。分区标题 20 px、小节 16 px、字段标签 13 px、字段值 14 px；没有引入联网字体或图片。实现只在共享 `components.css` 的 A89 维护，模块显式启用变体，规范同步为 v1.53。

## 实际核验

- Chromium / Playwright，`file://`，源码和离线附件各 51 屏 × 中英文 × 320 / 375 / 768 / 1000 / 1280 / 1440 / 1920 px，共 1428 次画面渲染；无脚本错误、HTTP(S) 请求或意外横向溢出。窄屏导航仍在其容器内横向滚动。
- 对照原型源码，所有画面标识、文案、交互控件属性及 `data-go` / `data-next` / `data-base` 目标一致。12 个中英文代表画面源码与离线版截图一致。
- 点击实测：登录 → 首登改密 → 重新登录 → 绑定钱包；完善资料提交；个人 / 企业信息编辑与取消；L9 → P1、L10 → A1；修改密码后返回登录。
- 中英文 × 320 / 375 / 768 / 1280 / 1440 / 1920 px，源码与附件分别检查 F1 / F3 在页首、中部、末尾的吸底栏：提交可见，上传中保持禁用，目录不遮挡提交栏。末项必填输入取得焦点后不被提交栏遮挡；邮箱页滚动时步骤条与顶栏不重叠。
- 键盘检查编辑入口、弹窗 Tab 限制和 Esc 关闭后的焦点返回、完整地址展开 / 关闭；现有时区有效值保存与无效值恢复可用。字体实测沿用本机 WenQuanYi Micro Hei 中文回退。
- 720 × 500 CSS px 补查完善资料、上传中、账户、修改邮箱及密码弹窗；未见整页横向溢出。该条件是缩放等效可用空间，不等同于浏览器原生 200% 缩放。
- M2 登录、列表、邀请、详情、账户设置及 ERP 确认弹窗共 6 类 × 中英文 × 3 个桌面宽度回归：DOM 尺寸与计算样式一致；原生控件有少量像素抖动。未改动 M2 源码，未重跑其业务流程。

未验证 Safari / Firefox、真实移动设备及软键盘、完整无障碍审计、真实接口、钱包签名或上传。静态原型的可点击路径不代表这些服务已实现。

## 审阅与运行

附件 `企业登录与首次入驻-UI优化.html` 可下载后双击离线打开，无需服务。画面目录仍提供全部 51 屏及主流程跳转；关闭弹窗后可继续打开目录。跨模块联看请从完整仓库的 `页面原型/index.html` 进入。

源文件为本目录 HTML 与共享层，附件由原有导出工具生成，生成件不入库：

```bash
python3 _shared/export.py --source 企业端/M1-企业登录与首次入驻/企业登录与首次入驻.html --output <仓库外路径>.html
```
