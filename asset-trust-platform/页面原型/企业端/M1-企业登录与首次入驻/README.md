# M1 · 企业登录与首次入驻（企业端）

邮箱密码登录、首登强制改密、自助找回密码、平台内入驻准备（绑定钱包 → 完善资料与组织资料）、按业务角色开放的菜单、账户信息查看与维护、修改密码。

- PRD 基线：`cly-v6.0.0` 提交 `de6affb` 的四册：[功能](../../../PRD/企业端/M1-企业登录与首次入驻/01-企业登录与首次入驻-PRD.md)、[流程](../../../PRD/企业端/M1-企业登录与首次入驻/02-企业登录与首次入驻-流程图与状态机.md)、[通知](../../../PRD/企业端/M1-企业登录与首次入驻/03-企业登录与首次入驻-消息通知.md)、[验收](../../../PRD/企业端/M1-企业登录与首次入驻/04-企业登录与首次入驻-验收.md)。
- 视觉口径：本平台 [`_shared/` 组件规范 v1.25](../../_shared/design-system/组件规范.md)，基线为代币发行平台组件规范 v1.96；展示约定参考《资产可信平台列表与详情展示参考规范 v1.0》。
- **规则、校验与异常分支以 PRD 为准。** 原型只画规则生效后的画面，不实现校验、计时、锁定或状态机。画面中的企业、邮箱、地址、时间均为演示数据。

## 打开方式

- 源码：双击 [`企业登录与首次入驻.html`](企业登录与首次入驻.html)（引用 `../../_shared/`），默认进入登录页。
- 单文件：在 `页面原型/` 下执行 `python3 _shared/export.py --source 企业端/M1-企业登录与首次入驻/企业登录与首次入驻.html --output <仓库外路径>.html`。生成件不入库。
- 左下角（窄屏右下角）「画面目录 · 演示数据」默认关闭，按“页面 → 状态”列出全部画面，并提供「主流程下一屏」。界面语言在顶栏切换，默认 English。

## 主流程

L1 登录 → P1 设置新密码（成功即登录，进入平台）→ W1 填写地址并连接钱包 → W2 钱包已连接、等待签名（用目录「主流程下一屏」推进）→ F1 填写资料并上传组织资料，提交 → A1 账户信息 · 账号设置（默认页面）→ A7 企业信息 → C1 / C2 修改密码 → L5 重新登录。

- 入驻在平台内进行，只有两步：绑定钱包、完善资料。入驻期间侧栏按本企业角色列出全部菜单，带锁形标记、不可点击，点击提示“完成入驻后可用”；提交资料后解锁。
- 首登改密（P1）、运营重置后改密（P3）、找回密码（R4）设置成功即登录：P1 进入入驻，P3 / R4 以已完成入驻的账号演示，进入账户信息。本人在账户信息中修改密码（C2）后回到登录页重新登录（L5）。
- 账号入口（右上角）：入驻期间只显示登录邮箱与退出；完成入驻后显示姓名，展开为登录邮箱、业务角色、账户信息、退出登录。
- 完善资料时点击已完成的“绑定钱包”步骤可查看绑定结果（W7）。
- 业务菜单“应收账款”“申请记录”“确权申请”属于 M7a / M7b，经[仓库联看](../../README.md#仓库联看)进入。

## 设计决定

- **默认页面为“账户信息”**（本轮视觉核验沿用）：它是任何角色组合（含暂无业务角色）都可用、且本模块交付的页面；业务入口在侧栏一步可达。后续若经确认调整为首个业务入口（债权人→应收账款、债务人→确权申请），应在 M7a / M7b 交付后统一核对角色映射、`TP.routes`、L5 / F1 与各返回入口；本轮不改去向。
- 首登改密与找回密码在登录前完成，使用 focus 骨架；绑定钱包与完善资料在平台内完成，两步进度在入驻卡片顶部始终可见。入驻卡片随内容区铺满；绑定钱包右侧放“绑定流程”栏说明当前子步骤与支持网络，避免右侧大块留白。
- “绑定后不可更换或解绑”在填写地址页以警示条展示，同页直接“连接钱包”；地址格式或占用检查不通过时原因显示在地址下方，不唤起钱包。连接成功后进入等待签名，并排展示填写的地址与钱包当前地址，便于核对。
- 账户信息用页内页签分为“账号设置”（账号、钱包、个人信息、账户安全、偏好设置）与“企业信息”（基本信息、组织资料）；账号入口和侧栏“账户信息”进入账号设置。角色差异只影响账号设置中的业务角色与侧栏菜单，企业信息以债权人身份演示。
- 组织资料在完善资料和账户信息中都放在独立分区：上传区说明格式、大小与份数，下方列出文件（文件名可预览，右侧下载、移除）。
- 登录邮箱只在“账号”分区展示一次，不在“个人信息”分区重复。
- 资料表单的企业身份信息只读核对，与企业补充信息分开；运营登记的联系信息（联系人、联系电话、联系邮箱）不出现在任何画面。
- 修改密码沿用代币发行平台的两步弹窗（验证当前密码 → 设置新密码）。
