# 资产可信平台 · 页面原型

原型只说明页面布局和展示的信息；规则、校验与异常分支以 [PRD](../PRD/README.md) 为准。画面中的企业、邮箱、地址、时间均为演示数据。

## 打开

完整同步 `页面原型/` 后双击 [`index.html`](index.html)，选择端与身份进入，无需启动服务：

- 企业端：未登录 / 入驻准备中 / 债权人 / 债务人 / 债权人与债务人。
- 运营端：未登录 / 运营管理员。

进入后就是真实壳层：侧栏菜单、账号入口（账户信息 / 账户设置、退出登录）、顶栏消息与页面内的跨模块入口都会打开对应模块，同一标签页切换，支持刷新与浏览器返回。直接双击任一模块 HTML 也可联动。侧栏底部（窄屏右下角）的「画面目录 · 演示数据」默认关闭；展开后顶部可切换端与身份，下方列出当前模块的全部画面和「主流程下一屏」。

## 仓库联看

模块之间的跳转只在仓库中生效，规则与代币发行平台一致：

- `_shared/navigation.js` 读取 `_shared/modules.js` 的模块清单，再按顺序加载各模块目录的 `route.js`。`route.js` 登记“路由 key → 各身份落地画面”，只登记本模块已有画面。
- 菜单 key 先找模块内 `TP.routes`，再找仓库路由。页面内的跨模块入口写 `data-module-key`，同时保留 `data-toast` 作为附件中的提示。
- 记录类入口按编号登记，如 `receivable:AR-DEMO-0012`、`purchaseTrace:AR-DEMO-0012`、`vehicle:LDEMOVIN000000001`、`alert:W-DEMO-0007`、`application:AP-DEMO-0031`、`request:` / `confirmation:`（企业端 M7a / M7b）。消息“前往原业务”使用 `m7a-` / `m7b-` / `m8-` / `m9-<编号>`。
- 只有存在对应记录画面的编号才跳转。未画出的记录提示“演示仅提供部分应收账款 / 车辆 / 预警 / 申请的…画面。”；没有任何画面的单据（收款登记、保单、合同等）提示“该入口尚未纳入原型。”。
- 跨模块时带上当前身份、界面语言与展示时区。同一身份在没有独立画面的模块中沿用另一身份的画面（`variants`），如“债权人与债务人”在 M7a 沿用债权人画面、在 M7b 沿用债务人画面，菜单仍按双角色显示。
- 运营端 M3–M8 的“返回”按钮回到记录对应画面；其他来源用浏览器返回。

## 目录约定

```
页面原型/
├─ index.html                  仓库联看入口（评审工具）
├─ _shared/                    公共层与本平台自持的设计规范
├─ 企业端/<模块号>-<模块名>/    企业端模块：<模块名>.html、模块文案 m<N>-copy.js、route.js、README.md
└─ 运营端/<模块号>-<模块名>/    运营端模块，结构同上
```

- 目录以 PRD 模块号开头，与 `PRD/` 下的端目录一致。PRD 放在 `两端共用/` 的模块按端拆成两个同号目录（如 M3：运营端列表与详情、企业端只读详情）。每个模块只维护自己的 HTML、文案与 README，不复制壳层、菜单、token 或 CSS，也不写行内样式。
- 菜单、账号、演示消息、壳层与通用文案只在 `_shared/` 维护，模块不复制；模块 `m<N>-copy.js` 只放本模块独有或译法不同的文案。
- **新增模块**：建目录 → 写模块 HTML（引用 `../../_shared/`，在 `inbox.js` 之后加 `<script src="../../_shared/navigation.js" data-local-only></script>`）→ 写 `route.js` → 在 `_shared/modules.js` 追加一行 → 在上方模块表追加一行。不需要修改其他模块或 `navigation.js`；其他模块指向本模块的入口改为 `data-module-key`。

| 公共层文件 | 作用 |
| --- | --- |
| `tokens.css`、`components.css` | 唯一 token 与公共组件（基线：代币发行平台组件规范 v1.96） |
| `frame.js`、`display.js`、`asset-icons.js` | 壳层与画面目录、中英文与时区展示（含跨模块提示等公共文案）、网络图标 |
| `common-copy.js` | 两个及以上模块共用、译法一致的英文文案（字段名、单位、操作与提示），在模块文案之前加载 |
| `menu.client.js` | 企业端菜单（按业务角色：应收账款、申请记录、确权申请）与演示账号，全平台一份 |
| `menu.ops.js` | 运营端菜单（按 M2 PRD 菜单表；“平台配置 / 汇率管理”随 M11 追加，待菜单表登记）、演示待办数量与运营演示账号，全平台一份 |
| `detail-nav.js`、`list-filters.js` | 详情分区导航；列表筛选条的展开与查询提示（M3 起，不实现查询；M5、M6、M8 复用） |
| `inbox.js`、`inbox-pages.js` | 顶栏消息入口与最近消息预览（各模块加载 `inbox.js`）；M10 列表与逐条详情的生成（只在 M10 使用） |
| `navigation.js`、`modules.js` | 仅仓库联看：读取模块清单与各模块 `route.js`，跨模块跳转及端与身份切换；导出附件时排除 |
| `export.py` | 生成单模块离线附件 |
| [`design-system/组件规范.md`](_shared/design-system/组件规范.md) | 取值基线、与代币发行平台的差异、本平台新增组件 |

## 导出单模块附件

在 `页面原型/` 下执行（生成件不入库）：

```
python3 _shared/export.py --source <端>/<模块目录>/<模块名>.html --output <仓库外路径>.html
```

附件只内联该模块必要资源，不包括 `navigation.js`、`modules.js`、各模块 `route.js` 或其他模块画面，可在 issue 中直接双击离线打开。跨模块入口提示“此入口在单模块附件中不展开，请在完整原型的 index.html 中打开。”，画面目录提示到仓库中打开 `index.html` 切换端与身份。
