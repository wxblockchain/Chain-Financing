## 打开与主流程

双击 [运营登录与企业管理.html](运营登录与企业管理.html) 打开（需同步 `../../_shared/`；模块英文文案在 `m2-copy.js`）；侧栏底部「画面目录 · 演示数据」默认关闭，展开后按“分组 → 画面”到达全部画面，并提供“主流程下一屏”。

- 登录：没有原目标时进入 M17 首页（仓库联看中跳到首页；单模块附件不含首页，落在 `ent-list`）；有原目标时 `login-target → d-active`
- 邀请：`ent-list → invite-ready → invite-same-name → invite-sent → d-initial → resend-confirm → d-initial-resent`
- 维护：`d-active → edit-ready → edit-changed → d-active-saved → role-confirm → d-role-added`
- 关联 ERP 企业：邀请时（名称一致）`invite-ready → invite-same-name → invite-erp-confirm → invite-sent`；补关联且名称不一致 `d-profile → edit-pre → erp-name-mismatch → edit-erp → erp-confirm → d-profile-linked`（企业名称改为 ERP 名称）；取消关联 `d-both → edit-erp-unlink → erp-unlink-confirm → d-both-unlinked`
- 首次登录：`login-initial → first-empty → first-ready → login-changed`
- 找回密码：`recover-filled → recover-captcha → recover-code → recover-password → recover-ready → login-recovered`
- 本人改密：`settings → password-verify → password-new → login-changed`

生成离线单文件（在 `asset-trust-platform/页面原型/` 下执行）：

```bash
python3 _shared/export.py --source 运营端/M2-运营登录与企业管理/运营登录与企业管理.html --output <仓库外路径>.html
```

## 页面与呈现要点

- 菜单按 PRD F-OP-11 运营端菜单表：首页（不分组）→ 企业 → 资产数据（6 项）→ 风控（风控预警、风控规则、三方数据源）→ 审核 → 数据监控（监控概览、数据接入、数据推送）→ 平台配置（汇率管理），共 16 项（`_shared/menu.ops.js`）。本模块只落地“企业管理”和账号入口，其他菜单在仓库联看中打开对应模块。
- 企业列表：十列，编号 / 企业名称 / 关联 ERP 企业 / 入驻进度 / 业务角色 / 注册国家／地区 / 登录邮箱 / 邀请时间 / 最近登录 / 操作；不展示认证状态和钱包。“未关联”用红色标签，比入驻进度醒目，两个状态列紧跟名称、1280 px 首屏可见。编号进入详情；三个下拉筛选（业务角色、入驻进度、是否关联 ERP 企业，选中即刷新）+ 关键字查找（回车或“查询”生效）；尚无企业时不显示筛选条。表格中文最小 1280 px、English 最小 1520 px，较窄时表内滚动，编号固定在左、操作列固定在右。
- 邀请企业：企业身份、联系人、业务角色与登录账号、关联 ERP 企业四张卡；不出现初始密码输入或展示；同名提醒为确认弹窗，重复企业身份在表单内指向已有企业。注册国家／地区为可查找的下拉，可输入中文或英文名称，只能从选项中选择（`invite-country-search`）。
- 关联 ERP 企业：单选，候选只列可关联的企业，可查找、分页；查不到时说明可能尚未同步或已关联其他平台企业，并可到企业列表查找（`invite-erp-no-match`）。选中的 ERP 名称与企业名称、企业英文名称都不一致时弹出提示（`erp-name-mismatch`），继续后卡内提示保存后企业名称将改为 ERP 名称，保存确认列出名称修改前后。已关联时编辑页只展示当前关联与“取消关联”，与 ERP 名称一致的名称项只读；取消关联后名称不恢复。
- 账号入口：顶栏为界面语言、消息入口（M10 定义）与账号入口（姓名、登录邮箱、运营管理员，账户设置 / 消息中心 / 退出登录）；消息中心不是菜单。首次登录改密只显示登录邮箱与退出。
- 企业详情：页头副行为企业编号、业务角色、时区；关联 ERP 企业（首卡，未关联时卡头红色“未关联”）→ 企业用户与钱包（首次改密完成时间，未完成时写“尚未完成首次改密”；只有从未完成首次改密时卡头有“重发邀请”；不展示账号状态、锁定或找回记录）→ 企业档案（运营维护）→ 入驻资料（企业端维护、只读：资料提交时间、个人信息、企业补充信息、组织资料）→ 操作记录。不展示入驻进度和认证状态。钱包展示地址、网络、控制权验证、绑定时间。组织资料逐份列出文件名、大小、上传时间，点文件名预览、图标下载；单份打不开时只在该行说明并可重试（`d-file-fail`）。页头为“编辑资料”与（仅单一角色时）“增加业务角色”。
- 操作记录按时间从新到旧，动作与结果为主行，操作人和带时区时间为次行，修改前后值与邮件结果放下方。成功但邮件未发出时保留成功结果，邮件提示独立显示。
- 已入驻企业编辑时，注册国家／地区与企业登记号码只读；入驻前可更正（`edit-pre`）。
- 账户设置不展示运营账号状态。
- 企业详情、邀请 / 编辑及账户设置均随壳层内容区全宽展开；档案与资料等分区、邀请 / 编辑表单按两列阅读。原有容器断点下转一列，字段、顺序和操作不变。
- 主流程示例企业外的同类操作按钮可用，点击提示演示范围，不另画重复确认画面。

## v1.2 视觉深化核验（226217a）

上游 aa73779 已记录的核验：87 屏中英文、三种桌面宽度，跳转与翻译、离线依赖检查。以下为本轮视觉深化的实际范围，不将未改画面算作重设计。

| 画面 / 组件 | 本轮变化与覆盖 |
| --- | --- |
| 企业列表 5 屏 | A7 列宽、筛选查询排列、双侧固定列；空 / 无结果 / 失败画面继承同一列表外框，原有提示和入口保留 |
| 邀请主表单 7 屏 | A13 两列与阅读宽度；业务角色、登录邮箱、字段错误、重复身份与服务反馈不变 |
| 企业详情主体 16 屏 | A10 紧凑进度与 A12 两列资料；已入驻、未入驻、锁定、邮件失败等变体沿用原状态与可用操作 |
| 编辑主表单 5 屏 | A13 两列；入驻前可更正身份、已入驻身份只读等规则不变 |
| 其余 54 屏 | 本轮继承未改；确认弹窗的背景页继承上述样式，单独页面未计为重设计。密码与账户设置同时继承 M1 并行共享改进 |

Playwright Chromium 实测：

- 源页 87 屏 × 中文 / English × 1280 / 1440 / 1920 px：无脚本错误、无整页横向溢出，标签与按钮内容未溢出自身盒子；所有既有 data-go / data-base / data-next 目标可达。
- 列表在左右端和中间位置滚动，编号、操作列均完整留在容器内；表格可用键盘方向键滚动。1920 px 两种语言均无需横向滚动。English 最长入驻标签从四行减为两行（1440 px，原演示首行高度从约 104 px 降至 69 px）。
- 逐击核对登录 → 列表 → 邀请 → 同名提醒 → 已发出 → 详情 → 重发邀请；另查编辑、增加角色、重置密码、解锁共 16 段跳转。编辑的“已修改”仍是画面目录里的静态场景，不新增模拟输入逻辑。
- 键盘补查增加角色弹窗循环焦点、Esc 关闭及返回触发按钮；完整钱包地址展开；邀请表单全部输入及提交的焦点未被吸顶区域挡住；详情页滚动时标题位于顶栏下方。
- 用 640 × 500 视口模拟 1280 × 1000 下 200% 缩放的可用空间，补查列表、邀请、详情、增角与改密弹窗，无整页溢出；这不是新增移动端适配承诺。
