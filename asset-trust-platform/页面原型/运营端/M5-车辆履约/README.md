# M5 车辆履约（单车维度）· 运营端原型

依据 [`PRD/运营端/M5-车辆履约/`](../../../PRD/运营端/M5-车辆履约/01-车辆履约-PRD.md)（`cly-v6.0.0` @ `ea5b093e`，WS-674；PRD 已无待确认项）。组件规范 v1.59（A62–A65、A81）；资产数据六模块统一口径见下文“与资产数据其他模块统一”。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。VIN、车辆属性值、单据号码（含出入库单号）、客户、金额、汇率（1 USD = 1,500.00 NGN）与日期均为演示值；Carloha Holding / Carloha Nigeria 不代表实际业务主体。单据编号、主体、客户名称与车辆属性值在英文界面不翻译。

## 打开与路径

双击 [`车辆履约.html`](车辆履约.html)，或从仓库 [`index.html`](../../index.html) 选择运营端进入；左侧菜单“资产数据 / 车辆履约”进入列表。侧栏底部“画面目录 · 演示数据”默认收起，列出全部画面和“主流程下一屏”。

- 主流程：L1 列表 → 点 VIN（…001）→ D1 详情；详情页头不放返回按钮，经面包屑“车辆履约”回到列表，跨模块进入时用浏览器返回。列表中 …002 / …001 / …021 / …012 / …031 / …011 / …015 有详情画面，其余 VIN 提示仅提供部分车辆。
- 其他模块中的 `vehicle:<VIN>` 入口进入对应详情（见 `route.js`）。
- 经[仓库联看](../../README.md#仓库联看)，单据编号进入所在模块已有画面：内销发票号 → M3；外采合同号、外采发票号、内销合同号、外销合同号 → M4；提单号 → M12；清关单号 CC-DEMO-0101（…001）→ M12 本车所在提单 BL-DEMO-5501 的详情并定位到车辆清单中的本车；保单号 → M13；外销收款交易流水号 RC-DEMO-7781 → M14。未画出的单据提示“演示仅提供部分单据的详情画面。”。目标模块没有可承载详情的编号按原值展示、不可点击（D9 的清关单号 CC-DEMO-0150；入库记录与出入库页签中的出入库单号，如 IN-DEMO-1025）。关联预警数量的落点与返回按 M8，演示中提示仅提供部分车辆。
- 明细页签：从页签内的单据编号进入其他模块再返回本车详情时，回到进入前的页签（演示用 `sessionStorage` 记住一次）；直接打开详情时默认“采购”。

## 详情布局

- 概要：当前物流节点作为标题（24 px），后接最新一条物流记录的日期与来源（入库记录为“出入库单号 · 出入库类型”，单号不可点击）；下方所属应收账款；右侧在库情况、关联预警；卡片底部为车辆属性。
- 车辆属性：品牌、车型、外饰颜色三项，取自外采合同车辆明细，按 ERP 原值展示名称、不展示编码；为空时“-”；没有外采合同时“暂无记录”。
- 概要下方两栏：左栏价格链，其下“明细”一张卡，用页签切换采购、内销、运输与保险、外销、出入库，各页签直接展示全部字段，不收起、不展开，没有记录时“暂无记录”。出入库页签为出入库单号（不可点击）、方向、出入库类型、出入库日期四列，新到旧；不展示仓库、库龄与来源订单。
- 右栏“物流节点进度”竖排时间线不变：最新在上并高亮（装船为最新时标“在途”，否则标“最新”）。节点为外采交货、装船、到港、清关、入库、外销出库；入库只由内销收货、销售退库生成，来源为“出入库单号 · 内销收货 / 销售退库”，单号不可点击；其他出入库只影响在库情况。
- 右栏宽 360 px（1440 px 及以上）/ 300 px（1280 px）；左栏不足 720 px 时价格链排成两行。≤ 1100 px 右栏移到概要下方（非本期验收宽度）。

## 与资产数据其他模块统一

- 列表：单一查找框；预警列右对齐，有未处理时 warn 色条数，没有为“无”；状态为带圆点的标签。
- 详情页头删除“返回列表”按钮，经面包屑返回；VIN 下说明行“时区 UTC”（D6 只有 VIN）。
- 概要“关联预警”两行：未处理 N 条（warn 色，可进入）/ 已处理 M 条；未处理为 0 时第一行不是链接；没有任何关联预警为“无”。
- 缺失值按 PRD [缺失值的展示](../../../PRD/运营端/M5-车辆履约/01-车辆履约-PRD.md#placeholder)：取不到或算不出的值为“-”，“无法折算”“无可用汇率”写在“-”下方；“暂无记录”“未关联应收账款”“暂无收款”“未开票”等业务状态照常以文字展示。
- 折算标记沿用 `fx-mark` 信息浮层（当前汇率、生效时间 UTC）。

个性化：页标题为 VIN；概要没有大号主金额，以当前物流节点为标题；明细为五个页签（用户 2026-11-25 确定）；D6 状态区保留“返回列表”。

## 本期不做（按 PRD §1.2）

企业端不提供车辆履约入口，以企业账号访问时按 M2 无权访问处理，本模块不出企业端画面；运营账号待首登改密、锁定的处理按 M2；不提供录入、编辑、删除；不保留原履约追溯中的费用登记、组装质检、出库交付记录和车辆异常事件（出库交付由出入库记录承接）；不展示仓库、库龄、来源订单与车辆的集装箱号；不在本模块判断风控规则，只承接 M8 的关联预警数量。

## 未出屏

PRD 已无待确认项。以下为原型未单独出屏的情况：

- 加载中、无权查看、关联预警加载失败、某一页签加载失败、单据已不再采信、无可用汇率等以 PRD 为准，未单独出屏。
- 演示数值以本模块场景为准，个别车辆的单价与其他模块演示值不完全一致。
