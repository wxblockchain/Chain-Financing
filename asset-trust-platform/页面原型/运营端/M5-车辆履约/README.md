# M5 车辆履约（单车维度）· 运营端原型

依据 [`PRD/运营端/M5-车辆履约/`](../../../PRD/运营端/M5-车辆履约/01-车辆履约-PRD.md)（2026-11-24 需求评审稿，`cly-v6.0.0` @ `b693d078`，WS-660）。组件规范 v1.44；资产数据六模块统一口径见下文“与资产数据其他模块统一”。替换原 M5 车辆物流与履约追溯（旧原型已于 WS-663 删除）。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。VIN、单据号码、客户、金额、汇率（1 USD = 1,500.00 NGN）与日期均为演示值；Carloha Holding / Carloha Nigeria 不代表实际业务主体。单据编号、主体与客户名称在英文界面不翻译。

## 打开与路径

双击 [`车辆履约.html`](车辆履约.html)，或从仓库 [`index.html`](../../index.html) 选择运营端进入；左侧菜单“资产数据 / 车辆履约”进入列表。侧栏底部“画面目录 · 演示数据”默认收起，列出全部画面和“主流程下一屏”。

- 主流程：L1 列表 → 点 VIN（…001）→ D1 详情；详情页头不放返回按钮，经面包屑“车辆履约”回到列表，跨模块进入时用浏览器返回。列表中 …001 / …002 / …011 / …012 / …021 / …015 有详情画面，其余 VIN 提示仅提供部分车辆。
- 其他模块中的 `vehicle:<VIN>` 入口进入对应详情（见 `route.js`）。
- 经[仓库联看](../../README.md#仓库联看)，单据编号进入所在模块已有画面：内销发票号 → M3；外采合同号、外采发票号（PPI-DEMO-0302 定位到该发票）、内销合同号、外销合同号 → M4；提单号 → M12；清关单号 CC-DEMO-0101（…001）→ M12 并定位本车；保单号 → M13；外销收款交易流水号 RC-DEMO-7781 → M14。未画出的单据提示“演示仅提供部分单据的详情画面。”；关联预警数量提示演示仅提供部分车辆（M8 按 VIN 筛选见 PRD M5-Q13）。

## 与资产数据其他模块统一（WS-655，2026-11-23）

按 M3 应收账款、M4 合同信息的呈现口径统一（只统一呈现方式，字段与规则以 PRD 为准）：

- 列表（L1–L4）：删除页标题下的说明句；去掉“查找方式”下拉，改为单一查找框，占位文字列出可查找的单据；“暂无记录”“未关联应收账款”单元格改为“-”占位（读屏读原文字）；预警列右对齐，有未处理预警时以 warn 色直接显示条数（入口与演示提示不变），没有为“无”；外销收款情况、当前物流节点仍为带圆点的状态标签。
- 详情页头（D1–D6）：删除“返回列表”按钮，经面包屑返回；D1–D5 在 VIN 下增加说明行“时区 UTC”（D6 未找到不展示资料，只有 VIN）。
- 概要右侧“关联预警”改为两行：未处理 N 条（warn 色，可进入关联预警）/ 已处理 M 条；未处理为 0 时第一行不是链接；没有任何关联预警为“无”。
- 取不到的值用“-”占位：价格链中尚无外销合同、无外采资料时的单价与收款金额（D3、D4），与同行金额同字号（`components.css` 文末“WS-655 统一 · M5”）。带业务含义的“未开票”“暂无保单”和分段“暂无记录”保留文字。
- 折算标记沿用 `fx-mark` 信息浮层，内容统一为“当前汇率 1 USD = 1,500.00 NGN”“生效时间 …（UTC）”。
- 分层标题：保留“明细”；“进度与核对”在 v1.44 改为左右两栏后不再单列标题（见下文“详情布局”）。

个性化说明（与通用口径不同之处）：

- 页标题为 VIN，不用“当事方 → 当事方”写法：单车没有买卖双方，说明行只写时区（VIN 已是标题，不重复编号）。
- 概要卡没有大号主金额：车辆不是金额对象，左侧以当前物流节点为标题（v1.44），其下为所属应收账款；单价、收款放在左栏价格链中。
- 明细为采购、内销、运输与保险、外销四段，默认收起、可逐段展开（D2 演示全部展开）；某段尚无单据时显示“暂无记录”且不可展开，不用“-”。
- 列表没有比率、进度列，也没有当事方合并列：每车一行，只列关联单据号、外销客户与状态，口径中“比率与进度移到详情”“当事方合为一列”两条在本模块无需改动。
- D6 未找到画面的状态区保留“返回列表”按钮：这是该画面唯一的页内操作，面包屑同样可返回。

## 详情布局（v1.44，用户 2026-11-23 确认）

- 概要：当前物流节点作为标题（24 px），后接最新一条物流记录的日期与来源单据；右侧状态区为在库情况、关联预警。
- 概要下方分两栏：左栏价格链与明细四段；右栏“物流节点进度”竖排时间线，按日期从新到旧，最新一条在最上方并高亮（装船为最新时标“在途”，否则标“最新”），每条为节点、日期、来源单据。滚动时右栏吸附在顶栏下方，记录多时栏内滚动。
- 右栏宽 360 px（1440 px 及以上）/ 300 px（1280 px）；左栏不足 720 px 时价格链排成两行。≤ 1100 px 右栏移到概要下方（非本期验收宽度）。
- 时间线只含 PRD 7.1 的物流记录（外采收货、装船、到港、清关、外销出库）。内销收货、其他入库 / 出库是否进入时间线待 PRD 确定，本版不展示。
- 原“进度与核对”的分区导航随布局调整取消：明细四段默认收起，页面不长，导航不再需要。
