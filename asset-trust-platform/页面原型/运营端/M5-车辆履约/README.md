# M5 车辆履约（单车维度）· 运营端原型

依据 [`PRD/运营端/M5-车辆履约/`](../../../PRD/运营端/M5-车辆履约/01-车辆履约-PRD.md)（2026-11-19 需求评审稿，WS-660）。组件规范 v1.33。替换原 M5 车辆物流与履约追溯（旧原型已于 WS-663 删除）。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。VIN、单据号码、客户、金额、汇率（1 USD = 1,500.00 NGN）与日期均为演示值；Carloha Holding / Carloha Nigeria 不代表实际业务主体。单据编号、主体与客户名称在英文界面不翻译。

## 打开与路径

双击 [`车辆履约.html`](车辆履约.html)，或从仓库 [`index.html`](../../index.html) 选择运营端进入；左侧菜单“资产数据 / 车辆履约”进入列表。侧栏底部“画面目录 · 演示数据”默认收起，列出全部画面和“主流程下一屏”。

- 主流程：L1 列表 → 点 VIN（…001）→ D1 详情 → “返回列表”。列表中 …001 / …011 / …021 / …015 有详情画面，其余 VIN 提示仅提供部分车辆。
- 其他模块中的 `vehicle:<VIN>` 入口进入对应详情（见 `route.js`）。
- 经[仓库联看](../../README.md#仓库联看)：内销发票号 INV-0012 / 0019 / 0021 进入 M3；提单号 BL-DEMO-5501 / 5530 进入 M12 提单详情，…001 的“查看清关明细”进入 M12 并定位本车（其他提单提示仅提供部分提单）。合同信息（M4 新版）、保单信息（M13）、资金收付（M14）尚无原型，单据号提示“该入口尚未纳入原型。”；关联预警数量提示演示仅提供部分车辆（M8 按 VIN 筛选见 PRD M5-Q13）。

## 本期不做（按 PRD §1.2）

企业端不提供车辆履约入口，本模块不出企业端画面；不提供录入、编辑、删除；不展示费用、组装质检、出库交付记录与车辆异常事件（M5-Q03）；不在本模块判断风控规则，只承接 M8 的关联预警数量。
