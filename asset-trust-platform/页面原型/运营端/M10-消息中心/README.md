# M10 消息中心 · 运营端原型

依据 [`PRD/两端共用/M10-消息中心/`](../../../PRD/两端共用/M10-消息中心/01-消息中心-PRD.md)（提交 `91db2ce`），页面结构参照代币发行平台 M7 消息通知原型。消息标题与正文取自来源模块现行 03 消息通知册：M7b（NT03）、M8（NT01）、M9（NT03）。组件规范 v1.29。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。企业、编号、金额、VIN、时间与失败原因均为演示数据。

## 打开与路径

双击 [`消息中心.html`](消息中心.html)，或使用离线单文件附件。默认进入消息列表；侧栏底部「画面目录 · 演示数据」默认关闭，可到达全部 49 屏，并提供「主流程下一屏」。

- 入口：右上角账号入口展开后“账户设置”下面的“消息中心”（侧栏不设消息菜单，用户 2026-11-13 确认），以及每个运营端页面顶栏的铃铛与未读数。
- 主流程：顶栏铃铛 → P01 最近消息 → 查看全部消息 → L01 消息列表（第一批 20 条）→ D02「有新的确权申请待运营审核 · AP-DEMO-0024」（打开即已读，未读 6 → 5）→ 面包屑回 L11（该条原地变为已读）→ A02 全部已读确认 → A04 处理中 → A06 成功。
- 全体运营的消息每人各自记录已读；全部已读确认中写明只改变本人的阅读状态。
- 原动作已办完的消息（已由其他运营管理员处理的预警、已审核或已到期关闭的申请）仍可前往，只能查看当前结果。详情中的申请编号、预警编号进入 M9 / M8 原业务；本平台尚无跨文件联看，点击提示“该入口尚未纳入原型。”。
- 顶栏铃铛同时接入 M2、M3、M4、M5、M6；首登改密等受限登录画面不显示。

## 本期不做与未出屏

- 按 PRD 本期不做：发送、编辑、撤回消息与模板；站外消息；删除、归档；逐条标为已读 / 未读；通知开关；查看他人阅读情况；两端未读合计。
- 本期没有来源模块登记运营端“本人”收件范围的消息，也没有业务提醒、账户安全类消息；分类下拉只列出已有分类。
- 未单独出屏（以 PRD 为准）：未登录打开消息链接、首登改密后回到原消息、登录失效、新消息自动插入、多标签页同步、新开通账号看到的历史消息直接为已读。

## 实际核验

Chromium / Playwright：

- 49 屏 × 中英文 × 1280 / 1440 / 1920 px：无脚本错误、无整页横向溢出、无失效跳转；英文模式除演示账号姓名与失败原因原文外无中文。各屏铃铛未读数与画面一致，P04 显示 99+。
- 点击实测：加载更多、预览开合、面包屑返回、全部已读确认；其他运营端模块中预览的消息与“查看全部消息”经仓库联看进入本模块（附件中给范围提示），不误跳到同名画面。
- 离线单文件由 `_shared/export.py` 生成，打开时无外部请求。
- 未验证：1280 px 以下、屏幕阅读器、真实消息服务（送达时效、已读保存、权限判断）。
