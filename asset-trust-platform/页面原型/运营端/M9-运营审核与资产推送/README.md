# M9 运营审核与资产推送 · 运营端原型

依据 [`PRD/运营端/M9-运营审核与资产推送/`](../../../PRD/运营端/M9-运营审核与资产推送/01-运营审核与资产推送-PRD.md)（2026-11-24 需求评审稿，提交 `b693d078`，WS-610）；当次依据按 M7a §9.4，资产健康度按 M3，预警等级与规则名称按 M8。组件规范 v1.46。原目录“M9-运营审核与资产出库”已随 PRD 改名。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。企业、姓名、编号、金额、VIN、钱包地址、链上交易标识与文件均为演示值，菜单待办数量为演示值。万纳连上链能力（Q-M9-04）与资产数字化平台的调取方式（Q-M9-03）待验证，原型能展示存证凭证与调取记录，不代表能力已实现。

## 打开与路径

双击 [`运营审核与资产推送.html`](运营审核与资产推送.html)，或从仓库 [`index.html`](../../index.html) 以运营端进入“审核 / 运营审核”。侧栏底部「画面目录 · 演示数据」默认关闭，可到达全部 24 屏。

- 审核主流程：L1 待审核 → D1 申请详情 → A1 审核通过 → A2 审核说明为空 → A3 已填写 → D3 审核通过 · 存证中（运营审核角标 4 → 3）→ D4 待推送 → D5 已推送。
- 存证失败：D6 存证失败（页头“重新存证”）→ R1 重新存证确认 → D7 存证中（数据推送角标 1 → 不显示）。
- 推送情况的列表与完整调取记录在 [M15 数据监控](../M15-数据监控/README.md)；详情“查看完整推送记录”经仓库联看进入 M15 推送记录。
- 应收账款编号、“查看应收账款当前资料”、内销合同号、VIN、关联单据（提单 / 保单 / 内销收款）、预警编号是跨模块入口，经仓库联看进入 M3、M4、M5、M12、M13、M14、M8 已有画面；单模块附件中提示到 index.html 打开。

## 本期不做与未出屏

- 按 PRD 本期不做：审核驳回、撤回审核或推送、批量审核、主动发送或手动推送、推送内容修订、调取后的处理回写、企业端查看审核人 / 存证凭证 / 调取记录。原“出库与供数”菜单、出库列表与出库弹窗已删除。
- 未单独出屏（以 PRD 为准）：审核提交失败、结果未确认、“出现新的未处理风控预警”提交拦截、重新存证重复提交与提交失败、当次依据读取失败、推送信息读取失败、登录失效；沿用 A2、D11、D12、L6 的提示位置与结构。
- 消息 M9-NT01～03 由 M10 承载，演示消息见 `_shared/inbox.js`。
