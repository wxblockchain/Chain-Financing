# M17 图形选型与参考页观察

2026-11-27｜用户指定参考：[Huma 透明度看板](https://huma.accountable.capital/)。以下为当日浏览实际页面及切换项所见。

## 参考页：什么数据用什么图形

| 统计内容 | 显示类型 |
| --- | --- |
| 当前供给、储备、抵押率 | 大数字与单位；两条水平对比条辅助比较规模 |
| 历史供给及其两种代币 | 堆叠面积图 |
| 历史储备（切换项） | 单面积图 |
| 储备比率 | 百分比折线，含 100% 参考线 |
| 储备与供给的历史对比 | 同一金额轴的双折线 |
| 资产分类构成 | 横向百分比分段条，下接金额／占比明细 |
| 未偿融资余额 | 折线，附核验日期标注 |
| 月度放款与回收 | 两系列堆叠柱 |
| 资本周转倍数 | 面积图，旁边为每周快照表 |
| 总储备、链、底层资产的分配 | 多级桑基图 |
| 条款、队列、来源、地址 | 数字字段与表格；评级、核验标识是状态信息 |

## 当前首页：按含义选择，而非增加图形数量

| M17 已有统计 | 本次落地 | 判断依据 |
| --- | --- | --- |
| 外采／外销累计数量、成本／收入 | 同一车辆经营区内并列累计金额与数量；当年／本月共用一张对比表，同比与合同价披露紧随对应值 | 总量优先用数字；不同车辆范围的成本、收入不能相加为“业务总额”或拼成利润／完成率 |
| 外采／外销月度或年度趋势 | 数量、金额各一张并列柱；独立小折线保留环比，补充实线／虚线图例 | 比较同单位的两系列，不堆叠外采与外销；无基数环比继续留缺口 |
| 业务周期与盈利的七档车辆数 | 主数字、辅助极值、七档直立频数柱；零档保留，亏损档红色 | 区间有顺序，柱高比较数量；不改为占比或仪表进度 |
| 应收发生额与余额 | 发生额为柱，余额为线并加浅面积；仍共用美元轴 | 区间发生额与时点余额分清形状；面积仅辅助原余额曲线，不能堆叠相加 |
| 历史逾期与逐笔记录 | 原有准确次数／金额、小圆环与明细表保留 | 两种状态来自同一历史集合，圆环有准确笔数支持，空集合保持空环 |

借鉴的是“规模 → 时间变化 → 分布 → 明细”的信息层级及图区与完整数值的配合。M17 没有“总额 → 多级渠道 → 底层资产”的分配链，未增加桑基图；没有真实核验字段，未复制参考页的验证徽章。沿用平台浅色壳层、token 与字体。

示例图来自重构后的真实原型截图；统计日、标准样本与精度沿用原稿。运行、覆盖及限制见 [README](README.md) 与 [UI设计说明](UI设计说明.md)。

最新整页布局将上述六个逻辑板块合为“车辆经营／效率与盈利／应收与逾期”三个连续工作区，图形选型和统计含义不变；详见 [UI设计说明](UI设计说明.md)。
