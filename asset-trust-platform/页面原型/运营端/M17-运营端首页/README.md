# M17 运营端首页 · 页面原型

2026-11-27｜WS-685｜按 cuiluyao 指定的 Huma 参考页重构展示，承接已批准 A 方案及既有 11 屏。默认页和视觉由 hallmark-GPT 完成，状态、入口及组装关系沿用 Hallmark 的实现。

产物类型：existing-system adaptation；surface：console。沿用资产可信平台现有壳层、字体、token、图标、双语和时区展示。M17 此前仅有 PRD。原型形态为画面规格：呈现规则生效后的画面，规则、校验与异常分支以 PRD 为准。

依据：[01 功能册](../../../PRD/运营端/M17-运营端首页/01-运营端首页-PRD.md)、[02 流程与状态机](../../../PRD/运营端/M17-运营端首页/02-运营端首页-流程图与状态机.md)、[04 验收](../../../PRD/运营端/M17-运营端首页/04-运营端首页-验收.md)（PRD 最新提交 8a8aca44，标准样本与 317e877f 一致）。所有业务数字来自 04 标准样本（VIN-08 外采为 NGN，按 1 USD = 1,500.00 NGN 折算），统计日固定为 2026-11-24，不随系统日期变化。原币为 USD 的逾期样本不重复显示一遍相同折算金额。

## 打开

- 双击 [运营端首页.html](运营端首页.html)，或从仓库 [index.html](../../index.html) 选“运营端 · 运营管理员”进入（落地即首页）；运营端任一模块侧栏的“首页”也可进入。

- 源文件是维护源。重新生成附件：在 `asset-trust-platform/页面原型/` 下执行 `python3 _shared/export.py --source 运营端/M17-运营端首页/运营端首页.html --output /tmp/M17-运营端首页-页面原型.html`。生成件不入库。

## 设计与覆盖

一个页面，六个板块。默认画面 H1（`#home-default`）：

| 板块 | 本轮呈现 |
| --- | --- |
| 外采与外销总览 | 外采／外销两张业务数字卡：累计金额为主、数量并列，当年度／本月分行，精确值／同比／披露常显；供应商／终端客户在卡尾直接显示数字；两卡对应周期行同步对齐 |
| 月度趋势 | 数量／金额两组并列柱，独立环比小图及实线／虚线图例；原图形、刻度、月年切换、缺值断线与完整数值表保留 |
| 业务周期 | 平均周期为主值，最长／最短为辅助；七档直立频数柱，保留 0 档、完整天数与排除注明 |
| 总体盈利 | 总体盈利为主值，最高／最低为辅助；七档直立频数柱，亏损档红色，合同价注明保留 |
| 应收账款 | 四项精确数字；发生额柱、余额线及跟随原余额点位的浅面积，同一美元刻度；完整月／年数值表保留 |
| 账款逾期 | 两项历史汇总与小型状态构成圆环；圆环对应现有列表的逾期中 1 笔／逾期已收清 1 笔，准确笔数常显；九列逐笔列表仍为主体，逾期中排前；桌面编号与状态固定两侧，更窄时区域滚动 |

首页画布只保留数据更新时间与刷新（同一行）。延续 A 方案的数字／趋势分工，顶部改为外采／外销业务数字卡，其下直接展示趋势。“首页”标题仍不显示，仅作为读屏可读的 h1 保留；当前位置由侧栏“首页”高亮表示。另去掉了业务范围副标题、统计日与汇率说明、演示数据标签及各板块的口径说明（同比口径、环比读法、账期加权、逾期金额含义、“只比较车价”等），这些口径以 PRD 为准。PRD 要求随数值注明的内容保留：无法折算、合同价、缺少外采交货日期未计入、同比“上年同期为 0”、截至今日。演示数据标识在画面目录入口与本说明中。

使用现有 token，不新建配色或字体体系。原共享层内仅 M17 消费的 `.home-*` 规则已归并至模块 [m17.css](m17.css)，共享层不保留副本；通用卡片、壳层、字体及组件继续引用共享层。1100 px 以下趋势与分布改单列；业务卡周期行在卡内换行，保持完整精度。密集明细表与趋势／分布图在区域内滚动，不压缩金额与日期。数值表用原生 details/summary，支持键盘展开；金额保留两位小数、天数精度及同比精度按样本原值；图中 k 标签为准确简写，完整金额在数值表中可达。最新视觉变化与核验见 [UI设计说明](UI设计说明.md)。

继承未改：其他模块页面内容、账号、消息预览与语言/时区组件。首页入口对共享层与 M2 的改动见下文“首页入口”。

| 编号 | 画面 id | 画面 | 到达方式 | 主流程下一屏 |
| --- | --- | --- | --- | --- |

| H2 | `home-empty` | 暂无资料（全部为 0） | 画面目录 | — |
| H3 | `home-trend-year` | 趋势按年（外采与外销） | H1 趋势“按年” | 按月 → H1 |
| H4 | `home-ar-year` | 发生额与余额趋势按年 | H1 应收账款趋势“按年” | 按月 → H1 |

| L2 | `home-fail` | 首页加载失败 | 画面目录 | 重试 → L1 |
| L3 | `home-cycle-fail` | 单个板块首次加载失败（业务周期，AC-M17-04 场景 1） | 画面目录 | 板块内重试 → H1 |

画面要点（规则生效后的结果，口径见 PRD 3.4、3.5、6.1、7–11）：

- 趋势按月／按年：趋势板块标题右侧与应收账款“发生额与余额趋势”小标题右侧各有一个“按月｜按年”切换，默认按月，两处各自切换；进入或刷新首页回到按月（PRD 7、10.2）。按年为 2025—2026 两期，2026 标“截至今日”；2025 环比为“-”（无上一年），2026 环比与同比一致（外采数量 +150.00%、外采成本 +186.84%、外销数量 +300.00%、外销收入 +333.63%），环比点在下方小图直接标注；应收账款按年为年发生额 100,000.00／200,000.00 USD、年末余额 0.00／130,000.00 USD。暂无资料画面的切换只提示“演示仅提供标准样本的按年画面”。
- 合同价：外采成本累计、当年度注明“含 1 辆合同价”，本月不注明；趋势中 2026-08（按年为 2026）的外采成本在数值表中注明。

- 加载中：刷新不可用；六个板块保留标题、内容位为加载中，不出现 0、0.00 USD 或 0.00%。
- 整页失败：只保留页头与失败提示和“重试”，不显示数据更新时间与任何数字。
- 单板块首次加载失败：仅该板块提示失败并可重试，不显示数字，其他五个板块正常；其余板块失败为同一呈现，未逐一出屏。
- 刷新时单板块失败：数据更新时间为本次刷新时间，失败板块保留上次数字，标题下方提示“本板块更新失败，当前显示 {该板块上次成功取数的时间}（时区）的数据”并可重试。
- 刷新中：按钮显示“刷新中”且不可用，页面数字与数据更新时间保持不变。刷新完成后只更新数据更新时间（演示为 10:25 → 10:40 UTC）。
- 刷新失败：保留上次数字，页头下方提示“数据更新失败，当前显示 {数据更新时间}（时区）的数据”，可再次刷新。
- 暂无资料：总览数字为 0、金额为 0.00（表头单位 USD）；同比为“-”并注明“上年同期为 0”；环比全部为“-”，曲线不画；平均周期、盈利水平、约定／实际账期为“-”，分档均为 0；月末余额为 0 照常连线；逾期 0 次、0.00 USD，圆环仅显示中性空轨道与 0，列表显示“暂无逾期记录”。
- 缺失值统一按 PRD 显示“-”；负数仍用减号“−”（如 −10.00%）。

源文件维护方式：只维护 H1。其余画面用 `data-from="home-default"` 加 `<template data-replace|data-body="板块">` 声明与 H1 的差异，页尾脚本在启动前复制 H1 并替换对应板块（`data-part`：actions、meta、context、overview、trend、analysis、cycle、profit、ar、overdue）。脚本只拼装静态画面，不计算、不请求、不计时；H1 后续视觉调整会自动带到各状态画面。

## 首页入口

“首页”已在 M2 运营端菜单表登记，登录后没有原目标时进入首页（PRD 016a075e，Q-M17-01 已裁定）：

- `_shared/menu.ops.js`：“首页”位于全部菜单之前，不属于任何分组；`frame.js` 的 home 图标，分组名为空时不显示分组标题。
- `route.js` 登记 `home → home-default`，`_shared/modules.js` 含本模块；`navigation.js` 中“运营管理员”的进入点为首页。
- M2 中没有原目标的登录画面点“登录”在仓库联看中进入首页；有原目标的 `login-target → d-active` 不变。M2 单模块附件不含首页，仍落在企业管理。

访问约束沿用 M2：锁定中、待首登改密的账号与企业账号到不了首页（M2 已有对应画面），本模块不另出屏；`data-who="ops"` 只是展示身份，不代表鉴权已实现。

## 应收账款编号往返（部分完成）

逾期明细的 `AR-0003`、`AR-0001` 已按仓库约定写成 `data-module-key="receivable:<编号>"`，返回首页走浏览器返回（地址保留 `#home-default`）。M3 原型目前只有 `AR-DEMO-*` 演示记录的详情画面，没有这两笔标准样本，所以仓库联看中点击提示“该入口尚未纳入原型。”，单模块附件提示到 index.html 打开；没有跳到不同编号的记录冒充闭环。M3 补画这两笔详情并在其 `route.js` 登记 `receivable:AR-0003`／`receivable:AR-0001` 后，本页无需修改即可往返。

- 源页 11 屏 × 中英文 × 1920／1440／1280／768／375／320 px，离线附件 11 屏 × 中英文 × 1440／375 px，共 176 个渲染组合。无整页溢出、长金额／同比裁切、英文漏译、重复 id 或脚本错误；桌面两业务卡周期行对齐。
