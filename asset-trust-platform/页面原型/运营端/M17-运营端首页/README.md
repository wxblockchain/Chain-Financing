## 设计与覆盖

一个页面 H1（`#home-default`），六个板块，默认画面已修改且实测：

| 板块 | 本轮呈现 |
| --- | --- |
| 外采与外销总览 | 累计、当年度及同比、本月四列指标对齐比较；供应商与终端客户另列，保留无法折算与合同价披露 |
| 月度趋势 | 四个指标各一图，月度值为柱、环比为折线且右轴独立；固定近 12 月，本月标截至今日；缺值断线、无法折算不当作 0；每图可展开完整数值表 |
| 业务周期 | 平均、最长、最短；七档横向柱状分布，明确缺少交货日期的排除数量 |
| 总体盈利 | 总体、最高、最低；七档售车分布，亏损文字与图形同时表达，保留仅比较车价和合同价披露 |
| 应收账款 | 发生额、余额、约定及实际账期；发生额柱状、月末余额折线，同一美元刻度；附完整月度表 |
| 账款逾期 | 两项历史汇总，九列逐笔列表，逾期中排前；应收编号固定左侧，其他字段横向可达 |

使用现有 token，不新建配色或字体体系。`.home-*` 规则位于共享 `components.css` 的 M17 专节；仅首页消费。1250 px 以下趋势与分布改单列；小屏密集表格、12 月图表区域内滚动，不压缩金额与日期。数值表用原生 details/summary，支持键盘展开；金额保留两位小数、天数精度及同比精度按样本原值；图中 k 标签为准确简写，完整金额在数值表中可达。

继承未改：其他模块页面、侧栏菜单、账号、消息预览与语言/时区组件。仅为首页的窄屏侧栏限定定位容器，防止隐藏读屏标签撑开文档；不改其余模块。仓库评审入口增加链接，没有改登录默认页或共享菜单。

## 交给 Hallmark 设计师

本轮只有页面展示；刷新和应收编号点击会如实提示“待接入”，不显示假成功，不改数据更新时间。页面没有任何统计计算、请求、状态模拟或定时器。共享脚本仅承接既有展示层能力。

请在本目录源文件和既有共享机制上补齐首页交互与展示逻辑：

1. 参照 PRD 3.5 和 02 流程册补齐首次加载、整页失败、六个板块分别失败、刷新失败保留旧值及重试；本次仅出默认 H1，不算这些状态已经交付。
2. 接入四项趋势与各汇总值的展示；保留 0 与无法折算的区别、环比断点、固定近 12 月、部分月份提示、精度和排除数量。真实统计或 ERP 接口能力需研发核验，静态页面不代表已实现。
3. 将逾期编号接到对应 M3 详情并保证返回首页。标准样本 `AR-0003`、`AR-0001` 尚无仓库详情路由；不要跳到不同编号的演示记录来假装闭环。
4. 待 Q-M17-01 的 M2 菜单冲突解决后，再增加 `route.js`、模块清单、首页菜单和无原目标时的登录落地；有原目标仍返回原目标。本轮没有更改菜单、路由权限或默认落地。
5. 按 M2 处理企业身份、锁定中及待首登改密的访问约束。当前 `data-who="ops"` 只是展示身份，不能作为真实鉴权。
6. 逻辑接入后重导出附件并按 04 册验收；涉及菜单、共享壳层或其他模块时补做相关回归。

PRD Q-M17-01～11 仍按原文保留待确认／待验证属性，本页面仅按推荐口径展示样本，不能视为用户已逐项确认。尤其菜单登记与 M2 正文冲突、当前汇率影响历史指标、外采币种及历史资料／去重身份，需对应专业人员处理，不由视觉稿静默定案。首页不加企业／时间筛选、导出、大屏或图表下钻。

## 实际核验

- Chromium：源页与离线附件 × 中文／英文 × 1440、1280、768、375 px，共 16 个渲染组合；检查截图和 DOM 尺寸，无整页横向溢出，六个板块、四张车辆趋势图和五个数值表可达。
- 键盘 Enter 展开／收起数值表；每张月度表保留 12 行；窄屏逾期表可横向滚至最终状态列。
- 点击刷新和应收编号会披露未接入，不更新时间、不伪造完成结果；两种版本没有页面脚本异常。
- 核对标准样本关键金额、同比、周期／盈利分布、应收月末余额和环比断点；检查离线文件无外部样式与脚本引用。
- 未验证：真实接口、统计实现、刷新成功与失败状态、权限、M3 明细往返、M2 登录落地、跨浏览器和真实设备。它们不在本轮页面展示完成范围内。
