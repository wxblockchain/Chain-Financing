# M17 运营端首页 · UI 设计说明

2026-11-26｜WS-685｜existing-system adaptation · console

基线为执行时最新 `cly-v6.0.0` 的 `8c40bbaf`；继承 Hallmark 的 11 屏及上一轮视觉优化。用户已批准 A 方案：数字看规模，图表看趋势和分布。本轮同步 PRD 中“总览必须图表化”的展示约定，业务口径与标准样本仍按 `8a8aca44`，没有增加业务流程或运行时统计。

## 实际变化

- 总览由数量／金额两张横条卡改为一个数字矩阵：外采／外销两组，累计／当年度／本月三行，数量／金额分列。金额完整保留两位小数，同比紧跟对应当年度值，合同价等披露常显。供应商与终端客户改为直接数字，取消没有增加信息的横条。
- 原四张车辆趋势图收为数量、金额两张对比卡。上方外采蓝／外销青绿并列柱共用数量或美元轴，下方较矮小图独立显示对应环比，不叠加右轴；共享时间位置，实线／虚线辅助区分系列。按年模式保留超过 100% 的真实变化及准确标签，没有截到 100%。无基数环比保持缺口，零值柱为零高，原 12 张完整数值表及披露在原生 details 中可达。
- 逾期汇总旁增加 88 px 小圆环，只表达现有历史逾期记录中的状态构成：逾期中 1 笔、逾期已收清 1 笔。准确笔数与历史金额常显，逐笔表仍为主体。暂无资料不画有色比例，仅显示中性轨道与 0。圆环有双语可访问名称，没有把外采与外销画成完成率或利润占比。
- 业务周期与盈利的主值、辅助值及七档分布，应收四项数字与单美元轴趋势，以及九列逾期表继承未改；亏损红色、桌面固定编号／状态及窄屏表内滚动保留。
- 无可见“首页”标题、更新时间与刷新同一行继续保留；紧凑总览使 1280 px 及以上桌面首屏可见趋势图主体。加载、刷新与失败披露保持原位置和原内容。

## 维护与响应式

展示规则只维护在 [m17.css](m17.css)，新增用语在 [m17-copy.js](m17-copy.js)，未复制共享层或增加全局 token。总览使用带列组的原生表格，窄屏保留 860 px 阅读下限并在区域内滚动；1100 px 以下两张趋势卡与周期／盈利改为单列，图表保留 420 px 阅读下限。滚动区域有可访问名称且可聚焦；数值表支持原生键盘展开。

首页组装脚本、全部跳转／模板属性、月／年默认值、菜单、路由、账号与消息组件均继承未改。图形是现有样本的静态呈现，不新增计算或接口。源页为唯一维护源，离线附件使用 `_shared/export.py` 生成。
