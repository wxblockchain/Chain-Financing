# M17 运营端首页 · UI 设计说明

2026-11-25｜WS-685｜existing-system adaptation · console

基线为执行时最新 `cly-v6.0.0` 的 `c43517bc`，M17 画面为 Hallmark `ee759d7c` 的 11 屏，PRD 已更新至 `8a8aca44`（本轮标准样本没有变化）。按用户已确认方向直接优化，没有重新定义业务流程。

## 呈现变化

- 保留无可见页面标题、只显示数据更新时间与刷新、进入即见图表的画布。六板块顺序、字段、样本、精度与关键披露不变。
- 总览数量与金额仍分开刻度。累计、当年度、本月使用共享网格行对齐，长披露自然撑高同一行；供应商与终端客户的原有横条移到下方通栏，两个统计对象仍可逐项读取。同比放在准确数值下方，减少空列对图形长度的挤占。小屏按原任务顺序堆叠。
- 趋势图改为外采数量／外销数量相邻、外采成本／外销收入相邻。同类两图的原始范围与刻度保留，没有改柱长、曲线点或样本。外采蓝、外销青绿沿用总览系列色；环比用文字色虚线与点，避免外销颜色与环比混淆。图例标明左右轴，图内标单位；按月、按年的数值表与切换入口保留。
- 业务周期／盈利保留现有主值、辅助值及七档分布；分档标签升到正文辅助层级。应收账款仍为四项汇总与单美元轴趋势，月／年切换位置保持在图标题右侧，与车辆趋势相同控件语言。
- 逾期列表按编号、交易方、金额、日期、天数、状态分配列宽；1440 px 英文九列完整显示，长企业名允许按词换行。桌面固定左编号和右状态，更窄时表内滚动；900 px 及以下不固定右侧，以免遮住主体列。首列去掉竖向分隔线，日期、状态与金额的精度及原始内容不变。
- 原生数值展开保留键盘 Enter 和焦点轮廓。未增加装饰性图形、演示控制台或新状态。

## 唯一维护源与继承

本模块的展示定义在 [m17.css](m17.css)。从 `_shared/components.css` 移出的是仅 M17 使用的原有规则，并合并其定义；没有复制公共壳层、卡片、字体、图标、状态组件或 token，也没有改变其他模块的样式。`m17-copy.js` 只追加图例的双语轴标识。

总览行对齐使用 CSS subgrid；窄于 1100 px 以普通单列排版。当前验收浏览器支持 subgrid，其他浏览器与老版本兼容性未验证。字号与颜色均取平台 token；未新建全局 token。

首页组装脚本、`data-from`／模板替换关系、全部 `data-go`／`data-module-key`／主流程下一屏、菜单、路由、账号与消息组件均继承未改。源页与离线附件由现有 `_shared/export.py` 生成，附件不是第二份维护源。
