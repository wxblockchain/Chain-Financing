# M17 运营端首页 · UI 设计说明

2026-11-27｜WS-685｜existing-system adaptation · console

基线为执行时最新 `cly-v6.0.0 @ d5b63945`，M17 最近提交为 `6b134902`。按用户本次要求，先观察 Huma 参考页，再以当前统计重构展示并提供示例图。[图形选型说明](图形选型说明.md) 记录参考类型和本页映射。原 A 方案的数字／趋势／分布分工、六个板块及 11 屏继续保留；本轮不定义业务规则。

## 实际变化

- **规模**：原单一数字矩阵改为外采／外销两张业务卡。累计金额为 28 px 主值，数量并列；当年／本月以精确数值行展示，完整金额、同比、合同价注明常显；供应商／终端客户为卡尾数字。两卡的主值、表头、年度、月度及卡尾用同一 subgrid 对齐，长注明自然撑高对应行。
- **趋势**：数量／金额并列柱及下方独立环比保留原始 SVG、刻度和点位。环比旁增加蓝色实线／青绿虚线图例，系列与上方柱色对应；图例从左排列，窄屏无需先滚到图右侧才能辨认。此前窄屏左轴文字留白修复保留。
- **分布**：周期／盈利七档横条改为直立频数柱，坐标共用整数 0–3，准确档位与数量常显，0 档仍显示 0，亏损档红色。周期标签将天数与单位分行，保留完整含义。主值改为标签下方的大数字，最长／最短和最高／最低为次层数字。
- **应收**：在原余额折线下加浅面积，填充边界严格跟随原有点位、同一零基线；原发生额柱、余额线、刻度与完整数值表未变，没有将发生额与余额相加。
- **逾期**：汇总、小圆环及九列逐笔表继承未改；桌面固定编号／状态、窄屏表内滚动、准确笔数与空环保持原样。
- 页面仍没有可见“首页”标题，顶部保留更新时间／刷新。画面目录、月年切换、原生数值展开及状态反馈均保留。

## 唯一维护源

本模块 DOM 与静态 SVG 在 [运营端首页.html](运营端首页.html)，展示规则在 [m17.css](m17.css)，新增双语标签在 [m17-copy.js](m17-copy.js)。旧矩阵及横条样式已移除；无共享运行代码、全局 token、路由或业务脚本变更。所有图形直接表达既有样本，没有运行时统计或模拟取数。

两业务卡及其原生表格使用 CSS subgrid 同步行高；Chromium 无障碍树仍识别为表格／列头／行头。≤1100 px 两业务卡、两趋势及两个分布收为单列。业务卡周期行在卡内换行，不需要横向滚动；趋势与分布保留 420 px、应收图 540 px 的阅读下限，窄屏各自在可聚焦区域内滚动。跨浏览器与旧版 subgrid 兼容性未验证。

## 实际核验与交付

Chromium（Playwright）：源页 11 屏 × 中英文 × 1920／1440／1280／768／375／320 px；离线附件 11 屏 × 中英文 × 1440／375 px，共 176 个渲染组合。检查整页溢出、总览长值／注明、英文漏译、重复 id、对比图文字边界及两卡周期行对齐；检查桌面、英文长文案、窄屏与失败截图。

源码逐项核对：原总览全部数字与同比／合同价披露、全部原数值表、逾期明细、车辆趋势 SVG、应收柱／线／点坐标均相同；七档标签／数量相同，柱高对应原数量；浅面积经过每个原余额点。组装脚本与全部跳转／模板属性相同。键盘实测月年往返、展开两系列完整数值表、刷新／重试、窄屏图表方向键滚动及焦点；核验空数据无环比点、分布零高、首次失败无旧值、更新失败保留 112.0 和失败披露；200% 放大无整页溢出。

交付离线自包含 HTML、中文桌面首屏示例图与完整页面示例图，均由最新源码导出／截图。截图仅展示标准样本，不代表真实接口已接入。菜单、壳层、权限、详情与其他模块内容继承未改，未计为本次优化。真实接口、统计实现、权限、跨浏览器及真实设备未验证；M3 仍缺 `AR-0003`／`AR-0001` 标准样本详情，编号沿用原有范围提示。其他板块的额外独立失败画面不在既有 11 屏清单，本次未新增。
