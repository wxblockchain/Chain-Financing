# M15 数据监控 · 运营端原型

依据 [`PRD/运营端/M15-数据监控/`](../../../PRD/运营端/M15-数据监控/01-数据监控-PRD.md)（2026-11-24 需求评审稿，提交 `b693d078`，WS-610）；推送状态、推送条件与重新存证按 [M9](../../../PRD/运营端/M9-运营审核与资产推送/01-运营审核与资产推送-PRD.md)。组件规范 v1.46（新增 A83–A87）。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。接口清单、调用次数、条数、金额、时间与原因均为演示值；图表是静态画面，不做统计、刷新或筛选。逐条结果能否取得（Q-M15-01）待研发核验；大屏刷新间隔（Q-M15-02）按推荐“每 1 分钟”标注，大屏登录时长（Q-M15-03）沿用 M2，不在画面中体现。

## 打开与路径

双击 [`数据监控.html`](数据监控.html)，或从仓库 [`index.html`](../../index.html) 以运营端进入“数据监控”。侧栏底部「画面目录 · 演示数据」默认关闭，可到达全部 26 屏。

- 概览 → 列表：V1 点“异常 1 个接口”→ I2 接口列表（筛选异常）→ C1 提单调用记录；V1 点“存证失败”→ P2 资产列表（筛选存证失败）。
- 重新存证：P1 行内或 PR2 页头“重新存证”→ R1 确认 → PR3 存证中（数据推送角标 1 → 不显示）。
- 大屏：V1 页头“大屏”→ S1；“退出大屏”回到概览。
- 申请编号经仓库联看进入 M9 申请详情；未接收单据中已在平台的提单号进入 M12。

## 本期不做与未出屏

- 按 PRD 本期不做：逐条单据异常处理、“长时间无数据”自动判断、手动重新取数与接口配置、主动推送、三方数据源接入监控、企业端查看。
- 未单独出屏：自定义时间范围的日期选择、大屏登录失效、重新存证重复提交 / 提交失败；以 PRD 为准。
- 告警 M15-NT01 未加入 M10 演示消息：加入会改变 M10 已评审画面中的未读数与条数，需 M10 负责人一并调整。

## 实际核验

Chromium / Playwright：26 屏 × 中英文 × 1280 / 1440 / 1920 px 无脚本错误、无整页横向溢出，操作列在视口内，指标卡与排行文字无截断；英文模式除演示账号姓名与业务原值外无中文。概览指标卡进入筛选列表、接口与资产记录、重新存证（角标变化）、大屏进入与退出点击实测。图表配色经 dataviz 校验脚本检查（`--accent` / `--chart-2` 与 `--ok` / `--danger` 两组均通过色觉分离与对比度检查）。离线单文件由 `_shared/export.py` 生成，打开时无外部请求。未验证：1280 px 以下、屏幕阅读器、真实接口与调取服务。
