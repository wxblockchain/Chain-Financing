# M15 数据监控 · 运营端原型

依据 [`PRD/运营端/M15-数据监控/`](../../../PRD/运营端/M15-数据监控/01-数据监控-PRD.md)（2026-11-25 需求评审稿，提交 `46fd0a8e`，WS-681，含用户 2026-11-25 裁定；首版 `b693d078`，WS-610）。内容不存在或无权查看按 [M2 F-OP-11](../../../PRD/运营端/M2-运营登录与企业管理/01-运营登录与企业管理-PRD.md#F-OP-11)，缺失值按 M3 以“-”展示。组件规范 v1.64。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。接口清单、调用次数、条数、金额、时间均为演示值；图表是静态画面，不做统计、刷新或筛选。时间按本人时区展示并标明时区。

## 本版要点

- 数据推送只看推送结果：列表只收存证完成的资产（待推送 / 已推送），不展示推送条件、拒绝原因、存证状态，不提供重新存证；“数据推送”菜单没有角标。调取情况与逐次调取记录放在推送详情，调取记录只有结果。
- 操作上下布局：列表行操作纵向排列、右对齐（本期只有“查看”）；推送详情自上而下为资产概要 → 调取情况 → 调取记录，不用页签。PRD 已就“上下布局”的具体含义请用户补充，确认后再调整。
- 数据接入加“数据来源”（本期均为客户 ERP）：接口列表一列 + 筛选，调用记录概要一项；概览的失败排行在接口名下注明来源，数据新鲜度表有来源列，新增外部跟踪数据等来源后沿用同一呈现。
- 缺失值统一为“-”（读屏读出原因）：取得 / 未接收条数未提供、比率无法计算。暂无调用、从未成功、暂无调取等业务状态仍为文字。

## 打开与路径

双击 [`数据监控.html`](数据监控.html)，或从仓库 [`index.html`](../../index.html) 以运营端进入“数据监控”。侧栏底部「画面目录 · 演示数据」默认关闭，可到达全部 24 屏。

- 概览 → 接入：V1 点“异常 1 个接口”→ I2 接口列表（筛选异常）→ C1 提单调用记录。
- 概览 → 推送：V1 点“待推送”→ P2 资产列表（筛选待推送）→ PR2 推送详情（AP-DEMO-0024，调取被拒绝）。
- 大屏：V1 页头“大屏”→ S1；“退出大屏”回到概览。
- 申请编号经仓库联看进入 M9 申请详情；未接收单据中已在平台的提单号进入 M12。
