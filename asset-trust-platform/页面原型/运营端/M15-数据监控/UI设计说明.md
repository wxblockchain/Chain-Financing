# M15 数据监控 · UI 设计说明

2026-11-25 首次优化，2026-11-26 定位标签增量见末节 · WS-681 · 既有系统适配（existing-system adaptation），运营端桌面控制台。

## 方向与实现

用户需要从概览发现异常，再进入接口调用或资产交互记录核对结果。沿用当前控制台的字体、色彩、壳层及菜单，调整已有展示 DOM 和模块样式。未选择全局改版：本任务不需要改变其他模块的视觉基线。

1. 概览 / 大屏：指标由独立小框改为组内分隔；异常 / 失败保留文字并使用浅红底，成功使用既有语义色。数据接入与数据推送仍上下分组，当前 / 区间标签保留。排行与新鲜度表在宽桌面使用 2:3 比例，表格减少上下内边距，图表坐标字号由 11 调至 12 px。SVG 坐标、数据、堆叠比例、完整 title 提示均继承。
2. 接口 / 资产列表：保留固定首列与操作列，英文使用较宽的模块列宽；名称、来源原因与平台名允许完整换行。金额使用系统正文栈与等宽数字，不改变币种、小数或千分位。平台情况保留在列表上方。
3. 调用 / 推送详情：对象字段在左、状态在右，避免页头重复同一状态。资产概要以完整金额开头，再列申请编号、内销发票号与首次成功时间；接口概要保留来源、承接模块、最近成功时间。≤1100 px 状态区移到字段下方。
4. 记录：推送情况的成功 / 失败计数突出，记录仍独立在下方，区分资产汇总结果与单次结果。调用记录显式分配时间、结果、未接收条数、原因与失败原因五列；原生 details 可用键盘展开，长原值可完整阅读。移除记录表的重复左右缩进。
5. 大屏画面目录按钮放入顶部空闲区域，避免覆盖排行；保留原目录与退出入口。

## 规范继承与边界

- `m15-ui.css` 在共享 `tokens.css` / `components.css` 后加载；展示选择器限定 `.m15-ui`，尺寸 token 限定 `:root[data-module="data-monitoring"]`。未改共享 token 默认值、共享 JS、菜单、字库、图标资产或其他模块源码。
- 复用 A43、A83–A87，以及 facts、tag、tablewrap、reason-detail、筛选和分页。字号只引用 `--fs-*`，颜色只引用既有语义 token；摘要状态栏宽 184 px，英文接口表下限 1360 px，英文资产表下限 1216 px，调用记录下限中 1000 / 英 1120 px。不足时在表内滚动。
- 交互方式与成功条件不由 M15 定义；保留成功 / 失败口径、成功后再失败仍成功的样本。未增加取得条数、待推送、推送方式、上链操作或失败原因字段。现有“推送”菜单 / 字段名称继承 PRD，不据此限定交互方式。
- 原有缺值、“暂无调用 / 从未成功”等状态、精度、时间值与时区、权限兜底、跨模块入口、筛选选项、画面目录和路由不变。只移除页头与摘要重复的接口状态文字，摘要状态仍可达。
- 静态图表与记录均为演示数据；本轮不新增统计、筛选、刷新或服务模拟逻辑。
