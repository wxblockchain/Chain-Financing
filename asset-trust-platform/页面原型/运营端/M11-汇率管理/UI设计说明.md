# M11 汇率管理 · UI 设计说明

2026-11-25 · WS-677 · 现有系统适配（existing-system adaptation），运营端桌面控制台。

基线：执行时 `cly-v6.0.0` 的 `b3728710`；M11 原型同步提交 `5176ae9`，PRD `b75577c`。承接已有 14 屏；菜单、角色与时区沿用共享壳层及 M2。

## 呈现变化

- 当前概要：完整汇率为主，生效时间、维护人及编号独立浅底分组，来源和备注在下方按字段排布。使用原有 28 px 主值、14 px 字段值、13 px 标签与表格正文；数字用等宽数字特性，编号沿用等宽字体。
- 历史列表：外置区块标题，移除重复条数，分页保留总数；当前记录保留语义标签，旧记录采用中性圆点文字；新记录保留原浅色行。日期 / 时分秒两行，时区仍在表头；变动右对齐，首次设置按文字处理。无新增操作列。
- 填写：当前汇率与生效时间为只读参照，新汇率仍以 `1 USD = [输入] NGN` 呈现；来源必填，备注明确“选填”，原有计数、输入、错误信息和填写内容不变。
- 核对：当前 / 新值并列，变动幅度独立一行，来源和备注另组；U5 把最新当前值与待保存的新值并列，其维护信息紧随对照。保留全部即时生效与不可改删说明。
- 反馈：保存成功保留原文与原持续时间，用成功色和对勾强化辨识；并发更新仍警示“本次未保存、重新核对”，保存失败与读取失败保留不同说明。补齐原有 toast 容器的共享定位类，避免反馈落入页面文档流。
- 完整值：只读汇率、编号、姓名、来源及备注允许完整换行，不使用省略或隐藏精度；备注保留换行。没有新增复制 / 显隐入口，原有关闭图标的可访问名称继承共享翻译。

## 实现与继承

样式唯一实现位于模块 `m11-ui.css`，所有选择器限定 `data-module="ops-fx"`。颜色、字号、字体、间距、语义反馈复用共享 token；尺寸只在 `tokens.css` 的 M11 作用域定义：弹窗 720 px，历史表中文 1120 px / 英文 1152 px，汇率 / 生效时间 / 状态 / 维护人列分别 184 / 128 / 144 / 144 px。未改变共享默认值，其他模块不命中此次选择器。

A39–A41 保持组件基线，本模块显式采用呈现变体；不复制壳层或公共组件。HTML 只调整展示分组、语义表头、类名和等义标签，模块 JS 只补“选填 / Optional”。数据、脚本主体、输入属性与值、14 屏身份、画面目录、`data-go` / `data-next` / `data-base`、时间戳均与基线对照一致。

## Coverage 与实际核验

Chromium / Playwright，系统字体栈，无网络字体。14 屏 × 简体中文 / English × 768 / 1024 / 1280 / 1440 / 1920 px，共 140 组；高度 900 px。脚本错误为 0，整页无横向溢出，弹窗无越界或横向滚动，字段 / 单元格无宽度裁切；英文除业务原文外无中文残留。

| 画面 | 本轮修改且实测 |
| --- | --- |
| R1、R4、R5 | 当前汇率概要、维护与说明分组、历史列表；R4 / R5 成功反馈 |

补充实测：

- 中英文更新流程 R1 → U1、U2 → U4 → R4，首次设置 R2 → F1 → F2 → R5；R3 → U7，下一步仍留 U7 且输入保留；R3 重试 → R1；U6 重新提交 → R4；U5 上一步 → U2。
- Tab 保持在弹窗内，Esc 关闭并恢复发起按钮焦点；焦点轮廓可见；画面目录默认收起，14 屏全部登记可达。U5“确认保存”继续是无跳转的静态画面，不为 UI 优化补写并发保存模拟。
- 1280×720、1024×600、720×450 CSS 像素及 375×812 下六个代表弹窗：内容区可滚到说明末尾，底部操作区可达，无弹窗横向滚动；主按钮上、中、下三点命中核验通过。弹窗打开时画面目录退到遮罩下，避免短窗口遮住按钮。720×450 用于压缩阅读空间检查，不代表实测浏览器 200% 缩放。375 px 顺带修正模块菜单定位上下文，菜单长内容仍在自身横向滚动。
- 浏览器内临时替换长汇率、`+15,358,300.00%` 变动、长编号 / 姓名 / 来源及多行无空格备注，768 px 下完整换行无裁切；没有向原型加入额外示例状态或数据。

未验证：真实服务、实际计算和并发保存、读取重试、全部后端校验、屏幕阅读器、其他浏览器与操作系统字体、真实 200% 浏览器缩放。本轮是页面呈现核验，不是 Eval 或生产验收。汇率可保存最大值仍待研发确定。
