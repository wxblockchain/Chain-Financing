# M11 汇率管理 · 运营端原型

依据 [`PRD/运营端/M11-汇率管理/`](../../../PRD/运营端/M11-汇率管理/01-汇率管理-PRD.md)，需求提交 `b75577c`（2026-11-25 需求评审稿）。组件规范 v1.18。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。汇率值、来源说明、备注、汇率编号、维护人与时间均为演示数据（汇率值沿用 PRD 示例口径），不代表真实汇率；汇率编号格式由研发确定。维护人为保存时该运营账号的姓名，演示姓名沿用 M2 原型的“运营示例账号”。来源说明、备注与维护人按录入原文展示，英文界面不翻译。英文界面文案以本原型为准（PRD 01 册约定），与中文含义一致。

## 打开与路径

双击 [`汇率管理.html`](汇率管理.html)，或使用离线单文件附件；无需服务。左侧菜单“平台配置 / 汇率管理”进入。侧栏底部“画面目录 · 演示数据”默认收起，列出全部画面和“主流程下一屏”。

- 主流程（更新）：R1 → 页头“更新汇率” → U1 →（主流程下一屏）U2 → “下一步” → U4 → “确认保存” → R4。
- 首次设置：R2 → “更新汇率” → F1 → “下一步” → F2 → “确认保存” → R5。
- 读取失败：R3 → 页头“更新汇率” → U7。
- U3、U5、U6 从画面目录打开；U6 “重新提交”进入 R4。弹窗内“取消”、关闭与 Esc 回到底层页面，“上一步”回到第 1 步。

## 呈现说明

- 只有运营管理员一种角色，权限相同，没有身份差异画面；企业端没有入口，本模块不出企业端画面。
- 未登录、以企业账号访问、待首登改密或锁定的运营账号按 M2“运营端菜单与无权访问（F-OP-11）”处理；填写或确认期间登录结束（登录到期、无操作登出、账号锁定）按 M2“登录有效期、无操作登出与退出（F-OP-07）”处理，本次不保存、当前汇率不变。以上均由 M2 出屏，本模块不单独出屏。本期运营账号没有“已停用”。
- 汇率始终完整写作“1 USD = R NGN”，R 固定两位小数、千分位；输入框按录入原值显示。
- 生效时间、失效时间精确到秒，按本人在 M2“界面语言与时区（F-OP-10）”中设置的时区展示并标明时区（共享层 `display.js`，原型以浏览器推断的时区预览，与 M2 首次登录写入口径一致），概要与弹窗在时间下方、历史在表头标注时区。界面语言为简体中文 / English。
- 变动幅度对绝对值保留 2 位小数后加符号，整数部分用千分位；取舍后为 0.00 时仍按实际方向写 +0.00% / −0.00%。负号用 “−”（U+2212）。演示数据未出现千分位与 ±0.00% 的取值，口径以 PRD 为准。
- 来源说明为单行输入；备注可换行，当前汇率、核对页与汇率历史中按录入保留换行与中间空格。
- 汇率历史可查看全部记录，与平台其他业务列表一样每页 10 条（只画第 1 页），不省略早期记录。

## 本期不做（按 PRD §1.2）

新增币种或任意币种对、外部行情与自动更新、预约 / 追溯生效、停用、修改或删除已保存汇率、审批或复核、历史导出、消息通知、企业端展示。哪些功能使用汇率、换算精度与展示由使用方模块规划，本原型不出使用方画面。

## 待确认与未覆盖

- 保存中、登录结束、重复提交、汇率历史读取失败（与 R3 同一表现）、来源说明或备注超长及汇率值为空 / 为 0 / 非数字 / 输入格式等其余校验以 PRD 为准，未单独出屏。
- 汇率值可保存的最大值待研发确定，原型不出对应提示。
