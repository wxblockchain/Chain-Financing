# M11 汇率管理 · 运营端原型

依据 [`PRD/运营端/M11-汇率管理/`](../../../PRD/运营端/M11-汇率管理/01-汇率管理-PRD.md)，需求提交 `d99dfce`（2026-11-12 需求评审稿）。组件规范 v1.18。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。汇率值、来源说明、备注、汇率编号、维护人与时间均为演示数据（汇率值沿用 PRD 示例口径），不代表真实汇率；汇率编号格式由研发确定。来源说明、备注与维护人按录入原文展示，英文界面不翻译。

## 打开与路径

双击 [`汇率管理.html`](汇率管理.html)，或使用离线单文件附件；无需服务。左侧菜单“平台配置 / 汇率管理”进入。侧栏底部“画面目录 · 演示数据”默认收起，列出全部画面和“主流程下一屏”。

- 主流程（更新）：R1 → 页头“更新汇率” → U1 →（主流程下一屏）U2 → “下一步” → U4 → “确认保存” → R4。
- 首次设置：R2 → “更新汇率” → F1 → “下一步” → F2 → “确认保存” → R5。
- U3、U5、U6 从画面目录打开；U6 “重新提交”进入 R4。弹窗内“取消”、关闭与 Esc 回到底层页面，“上一步”回到第 1 步。

## 呈现说明

- 只有运营管理员一种角色，权限相同，没有身份差异画面；企业端没有入口，本模块不出企业端画面。
- 汇率始终完整写作“1 USD = R NGN”，R 固定两位小数、千分位；输入框按录入原值显示。
- 生效时间、失效时间精确到秒，按本人账号时区展示（原型以浏览器时区预览），概要与弹窗在时间下方、历史在表头标注时区。
- 汇率历史与平台其他业务列表一样每页 10 条（只画第 1 页）。

## 本期不做（按 PRD §1.2）

新增币种或任意币种对、外部行情与自动更新、预约 / 追溯生效、停用、修改或删除已保存汇率、审批或复核、历史导出、消息通知、企业端展示。哪些功能使用汇率、换算精度与展示由使用方模块规划，本原型不出使用方画面。

## 待确认与未覆盖

- 菜单：“平台配置 / 汇率管理”已加入共享 `menu.ops.js`，M2 PRD F-OP-11 运营端菜单表尚未登记，需由 M2 负责人同步（分组名称可在登记时调整）。
- 运营端时区：PRD 写明按 M2 账号设置时区展示；M3–M5 因“M2 不提供时区设置时按 UTC”而固定 UTC。本模块沿用浏览器时区预览，最终以 M2 是否提供运营时区设置为准。
- R3 读取失败沿用平台通用读取失败表现，PRD 未单列；读取失败时是否仍允许发起更新，以 PRD 为准。
- 保存中、登录失效、重复提交、来源说明或备注超长及汇率值为空 / 为 0 / 非数字等其余校验以 PRD 为准，未单独出屏。
