# M13 保单信息 · 运营端原型

依据 [`PRD/运营端/M13-保单信息/`](../../../PRD/运营端/M13-保单信息/01-保单信息-PRD.md)，PRD 提交 `9350dde2`（2026-11-20 按 WS-655 确认口径修订）。属于既有系统适配（桌面 Web）：先读取本平台[组件规范](../../_shared/design-system/组件规范.md)与[列表与详情规范](../../_shared/design-system/列表与详情规范.md)，列表沿用 A14 固定列骨架，详情沿用 A18 / A24 版式，筛选条、分区导航、提示、区块状态、文件引用、分页均为既有组件；只为保障核对四项指标和本模块列宽新增 A70–A71（组件规范 v1.35）。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。保险公司、企业、保单号、提单号、VIN、金额、汇率与文件均为演示值；PL-DEMO-889 关联的 BL-DEMO-5501 及其 3 辆车与单车金额与 M12 提单信息原型一致（其中一辆为 NGN 单价折算）；汇率沿用 M11 原型当前汇率（FX-DEMO-0003，1 USD = 1,540.20 NGN）。保险金额等保单数据为本模块演示值，不再沿用旧版 M5 中的数值。

## 打开与路径

双击 [`保单信息.html`](保单信息.html)，或使用离线单文件附件；无需服务。左侧菜单“资产数据 / 保单信息”进入列表。侧栏底部“画面目录 · 演示数据”默认收起，列出全部画面和“主流程下一屏”。

- 主流程：L1 列表 → 点 PL-DEMO-889 进入 D1 详情 → 面包屑“保单信息”返回列表。
- 列表保单号或右侧“查看”进入详情（演示提供 PL-DEMO-921 / 903 / 889 / 862，其余行提示仅提供部分保单）。
- 详情中的 VIN 进入车辆履约（`vehicle:`）、提单号进入提单信息（`bl:`，M12 已画出 BL-DEMO-5501）、关联预警数量进入风控预警，经[仓库联看](../../README.md#仓库联看)跳转；未画出的记录提示“该入口尚未纳入原型。”。其他模块可用 `policy:<保单号>` 进入本模块已画出的详情，M12 关联保单中的 PL-DEMO-889 已可进入 D1。

| --- | --- | --- |
| 保单信息列表 | L1 | 默认：每张保单一行，十列为保单号、保单日期、保险公司、被保险人、保险金额（美元）、保险货值（美元）、保险覆盖率、关联提单／车辆、预警、操作；保单号与“查看”固定两侧；按保单日期从新到旧。含“无法计算”及原因、原币 NGN 折算、含未审核提单、无覆盖车辆的样例 |
| | L2 | 暂无保单资料（空） |
| | L3 | 查找无结果，可清除条件 |
| | L4 | 列表加载失败，条件保留、可重试 |
| | L5 | 按 VIN 查找：同一辆车出现在两张保单中，两张都列出、照常计算，不作提示 |
| 保单详情 | D1 | 默认（覆盖率 110.00%，一辆车内采单价为 NGN 折算）：页头保单号；概要为保险金额，保险公司、投保人、被保险人、保单日期，右侧关联预警；保障核对四项（保险金额（美元）、保险货值（美元）及车辆数、保险覆盖率、覆盖车辆）；明细为车辆清单（VIN、提单号、内采单价（美元）、车辆保险金额（美元）；未开内销发票的车辆为“未开票”）、关联提单（提单号、装船日期、车辆数）、附件（保单、保费支付凭证及取得时间） |
| | D2 | 无法计算：1 辆车未开票、1 张关联提单未审核；保险货值注明原因，覆盖率与车辆保险金额为“无法计算”，未审核提单不可点击、不展示车辆数；保费支付凭证暂无附件 |
| | D3 | 原币 NGN：保险金额下方为美元折算值，“折算”旁可查看所用汇率与生效时间；覆盖率低于 100% 按数值展示、不突出；关联预警未处理 1 条、已处理 1 条，可进入风控预警；同一类附件多份 |
| | D4 | 未关联提单（空）：覆盖车辆 0 辆，保险货值注明“无覆盖车辆”，车辆清单“暂无车辆”，关联提单“未关联提单” |
| | D5 | 车辆清单加载失败（代表性异常）：仅该分区提示并可重试，保险货值、覆盖率与覆盖车辆为“无法计算”，其他分区正常 |
| | D6 | 从其他模块带入的保单不存在或已更新，可返回保单信息 |

全模块只读：无新增、编辑、删除、补传或处理预警入口；覆盖率不按高低着色或提示（风险由风控预警判断）。

## 未单独出屏（以 PRD 为准）

- 企业端：PRD 规定债权人、债务人都没有保单信息入口，本模块只做运营端；企业用户通过链接访问时的“该内容不存在或无权查看”沿用平台无权限画面。
- PRD 已定义、未逐一出屏的情形：整页详情加载失败、关联提单 / 附件 / 关联预警分别加载失败、附件打开失败、内采单价无法折算或无可用汇率、保险金额无法折算、保险货值为 0、跳转目标已不再被采信。
- 从 M3、M5、M12 进入后的返回：仓库联看用浏览器返回，不另画来源相关的返回按钮。
- 本期不做（PRD §1.2）：录入、编辑、删除保单或附件；风控规则判断（保险未足额覆盖、保单信息与基础交易不一致）；提单船名航次、港口与清关明细；车辆的采购、内销、外销经历；保费金额与支付记录；保险条款结论；企业端查看。

## 待确认（不影响本原型布局）

- M13-Q08 风控预警同步：列表“预警”与详情关联预警数量为演示值，随 M8 完善生效。
- 运营端菜单：本模块在“资产数据”分组追加“保单信息”。按信息架构方案 v1，资产数据菜单会整体重组（应收账款、车辆履约、合同信息、提单信息、保单信息、资金收付），需在 M2 PRD 菜单表统一登记；本原型未改动其他菜单项。

## 实际核验

Chromium / Playwright，中英文 × 1280 / 1440 / 1920 px，视口高 1000 px，源文件与离线单文件：

- 全部 11 屏加载无脚本错误、无整页横向溢出、侧栏不遮挡内容、按钮与标签无截断、表格操作列可见；英文模式下除 ERP 原值与共享演示账号名外无残留中文。
- 1440 / 1920 px 列表十列完整展示；1280 px 列表在表内滚动，保单号与“查看”固定可见。
- 交互：列表保单号与“查看”进入详情、面包屑返回、汇率浮层展开、更多筛选展开、画面目录切换；仓库联看中 VIN 进入车辆履约、提单号进入 M12 提单详情，M12 关联保单 PL-DEMO-889 进入本模块 D1。
- 离线单文件断网打开无 HTTP 请求，跨模块入口给出单模块附件提示。
- 共享层回归：运营端其他已登记及保留模块（含新版 M4、M5 与 M12）全部画面在 1280 / 1920 px 加载无脚本错误、无整页横向溢出，侧栏均多出“保单信息”；未重跑其业务流程。

未验证 1280 px 以下、屏幕阅读器、完整无障碍符合性，以及真实 ERP 取数与附件下载。
