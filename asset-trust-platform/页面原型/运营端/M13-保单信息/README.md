# M13 保单信息 · 运营端原型

依据 [`PRD/运营端/M13-保单信息/`](../../../PRD/运营端/M13-保单信息/01-保单信息-PRD.md)，PRD 基线 `7ce77866`（“提单未审核”与已采信后被移除合并为“提单未采信”、M13-Q08 关闭改由 M8 RK-35 判断、VIN 去重按 M5 写法；`6fd87f15`：列表保险金额只放美元值、缺失值统一为“-”；`7a2f2072`：超出本模块的规则改为链接 M2、M3、M5、M8、M12； `6d6ae71f`：保单附件合为一组、未开票车辆取内销合同单价并标“合同价”）。属于既有系统适配（桌面 Web）：先读取本平台[组件规范](../../_shared/design-system/组件规范.md)与[列表与详情规范](../../_shared/design-system/列表与详情规范.md)，列表沿用 A14 固定列骨架，详情沿用 A18 / A24 版式，筛选条、分区导航、提示、区块状态、文件引用、分页均为既有组件；只为保障核对四项指标和本模块列宽新增 A70–A71（组件规范 v1.35）。2026-11-23 按 WS-655 与资产数据其他模块统一呈现（见下文“与资产数据其他模块统一”）；2026-11-24、11-25 分别按 PRD `7a2f2072`、`6fd87f15`、`7ce77866` 修订（见下文对应小节）。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。保险公司、企业、保单号、提单号、VIN、金额、汇率与文件均为演示值；PL-DEMO-889 关联的 BL-DEMO-5501 及其 3 辆车与单车金额与 M12 提单信息原型一致（其中一辆为 NGN 单价折算）；汇率沿用 M11 原型当前汇率（1 USD = 1,540.20 NGN，生效时间 2026-11-19 02:15 UTC）。保险金额等保单数据为本模块演示值，不再沿用旧版 M5 中的数值。

## 打开与路径

双击 [`保单信息.html`](保单信息.html)，或使用离线单文件附件；无需服务。左侧菜单“资产数据 / 保单信息”进入列表。侧栏底部“画面目录 · 演示数据”默认收起，列出全部画面和“主流程下一屏”。

- 主流程：L1 列表 → 点 PL-DEMO-889 进入 D1 详情 → 面包屑“保单信息”返回列表。
- 列表保单号或右侧“查看”进入详情（演示提供 PL-DEMO-921 / 903 / 889 / 862，其余行提示仅提供部分保单）。
- 详情中的 VIN 进入车辆履约（`vehicle:`）、提单号进入提单信息（`bl:`，M12 已画出 BL-DEMO-5501）、列表预警条数与详情“未处理 N 条”进入风控预警，经[仓库联看](../../README.md#仓库联看)跳转；未画出的记录提示“该入口尚未纳入原型。”。其他模块（M3 车辆清单、M5 运输与保险段、M12 关联保单、M8 预警详情）可用 `policy:<保单号>` 进入本模块已画出的详情；M3、M5、M12 中的 PL-DEMO-889 已可进入 D1，M8 原型中的保单号目前为纯文本，待 M8 原型接入。

## 与资产数据其他模块统一（WS-655，2026-11-23）

按 WS-655 统一口径（基准 M3 应收账款、M4 合同信息），同类信息与 M3、M4、M5、M12、M14 同样呈现：

- 列表页头只有页标题，删去说明句。
- 列表查找：去掉“查找方式”下拉，改为单一查找框，占位“保单号、提单号或 VIN”；L3 查找无结果、L5 按 VIN 查找保留已填内容。
- 列表当事方：原“保险公司”“被保险人”两列合为“保险公司 → 被保险人”，每行“角色短名 + 名称”（同 M3 应收账款列表），方向与详情页头一致。
- 列表只放识别、当事方、金额、日期和预警：删去“保险货值（美元）”“保险覆盖率”两列，“关联提单／车辆”只留张数 / 辆数，删去“含 1 张提单未审核”（现为“未采信”）等原因；这些值与原因在详情“保障核对”、关联提单中照常展示。列表由十列减为七列，表宽下限随之收窄。
- 预警列直接展示未处理条数（warn 色，可进入风控预警），没有时为“无”。
- 详情页头：“保险公司 X → 被保险人 Y”，说明行“保单号 PL-… · 时区 UTC”；概要不再重复保险公司、被保险人，保留投保人、保单日期；主金额带币种旗标。
- 关联预警：概要右侧单项“关联预警”，有未处理时“未处理 N 条”为链接、下方“已处理 M 条”；没有任何关联预警时为“无关联预警”（2026-11-24 按 PRD `7a2f2072` 恢复，与 M4、M5、M12 一致；列表预警列没有时仍为“无”）。
- 详情分层：概要 →“进度与核对”（保障核对）→“明细”（车辆清单、关联提单、附件），写法同 M3 应收账款详情。
- 取不到或算不出的值（保险货值、保险覆盖率、车辆保险金额、覆盖车辆，未采信提单的装船日期与车辆数）用“-”占位，读屏保留原文字；原因（“1 张关联提单未采信”“无覆盖车辆”）照旧写在值下方。
- 折算：原“折算 ⌄”下拉改为 `fx-mark`“折算ⓘ”信息浮层，内容为“当前汇率 1 USD = 1,540.20 NGN”与生效时间（同 M5、M14）；用于列表与保障核对的保险金额（美元）、概要“保险金额（美元）”和车辆清单 NGN 内采单价。浮层不再显示汇率编号。
- 附件：由分组字段改为表格“附件类别 | 附件 | 取得时间”，附件格为文件名 + 下载（同 M4），取得时间不再逐条标时区（页头已有时区）。

个性化说明（与通用口径不同或本模块特有之处）：

- 列表没有原币列，也不在美元值下方写原币（2026-11-25 按 PRD `6fd87f15`）：NGN 保单美元值下方只标“折算ⓘ”，写法同 M14 资金收付美元列；无法折算或无可用汇率时为“-”、下方注明原因。详情车辆清单中 NGN 内采单价仍在美元值下方写“原币 … NGN 折算ⓘ”。
- 附件（2026-11-24 按 PRD `6d6ae71f`）：全部附件合为一张“保单附件”表，只有“附件 / 取得时间”两列，卡头注明份数；没有附件时卡内写“暂无附件”。
- 内采单价（2026-11-24 按 PRD `6d6ae71f`）：未开内销发票时取内销合同单价，金额后以 `.price-note` 小字标“合同价”（同 M12），车辆保险金额照常计算并同样标注；合同价车辆计入保险货值，下方注明“含 N 辆合同价”。不再出现“未开票”。整块无内容的分区（“暂无车辆”“未关联提单”）保留空状态文字。
- 列表“关联提单／车辆”是数量，0 张／0 辆照常显示数字，不是缺值。
- 保单只有原币与美元两种金额，概要只在原币非美元时另列“保险金额（美元）”；美元保单不重复美元值（保障核对第一项已是美元值）。
- 详情页头与列表角色同为“保险公司 / 被保险人”（无全称 / 短名之分）。投保人不进入页头，留在概要。
- 公共层：只在 `components.css` 文末追加“WS-655 统一 · M13”一小块（列表合并列宽与表宽下限、原币折算行（现只用于详情车辆清单）、概要关联预警单项与折算标记、保障核对“-”字号、附件表垂直居中）；未改 `tokens.css`。A70 / A71 中原 `.policy-usd`、`.policy-fx`、`.attach-line` 与四个旧列宽类已不再使用。

## 未单独出屏（以 PRD 为准）

- 企业端：PRD 规定债权人、债务人都没有保单信息入口，本模块只做运营端；以企业账号访问本模块任何内容时按 M2 运营端菜单与无权访问（F-OP-11）处理，不返回任何内容，本模块不另出画面。运营账号待首登改密、锁定中不能使用本模块，按 M2 处理（本期运营账号不设停用）。
- PRD 已定义、未逐一出屏的情形：整页详情加载失败、关联提单 / 附件 / 关联预警分别加载失败、附件打开失败、无附件、某车“无内采单价”（既无内销发票也无内销合同单价，保险货值注明“N 辆车无内采单价”）、内采单价无法折算或无可用汇率、保险金额无法折算、保险货值为 0、已采信的提单被移除后按“提单未采信”展示（平台已取不到提单号时提单号也为“-”）。跳往提单、车辆、风控预警后的落点及目标已不存在时的展示以 M12、M5、M8 为准，本模块不出画面。
- 从 M3、M5、M12、M8 进入后的返回：仓库联看用浏览器返回，不另画来源相关的返回按钮。
- 本期不做（PRD §1.2）：录入、编辑、删除保单或附件；风控规则判断（保险未足额覆盖、保单信息与基础交易不一致、同一车辆被多张保单覆盖）；提单船名航次、港口与清关明细；车辆的采购、内销、外销经历；保费金额与支付记录；保险条款结论；企业端查看。
