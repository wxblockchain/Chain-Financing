# M12 提单信息（含清关）· 运营端原型

依据 [`PRD/运营端/M12-提单信息/`](../../../PRD/运营端/M12-提单信息/01-提单信息-PRD.md)（WS-661，01 功能与业务规则、02 流程图与状态机、04 验收；按 WS-655 确认口径修订的提交 `b091c74b`）。组件规范 v1.38。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。企业、船公司、单据号码、VIN、集装箱号、金额、日期、航程动态与文件均为演示数据；Carloha Holding / Carloha Nigeria 不代表实际业务主体。船公司、船名航次、港口、当事方与航程动态是来源原值，英文界面不翻译。

## 打开与路径

双击 [`提单信息.html`](提单信息.html)，或使用离线单文件附件；无需服务。左侧菜单“资产数据 / 提单信息”进入列表。侧栏底部“画面目录 · 演示数据”默认收起，列出全部画面和“主流程下一屏”。

- 列表：提单号或右侧“查看”进入详情（演示提供 BL-DEMO-5501、BL-DEMO-5530，其余行提示仅提供部分提单）。
- 详情：VIN 进入车辆履约（M5，演示提供 …001、…021 的画面），保单号进入保单信息（M13），预警数量进入风控预警（M8）按本提单筛选；清关单号定位到车辆清单。跨模块入口经[仓库联看](../../README.md#仓库联看)跳转，未登记的提示“该入口尚未纳入原型。”。
- 主流程：L1 列表 → D1 提单详情 → 返回列表。从 M5 清关节点进入为 D3（路由 `blVehicle:<提单号>:<VIN>` 定位到车辆清单）。

## 本期不做（按 PRD §1.2）

企业端（债权人、债务人）没有提单信息入口，本模块不出企业端画面。不提供录入、编辑、删除、补传或预警处理；不做风控判断，字段旁没有比对提示；不展示费用金额明细、预计到港日期与船舶位置地图。

## 待确认与未覆盖

- 预警列与概要预警数量依赖 M8 提供（M12-Q03）；M8 尚无“按提单筛选”的画面，入口提示尚未纳入原型。
- M3、M5、M13 已通过路由 `bl:<提单号>`、`blVehicle:<提单号>:<VIN>` 进入本模块；M8 尚未接入。
- 菜单“提单信息”在 `menu.ops.js` 的“资产数据”分组，待 M2 PRD 菜单表登记。
- 演示汇率与 M11 当前汇率一致（FX-DEMO-0003，1 USD = 1,540.20 NGN）。
- 按集装箱号查找命中提单登记或清关单登记的集装箱号，结果以 PRD 为准，未单独出屏。
- 内采单价单元格加载失败、附件打开失败、一辆车多张清关单（标出共几张）、企业用户链接访问等以 PRD 为准，未单独出屏。
