# M12 提单信息（含清关）· 运营端原型

依据 [`PRD/运营端/M12-提单信息/`](../../../PRD/运营端/M12-提单信息/01-提单信息-PRD.md)（WS-661，01 功能与业务规则、02 流程图与状态机、04 验收；当前基线为 WS-678 复核提交 `784ef614`：账号状态、界面语言与时区、企业账号访问按 M2，关联预警按 M8，新增从 M8 清关单号与 M9 提单号进入）。组件规范 v1.58；列表与详情的呈现按 WS-655 资产数据六模块统一口径（见下文）。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。界面语言随顶栏中英切换，平台记录的附件取得时间按本人时区展示，时区标在详情说明行（M2 F-OP-10）；来源日期与航程时间按原样展示，不换算。企业、船公司、单据号码、VIN、集装箱号、金额、日期、航程动态与文件均为演示数据；Carloha Holding / Carloha Nigeria 不代表实际业务主体。船公司、船名航次、港口、当事方与航程动态是来源原值，英文界面不翻译。

## 打开与路径

双击 [`提单信息.html`](提单信息.html)，或使用离线单文件附件；无需服务。左侧菜单“资产数据 / 提单信息”进入列表。侧栏底部“画面目录 · 演示数据”默认收起，列出全部画面和“主流程下一屏”。

- 列表：提单号或右侧“查看”进入详情（演示提供 BL-DEMO-5501、BL-DEMO-5530，其余行提示仅提供部分提单）；预警条数进入风控预警（M8）按本提单筛选。
- 详情：VIN 进入车辆履约（M5，演示提供 …001、…021 的画面），保单号进入保单信息（M13），概要“关联预警”的条数进入风控预警（M8），落点按 M8；清关单号定位到车辆清单。跨模块入口经[仓库联看](../../README.md#仓库联看)跳转，未登记的提示“该入口尚未纳入原型。”。
- 主流程：L1 列表 → D1 提单详情，经面包屑“提单信息”返回列表（页头不另设返回按钮）。
- 其他模块进入（PRD 14.2），都用浏览器返回进入前的位置：
  - M3、M5、M8、M9、M13、M15 中的提单号：路由 `bl:<提单号>`，进入该提单详情（D1、D2）。
  - M5 中的清关单号：路由 `blVehicle:<提单号>:<VIN>`，进入 D3，定位到车辆清单中的该车。
  - M8 预警详情中的清关单号：路由 `customs:<清关单号>`。对应一张提单时进入 D7，定位到清关单中的这张清关单（演示 CC-DEMO-0101）；对应多张提单时进入 L5，提单列表按该清关单号查找（演示 CC-DEMO-0108，对应 BL-DEMO-5520、BL-DEMO-5480）。

## 与资产数据其他模块统一（WS-655，2026-11-23）

按资产数据六模块（M3 / M4 / M5 / M12 / M13 / M14）统一呈现口径修订，基准为 M3 应收账款与 M4 合同信息；字段与规则不变，以 PRD 为准。

- 列表（L1–L4）：删除页标题下说明句；去掉“查找方式”下拉，改为单一查找框（提单号、船名航次、清关单号、VIN 或集装箱号），无结果画面保留已选筛选；“清关进度”列改为“清关状态”，只保留带圆点状态标签，“已清关 k／共 N 辆”只在详情清关进度中展示；提单货值无法计算时为“-”，未开票 / 无法折算原因只在详情展示；预警列右对齐，有未处理预警时直接展示 warn 色条数（可进入 M8 按本提单筛选），没有为“无”。
- 详情（D1–D5）：页头改为“发货人 → 收货人”，说明行为“提单号 · 时区”，概要不再重复发货人、收货人；页头不放“返回列表”“返回车辆履约”，面包屑返回列表，跨模块进入用浏览器返回；概要右侧“未处理预警 / 已处理预警”两栏合为一个“关联预警”（未处理 N 条可进入，已处理 M 条为次行，没有为“无”）；提单货值无法计算时主金额为“-”，原因写在下方；车辆清单“折算 ⌄”下拉改为“折算 ⓘ”信息浮层（当前汇率、汇率编号、生效时间）；附件中缺失的运费支付凭证与取得时间用“-”占位。
- 已符合口径、未改：概要主金额带币种旗标；“进度与核对 / 明细”两层标题；附件分区为“附件类别 | 附件 | 取得时间”，附件格为文件名 + 下载，取得时间表头不另写时区。

### 个性化说明

- 列表“装运港 → 卸货港”在一格单行展示：港口是航线两端而不是当事方，不套用当事方“A → B”两行写法；列表不展示发货人、收货人（PRD 列表字段不含），当事方只在详情页头出现。
- 附件按单据分组（PRD 512f4cbe）：提单附件只有一类，按统一写法省略类别列，为“附件 | 取得时间”；清关单附件多一列“清关单号”，同一清关单的全部附件连续排列，不分附件类别。
- 车辆清单中未清关车辆的清关各项写“未清关”，既未开票也不在内销合同中的车辆内采单价写“未关联内销合同”，到港日期写“未到港”：这些是带业务含义的状态文字，不改为“-”。取合同价时金额后加“合同价”（`.price-note`，与 M3、M4、M5 一致）。
- 折算浮层比通用写法多一行汇率编号（FX-DEMO-0003）：沿用本模块原有演示内容，便于与汇率管理（M11）中的当前汇率对照；汇率值与生效时间同通用写法。
- 列表与概要中提单货值无法计算时显示“-”，PRD F-M12-04 表述为展示“无法计算”并注明车辆数：按 WS-655 用户反馈改为占位符，“N 辆车无内采单价或无法折算”保留在详情主金额下方；“含 N 辆合同价”只在概要主金额下方注明，列表不展示（用户 2026-11-25 反馈）。PRD 文字待同步。列表“清关状态”只展示状态、“已清关 k／共 N 辆”只在详情展示，同样待 PRD F-M12-02 列表字段同步。
- 未找到画面（D5）在卡内保留“返回”：该画面没有业务内容可浏览，返回是唯一的下一步。
