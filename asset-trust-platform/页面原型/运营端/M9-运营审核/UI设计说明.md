# M9 运营审核 · UI 设计说明

2026-11-25 · WS-676 · existing-system adaptation · 现有桌面控制台适配。

业务基线为 PRD `95c37ea7`，页面基线为原型 `6107c883`，执行时仓库基线 `ec740129`。沿用已确认的“只保留运营审核”“上链成功且在到期边界前才生效”、菜单顺序和 25 屏画面清单。本轮不新增业务状态、数据、校验或服务模拟。

## 实际变化

- **列表**：金额表头允许换行，英文金额与到期日标题不再重叠；金额使用正文数字及等宽数字排版，币种保持次级。查看为次要色，审核入口沿用主色，入口条件不变。名称沿用共享 `name-clip` 的首尾保留方式，鼠标或键盘可展开完整名称。原十列、固定编号／操作列和表内横向滚动保留；不压缩英文状态以强塞所有列。
- **申请概要**：金额与关键字段在左侧三列，当前状态在右侧按行对齐，≤1100 px 纵向排列。金额精度、当前状态、资料校验与全部不能审核原因保留。
- **详情层级**：共享分区导航生成后，按现有“确权与审核进度／上链信息／当前情况／当次依据／处理记录”合并导航入口，仍用原锚点、滚动高亮与焦点定位。所有卡片仍展开、顺序不变。分组标题 20 px、卡片标题沿用 16 px、字段值 14 px；同组卡片连接成连续阅读面，当次依据标题有中性标记，避免与实时资料混淆。
- **数据与反馈**：资产健康度百分比降为 20 px，保留原进度与精度。处理记录的长结果标签允许换行，避免到期后上链成功的反馈越界。完整上链凭证及地址增加通用查看图标，沿用共享浮层、Esc、复制和可访问名称。部分文件指纹本来只有缩写演示值，本轮没有编造完整哈希，也未宣称可查看其完整值。
- **审核弹窗**：A1–A5 统一使用既有 600 px 上限；申请核对信息用浅底连续字段，预警、审核说明、提交后果与底部确认分层。原必填／选填、错误、带入说明、500 字符提示、取消与确认入口均保留。

## 实现与继承

`m9.css` 只在 `html[data-module="ops-review"]` 下生效，取值复用共享 token，不复制共享组件或修改全局样式。`m9-presentation.js` 只合并导航和补充完整值呈现；弹层开关、定位、语言、复制、焦点和路由继续使用共享实现。HTML 只增加两份模块资源及呈现初始化调用。模块源码中的 25 屏正文、画面属性、业务入口、时间与复制标识均与基线逐项比对一致。

## 核验与运行

Chromium / Playwright 对源页实测 25 屏 × 中文／英文 × 1024、1280、1440、1920 px（高度 1000 px），共 200 组合。无脚本错误、整页横向溢出、关键字段越界、英文界面漏译（保留原业务值），图标按钮有可访问名称。逐一点击分组导航 384 次，目标、高亮、键盘焦点与吸顶避让通过。英文列表沿用较宽表格，仅在表内滚动，操作列保持固定；1440 px 中文待审核十列完整展示。

导出附件在浏览器离线模式复核 25 屏 × 中英文 × 1024／1440 px，共 100 组合，无脚本错误、外部请求或整页横向溢出；画面目录包含全部 25 屏并可进入 D13。JavaScript 语法检查及 `git diff --check` 通过，独立代码评审未发现缺陷。截图仅用于内部核验，不作为本轮附件交付。

中英文均实测：L1 → D1 → A1 → A2，画面目录至 A3 → 确认提交至 D4（角标 4 → 3），画面目录至 D5；D6 → A5（保留上次审核说明）→ D7。实测弹窗 Tab／Shift+Tab 环绕、Esc 关闭返回入口焦点，名称与凭证的键盘开合／Esc 返回、凭证复制完整值，以及 1024 px 表格滚动后操作列可达。D2、D3、D9、D11、D13 没有审核按钮。

仓库联看实测应收账款、内销合同、VIN、提单、保单、内销收款六类入口均到达原有详情。D1 的预警 `W-DEMO-0101` 未登记跨模块目标，点击沿用“该入口尚未纳入原型”提示，中英文一致；这是继承范围，未替换成其他预警或补画面。筛选仍是静态评审工具，不声称真实查询通过。

原型不是生产系统；说明填写完成与上链回调等静态画面通过原有画面目录切换。浏览器核验不代表万纳连、ERP 或真实接口能力通过。屏幕阅读器、1024 px 以下和生产服务未验证。

打开方式：仓库 `index.html` 以运营端进入“审核／运营审核”；单模块附件由 `_shared/export.py` 从源页生成，双击即可打开。跨模块入口在完整仓库中联看，附件沿用范围提示。
