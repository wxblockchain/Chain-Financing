# M8 风控预警与三方数据源 · 运营端原型

依据 [`PRD/运营端/M8-风控预警与三方数据源/`](../../../PRD/运营端/M8-风控预警与三方数据源/01-风控预警与三方数据源-PRD.md)，需求提交 `5d8ff68`（2026-11-12 需求评审稿）。组件规范 v1.21。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。预警编号、应收账款编号、单据号码、VIN、企业、金额、汇率、日期、处理说明与文件均为演示值；Carloha Holding / Carloha Nigeria、Demo Auto Trading Ltd 等不代表实际业务主体。ERP 原值、企业名称与运营填写的处理说明在英文界面不翻译。

## 打开与路径

双击 [`风控预警与三方数据源.html`](风控预警与三方数据源.html)，或使用离线单文件附件；无需服务。左侧菜单“风控 / 风控预警”进入列表，“风控 / 三方数据源”进入能力说明；顶栏消息入口沿用 M10 共享演示消息。侧栏底部“画面目录 · 演示数据”默认收起，列出全部 16 屏和“主流程下一屏”。

- 主流程（PRD 第 1 节示例）：L1 列表 → D1 W-DEMO-0007 详情 → “记录处理” P1 → “提交” P3 → “确认提交” D2（已处理，菜单角标 5 → 4）→ D3 一周后追加的收款登记标“处理后新增”。
- 列表：预警编号或右侧“查看”进入详情（演示提供 W-DEMO-0007 / 0010 / 0008 / 0005，其余行提示仅提供部分预警）。
- 关联应收账款编号、发票号、L5 的“返回应收账款”经[仓库联看](../../README.md#仓库联看)进入 M3；收款登记、保单、合同等单据编号没有对应画面，提示“该入口尚未纳入原型。”。D4、D5 的“记录处理”提示演示只在 W-DEMO-0007 上提供处理流程。

## 本期不做（按 PRD §1.2）

企业端（债权人、债务人）没有任何风控预警或三方数据源入口，本模块不出企业端画面。不提供手动新建、修改、删除、合并预警，不提供调整比对口径或阈值、发起比对、导出、批量处理、指派，也不提供处理结果的修改、撤回或二次处理入口。三方数据源不提供配置、连接、测试或核验。站外通知、M3—M6 与 M9 中的关联预警展示由各模块原型承接；消息 M8-NT01 归 M10。

## 待确认与未覆盖

- 以 PRD 为准、未单独出屏：预警不存在、带入对象已不存在、详情中关联应收账款或预警记录的局部加载失败、提交时已被他人处理 / 有新的差异 / 提交失败 / 账号失效、附件超过数量或大小、企业用户访问提示、待办数量取数失败不显示角标。
- 菜单角标为演示值：列表 5 条未处理对应角标 5，D2、D3 为处理后 4；接入时由本模块按未处理条数提供，全体运营相同。运营端其他模块原型侧栏同步出现该角标。
- 预警编号为本模块演示值，与 M10 演示消息中的 M8-NT01 编号不联动。
