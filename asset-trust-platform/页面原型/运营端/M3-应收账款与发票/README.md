## 详情结构

页头：债权人 → 债务人（首要信息），下一行应收账款编号与时区。

1. **概要**：应收账款金额；应收账款金额（美元）、已收款金额（美元）、待收款金额（美元）、应收账款起算日、应收账款到期日（剩余天数）；右侧到期状态、回款状态、预警信息；底部关联风控预警（未处理 / 已处理条数与“查看关联预警”）。
2. **进度与核对**：资产健康度四项并列——已收款比率、终端销售进度（已售 X 辆／共 Y 辆）、终端回款进度、保险覆盖率（应收账款保险金额）。比率条只表示读数，不按阈值变色。
3. **明细**：基础交易（内销发票、内销合同摘要）→ 车辆清单 → 回款记录 → 确权与审核进度（发起申请 / 债务人确认 / 运营审核 / 出库）→ 核心资料差异与核实。

车辆清单默认列为 VIN、物流节点、外采 / 内采 / 外销单价（美元）、外销收款金额（美元）；外采单价取外采合同单价时下方标“合同价”。行首按钮展开本车的内销（内销合同号、内销买方）、采购、运输与保险、外销、附件五组，卡头“全部展开”同时展开全部车辆。一辆车有多张同类单据时逐条列出，日期或金额跟在各自编号旁。

本模块不展示任何自行判定的风控提示，预警只承接 M8 的结果（PRD F-M3-14）。比率或金额“无法计算”时以占位符“-”展示（读屏仍读出“无法计算”）；“无法折算”“未提供”等缺失文案不变。
