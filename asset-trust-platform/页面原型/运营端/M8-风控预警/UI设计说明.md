## 变化与用途

- **预警列表**：将英文规则名从偏窄的列中释放，规则名称为主、规则编号次行；比较对象可换行、编号完整显示。筛选查找保留原有顺序和折行，左右固定编号与操作。阻断仍用文字、加粗等级和左边线共同标识。
- **规则与参数**：默认等级保留语义色、去掉底色；当前等级用浅底列及加粗标签突出，便于对照。操作中“调整等级”保持主色，“查看”“停用/启用”使用次要文字层级，确认步骤及后果不变。参数当前值加强数字层级，不改默认值、单位或输入。
- **详情**：比较对象 20 px、差异摘要 14 px，状态独立排列；1024 px 窄桌面将状态移到摘要下方。分区标题 20 px、记录事件标题 14 px，区分当前依据与历史动作。规则正文限制为 88ch，不限制数据表宽度，完整文字仍可读。阻断影响仍在标题下以锁图标、文字和语义色呈现；没有新增人工处理入口。
- **弹窗**：保留同一流程 600 px 的既有上限。只读上下文使用共享浅底与边框，正文以统一 20 px 间距排布，减少与可编辑字段混淆。确认页保留变化前后、影响及不可撤回等披露；长内容在正文内滚动，页脚操作可达。

实现为模块文件 `m8-ui.css`，只作用于显式 `.risk-view`。没有复制共享组件或修改壳层脚本。共享 `tokens.css` 仅新增 `:root[data-module="ops-risk"]` 下的尺寸 token，不改变任何全局默认 token；文字、颜色、间距均复用既有 token。

| token | 中文 / 英文 | 用途 |

| `--risk-alert-rule-w` | 240 / 264 px | 预警列表规则名列 |
| `--risk-alert-level-w` | 96 / 104 px | 等级列 |
| `--risk-search-w` | 480 px | 查找区 flex 参考宽度，空间不足时折行 |
| `--risk-rule-table-min` | 1040 / 1280 px | 规则表阅读下限，窄桌面仅表内横向滚动 |

## 实际验证

- Chromium / Playwright：35 屏 × 中文 / 英文 × 1024 / 1280 / 1440 / 1920 px，合计 280 组。无脚本错误、整页横向溢出、所检字段 / 状态标签的横向裁切或固定操作列溢出。英文填写内容中的处理说明和调整原因按原文保留，不计作缺翻译。
- 英文在 1024 / 1440 px 实测详情分区共 110 次定位：当前项、目标焦点与吸顶导航避让正确。内部检查代表性列表、阻断详情、企业名称差异、处理、保单、规则和弹窗截图。
- 与 `ec740129` 比对：35 屏文字及导航、数据、输入值、禁用属性保持一致；`s-info` DOM 原样保留。

- 源页和导出单文件均以中英文、1280 × 720 px 点通记录处理、调整等级、停用、参数调整四条流程；更多筛选展开 / 收起、弹窗 Tab 焦点保持、Esc 关闭后的原入口焦点返回、表格横向滚动后固定操作可达均通过。禁用网络请求时附件未请求外部资源。
- 仓库联看中，D1 应收账款入口到 M3 `o-detail`，D11 保单入口到 M13 `d-ngn`；D10 企业编号仍沿用未登记入口提示，没有补造目标页面。
