# M14 资金收付 · 运营端原型

依据 [`PRD/运营端/M14-资金收付/`](../../../PRD/运营端/M14-资金收付/01-资金收付-PRD.md)（当前基线为 WS-680 提交 `d2e32402`：用户确定详情只分“基本信息”“凭证附件”两部分，金额（美元）按收付日期当日汇率确定、不标“折算”，关联业务写明业务类型；缺失值统一为“-”）。组件规范 v1.37，WS-655 统一写法见 v1.43；本模块详情不再采用资产数据模块共用的三层结构（PRD M14-Q06）。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。界面语言随顶栏中英切换；凭证取得时间与所用汇率的生效时间按本人时区展示，时区标在详情说明行（M2 F-OP-10）；收付日期按原样展示，不换算。企业与客户名称、交易流水号、单据编号、金额、银行、账号、汇率与文件均为演示数据。

演示数据约定：

- 交易流水号与 M3 回款记录、M4 合同信息付款 / 收款记录、M5 外销段、M9 当次依据一致（TRX-DEMO-1015、TRX-DEMO-1102、TRX-DEMO-1214、RC-DEMO-7781、RC-DEMO-7802 等）；PAY-DEMO-0130、PAY-DEMO-0140、第二条 TRX-DEMO-1102（关联 INV-0019）和交易流水号未提供的一条外销收款（关联 SC-DEMO-2038）为本模块补充的样本。
- 汇率取 M11 原型的汇率历史：FX-DEMO-0001 1 USD = 1,528.50 NGN（2026-11-05 首次设置）、FX-DEMO-0002 1,535.84（2026-11-12）、FX-DEMO-0003 1,540.20（2026-11-19，当前）。
- “今天”与 M3 一致按 2026-12-14 演示：TRX-DEMO-1214（M3 AR-DEMO-0008 的当日 NGN 回款）按当前汇率暂计。

## 打开与路径

双击 [`资金收付.html`](资金收付.html)，或使用离线单文件附件；无需服务。左侧菜单“资产数据 / 资金收付”进入。侧栏底部“画面目录 · 演示数据”默认收起，列出全部画面和“主流程下一屏”。

- 主流程：L1 → 点交易流水号 TRX-DEMO-1015 → D1 →（主流程下一屏）D2 → D11 → D12；同号记录 D5 → D9。
- 收付类型下拉选“内销收款”进入 L2、选“外采付款”进入 L3（演示该类为空），选“全部”回到 L1。
- 列表中有画面的记录：TRX-DEMO-1214（D12）、RC-DEMO-7802（D11）、RC-DEMO-7781（D3）、TRX-DEMO-1102（关联 AR-DEMO-0012 的进入 D5，关联 AR-DEMO-0019 的进入 D9）、TRX-DEMO-1015（D1）、交易流水号为“-”的一行（“查看”进入 D10）、PAY-DEMO-0140（D4）、PAY-DEMO-0130（D2）；RC-DEMO-7790 提示演示范围。
- 跨模块入口（`data-module-key`）：应收账款编号 → `receivable:<应收账款编号>`（M3）；外销合同号 → `exportContract:`（M4）；“返回应收账款” → `invoices`。外采发票演示未登记定位，提示“演示仅提供部分单据的详情画面。”。关联预警条数为 `alertsOfFunds:<交易流水号>`（同号记录为 `alertsOfFunds:<交易流水号>:<关联单据编号>`），落点按 M8；M8 原型尚未登记，仓库联看中提示“该入口尚未纳入原型。”。
- 其他模块进入本模块（PRD §9.2），都用浏览器返回进入前的位置：
  - M3 回款记录、M4 付款 / 收款记录、M5 外销段、M8 预警详情、M9 当次依据中的交易流水号：路由 `funds:<交易流水号>`。已登记 TRX-DEMO-1015（D1）、TRX-DEMO-1102（D5）、TRX-DEMO-1214（D12）、RC-DEMO-7781（D3）、RC-DEMO-7802（D11）、PAY-DEMO-0130（D2）、PAY-DEMO-0140（D4），其余交易流水号提示“演示仅提供部分收付记录的详情画面。”
  - 同一交易流水号有多条记录时，落到来源位置对应的那一条：路由 `funds:<交易流水号>:<关联单据编号>`，`funds:TRX-DEMO-1102:INV-0012` → D5、`funds:TRX-DEMO-1102:INV-0019` → D9（M3 已接入）。

## 呈现说明

- 只有运营管理员一种角色，没有身份差异画面；企业端没有入口，本模块不出企业端画面。企业账号访问按 M2 F-OP-11、运营账号状态按 M2 处理，均由 M2 原型展示。
- 详情两部分（PRD §6.1）：“基本信息”一张卡，上半部分为金额、金额（美元）与所用汇率、收付日期、关联业务、关联预警，下半部分为收付双方的银行与账号；“凭证附件”一张卡。两部分页面较短，不加分区导航。付款方、收款方名称在页头展示一次，基本信息中不重复。
- 金额（美元）不标“折算”；所用汇率只在 NGN 记录的详情中展示，列表只展示金额。“暂计”为状态标签，当天结束后转为确定值、当天 M11 又生效新汇率等变化以 PRD §3.2 为准，不单独出屏。
- 缺失值（PRD §3.1）：取不到的值统一为“-”，读屏读原因；金额（美元）的原因写在“-”下方；ERP 未提供的来源值只展示“-”。“暂无凭证”“无关联预警”“暂计”等业务状态照常以文字展示。
- 列表每页 10 条（只画第 1 页），不展示金额合计，没有新增、编辑、删除操作；列表没有预警列，关联预警只在详情展示。
- 凭证附件只有一类，表头为“附件 | 取得时间”（同 M4）。
