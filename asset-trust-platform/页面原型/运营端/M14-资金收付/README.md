# M14 资金收付 · 运营端原型

依据 [`PRD/运营端/M14-资金收付/`](../../../PRD/运营端/M14-资金收付/01-资金收付-PRD.md)（提交 `18a3662d`，WS-663；已按 WS-655 确认口径修订）。组件规范 v1.37。

原型只用于评审页面、字段和主流程；规则、校验与异常分支以 PRD 为准。企业与客户名称、交易流水号、单据编号、金额、银行、账号、汇率与文件均为演示数据，交易流水号与 M3 回款记录、M4 合同信息付款 / 收款记录、M5 外销段一致（TRX-DEMO-1015、TRX-DEMO-1102、RC-DEMO-7781 等），PAY-DEMO-0130、PAY-DEMO-0140、RC-DEMO-7810 为本模块补充的演示样本。

## 打开与路径

双击 [`资金收付.html`](资金收付.html)，或使用离线单文件附件；无需服务。左侧菜单“资产数据 / 资金收付”进入。侧栏底部“画面目录 · 演示数据”默认收起，列出全部画面和“主流程下一屏”。

- 主流程：L1 → 点交易流水号 TRX-DEMO-1015 → D1 →（主流程下一屏）D2 → D3。
- 收付类型下拉选“内销收款”进入 L2、选“外采付款”进入 L3（演示该类为空），选“全部”回到 L1。
- 列表中有画面的交易流水号：TRX-DEMO-1015（D1）、PAY-DEMO-0130（D2）、RC-DEMO-7781（D3）、PAY-DEMO-0140（D4）、TRX-DEMO-1102（D5）；其余提示演示范围。
- 跨模块入口（`data-module-key`）：内销发票 INV-0012 → `receivable:AR-DEMO-0012`（M3）；外采发票 PPI-DEMO-0302 → `purchaseInvoice:`、PPI-DEMO-0301 → `purchaseContract:PO-DEMO-031`（M4）；外销合同 → `exportContract:`（M4）；“返回应收账款” → `invoices`。关联预警数量为 `alertsOfFunds:<交易流水号>`，待 M8 登记（M14-Q02）。演示未画出的单据提示“演示仅提供部分单据的详情画面。”
- 其他模块进入本模块：`funds:<交易流水号>`。M3、M4、M5 中已画出的 TRX-DEMO-1015、TRX-DEMO-1102、RC-DEMO-7781 进入详情，其余交易流水号提示“演示仅提供部分收付记录的详情画面。”

## 呈现说明

- 只有运营管理员一种角色，没有身份差异画面；企业端没有入口，本模块不出企业端画面。
- 收付日期按原样展示；凭证取得时间与汇率生效时间按 UTC 展示（M2 不提供运营时区设置时的口径）。
- 列表与平台其他业务列表一样每页 10 条（只画第 1 页），不展示金额合计，没有新增、编辑、删除操作。

## 本期不做（按 PRD §1.2）

录入、编辑、删除收付记录或凭证；已收、已付汇总、比率与收付状态；按单车拆分；本模块判断风控规则；退款、冲销；银行流水外部核验；企业端查看。
