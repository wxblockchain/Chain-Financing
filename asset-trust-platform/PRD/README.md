# 资产可信平台 · PRD

本目录存放资产可信平台的产品需求文档。各模块按 01 功能与业务规则、02 流程图与状态机、03 消息通知（仅自身发送消息时）、04 验收阅读；缺少 03 表示该模块自身不发消息。

## 目录约定

- 按使用端分目录：`企业端/` 放只在企业端使用的模块，`运营端/` 放只在运营端使用的模块，`两端共用/` 放同一套规则同时覆盖企业端与运营端的模块。
- 模块目录命名为「模块号-模块名」，目录内文件命名为「册号-模块名-用途.md」；册号固定，缺册不顺延。
- 新模块交付时按所属端放入对应目录，并在下表增加一行。

## 运营端

| 模块 | 分册入口 |
| --- | --- |
| M4 上游采购追溯 | [01 功能与业务规则](运营端/M4-上游采购追溯/01-上游采购追溯-PRD.md) / [02 流程图与状态机](运营端/M4-上游采购追溯/02-上游采购追溯-流程图与状态机.md) / [04 验收](运营端/M4-上游采购追溯/04-上游采购追溯-验收.md)；本模块不发消息；以应收账款发票为入口，按 VIN 登记取得外采订单、外采发票、外采付款，以外采订单为单位组成采购交易；按订单买方与应收账款卖方比对标出车辆归属；只供运营端查看，企业端不可见 |
| M6 下游销售与收款追溯 | [01 功能与业务规则](运营端/M6-下游销售与收款追溯/01-下游销售与收款追溯-PRD.md) / [02 流程图与状态机](运营端/M6-下游销售与收款追溯/02-下游销售与收款追溯-流程图与状态机.md) / [04 验收](运营端/M6-下游销售与收款追溯/04-下游销售与收款追溯-验收.md)；本模块不发消息；以应收账款发票为入口，按 VIN 取得 ERP 整车销售／批售的合同、发票、收款，以合同为单位组成销售交易；按合同卖方与应收账款买方比对标出车辆归属；销售收款不计入应收账款回款；只供运营端查看，企业端不可见 |
| M11 汇率管理 | [01 功能与业务规则](运营端/M11-汇率管理/01-汇率管理-PRD.md) / [02 流程图与状态机](运营端/M11-汇率管理/02-汇率管理-流程图与状态机.md) / [04 验收](运营端/M11-汇率管理/04-汇率管理-验收.md)；本模块不发消息；运营管理员人工维护“1 USD = R NGN”，汇率值两位小数，保存即生效，记录只增不改；对外提供当前汇率与某一时刻适用的汇率，哪些功能使用汇率由各使用模块规划 |
