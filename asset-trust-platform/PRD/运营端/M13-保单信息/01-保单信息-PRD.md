本册只定义信息需求与业务行为；页面布局与交互承载由 Hallmark 设计决定。以下设计约束由用户确定，保持不变：

- 运营端菜单名称为“保单信息”；列表一行是一张保单，只放用于定位和比较的字段，比率只在详情展示，与其他资产数据模块的同类展示一致。
- 详情统一为“概要 → 进度与核对 → 明细”三层；本模块的“进度与核对”即保障核对。
- 详情中的信息分区上下排列，不左右并排；明细中的车辆清单、关联提单、保单附件各占整行。分区宽度与分区内短字段的排列由设计决定。
- 页面中的单据编号都可点击，进入该单据所在模块的详情；VIN 进入车辆履约（M5）。
- 一个事实只在一个模块完整展示，其他模块展示摘要并跳转。

## 1. 模块是什么

保单信息以一张保单为单位，回答“这批货保了多少、保险金额够不够覆盖货值、每辆车摊到多少保险金额”。平台采信 ERP 中已审核的保单，按保单关联的提单找到提单上的车辆，再按每辆车的内采单价算出保险货值、保险覆盖率和车辆保险金额。本模块是保险金额与保险覆盖率的唯一完整展示处，并向应收账款（M3）提供每辆车的车辆保险金额；M3、车辆履约（M5）、提单信息（M12）如何使用和展示这些值，以各自 PRD 为准。本模块只供运营端使用，只读。

基本原则：

- 保单不直接关联车辆，也不关联内销合同：保单关联提单，提单上的全部车辆都是本保单覆盖的车辆。
- 一辆车只应被一张保单覆盖。同一辆车出现在多张保单中（含同一张提单被多张保单关联）时，本模块如实展示、照常计算，不判断是否构成风险，并向 M3 标明本车在几张保单中。
- 车辆的内采单价按车辆履约（M5）[价格链](../M5-车辆履约/01-车辆履约-PRD.md#price-chain)取值：已开内销发票时取内销发票单价；尚未开票时取内销合同单价，并标“合同价”。本车既无内销发票也无内销合同单价时，依赖它的保险货值、保险覆盖率和车辆保险金额展示“无法计算”，不按部分车辆先算。
- 只采信 ERP 中已审核的保单；未审核、已反审核、已作废或已删除的保单不出现在本模块。
- 美元金额按汇率管理（M11）查看时的当前汇率折算，同时保留原币金额。
- 本模块不判断任何风控规则。保险相关的风控规则由风控预警（M8）[保险规则（F-M8-17）](../M8-风控预警/01-风控预警-PRD.md#F-M8-17)定义，本模块只展示 M8 提供的本保单关联预警。
- 企业端（债权人、债务人）本期都看不到保单信息。

**一个完整的例子**（企业、保险公司名称、单据编号和金额为演示值）。ERP 中有一张已审核的保单 PL-889：保单日期 2026-09-09，保险公司“保险甲”，投保人和被保险人均为 Carloha Holding，币种 USD，保险金额 132,000.00 USD，关联提单 BL-5501 和 BL-5502。按提单信息（M12），BL-5501（装船日期 2026-09-10）装有 VIN-A、VIN-B，BL-5502（装船日期 2026-09-12）装有 VIN-C、VIN-D；四辆车都已开内销发票，内采单价都是 30,000.00 USD。平台算出：保险货值 120,000.00 USD，保险覆盖率 110.00%，每辆车的车辆保险金额 33,000.00 USD。运营人员打开“保单信息”，在列表中看到 PL-889 一行：保单日期 2026-09-09、保险甲、Carloha Holding、保险金额（美元）132,000.00 USD、关联提单 2 张／车辆 4 辆、预警“无”。进入详情：概要展示保单号、保单日期、保险公司、投保人、被保险人、币种、保险金额和关联预警；保障核对展示保险金额（美元）、保险货值（美元）、保险覆盖率和覆盖车辆数；明细中列出四辆车（VIN、提单号、内采单价、车辆保险金额）、两张关联提单和保单附件。运营人员点 VIN-C 进入车辆履约（M5）查看该车的外销情况，返回后点 BL-5502 进入提单信息（M12）查看船名航次，再返回 PL-889。本模块把每辆车 33,000.00 USD 的车辆保险金额提供给应收账款（M3）。

### 1.2 本期不做

- 在平台录入、编辑、删除保单或附件；运营端和企业端都没有这类操作。
- 任何风控规则的判断，包括保险是否足额、被保险人是否与基础交易一致、同一车辆是否被多张保单覆盖：由风控预警（M8）负责，本模块只展示 M8 提供的关联预警；保险覆盖率低于 100% 时也不在本模块突出显示。
- 提单的船名航次、港口、清关明细：在提单信息（M12）完整展示，本模块只展示提单号、装船日期、车辆数并跳转。
- 车辆的采购、内销、外销经历：在车辆履约（M5）完整展示，本模块只展示 VIN 并跳转。
- 应收账款的保险金额与保险覆盖率：由应收账款（M3）按本模块提供的车辆保险金额计算和展示。
- 保费金额、保费支付记录的展示与核对。
- 对保险条款、险种、承保范围作专业或合规结论。
- 企业端查看保单信息，包括债权人和债务人。

## 2. 术语

| 术语 | 含义 |
| --- | --- |
| 保单 | ERP 中一张已审核的保单单据，关联一张或多张提单 |
| 保单号 | 保单的编号 |
| 保单日期 | 保单上的保险日期；只展示，不参与任何计算 |
| 投保人 | 购买保险的一方，按 ERP 原值展示 |
| 被保险人 | 享有保险赔偿权利的一方，按 ERP 原值展示 |
| 保险金额 | 保单承保的金额，即整张保单的赔偿上限，按 ERP 原值展示 |
| 关联提单 | 保单在 ERP 中关联的提单；保单通过关联提单覆盖车辆 |
| 提单未采信 | 关联提单在 ERP 中尚未审核，或采信后被反审核、作废、删除而不在提单信息（M12）中；这类提单的车辆不计入覆盖车辆 |
| 覆盖车辆 | 已采信的关联提单上的全部车辆（按 VIN 去重），见[保单的采信与车辆对应（F-M13-01）](#F-M13-01) |
| 内采单价 | 本车在内销环节的单车价格，按车辆履约（M5）[价格链](../M5-车辆履约/01-车辆履约-PRD.md#price-chain)取值；保单本身不提供单车价 |
| 合同价 | 内采单价取自内销合同（本车尚未开内销发票）时的标记 |
| 保险货值 | 本保单全部覆盖车辆的内采单价（美元）合计，见[保障核对（F-M13-04）](#F-M13-04) |
| 保险覆盖率 | 保险金额（美元）÷ 保险货值（美元），见[保障核对（F-M13-04）](#F-M13-04) |
| 车辆保险金额 | 本车按本保单分得的保险金额：内采单价（美元）× 保险覆盖率，见[车辆清单与车辆保险金额（F-M13-05）](#F-M13-05) |
| 关联预警 | 风控预警（M8）提供的、关联对象中含本保单的预警，见 M8 [向其他模块提供的预警信息](../M8-风控预警/01-风控预警-PRD.md#external) |
| 运营人员 | 运营端账号的使用者，即 M2 [运营账号与角色（F-OP-01）](../M2-运营登录与企业管理/01-运营登录与企业管理-PRD.md#F-OP-01)中的运营管理员；本期运营端只有这一种角色，权限相同 |

## 3. 共用展示与异常规则

本节规则适用于本模块全部功能，其他章节直接引用，不重复展开。来源值、美元折算与比率、单据编号跳转与附件查看的口径与应收账款（M3）的[共用规则](../../两端共用/M3-应收账款与发票/01-应收账款与发票-PRD.md#shared-rules)一致，本节只写本模块的取值与结果。

<a id="display-values"></a>
### 3.1 来源值、金额与日期

- 保单号、保险公司、投保人、被保险人、日期、金额等按 ERP 原值展示，不翻译、不改写。
- ERP 没有提供某项值时，原因为“未提供”，页面上按[缺失值的展示](#placeholder)呈现。
- 平台文字（状态、空状态、说明）随 M2 [界面语言与时区（F-OP-10）](../M2-运营登录与企业管理/01-运营登录与企业管理-PRD.md#F-OP-10)中的界面语言切换；来源值不随界面语言翻译。
- 本册的业务文字以中文写定含义；英文界面文字以 Hallmark 原型的文案为准，须与中文含义一致，与 M3 [来源值、金额与时间](../../两端共用/M3-应收账款与发票/01-应收账款与发票-PRD.md#display-values)相同。
- 没有附件时展示“暂无附件”；某类内容一条都没有时展示该部分的空状态（如“暂无车辆”“未关联提单”）。
- 金额与币种代码同时展示，数值在前、币种代码在后，带千分位，例如“132,000.00 USD”。ERP 提供的原币金额按原值展示，不四舍五入、不截断。任何位置都不展示没有币种的金额。
- 不同币种的原币金额不直接相加；需要合计时按美元折算值合计。
- ERP 提供的日期（保单日期、装船日期）按原样展示，不做时区换算；ERP 随日期提供时区时，时区写在日期后面。
- 平台自己记录的时间（附件取得时间）展示到分钟，按 M2 [界面语言与时区（F-OP-10）](../M2-运营登录与企业管理/01-运营登录与企业管理-PRD.md#F-OP-10)中本人的时区展示并标明时区；同一页面已标明本人时区时，各条时间不必逐条重复标注。

<a id="sort-rule"></a>
#### 排列与比较

- 本册写“按某编号排列”（如按保单号、提单号、VIN 排列）时，均为升序，逐个字符比较，不区分大小写；例如 BL-10 排在 BL-9 之前。
- 按日期排列时，日期相同的再按本条规则写明的编号排列；日期缺失（显示为“-”）的排在最后。

<a id="M13-Q09"></a>
<a id="placeholder"></a>
#### 缺失值的展示

- 取不到或算不出的值，按应收账款（M3）[缺失值的展示](../../两端共用/M3-应收账款与发票/01-应收账款与发票-PRD.md#placeholder)统一以“-”展示。本册写作“未提供”“无法计算”“无法折算”“无可用汇率”“无内采单价”的，都是缺失原因，页面上均显示为“-”。
- 原因需要让运营人员知道时，写在“-”下方，例如保险货值下方注明“N 张关联提单未采信”“N 辆车无内采单价”“无覆盖车辆”，美元值下方注明“无法折算”“无可用汇率”。
- 以下是业务状态，照常以文字展示，不改为“-”：提单未采信、未关联提单、无关联预警、无，以及“合同价”标记与折算标识。
- 空清单与无结果（如“暂无车辆”“暂无附件”“暂无保单资料”“没有符合条件的保单”）照常以文字展示。

<a id="usd"></a>
### 3.2 美元折算与比率

字段名带“（美元）”的值按下表得出，并与原币金额同时展示（列表中的保险金额（美元）除外，见[保单信息列表（F-M13-02）](#F-M13-02)）；折算值带折算标识。

| 原币 | 美元值 |
| --- | --- |
| USD | 等于原币金额，不带折算标识 |
| NGN | 原币金额 ÷ M11 汇率（1 USD = R NGN），汇率取查看时 M11 的当前汇率 |
| 其他币种 | 展示“无法折算”（M11 只维护美元与奈拉） |
| NGN，但 M11 无可用汇率 | 展示“无可用汇率” |

- 汇率按 M11 [对外提供的汇率口径（FX-05）](../M11-汇率管理/01-汇率管理-PRD.md#FX-05)取得；从折算标识可查看所用汇率值及其生效时间。折算标识的形式（是否带“折算”文字）由设计确定。
- 美元值保留两位小数，四舍五入；合计、比率和车辆保险金额用未取舍的值计算，展示时再取舍。
- 比率以百分数展示，保留两位小数、向下截取（例如 99.996% 展示为 99.99%），保证未达到 100% 时不会显示为 100.00%；超过 100% 时按实际值展示，不封顶。
- 美元值为“无法折算”“无可用汇率”时，美元值显示“-”并在下方注明原因，不用 0 或其他值代替；详情中原币金额照常展示。依赖它的合计、比率和车辆保险金额展示“无法计算”。
- 比率的分子或分母无法取得，或分母为 0 时，比率展示“无法计算”。

### 3.3 单据编号跳转

本模块中的编号都可点击，进入该编号所在模块的详情；看完可返回本保单详情。

| 编号 | 进入 |
| --- | --- |
| 保单号 | 本模块该保单的详情 |
| 提单号 | 提单信息（M12）的[提单详情（F-M12-03）](../M12-提单信息/01-提单信息-PRD.md#F-M12-03) |

- 编号对应的单据未采信、不在平台中时，编号按原值展示，不可点击。
- 目标详情的落点及目标已不存在时的结果，以目标模块为准。

### 3.4 附件查看

- 每份附件展示附件名称和取得时间，可在线查看和下载。
- 附件打开或下载失败时，提示“文件暂时无法打开，请稍后重试”，不影响查看其他信息。

<a id="no-access"></a>
### 3.5 不可访问

- 企业端没有保单信息入口。以企业账号的登录状态访问本模块任何内容时，按 M2 [运营端菜单与无权访问（F-OP-11）](../M2-运营登录与企业管理/01-运营登录与企业管理-PRD.md#F-OP-11)处理，不返回任何内容，不透露保单是否存在。
- 运营账号待首登改密或锁定中时不能使用本模块，账号状态见 M2 [运营账号状态](../M2-运营登录与企业管理/01-运营登录与企业管理-PRD.md#op-account-status)；本期运营账号不设停用。

<a id="load-fail"></a>
### 3.6 加载失败

- 列表或详情加载失败时，提示加载失败并可重试；不展示不完整的金额或比率，避免把加载失败误显示为“暂无保单资料”或“0.00%”。
- 详情中某一部分（如车辆清单、关联提单、附件、关联预警）或某一项来自其他模块的值加载失败时，仅该处提示失败并可重试，其他部分正常展示。
- 某辆车的内采单价或折算所需的汇率加载失败时，该单元格提示失败并可重试；依赖它的保险货值、保险覆盖率和车辆保险金额显示“-”，下方不注明“N 辆车无内采单价”（车辆并非没有单价）。此时这些车辆的车辆保险金额对其他模块同样是“无法计算”，不以 0 代替。

<a id="F-M13-01"></a>
## 4. 保单的采信与车辆对应（F-M13-01）

适用范围：平台从 ERP 取得保单后，判断哪些保单进入本模块、每张保单覆盖哪些车辆。结果对运营人员可见，没有用户操作。取得方式由研发决定，本 PRD 不限定。

流程参见：[保单的采信与车辆对应（图 M13-1）](./02-保单信息-流程图与状态机.md#fig-m13-1)。
验收参见：[保单的采信与车辆对应](./04-保单信息-验收.md#acc-f-m13-01)。

<a id="adopt-rules"></a>
### 4.1 只采信已审核保单

- 只有 ERP 中已审核的保单进入本模块；未审核的保单不展示，也不参与任何计算。
- 平台以 ERP 中的同一张保单单据识别同一张保单。同一张保单再次取得且内容一致时不重复展示；内容不同（含保险金额、币种、关联提单的增减）时，新内容直接成为当前展示内容，本模块的计算值随之更新。
- 已采信的保单之后被反审核、作废或删除时，从本模块移除，并不再向其他模块提供该保单。
- 运营人员只看到当前资料，本模块不展示保单变化前的内容和变化历史。

<a id="vehicle-rules"></a>
### 4.2 保单覆盖哪些车辆

| 对象 | 取得方式 | 缺失或异常时 |
| --- | --- | --- |
| 关联提单 | 保单在 ERP 中关联的提单，可多张 | 保单没有关联任何提单时，关联提单展示“未关联提单”，覆盖车辆为 0 辆 |
| 提单号、装船日期、提单上的车辆 | 按提单信息（M12）中该提单的当前资料 | 关联提单未采信（ERP 中尚未审核，或采信后被反审核、作废、删除）时，该提单展示“提单未采信”，它的车辆不计入；已采信的提单之后被移除时同样处理，本保单的覆盖车辆和计算值随之重新得出 |
| 覆盖车辆 | 已采信的关联提单上的全部车辆，按 VIN 去重；VIN 的比较与展示写法按车辆履约（M5）[只采信已审核单据](../M5-车辆履约/01-车辆履约-PRD.md#adopt-rules)（不区分大小写、忽略空白字符，展示规范写法） | 同一 VIN 出现在本保单的两张关联提单上时只计一辆，提单号两张都列出 |
| 内采单价 | 按车辆履约（M5）[价格链](../M5-车辆履约/01-车辆履约-PRD.md#price-chain)：已开内销发票时取内销发票单价；尚未开票时取内销合同单价，并标“合同价” | 本车既无内销发票也无内销合同单价时展示“无内采单价” |

- 保单不需要 VIN，也不关联内销合同；车辆一律经关联提单得到。
- 关联提单的车辆增减（如 M12 中提单车辆变化）后，本保单的覆盖车辆和计算值随之更新。
- 一辆车只应被一张保单覆盖。同一辆车出现在多张保单中（含同一张提单被多张保单关联）时，本模块如实展示：每张保单的车辆清单都列出该车，每张保单的保险货值、保险覆盖率和车辆保险金额照常计算，本模块不作提示。
- <a id="M13-Q08"></a>是否构成风险由风控预警（M8）的[同一车辆被多张保单覆盖（RK-35）](../M8-风控预警/01-风控预警-PRD.md#RK-35)判断，提醒以 M8 提供的关联预警呈现，计入本保单的[关联预警（F-M13-07）](#F-M13-07)。

<a id="F-M13-02"></a>
## 5. 保单信息列表（F-M13-02）

适用角色与前提：可正常使用的运营人员，从运营端“保单信息”菜单进入。可查看本模块的全部保单。

验收参见：[保单信息列表](./04-保单信息-验收.md#acc-f-m13-02)。

列表每张保单一行，只放定位和比较所需的字段；保险货值、保险覆盖率及不能计算的原因只在详情[保障核对（F-M13-04）](#F-M13-04)展示：

| 业务信息 | 含义 | 来源 |
| --- | --- | --- |
| 保单号 | 点击进入[保单详情（F-M13-03）](#F-M13-03) | 保单 |
| 保单日期 | 保险日期 | 保单 |
| 保险公司 | 承保保险公司 | 保单 |
| 被保险人 | 被保险人 | 保单 |
| 保险金额（美元） | 按[美元折算与比率](#usd)得出，只展示美元值，折算值带折算标识；原币金额在[保单详情（F-M13-03）](#F-M13-03)概要中查看 | 保单保险金额折算；无法折算或无可用汇率时按[缺失值的展示](#placeholder)显示“-”，下方注明原因 |
| 关联提单数／车辆数 | 关联提单张数、覆盖车辆辆数，如“2 张／4 辆”；未采信的提单计入张数，它的车辆不计入辆数 | 平台计数 |
| 预警 | 本保单未处理的关联预警条数；没有时展示“无” | M8 提供，见[关联预警（F-M13-07）](#F-M13-07) |

查找与筛选：

- 查找：输入内容先去掉首尾空格，再与保单号、提单号、VIN 任一项部分匹配，不区分大小写，即列出对应保单。按提单号匹配时列出关联了该提单的全部保单，含未采信、按原值展示的关联提单号；按 VIN 匹配时列出覆盖该车的全部保单。
- 筛选：
  - 保险公司：选项为当前已采信保单中出现过的保险公司。
  - 保单日期范围：包含起止日；设了日期范围时，没有保单日期的保单不列出。
  - 是否有未处理关联预警。
  - 查找与各筛选同时生效。
- 默认按保单日期从新到旧排列；日期相同时按保单号排列，没有保单日期的排在最后，规则见[排列与比较](#sort-rule)。

边界与异常：

- 平台尚未采信任何保单时，展示“暂无保单资料”；查找或筛选无结果时，展示“没有符合条件的保单”并可清除条件。
- 关联预警条数加载失败时，“预警”列提示失败并可重试，不显示“无”；此时选用“有未处理关联预警”筛选，提示加载失败并可重试，不返回“没有符合条件的保单”。
- 列表不提供新增、编辑、删除操作。
- 加载失败按[加载失败](#load-fail)处理。

<a id="F-M13-04"></a>
## 7. 保障核对（F-M13-04）

适用范围：平台对每张保单计算保险货值和保险覆盖率，在详情“保障核对”中展示。没有用户操作。

流程参见：[保险货值、覆盖率与车辆保险金额（图 M13-2）](./02-保单信息-流程图与状态机.md#fig-m13-2)。
验收参见：[保障核对](./04-保单信息-验收.md#acc-f-m13-04)。

<a id="coverage-rule"></a>
### 7.1 计算口径

| 指标 | 计算 | 展示 |
| --- | --- | --- |
| 保险金额（美元） | 保单保险金额按[美元折算与比率](#usd)折算 | 美元金额，原币不是 USD 时同时展示原币金额 |
| 保险货值（美元） | 本保单全部覆盖车辆的内采单价（美元）合计 | 美元金额，并注明“共 N 辆车”；有合同价车辆时同时注明“含 N 辆合同价” |
| 保险覆盖率 | 保险金额（美元）÷ 保险货值（美元） | 百分数，按[美元折算与比率](#usd)取舍，超过 100% 按实际值展示 |
| 覆盖车辆数 | 覆盖车辆的辆数，未采信提单上的车辆不计入 | 辆数 |

<a id="coverage-cases"></a>
### 7.2 不能计算的情形

| 情形 | 保险货值（美元） | 保险覆盖率 |
| --- | --- | --- |
| 任一覆盖车辆既无内销发票也无内销合同单价 | 展示“无法计算”，并注明“N 辆车无内采单价” | 展示“无法计算” |
| 任一覆盖车辆的内采单价无法折算或无可用汇率 | 展示“无法计算”，并注明对应车辆数及原因 | 展示“无法计算” |
| 关联提单中有提单未采信 | 展示“无法计算”，并注明“N 张关联提单未采信” | 展示“无法计算” |
| 保单没有覆盖车辆（未关联提单，或关联提单上没有车辆） | 展示“无法计算”，并注明“无覆盖车辆” | 展示“无法计算” |
| 保险金额无法折算或无可用汇率 | 照常计算 | 展示“无法计算” |
| ERP 未提供保险金额或币种（保险金额显示“-”，下方注明“未提供”） | 照常计算 | 展示“无法计算” |
| 保险货值合计为 0 | 展示“0.00 USD” | 展示“无法计算” |

- 保险金额为 0.00 时照常计算：保险覆盖率为 0.00%，车辆保险金额为 0.00 USD，本模块不作提示。
- 不按部分车辆先算保险货值；全部覆盖车辆都有内采单价（美元）后才得出结果。
- 内采单价为合同价的车辆照常计入保险货值；该车开出内销发票后改按内销发票单价重新计算，不再标“合同价”。
- 内采单价、汇率、关联提单或车辆变化后，保险货值和保险覆盖率随之重新计算。
- 保险覆盖率只是计算结果，本模块不判断是否足额、不作提示，也不影响其他模块的任何状态。
- 保单日期不参与计算；汇率按[美元折算与比率](#usd)取当前口径。

<a id="F-M13-05"></a>
## 8. 车辆清单与车辆保险金额（F-M13-05）

适用角色与前提：可正常使用的运营人员，在详情明细中查看。只读。

验收参见：[车辆清单与车辆保险金额](./04-保单信息-验收.md#acc-f-m13-05)。

每辆覆盖车辆一行，按提单号、再按 VIN 排列（见[排列与比较](#sort-rule)）；本车在本保单两张关联提单上时，按排在最前的提单号排列：

| 业务信息 | 含义 |
| --- | --- |
| VIN | 可点击，进入车辆履约（M5）详情 |
| 提单号 | 本车所在的本保单关联提单，可点击进入提单信息（M12）详情；本车在本保单两张关联提单上时两张都列出 |
| 内采单价（美元） | 本车内采单价按[美元折算与比率](#usd)折算，原币不是 USD 时同时展示原币金额；取自内销合同时标“合同价”；本车既无内销发票也无内销合同单价时展示“无内采单价” |
| 车辆保险金额（美元） | 内采单价（美元）× 本保单保险覆盖率；不能计算时展示“无法计算” |

- 车辆保险金额用未取舍的内采单价（美元）和保险覆盖率计算，结果保留两位小数、四舍五入。全部车辆保险金额之和与保险金额（美元）因取舍可能相差几分，不另作调整。
- 内采单价为合同价的车辆，车辆保险金额照常计算，并同样标“合同价”。
- 本保单保险覆盖率为“无法计算”时，全部车辆的车辆保险金额都展示“无法计算”。
- 本模块向应收账款（M3）提供每辆车在每张保单中的车辆保险金额，并标明本车在几张保单中；M3 如何汇总，见 M3 [资产健康度（F-M3-11）](../../两端共用/M3-应收账款与发票/01-应收账款与发票-PRD.md#F-M3-11)。
- 本车同时在多张保单中时，本模块在每张保单中照常给出它的车辆保险金额，不作提示。
- 没有覆盖车辆时，车辆清单展示“暂无车辆”；有提单未采信时，只列已采信提单上的车辆，并注明“N 张关联提单未采信”。

## 9. 关联提单与附件（F-M13-06）

<a id="linked-bl"></a>
### 9.1 关联提单

每张关联提单一行，按装船日期从新到旧排列；装船日期相同时按提单号排列，装船日期缺失（如提单未采信）的排在最后，见[排列与比较](#sort-rule)：

| 业务信息 | 含义 |
| --- | --- |
| 提单号 | 可点击，进入提单信息（M12）详情 |
| 装船日期 | 该提单的装船日期，按提单信息（M12） |
| 车辆数 | 该提单上的车辆数 |

- 关联提单未采信时（含已采信后被反审核、作废、删除），该行提单号按原值展示并注明“提单未采信”，不可点击，装船日期和车辆数按[缺失值的展示](#placeholder)显示“-”；平台已取不到提单号时，提单号也显示“-”。
- 船公司、船名航次、港口、清关等提单信息在提单信息（M12）查看，本模块不展示。
- 保单没有关联提单时展示“未关联提单”。

<a id="attachments"></a>
### 9.2 附件

- 本保单的全部附件统一列为“保单附件”，可有多份，不再细分类别。
- 没有附件时展示“暂无附件”；附件查看按[附件查看](#file-view)。

<a id="F-M13-07"></a>
## 10. 关联预警（F-M13-07）

适用角色与前提：可正常使用的运营人员，在列表和详情中查看。

流程参见：[各入口与跳转（图 M13-3）](./02-保单信息-流程图与状态机.md#fig-m13-3)。
验收参见：[关联预警](./04-保单信息-验收.md#acc-f-m13-07)。

- 本模块不判断任何风控规则，也不在字段旁给出风控提示。哪些预警算本保单的关联预警、条数如何计算，按 M8 [向其他模块提供的预警信息](../M8-风控预警/01-风控预警-PRD.md#external)。
- 本模块展示 M8 提供的本保单关联预警：
  - 列表“预警”：本保单未处理的关联预警条数；没有时展示“无”；加载失败时见[保单信息列表（F-M13-02）](#F-M13-02)的边界与异常。
  - 详情概要：未处理和已处理的关联预警条数；都没有时展示“无关联预警”。
- 点击预警条数进入 M8，落点与返回按 M8 [进入与返回](../M8-风控预警/01-风控预警-PRD.md#entries)。
- 本模块展示的条数始终与 M8 一致，M8 生成、处理或解除预警后随之更新。
- 预警不改变本模块的任何金额、比率或车辆清单；本模块没有处理预警的操作。
- 关联预警加载失败时，仅该部分提示失败并可重试，不显示为“无”或“无关联预警”。

<a id="pending"></a>
## 12. 待确认事项与依赖

本模块当前没有待确认事项。

<a id="dependencies"></a>
依赖：

- 客户 ERP：提供已审核的保单（保单号、保险日期、保险公司、投保人、被保险人、币种、保险金额、关联提单）、保单附件，以及保单的反审核、作废、删除；数据对接由研发负责。
- 提单信息（M12）：按提单提供提单号、装船日期、车辆 VIN 及详情入口，以及提单是否仍被采信。
- 车辆履约（M5）：按[价格链](../M5-车辆履约/01-车辆履约-PRD.md#price-chain)提供每辆车的内采单价（含是否为合同价），并提供车辆履约详情入口。
- 汇率管理（M11）：按[对外提供的汇率口径（FX-05）](../M11-汇率管理/01-汇率管理-PRD.md#FX-05)提供查看时的当前汇率及其生效时间。
- 风控预警（M8）：判断全部风控规则（含[同一车辆被多张保单覆盖（RK-35）](../M8-风控预警/01-风控预警-PRD.md#RK-35)），按[向其他模块提供的预警信息](../M8-风控预警/01-风控预警-PRD.md#external)提供本保单未处理、已处理的关联预警条数及入口。
- 应收账款（M3）、车辆履约（M5）、提单信息（M12）、风控预警（M8）：在各自页面提供进入本模块的保单号。
- 运营登录与企业管理（M2）：提供运营账号及状态、界面语言与时区、运营端菜单登记，以及无权访问的统一处理。
