# 运营登录、企业邀请与企业管理 · 消息通知

2026-11-24｜需求评审稿｜对应功能册：[01](./01-运营登录与企业管理-PRD.md)

本模块发送 3 类邮件，均为必发，收件人不能关闭；全部只发邮件，不发站内消息，不进入消息中心（M10）。发送对象只有运营账号本人和企业账号的当前登录邮箱，不发联系邮箱，不抄送其他运营或其他企业。

| 消息 | 渠道 | 触发功能 | 收件人 | 打开后去哪 |
| --- | --- | --- | --- | --- |
| [运营找回密码验证码（NT-OP-01）](#NT-OP-01) | 邮件 | [自助找回密码（F-OP-03）](./01-运营登录与企业管理-PRD.md#F-OP-03) | 运营账号当前登录邮箱 | 回到已发起的找回流程输入验证码，不自动登录 |
| [运营密码变更通知（NT-OP-02）](#NT-OP-02) | 邮件 | [首次登录强制改密（F-OP-04）](./01-运营登录与企业管理-PRD.md#F-OP-04)、[自助找回密码（F-OP-03）](./01-运营登录与企业管理-PRD.md#F-OP-03)、[修改密码（F-OP-09）](./01-运营登录与企业管理-PRD.md#F-OP-09) | 运营账号本人当前登录邮箱 | 仅告知，不要求操作 |
| [企业邀请邮件（NT-EN-01）](#NT-EN-01) | 邮件 | [邀请企业并开通唯一企业用户（F-EN-02）](./01-运营登录与企业管理-PRD.md#F-EN-02)、[重发邀请（F-EN-07）](./01-运营登录与企业管理-PRD.md#F-EN-07)、[登录邮箱填错的更正](./01-运营登录与企业管理-PRD.md#login-email-fix) | 企业账号当前登录邮箱 | 企业端登录入口 |

以下情况本模块不发消息：运营账号的锁定与解除；企业账号的临时锁定、自助找回密码和修改登录邮箱（均由 M1 处理，运营端不接收任何通知）【确认】；编辑企业资料、增加业务角色；企业完成入驻、成为已认证；登录成功或失败；语言与时区变更；开发人员分配、重新分配运营初始密码；任何未成功的操作（校验失败、取消、保存失败）。企业用户在企业端产生的消息由[企业登录与首次入驻（M1）](../../企业端/M1-企业登录与首次入驻/03-企业登录与首次入驻-消息通知.md)定义；运营端不接收企业用户自助找回密码的任何通知【确认】。

<a id="NT-OP-01"></a>
## 运营找回密码验证码（NT-OP-01）

- 触发：运营在忘记密码流程获取或重发验证码，目标是运营账号当前登录邮箱，已通过[发码前人机校验](./01-运营登录与企业管理-PRD.md#captcha)并满足[验证码参数](./01-运营登录与企业管理-PRD.md#code-params)。
- 不触发：邮箱格式不合格、邮箱不是运营账号（含企业账号的登录邮箱）、人机校验未通过或已失效、发送限制未满足、请求失败。
- 收件人：只发该运营账号当前登录邮箱。
- 必须包含：6 位验证码、用途为找回运营端密码、有效期 10 分钟、非本人操作时可忽略；不包含任何密码或其他账号信息；验证码不出现在主题中。
- 同一事实：同一次发送请求只发一封；再次成功获取是新的发码事实，使前一码作废。
- 异常：发送失败时说明暂时无法发送，可立即重试 1 次（不计额度、不受间隔限制，仍须人机校验）；密码与已有登录不变。邮箱不是运营账号时反馈与有效邮箱相同。

**文案**（先简体中文、后 English，两段使用同一验证码；{验证码} 为本次 6 位数字）

| 语言 | 主题 | 正文 |
| --- | --- | --- |
| 中文 | 运营端找回密码验证码 | 您正在找回资产可信平台运营端账号的密码。验证码：{验证码}，10 分钟内有效。请勿将验证码告诉他人。如非本人操作，请忽略本邮件，您的密码不会改变。 |
| English | Operations console password reset code | You are resetting the password of your Asset Trust Platform operations console account. Your verification code is {code}, valid for 10 minutes. Do not share this code with anyone. If you did not request this, ignore this email; your password will not change. |

<a id="NT-OP-02"></a>
## 运营密码变更通知（NT-OP-02）

| 项目 | 规则 |
| --- | --- |
| 触发 | 新密码真实生效时：首次登录强制改密成功（设置）、自助找回成功（重置）、修改密码成功（修改）；在新密码生效之后、该账号全部登录结束之前发出 |
| 不触发 | 校验不通过、当前密码错误或验证已过期、验证码无效、取消、保存失败、提交期间登录结束；开发人员重新分配初始密码 |
| 收件人 | 该运营账号当前登录邮箱，不发给其他运营 |
| 同一事实 | 账号＋本次密码生效；一次生效只发一封，重试和重新登录不构成新事实 |
| 发生时间 | 新密码生效的时间，按本人时区展示并标明时区 |
| 发送失败 | 不回滚已生效的新密码，也不阻止全部登录结束 |
| 不得出现 | 明文密码、初始密码、验证码、免密或自动登录链接 |

## 企业邀请邮件（NT-EN-01）

| 项目 | 规则 |
| --- | --- |
| 触发 | 三种情形：邀请企业成功；入驻进度为待首次改密时运营重发邀请成功；入驻进度为待首次改密时开发人员更正登录邮箱成功 |
| 不触发 | 邀请校验失败、重复邀请被拦截、重复提交承接原结果；企业用户已完成首次改密（此后没有重发邀请，也没有运营重置密码） |
| 收件人 | 企业账号当前登录邮箱；不发联系邮箱，不发填错的旧登录邮箱 |
| 必须包含 | 企业名称、登录邮箱、本次初始密码、企业端登录入口、首次登录须修改密码并完成钱包绑定与资料提交后才能办理业务 |
| 不得出现 | 运营姓名、企业编号等内部信息；初始密码不出现在主题中 |
| 同一事实 | 账号＋本次初始密码生成；每次邀请、重发或更正各为新事实，各发一封；新一封中的初始密码生效后，之前邮件中的初始密码作废 |
| 发送失败 | 不回滚已建立的企业与账号或已生效的新初始密码；运营看到邮件未发出，可重发邀请 |
| 打开后去哪 | 企业端登录入口；邮件不提供免密登录 |

## 共同内容与有效性

- 每封邮件先简体中文、后 English，两段内容相同；变量中的业务值（企业名称、邮箱、验证码、初始密码）两段一致，不翻译。
- 所有邮件都不提供免密登录链接，不发送本人设置后的密码。
- 企业邀请邮件中的初始密码是平台向企业用户交付初始凭据的唯一渠道；运营在任何页面都看不到。
- <a id="support-channel"></a>运营密码变更通知中的求助方式使用官方客服邮箱，由需求方在上线后提供；该邮箱须在账号无法登录时仍可使用，中英文使用同一地址，不使用个人联系方式或占位内容。客服邮箱提供前，该通知省略含 {官方求助渠道} 的一句，其余内容照常发送；已发出的邮件不补发、不改写。
