# 下游销售与收款追溯 · 验收

2026-11-13｜需求评审稿｜供测试使用

本册只写验收标准，测试用例与执行步骤由测试小队编写。规则见[功能册](./01-下游销售与收款追溯-PRD.md)，各节顺序与功能册一致；原型画面用于核对布局，不作为验收依据。

怎么读：

- 共 26 条验收，编号 AC-M6-01 至 AC-M6-26 连续。
- 一条验收写了多个场景时，全部场景都满足才算通过。
- 下文的企业名称、客户名称和单据编号都是演示值。

## 0. 验收前准备

账号：

- 运营人员甲：可正常使用，M2 账号设置中时区为 UTC+01:00。
- 运营人员乙：可正常使用；用于验证 M2 不提供时区设置时按 UTC 展示（如 M2 已提供时区设置，可改用时区设为 UTC 的账号）。
- 运营人员丙：处于待首次改密、已停用或锁定中之一。
- 企业 H：已完成首次入驻，运营分配了债权人角色（演示值可用 Carloha Holding）。
- 企业 N：已完成首次入驻，运营分配了债务人角色（演示值可用 Carloha Nigeria）。

数据：

- 应收账款 AR-0012：卖方对应企业 H，买方对应企业 N，销售清单含 VIN-A、VIN-B；有累计已收、未收金额和回款状态，用于核对不受下游收款影响。
- 应收账款 AR-0020：买方对应企业丙，销售清单含 VIN-A。
- 应收账款 AR-0030：买方未对应任何平台企业，销售清单含 VIN-E。
- 销售交易 SC-2045：合同卖方企业 N，客户 Lagos Motors Ltd、客户号 C-0388，车辆 VIN-A 销售价格 45,000,000.00 NGN、VIN-C 销售价格 45,000,000.00 NGN，未开票金额 0.00 NGN；发票 SI-3301 金额 90,000,000.00 NGN、未收金额 40,000,000.00 NGN；SI-3301 下一笔收款 RC-5501，收款金额 50,000,000.00 NGN。
- 合同 SC-3001：卖方企业丙，车辆中列有 VIN-A。
- 归属变体：VIN-D 列在两份卖方都是企业 N 的合同中；VIN-F 只列在卖方为企业丙或卖方未提供的合同中；VIN-B 没有任何合同列有；VIN-G 列在某份合同中但不在任何应收账款中；VIN-E 所在合同的卖方与 AR-0030 发票上的买方主体一致。
- 更新变体：同一资料再次取得且内容一致、内容不同（合同车辆增减、销售价格或未收金额变化、附件更换）、被移除；VIN-B 之后取得卖方为企业 N 的合同。
- 金额与收款变体：一份合同有两张发票；某车销售价格未提供；合同车辆销售价格币种不一致；收款币种与发票币种不同；同一收款交易编号登记在两张发票下；付款方不是客户的收款；累计已收与未收金额之和不等于发票金额；ERP 未提供未收金额或未开票金额；发票下没有收款；合同下没有发票。
- 有关联风控预警（含未处理和已处理）的销售交易，以及没有预警的销售交易（预警由 M8 提供，可用模拟数据）。
- 附件打开失败的样本；尚无任何下游资料的空环境。
