# 运营审核 · 消息通知

2026-11-25｜需求评审稿｜配套[功能与业务规则](./01-运营审核-PRD.md)

本模块发送 2 类站内消息，经消息中心（M10）展示，按 [来源接入要求（MSG-06）](../../两端共用/M10-消息中心/01-消息中心-PRD.md#MSG-06)登记；必发，收件人不能关闭。本模块不发送邮件。事件编号沿用原值，缺号不代表遗漏。

| 消息 | 端 | 所在功能 | 触发环节 | 谁收到 | 打开后去哪 |
| --- | --- | --- | --- | --- | --- |
| [运营审核已通过（M9-NT01）](#M9-NT01) | 企业端 | [审核通过（F-M9-03）](./01-运营审核-PRD.md#F-M9-03) | 审核提交上链成功、申请变为“运营审核通过” | 该申请的债权人企业 | 应收查看与确权申请（M7a）中这笔申请的详情 |
| [运营审核上链失败（M9-NT03）](#M9-NT03) | 运营端 | [审核通过（F-M9-03）](./01-运营审核-PRD.md#F-M9-03) | 一次审核提交上链失败 | 全体运营 | 本模块中这笔申请的详情 |

以下情况本模块不发消息：审核通过因不满足条件、提交失败、重复提交而未形成审核提交；用户取消；审核提交形成、进入上链中；上链结果未返回；查看列表、详情；待审核数量变化。

不发给债务人企业：债务人看到的进度到“运营审核通过”为止（按 M7b）。新申请待运营审核的消息由确权待办与确认处理（M7b）发送“有新的确权申请待运营审核（M7b-NT03）”，本模块不发同义消息；申请到期关闭的消息由 M7a 发送。

<a id="M9-NT01"></a>
## 运营审核已通过（M9-NT01）

| 项目 | 规则 |
| --- | --- |
| 发送来源 | 运营审核（M9）；其他模块不发同义消息 |
| 端 | 企业端 |
| 分类 | 业务办理进度 / Business progress |
| 收件范围 | 本企业：该申请的债权人企业（发起企业）。不发给债务人企业，不发运营 |
| 触发 | 审核提交上链成功、申请状态由“待运营审核”变为“运营审核通过”时发送 |
| 不触发 | 审核通过未生效的任何情况（不满足审核条件、到期时点后提交、提交失败、重复提交、取消）；上链中；上链失败 |
| 同一事实的区分依据 | 债权人企业 + 申请编号 + “运营审核已通过”。一笔申请只会审核通过一次，只发一条；重复送达、重试、刷新不新增 |
| 发生时间 | 上链成功的时间（即审核时间） |
| 债权人企业暂时不能登录（如临时锁定） | 消息照常生成并保留，按 M10 规则在可查看后展示 |
| 原业务识别信息 | 申请编号、内销发票号 |
| 打开后去哪 | 原业务：M7a 中该申请的详情（只能查看） |
| 查看与办理条件 | 查看：本企业是该申请的发起企业且当前拥有债权人角色，按 M7a 规则。没有办理动作 |
| 必须出现的业务值 | 债务人企业名称、内销发票号、应收账款编号、申请编号；写明本企业在这笔业务中是债权人；写明审核通过的资料已上链存证 |
| 业务值取值 | 取审核通过生效时的值（企业名称、发票号、编号取当次依据），之后资料或状态变化不改写 |
| 不得出现 | 审核人姓名、审核说明、风控预警、上链凭证、上链失败记录；发票、合同等原件或下载地址 |

文案（按收件人的界面语言展示中文或 English；花括号为业务值，企业名称、发票号按原值展示不翻译）：

| 语言 | 标题 | 正文 |
| --- | --- | --- |
| 中文 | 运营审核已通过 | 贵企业就内销发票 {内销发票号}（应收账款编号 {应收账款编号}）向 {债务人企业名称} 发起的确权申请 {申请编号} 已通过运营审核，审核通过的资料已上链存证。贵企业在这笔业务中是债权人。详情可在申请详情中查看。 |
| English | Operations review approved | Confirmation request {request number} submitted by your company to {debtor name} for invoice {invoice number} (receivable {receivable number}) has been approved by operations, and the approved records have been recorded on chain. Your company is the creditor in this transaction. You can view the details in the request details. |

<a id="M9-NT03"></a>
## 运营审核上链失败（M9-NT03）

| 项目 | 规则 |
| --- | --- |
| 发送来源 | 运营审核（M9）；其他模块不发同义消息 |
| 端 | 运营端 |
| 分类 | 运营告警 / Operations alerts |
| 收件范围 | 全体运营。不发给企业 |
| 触发 | 一次审核提交的上链结果为失败时发送 |
| 不触发 | 上链中、上链成功、结果未返回；审核通过未形成审核提交的任何情况 |
| 同一事实的区分依据 | 全体运营 + 申请编号 + 提交次序 + “运营审核上链失败”。同一次审核提交只发一条；再次提交后又失败是新的事实，另发一条 |
| 发生时间 | 上链失败结果返回的时间 |
| 原业务识别信息 | 申请编号、内销发票号 |
| 打开后去哪 | 原业务：本模块中该申请的详情 |
| 查看与办理条件 | 查看：可正常使用的运营人员。办理：再次审核通过另需满足[可以审核通过的条件](./01-运营审核-PRD.md#review-conditions)；已由其他运营人员再次提交、已审核通过或已到期关闭时，前往后只能查看当前结果，按 M10 [前往原业务（MSG-05）](../../两端共用/M10-消息中心/01-消息中心-PRD.md#MSG-05)处理 |
| 必须出现的业务值 | 申请编号、内销发票号、应收账款编号、债权人企业名称、提交次序、失败原因；写明这笔申请尚未审核通过 |
| 业务值取值 | 取失败结果返回时的值；失败原因按返回原文展示，未返回原因时为“未返回失败原因”；之后不改写 |
| 不得出现 | 完整钱包地址；发票、合同等原件或下载地址 |

文案（按收件人的界面语言展示；花括号为业务值，企业名称、发票号、失败原因按原值展示不翻译）：

| 语言 | 标题 | 正文 |
| --- | --- | --- |
| 中文 | 运营审核上链失败 | 债权人 {债权人企业名称} 的内销发票 {内销发票号}（应收账款编号 {应收账款编号}，确权申请 {申请编号}）第 {提交次序} 次审核提交上链失败，原因：{失败原因}。这笔申请尚未审核通过，仍为待运营审核，请查看后重新审核通过。 |
| English | Review on-chain recording failed | On-chain recording for review submission {submission number} of creditor {creditor name}'s invoice {invoice number} (receivable {receivable number}, confirmation request {request number}) failed. Reason: {failure reason}. The request has not been approved and is still pending operations review. Please review it and approve again. |
