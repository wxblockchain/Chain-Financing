# 风控预警与三方数据源 · 消息通知

2026-11-12｜需求评审稿｜配套[功能与业务规则](./01-风控预警与三方数据源-PRD.md)

本模块发送 1 类站内消息，经消息中心（M10）展示，按[来源接入要求（MSG-06）](../../两端共用/M10-消息中心/01-消息中心-PRD.md#MSG-06)登记；必发，收件人不能关闭。本模块不发送邮件、短信，也不向企业端发送任何消息。

| 消息 | 端 | 所在功能 | 触发环节 | 谁收到 | 打开后去哪 |
| --- | --- | --- | --- | --- | --- |
| [新的风控预警（M8-NT01）](#M8-NT01) | 运营端 | [比对与预警生成（F-M8-01）](./01-风控预警与三方数据源-PRD.md#F-M8-01) | 平台新建一条预警 | 全体运营 | 本模块中该预警的详情 |

以下情况本模块不发消息：差异项追加到已有预警（含追加到已处理预警的“处理后新增”）；差异现状变为“差异已消除”或差异再次出现；回款金额偏差的比对结果追加到未处理预警；运营人员记录处理；无法比对；查看列表、详情；待办数量变化；三方数据源相关的任何情况。

<a id="M8-NT01"></a>
## 新的风控预警（M8-NT01）

| 项目 | 规则 |
| --- | --- |
| 发送来源 | 风控预警与三方数据源（M8）；其他模块不发同义消息 |
| 端 | 运营端 |
| 分类 | 运营告警 / Operations alerts |
| 收件范围 | 全体运营。不发给企业 |
| 触发 | 平台按[生成、追加与去重](./01-风控预警与三方数据源-PRD.md#item-rules)新建一条预警（状态“未处理”）时发送；三类预警类型都适用 |
| 不触发 | 见上文“以下情况本模块不发消息” |
| 同一事实的区分依据 | 全体运营 + 预警编号 + “新的风控预警”。一条预警只发一条；同一次资料更新新建多条预警时，每条预警各发一条，不合并。已处理之后同一比较对象再次新建的预警有新的预警编号，另发一条 |
| 发生时间 | 预警的生成时间 |
| 原业务识别信息 | 预警编号、预警类型 |
| 打开后去哪 | 原业务：本模块中该预警的详情 |
| 查看与办理条件 | 查看：可正常使用的运营管理员。办理：另需预警状态为“未处理”；已由其他运营管理员处理时，前往后只能查看当前结果，按 M10 [前往原业务（MSG-05）](../../两端共用/M10-消息中心/01-消息中心-PRD.md#MSG-05)处理 |
| 必须出现的业务值 | 预警编号、预警类型、比较对象、差异摘要、关联应收账款编号（多笔时第一笔并注明共几笔；没有时写“无”） |
| 业务值取值 | 取预警生成时的值，之后追加差异、差异现状变化或处理都不改写 |
| 不得出现 | 发票、合同、收付款凭证等原件或下载地址；银行账号；处理人姓名 |

差异摘要按各类型的写法生成：主体不一致见[主体不一致的预警内容](./01-风控预警与三方数据源-PRD.md#party-detail)，VIN 不一致见[VIN 不一致的预警内容](./01-风控预警与三方数据源-PRD.md#vin-detail)，回款金额偏差见[回款金额偏差的预警内容](./01-风控预警与三方数据源-PRD.md#repay-detail)。

文案（按收件人的界面语言展示中文或 English；花括号为业务值，主体名称、单据编号、VIN 按原值展示不翻译；预警类型按界面语言展示对应名称）：

| 语言 | 标题 | 正文 |
| --- | --- | --- |
| 中文 | 新的风控预警：{预警类型} | 平台比对发现{预警类型}，预警编号 {预警编号}。比较对象：{比较对象}。差异：{差异摘要}。关联应收账款：{关联应收账款编号}{，共 N 笔}。请核实后记录处理结果。预警不会自动阻止确权申请、运营审核或出库。 |
| English | New risk alert: {alert type} | A {alert type} has been detected, alert number {alert number}. Compared item: {compared item}. Difference: {difference summary}. Related receivables: {receivable numbers}{, N in total}. Please verify and record the result. The alert does not automatically block confirmation requests, operations review or asset release. |

- “{，共 N 笔}”只在关联应收账款多于一笔时出现；没有关联应收账款时“关联应收账款”后写“无”（English：None）。
- 差异摘要中的平台用语（如“等 N 处”“不在……的车辆中”“按汇率折算后”）随界面语言切换，主体名称、VIN、单据编号、金额、百分比不变。
