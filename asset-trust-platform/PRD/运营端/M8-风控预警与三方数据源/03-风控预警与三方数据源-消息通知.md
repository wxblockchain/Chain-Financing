# 风控预警与三方数据源 · 消息通知

2026-11-24｜需求评审稿｜配套[功能与业务规则](./01-风控预警与三方数据源-PRD.md)

本模块发送 2 类站内消息，经消息中心（M10）展示，按[来源接入要求（MSG-06）](../../两端共用/M10-消息中心/01-消息中心-PRD.md#MSG-06)登记；必发，收件人不能关闭。本模块不发送邮件、短信，也不向企业端发送任何消息。

| 消息 | 端 | 所在功能 | 触发环节 | 谁收到 | 打开后去哪 |
| --- | --- | --- | --- | --- | --- |
| [新的风控预警（M8-NT01）](#M8-NT01) | 运营端 | [比对与预警生成（F-M8-01）](./01-风控预警与三方数据源-PRD.md#F-M8-01) | 平台新建一条当前等级为阻断或预警的预警 | 全体运营 | 本模块中该预警的详情 |
| [风控规则已调整（M8-NT02）](#M8-NT02) | 运营端 | [风控规则配置（F-M8-19）](./01-风控预警与三方数据源-PRD.md#F-M8-19) | 一次等级调整、停用、启用或风控参数修改生效 | 全体运营 | 本模块中该规则的详情 |

以下情况本模块不发消息：新建当前等级为提示的预警；已停用规则（不再比对，不会新建预警）；规则调整未生效（未填原因、他人已调整、提交失败、取消）；规则调整后已有预警的等级变化（不补发、不撤回 M8-NT01）；差异项追加到已有预警（含“处理后新增”）；条件型规则数值更新；差异现状变为“差异已消除”或差异再次出现；阻断解除或恢复；运营人员记录处理；提示类自动解除；无法比较；查看列表、详情；待办数量变化；三方数据源相关的任何情况。

| 同一事实的区分依据 | 全体运营 + 预警编号 + “新的风控预警”。一条预警只发一条；同一次资料更新新建多条预警时，每条各发一条，不合并。回款风险、逾期、严重逾期是三条规则，进入每个阶段各新建一条预警、各发一条 |

## 风控规则已调整（M8-NT02）

| 项目 | 规则 |
| --- | --- |
| 发送来源 | 风控预警与三方数据源（M8）；其他模块不发同义消息 |
| 端 | 运营端 |
| 分类 | 业务提醒 / Business reminders |
| 收件范围 | 全体运营（含调整人本人）。不发给企业 |
| 触发 | [风控规则配置（F-M8-19）](./01-风控预警与三方数据源-PRD.md#F-M8-19)中一次调整等级、停用、启用或修改风控参数生效时发送 |
| 不触发 | 调整未生效的任何情况（未填写原因、等级或参数没有变化、参数不符合校验、他人已先调整、提交失败、结果未确认、取消） |
| 同一事实的区分依据 | 全体运营 + 规则编号或参数名称 + 本次调整的生效时间 + “风控规则已调整”。每次生效的调整各发一条；重复送达不新增 |
| 发生时间 | 调整生效的时间 |
| 原业务识别信息 | 规则名称及编号 |
| 打开后去哪 | 原业务：本模块中该规则的详情（含配置记录） |
| 查看与办理条件 | 查看：可正常使用的运营管理员。没有办理动作 |
| 必须出现的业务值 | 规则名称及编号（修改参数时为参数名称）、调整项（等级／启用状态／风控参数）、调整前、调整后、调整人姓名、调整原因原文；调整涉及阻断时另写明受影响的“待运营审核”申请笔数与已取得推送资格的资产笔数 |
| 业务值取值 | 取生效时的值，之后再次调整不改写；调整原因按原文展示，不翻译 |
| 不得出现 | 发票、合同、收付款凭证等原件或下载地址；银行账号 |
