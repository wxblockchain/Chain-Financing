# PRD 目录

产品需求文档统一存放于此，并按功能或版本组织子目录。

## 命名约定

- 单文档：`[版本号]-[功能名]-PRD.md`，例如 `v1.0-登录注册-PRD.md`。
- 模块化文档：每个功能建立独立子目录，包含 PRD 主文档及流程图、数据字典等附件。

## 现有文档

- `v1.0-账户与登录/`——资产端与资产管理端的账户与登录 PRD（对应需求 WS-302），按模块化方式拆为 7 个文件。入口是该目录下的 `v1.0-账户与登录-PRD.md`，其中含文件索引、编号索引与章节对照表。

## 模板要点

- 背景与目标
- 用户故事与需求清单
- 功能详述（交互流程、规则、边界）
- 数据要求
- 验收标准
